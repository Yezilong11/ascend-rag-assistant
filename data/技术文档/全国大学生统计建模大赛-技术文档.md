# 全国大学生统计建模大赛 参赛技术指南

## 一、赛事概述

**全国大学生统计建模大赛**是由中国统计教育学会主办的国家级学科竞赛，已连续举办十一届。大赛旨在倡导大学生学习统计、应用统计的良好氛围，适应大数据时代的高校数据科学人才培养需求，促进关注经济社会热点难点问题，提高大学生数据挖掘、数据分析、运用统计方法及计算机技术处理数据的能力，加强创新思维意识。

- **主办单位**：中国统计教育学会
- **协办单位**：教育部高等学校统计学类专业教学指导委员会、全国应用统计专业学位研究生教育指导委员会
- **承办单位**：各届总决赛由不同高校承办（第十二届承办单位待公布）
- **大赛官网**：http://tjjmds.ai-learning.net/

### 1.1 赛事影响力

2024年3月，大赛正式进入中国高等教育学会《2023全国普通高校大学生竞赛分析报告》竞赛目录，成为全国高校学科竞赛排行榜中的国家级竞赛。

## 三、竞赛主题与选题方向

### 3.1 2026年大赛主题

第十二届全国大学生统计建模大赛主题为：**“新质生产力与统计创新应用”**

### 3.2 选题方向要求

参赛队围绕大赛主题，自定选题进行统计建模和分析。选题方向包括但不限于：

| **方向领域** | **示例选题** |
| :--- | :--- |
| **经济社会问题** | 新质生产力测度与时空演进、区域经济高质量发展、数字经济与产业升级 |
| **大数据与人工智能** | 基于机器学习的预测建模、文本挖掘与情感分析、图像识别与统计应用 |
| **公共卫生与健康** | 疾病传播模型、医疗资源配置、健康影响因素分析 |
| **环境与可持续发展** | 碳排放预测、环境质量评价、绿色经济效率 |
| **金融与风险管理** | 金融风险测度、投资组合优化、信用风险评估 |
| **其他领域** | 可结合学科特色自定，须运用统计建模方法 |

## 四、作品技术规范

### 4.1 论文结构要求

| **部分** | **内容要求** |
| :--- | :--- |
| **首页** | 标题、参赛队员信息、指导教师信息、学校信息 |
| **摘要页** | 中英文摘要各一页，300-500字 |
| **目录页** | 自动生成目录 |
| **正文** | 引言、文献综述、理论基础、数据说明、模型构建、实证分析、结论建议 |
| **参考文献** | 按学术规范列出 |
| **附录** | 原始数据、代码、算法说明、附加图表等 |

### 4.2 论文格式技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **文件格式** | PDF |
| **正文字体** | 中文宋体，英文Times New Roman |
| **字号** | 小四号（12pt） |
| **行距** | 1.5倍行距 |
| **页数限制** | **正文≤25页**（不含摘要、目录、参考文献、附录） |
| **文件大小** | ≤50MB |

### 4.3 数据处理要求

| **要求项** | **技术规格** |
| :--- | :--- |
| **数据来源** | 须注明数据来源，鼓励使用公开数据或自主采集数据 |
| **数据处理** | 须说明数据清洗、预处理过程 |
| **统计分析软件** | 可使用R、Python、SPSS、Stata、SAS、MATLAB、EViews等 |
| **代码提交** | 鼓励提交原始代码作为附录 |

### 4.4 原创性与学术诚信

| **要求项** | **技术规格** |
| :--- | :--- |
| **原创性** | 参赛论文必须是参赛团队原创，未在公开出版物发表，未参加过其他竞赛 |
| **引用规范** | 引用他人成果必须在正文中标注，并在参考文献中列出 |
| **查重要求** | 查重率一般≤20%（具体以当年通知为准） |
| **AI工具使用** | 如使用AI工具辅助，须在附录说明工具名称、版本和使用方式 |
