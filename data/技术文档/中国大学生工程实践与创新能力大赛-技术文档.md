# 中国大学生工程实践与创新能力大赛 参赛技术指南

## 一、赛事概述

**中国大学生工程实践与创新能力大赛**（简称“工创赛”）是教育部高等教育司主办、教育部工程训练教学指导委员会举办的国家级大学生科技创新竞赛。大赛是列入《教育部评审评估和竞赛清单（2021年版）》的重要赛事，是全国工程实践教育领域最具影响力的竞赛之一。

- **主办单位**：教育部高等教育司
- **举办单位**：教育部工程训练教学指导委员会
- **官方网站**：http://www.gcxl.edu.cn/

---

## 二、赛道设置与技术方向

2025年大赛设置**三个赛道**，各赛道下设不同赛项：

### 2.1 新能源车赛道

| **赛项** | **技术方向** | **核心任务** |
| :--- | :--- | :--- |
| **太阳能电动车** | 太阳能高效利用、能量管理、轻量化设计 | 设计制作以太阳能为主要能源的电动车，完成竞速、爬坡等任务 |
| **温差电动车** | 温差发电技术、热能管理、储能系统 | 设计制作以温差发电为动力的电动车，完成规定路线行驶 |

### 2.2 “智能+”赛道

| **赛项** | **技术方向** | **核心任务** |
| :--- | :--- | :--- |
| **智能物流搬运** | 机器人定位导航、路径规划、物料识别、运动控制 | 设计智能机器人完成指定区域的物料识别、抓取、搬运和投放 |
| **生活垃圾智能分类** | 图像识别、机器学习、机械臂控制、多传感器融合 | 设计智能装置实现生活垃圾的自动识别、分类和投放 |
| **智能救援** | 环境感知、自主导航、目标识别、救援策略 | 设计智能机器人在模拟灾害场景中完成救援任务 |
| **水下管道智能巡检** | 水下机器人设计、图像识别、自主巡航 | 设计水下机器人完成管道识别、缺陷检测和报告 |

### 2.3 虚拟仿真赛道

| **赛项** | **技术方向** | **核心任务** |
| :--- | :--- | :--- |
| **工程场景数字化** | 数字孪生、虚拟仿真、工业机器人编程 | 在虚拟环境中完成工厂布局、产线设计和生产仿真 |
| **企业运营仿真** | 企业资源规划、生产管理、供应链优化 | 模拟企业运营全过程，进行经营决策和绩效优化 |
| **智能网联汽车设计** | 智能网联汽车架构、传感器配置、控制算法 | 在虚拟环境中完成智能网联汽车的设计、仿真和测试 |

## 三、参赛资格技术规范

### 3.1 参赛对象

| **类别** | **技术规格** |
| :--- | :--- |
| **学历层次** | 全国各类本科院校在籍本科学生 |
| **专业范围** | 专业不限，鼓励跨学科组队 |

### 3.2 组队技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **队员人数** | 3-4名学生（不同赛项略有差异） |
| **指导教师** | ≤2名 |
| **跨校组队** | **不允许**跨校组队，须来自同一所学校 |
| **每人限报** | 每人限参加1支队伍，每队限报1个赛项 |
| **每校限额** | 每个赛项每校≤2支队伍 |

## 四、作品技术规范

### 4.1 通用要求

| **要求项** | **技术规格** |
| :--- | :--- |
| **原创性** | 参赛作品须为学生原创，不得侵犯他人知识产权 |
| **匿名字符** | 参赛作品（小车/机器人）上不得出现表明参赛学校名称的字符和标志 |
| **实物参赛** | 新能源车赛道、“智能+”赛道均需实物参赛并现场运行 |
| **虚拟仿真** | 虚拟仿真赛道需在规定平台完成作品设计和运行 |

### 4.2 各赛项技术要求示例

#### 4.2.1 智能物流搬运机器人（第七届参考）

| **项目** | **技术规格** |
| :--- | :--- |
| **任务描述** | 识别二维码任务码→抓取物料→搬运至指定区域→投放 |
| **通信要求** | 决赛阶段需使用组委会提供的Wi-Fi通信程序源代码 |
| **场地识别** | 采用二维码、颜色标识或形状识别进行定位和分类 |
| **控制系统** | 自主设计，可使用单片机、嵌入式系统等 |

#### 4.2.2 生活垃圾智能分类（第七届参考）

| **项目** | **技术规格** |
| :--- | :--- |
| **分类种类** | 可回收物、厨余垃圾、有害垃圾、其他垃圾 |
| **识别方式** | 图像识别、重量检测、金属检测等多传感器融合 |
| **投放要求** | 机械臂或传送带实现自动分类投放 |
| **数据记录** | 记录分类结果、准确率、处理时间等指标 |

## 八、原创性与学术诚信技术规范

### 8.1 原创性要求

- 参赛作品须由学生自主构思、设计、制作和调试
- 不得直接使用教师科研成果或购买成品参赛
- 所有技术文档和源代码需体现学生原创性贡献

### 8.2 违规处理

| **违规行为** | **处理措施** |
| :--- | :--- |
| 冒用身份 | 取消参赛资格，通报学校 |
| 代工代做 | 取消参赛资格，通报学校 |
| 学校标识泄露 | 取消评奖资格 |
| 违反比赛规则 | 取消参赛资格 |
