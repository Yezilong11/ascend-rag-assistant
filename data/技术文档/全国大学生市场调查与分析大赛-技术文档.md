# 全国大学生市场调查与分析大赛 参赛技术指南

## 一、赛事概述

**全国大学生市场调查与分析大赛**（简称“市调大赛”）是由中国商业统计学会主办的国家级学科竞赛，已连续举办16届，是全国普通高校学科竞赛排行榜中的优秀竞赛项目。大赛旨在引导大学生创新和实践，提高学生的组织、策划、调查实施和数据处理与分析等专业实战能力，培养学生的社会责任感、服务意识、市场敏锐度和团队协作精神 [citation:1][citation:6]。

- **主办单位**：中国商业统计学会
- **冠名单位**：正大集团
- **第十六届总决赛承办单位**：
  - 专科组：武汉工商学院
  - 本科组：大连理工大学
  - 研究生组&在华留学生组：郑州大学 [citation:1]
- **高级合作伙伴**：益普索（中国）咨询有限公司 [citation:1]
- **大赛官网**：http://www.china-cssc.org/

## 二、组别设置与参赛资格

### 2.1 组别划分

| **组别** | **参赛对象** | **知识赛要求** |
| :--- | :--- | :--- |
| **本科组** | 团队成员均为本科生 | 须通过知识赛（网考）后方可组队参加实践赛 [citation:1][citation:6] |
| **研究生组** | 团队成员均为研究生 | 不参加知识赛，直接组队参加实践赛 [citation:1][citation:7] |
| **在华留学生组** | 团队中以留学生为主：3人团队≥2名留学生；4-5人团队≥3名留学生 | 不参加知识赛，直接组队参加实践赛 [citation:2][citation:3][citation:7] |

### 2.2 组队技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **队员人数** | **3-5人**/队 [citation:1][citation:2][citation:3] |
| **指导教师** | 1-3人/队 [citation:2][citation:3][citation:7] |
| **跨专业组队** | 鼓励跨专业、跨院系组队 [citation:1][citation:3][citation:7] |
| **跨校组队** | 原则上不可跨校，所有成员须来自同一所高校 [citation:1][citation:2][citation:3] |
| **每人限报** | 每名学生只能参加一个团队 [citation:1][citation:2][citation:3] |

## 四、实践赛技术规范

### 4.1 作品要求

| **项目** | **技术规格** |
| :--- | :--- |
| **作品形式** | 市场调查报告（含正文和附录）+ PPT |
| **正文页数** | ≤65页 [citation:2][citation:4][citation:5] |
| **正文字数** | ≤2万字 [citation:3] |
| **语言要求** | 在华留学生组须以中文撰写报告，展示答辩可选中文或中英双语 [citation:3][citation:7] |
| **原创性** | 参赛报告须为原创，不得抄袭 |

### 4.2 报告结构要求

| **部分** | **内容要求** |
| :--- | :--- |
| **正文** | 标题页、摘要页、目录页、正文页（按组委会规定的字体、字号、行间距、段间距等格式要求排版）[citation:2][citation:4] |
| **附录** | 调查过程照片、AI工具使用情况说明、数据分析过程编码脚本、原始数据等 [citation:2][citation:4][citation:5] |

### 4.3 匿名评审要求

报告任何一页不得出现参赛校名称、标识、指导教师姓名、学生姓名等信息，否则视为违规，取消参赛资格 [citation:3][citation:4][citation:5]。

### 4.4 地图使用规范

参赛报告和PPT中如有中国地图，必须规范使用信息完整的最新版地图，发现地图信息不完整将取消团队参赛资格 [citation:5][citation:8]。

### 4.5 查重要求

| **查重率** | **处理措施** |
| :--- | :--- |
| ≤20% | 符合要求 |
| >20% | 取消比赛成绩和参赛资格 [citation:2][citation:4][citation:5] |
| >40% | 视为学术不端行为，在大赛官网予以通报 [citation:2][citation:4][citation:5] |

### 4.6 AI工具使用规范

参赛队可以在竞赛期间使用人工智能工具，但必须遵循公开透明原则，并在附录中说明AI工具使用情况。确保参赛作品的核心调查与分析必须由参赛队独立完成 [citation:3][citation:5][citation:8]。

## 六、晋级名额技术指标

### 6.1 本科组晋级省赛名额

| **网考通过人数** | **晋级省赛队数计算方式** | **上限** |
| :--- | :--- | :--- |
| ≤300人 | 网考通过人数 ÷ 20（四舍五入） | ≤15支 [citation:2][citation:3][citation:6] |
| >300人 | (网考通过人数-300) ÷ 30 + 15（四舍五入） | ≤30支 [citation:2][citation:6] |

*注：省赛承办校可另外增加2支直接晋级团队 [citation:2]。*

### 6.2 研究生组晋级省赛名额

| **有效报名人数** | **晋级省赛队数计算方式** | **上限** |
| :--- | :--- | :--- |
| ≤200人 | 有效报名人数 ÷ 10（四舍五入） | ≤15支 [citation:2][citation:3] |
| >200人 | (人数-200) ÷ 20 + 15（四舍五入） | ≤20支 [citation:2] |

*注：省赛承办校可另外增加2支直接晋级团队 [citation:2]。*

### 6.3 留学生组晋级名额

各校选拔**≤3支**优秀团队直接参加全国赛 [citation:2][citation:3][citation:7]。
