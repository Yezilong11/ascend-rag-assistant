# 全国三维数字化创新设计大赛 参赛技术指南

## 一、赛事概述

**全国三维数字化创新设计大赛**（简称“全国3D大赛”）是由科技部、教育部、工信部、中国科协等部门指导，全国三维数字化创新设计大赛组委会、国家制造业信息化培训中心、全国三维数字化技术与教育培训联盟、北京光华设计发展基金会联合主办的国家级学科竞赛。大赛自2008年发起举办以来，已连续成功举办至第18届，被教育部正式列入全国高校学科评估体系。

- **指导单位**：科学技术部、教育部、工业与信息化部、中国科协
- **主办单位**：全国三维数字化创新设计大赛组委会、国家制造业信息化培训中心、全国三维数字化技术与教育培训联盟、北京光华设计发展基金会
- **大赛官网**：https://3dds.3ddl.net/

## 二、赛道设置与技术方向

### 2.1 开放赛项

| **赛项** | **技术方向** | **作品形式** |
| :--- | :--- | :--- |
| **数字工业设计大赛** | 工业产品设计/外观结构设计、模具设计、工程分析计算、仿真分析、数字孪生等 | 3D模型、设计图纸、仿真动画 |
| **数字人居设计大赛** | 建筑设计、室内外装饰设计、环境规划设计、BIM应用等 | 3D模型、效果图、动画 |
| **数字文化设计大赛** | 文化创意产品设计、数字艺术、新媒体艺术、微电影与动漫游戏等 | 3D模型、视频、交互作品 |
| **元宇宙创建大赛** | 游戏开发、3D视频制作、虚拟空间设计等 | 元宇宙作品 |

## 三、参赛资格技术规范

### 3.1 参赛对象

| **项目** | **技术规格** |
| :--- | :--- |
| **学历层次** | 全国各类高等院校在籍本科生、研究生、高职高专学生 |
| **组别划分** | 本科生组、研究生组、高职高专组（开放赛项）；专项赛按参赛指南报名 |

### 3.2 组队技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **队员人数** | ≤5人/队 |
| **指导教师** | 1-2名/队 |
| **跨校组队** | 允许跨专业、跨院系、跨校组队 |
| **每人限报** | 每名学生参赛作品数不限 |
| **指导老师指导** | 指导教师可以指导多队 |
