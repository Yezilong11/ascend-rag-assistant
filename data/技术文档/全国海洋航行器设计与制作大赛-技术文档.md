# 全国海洋航行器设计与制作大赛 参赛技术指南

## 一、赛事概述

**全国海洋航行器设计与制作大赛**是由中国科学技术协会、工业和信息化部指导，中国造船工程学会、中国船舶重工集团公司、中国船舶工业集团公司主办的国家级学科竞赛[citation:3]。大赛自2012年起每年举办一届，是我国船舶与海洋工程领域内层次最高、规模最大、覆盖面最广的竞赛[citation:3][citation:7]。竞赛的宗旨为“崇尚科学、实践求知、锐意创新、面向海洋、服务国防”[citation:3]。

- **指导单位**：中国科学技术协会、工业和信息化部
- **主办单位**：中国造船工程学会、中国船舶重工集团公司、中国船舶工业集团公司
- **组委会挂靠单位**：中国造船工程学会
- **秘书处挂靠单位**：西北工业大学[citation:3]
- **大赛官网**：http://www.csname.org.cn/cms[citation:2]
- **报名平台**：https://cmvc.moocollege.com/[citation:1][citation:6]

### 1.1 第十四届（2025年）参赛规模
2025年第十四届大赛吸引了全国近400家单位、3345支队伍、1.6万余名师生参赛[citation:7]。

### 1.2 第十五届（2026年）安排
第十五届全国海洋航行器设计与制作大赛将于**2026年8月**举行全国总决赛[citation:2][citation:5][citation:7]。

## 二、赛道设置与技术方向

第十四届、第十五届大赛设**七大类赛项**，具体如下[citation:1][citation:6][citation:7]：

| **类别** | **赛项名称** | **技术方向/细分类别** |
| :--- | :--- | :--- |
| **A类** | 创新、创意及创业（“三创”） | A1 新概念创意设计、A2 技术难题求解、A3 前沿科技与产业发展挑战、A4 科普创意设计与实践 |
| **B类** | 设计与制作 | B1 水面组、B2 水下组 |
| **C类** | 智慧船舶与海洋工程技术 | C1 智能航行、C2 模拟对岸火力支援、C3 智能感知、C4 智能导航 |
| **D类** | 名船名舰模型仿真制作 | — |
| **E类** | 船模竞速 | E1 常规动力组、E2 改装动力组 |
| **F类** | 帆船模型竞速 | F1 现代帆船竞速、F2 中式古帆船竞速 |
| **G类** | 海洋知识竞赛 | — |

## 三、参赛资格与组队规范

### 3.1 参赛对象

| **项目** | **技术规格** |
| :--- | :--- |

| **项目** | **技术规格** |

## 四、作品技术规范

### 4.1 各类别作品要求

| **类别** | **作品形式要求** |
| :--- | :--- |
| **A类（创意设计）** | 须提供项目可行性报告，内容包括创新点、计算过程、设计图纸、实施途径、应用前景等；需要提供功能演示视频或实物模型[citation:2] |
| **B类（设计与制作）** | 完成具有创新性的实物或原理样机制作[citation:5] |
| **C类（智慧船舶）** | 舰船模型智能航行与特种作业，需进行实航竞赛[citation:3] |
| **D类（名舰模型）** | 模型仿真制作，提交实物模型及制作说明 |
| **E/F类（竞速类）** | 船模/帆船模型竞速，需进行现场竞速比赛 |
| **G类（知识竞赛）** | 海洋知识综合测试 |

### 4.2 提交材料清单

| **材料类型** | **规格要求** |
| :--- | :--- |
| **参赛作品说明书** | 完整纸质版，A/B/C/D类需一式六份（其中一份需有各参赛队员完整签名及学校或学院盖章）；E/F类一式一份[citation:6][citation:9] |
| **作品简介** | A/B/C类需提交200字以内并附两张图片的简介[citation:6][citation:9] |
| **电子版资料** | 作品说明书、简介、PPT、演示视频[citation:6][citation:9] |
| **宣传海报** | A1/D类需提交制作宣传海报的电子版（60cm×160cm），名船名舰外观模型仿真制作类海报不得出现参赛单位信息[citation:4][citation:6] |
| **功能演示视频** | 展示作品核心功能及运行效果 |

### 4.3 原创性与学术诚信

| **要求项** | **技术规格** |
| :--- | :--- |
| **原创性** | 参赛作品必须是参赛团队原创，不得抄袭、盗用他人成果[citation:3] |
| **保密处理** | 如有涉密项目，必须作脱密处理后方可参赛[citation:4][citation:6] |
| **往届限制** | 曾经获奖但已实质性改进并再创新的作品，经资格审查同意、公示后无异议方可参赛[citation:3] |

## 五、赛程技术时间轴

### 5.1 第十五届大赛时间安排（2026年）

| **阶段** | **时间节点** | **技术任务** |
| :--- | :--- | :--- |
| **校内选拔赛** | 2025年11月-2026年4月 | 各高校自行组织选拔[citation:2][citation:5] |
| **中期检查** | 2026年4月 | 部分高校组织中期检查[citation:2][citation:5] |
| **区域赛报名** | 2026年5月-6月 | 登录网络平台选择所在区域报名 |
| **区域赛举办** | 2026年6月-7月 | 各区域赛现场答辩/评审[citation:1][citation:6] |
| **国赛作品修改** | 2026年7月下旬 | 晋级国赛队伍修改相关信息及资料[citation:6] |
| **全国总决赛报到** | **2026年8月上旬** | 报到及作品调试 |
| **全国总决赛** | **2026年8月** | 现场比赛、答辩、颁奖[citation:1][citation:2][citation:5] |

### 5.2 区域赛划分

大赛设东北、华北、华东、华中、华南、西北、西南等区域赛，各参赛单位参加本省所在区域赛[citation:6]。若本省无区域赛，可就近自主选择参加其他省份区域赛[citation:6]。

### 5.3 晋级规则

国赛参赛作品由区域赛晋级产生，不得越级报名参加国赛[citation:6]。

## 七、评审技术指标

### 7.1 评审方式

| **类别** | **评审形式** | **说明** |
| :--- | :--- | :--- |
| **创意设计类（A）** | 材料审查+现场答辩[citation:3] | 两部分评分总和为综合成绩 |
| **实物制作类（B）** | 材料审查+实物演示+现场答辩[citation:3] | 三部分评分总和为综合成绩 |
| **智能航行类（C）** | 实航竞赛[citation:3] | 按比赛规则评定成绩 |
| **模型制作类（D）** | 材料审查+实物评审 | — |
| **竞速类（E/F）** | 现场竞速 | — |
| **知识竞赛类（G）** | 笔试/现场答题 | — |

### 7.2 评审维度

| **维度** | **考察要点** |
| :--- | :--- |
| **创新性** | 设计思路的独创性、技术突破、功能原理创新[citation:2][citation:3] |
| **科学性** | 技术方案的合理性、理论依据 |
| **可行性** | 实施途径的可行性、经济应用价值[citation:3] |
| **完成度** | 实物/模型的完整性、功能实现程度 |
| **现场表现** | 答辩逻辑、演示效果、实航成绩 |

## 十、参赛注意事项

### 10.1 信息核对
- 报名系统中的团队名字和作品名字必须保持一致，参赛过程中不得修改[citation:1][citation:6]
- 网站报名数据将作为成绩认定、颁发与核验证书的唯一依据[citation:6]
- 作者排序以报名表为准，获奖证书按此排序制作[citation:3]

### 10.2 时间节点
- 区域赛报名截止时间以各区域赛通知为准
- 国赛作品信息修改时间通常在7月下旬，仅可修正错别字[citation:6]

### 10.3 领队与评委推荐
- 各参赛单位需上报领队老师1位，推荐大赛评委1位[citation:6]
- 领队老师负责赛前宣传与报名工作、赛中学校领队、赛后奖状及奖杯收发[citation:6]

### 10.4 校旗提交
- 国赛报到时需提交参赛单位3号校（所）旗一面（192×128cm），赛后随奖状一同寄回[citation:6]
