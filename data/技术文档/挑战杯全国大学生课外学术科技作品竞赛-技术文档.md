# “挑战杯”全国大学生课外学术科技作品竞赛 参赛技术指南

## 一、赛事概述

**“挑战杯”全国大学生课外学术科技作品竞赛**（简称“大挑”）是由共青团中央、中国科协、教育部、中国社会科学院、全国学联和承办高校所在省（市）人民政府主办的国家级学科竞赛，每两年举办一届。竞赛被誉为当代大学生科技创新的“奥林匹克”盛会，始终坚持“崇尚科学、追求真知、勤奋学习、锐意创新、迎接挑战”的宗旨[citation:9]。

- **主办单位**：共青团中央、中国科学技术协会、教育部、中国社会科学院、中华全国学生联合会、承办地省级人民政府
- **官方网站**：http://www.tiaozhanbei.net/
- **技术支持电话**：（010）52878507
- **技术支持邮箱**：kefu@tiaozhanbei.net

## 二、作品类别与赛道设置

### 2.1 三大作品类别

| **类别** | **内容说明** | **字数/页数限制** | **参赛对象限制** |
| :--- | :--- | :--- | :--- |
| **自然科学类学术论文** | 信息技术、数理科学、生命科学、能源化工等领域的基础学科学术探索 | 8000字以内[citation:4] | 仅限本科生[citation:6][citation:10] |
| **哲学社会科学类社会调查报告** | 经济、政治、文化、社会、生态文明建设5个组别，扎根实际、深入一线 | **15000字以内**[citation:1][citation:3][citation:4] | 本科/硕士/博士均可 |
| **科技发明制作** | A类：科技含量较高、制作投入较大；B类：投入较少、为生产技术或社会生活带来便利的小发明[citation:4] | 不限 | 本科/硕士均可 |

### 2.2 专项赛道

第十九届/第二十届大赛设置以下专项赛道[citation:1][citation:3]：

| **专项赛道** | **技术方向** |
| :--- | :--- |
| **“人工智能+”专项** | 运用人工智能技术赋能经济、金融、管理、法律、公共治理、文化、教育等各领域的前沿探索与应用创新 |
| **“乡村振兴+”专项** | 围绕乡村产业、人才、文化、生态、组织“五大振兴”中的关键问题开展学术研究或实践探索 |

## 三、参赛资格技术规范

### 3.1 参赛对象

| **学历层次** | **参赛资格** |
| :--- | :--- |
| **本科生** | 2026年6月1日前正式注册的全日制非成人教育在校本科生[citation:2][citation:7] |
| **硕士研究生** | 同上（不含在职研究生）[citation:2][citation:6] |
| **博士研究生** | 仅可作为项目团队成员参赛（不作项目负责人），且人数不超过团队成员数量的30%[citation:2] |

### 3.2 作品时间要求

申报参赛的作品必须是**距2026年6月1日之前两年内**完成的学生课外学术科技或社会实践活动成果[citation:6][citation:10]。毕业设计和课程设计（论文）、学年论文和学位论文、国际竞赛中获奖作品、获国家级奖励成果等均不在申报范围之列[citation:1][citation:3][citation:6]。

### 3.3 组队技术规格

| **项目** | **个人作品** | **集体作品** |
| :--- | :--- | :--- |
| **作者人数** | 1人独立完成，或2人合作完成[citation:1][citation:3] | 3-10人/队（部分高校限≤8人[citation:6][citation:10]或≤10人[citation:2]） |
| **第一作者要求** | 必须承担申报作品60％以上的研究工作，发表的有关作品署名均应为第一作者[citation:1][citation:3][citation:6] | 须有1名团队负责人 |
| **合作者限制** | 合作者必须是学生且不得超过2人[citation:1][citation:3][citation:6] | 所有作者必须均为学生 |
| **指导教师** | ≤3人[citation:1][citation:2][citation:3] | ≤3人 |
| **跨校组队** | 允许，以项目负责人所在学院进行申报[citation:2] | 允许，以项目负责人所在学院进行申报 |

### 3.4 高级职称教师要求（部分高校）

| **项目** | **技术要求** |
| :--- | :--- |
| **普通作品** | 指导教师中须包含至少2名副高级及以上职称的专业教师[citation:1][citation:3] |
| **“人工智能+”专项** | 指导教师中必须包含至少1名正高级职称专业教师，且作品应依托高水平科研项目开展[citation:1][citation:3] |
| **“乡村振兴+”专项** | 同上 |

## 四、作品技术规范

### 4.1 提交材料清单

| **材料类型** | **格式要求** | **规格说明** |
| :--- | :--- | :--- |
| **作品申报表** | Word + PDF | 按官方模板填写，需签字盖章[citation:1][citation:3] |
| **参赛作品正文** | PDF | 社会调查报告/学术论文全文（含标题、摘要、正文、参考文献）[citation:6] |
| **项目介绍材料** | PPT转PDF | **20页以内**[citation:2][citation:7][citation:9] |
| **项目详细介绍材料** | PDF | 可选提交[citation:2] |
| **项目介绍视频** | MP4 | 可选提交，≤100M[citation:2]或≤20MB[citation:7] |
| **支撑材料** | 单个PDF整合 | 专利证明、第三方应用证明、鉴定证书等[citation:2] |

### 4.2 社会调查报告技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **字数限制** | **15000字以内**[citation:1][citation:3][citation:4] |
| **内容要求** | 与我国当前经济社会发展结合度高、前瞻性强的调查研究 |
| **特别说明** | 为党政部门、企事业单位所作的各类发展规划、工作方案和咨询报告，已被采用者亦可申报参赛，同时附上原件和采用单位证明的复印件和鉴定材料[citation:1][citation:3] |

### 4.3 学术论文技术规格

| **项目** | **自然科学类学术论文** | **哲学社会科学类学术论文** |
| :--- | :--- | :--- |
| **字数限制** | 8000字以内[citation:4] | 15000字以内 |
| **研究领域** | 信息技术、数理科学、生命科学、能源化工[citation:6][citation:10] | 经济、管理、法律、社会、教育、历史、哲学等 |

### 4.4 匿名评审要求

部分高校要求提交**匿名版作品**（不得出现作者姓名、指导教师姓名、学校信息），具体以各校通知为准[citation:10]。

### 4.5 查重要求

部分高校要求提交**知网查重报告**，确保作品原创性[citation:10]。

## 五、知识产权与证明材料技术规范

### 5.1 知识产权要求

| **情况** | **需提交材料** |
| :--- | :--- |
| **涉及知识产权** | 具有法律效力的发明创造或专利技术所有人的书面授权许可、项目鉴定证书、专利证书[citation:2][citation:9] |
| **动植物新品种** | 省级及以上农科部门或科研院所开具的证明[citation:9] |
| **国家保护动植物研究** | 省级及以上林业部门开具的证明[citation:9] |
| **新药物研究** | 卫生行政部门授权机构的鉴定证明[citation:9] |
| **医疗卫生研究** | 专家鉴定，最好附有公开发表文章[citation:9] |
| **燃气用具等安全研究** | 国家相应行政部门授权机构的认定证明[citation:9] |

### 5.2 已工商注册项目要求

| **项目** | **技术规格** |
| :--- | :--- |
| **需提交材料** | 单位概况、法定代表人情况、加载统一社会信用代码的营业执照、股权结构等[citation:2][citation:9] |
| **项目负责人要求** | 必须为企业法定代表人，在省赛通知发布之日后变更的不予认可[citation:9] |

## 七、评审技术指标

### 7.1 评审维度

| **维度** | **考察要点** |
| :--- | :--- |
| **科学性** | 理论依据充分，研究方法科学，数据真实可靠 |
| **先进性** | 创新性突出，技术难度高，学术价值或应用价值显著 |
| **现实意义** | 对社会热点、难点问题的回应，实践指导价值 |
| **实践过程** | 社会调研、实地考察、数据采集的完整性[citation:9] |
| **团队协作** | 成员结构合理性、分工协作能力[citation:9] |

## 八、学术诚信技术规范

### 8.1 原创性要求

| **要求** | **说明** |
| :--- | :--- |
| **原创性** | 参赛作品必须是参赛团队真实项目，不得侵犯他人知识产权[citation:9] |
| **往届限制** | 已获往届“挑战杯”国赛奖励的作品不得重复参赛[citation:6] |
| **重复参赛** | 杜绝雷同作品重复参赛、抄袭他人成果和学术造假行为[citation:1][citation:3] |

### 8.2 违规处理

| **违规行为** | **处理措施** |
| :--- | :--- |
| 学术不端 | 取消作品参赛资格，取消二级单位优秀组织奖评选资格[citation:1][citation:3] |
| 剽窃、盗用 | 取消参赛资格，自负法律责任[citation:9] |
| 提供虚假材料 | 取消参赛资格 |
