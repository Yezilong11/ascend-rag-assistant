# 全国大学生节能减排社会实践与科技竞赛 参赛技术指南

## 一、赛事概述

**全国大学生节能减排社会实践与科技竞赛**是由教育部高等学校能源动力类专业教学指导委员会指导，全国大学生节能减排社会实践与科技竞赛委员会主办的大学生课外科技作品和社会实践调查竞赛[citation:2][citation:3]。竞赛紧密围绕国家“双碳”战略目标等重大需求，以“节能减排、绿色能源”为主题，已发展成为起点高、精品多、覆盖面广且影响力大的全国大学生实践创新活动[citation:1][citation:5]。

- **指导单位**：教育部高等学校能源动力类专业教学指导委员会
- **主办单位**：全国大学生节能减排社会实践与科技竞赛委员会
- **第十九届国赛承办单位**：大连理工大学[citation:1][citation:3]
- **大赛官网**：http://www.jienengjianpai.org/
- **作品申报系统**：http://upc01.jienengjianpai.org/

---

## 二、竞赛主题与内容

### 2.1 竞赛主题

第十九届竞赛主题为：**“节能减排，绿色能源”**[citation:1][citation:2][citation:5]。部分高校通知中提及“智行低碳·科创未来”等分主题[citation:8]。

### 2.2 竞赛内容

紧扣竞赛主题，作品包括[citation:3][citation:4][citation:6]：
- **实物制作（含模型）**
- **软件**
- **设计**
- **社会实践调研报告**

要求体现新思想、新原理、新方法以及新技术。

### 2.3 作品分类

竞赛分为两大类[citation:1][citation:4]：
- **科技作品类**：含实物、模型、软件、设计等
- **社会实践调查报告类**：含社会调查、实践报告等

## 三、参赛资格与组队规范

### 3.1 参赛对象

| **项目** | **技术规格** |
| :--- | :--- |
| **学历层次** | 全日制非成人教育的专科生、本科生、硕士研究生、博士研究生（不含在职研究生）[citation:2][citation:4] |
| **组别划分** | 参赛队伍按照研究生组和本（专）科生组分别比赛，队伍中有研究生参加的归类为研究生组[citation:1][citation:5] |

### 3.2 组队技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **队员人数** | **≤7人**/队[citation:1][citation:5][citation:6] |
| **指导教师** | ≤3名/队，如聘请3名指导教师，其中1名必须是企业技术人员或交叉学科老师[citation:1][citation:3][citation:7] |
| **每人限报** | 每位同学参赛作品不超过2项（部分高校要求）[citation:5] |
| **跨校组队** | 允许混合组队，按第一作者所在高校统计[citation:9] |

### 3.3 高校推荐限额

每所高校限报**15项**作品参加国赛[citation:2][citation:5][citation:9]。

## 四、作品技术规范

### 4.1 提交材料清单

| **材料类型** | **规格要求** | **备注** |
| :--- | :--- | :--- |
| **作品申报书** | 按官方模板填写，需签字盖章 | 科技类/社会实践类模板不同[citation:1][citation:7] |
| **作品说明书/报告** | 科技类≤10页；社会实践类≤16页，约5000字[citation:3] | PDF格式 |
| **介绍视频** | **3-5分钟**，大小**≤20MB**[citation:1][citation:3][citation:7] | 必需提交 |
| **其他佐证材料** | PPT、标志性图片、专利受理文件、论文、应用证明等 | 大小≤10MB[citation:1] |
| **诚信承诺书** | 参赛成员及指导教师签署[citation:2][citation:10] | 需提供身份证号 |

### 4.2 作品完成时间要求

参赛作品必须是**2026年当年完成**的作品[citation:1][citation:4][citation:6]。

### 4.3 原创性与学术诚信

| **要求项** | **技术规格** |
| :--- | :--- |
| **原创性** | 所有参赛作品必须为原创，严禁抄袭或侵犯他人知识产权[citation:8] |
| **学术不端处理** | 一旦发现并查实学术不端问题，涉事学生**永久禁赛**，相关指导教师**禁赛两年**；对涉事学校进行警告；如再次违犯则该校**禁赛2年**[citation:2][citation:4][citation:9] |

## 十、参赛注意事项

### 10.1 关键时间提醒

| **事项** | **时间节点** |
| :--- | :--- |
| **校赛报名截止** | 各校集中在3月上中旬（3月6日-29日） |
| **省赛决赛** | 2026年4月-5月 |
| **国赛决赛** | **2026年8月上旬** |

### 10.2 材料准备要点

| **要点** | **说明** |
| :--- | :--- |
| **视频要求** | 3-5分钟，≤20MB，过大会影响作品评分[citation:7] |
| **申报书签字** | 校赛阶段无需签字盖章，推送省赛/国赛需完成签字盖章[citation:7] |
| **人员顺序** | 获奖证书按系统最终提交顺序为准，不得随意更改[citation:5][citation:7] |
| **命名规范** | 严格按各校要求的命名格式提交，否则视为无效 |

### 10.3 入群要求

所有参赛选手须实名加入各校官方QQ群，关注群通知和比赛进程，未加群导致错过通知者后果自负[citation:1][citation:3][citation:5]。
