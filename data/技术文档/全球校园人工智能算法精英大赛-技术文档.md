# 全球校园人工智能算法精英大赛 参赛技术指南

## 一、赛事概述

**全球校园人工智能算法精英大赛**（简称“AIC算法大赛”）由江苏省人工智能学会主办，自2019年起已连续举办七届，吸引来自全球26个国家和地区、1000多所高校选手参赛。2023年，该赛事被列入中国高等教育学会《全国普通高校学科竞赛排行榜》，正式跻身全国性学科竞赛行列 [citation:3]。

- **主办单位**：江苏省人工智能学会
- **大赛官网**：https://www.aicomp.cn/
- **大赛主题**：智青春·算未来 [citation:1][citation:7]
- **秘书处地址**：南京大学鼓楼校区费彝民楼B1013室 [citation:2]
- **2024年参赛规模**：参赛人数突破3.7万 [citation:4][citation:6][citation:7]

## 三、参赛资格与组队规范

### 3.1 参赛对象

| **项目** | **技术规格** |
| :--- | :--- |
| **学历层次** | 全球高校在校研究生、本科生、专科生均可报名参赛 [citation:1][citation:2][citation:3] |
| **专业范围** | 不限专业 |

### 3.2 组队技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **队员人数** | ≤3人/队，可单人创建队伍 [citation:1][citation:3][citation:4] |
| **跨校组队** | 不允许跨校组队，须来自同一所学校（不含分校）[citation:1][citation:4][citation:7] |
| **指导教师** | ≤2人/队 [citation:1][citation:4][citation:7] |
| **队长职责** | 每支团队设置1名队长，负责团队管理及提交比赛结果 [citation:1][citation:4] |
| **多赛题参赛** | 每个参赛团队可选择多个赛题参赛 [citation:1][citation:4][citation:7] |
| **同赛题限报** | 同一赛题，每位选手只能加入一个团队参赛 [citation:1][citation:4][citation:7] |
| **人员变更** | 报名截止后，参赛团队及指导老师信息均不得变更 [citation:1][citation:4][citation:7] |

## 四、赛制与赛程技术规范

### 4.1 赛制模式

| **赛道** | **赛制模式** | **晋级规则** |
| :--- | :--- | :--- |
| **算法创新赛、算法应用赛** | 校赛-省赛-总决赛三级赛制 [citation:3][citation:7][citation:10] | 校赛成绩前30%晋级省赛；省赛一、二等奖晋级总决赛 [citation:10] |
| **算法挑战赛、算法主题赛** | 初赛-复赛-总决赛三级赛制（不分赛区）[citation:2][citation:7] | 复赛成绩前40%进入半决赛，半决赛前40%进入总决赛 [citation:2] |
| **产业命题赛、算法专项赛** | 详见各专项通知 [citation:7] | — |

### 4.2 评审流程

| **阶段** | **评审形式** | **晋级比例/要求** |
| :--- | :--- | :--- |
| **初赛** | 线上自动判分 | 设置基础性任务，达到基本成绩均可进入复赛 [citation:2] |
| **复赛** | 线上评审 | 成绩排名前40%选手进入半决赛 [citation:2] |
| **半决赛** | 线上评审 | 成绩排名前40%选手进入总决赛 [citation:2] |
| **总决赛** | 线下答辩 | 对选手解题思路进行评判打分，同时对技术报告、模型、源代码等材料进行复核 [citation:2][citation:5] |

### 4.3 第七届大赛时间安排（2025-2026年）

| **阶段** | **时间节点** | **技术任务** |
| :--- | :--- | :--- |
| **报名系统开放** | 2025年6月20日 | 官网（www.aicomp.cn）开放报名 [citation:7] |
| **报名截止** | 各赛题不同（2025年9月-10月） | 各高校截止时间：9月1日（中北大学）、9月10日（无锡学院）、9月25日（新乡工程学院）、10月15日（河南大学）、10月24日（新疆师范大学） |
| **校赛** | 2025年9月-10月 | 各校自行组织选拔 |
| **省赛/区域赛** | 2025年11月 | 各省/区域组织评审 |
| **总决赛** | **2026年2月-3月** | 线下答辩（2026年2月8日神思智飞具身智能挑战赛总决赛在济南举办）[citation:5] |
