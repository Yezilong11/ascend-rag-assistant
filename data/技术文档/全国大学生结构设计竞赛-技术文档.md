# 全国大学生结构设计竞赛 技术文档

## 一、赛事概述

**全国大学生结构设计竞赛**是经教育部、财政部联合批准（教高函〔2007〕30号）的全国性九大学科竞赛资助项目之一，被誉为“土木建筑工程皇冠上璀璨的明珠”[citation:1][citation:9]。该竞赛由浙江大学于2005年发起，现由中国高等教育学会工程教育专业委员会、高等学校土木工程学科专业指导委员会、中国土木工程学会教育工作委员会、教育部科学技术委员会环境与土木水利学部共同主办，各高校轮流承办，每年举办一届[citation:1][citation:9]。

### 1.1 办赛宗旨
竞赛旨在培养大学生的创新意识、合作精神和工程实践能力，为高等学校开展创新教育和实践教学改革、加强高校与企业之间联系、推动学科创新活动起到积极示范作用[citation:1]。

### 1.2 第十九届基本信息
- **举办时间**：2026年10月14日-18日
- **举办地点**：内蒙古科技大学
- **大赛官网**：http://www.structurecontest.com/
- **竞赛秘书处**：设在浙江大学
- **赛事级别**：全国性9大学科竞赛资助项目

## 三、参赛资格与组队要求

### 3.1 参赛对象
全国普通高校在籍的全日制本科生、专科生，专业不限[citation:1][citation:3]。

### 3.2 组队要求

| **项目** | **要求** |
| :--- | :--- |
| **队员人数** | 每支参赛队由**3名学生**组成[citation:1][citation:3][citation:10] |
| **指导教师** | 可指定**1-2名指导教师**（3名及以上署名指导组）[citation:1] |
| **成员要求** | 参赛学生必须属于同一所高校在籍的全日制本科生、专科生[citation:1] |
| **指导教师要求** | 必须是参赛队所属高校在职教师[citation:1] |
| **跨校组队** | **不允许**跨校组队，须来自同一所学校 |

### 3.3 指导教师职责
指导教师有责任保证参赛成员身份的真实性，负责指导参赛队选题、组织学生参加赛前培训，同时负责竞赛过程中与学校及组委会之间的信息沟通[citation:1]。

## 四、竞赛方式与赛制

### 4.1 两级赛制
竞赛分省（市）分区赛和全国总决赛两个阶段进行[citation:1]：

| **阶段** | **时间安排** | **说明** |
| :--- | :--- | :--- |
| **省（市）分区赛** | 2026年4月-7月 | 由各省（市）教育行政部门或委托相关学会主办，高校轮流承办[citation:4][citation:8] |
| **全国总决赛** | 2026年10月14日-18日 | 在内蒙古科技大学举行[citation:4][citation:8] |

### 4.2 参赛名额分配

**全国总决赛参赛高校来源**[citation:1]：
1. 全国竞赛发起高校及承办过全国竞赛的高校
2. 当年承办各省（市）分区赛的高校
3. 各省（市）分区赛推荐的高校
4. 适当邀请部分境内外高校

**参赛队数量规定**[citation:1]：
- 参加全国总决赛的高校推荐**1个参赛队**
- 当年承办全国总决赛的高校可推荐**2个参赛队**
- 全国总决赛参赛高校总数一般控制在**100-120所**

### 4.3 竞赛过程
竞赛过程包括以下环节[citation:1]：
- 参赛报名、提交方案
- 开幕式
- 现场制作模型
- 陈述答辩
- 加载测试
- 专家点评
- 闭幕式（颁奖仪式）

参赛队必须参与完成上述全过程，方可取得参赛成绩[citation:1]。

### 4.4 竞赛方式特点
全国总决赛一般采用**提前公布题目**，在同一时间、地点，使用**统一材料、工具制作**和统一设备测试等方式[citation:1]。省（市）分区赛可根据实际情况，参照全国总决赛方式或采取其他竞赛方式[citation:1]。

## 六、作品与赛题要求

### 6.1 竞赛题目特点
历届赛题涵盖桥梁、塔式结构等类型[citation:9]。2026年第十九届竞赛题目于1月上旬正式公布，倡导各省（市、自治区）竞赛秘书处和承办省赛高校开展**自主命题**组织分区赛，其目的是推进更多高校参与赛题的自主研发[citation:4][citation:8]。现已公布的赛题在完成分区赛后，全国总决赛题目将作适当补充变化与调整[citation:4][citation:8]。

### 6.2 第十八届赛题参考（2025年）
2025年第十八届赛题涉及“**乌篷船式模型结构设计与制作**”[citation:9]。

### 6.3 第十六届赛题参考（2023年）
2023年第十六届赛题为“**撞击荷载下变参数两跨四车道桥梁结构设计与制作**”，以承受移动荷载和撞击荷载的两跨四车道桥梁为对象，通过加入部分待定参数，自定荷载放入3D打印联排车移动荷载，赋予赛题更多的灵活性，同时增加现场设计环节，强调对未来卓越工程师综合能力的全面要求[citation:2]。

### 6.4 校赛赛题示例（洛阳理工学院2026年）
以**装配式结构**为核心对象，要求参赛者完成结构模型的设计、预制构件制作、现场装配及加载测试。引入竖向及冲击荷载测试，以精准检验预制构件之间连接节点的抗冲击性能、结构整体的抗变形能力及能量吸收能力[citation:5]。

## 八、竞赛纪律与要求

### 8.1 诚信要求
- 参赛学生和指导教师必须严格遵守《章程》、《实施细则》等各项规定，诚信参赛，服从裁判[citation:1]
- 严禁校与校之间、队与队之间和社会第三方机构提供方案与制作模型交流等现象[citation:4][citation:8]

### 8.2 材料统一要求
为使竞赛更为公平公正客观，参赛高校师生应按照大赛统一规定提供的制作材料、工具和测试仪器，避免由于规定之外模型竹材和工具及测试设备所引起带来不公平的现象和申诉事件的发生[citation:4][citation:8]。

### 8.3 违纪处理
- 全国总决赛违纪事件由全国竞赛专家委员会和秘书处负责处理[citation:1]
- 各省（市）分区赛违纪事件由赛区组委会秘书处负责处理，并报全国竞赛秘书处备案[citation:1]
- 对出现违纪行为并处理不力的高校，视情节可给予公开通报批评或取消其下一年度参赛评奖资格[citation:1]

### 8.4 申诉处理
全国和各省（市、自治区）评审专家委员会全权负责对参赛作品的雷同、作弊、违规、违纪、违约、申诉和奖项设置调整等事项进行审核与综合分析，提出评判意见和酌情裁定[citation:4][citation:8]。
