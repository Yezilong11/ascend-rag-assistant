# 全国大学生交通运输科技大赛 参赛技术指南

## 一、赛事概述

**全国大学生交通运输科技大赛**是由中国交通教育研究会、中国交通运输协会、教育部高等学校交通运输类专业教学指导委员会主办的国家级学科竞赛。大赛旨在培养大学生的科技创新精神和实践能力，提高大学生科学素养，促进高校大学生学术活动开展，加强高校间大学生文化交流。

- **主办单位**：中国交通教育研究会、中国交通运输协会、教育部高等学校交通运输类专业教学指导委员会
- **大赛官网**：http://www.nactrans.com.cn/
- **信息发布及作品报送网址**：http://www.nactrans.net/

## 三、参赛资格技术规范

### 3.1 参赛对象

| **项目** | **技术规格** |
| :--- | :--- |
| **面向对象** | 全国开设交通运输类及相关专业的高校在校本科生、研究生 |
| **参赛单位** | 以高校、科研院所为大赛的基础组织单位 |

### 3.2 组队技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **队员人数** | ≤5人/作品 |
| **指导教师** | ≤2人/作品 |
| **推荐方式** | 大赛只接受高校的推荐作品，不接受个人或以团体名义的参赛申请 |
| **推荐数量** | 每一竞赛类或分赛道≤3件/校（获得省级一等奖可在相应分赛道增加推荐1件） |
| **同一作品限制** | 同一作品不得重复推荐 |

## 四、作品技术规范

### 4.1 作品范围

参赛作品必须是本次大赛之前**未参加过相关学科竞赛的成果**。

### 4.2 作品要求

| **项目** | **技术规格** |
| :--- | :--- |
| **原创性** | 所有参赛作品应为参赛者自主完成的原创性作品，不得把导师的科研成果而非成员自身成果的部分作为参赛作品 |
| **主题响应** | 所有参赛作品应围绕大赛主题，针对交通运输系统出现的具体问题，运用相关专业知识 |
| **评价标准** | 提出具有新颖性、可行性、实用价值，具备完成度及一定难度的优化方法或解决方案 |
| **作品形式** | 可以是实物模型、研究报告、设计图纸和计算机软件等 |
| **组别匹配** | 作品申报组别应符合作品实际内涵，以评审专家意见为准 |

### 4.3 作品评价维度

| **赛道** | **评价维度** |
| :--- | :--- |
| **本科生赛道** | 创新性、专业知识综合运用、实用价值、完成度 |
| **研究生赛道** | 在上述基础上增加：学术性、理论方法的科学严谨性、作品方案的系统性 |

## 六、评审技术规范

### 6.1 初评阶段

| **项目** | **技术规格** |
| :--- | :--- |
| **评审方式** | 网评 |
| **推荐比例** | 按竞赛类或分赛道参赛作品数量不超过20%的比例推荐参加决赛 |
| **评审依据** | 综合考虑作品对大赛主题的响应程度和作品自身质量 |
| **承办高校特别条款** | 如承办高校没有作品通过初评，可将其不同竞赛组的、得分最高的、仅限两件作品直接进入决赛 |

### 6.2 决赛阶段

| **项目** | **技术规格** |
| :--- | :--- |
| **评审方式** | 现场公开答辩 |
| **竞赛组划分** | 每20项作品左右划分一个竞赛组 |
| **答辩组组成** | ≥5位专家组成答辩组，同一答辩组内不得有2人来自同一单位 |
| **答辩时间** | 共20分钟（第一环节≤12分钟，第二环节问答） |
| **超时处理** | 超时停止答辩 |

### 6.3 复审答辩

各竞赛类或分赛道推荐的一等奖，由学术委员会会同执行委员会组织复审答辩，参加各竞赛组答辩的全体专家及大赛嘉宾为评委，进行综合评定，本阶段不设问答环节。
