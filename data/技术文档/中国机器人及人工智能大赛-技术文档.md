# 中国机器人及人工智能大赛 参赛技术指南

## 一、赛事概述

**中国机器人及人工智能大赛**是一项历史悠久、影响广泛的全国性学科竞赛。作为中国人工智能学会最早主办的竞赛之一，大赛自1999年创办以来已成功举办二十七届，2026年将举办第二十八届 [citation:1][citation:5]。大赛已列入中国高等教育学会发布的全国普通高等学校学科竞赛排行榜、全国普通高校大学生竞赛分析报告，是我国首个在机器人及人工智能领域开设的大型学科赛事 [citation:3][citation:4]。大赛旨在引导和激励广大青年学生弘扬创新精神，搭建良好的科技创新赛事平台，推动“人工智能+”“机器人+”新经济产业体系建设，培养“能动手”“敢创新”“善协作”的复合型人才 [citation:4][citation:9]。

- **主办单位**：中国人工智能学会 [citation:3][citation:4]
- **大赛官网**：https://www.caairobot.com/ [citation:1][citation:3][citation:4]
- **官方邮箱**：info#caairobot.com（请将#替换为@） [citation:1][citation:3]
- **官方微信公众号**：CRAIC [citation:1][citation:7]

| 智能文化创意创新赛 | 文化与AI融合、创意交互设计 |

## 三、参赛资格与组队规范

### 3.1 参赛组别

| **组别** | **适用对象** |
| :--- | :--- |
| **普通高等教育组** | 研究生、本科生 [citation:4] |
| **职业教育组** | 中职、高职（高专）、职业本科 [citation:4] |

### 3.2 组队技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **队员人数** | **1-3人**/队 [citation:3][citation:10] |
| **指导教师** | 1-2名/队 [citation:3][citation:10] |
| **跨校组队** | 不允许跨校组队，须来自同一所学校（不含分校） [citation:3] |
| **跨专业组队** | 鼓励跨专业、跨学科组合参赛 [citation:10] |
| **每人限报** | 每位作者在每个大类中只能提交1件作品，无论作者排名如何；参赛作品不得在本大赛的其他类别一稿多投 [citation:9] |

### 3.3 国赛队伍数量限制

同一赛项，参赛学校（不含分校）进入国赛队伍不能超过**3支**（含3支），创新类赛项除外 [citation:3]。

## 四、赛制与赛程技术安排

### 4.1 三级赛制

大赛采用“**校级选拔赛—省级选拔赛—全国总决赛**”三级赛制 [citation:3][citation:10]。

| **级别** | **组织单位** | **晋级规则** |
| :--- | :--- | :--- |
| **校级选拔赛** | 各高校 | 排名在前50%进入省级选拔赛 [citation:3] |
| **省级选拔赛** | 各省赛区组委会 | 原则上一、二等奖推荐参加国赛，推荐比例不超过对应赛项参赛队伍的50% [citation:3] |
| **全国总决赛** | 全国大赛组委会 | 现场评审，决出全国奖项 |

### 4.2 特殊晋级情况

有下列情况之一，需要参加全国组委会组织的省级层次选拔赛 [citation:3]：
- 对于已设立省赛组委会的地区，但由于本地区高校专业设置情况导致部分赛项不能成赛
- 未成立省赛组委会地区

### 4.3 第二十八届大赛时间安排（2026年）

综合官方预通知及各高校通知 [citation:1][citation:4][citation:6]：

| **阶段** | **时间节点** | **技术任务** |
| :--- | :--- | :--- |
| **预通知发布** | 2026年2月2日 [citation:1] | 大赛启动 |
| **校赛报名与作品提交** | **2026年3月-5月**（各校截止时间：3月15日、4月30日、5月15日不等） | 官网注册报名，提交参赛材料 |
| **校赛评审** | 2026年5月 | 各校组织评审 |
| **省级选拔赛** | **2026年6月** [citation:4] | 各省组织评审，推荐国赛作品 |
| **全国总决赛** | **2026年7月-8月** [citation:4] | 现场答辩、评审 |

## 五、作品提交技术规范

### 5.1 提交材料清单

各校要求略有差异，综合整理如下 [citation:10]：

| **材料类型** | **内容要求** | **规格限制** |
| :--- | :--- | :--- |
| **技术报告** | 详细阐述技术方案、创新点、实现过程 | PDF格式，按官方模板撰写 |
| **技术报告PPT演讲录屏** | 讲解技术报告内容 | ≤15分钟 |
| **参赛机器人实际演示视频** | 展示机器人功能、运行效果 | MP4格式 |
| **其他支撑材料** | 源代码、设计图纸、测试数据等 | 可选提交 |

### 5.2 原创性要求 [citation:9]

| **要求项** | **技术规格** |
| :--- | :--- |
| **完成时间** | 必须是参赛者在本届大赛期间完成的原创作品 |
| **重复参赛** | 与之前校外展出或获奖的作品雷同的作者前期作品，不得重复参赛 |
| **知识产权** | 参赛作品的版权必须属于参赛作者，不得侵权；凡已经转让知识产权或不具有独立知识产权的作品，均不得参赛 |
| **数据合规** | 参赛作品的数据应来源合规、信息处理恰当，不得引用涉密数据，不得侵犯个人隐私 |

## 六、评审技术指标

### 6.1 评审维度 [citation:10]

| **评审维度** | **权重** | **考察要点** |
| :--- | :--- | :--- |
| **技术先进性** | 30% | 所采用技术的创新性、与同类算法的性能对比、兼顾算法性能与硬件算力的平衡 |
| **实际工作量** | 40% | 功能模块自研程度、算法改进深度、系统架构完整性 |
| **项目完成度** | 30% | 视频展示与所述技术内容的关联性、技术解释的合理性 |

### 6.2 技术先进性评分细则 [citation:10]

| **得分区间** | **评价标准** |
| :--- | :--- |
| 25-30分 | 所采用技术具有很强的创新性，能很好兼顾运算平台的算法性能、硬件算力和能源供应的平衡 |
| 20-25分 | 所采用技术具有较强的创新性，能较好兼顾运算平台的算法性能、硬件算力和能源供应的平衡 |
| 0-20分 | 所采用技术具有的创新性一般，基本兼顾运算平台的算法性能、硬件算力和能源供应的平衡 |

### 6.3 实际工作量评分细则 [citation:10]

| **得分区间** | **评价标准** |
| :--- | :--- |
| 35-40分 | 能很好地阐明所用平台的系统架构、电子电路、传感系统、软件系统等技术细节，具有自研的核心硬件机构、对现有算法进行了重大的改进 |
| 30-35分 | 能较好地阐明所用平台的系统架构、电子电路、传感系统、软件系统等技术细节，具有自研的一般硬件机构、对现有算法进行了较大的改进 |
| 0-30分 | 能够阐明所用平台的系统架构、电子电路、传感系统、软件系统等技术细节，具有自研的硬件机构或对现有算法进行了改进 |

### 6.4 项目完成度评分细则 [citation:10]

| **得分区间** | **评价标准** |
| :--- | :--- |
| 25-30分 | 能够很好展示机器人的硬件平台和软件系统，展示机器人的各方面性能，并与技术先进性中所阐述的技术内容关联密切，能够对机器人的具体表现给出合理的技术解释 |
| 20-25分 | 能够较好展示机器人的硬件平台和软件系统，展示机器人的各方面性能，并与技术先进性中所阐述的技术内容基本一致，能够对机器人的具体表现给出较为合理的技术解释 |
| 0-20分 | 能够展示机器人的硬件平台和软件系统的技术细节，展示机器人的各方面性能，与技术先进性中所阐述的技术内容关联不大，不能够对机器人的具体表现给出解释 |
