# “挑战杯”中国大学生创业计划竞赛 参赛技术指南

## 一、赛事概述

**“挑战杯”中国大学生创业计划竞赛**（简称“小挑”）是由共青团中央、中国科学技术协会、教育部、中国社会科学院、中华全国学生联合会共同主办的国家级创新创业赛事，每两年举办一届。赛事旨在引导大学生将创新实践与社会需求结合，覆盖全国2700余所高校，累计吸引超300万学生参与[citation:1]。

- **主办单位**：共青团中央、中国科学技术协会、教育部、中国社会科学院、中华全国学生联合会
- **官方网站**：https://www.tiaozhanbei.net/ [citation:1]
- **官方微信公众号**：创青春[citation:3]

## 二、竞赛组别与技术方向

第十五届大赛聚焦**创新、协调、绿色、开放、共享**五大发展理念，设置五个主体组别[citation:3][citation:6][citation:8]：

| **组别** | **技术方向** | **应用场景示例** |
| :--- | :--- | :--- |
| **科技创新和未来产业** | 人工智能、智能制造、信息技术、大数据、生命科学、新材料、新能源、量子技术、元宇宙、低空经济、第六代移动通信 | 智能装备、AI算法平台、生物医药研发、新材料应用 |
| **乡村振兴和农业农村现代化** | 农林牧渔、电子商务、乡村旅游、城乡融合、林下经济、农业金融 | 智慧农业、农村电商、乡村旅游规划 |
| **社会治理和公共服务** | 政务服务、消费生活、医疗健康、教育培训、交通物流、人力资源、金融与财经法务 | 智慧政务平台、社区服务APP、医疗信息系统 |
| **生态文明建设和绿色低碳发展** | 环境治理、可持续资源开发、生态环保、清洁能源应用、新型电力系统、智能电网、新型储能 | 碳足迹监测、环保材料、新能源发电系统 |
| **文化创意和区域合作** | 工业设计、动漫广告、体育竞技、国际文化传播、对外交流培训、对外经贸、非遗传承 | 国潮文创产品、文化IP开发、跨境电商平台 |

*注：部分高校通知中组别名称略有差异（如“城市治理和社会服务”“生态环保和可持续发展”），但核心覆盖领域一致。*

### 2.2 专项赛

2026年度配套举办以下专项赛[citation:4]：
- **“揭榜挂帅”专项赛**：围绕关键核心技术及社会科学领域重大课题，由企业和科研机构发榜出题，高校学生团队揭榜打擂
- **东北振兴产业升级专项赛**：聚焦国家粮食安全、产业安全、能源安全、生态安全、国防安全等重点方向

*注：专项赛作品不纳入学校团体总分，同一作品不得同时参加主体赛道和专项赛道的评选[citation:4]。*

## 三、参赛资格技术规范

### 3.1 参赛对象

| **类别** | **技术规格** |
| :--- | :--- |
| **本科生** | 2026年6月1日前正式注册的全日制非成人教育在校本科生[citation:1][citation:3][citation:4] |
| **硕士研究生** | 同上 |
| **博士研究生** | 仅可作为项目团队成员参赛（不作项目负责人），且人数不超过团队成员数量的30%[citation:1][citation:3][citation:4] |

### 3.2 组队技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **队员人数** | 3-15人（多数高校限≤10人，个别≤15人）[citation:1][citation:2][citation:3] |
| **指导教师** | ≤3人（部分高校限≤5人）[citation:1][citation:2][citation:3] |
| **跨校组队** | 允许，但须事先明确项目申报单位[citation:4][citation:5][citation:9] |
| **每人限报** | 每人限参加1支队伍，每队限报1个项目[citation:1][citation:2][citation:4] |
| **跨专业组队** | 鼓励[citation:1][citation:3][citation:6] |

### 3.3 人员变更规则

| **时间节点** | **变更规则** |
| :--- | :--- |
| 报名截止前 | 可调整人员信息 |
| 报名截止后 | 只可进行人员删减，不可进行人员顺序调整及添加[citation:4][citation:5][citation:8] |

## 四、作品技术规范

### 4.1 基本要求

| **要求项** | **技术规格** |
| :--- | :--- |
| **原创性** | 应为参赛团队真实项目，不得侵犯他人知识产权，不得借用他人项目参赛[citation:3][citation:4][citation:5] |
| **往届限制** | 已获往届“挑战杯”国赛金奖（特等奖）、银奖（一等奖）的项目不可重复报名[citation:2][citation:3][citation:4] |
| **时间限制** | 申报项目须是距2026年6月1日前两年内完成的创业计划项目或社会实践活动成果（所有作品展示内容及佐证材料须为2024年6月之后产生）[citation:7] |
| **成果归属** | 原则上保证以学生为第一作者（第一成果所有者）[citation:7] |

### 4.2 提交材料技术规格

| **材料类型** | **规格要求** | **备注** |
| :--- | :--- | :--- |
| **项目申报表** | 按官方模板填写 | 需签字盖章[citation:1][citation:3][citation:5] |
| **商业计划书** | 样式、字数不作统一要求 | 按规范排版（正文小四楷体等）[citation:7] |
| **路演PPT** | ≤30页[citation:2]，或20页以内[citation:3][citation:7] | PDF格式[citation:3] |
| **一分钟介绍视频** | MP4格式，≤3分钟[citation:3][citation:7] | 可选提交 |
| **支撑材料** | 单个PDF整合 | 含专利证书、知识产权授权书、营业执照、获奖证明等[citation:1][citation:3][citation:4] |

### 4.3 知识产权材料要求

| **情况** | **需提交材料** |
| :--- | :--- |
| **涉及知识产权** | 具有法律效力的发明创造或专利技术所有人的书面授权许可、项目鉴定证书、专利证书[citation:1][citation:3][citation:4] |
| **已工商注册** | 单位概况、法定代表人情况、营业执照复印件、税务登记证复印件、组织机构代码复印件、股权结构等[citation:1][citation:3][citation:4] |
| **已注册项目负责人** | 须为企业法人代表（通知发布之日后变更的不予认可）[citation:3][citation:4][citation:5] |
| **动植物新品种/新药物** | 提供相关证明材料[citation:3][citation:8] |

### 4.4 匿名评审要求

校赛及省赛部分阶段采用匿名评审，商业计划书等材料中**不得出现指导教师及小组成员信息**[citation:10]。

## 六、评审技术指标

### 6.1 评审要点

突出实践导向，在考察项目商业价值的基础上，更加注重考察学生了解社会现状、关注社会民生、解决社会问题的意识、能力和水平[citation:3][citation:6][citation:7]。

| **评审维度** | **考察要点** |
| :--- | :--- |
| **社会价值** | 项目对社会问题的解决能力、社会效益 |
| **实践过程** | 社会调研、实地考察、市场验证的完整性 |
| **创新意义** | 技术/模式创新性、与现有方案的差异化 |
| **发展前景** | 市场潜力、商业模式可行性 |
| **团队协作** | 成员结构合理性、分工协作能力 |

### 6.2 评分权重参考
各高校可根据实际情况调整，一般路演答辩占主要权重。

## 八、原创性与学术诚信技术规范

### 8.1 原创性要求

| **要求** | **说明** |
| :--- | :--- |
| **真实项目** | 应为参赛团队真实项目，不得借用他人项目参赛[citation:3][citation:4][citation:5] |
| **知识产权** | 不得侵犯他人知识产权[citation:3][citation:4][citation:5] |
| **成果归属** | 原则上保证以学生为第一作者（第一成果所有者）[citation:7] |
| **购买成果** | 项目购买成果、借用成果、伪造成果造成的纠纷由项目组自行处理，主办方有权取消其参赛资格[citation:8] |

### 8.2 违规处理

| **违规行为** | **处理措施** |
| :--- | :--- |
| 剽窃、盗用 | 取消参赛资格，自负法律责任[citation:3][citation:4][citation:5] |
| 提供虚假材料 | 取消参赛资格[citation:3][citation:4][citation:5] |
| 重复报名（同一项目报多个组别） | 取消参赛资格[citation:4][citation:9] |

### 8.3 免责声明

竞赛组委会将严格保守参赛作品中涉及的技术及商业秘密。参赛者与发明创造或专利技术持有人之间的一切纠纷与组委会无关[citation:7]。
