# 东南·中国建筑新人赛 参赛技术指南

## 一、赛事概述

**东南·中国建筑新人赛**是由东南大学建筑学院主办、面向全国建筑学专业本科低年级学生的建筑设计竞赛。赛事源于2009年日本举办的“日本建筑新人赛”，后发展为“亚洲建筑新人赛”的中国区选拔赛，旨在为年轻设计者提供展示作品、交流思想的平台，帮助其形成个性化的设计思维[citation:1]。

- **主办单位**：东南大学建筑学院
- **合作单位**：东南大学建筑设计研究院有限公司、《建筑学报》等[citation:1]
- **竞赛官网**：http://www.archirookies.com/
- **赛事定位**：亚洲建筑新人赛中国区选拔赛，优胜者可代表中国参加亚洲建筑新人赛总决赛[citation:1]

## 四、赛程技术时间轴

### 4.1 标准赛程安排

| **阶段** | **时间节点** | **技术任务** |
| :--- | :--- | :--- |
| **作品提交** | 每年6月-7月 | 通过网络平台提交作品 |
| **初赛评审** | 7月-8月 | 线上评选，确定晋级作品 |
| **海选评选** | 8月上旬 | 评选出前100名作品[citation:1] |
| **决赛** | 8月下旬 | 线下答辩+评审[citation:1] |

### 4.2 评审流程

| **阶段** | **评审方式** | **说明** |
| :--- | :--- | :--- |
| **初赛** | 线上评选 | 由评审团进行网络评审[citation:1] |
| **海选** | 线上评选 | 确定前100强作品 |
| **决赛** | 线下答辩 | 现场答辩+评委点评，产生前三名等奖项[citation:1] |

## 五、评审技术指标

### 5.1 评审维度

| **维度** | **考察要点** |
| :--- | :--- |
| **创造性** | 设计思维的独创性、个性化的表达方式 |
| **合理性** | 设计逻辑的清晰度、功能与技术处理的合理性 |
| **表达性** | 图纸表现力、模型制作质量 |
| **完整性** | 设计方案的完成度、成果的完整性 |

### 5.2 评审标准
赛事鼓励学生展现**创造性与合理性并存**的设计思维[citation:1]，评审团队由高水平专家组成，保证评审的专业性和公正性[citation:1]。

## 八、原创性与学术诚信技术规范

### 8.1 原创性要求

- 参赛作品必须为参赛者本人设计课作业成果
- 可在原作业基础上进行修改完善，但须保持原创性[citation:1]
- 不得抄袭、盗用他人成果

### 8.2 违规处理

| **违规行为** | **处理措施** |
| :--- | :--- |
| 抄袭 | 取消参赛资格 |
| 代做 | 取消参赛资格 |
