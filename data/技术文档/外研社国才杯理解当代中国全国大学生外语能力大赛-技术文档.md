# “外研社·国才杯”“理解当代中国”全国大学生外语能力大赛 参赛技术指南

## 一、赛事概述

**“外研社·国才杯”“理解当代中国”全国大学生外语能力大赛**是基于已有20余年办赛历程的“外研社·国才杯”系列赛事升级而来，由北京外国语大学主办，外语教学与研究出版社承办。大赛已纳入中国高等教育学会《全国普通高校大学生竞赛分析报告》竞赛目录，是全国规模最大、影响力最广的外语类学科竞赛之一。

- **主办单位**：北京外国语大学
- **承办单位**：外语教学与研究出版社、北京外研在线数字科技有限公司、中国外语测评中心
- **大赛官网**：http://uchallenge.unipus.cn/
- **大赛指定平台**：iTEST智能测评云平台（https://itestcloud.unipus.cn/）、iWrite英语写作教学与评阅系统

## 二、竞赛组别与赛道设置

2026年大赛设置**英语组**和**多语种组**两大组别。

### 2.1 英语组

英语组分设多个赛项：

| **赛项名称** | **考查内容** | **官方指定平台** |
| :--- | :--- | :--- |
| **综合能力赛项** | 外语综合运用能力 | iTEST智能测评云平台 |
| **笔译赛项** | 笔译实践能力 | iTEST智能测评云平台 |
| **演讲赛项** | 定题演讲+即兴演讲 | — |
| **口译赛项** | 口译实践能力 | — |
| **短视频赛项** | 外语表达+创意内容 | — |

### 2.2 多语种组

多语种组覆盖**6个语种**，不设置分赛项，考查外语综合运用能力[citation:1][citation:2]：

| **语种** | **代码** | **考查形式** |
| :--- | :--- | :--- |
| 俄语 | R | 定题演讲+综合试卷 |
| 德语 | G | 定题演讲+综合试卷 |
| 法语 | F | 定题演讲+综合试卷 |
| 西班牙语 | S | 定题演讲+综合试卷 |
| 日语 | J | 定题演讲+综合试卷 |
| 韩国语 | K | 定题演讲+综合试卷 |

## 四、公开赛技术规范

### 4.1 公开赛定位

公开赛是由外研社主办的全国性赛事，可作为大赛的线上模拟赛。英语组公开赛可作为校赛选拔方式之一（以本校通知为准）；多语种组公开赛成绩不等同于省赛成绩[citation:2][citation:3]。

### 4.2 比赛时间

#### 英语组公开赛

英语组设多场比赛，可任选其中一场报名或同时报名多场比赛[citation:2][citation:3]。

#### 多语种组公开赛[citation:1]

| **比赛日期** | **比赛时间** | **参赛语种组别** |
| :--- | :--- | :--- |
| 2026年5月30日 | 9:30—11:40 | 俄语组、德语组、法语组 |
| 2026年5月30日 | 14:30—16:40 | 西班牙语组、日语组、韩国语组 |

**报名截止时间**：2026年5月26日17:00[citation:1]

**成绩查询时间**：2026年6月18日登录iTEST查看比赛成绩[citation:1][citation:2]

## 五、比赛题型与技术参数

### 5.1 多语种组比赛题型[citation:1]

多语种组比赛总分**140分**，总时长**130分钟**。

| **部分** | **分值** | **形式** | **时长/要求** |
| :--- | :--- | :--- | :--- |
| **定题演讲** | 40分 | 线上录制视频 | 演讲时长不超过2分钟 |
| **综合试卷** | 100分 | 线上答题 | 建议作答时长120分钟 |

### 5.2 综合试卷题型[citation:1]

| **题型** | **分值** |
| :--- | :--- |
| 阅读理解 | 40分 |
| 汉外翻译 | 30分 |
| 写作 | 30分 |

### 5.3 定题演讲题目

定题演讲题目与2026“外研社·国才杯”“理解当代中国”全国大学生外语能力大赛（多语种组）省赛定题演讲题目一致[citation:1]。
