# 全国大学生软件创新大赛 参赛技术指南

## 一、赛事概述

**全国大学生软件创新大赛**是由示范性软件学院联盟主办、面向全国高校大学生的国家级学科竞赛。大赛旨在提升大学生创新思维与实践能力，培养国家软件产业急需的高端人才，已成功举办十八届，在全国高校具有广泛影响力 [citation:1][citation:7]。

- **主办单位**：示范性软件学院联盟 [citation:6][citation:7]
- **全国赛承办**：西北工业大学 [citation:1][citation:7]
- **支持单位**：OPPO广东移动通信有限公司、青软创新科技集团股份有限公司 [citation:7]
- **大赛官网**：https://www.swcontest.com.cn/
- **官方微信公众号**：SWContest [citation:7]

---

## 二、赛道设置与技术主题

### 2.1 大赛主题
第十九届大赛主题为：**“软件定义世界，创新引领未来”**，赛题聚焦 **“AI无界·创见未来”** [citation:1][citation:4][citation:7]。

### 2.2 六个技术赛道
赛题细分为以下六个方向，参赛作品需覆盖至少一个核心场景 [citation:1][citation:4][citation:7]：

| **赛道** | **技术方向** | **应用场景示例** |
| :--- | :--- | :--- |
| **全场景移动办公智能体** | 语音指令触发多任务处理、录音转写、自动生成纪要、一句话生成PPT | 会议内容整理、日历关联待办、移动端模板匹配 |
| **随身AI互动导学** | 视觉识别与几何生成、知识图谱、长视频知识点萃取 | 数学题3D解题步骤、历史事件时间轴、视频课程一键萃取 |
| **智能生活服务工具** | 图像识别、多模态感知、实时数据分析 | 菜单成分识别（过敏原）、出行规划整合、离线行程表 |
| **AI全模态影像处理** | 端侧低bit量化、一句话调色、AGI相机功能 | 照片色调复刻、手工艺品3D演示动画生成 |
| **AI协同互动游戏** | 自然语言理解AI队友、语音指令执行战术、万物生成器 | 团队战斗语音指挥、赛博朋克武器模型生成 |
| **随身AI健康管家** | 药品识别、定时提醒、多设备数据整合 | 药盒识别并设置提醒、心率/血糖/睡眠数据生成健康报告 |

## 三、参赛资格与技术规范

### 3.1 参赛对象
普通高等院校在籍学生（含本科生、研究生及以上学历）[citation:1][citation:3][citation:4]。

### 3.2 组队技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **队员人数** | ≤6人（其中队长1名，其他队员≤3名）[citation:1][citation:3][citation:4] |
| **指导教师** | ≤2名 [citation:1][citation:3][citation:4] |
| **跨校组队** | **允许**跨校组队，以队长所在院校为准 [citation:1][citation:3][citation:4] |
| **每人限报** | 每名参赛学生限参加一支队伍 [citation:1][citation:3][citation:4] |
| **每队作品数** | 每个参赛队伍只能提交一个软件作品 [citation:1][citation:3][citation:4] |

### 3.3 人员变更规则
- **截止时间**：区域赛初赛作品提交截止后成员信息不得修改 [citation:1][citation:3]
- **赛队名称**：不得含有不文明语言，需避开学校名称或其他可识别学校信息的字眼 [citation:1][citation:3]

## 四、作品技术规范

### 4.1 作品形式要求

| **维度** | **技术规范** |
| :--- | :--- |
| **完整性** | 一个完整的软件作品，需围绕赛题针对真实应用场景 [citation:5][citation:7] |
| **技术深度** | 具备一定技术深度，解决方案设计完备 [citation:5][citation:7] |
| **工程规范** | 严格按照软件工程基本规范开发，编程风格良好，注释清晰，文档完整 [citation:5][citation:7] |
| **可验证性** | 最终作品需能够在比赛现场实际运行并进行功能展示 [citation:5][citation:7] |

### 4.2 技术平台与工具

| **类别** | **技术要求** |
| :--- | :--- |
| **移动端开发** | 基于**Android平台**开发（手机端展示）[citation:5][citation:7] |
| **其他硬件** | 可自由选择耳机、手环、平板、智能眼镜、家庭机器人、可穿戴设备等 [citation:5][citation:7] |
| **开源工具** | 允许使用各类开源的本地发现、通讯、数据传输等工具 [citation:5][citation:7] |
| **AI模型** | 可自行选择模型架构、设计训练策略、进行模型训练和调优 [citation:5][citation:7] |
| **开源声明** | 使用开源模型必须在文档和代码中明确呈现开源及非开源部分 [citation:5][citation:7] |
| **云服务** | 根据实际需要自行选择 [citation:5][citation:7] |

### 4.3 技术能力支持
OPPO将为进入区域赛复赛的参赛团队提供部分能力支持，选手可选择申请使用（具体能力清单见大赛官网附件）[citation:5][citation:7]。

### 4.4 提交材料技术规格

| **材料类型** | **规格要求** |
| :--- | :--- |
| **源代码** | 完整工程文件，符合工程规范，注释清晰 |
| **设计文档** | 按大赛规定模板格式提交 [citation:5][citation:7] |
| **演示视频** | 展示作品核心功能和运行效果 |
| **其他材料** | 按各阶段通知要求提交 |

### 4.5 匿名评审要求
为确保公平公正，大赛采用**匿名评审**。参赛团队提交的所有材料内容中均**不得透露学校信息和参赛成员姓名**。组委会保留取消违反匿名评审规定的团队参赛资格的权力 [citation:7]。

### 4.6 原创性要求
- 参赛作品必须是**原创且未参加过其他国家级公开比赛**的作品 [citation:5][citation:7]
- 作品的核心工作、关键组件、主要开发过程须在本次大赛期间完成 [citation:5][citation:7]
- 一经发现抄袭、重复参赛，取消比赛资格和成绩 [citation:5][citation:7]

## 五、赛制与技术评审流程

### 5.1 六级赛区划分
大赛设**6大区域赛** [citation:1][citation:3][citation:7]：

| **赛区** | **覆盖范围** | **承办单位** |
| :--- | :--- | :--- |
| **东北赛区** | 黑龙江、吉林、辽宁、内蒙古 | 东北大学 [citation:7] |
| **华北赛区** | 北京、天津、河北、山西、河南 | 北京交通大学 [citation:7] |
| **华东赛区** | 山东、江苏、上海、浙江、福建、安徽、江西、台湾 | 山东大学 [citation:7] |
| **华南赛区** | 广东、广西、湖南、湖北、海南、香港、澳门 | 华南理工大学 [citation:7] |
| **西北赛区** | 陕西、甘肃、宁夏、青海、新疆 | 西北大学 [citation:7] |
| **西南赛区** | 重庆、四川、贵州、云南、西藏 | 四川大学 [citation:7] |

### 5.2 三级赛制流程

| **级别** | **阶段** | **评审方式** | **晋级规则** |
| :--- | :--- | :--- | :--- |
| **区域赛** | 初赛、复赛、决赛 | 线上通信评审+线上答辩会议评审 [citation:3] | 每一轮成绩不带入下一轮 [citation:3] |
| **全国赛复赛** | 通信评审 | 线上评审 | 区域复赛排名前25%入围全国复赛，共计不少于100支队伍 [citation:1][citation:3] |
| **全国赛决赛** | 线下答辩演示 | 现场答辩+作品演示 | 区域赛复赛前3%直推全国决赛 [citation:1][citation:3] |

### 5.3 评审技术指标
- **创新性**：技术应用与解决方案的独创性
- **技术深度**：技术实现的复杂程度和完整性
- **工程规范**：代码质量、文档完整性、注释清晰度
- **用户体验**：交互设计、场景适配度
- **现场表现**：答辩逻辑、演示效果
