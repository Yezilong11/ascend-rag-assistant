# 全国高等院校数智化企业经营沙盘大赛 参赛技术指南

## 一、赛事概述

**全国高等院校数智化企业经营沙盘大赛**是由中国商业联合会主办的国家级学科竞赛，自2005年发起以来已成功举办二十届，有效推动了经管实践教学与创新创业教育的融合[citation:2][citation:3]。大赛已入选中国高等教育学会《全国普通高校大学生竞赛排行榜》，是全国规模最大、影响最广的企业经营模拟类赛事之一[citation:3]。

- **主办单位**：中国商业联合会[citation:9]
- **技术支持**：新道科技股份有限公司[citation:3][citation:5]
- **竞赛平台**：新道数智企业经营管理沙盘平台[citation:3][citation:5][citation:9]
- **大赛官网**：http://spbk.seentao.com/

---

## 二、赛道设置与技术方向

大赛通过还原真实的企业数智化转型应用场景，要求参赛选手模拟企业核心管理岗位，完成数智企业经营管理[citation:3][citation:5]。

### 2.1 角色分工

| **岗位** | **职责** |
| :--- | :--- |
| **营销总监** | 市场调查与分析、营销数字化、市场开拓 |
| **财务总监** | 财务数字化、融资管理、成本控制 |
| **生产总监** | 生产智能化、产能规划、物料管理 |
| **人力总监** | 人力资源管理智能化、人员配置、绩效管理 |

*数据来源：[citation:3][citation:5]*

### 2.2 核心考察能力

| **能力维度** | **技术要点** |
| :--- | :--- |
| **数字化战略** | 依据数据驱动决策，制定企业发展战略 |
| **数字化思维** | 利用数字手段分析问题、解决问题 |
| **数字化执行** | 生产智能化、财务数字化、营销数字化的实操能力 |
| **大数据应用** | 统计分析、数据管理运用、变化应对能力 |

*数据来源：[citation:3][citation:5]*

## 三、参赛资格与技术规范

### 3.1 参赛对象

| **组别** | **面向对象** |
| :--- | :--- |
| **本科组** | 普通高等学校全日制在籍本科学生[citation:2][citation:5] |
| **高职组** | 高职院校全日制在籍学生[citation:2] |
| **研究生组** | 普通高等学校全日制在籍研究生[citation:7] |

### 3.2 组队技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **队员人数** | **4名学生**[citation:2][citation:3][citation:5] |
| **指导教师** | 1-2名[citation:2][citation:3][citation:5] |
| **跨校组队** | **不允许**跨校组队[citation:2][citation:5][citation:7] |
| **每校限额** | 每所学校报名参赛队不超过**2支**[citation:2][citation:5][citation:7] |
| **国赛晋级** | 每校最多**1支**队伍进入全国总决赛[citation:2][citation:9] |

### 3.3 人员变更规则

| **时间节点** | **变更规则** |
| :--- | :--- |
| 报名截止前 | 可修改团队成员信息 |
| 报名截止后 | 不得换人、不得增人、不得更改队员次序[citation:1] |
| 特殊情况 | 可减少队员（需报备），不得增加 |

## 四、竞赛平台技术规格

### 4.1 竞赛平台

| **项目** | **技术规格** |
| :--- | :--- |
| **竞赛平台** | 新道数智企业经营管理沙盘平台[citation:2][citation:3][citation:5] |
| **平台网址** | https://edu.seentao.com/sworldweb/race/home [citation:9] |
| **登录要求** | 实名制注册，已有账号可找回密码[citation:9] |

### 4.2 系统自动评分机制

竞赛评分采用**系统按照规则自动生成**，无人为因素干扰[citation:2][citation:5][citation:7]。

| **阶段** | **评分方式** |
| :--- | :--- |
| **校赛** | 依据第四年企业经营发展指数排名（破产按时间先后排名）[citation:9] |
| **省赛/国赛** | 沙盘模拟对抗赛(60%) + 管理创新路演答辩(40%)[citation:9] |

### 4.3 排名规则

| **优先级** | **排序依据** |
| :--- | :--- |
| **第1顺位** | 企业经营发展指数（或综合成绩）[citation:9] |
| **第2顺位** | 企业权益[citation:9] |
| **第3顺位** | 企业商誉值[citation:9] |
| **特殊处理** | 提前破产按破产时间先后排名；全程未经营取消名次[citation:9] |

## 九、原创性与学术诚信技术规范

### 9.1 原创性要求
- 参赛作品必须是**原创**，不得抄袭、盗用他人成果[citation:2][citation:5][citation:7]
- 如果出现知识产权纠纷，由学生自己承担相关责任[citation:2][citation:5][citation:7]

### 9.2 学术诚信
- 严禁冒用他人姓名申报参赛，一经发现立即取消参赛资格[citation:2][citation:5]
- 参赛选手须遵守比赛规程，诚信参赛[citation:1]
- 作弊行为处理：取消成绩、通报学校、取消下一年度参赛资格[citation:1]
