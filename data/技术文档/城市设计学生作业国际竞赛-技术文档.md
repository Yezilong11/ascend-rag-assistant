# WUPENiCity 城市设计学生作业国际竞赛 参赛技术指南

## 一、赛事概述

**WUPENiCity城市设计学生作业国际竞赛**是由世界规划教育组织（WUPEN）、联合国教科文组织iCity网站联合主办的国际性学科竞赛，面向全球高校城乡规划及相关专业在读学生。该赛事是国内城乡规划专业领域级别最高、最权威的竞赛之一[citation:5][citation:10]。

- **主办单位**：世界规划教育组织（WUPEN）、联合国教科文组织iCity网站（IKCEST-iCity Website）、城乡空间规划前沿杂志（GUIHUA Journal）[citation:1][citation:3]
- **竞赛平台**：https://wupen.org/
- **竞赛主题（2026年）**：**“美好生活HAI家园”**（Better HAI Jiayuan）[citation:1][citation:3]

---

## 二、竞赛主题技术解读

### 2.1 主题内涵
2026年竞赛主题为“美好生活HAI家园”，要求参赛者以独特、新颖的视角解析主题内涵，以全面、系统的专业素质进行城市设计[citation:1][citation:3]。

| **关键词** | **技术解读** |
| :--- | :--- |
| **家园（Jiayuan）** | 中国人对于城市最基础社会空间的共同认知，通过合理的资源分配与空间规划实现：人与自然永续生态、人与人和谐关系、人机间创新协同、物质与精神可持续发展[citation:1][citation:3] |
| **HAI** | Humanity + Artificial Intelligence（人类+人工智能），将人类创造力、决策能力与AI高效算力深度融合的全新人机交互模式[citation:1][citation:3] |
| **AICITY** | 将城市打造为有机生长的“高级智能生命体”[citation:1][citation:3] |

### 2.2 选题方向
参赛者可基于HAI核心理念，从以下城市场景的智能化升级维度切入[citation:1][citation:3]：
- 交通出行、教育文化、医疗服务
- 公共安全、政务创新、商业运营
- 居住环境、消费体验等

## 五、报名与提交流程

### 5.1 时间节点

| **阶段** | **时间** | **说明** |
| :--- | :--- | :--- |
| **注册报名与成果提交开启** | 2026年03月02日 | — [citation:1][citation:3] |
| **最终成果提交截止** | **2026年05月31日 18:00（北京时间）** | 逾期系统关闭 [citation:1][citation:3] |
| **一、二、三等奖及提名奖公布** | 2026年07月初 | — [citation:1][citation:3] |
| **人气奖投票** | 另行通知 | — [citation:1][citation:3] |

### 5.2 报名流程

| **步骤** | **操作说明** |
| :--- | :--- |
| **1. 平台注册** | 团队所有成员在 WUPEN 网站（http://wupen.org）完成用户注册 [citation:1][citation:3] |
| **2. 进入竞赛页面** | 由团队负责人前往竞赛页面选择竞赛进行报名 [citation:1][citation:3] |
| **3. 填写报名信息** | 填写必填项，点击保存即完成报名，获得**参赛码** [citation:1][citation:3] |
| **4. 上传作品** | 在作品提交截止日前上传展板文件、封面文件等材料 [citation:1][citation:3] |
| **5. 确认提交** | 确认无误后点击提交，作品进入待评审后台，不可再更改 [citation:1][citation:3] |

### 5.3 作品修改规则
- 从报名开始至作品提交截止日，可随时编辑修改表单信息、上传作品[citation:1][citation:3]
- 可在竞赛首页点击“取消报名”放弃参赛[citation:1][citation:3]
- 一旦点击提交并确认，作品即进入待评审后台，不可再更改[citation:1][citation:3]
- 获奖证书将按照报名时团队成员在表单上的填写顺序排序[citation:1][citation:3]

### 5.4 参赛费用
大赛**不收取报名费、参赛费**，所有参赛费用由参赛团队自理[citation:1][citation:3]。

## 六、评审与奖项技术指标

### 6.1 评审流程

| **阶段** | **评审方式** | **说明** |
| :--- | :--- | :--- |

| **第一轮专家评审** | 线上评审 | 按得分排序晋级 [citation:1][citation:3] |
| **第二轮专家评审** | 线上评审 | 综合两轮得分确定最终获奖名单 [citation:1][citation:3] |

### 6.2 奖项设置与获奖比例

| **奖项** | **获奖比例** | **说明** |
| :--- | :--- | :--- |
| **一等奖** | 得分前1% | 电子版获奖证书 [citation:1][citation:3] |
| **二等奖** | 得分前2-5% | 电子版获奖证书 [citation:1][citation:3] |
| **三等奖** | 得分前6-10% | 电子版获奖证书 [citation:1][citation:3] |
| **提名奖** | 得分前11-15% | 电子版获奖证书 [citation:1][citation:3] |
| **人气奖** | 10份 | 投票产生，电子版获奖证书 [citation:1][citation:3] |

| **奖项** | **名额** | **评选方式** |
| :--- | :--- | :--- |
| **优秀组织奖** | 10席 | 按学校积分排名：一等奖3分、二等奖2分、三等奖1分 [citation:1][citation:3] |

### 6.4 同分处理规则

若出现综合得分相同情况[citation:1][citation:3]：
- **第一轮评审**：同分作品同时晋级，相应入选或奖项名额随之增加
- **第二轮评审**：由评委会统一讨论投票决定一、二、三等奖归属

## 七、原创性与学术诚信技术规范

### 7.1 原创性要求

参赛方案必须是**参赛者个人原创作品**，不能侵犯任何第三方个人和单位的任何专利权、著作权、商标权及其他合法知识产权[citation:1][citation:3]。

### 7.2 违规处理

| **违规行为** | **处理措施** |
| :--- | :--- |
| **抄袭** | 取消参赛资格，作品公开展示并接受监督举报 [citation:1][citation:3] |
| **匿名信息泄露** | 直接取消参赛资格 [citation:1][citation:3] |
| **身份造假** | 取消参赛资格 [citation:1][citation:3] |
| **举报机制** | 可通过官方邮箱 cqa@wupen.org 举报疑似抄袭 [citation:1][citation:3] |

### 7.3 版权声明

参赛者上传作品即表示同意授权组委会为举办大赛目的向所有人以署名或隐名的形式展示作品，同意大赛确定的评选方式[citation:1][citation:3]。
