# “新人杯”全国大学生室内设计竞赛 参赛技术指南

## 一、赛事概述

**“新人杯”全国大学生室内设计竞赛**是由CIID“新人杯”全国大学生室内设计竞赛组委会主办的全国性室内设计学科竞赛，自2001年创立[citation:8]。竞赛旨在鼓励在校学生对室内设计学科的兴趣，培养学生的设计创新能力，发现和表彰优秀学生，加强院（系）间的教学交流，促进我国室内设计人才的培养和教学水平的提高[citation:1]。

- **主办单位**：CIID“新人杯”全国大学生室内设计竞赛组委会[citation:1]
- **竞赛官网**：http://www.ciid.com.cn/[citation:1]
- **竞赛主题（2026年）**：住宅空间设计（参赛人可自行拟定题目）[citation:1]

---

## 二、设计条件技术参数

### 2.1 原始户型参数

| **项目** | **技术规格** |
| :--- | :--- |
| **建筑面积** | 约110平方米[citation:1] |
| **户型结构** | 三室两卫一厨双阳台[citation:1] |
| **朝向** | 南向[citation:1] |
| **层高** | 3米[citation:1] |
| **图纸下载** | 在报名网站www.ciid.com.cn下载CAD图纸[citation:1] |

### 2.2 改造限制

| **项目** | **技术规格** |
| :--- | :--- |
| **不可改动** | 承重梁、墙、排污排水主管道、烟道[citation:1] |
| **可拆除** | 除承重结构外的其余内墙[citation:1] |
| **主卧阳台墙垛** | 轻体墙，可拆除[citation:1] |
| **卫生间改造** | 两个卫生间均有降板，同层排水，可随意调整位置[citation:1] |
| **自行拟定条件** | 住宅所在城市、楼层、建筑环境条件[citation:1] |

## 三、用户需求技术规范

| **需求项** | **技术规格** |
| :--- | :--- |
| **户主身份** | 90后单身家居赛道小红书网红博主[citation:1] |
| **风格偏好** | 自然舒适的家居环境，偏女性化的感觉，有设计感、表现力[citation:1] |
| **功能需求** | 一个卧室，一个卫生间，其余空间尽量敞开[citation:1] |
| **特殊要求** | 需在房子拍摄家居视频，为后续改造和换装新场景留有空间[citation:1] |
| **改造接受度** | 能接受颠覆性改造或较大的设计改动[citation:1] |

## 四、作品技术规范

### 4.1 设计成果要求

| **成果类型** | **内容要求** |
| :--- | :--- |
| **设计说明** | 明确表达设计定位、设计理念及手法，字数不限[citation:1] |
| **设计图纸** | ①平面图、顶面图、立面图、局部详图；②主要空间效果图[citation:1] |
| **效果表现** | 图纸表达方式不限（CAD图纸、SU效果、3D效果、手绘等）[citation:1] |

### 4.2 参评展板技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **展板尺寸** | 590mm × 820mm（竖式展板）[citation:1] |
| **像素要求** | 6969像素 × 9685像素[citation:1] |
| **分辨率** | 300dpi[citation:1] |
| **文件格式** | JPG[citation:1] |
| **色彩模式** | RGB[citation:1] |
| **单张大小** | 5M - 50M[citation:1] |
| **展板数量** | 1-5张/作品[citation:1] |
| **内容要求** | 只允许有参赛作品信息，禁止出现参赛人相关信息（姓名、班级、签名、二维码、院校名称、老师信息等）[citation:1] |
| **禁止事项** | 不得在展板上标注竞赛名称或logo[citation:1] |

### 4.3 其他参赛资料技术规格

| **材料类型** | **格式要求** | **内容说明** |
| :--- | :--- | :--- |
| **参赛者照片** | JPG | 个人照/团体照，简单背景，不要大头照[citation:1] |
| **学生证证明** | JPG | 学生证内页拍照（含本人信息和入学时间）[citation:1] |
| **个人简介** | Word | 包括教育经历、指导老师姓名等信息[citation:1] |
| **设计说明** | Word | 300字之内[citation:1] |
| **设计资料** | JPG/PDF | 主要的平面图、立面图、室内效果图（不要PSD文件）[citation:1] |

## 九、原创性与学术诚信技术规范

### 9.1 原创性要求

| **要求** | **说明** |
| :--- | :--- |
| **原创性** | 参赛作品必须是参赛者本人原创设计，可有老师指导[citation:1] |
| **抄袭处理** | 发现抄袭现象，立即取消参赛/获奖资格，且参赛费用不退[citation:1] |

### 9.2 报名信息规范

| **要求** | **说明** |
| :--- | :--- |
| **信息准确性** | 报名表第一栏填写的参赛人名单即为最终获奖证书上的人员名单（备注或参赛资料中填写无效）[citation:1] |
| **信息修改** | 获奖名单公布后任何参赛人相关信息（包括指导老师信息）均不接受任何形式的修改[citation:1] |
| **伪造处理** | 伪造参赛资料或资料不符合要求，组委会有权取消参赛/获奖资格，费用不退[citation:1] |

### 9.3 组委会权利

| **权利** | **说明** |
| :--- | :--- |
| **作品使用权** | 组委会有对参赛作品进行展览、刊登、出版的权利[citation:1] |
| **署名依据** | 署名均依据《参赛报名表》信息[citation:1] |
| **最终解释权** | 组委会对竞赛活动具有最终解释权[citation:1] |
