# 全国大学生数学竞赛 参赛技术指南

## 一、赛事概述

**全国大学生数学竞赛**是由中国数学会主办、面向全国高校本科生的高水平学科竞赛，旨在激励大学生学习数学的兴趣，培养分析问题、解决问题的能力，促进高等学校数学课程建设，为青年学子搭建展示数学思维能力和学习成果的平台。目前，赛事已成功进入高等教育学会的学科竞赛榜单观察目录[citation:3][citation:6]。

- **主办单位**：中国数学会
- **第十七届决赛承办单位**：四川大学、成都理工大学[citation:2][citation:3]
- **官方网站**：https://www.cmathc.org.cn/ [citation:1][citation:8]

## 三、参赛资格与组别划分

### 3.1 参赛对象

大学本科在校大学生均可参赛[citation:2][citation:3][citation:6]。

### 3.2 组别设置

竞赛分为**数学专业类**和**非数学专业类**，并在两类中进一步细分：

| **类别** | **组别** | **适用对象** | **报考限制** |
| :--- | :--- | :--- | :--- |
| **数学专业类** | 数学A类 | 具有数学一级学科博士点高校或在最新一轮学科评估中数学学科排名B-以上高校的数学类专业学生[citation:3][citation:4][citation:5] | 数学类专业（代码0701）学生只能报考数学专业类，不得参加非数学专业类[citation:1][citation:3] |
| **数学专业类** | 数学B类 | 其他高校数学类专业学生[citation:4][citation:5] | — |
| **非数学专业类** | 非数学A类（理工类） | 专业代码为07（理科）、08（工科）的学生[citation:1][citation:3][citation:4] | — |
| **非数学专业类** | 非数学B类（经管文史类） | 其他非数学类专业学生[citation:1][citation:3][citation:4] | — |

## 五、报名技术规范

### 5.1 报名时间

各高校报名截止时间略有差异，一般在**2025年9月至10月中旬**之间，具体以本校通知为准[citation:2][citation:4][citation:5]。

### 5.2 报名费用

| **项目** | **金额** | **用途** |
| :--- | :--- | :--- |
| **报名费** | **100元/人**[citation:2][citation:3][citation:5] | 其中80元用于分赛区，20元上交中国数学会[citation:6] |
| **部分院校优惠** | 60元/人（河北）[citation:4] | 或由学校统一承担（西北师范大学）[citation:9] |

### 5.3 报名流程

各校报名方式分为以下两种：

| **方式** | **操作说明** |
| :--- | :--- |
| **在线报名** | 登录赛氪网（https://www.saikr.com/cmathc/hlj/2025）完成注册缴费[citation:6] |
| **校内集中报名** | 填写报名表→发送至指定邮箱→现场缴费或转账[citation:2][citation:3][citation:4] |

## 六、奖项设置技术指标

### 6.1 初赛奖项

| **奖项** | **获奖比例**（按各组别实际参赛人数） | **证书颁发** |
| :--- | :--- | :--- |
| **一等奖** | ≤6%[citation:2][citation:3][citation:5] | 中国数学会普及工作委员会公章[citation:2] |
| **二等奖** | ≤9%[citation:2][citation:3][citation:5] | 同上 |
| **三等奖** | ≤15%[citation:2][citation:3][citation:5] | 同上 |
| **总获奖比例** | **≤30%** | — |

*注：按照数学专业类（分A/B类）与非数学专业类（分A/B类）的实际参赛人数分别评奖[citation:3][citation:5][citation:6]。*

### 6.2 决赛奖项

| **项目** | **技术规格** |
| :--- | :--- |
| **决赛总人数** | 原则上**1000人**（数学专业类500人，非数学专业类500人）[citation:3][citation:5][citation:6] |
| **数学A+高校单列** | 数学专业类中100人单列给第五轮学科评估数学学科A+的高校[citation:5][citation:6] |
| **评奖方式** | 按绝对分数评出一、二、三等奖[citation:2][citation:3] |

## 七、命题与评审技术规范

### 7.1 命题单位
初赛和决赛试题均由**全国大学生数学竞赛工作组组织专家统一命题**[citation:2][citation:3][citation:6]。

### 7.2 阅卷与评奖

| **阶段** | **组织单位** | **工作内容** |
| :--- | :--- | :--- |
| **初赛** | 各赛区统一安排[citation:2][citation:3][citation:6] | 试卷印刷、保密、密封送评阅点集中阅卷、自行评奖 |
| **决赛** | 全国大学生数学竞赛工作组[citation:2][citation:3][citation:6] | 试卷印刷、保密、阅卷、评奖 |

## 八、参赛注意事项

### 8.1 诚信要求
- 报名后无故弃考将被认定为浪费公共资源、违背诚信原则，部分高校在评奖评优中酌情扣分[citation:9]
- 有缺考记录的学生可能被限制再次报名[citation:9]

### 8.2 信息核对
- 务必正确填写姓名、身份证号、学校、专业等信息，决赛名单需上报全国工作组[citation:2][citation:3]
- 加入本校竞赛QQ群及时获取考试安排通知（各校群号见联系方式章节）
