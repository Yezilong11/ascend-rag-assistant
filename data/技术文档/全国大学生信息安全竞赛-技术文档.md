# 全国大学生信息安全竞赛 参赛技术指南

## 一、赛事概述

**全国大学生信息安全竞赛**是由教育部高等学校网络空间安全专业教学指导委员会、中国信息安全测评中心联合主办的国家级学科竞赛。大赛自2008年起每年举办一届，已成功举办十八届，是国内信息安全领域级别最高、规模最大、影响力最广的大学生学科竞赛之一。第十九届竞赛与第三届“长城杯”网数智安全大赛（防护赛）合并举办，采用“一赛两赛”模式 [citation:1][citation:5]。

- **主办单位**：中国信息安全测评中心、教育部高等学校网络空间安全专业教学指导委员会 [citation:1][citation:5]
- **指导单位**：中央网信办网络安全协调局、教育部高等教育司 [citation:2]
- **支持单位**：中国互联网发展基金会 [citation:1]
- **大赛官网**：http://www.ciscn.cn/
- **微信公众号**：IST_t3sec、大学生信息安全竞赛 [citation:5]

本届大赛采用线上线下结合的办赛模式，分为**线上初赛、分赛区半决赛、全国总决赛**三个阶段 [citation:1][citation:5]。

### 4.2 第十九届大赛时间安排（2025-2026年）

| **阶段** | **时间节点** | **技术任务** |
| :--- | :--- | :--- |
| **报名** | 2025年11月10日 - 12月21日 | 官网注册、组队、联络教师审核 [citation:5] |
| **线上初赛** | **2025年12月28日 9:00-17:00** | 线上CTF解题赛 [citation:1][citation:8] |
| **半决赛** | **2026年3月22日** | 线下分区赛 [citation:1][citation:8] |
| **长城杯决赛** | **2026年4月**（福州，与数字中国峰会同期） | 第三届“长城杯”防护赛决赛 [citation:1][citation:8] |
| **创新实践能力赛决赛** | **2026年7月** | 全国总决赛 [citation:1][citation:7] |

## 五、线上初赛技术规范

### 5.1 初赛时间与形式

| **项目** | **技术规格** |
| :--- | :--- |
| **考试时间** | 2025年12月28日 9:00-17:00（共8小时） [citation:1][citation:8] |
| **考试形式** | 线上CTF解题赛 [citation:1] |
| **考核内容** | 理论知识考核 + 实操技能解题 [citation:8] |

### 5.2 初赛考试大纲

初赛考核大纲主要包括理论知识考核和实操技能解题，涵盖以下八部分内容 [citation:8]：

| **模块** | **内容方向** |
| :--- | :--- |
| **（一）信息安全基础知识** | 信息安全保障、信息安全管理、信息安全支撑技术、物理与网络通信安全、计算环境安全、软件安全开发 |
| **（二）法律法规及安全标准** | 《网络安全法》《个人信息保护法》《数据安全法》《关键信息基础设施保护条例》《信息安全风险评估规范》《网络安全等级保护基本要求》《个人信息安全规范》等 |
| **（三）密码学** | 编码解码、古典密码学、现代密码学算法（AES/DES、SM2/SM4）、量子密码学 |
| **（四）WEB安全** | SQL注入、文件上传漏洞、命令执行、权限绕过、弱口令、反序列化漏洞、文件包含漏洞、通用框架/中间件漏洞、Burp Suite工具使用 |
| **（五）逆向工程** | 平台适配（Windows/Linux/Android）、反汇编工具（IDA Pro）、反编译工具（JD-GUI）、脱壳、调试、加解密/反调试/代码混淆、恶意样本分析 |
| **（六）PWN** | 堆栈溢出、格式化漏洞、汇编代码分析、漏洞利用代码（EXP）编写 |
| **（七）威胁检测与网络流量分析** | 网络流量分析（TCP/IP协议）、流量还原解密、日志分析、恶意代码检测、数据恢复 |
| **（八）AI安全** | 统计学与数据分析基础、机器学习原理、AI模型安全分析、对抗样本构造 |

### 5.3 初赛答题要求 [citation:8]

| **要求项** | **技术规格** |
| :--- | :--- |
| **身份验证** | 赛前开启视频摄像头，手持身份证和学生证原件完成身份确认 |
| **比赛环境** | 全程开启房间摄像头和个人计算机视频摄像头，非参赛人员（指导老师等）严禁出现在比赛场地 |
| **设备限制** | 严禁使用双屏幕答题，严禁使用互联网大模型辅助答题 |
| **行为规范** | 不得对比赛平台、系统和第三方服务进行攻击 |
| **录屏要求** | 全程开启电脑录屏，每小时保存1份视频文件，比赛结束后4小时内将录屏视频文件和CTF解题思路上传网盘并提交赛务组存档 |

### 5.4 初赛晋级规则 [citation:1][citation:8]

| **规则项** | **技术规格** |
| :--- | :--- |
| **高校晋级上限** | 每个高校最多有2支排名靠前的队伍晋级分区半决赛（半决赛承办高校可多1个名额） |
| **同分处理** | 成绩相同且只有一个晋级名额时，由场景实操模块得分高的队伍晋级；分数相同用时较短的队伍排名靠前 |
| **赛区规模** | 每个赛区按得分从高至低排名，选取不超过100支赛队晋级半决赛 |
| **反作弊措施** | 严格的反作弊监控机制，发现作弊或攻击平台行为将采取禁赛、取消成绩等处罚措施 |

## 九、报名技术规范

### 9.1 报名流程 [citation:5][citation:6]

| **步骤** | **操作说明** |
| :--- | :--- |
| **1. 官网注册** | 所有参赛学生、指导教师登录官网（http://www.ciscn.cn）注册 |
| **2. 组队** | 队长在系统中邀请队员、邀请指导教师，队员接受邀请后组队完成 |
| **3. 联络教师审核** | 各高校联络教师对本校参赛队伍人员情况的真实性、合规性进行审核 |
| **4. 组委会复核** | 大赛组委会对参赛队伍进行复核，公布初赛名单 |
| **5. 队员变更** | 报名截止前可申请解散队伍重新组队，报名截止后队员及排名一律不得更改 |

## 十、违规处理与申诉仲裁

### 10.1 违规行为界定 [citation:1]

| **违规类型** | **具体行为** |
| :--- | :--- |
| **参赛队伍禁止项** | 报名信息造假、违反法律法规、涉嫌抄袭/代赛/串题、攻击比赛平台、恶意攻击其他选手、其他破坏比赛公平性的行为 |
| **承办院校与平台禁止项** | 平台未提供必要防作弊功能、组织不力导致裁判不公、未遵守赛题管理要求导致漏题泄题 |

### 10.2 违规处理措施 [citation:1]

| **情节严重程度** | **处理措施** |
| :--- | :--- |
| 一般违规 | 取消参赛资格 |
| 严重违规 | 通报赛队所在高校 |
| 平台/承办方违规 | 追究相关方责任 |

### 10.3 申诉流程 [citation:1]

| **步骤** | **技术规格** |
| :--- | :--- |
| **申诉主体** | 参赛队队长 |
| **申诉邮箱** | info@ciscn.cn |
| **申诉报告** | 对现象、发生时间、涉及人员、申诉依据进行充分叙述，队长亲笔签名 |
| **申诉时效** | 比赛结束后2日内 |
| **处理时效** | 组委会秘书处在接到申诉报告后的2个工作日内组织复议，并告知结果 |
