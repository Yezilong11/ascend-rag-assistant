# 全国大学生金相技能大赛 参赛技术指南

## 一、赛事概述

**全国大学生金相技能大赛**是由教育部高等学校材料类专业教学指导委员会指导的全国性大学生学科竞赛。大赛最初由清华大学、北京科技大学、天津大学、国防科技大学等高校于2012年联合发起，每年举办一届。2020年2月，大赛正式纳入中国高等教育学会《全国普通高校学科竞赛排行榜》，成为排行榜内核心竞赛项目之一。

- **指导单位**：教育部高等学校材料类专业教学指导委员会
- **大赛官网**：https://www.jxds.tech/
- **证书查验**：官网首页“获奖证书查验”可查验第五届以来所有电子版证书

---

## 二、赛道设置与技术方向

目前大赛共开设三个赛道：

| **赛道** | **名称** | **设立时间** | **定位** |
| :--- | :--- | :--- | :--- |
| **第一赛道** | 实验技能赛道 | 2012年（第一届） | 大赛主体赛道，金相技能核心考核 |
| **第二赛道** | 综合分析赛道（金相大会） | 2023年（第十二届） | 金相理论知识综合考核 |
| **第三赛道** | 创新应用赛道（材料分析大赛） | 2025年（第十四届） | 材料分析与创新应用能力考核 |

## 三、实验技能赛道（第一赛道）技术规范

### 3.1 参赛资格

| **项目** | **技术规格** |
| :--- | :--- |
| **参赛对象** | 普通高等学校全日制在校本科生 |
| **专业范围** | 材料类及相关专业 |
| **组队要求** | 以学校为单位组队参赛 |
| **参赛人数** | 每校最多3名选手（部分届次可增加1名预备选手） |
| **指导教师** | 1-2名/校 |

### 3.2 竞赛内容

| **项目** | **技术规格** |
| :--- | :--- |
| **竞赛形式** | 现场操作竞赛 |
| **比赛时间** | 30分钟/试样 |
| **比赛轮次** | 通常进行2-3轮，每轮不同试样 |
| **试样材料** | 工业常用金属材料（如20钢、45钢、球墨铸铁、工业纯铁等） |
| **操作要求** | 完成试样的磨制、抛光、浸蚀、显微镜观察全过程 |

### 3.3 评分标准

| **评分项** | **分值** | **考察要点** |
| :--- | :--- | :--- |
| **金相图像质量** | 70分 | 组织清晰度、衬度、均匀性、无划痕、无假象 |
| **样品表面质量** | 20分 | 表面平整度、无污渍、无氧化 |
| **操作规范性** | 10分 | 操作流程规范、安全操作、时间控制 |

### 4.1 参赛资格

| **项目** | **技术规格** |
| :--- | :--- |

| **考试范围** | 金相制样原理、材料科学基础、相图分析、热处理工艺、典型组织识别 |
| **题型设置** | 选择题、判断题、看图识组织题、综合分析题 |
| **题目来源** | 大赛题库系统 |

### 4.3 评分标准

| **阶段** | **形式** | **分值占比** |
| :--- | :--- | :--- |
| **个人笔试** | 闭卷考试 | 60% |
| **团体抢答** | 现场抢答 | 40% |

## 七、分赛区设置

大赛设立多个分赛区，各赛区组织复赛选拔，优胜队伍晋级全国决赛。分赛区划分根据各省高校分布情况确定，具体以当届通知为准。

## 九、证书查验与教师专区

### 9.1 证书查验

大赛官网提供证书查验功能，可查验自第五届以来的所有电子版证书：
- **查验入口**：官网首页“获奖证书查验”
- **输入信息**：证书编号

### 9.2 指导教师专区

| **功能** | **说明** |
| :--- | :--- |
| **注册方式** | 教师自行在大赛官网注册，详见《关于设置大赛官网登录密码的通知》 |
| **开通权限** | 联系大赛秘书处申请开通指导教师专区 |
| **主要功能** | 查找、收藏、下载历届电子版证书；查询本人历届参赛及备案情况 |
| **登录入口** | 官网首页右上角“登录”，进入后点击“教师个人专区” |

### 9.3 大赛管理系统

| **角色** | **功能** |
| :--- | :--- |
| **分赛区秘书长** | 登录工作台进行分赛区管理 |
| **高校联系人** | 登录工作台进行本校参赛管理 |

### 9.4 大赛题库系统

第二赛道命题专家和评审专家可登录系统提交或评审试题。
