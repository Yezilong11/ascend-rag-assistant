# 全国大学生数学建模竞赛 参赛技术指南

## 一、赛事概述

**全国大学生数学建模竞赛**（英文简称CUMCM）创办于1992年，每年一届，是首批列入“高校学科竞赛排行榜”的19项竞赛之一，目前已成为全球规模最大的数学建模竞赛[citation:6][citation:7]。2025年，来自全国及美国、英国、澳大利亚、新加坡、马来西亚等国家的1837所院校/校区、68311队（本科61463队、高职高专6848队）、20多万人报名参赛[citation:7]。

- **主办单位**：中国工业与应用数学学会[citation:6]
- **竞赛官网**：https://www.mcm.edu.cn/
- **竞赛宗旨**：激励学生学习数学的积极性，提高学生建立数学模型和运用计算机技术解决实际问题的综合能力[citation:10]

## 四、竞赛规则与学术诚信

### 4.1 独立完成要求

竞赛期间，各参赛队必须独立完成赛题解答。严禁参赛队员以任何方式与队外任何人（包括指导教师）交流、讨论任何与赛题有关的问题；参赛队员无论主动参与讨论，还是被动接收讨论信息，均视为严重违反竞赛纪律[citation:1][citation:3]。

### 4.2 网络平台限制

竞赛期间，参赛队员不得在任何交流平台（包括但不限于“贴吧”、QQ群、微信群、网络直播间、知乎、小红书、CSDN、GitHub等）浏览、发布或讨论与赛题相关的内容，否则一律视为严重违反竞赛纪律[citation:1][citation:3]。

### 4.3 指导教师行为规范

指导教师在竞赛期间不得通过任何方式对参赛学生进行任何形式的指导（包括向学生解释赛题或提供选题、解题建议，提供参考资料，修改论文或提供修改建议等），否则一律按违纪处理。对出现违纪行为的参赛队的指导教师，全国组委会两年内将不受理该指导教师指导学生参加本竞赛的报名申请[citation:1][citation:3]。

### 4.4 抄袭与引用规范

抄袭是严重违反竞赛纪律的行为；参赛论文引用他人的研究成果或其他任何公开的资料（包括网上查到的资料），必须按照规定的参考文献的表述方式在正文中加以引用，并在参考文献中明确列出，且不得大篇幅照抄，否则视为学术不端行为和违反竞赛纪律，相应的参赛队将被无条件取消评奖资格[citation:1][citation:3]。

### 4.5 AI工具使用规定

参赛队员可以使用人工智能（AI）工具作为辅助，但各参赛队必须对所提交作品的原创性、真实性和准确性负全部责任。参赛队须遵守《全国大学生数学建模竞赛人工智能工具使用规定》[citation:1][citation:3]。

### 4.6 违纪处理

对严重的、典型的违纪行为，全国组委会（或赛区组委会）将以适当的方式给予公开通报批评。所属学校须对当事人进行批评教育并作出相应处理，并提出整改方案[citation:1][citation:3]。

## 五、论文格式技术规范（2026年修订稿）

### 5.1 纸质版论文格式规范

| **项目** | **技术规格** |
| :--- | :--- |
| **纸张** | 白色A4纸打印（单面/双面均可）[citation:2] |
| **页边距** | 上下左右各留出至少2.5厘米[citation:2] |
| **装订** | 从左侧装订[citation:2] |
| **页码** | 从第三页（摘要页）开始编写页码，页脚中部，阿拉伯数字从“1”开始连续编号[citation:2] |

### 5.2 论文结构要求

| **页码** | **内容** | **要求** |
| :--- | :--- | :--- |
| **第一页** | 承诺书 | 具体内容见专用页[citation:2][citation:9] |
| **第二页** | 编号专用页 | 用于赛区和全国评阅前后对论文进行编号[citation:2][citation:9] |
| **第三页** | 摘要专用页 | 含标题、关键词（无需翻译成英文），篇幅不能超过一页[citation:2][citation:9] |
| **第四页起** | 正文 | 不要目录，不超过30页[citation:2] |
| **附录** | 支撑材料列表、源程序代码 | 页数不限，与正文装订在一起[citation:2] |

### 5.3 正文内容要求

| **项目** | **技术规格** |
| :--- | :--- |
| **正文页数** | ≤30页[citation:2] |
| **目录** | 不要目录[citation:2] |
| **页眉** | 不能有任何可能显示答题人身份和所在学校等信息[citation:9] |
| **参考文献** | 在正文引用处和参考文献中均明确列出，格式见规范[citation:2][citation:9] |

### 5.4 参考文献格式规范

| **资源类型** | **格式规范** |
| :--- | :--- |
| **书籍** | [编号] 作者，书名，出版地：出版社，出版年[citation:9] |
| **期刊论文** | [编号] 作者，论文名，杂志名，卷期号：起止页码，出版年[citation:9] |
| **网上资源** | [编号] 作者，资源标题，网址，访问时间（年月日）[citation:9] |

### 5.5 附录内容要求

论文附录内容应包括支撑材料的文件列表，建模所用到的全部完整、可运行的源程序代码（含EXCEL、SPSS等软件的交互命令）等。如果缺少必要的源程序、程序不能运行或运行结果与论文不符，都可能会被取消评奖资格。如果确实没有用到程序，应在论文附录中明确说明“本论文没有用到程序”[citation:2]。

### 5.6 匿名评审要求

论文摘要专用页、正文和附录中任何地方都不能有显示参赛者身份和所在学校及赛区的信息[citation:2]。

## 六、电子版论文格式规范

### 6.1 电子版文件要求

| **项目** | **技术规格** |
| :--- | :--- |
| **参赛论文电子版** | PDF或Word格式（建议PDF），文件大小≤20MB[citation:2] |
| **内容要求** | 必须与纸质版内容及格式完全一致，第一页必须为摘要专用页（不含承诺书和编号专用页）[citation:2] |
| **支撑材料文件** | 所有支撑材料文件使用WinRAR压缩，后缀RAR或ZIP，大小≤20MB[citation:2] |
| **支撑材料内容** | 所有可运行源程序、自主查阅使用的数据资料、较大篇幅中间结果的图表等[citation:2] |

### 6.2 支撑材料注意事项

- 支撑材料的文件列表应放入论文附录
- 如果确实没有需要提供的支撑材料，可不提供支撑材料文件，并在论文附录中注明“本论文没有支撑材料”[citation:2]
- 如果支撑材料文件与论文内容不相符，该论文可能会被取消评奖资格[citation:2]
- 承诺书和编号专用页不要放在支撑材料中[citation:2]
- 所有文件中不能有显示参赛者身份和所在学校及赛区的信息[citation:2]
