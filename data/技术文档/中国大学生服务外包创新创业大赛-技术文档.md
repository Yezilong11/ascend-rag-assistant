# 中国大学生服务外包创新创业大赛 参赛技术指南

## 一、赛事概述

**中国大学生服务外包创新创业大赛**（简称“服创大赛”）是由教育部、商务部联合主办的国家级A类赛事，是服务外包领域唯一的创新、创业国家级赛事，已列入《全国普通高校学科竞赛排行榜》[citation:10]。大赛紧贴现代服务经济和创新、创业、创富主题，强调应用导向和产学互动，在服务外包领域搭建大学生创新与创业能力展示平台[citation:1]。

- **主办单位**：教育部、商务部、无锡市人民政府
- **大赛官网**：http://www.fwwb.org.cn/
- **官方微信公众号**：fwwbds

---

## 二、赛道设置与技术方向

第十七届大赛设**四个竞赛类别**：

| **类别** | **名称** | **特点与定位** | **名额限制** |
| :--- | :--- | :--- | :--- |
| **A类** | 企业命题类 | 31家企业发布真实需求，适合技术实现能力强的学生[citation:10] | 不限 |
| **B类** | 创业实践类 | 已有成效的创业项目参赛，侧重商业模式创新和市场实践[citation:10] | **每校限报2队**[citation:1][citation:4][citation:10] |
| **C类** | OPC创客类 | 个人主导，借助AI工具在服务外包领域完成从设计到市场的全流程项目[citation:8][citation:10] | 不限 |
| **D类** | 人工智能专项赛道 | 腾讯开悟人工智能全球公开赛，聚焦人工智能场景真实需求[citation:1][citation:8] | 不限 |

*注：C类（OPC创客类）项目单独组织评审，不参加区域赛[citation:1][citation:4]。*

## 三、参赛资格技术规范

### 3.1 参赛对象

| **项目** | **技术规格** |
| :--- | :--- |
| **在校学生** | 全国高等学校具有正式学籍的全日制在校学生（含2026年应届毕业生）[citation:1][citation:4] |
| **毕业年限** | 毕业不超过5年（2021年后毕业）的大学生[citation:1][citation:4][citation:10] |
| **跨校组队** | 允许跨校、跨专业组队[citation:6][citation:10] |

### 3.2 组队技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **队员人数** | **3-5人**/队[citation:1][citation:4][citation:10] |
| **指导教师** | ≤2人/队[citation:1][citation:4][citation:6] |
| **每人限报** | 每位学生只能参加一支队伍，禁止不同参赛团队共用队员[citation:2][citation:9] |
| **赛道限制** | 参赛团队仅限选一个竞赛类别参赛[citation:1][citation:4][citation:5] |

### 3.3 B类参赛资格特别说明

| **报名数量** | **资格获取方式** |
| :--- | :--- |
| **报名≤2支团队** | 自动获得参赛资格，无须校内选拔[citation:1][citation:4][citation:10] |
| **报名>2支团队** | 须由校内选拔赛/推选方式产生参赛资格[citation:1][citation:4][citation:10] |

### 3.4 往届项目规定

| **类别** | **规定** |
| :--- | :--- |
| **B类及C类** | 允许使用往届参赛项目继续参赛[citation:1][citation:9] |
| **禁止使用** | 禁止使用往届服创大赛全国赛获奖项目（一、二、三等奖）[citation:1][citation:4][citation:10] |

## 五、作品提交技术规范

### 5.1 A类（企业命题类）提交材料[citation:8]

| **材料名称** | **内容要求** | **格式规格** | **必选/可选** |
| :--- | :--- | :--- | :--- |
| **概要介绍** | 前言、创意描述、功能简介、特色综述、开发工具、应用对象等 | PDF，≤1500字，≤10M | **必选** |
| **项目简介PPT** | 目标与思路、问题分析、技术路线、业务模式等 | PPT/PDF，≤20页，≤20M | **必选** |
| **项目详细方案** | 项目详细解决方案 | PDF，≤20M | **必选** |
| **项目演示视频** | 展示技术实现方式、运行方式和完成程度 | MP4，≤5分钟，≤100M | **必选** |
| **项目知识产权证明** | 专利证书、著作权证书等 | PDF，≤2M | 可选 |
| **企业要求其他材料** | 按赛题手册要求 | 自定 | 按需 |

### 5.2 B类（创业实践类）提交材料[citation:8]

| **材料名称** | **内容要求** | **格式规格** | **必选/可选** |
| :--- | :--- | :--- | :--- |
| **项目商业计划书PPT** | 项目背景、公司简介、核心团队、产品/服务、商业模式、市场分析、财务预测等 | PPT/PDF，≤50M | **必选** |
| **商业计划书详细方案** | 商业计划书详细内容 | PDF，≤20M | **必选** |
| **项目演示视频** | 展示项目和团队基本情况 | MP4，≤5分钟，≤100M | **必选** |
| **公司简介** | 已成立公司的必选，填写公司简介表 | PDF，≤5M | 已成立公司必选 |
| **项目知识产权证明** | 专利证书、著作权证书等 | PDF，≤2M | 可选 |

### 5.3 C类（OPC创客类）提交材料[citation:8]

| **材料名称** | **内容要求** | **格式规格** |
| :--- | :--- | :--- |
| **项目商业计划书PPT** | 行业背景、项目介绍、技术路径、核心团队、商业模式、发展规划等 | PPT/PDF，≤50M |
| **AI协同流程说明文档** | 详细说明各环节使用的AI工具/平台/技术 | PDF，≤20M |
| **产品原型或演示视频** | 展示项目核心功能、应用场景 | MP4，≤5分钟，≤100M |

### 5.4 匿名评审要求

在提交的文档作品中**不得出现参赛学院名称、专业名称、学生信息和指导教师信息**及其提示、图片、照片、图像或链接等形式的暗示内容，否则视为违规，取消比赛资格[citation:3][citation:6]。

### 5.5 文件命名规则

| **材料类型** | **命名规则** |
| :--- | :--- |
| **A类材料** | `团队编号—团队名称—赛题编号赛题名称—材料名称`[citation:8] |
| **B类材料** | `团队编号—团队名称—B类***项目—材料名称`[citation:8] |
| **C类材料** | `团队编号—团队名称—C类***项目—材料名称`[citation:8] |

### 5.6 提交方式（A类/B类均需完成）[citation:8][citation:9]

| **提交方式** | **操作说明** |
| :--- | :--- |
| **官网提交** | 登录大赛官网，在指定位置上传参赛作品电子材料 |
| **网盘提交** | 将所有材料打包为ZIP，上传百度网盘，将分享链接发送至大赛作品邮箱：fwwbdszp@fwwb.org.cn |

## 六、评审技术规范

### 6.1 评审原则[citation:3]

| **原则** | **说明** |
| :--- | :--- |
| **过程与结果并重** | 评审参赛作品同时，关注作品过程中体现的意识与素质 |
| **重视团队与人员表现** | 综合考察团队在方案中体现的综合素质与能力 |
| **体现“三创”特色** | 秉承“创新、创业、创富”精神，综合考察业务分析、组织模型、技术方案、可行性分析等 |

### 6.2 B类校赛评分标准参考[citation:9]

| **评审维度** | **权重** |
| :--- | :--- |
| 填写及描述 | 20% |
| 项目创新点 | 30% |
| 市场前景 | 20% |
| 商业逻辑性 | 30% |

### 6.3 区域赛与国赛评审

初赛线上评审后，入围团队参加区域赛现场答辩，评选出区域赛晋级全国赛决赛名单[citation:1]。全国总决赛采用现场公开答辩方式[citation:10]。

## 七、奖项设置技术指标

### 7.1 校赛奖项

| **奖项** | **获奖比例** |
| :--- | :--- |
| **一等奖** | 10%[citation:9] |
| **二等奖** | 20%[citation:9] |
| **三等奖** | 30%[citation:9] |

### 7.2 区域赛奖项

各区域赛将根据提交作品数量与作品质量，设置区域一二三等奖，并获取相应晋级全国赛决赛名额[citation:1]。

### 7.3 全国总决赛奖项

全国总决赛设一等奖、二等奖、三等奖，具体比例以组委会公布为准。
