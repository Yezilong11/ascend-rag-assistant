# 全国大学生智能汽车竞赛 参赛技术指南

## 一、赛事概述

**全国大学生智能汽车竞赛**起源于韩国，2006年由教育部高等学校自动化类专业教学指导委员会（原自动化专业教学指导分委员会）创办，首届比赛在国内举办[citation:1]。2020年起主办单位转为中国自动化学会[citation:5]。竞赛以“立足培养、重在参与、鼓励探索、追求卓越”为指导思想，旨在加强大学生实践、创新能力和团队精神的培养，促进高等教育教学改革[citation:1]。

- **主办单位**：中国自动化学会[citation:5]
- **竞赛秘书处**：挂靠清华大学[citation:6]
- **官方网站**：http://www.smartcarrace.com/ [citation:5]

## 二、赛道设置与技术方向

| 缩微电磁组 | 电磁感应寻迹 | 指定微控制器 |
| 缩微光电组 | 光电传感器寻迹 | 指定微控制器 |
| 极速光电组 | 高速光电寻迹 | 指定微控制器 |
| 平衡轮腿组 | 两轮平衡控制 | 指定微控制器 |
| 双车跟随组 | 双车协同控制 | 指定微控制器 |
| 独轮信标组 | 信标导航定位 | 指定微控制器 |
| 智能视觉组 | 图像识别处理 | 指定微控制器 |
| 完全模型组 | 整车模型控制 | 指定微控制器 |
| 极速越野组 | 户外越野场景 | 指定微控制器 |
| 气垫越野组 | 气垫船式结构 | 指定微控制器 |

### 2.2 创意组（AI组）

| **组别名称** | **技术方向** |
| :--- | :--- |
| 智慧配送组 | 无人配送、路径规划 |

| **组别类型** | **队员人数** | **指导教师** |

| **限制项** | **技术规格** |
| :--- | :--- |

## 六、竞赛规则与技术流程

### 6.1 比赛方式

| **项目** | **技术规格** |
| :--- | :--- |
| **比赛形式** | 现场赛道竞速[citation:1] |
| **计时方式** | 由计时起跑线传感器自动计时[citation:2] |
| **限时规则** | 每支队伍入场限时10分钟完成比赛，取最好成绩[citation:2] |
| **赛道类型** | 根据组别设置不同赛道，可多条赛道同时进行[citation:2] |

### 6.2 比赛流程

| **步骤** | **时间要求** | **说明** |
| :--- | :--- | :--- |
| 点名入场 | 裁判点名后30秒内[citation:2] | 未进入场地算冲出跑道一次 |
| 准备时间 | 60秒准备[citation:2] | 赛车静止在起跑区 |
| 发车 | 30秒内离开发车区[citation:2] | 超过时间算冲出跑道一次 |
| 比赛计时 | 连续跑两圈，取用时短的一圈[citation:1] | 赛车跑完一圈且自动停止完成比赛 |
| 成绩评定 | 现场计算机自动评分[citation:2] | 取最好成绩 |

### 6.3 犯规与失败规则

| **情形** | **判定** |
| :--- | :--- |
| 裁判点名后30秒未进入场地 | 冲出跑道一次[citation:2] |
| 开始后30秒未离开出发区 | 冲出跑道一次[citation:2] |
| 离开出发区后60秒未跑完一圈 | 冲出跑道一次[citation:2] |
| 未经裁判允许接触赛车 | 比赛失败[citation:2] |
| 未通过现场技术检验 | 比赛失败[citation:2] |

### 6.4 禁止事项

| **禁止项** | **说明** |
| :--- | :--- |
| 辅助设备 | 不允许在赛车之外安装辅助照明设备及其他辅助传感器[citation:2] |
| 更换硬件 | 进入正式比赛场地后，除更换电池外不得进行硬件电路更换[citation:2] |
| 干扰行为 | 不允许干扰或远程遥控赛车运动[citation:2] |
| 赛道损毁 | 不允许赛车的任何传感器或者部件损毁赛道[citation:2] |

## 十、参赛注意事项

### 10.1 技术准备

| **事项** | **要求** |
| :--- | :--- |
| **车模调试** | 每支队伍在比赛前有10分钟现场调试时间[citation:2] |
| **技术检查** | 比赛结束后需进行车模技术检查和答辩[citation:2] |
| **维修工具** | 可携带维修工具对赛车进行调整修理[citation:2] |

### 10.2 信息核对

- 报名信息由学校统一提交，务必核对姓名、学校、组别等信息[citation:2]
- 参赛队伍提交最后参赛学生与指导教师信息截止日期为7月10日[citation:2]
- 参加全国总决赛的队伍最多只允许改变一名队员[citation:2]

### 10.3 学术诚信

| **要求项** | **技术规格** |
| :--- | :--- |
| **原创性** | 各参赛队伍所设计的硬软件需相互之间有明显不同[citation:2] |
| **克隆禁止** | 同一学校同一组别中不同队伍除MCU最小系统外，其它功能模块原理图和PCB不能雷同[citation:2] |
| **作弊处理** | 比赛过程中有其他作弊行为的，取消比赛成绩[citation:2] |
