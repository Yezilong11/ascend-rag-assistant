# “全国大学生物流设计大赛” 参赛技术指南

## 一、赛事概述

**“全国大学生物流设计大赛”**（英文名称：National Contest On Logistics Design for University Students）是由教育部高等学校物流管理与工程类专业教学指导委员会和中国物流与采购联合会共同主办的国家级学科竞赛。大赛自2006年首次举办以来，每两年举办一届，已连续举办多届，是纳入教育部高校学科竞赛排行榜的重点赛事之一，也是国内物流类级别最高、影响力最大的学科竞赛。

- **主办单位**：教育部高等学校物流管理与工程类专业教学指导委员会、中国物流与采购联合会
- **承办单位**：每届由不同的高校或单位承办（如往届的安徽大学、吉林大学、天津大学等）
- **赛事官网**：https://ideaslogistics.clpp.org.cn/

## 二、参赛资格与组队要求

### 2.1 参赛对象

| **项目** | **技术规格** |
| :--- | :--- |
| **学历层次** | 全国普通高等学校（含高职高专）正式录取的全日制在校本科生、高职高专学生 |
| **专业范围** | 物流管理与工程类、供应链管理、交通运输、工商管理、计算机、自动化等相关专业 |

### 2.2 组队技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **队员人数** | **4-5人**/队 |
| **指导教师** | 1-2人/队 |
| **跨校组队** | 不允许跨校组队 |
| **跨专业组队** | 鼓励跨专业组队（管理、工程、计算机等） |
| **每人限报** | 每位学生只允许参加一个参赛队 |
| **每校队伍数** | 一般不限，部分届次限制每校不超过2-3支 |

## 三、赛题与作品技术规范

### 3.1 赛题形式

| **项目** | **技术规格** |
| :--- | :--- |
| **赛题来源** | 大赛组委会邀请企业提供实际案例，形成“案例集” |
| **赛题内容** | 围绕企业物流运营中的实际问题（如网络规划、库存优化、仓储设计、运输调度、供应链协同等） |
| **选题方式** | 参赛队从案例集中选择1-2个案例进行设计，提交完整的解决方案 |

### 3.2 作品形式要求

| **项目** | **技术规格** |
| :--- | :--- |
| **作品形式** | 物流设计方案（Word/PDF文档）+ 答辩PPT |
| **方案内容** | 问题分析、数据调研、方案设计、可行性论证、创新点阐述 |
| **文件规范** | 按大赛官网发布的《参赛作品格式规范》执行 |
| **数据要求** | 方案中使用的数据须注明来源，鼓励使用真实企业数据 |
| **设计工具** | 可使用FlexSim、AnyLogic、Lingo、MATLAB、ArcGIS、Python等物流系统优化与仿真软件 |

### 3.3 原创性要求

| **要求项** | **技术规格** |
| :--- | :--- |
| **原创性** | 参赛作品必须是参赛团队原创，不得抄袭、盗用他人成果 |
| **引用规范** | 引用他人成果必须在正文中明确标注，并在参考文献中列出 |
| **AI工具使用** | 如使用AI工具辅助，须在附录说明工具名称、版本和使用方式 |

## 四、赛程技术时间轴

### 4.1 通用时间安排（每两年一届）

| **阶段** | **时间节点** | **技术任务** |
| :--- | :--- | :--- |
| **报名启动** | 每届3月-6月 | 官网注册报名 |
| **校园赛/初赛** | 6月-8月 | 各校自行组织选拔 |
| **方案提交** | 9月-10月 | 提交完整设计方案 |
| **复赛评审** | 10月-11月 | 专家网评，确定决赛入围名单 |
| **全国总决赛** | **11月-12月** | 现场答辩，决出最终奖项 |

*注：具体时间以当届大赛官网发布的正式通知为准。*

## 五、评审技术指标

### 5.1 评审维度

| **评审维度** | **考察要点** | **参考权重** |
| :--- | :--- | :--- |
| **问题分析的准确性** | 对案例问题的理解深度、关键问题的识别 | 20% |
| **方案设计的创新性** | 设计思路的独创性、技术与模式创新 | 25% |
| **技术方法的科学性** | 优化算法、仿真模型、数据分析方法的合理性 | 20% |
| **方案实施的可行性** | 技术路线、经济成本、风险控制的可行性 | 20% |
| **文本表达与答辩表现** | 文档规范性、逻辑性、答辩清晰度 | 15% |
