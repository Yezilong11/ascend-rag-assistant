# 中国风景园林学会大学生设计竞赛 参赛技术指南

## 一、赛事概述

**中国风景园林学会大学生设计竞赛**是由中国风景园林学会（CHSLA）主办、中国风景园林学会教育工作委员会承办的全国性学科竞赛[citation:1][citation:2]。竞赛旨在进一步推动风景园林事业服务人民、扎根乡土，激发大学生的创造性思维，提升规划设计与实践能力，鼓励不同层次学生从研究、设计、营建多维度推动风景园林的普惠性与地域性发展[citation:1]。

- **主办单位**：中国风景园林学会
- **承办单位**：中国风景园林学会教育工作委员会
- **竞赛官网**：https://www.chsla.org.cn/
- **学会年会**：第十五届中国风景园林学会年会（2025年）
- **参赛费用**：**不收取任何费用**[citation:2]

---

## 二、竞赛主题与组别设置

### 2.1 2025年竞赛主题

竞赛围绕学会年会主题 **“百姓园林·乡土风景”** 展开，分设三个组别[citation:1][citation:4]：

| **组别** | **主题** | **任务方向** | **设计导向** |
| :--- | :--- | :--- | :--- |
| **研究生组** | 乡土生态与百姓福祉 | 城乡自然系统与社会生产生活的共生关系，采用多学科交叉研究方法（生态学、社会学、设计学等），提出以生态保护修复为策略、百姓福祉提升为核心的设计方案 | 研究型设计 |
| **本科生组** | 乡土空间与百姓生活 | 乡土空间与日常生活的互动关系，采用参与式设计方法（乡村调研、社区工作坊、空间行为分析等），提出以城乡绿色空间更新激活百姓生活场景的设计方案 | 设计理念与手法 |
| **高职生组** | 乡土工法与百姓实践 | 传统工法与现代民生需求的融合，采用地域性材料展示利用与施工工法优化（营造技法、标准化建构、生态材料等），提出由百姓参与的乡土景观设计方案 | 可操作性与工艺创新性 |

### 2.2 设计场地要求

| **组别** | **场地要求** |
| :--- | :--- |
| **研究生组** | 参赛者可自选设计场地[citation:1] |
| **本科生组** | 参赛者可自选设计场地[citation:1] |
| **高职生组** | 参赛者自选城乡公共空间（如社区广场、田间步道、河岸等），以传统乡土材料与工艺为基础，完成一处小微乡土景观的精细化设计[citation:1] |

## 四、作品技术规范

### 4.1 图纸内容要求

| **组别** | **图纸内容要求** |
| :--- | :--- |
| **研究生组** | 项目位置、范围和规模、场地分析、平面图、鸟瞰图、重要节点效果图以及必要的规划设计分析图（其他图纸内容可自行确定）[citation:1] |
| **本科生组** | 项目位置、范围和规模、场地分析、平面图、鸟瞰图、重要节点效果图以及必要的规划设计分析图（其他图纸内容可自行确定）[citation:1] |
| **高职生组** | 项目位置、范围和规模、场地分析、平面图、做法大样、材料工艺说明等（其他图纸内容可自行确定）[citation:1] |

### 4.2 图纸格式技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **展板数量** | 1幅 |
| **展板尺寸** | A0（1189mm × 841mm）[citation:2][citation:4] |
| **版面方向** | 竖向排版 |
| **留白要求** | 四边各留白2cm[citation:2][citation:4] |
| **分辨率** | 300dpi[citation:2] |
| **文件格式** | JPG |
| **文件大小** | ≤20M[citation:2][citation:4] |
| **比例要求** | 自定，要求能够清晰准确表达设计思想和意图[citation:1] |
| **语言要求** | 设计说明和注解均需使用中文[citation:2][citation:4] |

### 4.3 匿名评审要求

图像文件中**不得包含任何反映作者、指导教师及学校等相关信息**，违者将取消参赛资格[citation:2][citation:4]。

### 4.4 文件命名规范

| **文件类型** | **命名规则** | **示例** |
| :--- | :--- | :--- |
| **报名表** | `[竞赛组别]+[第一作者姓名]+[学校名称]` | 本科生组+张三+XX大学[citation:2] |
| **参赛作品** | `[竞赛组别]+[第一参赛作者]+[作品名称].jpg` | 高职生组+张三+小微花园设计.jpg[citation:2] |
