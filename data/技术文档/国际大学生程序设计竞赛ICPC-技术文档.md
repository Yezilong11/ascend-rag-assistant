# 国际大学生程序设计竞赛（ICPC）参赛技术指南

## 一、赛事概述

**国际大学生程序设计竞赛**（International Collegiate Programming Contest，简称ICPC）是由ICPC基金会主办的全球性年度程序设计竞赛，始于1970年，被誉为“计算机领域的奥林匹克” [citation:3]。竞赛旨在考察大学生的创新能力、团队协作精神与高压环境下的问题解决能力，是全球最具影响力的计算机竞赛之一 [citation:3]。

- **主办单位**：ICPC基金会
- **赛事级别**：国际级学科竞赛
- **全球官网**：https://icpc.global/
- **ICPC北京总部**：https://icpc.pku.edu.cn/ [citation:7]

## 六、竞赛规则技术参数

### 6.1 比赛时长

| **赛事级别** | **时长** |
| :--- | :--- |
| 区域赛/欧洲冠军赛 | 5小时 [citation:8] |
| 世界总决赛 | 5小时 [citation:9] |
| 校赛选拔 | 4-5小时 [citation:2] |

### 6.2 题目数量

| **赛事级别** | **题量** |
| :--- | :--- |
| 区域赛 | 8-15题 |
| 世界总决赛 | 12题左右 [citation:9] |

### 6.3 罚时规则

| **规则项** | **技术参数** |
| :--- | :--- |
| **错误提交罚时** | 20分钟/次 |
| **编译错误罚时** | 0分钟（不计罚时）[citation:8][citation:9] |
| **总用时计算** | 解题通过时间 + 该题错误提交次数×20分钟 |
| **排名基准** | 解题数优先 → 解题数相同总用时少优先 → 最后正确提交时间早优先 [citation:9] |

### 6.4 封榜规则

| **时间节点** | **规则** |
| :--- | :--- |
| 比赛最后1小时 | 封榜，榜单不再实时更新 [citation:8] |
| 闭幕式 | 滚榜揭晓最终排名 [citation:2] |

## 七、参赛行为技术规范

### 7.1 允许携带物品

| **物品类别** | **技术规格** |
| :--- | :--- |
| **纸质资料** | 允许携带纸质参考资料 [citation:2][citation:5] |
| **词典** | 每名队员可带1本自然语言词典（无注释）[citation:8] |
| **文具** | 笔、草稿纸（由组委会提供）[citation:2] |
| **食物/饮料** | 自备无异味食品及饮用水（建议）[citation:2] |

### 7.2 禁止行为

| **行为** | **处罚** |
| :--- | :--- |
| 交换代码 | 取消资格 [citation:2][citation:8] |
| 交流解题思路 | 取消资格 |
| 替考 | 通报学校 |
| 提交破坏系统代码 | 取消资格 |
| 打开非比赛网页 | 按作弊处理 [citation:2] |

### 7.3 队员变更规则

| **变更类型** | **规则** |
| :--- | :--- |
| 区域赛→EUC | 可申请替换1名队员，但WF资格仍属原队 |
| EUC→WF | 若EUC替换队员后晋级WF，则以EUC参赛队为准 [citation:8] |
