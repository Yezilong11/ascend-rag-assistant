# 全国大学生计算机系统能力大赛 参赛技术指南

## 一、赛事概述

**全国大学生计算机系统能力大赛**是由系统能力培养研究专家组发起、全国高等学校计算机教育研究会主办、面向高校大学生的全国性大赛。大赛旨在以学科竞赛推动专业建设和计算机领域创新人才培养体系改革，培育我国高端芯片、关键基础软件的后备人才[citation:1][citation:3]。

- **主办单位**：全国高等学校计算机教育研究会、系统能力培养研究专家组、系统能力培养研究项目发起高校[citation:3]
- **大赛官网**：https://compiler.educg.net/[citation:3]
- **各赛道平台**：
  - 操作系统设计赛：https://os.educg.net/[citation:2][citation:5]
  - 数据库管理系统设计赛：https://db.educg.net/[citation:8][citation:9]
  - 智能系统创新设计赛：https://is.educg.net/[citation:4][citation:5]

---

## 二、赛道设置与技术方向

2026年大赛设置以下主要赛道，各赛道技术方向如下：

| **赛道** | **技术方向** | **核心考察点** |
| :--- | :--- | :--- |
| **编译系统设计赛（华为毕昇杯）** | ARM后端、RISC-V后端、挑战赛道（华为命题） | 编译器构造、编译优化、目标码生成效率[citation:3] |
| **操作系统设计赛** | OS内核实现赛道、OS功能挑战赛道 | 操作系统内核设计、系统模块开发、开源OS应用[citation:2][citation:3] |
| **数据库管理系统设计赛** | 存取管理、查询处理、事务处理 | 数据库内核实现、功能完善、性能优化（C++）[citation:1][citation:10] |
| **CPU设计赛（龙芯杯）** | 团体赛、个人赛 | CPU微架构设计、流水线、缓存、性能优化[citation:4][citation:7] |
| **智能系统创新设计赛（小米杯）** | 运动控制、感知规划 | 四足仿生机器人开发、计算机视觉、多CPU并行处理[citation:4][citation:5] |

## 四、各赛道技术方案与提交规范

### 4.1 操作系统设计赛

#### 4.1.1 “OS原理”赛道技术方向

| **方向** | **技术要求** |
| :--- | :--- |
| **内核实现** | 基于硬件平台或软件模拟器从零实现小型操作系统内核，开发语言自定 |
| **模块实验设计** | 针对进程管理、内存管理、文件系统等模块做拓展延伸和优化创新 |
| **完整实验设计** | 设计一套新的操作系统实验方案，涵盖课程主要内容[citation:2] |

#### 4.1.2 “OS应用开发”赛道技术方向

| **方向** | **技术要求** |
| :--- | :--- |
| **系统工具开发** | 基于OpenHarmony、OpenEuler等开发性能测试、功能测试、漏洞分析、调试工具 |
| **应用程序开发** | 独立开发或移植应用程序，展示面向特定OS的优化能力[citation:2] |

#### 4.1.3 提交材料技术规格

| **材料类型** | **内容要求** |
| :--- | :--- |
| **源代码** | 完整工程文件，代码注释（中英文均可） |
| **设计文档** | 思路过程、模块设计方案、创新点、测试情况 |
| **过程性资料** | 各阶段文档、开发历史、线上仓库提交记录 |
| **开源要求** | 在大赛托管平台公开代码和文档[citation:2] |

#### 4.1.4 评审技术指标

| **OS原理赛道** | **权重** | **OS应用开发赛道** | **权重** |
| :--- | :--- | :--- | :--- |
| 代码（内核实现/实验设计） | 30% | 代码（应用开发实现） | 30% |
| 文档（设计文档/实验指导） | 30% | 文档（设计方案和测试） | 30% |
| 有助于教学 | 10% | 有助于教学 | 10% |
| 软件工程规范 | 10% | 软件工程规范 | 10% |
| 现场演示+答辩 | 20% | 现场演示+答辩 | 20%[citation:2] |

### 4.2 数据库管理系统设计赛

#### 4.2.1 技术平台与语言
- **开发语言**：C++
- **技术框架**：大赛提供的原型系统框架
- **核心功能**：存取管理、查询处理、事务处理三大核心功能的补充和完善[citation:1][citation:10]

#### 4.2.2 提交材料要求
- 源代码（按题目要求实现功能）
- 设计文档
- 性能测试结果[citation:8][citation:9]

### 4.3 编译系统设计赛

#### 4.3.1 赛道技术参数

| **项目** | **编译系统设计赛道** | **编译系统挑战赛道** |
| :--- | :--- | :--- |
| 技术方向 | ARM后端、RISC-V后端 | 华为命题（如MCU代码规模优化） |
| 初赛 | 线上提交作品，云端评测 | 线上提交作品 |
| 决赛 | 现场答辩 | 现场答辩[citation:3][citation:4] |

#### 4.3.2 挑战赛道示例（MCU代码规模优化）
- **目标**：在确保功能正确且性能损失合理前提下，减小面向特定目标平台的二进制可执行文件代码规模
- **技术手段**：汇编/链接时代码规模优化技术、基于GP寄存器的优化等[citation:4]

### 4.4 CPU设计赛（龙芯杯）

#### 4.4.1 技术要点
- **微架构**：流水线、超标量、预测、Cache等自行决定
- **硬件资源**：充分利用实验板硬件资源提高运行性能
- **综合系统**：设计并实现综合性的软硬件系统[citation:4][citation:10]

### 4.5 智能系统创新设计赛（小米杯）

#### 4.5.1 技术平台
- **硬件平台**：小米四足仿生机器人
- **技术领域**：运动控制、感知规划、算法设计、计算机视觉、图像识别、多CPU并行处理[citation:4]

#### 4.5.2 提交材料
- 源代码
- 设计文档
- 运行结果视频
- 按功能与性能指标评比[citation:4][citation:10]

## 六、报名技术规范

### 6.1 报名流程

| **步骤** | **操作说明** |
| :--- | :--- |
| **1. 官网注册** | 登录各赛道指定网站（https://compiler.educg.net/ 或各子平台） |
| **2. 填写信息** | 创建参赛队，添加队员和指导教师 |
| **3. 上传材料** | 学生证/工作证扫描件、加盖公章报名表、参赛诚信承诺书（单个文件打包） |
| **4. 确认报名** | 收到组委会邮件/短信确认后报名完成[citation:3][citation:5][citation:9] |

### 6.2 参赛费用
- **大赛不收取报名费、参赛费、评审费、技术平台购买费等任何费用**[citation:3][citation:9]
- 决赛期间交通、住宿、用餐费用自理
- 指定开发板由组委会免费发放[citation:3]

### 6.3 校内报名注意事项
- 需同时在**学校学科竞赛系统**和**大赛官网**报名
- 校内报名后务必加入竞赛QQ群[citation:10]

## 八、知识产权与学术诚信技术规范

### 8.1 开源要求
- 参赛作品源代码需遵循开源协议（GPL-3、Apache、BSD、木兰等）
- 文档遵循CC-BY-SA 4.0协议
- 大赛结束后公开参赛作品源代码、答辩PPT等资料[citation:9]

### 8.2 学术诚信
- 严禁抄袭、学术不端行为
- 使用第三方代码必须在文档和源代码头部明确说明
- 经监督委员会确认学术不端，取消参赛资格并通报学校[citation:2][citation:9]

### 8.3 代码注释规范
- 所有提交代码需有注释（中英文均可）
- 符合软件工程规范[citation:2]
