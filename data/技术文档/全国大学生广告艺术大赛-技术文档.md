# 全国大学生广告艺术大赛 参赛技术指南

## 一、赛事概述

**全国大学生广告艺术大赛**（简称“大广赛”）是面向全国高等院校在校大学生的国家级学科竞赛，自2005年首届举办至今，已成功举办17届。大赛遵循“促进教改、启迪智慧、强化能力、提高素质、创新创业”的竞赛宗旨，是全国规模最大、覆盖高校最广、参与师生人数最多的广告艺术类赛事之一，已纳入中国高等教育学会《全国普通高校学科竞赛排行榜》。

- **大赛官网**：https://www.sun-ada.net/

### 3.2 各类别技术规格

#### A. 平面类

| **项目** | **技术规格** |
| :--- | :--- |
| **单幅作品尺寸** | A3（297×420mm），横竖不限 |
| **系列作品** | ≤3张画面 |
| **色彩模式** | RGB |
| **分辨率** | 300dpi |
| **线上提交格式** | jpg |
| **线上提交文件大小** | ≤5MB/张 |

#### B. 视频类

| **细分类别** | **时长要求** | **画幅要求** | **文件大小** |
| :--- | :--- | :--- | :--- |
| **Ba 影视广告** | 15秒或30秒 | 横屏，16:9 | ≤30MB |
| **Bb 微电影广告** | 60秒-180秒 | 横屏，16:9 | ≤50MB |
| **Bc 短视频广告** | 15秒-60秒 | 竖屏，9:20至9:16 | ≤30MB |

- **格式**：mp4
- **其他要求**：严禁出现倒计时及创作者相关信息；系列短剧建议不超过3集，须合并为一个视频文件提交

#### C. 动画类

| **项目** | **技术规格** |
| :--- | :--- |
| **时长** | 15秒或30秒 |
| **帧率** | 24帧/秒 |
| **画幅** | 16:9 |
| **格式** | mp4 |
| **文件大小** | ≤30MB |
| **其他要求** | 须有配音、配乐，符合动画广告特点，严禁出现倒计时及创作者相关信息 |

#### D. 互动类

| **细分类别** | **技术规格** |
| :--- | :--- |
| **Da 线上互动广告** | 总页数≤15页，分辨率适合主流移动端设备屏幕尺寸；提交作品发布后的链接及二维码（保证1年内可正常查看） |
| **Db 线下互动广告** | 视频时长≤180秒，mp4格式，≤50MB，16:9，横竖屏不限 |

#### E. 广播类

| **细分类别** | **时长** | **格式** | **文件大小** |
| :--- | :--- | :--- | :--- |
| **Ea 15秒广播广告** | 15秒 | mp3 | ≤3MB |
| **Eb 30秒广播广告** | 30秒 | mp3 | ≤3MB |

## 四、创作规范

### 4.1 遵循命题要求

参赛作品必须严格依照大广赛组委会统一发布的命题进行创作。命题见大广赛官网或参赛手册。

### 4.2 原创性与诚信原则

| **要求项** | **说明** |
| :--- | :--- |
| **原创性** | 参赛作品必须为本人原创作品，拥有独立知识产权 |
| **法律合规** | 遵守《广告法》和其他相关法律及政策法规、行业规范等 |
| **创新鼓励** | 鼓励采用广告新思维、新形式、新技术进行创作 |
| **杜绝抄袭** | 坚持原创，杜绝抄袭，遵守《承诺书》的承诺 |

### 4.3 字体使用

字由平台为本届大广赛提供字体技术支持。参赛选手可通过竞赛专属活动页面注册后免费领取3个月字体会员，按照【字由官网用户协议及字体授权书的要求】使用字体，应用于参赛作品。

### 4.4 素材使用

创作中如使用了素材，务必在报名表中详细注明出处，并取得授权（授权书可线下附带提交至学校）。

### 4.5 AI工具使用

如使用AIGC工具辅助创作，须在报名表中予以注明。

## 五、作品提交与报送流程

### 5.1 关键时间节点

| **事项** | **时间节点** |
| :--- | :--- |
| **营销创客单元海选提交** | 2026年3月10日 - 4月10日22:00 |
| **线上作品提交** | **2026年5月10日 - 6月12日16:00** |
| **各赛区报送全国截止** | 2026年7月5日（以邮戳为准） |
| **退赛申请截止** | 2026年6月24日24:00 |

### 5.2 线上提交流程

| **步骤** | **操作说明** |
| :--- | :--- |
| **1. 注册账号** | 在大广赛官网“提交平台”注册账号 |
| **2. 上传学生证明** | 上传学生证拍图或学信网截图 |
| **3. 提交作品** | 按流程填写信息，上传作品 |
| **4. 转为正式作品** | 确认无误后将作品转为正式作品，系统自动生成唯一对应的参赛编号 |
| **5. 获取报名表** | 系统生成参赛报名表及承诺书 |
| **6. 电子签名** | 在线电子签名（特殊情况下可第一作者代签） |

### 5.3 线下报送流程

#### 5.3.1 参赛者向学校报送

- 将作品文件（已生成参赛编号的正式作品）、报名表的电子版统一报送给学校主管竞赛的负责人
- 文件均以参赛编号命名
- 保证报送到学校的作品及报名表内容与提交平台一致

#### 5.3.2 学校向赛区报送

- 学校核对报名表、作品电子文件与线上平台信息的一致性
- 线上填写院校参赛作品明细表并上传至提交平台
- 下载并导出《学校作品汇总表》，加盖公章
- 连同作品电子文件线下报送至所在赛区

#### 5.3.3 赛区向全国组委会报送

**线上报送**：
- 本赛区实际收取的参赛名单
- 报送全国总评审的参评作品明细表

**线下报送**：
- 参加全国总评审的作品电子版
- 参加全国总评审的作品名单（电子版+纸质版盖章）
- 赛区获奖名单（电子版）
- 赛区获奖名单（纸质版扫描件，须有评委签名）
- 赛区评审的评委名单

## 八、抄袭判定与处理

### 8.1 抄袭判定标准

| **判定标准** | **说明** |
| :--- | :--- |
| **创意核心高度相似** | 作品整体设计理念、主题构思、关键视觉元素组合、创意表达方式与他人已公开作品高度雷同 |
| **作品内容复制比率偏高** | 作品中有超过60%的内容直接复制自他人作品，且未作实质性修改或创新转化 |
| **过度模仿与借鉴** | 过度依赖他人设计元素、风格或手法，导致作品整体呈现明显模仿痕迹，缺乏独立创作特征 |
| **未经授权许可** | 未经著作权人许可使用其原创作品，并以自己名义参赛 |

### 8.2 抄袭处理措施

| **处理措施** | **说明** |
| :--- | :--- |
| **取消参赛资格** | 无论处于比赛哪个阶段，涉事参赛者立即取消参赛资格，作品从评选流程中剔除 |
| **通报抄袭行为** | 通报给涉事参赛者所在的赛区及学校 |
| **公示抄袭事实** | 在官方网站上对抄袭作品详情及抄袭事实进行公示通报批评 |
| **追究法律责任** | 保留追究涉事参赛者法律责任的权利，协助原创者或著作权人通过法律途径维权 |
