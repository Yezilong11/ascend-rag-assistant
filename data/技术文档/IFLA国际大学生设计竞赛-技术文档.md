# IFLA国际大学生设计竞赛 参赛技术指南

## 一、赛事概述

**IFLA国际大学生设计竞赛**（IFLA International Student Design Competition）是由国际风景园林师联合会（International Federation of Landscape Architects，简称IFLA）主办的全球性学生设计竞赛。该竞赛是风景园林领域最具影响力的国际学生赛事之一，作为IFLA世界大会（IFLA World Congress）的核心活动举行，旨在鼓励和发掘未来景观设计师的创新思维与解决实际问题的能力[citation:1][citation:6]。

- **主办单位**：国际风景园林师联合会（IFLA）
- **第60届IFLA世界大会时间**：**2026年10月28日-30日**
- **第60届IFLA世界大会地点**：中国香港
- **大会主题**：**“Liminal Landscapes: Shifting Boundaries of Watersheds and Coastlines”**（阈限景观：流域与海岸线的变迁边界）[citation:3]
- **学生竞赛主题**：**“Guiding Landscapes”**（引导性景观）[citation:6]

## 二、竞赛技术参数

### 2.1 竞赛主题与方向

| **项目** | **技术规格** |
| :--- | :--- |
| **竞赛主题** | Guiding Landscapes（引导性景观）[citation:6] |
| **主题内涵** | 围绕气候变化、社会不平等、生物多样性丧失等全球挑战，提出以景观为基础的引导性策略，促进协作与创新[citation:6] |
| **设计方向** | 景观建筑学视角下的创新解决方案，鼓励跨学科协作 |

### 2.2 参赛资格

| **项目** | **技术规格** |
| :--- | :--- |
| **面向对象** | 全球风景园林、景观建筑及相关专业（城市规划、环境设计等）在校大学生 |
| **学历层次** | 本科生、硕士生、博士生均可参赛[citation:2] |
| **组队方式** | 以团队为单位参赛，每组成员一般不超过5人 |
| **指导教师** | 可邀请1名指导老师 |

## 三、作品技术规范（基于往届通用标准）

### 3.1 提交内容

| **成果类型** | **内容要求** |
| :--- | :--- |
| **设计图纸** | 平面图、剖面图、效果图、分析图、概念图解等 |
| **设计说明** | 英文，清晰阐述设计理念、策略、创新点 |
| **附加材料** | 模型照片、动画视频（可选） |

### 3.2 图纸技术规格（往届参考）

| **项目** | **技术规格** |
| :--- | :--- |
| **图纸数量** | 通常不超过3幅 |
| **图纸尺寸** | A1（841mm×594mm）或A0（1189mm×841mm） |
| **文件格式** | JPG或PDF |
| **分辨率** | ≥300dpi |
| **语言要求** | 设计说明须为英文 |

## 五、评审技术指标

| **评审维度** | **考察要点** |
| :--- | :--- |
| **主题契合度** | 作品是否深刻回应“Guiding Landscapes”主题[citation:6] |
| **创新性与原创性** | 设计概念、方法或技术应用的独特性 |
| **可持续性与生态考量** | 方案在环境保护、生态修复等方面的思考 |
| **可实施性与社会价值** | 设计对气候变化、社会不平等、生物多样性等现实问题的解决能力[citation:6] |
| **图面表达与逻辑性** | 设计成果的呈现质量、清晰度和逻辑说服力 |

## 七、原创性与学术诚信技术规范

### 7.1 原创性要求

| **要求** | **说明** |
| :--- | :--- |
| **原创性** | 参赛作品必须是参赛者本人原创设计，不得抄袭、盗用他人成果 |
| **指导原则** | 可在指导教师指导下完成，但核心创意和设计工作须由参赛者本人完成 |
