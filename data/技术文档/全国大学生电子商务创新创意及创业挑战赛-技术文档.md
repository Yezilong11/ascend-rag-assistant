# 全国大学生电子商务“创新、创意及创业”挑战赛 技术文档

## 一、赛事概述

**全国大学生电子商务“创新、创意及创业”挑战赛**（简称“三创赛”）是从2009年开始，根据教育部、财政部（教高函〔2010〕13号）文件精神创办，并列入中国高等教育学会《全国普通高校学科竞赛排行榜》的赛事[citation:1]。本项赛事现已成为颇具影响力的全国性品牌赛事，在《2023全国普通高校大学生竞赛分析报告》84项赛事中排名第12位，在2024年全国高校大学生学科竞赛排行榜“创新创业类”赛事中排名第三[citation:1][citation:6]。

### 1.1 办赛宗旨与价值
大赛的目的是**强化创新意识、引导创意思维、锻炼创业能力、倡导团队精神**[citation:2][citation:4]。大赛的价值是**促进教学，促进实践，促进就业，促进创业，促进升学、促进育人**[citation:2][citation:4]。

### 1.2 第十六届基本信息
- **主办单位**：全国电子商务产教融合创新联盟、西安交通大学[citation:1][citation:2][citation:4]
- **官方网站**：http://www.3chuang.net/ [citation:1]
- **官方微信公众号**：电子商务三创赛（eccn3chuang）[citation:1]
- **赛事级别**：全国A类赛事[citation:10]
- **参赛规模**：第十五届官网报名超过23万支团队[citation:5][citation:6]

## 三、参赛资格与组队要求

### 3.1 参赛对象
经教育部批准设立的普通高等学校的全日制在校大学生（专科、本科、研究生均可，专业不限）可以报名参赛[citation:1][citation:2][citation:3]。高校教师既可以作为指导老师（在学生队中），也可以作为参赛选手（在混合队中做队长或队员）组成师生混合队参赛[citation:4][citation:8][citation:10]。

### 3.2 组队方式

参赛选手有两种组队方式[citation:4][citation:8][citation:10]：

| **组队方式** | **说明** |
| :--- | :--- |
| **学生队** | 学生作为队长，队长和队员须全部为全日制在校学生 |
| **混合队** | 教师作为队长或队员，但队员中学生数量必须多于教师 |

### 3.3 组队规模与限制

| **项目** | **要求** |
| :--- | :--- |
| **队员人数** | 每支参赛团队由**3-5名学生**组成，其中一名为队长[citation:1][citation:2][citation:3] |
| **跨校组队** | **可以跨校组队**，以队长所在学校为该队报名学校[citation:1][citation:3][citation:4] |
| **每人限报** | 每人可以同期参加常规赛、实战赛两类比赛中的**两个**（不能是一类比赛中的两个），但不能是同一个项目[citation:1][citation:2][citation:3] |
| **同一团队双赛** | 同一团队如果参加两个比赛，必须通过两个不同的邮箱号进行注册，系统会分别自动生成两个不同的团队ID号[citation:1][citation:2][citation:3] |
| **指导教师** | 可以有**0-2名高校指导老师**，**0-2名企业指导老师**[citation:1][citation:2][citation:3] |

### 3.4 人员变更规则

| **时间节点** | **变更规则** |
| :--- | :--- |
| **报名截止前** | 可以自由添加、修改成员信息[citation:1] |
| **审核通道关闭后** | 仅可申请**减员**，不能增员或更换成员[citation:1][citation:3][citation:4] |
| **减员流程** | 在官网下载《团队减员申请表》，由第一高校指导老师、队长以及被减掉的队员或指导老师签字，经校赛管理员审查后提交竞组委秘书处备案复核确认[citation:1][citation:3][citation:4] |
| **人数下限** | 团队学生数不得低于3人[citation:1][citation:3][citation:4] |

### 3.5 信息一致性要求
团队参赛过程中提交的作品文档（Word、PDF、PPT、纸质材料等）和演讲中团队成员信息、高校指导老师信息、企业指导老师信息等，必须与官网注册信息完全一致，否则取消参赛资格[citation:4][citation:8]。

## 五、报名方式与流程

### 5.1 报名流程

| **步骤** | **操作说明** |
| :--- | :--- |
| **1. 官网注册** | 由团队学生队长在三创赛官网（http://www.3chuang.net）统一注册[citation:1][citation:2][citation:3] |
| **2. 规则测试** | 队长需完成第十六届三创赛重要规则（第四十八条到第五十四条）的答题测试，通过后方可完成正式注册[citation:2][citation:3][citation:5] |
| **3. 添加成员** | 登录团队账号，选择“成员管理”模块，添加团队成员、高校指导老师、企业指导老师[citation:1][citation:8] |
| **4. 上传材料** | 上传作品摘要、《团队高校指导老师承诺书》等材料[citation:4] |
| **5. 学校审核** | 校赛管理员审核通过后即为报名成功[citation:1][citation:3][citation:5] |

### 5.2 实战赛特殊要求
实战赛团队报名过程中还需提交《**实战赛参赛学生知情书**》[citation:1][citation:8]。

### 5.3 参赛费用
根据大赛章程，大赛为公益性活动，**不向参赛队伍收取报名费、参赛费**[citation:6]。各参赛作品的制作及参赛所需费用由参赛学生所在学校承担。

| :--- | :--- |

| **《团队高校指导老师承诺书》** | 需签字，随作品提交[citation:1][citation:4][citation:7] |
| **《实战赛参赛学生知情书》** | 实战赛团队需提交[citation:1][citation:8] |

### 6.2 迭代创新作品要求
对于迭代创新作品（在已有作品基础上进行的再创新），需满足以下条件[citation:1][citation:4][citation:9]：
1. 提交的新作品对原参赛作品做了明显地再创新
2. 提交原参赛作品
3. 提交新旧作品的比较说明（对迭代创新的主要内容给予说明）

### 6.3 知识产权说明
参赛者应拥有作品著作权，大赛组委会不承担包括（不限于）肖像权、名誉权、隐私权、著作权、商标权等纠纷而产生的法律责任，其法律责任由参赛团队承担[citation:9]。参赛队如果出现侵权行为，大赛组委会保留取消其参赛资格及追回奖项、奖品的权力[citation:9]。

## 八、评审与奖项设置

### 8.1 评审原则
大赛组委会本着“**公平、公正、公开、科学、规范**”的原则，对每一件参赛作品进行评比[citation:2][citation:6]。三创赛遵循“**公开、公平、公正**”的三公原则，在《项目报告书》中，参赛团队及所属学校的名称应实名标出（不允许匿名），有利于监督[citation:2]。

### 8.2 奖项设置

| **级别** | **奖项** |
| :--- | :--- |
| **校赛** | 设一、二、三等奖，由学校颁发获奖证书[citation:1][citation:9] |
| **省级赛** | 设一、二、三等奖，由大赛组委会颁发电子证书[citation:1] |
| **全国总决赛** | 设一、二、三等奖，由大赛组委会颁发证书[citation:1] |
| **特别奖项** | 优秀指导教师奖、优秀学校组织奖等[citation:2] |

### 8.3 获奖比例参考
校赛获奖比例按照有效参赛队伍计算，由各校自行确定[citation:9]。省赛和国赛获奖比例以组委会最终核定为准。

## 九、原创性与学术规范

### 9.1 原创性要求
- 参赛作品必须是参赛团队的**原创作品**且首次公开发表（或参赛）[citation:1][citation:4][citation:9]
- 不可不经修改直接使用参加其他竞赛的参赛作品参赛[citation:1][citation:4]
- 指导教师要切实履行项目真实性第一责任人的义务[citation:9]

### 9.2 学术规范
- 严禁抄袭、盗用他人成果[citation:9]
- 一经发现学术不端行为，立即取消该团队参赛资格，并给予学校官网通报批评[citation:9]

## 十一、参赛注意事项

### 11.1 报名注意事项
- 必须在官网（www.3chuang.net）完成统一注册[citation:1][citation:2][citation:4]
- 队长需通过规则答题测试才能完成注册[citation:2][citation:3][citation:5]
- 必须同时在**学校创新创业平台**和**竞赛官网**进行注册和报名（部分高校要求）[citation:2]
- 最终报名信息以官网为准，获奖证书严格按照官网信息制作[citation:1][citation:4]

### 11.2 作品提交注意事项
- 作品摘要需在2026年1月10日前上传官网[citation:4]
- 各高校校内截止时间通常早于全国截止时间，请及时关注校内通知
- 严格按照组委会发布的文档格式要求制作[citation:2][citation:6]

### 11.3 信息一致性
- 团队所有信息（成员、指导老师、作品名称等）在校赛审核通过后原则上不得更改[citation:4]
- 校赛、省级赛、国赛获奖证书仅以三创赛官网信息为准[citation:4]
- 如果遗漏或者填写错误导致信息不一致，将取消团队比赛成绩[citation:4]

### 11.4 实战赛特别提示
- 实战赛与常规赛同等规范化，强调原创和迭代创新两种形式参赛[citation:1][citation:3][citation:5]
- 参加实战赛道的团队请关注官网各分赛道赛事报名指南和实施要点[citation:10]
- 需提交《实战赛参赛学生知情书》[citation:1][citation:8]
