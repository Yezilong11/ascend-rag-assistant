# 中国大学生计算机设计大赛 参赛技术指南

## 一、赛事概述

**中国大学生计算机设计大赛**（简称“4C”或“大赛”）启筹于2007年，始创于2008年，是我国高校面向本科生最早的赛事之一。大赛由教育部计算机相关教指委发起创办，现由北京语言大学、中国人民大学、华东师范大学、浙江大学、南京大学、东南大学、山东大学、厦门大学、东北大学等高校，以及清华大学、北京大学、复旦大学等高校的教师组成的中国大学生计算机设计大赛组织委员会主办[citation:4]。

大赛已入选中国高等教育学会《全国普通高校大学生竞赛分析报告》竞赛目录，是全国普通高校学科竞赛排行榜的榜单赛事之一[citation:3][citation:5]。大赛的目的是以赛促学、以赛促教、以赛促创，为国家培养德智体美劳全面发展的创新型、复合型、应用型人才服务[citation:1]。

- **大赛官网**：http://jsjds.blcu.edu.cn/
- **作品提交平台**：http://2026.jsjds.com.cn/ [citation:6]
- **官方微信公众号**：计算机设计大赛服务号、计算机设计大赛JX信息[citation:6]

## 二、赛道设置与作品分类

2026年（第19届）大赛分设**11个大类**，具体如下[citation:1][citation:2][citation:4]：

| **类别编号** | **大类名称** | **包含小类/说明** |
| :--- | :--- | :--- |
| **（1）** | 软件应用与开发 | Web应用与开发、管理信息系统、移动应用开发（非游戏类）、算法设计与应用、软件应用与开发专项赛[citation:9] |
| **（2）** | 微课与AI辅助教学 | 人工智能通识课/计算机基础类课程的微课、教学课件、虚拟仿真实验、教学案例；中/小学数学或自然科学课程的微课；汉语言文学（限于唐宋诗词）微课；专项赛[citation:9] |
| **（3）** | 物联网应用与物联网创新转化（创业实践） | 城市管理、医药卫生、运动健身、数字生活、行业应用、物联网专项、物联网创新转化（创业实践）[citation:9] |
| **（4）** | 大数据应用 | 大数据实践赛、大数据主题赛[citation:9] |
| **（5）** | 人工智能应用 | 人工智能实践赛、人工智能挑战赛[citation:9] |
| **（6）** | **AI+信息可视化设计** | 信息图形设计、动态信息影像（MG动画）、交互信息设计、数据可视化[citation:9] |
| **（7）** | **AI+数媒静态设计** | 平面设计、环境设计、产品设计[citation:9] |
| **（8）** | **AI+数媒动漫与短片** | 微电影、数字短片、纪录片、动画、新媒体漫画[citation:9] |
| **（9）** | **AI+数媒游戏与交互设计** | 游戏设计、交互媒体设计、虚拟现实VR与增强现实AR[citation:9] |
| **（10）** | **AI+计算机音乐创作** | 纯音乐类、歌曲类、配乐与声音设计类[citation:9] |
| **（11）** | **国际生“AI+汉学”（“中华优秀传统文化”数智创作）** | 涵盖软件应用与开发、微课、物联网、大数据、人工智能、AI+信息可视化、AI+数字媒体、AI+计算机音乐创作等方向[citation:9] |

## 三、2026年作品主题与AI工具规范

### 3.1 数媒类与可视化类作品主题

2026年大赛的**（6）至（11）共6个大类**的作品主题是：**“中国古代建筑成就——中华优秀传统文化系列之六”**[citation:2][citation:4][citation:5]。

| **主题要求项** | **技术规格** |
| :--- | :--- |
| **内容范围** | 民居、官府、皇宫、桥梁（不含庙宇、宝塔）[citation:2][citation:4][citation:5] |
| **时间限制** | 限在1911年以前[citation:2][citation:4][citation:5] |
| **具体方向** | （1）中国古代建筑成就——弘扬中华优秀自然科学成就；<br>（2）中国古代建筑领域杰出科学家——弘扬中华优秀古建筑科学家精神；<br>（3）中国古代建筑著作——弘扬中华优秀古建筑学专著；<br>（4）中国古代建筑文化——弘扬中华优秀古建筑文明和文化传承[citation:5][citation:9] |

### 3.2 AI工具使用规范

| **项目** | **技术规格** |
| :--- | :--- |
| **AI工具使用** | 参赛作品中鼓励使用人工智能工具[citation:5][citation:8] |
| **工具范围** | 必须采用大赛组委会指定的**15款国产免费AI工具**（每年动态调整一次，2026年AI工具列表详见官网附件），或采用拥有自主知识产权的AI工具[citation:2][citation:4][citation:5] |
| **评审焦点** | 评审焦点始终是参赛作者本身对AI工具的**驾驭能力**，而非AI工具的性能；重点考核作者运用、组合和优化AI工具以解决实际问题的技能与策略[citation:5][citation:8] |
| **专业/非专业组** | 数媒类和可视化类作品中，有专业队员参赛（无论排名）仅能报专业组赛道，参与队员均为非专业学生的只能报非专业赛道，否则按无效作品处理[citation:2][citation:7] |

## 四、参赛资格与组队规范

### 4.1 参赛对象

| **项目** | **技术规格** |
| :--- | :--- |
| **学历层次** | 全国普通高校全日制在校本科生（以2026年6月为准）[citation:1][citation:4] |
| **特殊群体** | 含港澳台学生及来华留学生[citation:4][citation:5] |
| **组别限制** | 不得与高职高专学生或研究生混合组队[citation:9] |

### 4.2 组队技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **队员人数** | **2-9名**本科生/队[citation:3][citation:4][citation:5]（部分赛区要求2-5名[citation:2][citation:7]） |
| **指导教师** | ≤2名/队[citation:1][citation:2][citation:3] |
| **跨校组队** | 不允许跨校组队，须来自同一所学校[citation:9] |
| **每人限报** | 每位作者在每个大类中只能提交1件作品，无论作者排名如何[citation:4][citation:5][citation:9] |
| **一稿多投** | 参赛作品不得在本大赛的11个大类间一稿多投[citation:3][citation:4][citation:9] |
| **答辩要求** | 每队到国赛决赛现场参与答辩的作者不少于（含）2人（特殊情况除外）[citation:4][citation:9] |

## 五、作品技术规范

### 5.1 作品原创性要求

| **要求项** | **技术规格** |
| :--- | :--- |
| **完成时间** | 必须是参赛者在本届大赛期间（**2025年7月1日 - 2026年6月30日**）完成的原创作品[citation:3][citation:4][citation:5] |
| **重复参赛** | 与2025年7月1日之前校外展出或获奖的作品雷同的作者前期作品，不得重复参赛[citation:3][citation:4][citation:5] |
| **知识产权** | 参赛作品的版权必须属于参赛作者，不得侵权；凡已经转让知识产权或不具有独立知识产权的作品，均不得参赛[citation:3][citation:4][citation:5] |

### 5.2 提交材料清单

各高校校赛提交要求略有差异，综合整理如下[citation:8]：

| **材料类型** | **内容要求** | **规格限制** |
| :--- | :--- | :--- |
| **演示答辩视频** | 作品展示与讲解 | ≤10分钟[citation:8] |
| **答辩幻灯片** | 用于评审的演示文稿 | ≤50MB，PPT/PPTX格式[citation:8] |
| **源代码文件** | 关键源代码（软件类必交）[citation:2][citation:7] | ≤100MB，ZIP格式[citation:8] |
| **作品演示文件** | 用于网络评审及公示[citation:1] | 格式及要求按官网规范 |
| **作品源文件** | 过程文件、设计源文件[citation:1][citation:5] | — |
| **团队名单** | 包含成员及指导教师信息 | Excel格式[citation:8] |
| **报名表** | 系统生成的报名表，全体作者及指导教师手写签字[citation:9] | 拍照/扫描上传系统 |
| **版权声明** | 系统生成的版权声明，全体作者及指导教师手写签字[citation:9] | 拍照/扫描上传系统 |
| **压缩包命名** | 赛道名称+作品名称+队长姓名 | RAR/ZIP，≤500M[citation:8] |

### 5.3 匿名评审要求

除团队名单外，其他材料避免出现成员与指导老师等信息，未按规定提交材料的视为报名未成功[citation:8]。

### 5.4 地图使用规范

| **要求项** | **技术规格** |
| :--- | :--- |
| **地图来源** | 涉及国家当代疆域版图时，须以中国国家相关出版社或相关地图网站（如中华人民共和国自然资源部网站、国家地理信息公共服务平台、标准地图服务网站）的地图为准[citation:3][citation:5][citation:6] |
| **审图号** | 必须注明地图来源和审图号[citation:3][citation:5][citation:8] |
| **违规处理** | 未注明审图号的地图作品属于违规，取消参赛资格[citation:3][citation:5][citation:8] |

### 5.5 数据安全要求

参赛作品的数据应来源合规、信息处理恰当，不得引用涉密数据，不得侵犯个人隐私等[citation:5][citation:8]。

## 六、赛制与赛程技术时间轴

### 6.1 三级赛制

大赛采用**校级赛-省级赛-国家级决赛**三级竞赛形式[citation:1][citation:2][citation:3]。

| **级别** | **组织单位** | **晋级规则** |
| :--- | :--- | :--- |
| **校级赛** | 各高校 | 选拔优秀作品上推省赛[citation:1] |
| **省级赛** | 各省赛区组委会 | 评审后推荐优秀作品入围国赛[citation:3] |
| **国家级决赛** | 全国大赛组委会 | 现场决赛，决出全国奖项[citation:1][citation:3] |

### 6.2 第19届大赛时间安排（2026年）

综合各高校校赛通知，时间安排如下：

| **阶段** | **时间节点** | **技术任务** |
| :--- | :--- | :--- |
| **校赛报名与作品提交** | **2026年3月-4月**（各校截止时间不同：3月15日[citation:3]、3月22日[citation:5]、3月27日[citation:7]、4月5日[citation:8]、4月14日[citation:6]、4月26日[citation:9]） | 官网注册报名，提交作品 |
| **校赛评审** | 2026年4月中下旬 | 各校组织评审，确定上推省赛名单[citation:1][citation:2][citation:7] |
| **省级赛** | **2026年5月-6月** | 各省组织评审，推荐国赛作品[citation:1][citation:2][citation:3] |
| **全国总决赛** | **2026年7月-8月** | 各决赛区现场答辩[citation:1][citation:2][citation:3] |
| **评审结果公示** | 2026年9月-10月[citation:2] | 获奖名单公示与发布 |
