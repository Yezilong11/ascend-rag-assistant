# “天作奖”国际大学生建筑设计竞赛 参赛技术指南

## 一、赛事概述

**“天作奖”国际大学生建筑设计竞赛**是由《建筑师》杂志主办的国际性大学生建筑设计竞赛，旨在鼓励在校建筑专业学生的创造性思维，培养具有国际视野和创新能力的建筑设计人才。

- **主办单位**：《建筑师》杂志
- **竞赛官网**：http://thearchitect.cabp.com.cn/

---

## 二、参赛资格技术规范

### 2.1 参赛对象

| **项目** | **技术规格** |
| :--- | :--- |
| **学历要求** | 全国全日制建筑院系在校学生（含本科生、研究生） |
| **专业范围** | 建筑学及相关专业 |
| **国籍要求** | 无限制，欢迎国际学生参赛 |

### 2.2 组队技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **参赛形式** | 个人或小组形式参赛 |
| **队员人数** | ≤4人/组 |
| **指导教师** | ≤2名 |

## 三、作品技术规范

### 3.1 图纸技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **图纸数量** | 2幅 |
| **图纸尺寸** | A1（841mm×594mm） |
| **文件格式** | JPG |
| **分辨率** | ≥300dpi |

### 3.2 匿名评审要求

| **项目** | **技术规格** |
| :--- | :--- |
| **个人信息** | 图纸中不得出现任何有关作者姓名、所在院校、指导教师信息的文字或图案 |
| **违规处理** | 不符合匿名评审规定的作品将被取消参赛资格 |

## 七、原创性与学术诚信技术规范

### 7.1 原创性要求

| **要求** | **说明** |
| :--- | :--- |
| **原创性** | 参赛作品必须是参赛者本人原创设计，不得抄袭、盗用他人成果 |
