# 全国大学生机械创新设计大赛 技术文档

## 一、赛事概述

**全国大学生机械创新设计大赛**经教育部高等教育司批准成立大赛组织委员会，是由教育部高等教育司发文举办的全国理工科重要课外竞赛活动之一[citation:2]。大赛每两年举办一届，自2003年以来已成功举办十一届，是国内最具影响力、培养学生工程实践能力和综合素质效果显著的大学生竞赛项目之一，已纳入全国普通高校学科竞赛排行榜[citation:8][citation:10]。

### 1.1 办赛宗旨
大赛旨在引导高等学校在教学中注重培养大学生的创新设计意识、综合设计能力与团队协作精神；加强学生动手能力的培养和工程实践的训练，提高学生针对实际需求通过创新思维，进行机械设计和工艺制作等实际工作能力；吸引、鼓励广大学生踊跃参加课外科技活动，为优秀人才脱颖而出创造条件[citation:1][citation:7]。

### 1.2 办赛特色
大赛始终坚持“**实物参赛、机电结合、系统训练、创新应用、科技兴国**”的办赛特色，为创新人才培养提供了良好的创新实践平台和交流展示舞台[citation:2]。

### 1.3 大赛文化
大赛弘扬在办赛实践中形成的“**规范、平等、优雅、仁爱、创新**”大赛文化，确保大赛健康发展[citation:7]。

### 1.4 第十二届基本信息
- **举办时间**：2026年7月
- **全国决赛承办单位**：哈尔滨工业大学[citation:1][citation:10]
- **大赛官网**：https://umic.moocollege.com/ [citation:1][citation:10]
- **专题网站**：https://12umic.hit.edu.cn/ [citation:9]
- **主办单位**：全国大学生机械创新设计大赛组委会、教育部高等学校机械基础课程教学指导分委员会[citation:3]

## 二、大赛主题与内容

### 2.1 第十二届大赛主题
第十二届全国大学生机械创新设计大赛的主题为：**“灵巧·智能，美好生活”**[citation:1][citation:3][citation:10]。

### 2.2 2026年常规赛季内容
2026年常规赛季的内容为设计与制作以下三类机械[citation:1][citation:4][citation:10]：

| **序号** | **内容** | **简要说明** |
| :--- | :--- | :--- |
| **1** | 特定水产品初加工机械 | 鱼类、甲壳类和贝类的批量化去鳞、去内脏、去壳等加工工序 |
| **2** | 叶菜洁净化处理包装一体化机械 | 叶菜去根、去黄叶、去泥土、归一化加工并按重量包装 |
| **3** | 高性能仿生蝴蝶 | 具有明确蝴蝶外形，4个独立翅膀、6只足，进行运动性能比赛 |

### 2.3 内容详细说明

#### 2.3.1 特定水产品初加工机械
- **限定范围**：水产品中的**鱼类、甲壳类和贝类**这三类，不包括藻类、软体动物和其他水生动物[citation:1][citation:10]
- **加工要求**：初加工是指对限定水产品完成批量化去鳞、去内脏和去壳等加工工序，方便后续运输、晾晒处理以形成初级商品[citation:1]
- **选题示例**：鲜虾剥虾仁机械、马面鱼剥皮处理机、海虹去壳机等，**不包括烹饪机械**[citation:1]
- **应用场景**：用于对水产品的批量加工、处理场合，而非家庭厨房场合[citation:1]
- **调研建议**：大赛组委会提倡学生们亲自去学校当地水产品生产加工基地进行调研，获取设计灵感，完成样机设计，实现特定水产品批量加工、处理功能，并期望能进一步推广应用[citation:1]

#### 2.3.2 叶菜洁净化处理包装一体化机械
- **叶菜范围**：青菜、菠菜、韭菜、（小）白菜、空心菜、茼蒿、大葱等，**不包括根茎花类菜**如洋葱、土豆、莲藕、萝卜、蒜苔、韭苔、菜花、韭菜花等[citation:1][citation:10]
- **洁净化处理**：包括对叶菜去根、去黄叶、去泥土和归一化加工等工序[citation:1]
- **包装要求**：对处理后的叶菜要按一定重量进行包装，方便后续出售[citation:1]
- **应用场景**：用于批量生产供应给城乡超市的叶菜加工场合，而非家庭厨房场合[citation:1]
- **调研建议**：提倡学生们亲自去蔬菜种植基地或自己的家乡进行调研，完成样机设计[citation:1]

#### 2.3.3 高性能仿生蝴蝶
- **外形要求**：须有明确的蝴蝶外形，即仿生蝴蝶有类似真蝴蝶的身体部分（包括头、眼、触须，胸、腹）、**4个连接在胸部且独立的翅膀**和**6只足**等[citation:1][citation:10]
- **评审重点**：对该类仿生机械的运动性能进行比赛和仿生设计评审[citation:6]

### 2.4 技术导向
提倡在常规赛设计机械作品时应用**智能技术、数字（孪生）技术或5G+通信技术**等，以提升作品的时代特征[citation:3][citation:4]。

## 三、参赛资格与组队要求

### 3.1 参赛对象
全国普通高等院校在校本、专科大学生（含当届毕业生）均可报名参赛[citation:6][citation:7]。参赛者的身份由所在学校学籍管理部门负责审核确认[citation:7]。

### 3.2 组队要求
| **项目** | **要求** |
| :--- | :--- |
| **队员人数** | 每个参赛队学生人数**不得多于5人**[citation:1][citation:6][citation:7] |
| **指导教师** | 指导教师**不多于2人**[citation:1][citation:6][citation:7] |
| **教师指导限额** | 每位教师指导的作品不超过3项[citation:6] |
| **作品原创性** | 不得将教师的科研成果或其他不满足参赛条件的他人的作品充当参赛[citation:7] |

## 四、赛制与赛程安排

### 4.1 三级赛制
大赛采用“**学校选拔赛—分赛区预赛—全国决赛**”三级赛制[citation:1][citation:4][citation:7]：
- **学校选拔赛**：各高校自行组织，确定参加分赛区预赛的作品名单
- **分赛区预赛**：各省、直辖市、自治区组织，确定推荐参加全国决赛的作品名单
- **全国决赛**：全国统一组织，评定最终奖项

## 五、参赛作品要求

### 5.1 基本要求
1. **实物参赛**：所有参赛作品必须以实物参赛，与本届大赛的主题和内容不符的作品不能参赛[citation:1][citation:10]
2. **原创性**：参赛作品必须为原创，不得侵犯他人知识产权
3. **应用技术**：提倡应用智能技术、数字（孪生）技术或5G+通信技术等[citation:3]

### 5.2 提交材料清单

| **材料名称** | **内容要求** |
| :--- | :--- |
| **作品报名表** | 纸质、电子文档，正反面打印[citation:6] |
| **设计说明书** | 完整的设计说明书，详细阐述设计理念、技术方案、创新点等[citation:1][citation:4] |
| **主要设计图纸** | 包括（A0或A1）总装配图、部件装配图和重要零件图，要求正确、规范[citation:6] |
| **实物样机** | 作品的实物样机或放缩的实物样机[citation:1][citation:4] |
| **演示视频** | **3分钟之内**，MP4或rmvb格式，介绍作品功能[citation:1][citation:4][citation:6] |

### 5.3 图纸质量要求
所有对机械设计图纸的国家标准要求和工艺设计要求均为图纸质量评价的要素[citation:6]。

## 六、评审标准

### 6.1 评价观测点
参赛作品的评审采用综合评价，评价观测点有以下几个方面[citation:1][citation:4][citation:10]：

| **评价类别** | **观测点** |
| :--- | :--- |
| **选题评价** | （1）新颖性 （2）实用性 （3）意义或前景 |
| **设计评价** | （1）创新性 （2）结构合理性 （3）工艺性 （4）智能、数字和5G通信技术的应用 （5）设计说明书、图纸质量 |
| **制作评价** | （1）功能实现 （2）制作水平与完整性 （3）作品性价比 |
| **现场评价** | （1）介绍及演示 （2）答辩与质疑 |

### 6.2 评审原则
大赛坚持“**公平、公正、公开、科学、高效**”的评审原则[citation:7]。

## 七、奖项设置

### 7.1 奖项类别
全国决赛设立设计奖、单项奖、组织奖三类奖项[citation:7]。

#### 7.1.1 设计奖
全国决赛设立一等奖、二等奖、三等奖三个获奖等级。原则上，以符合当届大赛主题和要求的全国作品总数为基数，**获奖作品数量的比例为10%左右**[citation:7]。一等奖、二等奖、三等奖等级的具体数量和比例由全国决赛评审委员会根据当届赛事实际情况确定[citation:7]。

#### 7.1.2 单项奖
由当届决赛评审委员会提出各种类型的单项奖的名称，并作相应的提名，报全国大赛组委会批准[citation:7]。

#### 7.1.3 组织奖
设立优秀组织奖、杰出贡献奖、贡献奖、赞助奖和纪念奖等[citation:7]：
- **优秀组织奖**：对决赛承办单位，以及在预赛组织工作中表现突出的分赛区颁发
- **杰出贡献奖、贡献奖、赞助奖、纪念奖**：对大赛工作中有突出贡献的个人、企业和单位分别颁发

### 7.2 校内奖项参考
各高校校内选拔赛通常设一、二、三等奖，获奖比例按照有效参赛队伍计算，由学校颁发获奖证书，并推荐优秀作品参加省赛[citation:4][citation:6]。

### 7.3 历届获奖比例参考（第十届）
- **一等奖**：162项，获奖率约3%
- **二等奖**：266项，获奖率约5%
- **三等奖**：125项[citation:8]

## 九、申诉与仲裁

### 9.1 公示期
- 全国决赛举行前一个月左右，在大赛指定网站公示所有参加决赛作品的名单[citation:7]
- 全国决赛评审结果自公布之日起**七日时间**作为获奖作品名单的公示期[citation:7]

### 9.2 申诉流程
在公示期内，若对参赛作品评审结果持有异议者，可向申诉受理人提交具有申诉人真实姓名（签字）和单位公章的**书面申诉书**，提请决赛仲裁委员会进行处理[citation:7]。由决赛仲裁委员会负责回复处理意见，并将结果报送全国大赛组委会[citation:7]。

## 十、知识产权说明

1. **默认权利**：全国大赛组委会拥有非盈利性的发布或编辑参赛作品的简介、聘请专家对参赛作品进行评价、向相关机构和组织推荐参赛作品的默认权利[citation:7]
2. **权利保留**：如果参赛作品的知识产权人对这些权利有异议者，请在参赛作品的报名表中申明[citation:7]
3. **责任归属**：全国大赛组委会不负责参赛作品的知识产权事宜[citation:7]
4. **名称使用**：未经全国大赛组委会允许，不得擅自使用“全国大学生机械创新设计大赛”的名称和赛徽[citation:7]
