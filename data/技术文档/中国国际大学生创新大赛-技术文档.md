# 中国国际大学生创新大赛 参赛技术指南

## 一、赛事概述

**中国国际大学生创新大赛**（原“互联网+”大学生创新创业大赛）是由教育部、中央统战部、国家发展改革委、中国科学院、中国工程院等十余个部委共同主办的国际性创新创业大赛。大赛旨在深化高等教育综合改革，激发大学生的创造力，培养造就“大众创业、万众创新”的生力军，推动赛事成果转化和产学研用紧密结合，促进“互联网+”新业态形成，以创新引领创业、创业带动就业。

- **主办单位**：教育部、中央统战部、国家发展改革委、中国科学院、中国工程院等十余个部委
- **承办单位**：各省（区、市）教育厅（教委）及高校
- **大赛官网**：https://cy.ncss.cn/
- **官方微信公众号**：全国大学生创业服务网

---

## 二、赛道与组别设置

2025年大赛共设置**四个主赛道**及**萌芽赛道**。

### 2.1 高教主赛道

| **组别** | **细分方向** | **参赛对象** |
| :--- | :--- | :--- |
| **本科生组** | 创意组、创业组 | 在校本科生 |
| **研究生组** | 创意组、创业组 | 在校研究生（硕士、博士） |

**参赛类别**：
- 新工科类、新医科类、新农科类、新文科类
- 人工智能+、低空经济、生物技术、量子科技、新能源、新材料

### 2.2 青年红色筑梦之旅赛道

| **组别** | **参赛对象** |
| :--- | :--- |
| **公益组** | 在校生或毕业5年内毕业生 |
| **创意组** | 在校生 |
| **创业组** | 在校生或毕业5年内毕业生 |

**参赛类别**：
- 现代农业、制造业、信息技术服务、文化创意服务、社会服务

### 2.3 职教赛道

| **组别** | **参赛对象** |
| :--- | :--- |
| **创意组** | 职业院校（含高职高专、中职中专）在校生 |
| **创业组** | 职业院校在校生或毕业5年内毕业生 |

**参赛类别**：
- 创新类、商业类、工匠类

### 2.4 产业赛道

由行业企业出题，聚焦产业发展需求，参赛团队根据企业命题提出解决方案。赛道设金奖70个、银奖140个、铜奖440个。

### 2.5 萌芽赛道

面向普通高中学生，设置创新潜力奖20个。

## 三、参赛资格与组队规范

### 3.1 参赛对象

| **赛道** | **适用对象** |
| :--- | :--- |
| **高教主赛道** | 普通高等学校在校生（本专科、研究生）及毕业5年内毕业生 |
| **青年红色筑梦之旅** | 普通高等学校在校生（本专科、研究生）及毕业5年内毕业生 |
| **职教赛道** | 职业院校（含高职高专、中职中专）在校生及毕业5年内毕业生 |
| **产业赛道** | 普通高等学校在校生（本专科、研究生）及毕业5年内毕业生 |
| **萌芽赛道** | 普通高中在校学生 |

### 3.2 组队技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **队员人数** | 3-15人/队 |
| **指导教师** | ≤5人/队（金奖项目指导教师可获“优秀创新创业导师”证书） |
| **跨校组队** | 允许跨校组建团队 |
| **跨专业组队** | 鼓励跨专业、跨学科组队 |
| **每人限报** | 每位学生只能参加一个项目的申报 |

## 四、作品技术规范

### 4.1 作品形式要求

| **材料类型** | **内容要求** |
| :--- | :--- |
| **商业计划书** | PDF格式，完整阐述项目背景、产品/服务、市场分析、商业模式、团队构成、财务预测等 |
| **项目展示PPT** | 路演演示文稿，图文并茂，重点突出 |
| **1分钟视频** | 展示项目亮点、核心产品或服务 |
| **支撑材料** | 专利证书、合作协议、市场数据、用户反馈等 |

### 4.2 原创性与知识产权

| **要求项** | **技术规格** |
| :--- | :--- |
| **原创性** | 参赛项目须真实、健康、合法，无任何不良信息；项目立意应弘扬正能量，践行社会主义核心价值观 |
| **知识产权** | 参赛项目不得侵犯他人知识产权；所涉及的发明创造、专利技术、资源等必须拥有清晰合法的知识产权或物权 |
| **抄袭处理** | 抄袭、盗用、提供虚假材料或违反相关法律法规者，一经发现即刻丧失参赛相关权利并自负一切法律责任 |
