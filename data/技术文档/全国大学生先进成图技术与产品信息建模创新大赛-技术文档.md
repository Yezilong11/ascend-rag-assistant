# 全国大学生先进成图技术与产品信息建模创新大赛 参赛技术指南

## 一、赛事概述

**全国大学生先进成图技术与产品信息建模创新大赛**（简称“成图大赛”）是由原教育部高等学校工程图学课程教学指导委员会、中国图学学会制图技术专业委员会和中国图学学会产品信息建模专业委员会联合主办的图学类课程最高级别的国家级赛事。2018年被中国高等教育学会列入全国普通高校学科竞赛排行榜。

- **主办单位**：中国图学学会制图技术专业委员会、中国图学学会产品信息建模专业委员会
- **大赛官网**：http://www.chengtudasai.com/
- **办赛宗旨**：培养学生的工匠精神，激发学生的创新意识，探索图学的发展方向，创新成图载体的方法与手段
- **办赛目标**：以赛促教，以赛促学，以赛促改，全面提高大学生的图学能力

## 五、作品技术规范

### 5.1 竞赛内容

| **类别** | **考核内容** |
| :--- | :--- |
| **产品信息建模** | 根据给定的产品图纸或设计要求，完成三维数字建模 |
| **图学基础知识** | 工程图学相关理论知识 |
| **轻量化设计** | 面向增材制造的结构优化设计 |

### 5.2 软件平台

大赛使用的软件平台包括但不限于：
- 中望CAD
- 浩辰CAD
- 卡伦特在线系统
- Altair Inspire（轻量化设计）
- 其他主流CAD/BIM软件

### 5.3 提交材料

| **材料类型** | **内容要求** |
| :--- | :--- |
| **建模文件** | 按赛题要求生成的3D模型文件 |
| **工程图** | 符合国家标准的二维工程图 |
| **轻量化设计报告** | 轻量化赛道需提交设计说明、优化过程、结果分析 |

## 六、评审技术指标

### 6.1 评审维度

| **维度** | **考察要点** |
| :--- | :--- |
| **建模准确性** | 模型与给定图纸/要求的符合度 |
| **制图规范性** | 工程图是否符合国家标准 |
| **创新性** | 设计思路、结构优化的独创性 |
| **技术难度** | 建模复杂度、优化深度 |
| **完成度** | 作品的完整性、细节处理 |

### 6.2 轻量化设计专项评审

| **维度** | **考察要点** |
| :--- | :--- |
| **减重效果** | 优化前后的质量对比 |
| **结构合理性** | 优化后结构是否满足强度要求 |
| **可制造性** | 是否适合增材制造 |
| **AI应用** | AI工具辅助设计的创新性 |
