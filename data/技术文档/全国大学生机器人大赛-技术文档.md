# 全国大学生机器人大赛（RoboMaster机甲大师赛）参赛技术指南

## 一、赛事概述

**RoboMaster机甲大师赛**是由大疆创办的全国大学生机器人大赛旗下核心赛事，也是全球最具影响力的机器人竞技平台之一。比赛要求参赛队综合运用机械设计、计算机视觉、嵌入式系统、自动化控制、人工智能等技术，自主研发不同功能的机器人，在复杂的战场环境中进行战术对抗。

- **主办单位**：全国大学生机器人大赛组委会
- **创办单位**：大疆（DJI）
- **官方网站**：https://www.robomaster.com/
- **官方论坛**：https://bbs.robomaster.com/
- **官方邮箱**：robomaster@dji.com
- **联系电话**：+86 (0)755 84357613

## 二、赛事体系构成

RoboMaster 2026 机甲大师高校系列赛包含以下三个主要赛道：

| **赛道** | **技术定位** | **参赛对象** | **核心特点** |
| :--- | :--- | :--- | :--- |
| **超级对抗赛** | 全尺寸机器人竞技对抗 | 全球高校 | 5v5战术对抗，工程/步兵/英雄/哨兵/无人机等多兵种协同 |
| **高校联盟赛** | 3v3战术对抗 | 高校团队 | 规则简化，降低参赛门槛，侧重基础技术验证 |
| **人工智能挑战赛** | 全自动机器人对抗 | 高校团队 | 机器人自主决策，无人工干预，入选ICRA国际会议 |

## 三、超级对抗赛技术规范

### 3.1 参赛资格

| **项目** | **技术规格** |
| :--- | :--- |
| **组队人数** | 每所学校可注册1支队伍，人数不限 |
| **参赛身份** | 2026年7月前在读的本科生、研究生、专科生 |
| **指导教师** | 需有指导教师，具体人数不限 |
| **跨校组队** | 不允许跨校组队 |

### 3.2 机器人兵种与数量

| **兵种** | **数量上限** | **操作方式** | **核心功能** |
| :--- | :--- | :--- | :--- |
| **英雄机器人** | 2台 | 第一人称视角操控 | 高伤害输出，可登岛取弹 |
| **步兵机器人** | 4台 | 第一人称视角操控 | 机动灵活，可激活能量机关 |
| **工程机器人** | 1台 | 第一人称视角操控 | 救援、取弹、回血，不可攻击 |
| **哨兵机器人** | 1台 | 全自动运行 | 基地防御，自动索敌射击 |
| **空中机器人** | 1台 | 第一人称视角操控 | 空中侦察与打击 |

### 3.3 机器人技术要求

| **技术领域** | **核心要求** |
| :--- | :--- |
| **机械结构** | 自主研发底盘、云台、发射机构、悬挂系统等 |
| **嵌入式系统** | 基于STM32等MCU的电机控制、传感器数据采集 |
| **计算机视觉** | 能量机关识别、装甲板识别、自动瞄准 |
| **自主决策** | 哨兵机器人全自动运行，空中机器人自主导航（可选） |
| **通信系统** | 机器人间通信、与操作手间的数据传输 |

### 3.4 赛事指定产品

RoboMaster赛事提供一系列官方指定产品供参赛队使用，包括：
- **电机**：M2006、M3508、GM6020等无刷直流电机
- **电调**：C620、C610等配套电子调速器
- **开发板**：A型/B型开发板，基于STM32F427微控制器
- **裁判系统**：装甲模块、测速模块、图传模块等

*详细产品规格见官方资料中心：https://bbs.robomaster.com/wiki/20204847/804051*

## 七、评审与技术评估

### 7.1 机器人检录

所有参赛机器人需通过**裁判系统检录**，确保符合技术规范。检录内容包括：

| **检查项** | **技术要求** |
| :--- | :--- |
| **尺寸限制** | 各兵种有明确的尺寸上限（启动状态/静止状态） |
| **重量限制** | 各兵种有明确的重量上限 |
| **发射机构** | 弹丸初速、射速符合安全规范 |
| **电源系统** | 电压、电流在安全范围内 |
| **裁判系统完整性** | 装甲模块、测速模块等安装正确 |

### 7.2 技术报告评审

部分赛道要求提交技术报告，评审维度包括：

| **维度** | **考察要点** |
| :--- | :--- |
| **机械设计** | 结构合理性、创新性、可靠性 |
| **嵌入式系统** | 控制算法、传感器融合、稳定性 |
| **视觉算法** | 目标识别、自动瞄准、能量机关破解 |
| **系统集成** | 软硬件协同、调试流程、故障处理 |

## 十一、参赛注意事项

### 11.1 安全要求

- 所有机器人必须通过**安全检录**才能上场
- 发射机构初速不得超过规定上限
- 电源系统需有可靠的短路保护
- 机器人运动部分需有防护措施

### 11.2 诚信要求

- 严禁使用非自主研发的核心部件
- 严禁恶意干扰对手通信系统
- 严格遵守裁判系统规则
- 如有违规行为，将按《违规处罚条例》处理

### 11.3 知识产权

参赛队拥有自主研发技术的知识产权，但需遵守赛事开源分享的精神，在论坛等平台积极交流技术成果。
