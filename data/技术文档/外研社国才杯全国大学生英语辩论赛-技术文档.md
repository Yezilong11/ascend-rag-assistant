# “外研社·国才杯”全国大学生英语辩论赛 参赛技术指南

## 一、赛事概述

**“外研社·国才杯”全国大学生英语辩论赛**（原“外研社杯”全国大学生英语辩论赛）创立于1997年，由北京外国语大学主办，外语教学与研究出版社、北京外国语大学中国外语测评中心、北京外研在线数字科技有限公司承办。大赛秉持“以辩促学、以论育人”的宗旨，已发展成为一项高规格、大规模的权威赛事活动，连续多年被纳入教育部中国高等教育学会发布的《全国普通高校大学生竞赛分析报告》竞赛目录[citation:1][citation:4][citation:5]。

- **主办单位**：北京外国语大学[citation:6]
- **承办单位**：外语教学与研究出版社、北京外国语大学中国外语测评中心、北京外研在线数字科技有限公司[citation:6]
- **大赛官网**：http://uchallenge.unipus.cn/
- **官方微信公众号**：思辩精英平台[citation:7]

## 二、竞赛形式与赛制

### 2.1 赛制概述

大赛采用国际最高水平的**英国议会制辩论**（British Parliamentary Style，简称BP赛制），这是目前全球英语辩论公认的最高竞技形式[citation:2][citation:8]。

### 2.2 英国议会制辩论技术规范

| **项目** | **技术规格** |
| :--- | :--- |
| **参赛队伍** | 每轮比赛4支队伍同场竞技，每队2名选手[citation:4][citation:6] |
| **队伍构成** | 正方一队（上院）、反方一队（上院）、正方二队（下院）、反方二队（下院）[citation:4][citation:6] |
| **辩位设置** | 8个固定辩位，发言顺序依次为：首相（PM）→反对党领袖（LO）→副首相（DPM）→反对党副领袖（DLO）→正方成员（MG）→反方成员（MO）→正方党鞭（GW）→反方党鞭（OW）[citation:6][citation:10] |
| **发言时长** | 每位辩手发言时间为**7分钟**[citation:1][citation:4][citation:6] |
| **质询规则** | 发言的第2至第6分钟，对方选手可举手提出质询（Point of Information，POI）；第1分钟和最后1分钟为保护时间，不允许质询[citation:1][citation:6] |
| **准备时间** | 辩题公布后，辩手有**15分钟**准备时间[citation:6][citation:10] |
| **资料使用** | 准备期间可从纸媒资料中获取信息，预先准备的纸媒资料可在辩论中使用[citation:10] |

## 五、校赛选拔形式参考

各高校校赛选拔形式略有差异，主要形式如下：

### 5.1 视频海选+线下辩论（厦门大学）

| **阶段** | **形式** | **内容要求** |
| :--- | :--- | :--- |
| **第一阶段** | 提交视频 | 约3分钟英文脱稿演讲视频，两名选手根据相反立场先后陈述[citation:2] |
| **第二阶段** | 线下淘汰赛 | 抽签决定对手、正反方及上下院角色，进行BP制辩论[citation:2] |

### 5.2 纯线下辩论（安庆师范大学、重庆大学）

| **阶段** | **形式** | **内容要求** |
| :--- | :--- | :--- |
| **初赛** | 线上/线下淘汰赛 | BP制辩论，决出晋级队伍[citation:1][citation:8] |
| **复赛/决赛** | 线下循环赛/淘汰赛 | 多轮BP制辩论，最终决出冠亚季军[citation:8] |

| :--- | :--- | :--- |

## 十、参赛注意事项

### 10.1 信息核对

- 务必核对报名信息、队员姓名，获奖证书按最终确认信息制作
- 报名截止后，参赛团队及指导老师信息均不得变更[citation:7]

### 10.2 时间节点

- 各高校校内报名截止时间集中在**3月上中旬**，请及时关注本校通知
- 报名后务必加入官方QQ群，所有后续通知均通过QQ群发布[citation:1][citation:4]

### 10.3 比赛纪律

| **纪律项** | **技术规格** |
| :--- | :--- |
| **签到要求** | 须按规定时间到场签到、抽签[citation:8] |
| **弃赛处理** | 未按规定时间到场或临场弃赛，取消比赛资格[citation:8] |
| **全程参与** | 需完成签到、抽签、比赛、观赛、评委点评、颁奖合影等全部环节，方视为成功完成比赛[citation:8] |

### 10.4 赛前培训

多数高校会组织赛前培训，内容包括：
- BP赛制规则讲解
- 辩论技巧指导
- 模拟辩论演练[citation:3][citation:7]
