# 全国周培源大学生力学竞赛 参赛技术指南

## 一、赛事概述

**全国周培源大学生力学竞赛**受教育部高等教育司委托，由教育部高等学校力学教学指导委员会力学基础课程教学指导委员会、中国力学学会和周培源基金会共同主办。竞赛自1988年首届举办以来，每两年举办一届，已成功举办十五届，是全国高校力学领域规模最大、影响最广的学科竞赛之一。竞赛旨在增进青年学生学习力学的兴趣，培养分析、解决实际问题的能力，发现力学创新人才，为青年学子提供一个展示基础知识和思维能力的舞台。

- **指导单位**：教育部高等教育司
- **主办单位**：中国力学学会、周培源基金会
- **承办单位**：第十五届基础力学实验团体赛由东南大学承办，理论设计与操作团体赛由国防科技大学承办
- **竞赛官网**：http://zpy.cstam.org.cn/

---

## 二、竞赛形式与组别设置

### 2.1 个人赛

个人赛面向全国高校本科生及研究生，采用闭卷笔试方式，内容包括理论力学和材料力学两门课程的理论和实验，着重考核灵活运用基础知识、分析和解决问题的能力。

### 2.2 团体赛

团体赛分为“基础力学实验”和“理论设计与操作”两部分，从个人赛成绩优秀者中选拔组队。

| **团体赛类别** | **承办单位** | **核心内容** |
| :--- | :--- | :--- |
| **基础力学实验团体赛** | 东南大学 | 综合性实验设计与操作 |
| **理论设计与操作团体赛** | 国防科技大学 | 理论分析、方案设计、动手操作 |

## 十、参赛注意事项

### 10.1 考试纪律

| **纪律项** | **技术规格** |
| :--- | :--- |
| **考试形式** | 闭卷笔试 |
| **允许携带** | 无编程功能的计算器 |
| **禁止携带** | 书籍、笔记、手机及其他电子设备 |

### 10.2 信息核对

- 报名信息由学校统一提交，务必核对姓名、学校、身份证号等信息
- 获奖证书按报名信息制作，信息错误不予更改

### 10.3 考试时间

全国统一考试时间为**2025年5月18日上午8:30-12:00**，迟到者不得入场。

### 10.4 考前准备

| **事项** | **要求** |
| :--- | :--- |
| **证件** | 身份证、学生证、准考证 |
| **文具** | 黑色签字笔、2B铅笔、橡皮、直尺 |
| **计算器** | 仅限无编程功能的科学计算器 |
