# 全国大学生物理实验竞赛 技术文档

## 一、赛事概述

**全国大学生物理实验竞赛**（Chinese Undergraduate Physics Experiment Competition，简称CUPET）是一项面向在校大学生的全国性高水平物理学科竞赛活动，旨在激发我国大学生对大学物理和物理实验课程的学习兴趣和学习潜能，在实践中培养学生的创新精神和实践能力，在竞争中提升学生的团队协作意识和综合素质，着力提高物理实验教学质量和高素质创新性人才培养质量[citation:1]。

本赛事已进入中国高等教育学会高校竞赛评估与管理体系研究工作组发布的“**全国普通高校普通竞赛排行榜**”，是目前全国唯一最大规模的大学生物理实验类学科竞赛，在国内具有较高知名度[citation:6]。

### 1.1 第十二届基本信息
- **举办时间**：2026年5月-12月[citation:4]
- **全国决赛承办单位**：**哈尔滨工业大学**[citation:4]
- **协办单位**：黑龙江省物理学会、《物理实验》杂志、高等教育出版社物理分社[citation:4]
- **大赛官网**：http://wlsycx.moocollege.com/

### 1.2 组织机构

## 二、竞赛赛道设置

第十二届全国大学生物理实验竞赛（创新）涵盖以下**三个类别**[citation:2][citation:4]：

| **类别** | **说明** |
| :--- | :--- |
| **命题类创新作品** | 参赛学生从竞赛组委会公布的命题类项目中选题，按要求提交作品 |
| **自选课题类创新作品** | 参赛学生从竞赛组委会公布的自选类项目中选题，按要求提交作品 |
| **大学生物理实验讲课比赛** | 参赛学生根据竞赛组委会公布的讲课比赛形式及要求，自选讲课内容，按要求提交讲课视频 |

### 2.1 命题类创新作品

命题类题目包括以下方向[citation:8]：

| **题号** | **题目名称** |
| :--- | :--- |
| 题目1 | 冰与金属的摩擦系数测量 |
| 题目2 | 磁探伤 |
| 题目3 | 菲涅耳波带片 |
| 题目4 | 微弱电信号测量 |
| 题目5 | 大学物理教学微视频 |
| 题目6 | AI+物理实验 |

**命题类第5题（微视频）和第6题（AI+物理实验）** 为特色赛道，每校每项最多报1支队伍[citation:4]。

### 2.2 自选课题类创新作品

自选类题目包括以下方向[citation:8]：

| **题号** | **题目名称** |
| :--- | :--- |
| 自选题1 | 自制仪器和改进 |
| 自选题2 | 教学资源和虚仿 |
| 自选题3 | 前沿物理 |

### 2.3 大学生物理实验讲课比赛

讲课比赛要求参赛学生自选大学物理实验教学内容，按照正式讲课的形式进行录制，提交讲课视频和课程教案[citation:9]。该类别设有**校企合作通道**，具体参赛规则详见组委会通知[citation:4]。

## 三、参赛资格与组队要求

### 3.1 参赛对象
参赛对象为全国各类高等学校**2026年秋季学期在籍本（专）科学生**[citation:4]。

### 3.2 组队规模

| **类别** | **队员人数限制** | **指导教师限制** |
| :--- | :--- | :--- |
| **命题类创新作品** | 最多5人[citation:4] | 不多于2人[citation:4] |
| **自选课题类创新作品** | 最多5人[citation:4] | 不多于2人[citation:4] |
| **大学生物理实验讲课比赛** | **最多3人**[citation:4] | 不多于2人[citation:4] |

### 3.3 参赛限制

1. **每人限报**：每名学生只能参加1支队伍，不可兼报[citation:4]
2. **获奖限制**：本年度以前获得过全国大学生物理实验竞赛（创新）**二等奖（含）以上**的学生、其他国家级竞赛二等奖（含）以上作品不得再参加本竞赛[citation:4]
3. **再次参赛**：其他作品可以再次参赛，报名时须选上“再次参赛”选项并说明上次参赛年份和获奖等级，提交原来的参赛文档（须删除参赛队伍相关信息），并在新参赛文档中明确说明主要改进和提升内容[citation:4]
4. **讲课比赛限制**：对于上一年度获得过讲课比赛一等奖的作品，所在学校在随后的**2年内不得再报相同的实验题目参赛**[citation:4]

### 3.4 国际赛道

为开拓学生国际视野、提高国际交流能力，2026年设置**国际赛道**[citation:4]。

**参赛条件**（满足如下条件之一）[citation:4]：
1. 具有国外普通高等院校学籍的在校生，包括国内和国外双学籍学生
2. 国内普通高校学籍但具有外国国籍的学生

**参赛语言**：英语或中文（所提交作品及决赛答辩环节所用语言为英语或中文）[citation:4]

**参赛组别**：与国内参赛队伍统一管理，单独分组，**单设获奖指标**[citation:4]

## 七、评审规则

### 7.1 评审原则
专家本着“**公平、公正、科学、规范**”的原则，通过评阅项目资料和实验视频资料，对每件作品进行评分[citation:4]。

### 7.2 评审流程

| **阶段** | **评审方式** |
| :--- | :--- |
| **网络初评** | 组委会从各高校遴选评审专家，对各个项目进行网络初评[citation:4] |
| **决赛评审** | 进入决赛的作品，采取**现场答辩**的形式进行评比和展示[citation:4] |

### 7.3 评审标准参考
参赛作品应力求做到[citation:8]：
- 原理明确
- 装置简便且易于操作
- 方法巧妙且手段新颖有特色
- 现场操作规范
- 测量结果准确

| :--- | :--- |
| **一等奖** | 10%[citation:4] |
| **二等奖** | 20%[citation:4] |

国际赛道单独分组，**单设获奖指标**[citation:4]。

- 二等奖：20%
- 三等奖：30%

获国奖的作品将由竞赛指导组择优协助进行成果转化，如组织国赛一、二等奖作品展示，并将优秀作品收编成册，推荐高教社出版等[citation:6]。

## 十一、参赛注意事项

### 11.1 时间节点
- **密切关注**：各高校校内截止时间通常早于国赛截止时间，请及时关注校内通知
- **暑假安排**：部分高校要求参赛学生**暑假全程留校备赛**[citation:1]
- **作品提交**：9月1日-15日为正式提交作品时间，切勿错过[citation:4]

### 11.2 材料准备
- 严格按照命题要求准备研究报告、PPT和视频
- 再次参赛作品须删除原参赛队伍信息
- 视频录制注意画质清晰、声音清楚

### 11.3 查重与学术规范
- 所有参赛作品须通过查重检测
- 严禁抄袭、盗用他人成果
- 违反学术规范将取消参赛资格

### 11.4 人员变更
- 报名结束后原则上不接受更改队员和指导教师
- 获奖证书将严格按照组队顺序制作，请队长确认指导老师和队员顺序及名称准确
