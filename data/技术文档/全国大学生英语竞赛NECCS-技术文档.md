# 全国大学生英语竞赛（NECCS）参赛技术指南

## 一、赛事概述

**全国大学生英语竞赛**（National English Competition for College Students，简称NECCS）是经教育部批准举办的全国唯一的大学生英语综合能力竞赛活动，由国际英语外语教师协会中国英语外语教师协会和高等学校大学外语教学研究会联合主办[citation:4][citation:9]。本届竞赛为第二十八届[citation:6][citation:10]。

- **主办单位**：国际英语外语教师协会中国英语外语教师协会、高等学校大学外语教学研究会[citation:4][citation:9]
- **官方网站**：http://www.chinaneccs.cn/ [citation:1][citation:6]
- **报名平台**：https://www.saikr.com/neccs/2026 [citation:3][citation:6][citation:7]

## 二、竞赛类别与分组

竞赛分A、B、C、D四个类别，**跨类别报名无效**[citation:6]。

| **类别** | **适用对象** | **命题依据** |
| :--- | :--- | :--- |
| **A类** | 研究生 | 《非英语专业学位研究生英语教学大纲》[citation:1][citation:4][citation:10] |
| **B类** | 英语专业本、专科学生 | 《高等学校英语专业英语教学大纲》[citation:1][citation:4][citation:10] |
| **C类** | 非英语专业本科生 | 《大学英语教学指南（2020年版）》[citation:1][citation:4][citation:10] |
| **D类** | 体育/艺术类本科生、非英语专业高职高专学生 | 《高等职业教育专科英语课程标准（2021年版）》[citation:1][citation:4][citation:10] |

## 三、竞赛时间与形式

### 3.1 关键时间节点

| **阶段** | **时间** | **形式** |
| :--- | :--- | :--- |
| **初赛** | 2026年4月12日（星期日）9:00-11:00 | 笔试（含听力），全国统一命题，在各高校校内举行[citation:1][citation:3][citation:5] |
| **决赛** | 2026年5月10日（星期日）9:00-11:00 | 笔试（含听力），各省统一组织[citation:1][citation:3][citation:5] |
| **全国总决赛** | 2026年8月初 | 演讲、辩论、风采大赛等活动[citation:8][citation:10] |

### 3.2 考试形式
- **初赛**：笔答+听力（听力采取播放录音形式）[citation:4][citation:6]
- **决赛**：笔试（含听力）+ 口试（口试满分50分）[citation:3][citation:4][citation:7]

## 四、试卷结构与技术规格

### 4.1 试卷满分与题型分布

| **项目** | **分值** | **题型构成** |
| :--- | :--- | :--- |
| **初/决赛笔试满分** | 150分 | 建构反应题型（主观题）90分 + 选择反应题型（客观题）60分[citation:1][citation:2][citation:3] |
| **听力部分** | 30分（部分院校为35分） | 包含在笔试总分内[citation:2][citation:3][citation:4] |
| **决赛口试** | 50分 | 附加环节[citation:3][citation:4][citation:7] |

### 4.2 笔试七大题型

试卷主要由以下七大部分组成[citation:1]：
1. 听力理解
2. 词汇和语法
3. 完形填空
4. 阅读理解
5. 翻译
6. 改错
7. 写作

### 4.3 命题特点
- **考查能力**：英语基础知识和基本技能 + 英语综合运用能力、阅读能力、智力水平[citation:1][citation:2][citation:4]
- **题型创新**：借鉴国内外英语测试新题型，保持稳定性基础上有所创新[citation:1][citation:2][citation:4]

## 六、报名技术规范

### 6.1 报名方式
各高校报名方式分为以下两种，请以本校通知为准：

| **报名方式** | **操作说明** | **适用高校示例** |
| :--- | :--- | :--- |
| **赛氪网统一报名** | 登录 https://www.saikr.com/neccs/2026 → 选择赛区入口 → 选择本校入口 → 注册/登录 → 填写信息 → 缴费[citation:3][citation:6][citation:7] | 河南科技学院[citation:3]、华南理工大学[citation:6]、中南财经政法大学[citation:7]、哈尔滨师范大学[citation:8] |
| **校内集中报名** | 填写报名表→发送至指定邮箱→统一缴费[citation:1][citation:2][citation:4] | 南通大学[citation:1]、西北师范大学[citation:2]、哈尔滨学院[citation:4]、东北电力大学[citation:5]、山东师范大学[citation:10] |

### 6.2 报名时间
- **全国截止时间**：2026年3月13日（各校略有差异）[citation:3][citation:5][citation:6]
- **部分高校截止时间**：3月6日-3月13日不等，请以本校通知为准[citation:2][citation:4]

### 6.3 报名费用
- **标准费用**：50元/人（绝大多数院校）[citation:1][citation:2][citation:3]
- **特殊标准**：20元/人（成都大学）[citation:9]
- **退费说明**：报名成功后原则上不予退还[citation:6][citation:8]

### 6.4 准考证获取
- **打印时间**：4月5日后（部分院校）[citation:6]
- **打印方式**：登录报名平台自行打印[citation:6][citation:8]

## 七、考试技术规范

### 7.1 考生准备
| **物品** | **要求** |
| :--- | :--- |
| **证件** | 准考证、身份证、学生证 |
| **文具** | 黑色签字笔、2B铅笔、橡皮[citation:6] |
| **听力设备** | 多数院校采用外放听力，无需携带收音机，具体以准考证为准[citation:6] |
| **到场时间** | 提前30分钟到达考场[citation:6] |

### 7.2 考场规则
- 跨校报名、跨类别报名成绩无效[citation:6]
- 考试当天迟到者不得入场
