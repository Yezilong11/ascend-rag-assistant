# 全国大学生电子设计竞赛 参赛技术指南

## 一、赛事概述

**全国大学生电子设计竞赛**（National Undergraduate Electronics Design Contest，简称NUEDC）是教育部高等教育司、工业和信息化部人事教育司共同发起的大学生学科竞赛之一，是目前中国规模最大、参赛范围最广、极具影响力的电子信息类学科竞赛[citation:9]。竞赛始于1994年，每逢单数年的8月份举办全国性竞赛，双数年则组织专题邀请赛[citation:3][citation:4]。

- **主办单位**：教育部高等教育司、工业和信息化部人事教育司
- **组织模式**：“政府主办、专家主导、学生主体、社会参与”十六字方针[citation:3]
- **赞助企业**：德州仪器（TI）为2018年至2027年竞赛唯一赞助商[citation:2]
- **竞赛官网**：http://nuedc.xjtu.edu.cn/
- **培训网**：https://www.nuedc-training.com.cn/

### 1.1 2025年竞赛规模
2025年竞赛共有全国1161所高校、22586支队伍、67758名学生参赛，评选出全国一等奖404项、全国二等奖1150项[citation:9]。

## 四、竞赛题目与技术要求

### 4.1 命题原则

竞赛题目着重考核学生综合运用基础知识进行理论设计的能力、实践创新和独立工作的基本能力、实验综合技能（制作与调试），同时鼓励团队协作精神[citation:2]。

### 4.2 题目类型（参考历届）

| **类型** | **示例题目** |
| :--- | :--- |
| **电源类** | 简易数控直流电源、直流稳压电源、各类升降压变换电源[citation:7] |
| **信号源类** | 实用信号源、波形发生器、电压控制LC振荡器[citation:7] |
| **高频无线电类** | 简易无线电遥控系统、调幅广播收音机、调频收音机[citation:7] |
| **放大器类** | 实用低频功率放大器、宽带放大器[citation:7] |
| **仪器仪表类** | 简易数字频率计、频率特性测试仪、数字式工频有效值多用表[citation:7] |
| **数据采集与处理类** | 多路数据采集系统、数据采集与传输系统[citation:7] |
| **控制类** | 自动往返电动小汽车、倒立摆控制系统、风摆控制系统、多旋翼无人机系统[citation:7] |

### 4.3 2026年专题赛主题

2026年信息科技前沿专题赛（瑞萨杯）主题为：**“瑞萨MCU助力新兴产业和未来产业”**。决赛以单片瑞萨MCU-RA8P1为核心，制作指南限于[citation:1][citation:8]：
- 基于视觉、听觉、嗅觉、味觉和触觉的智能感知
- 面向低空经济的前沿科技
- “眼手力”机器人作业
- 简易AI超算装置

### 4.4 技术限制

除题目特殊要求外，参赛作品中不得包含个人计算机（PC机、平板电脑、笔记本电脑及通用键盘、鼠标等调试外设）、手机等。实际制作实物中凡需软件编程的芯片必须事先下载脱机工作封存在作品箱中[citation:2]。

## 五、作品与设计报告技术规范

### 5.1 设计报告格式要求

| **项目** | **技术规格** |
| :--- | :--- |
| **正文长度** | **≤8页**（A4纸）[citation:6] |
| **摘要** | 首页另附，≤300字[citation:6] |
| **正文格式** | 小四号宋体，行距固定值22磅，标题字号自定，纵向打印[citation:6] |
| **页眉要求** | 每页上方留出≥3cm空白，空白区域内不得有任何文字[citation:6] |
| **页码** | 每页右下端注明页码[citation:6] |

### 5.2 匿名评审要求

- 报告封面及每页纸上**不得出现参赛队的学校、代码、姓名等文字**，否则取消评审资格[citation:6]
- 密封方式：参赛队代码写在密封纸距上边约1cm居中处，掀起密封纸折向背面用胶水粘在背面[citation:6]

### 5.3 作品封存要求

竞赛结束时，各参赛队应将[citation:6]：
1. 设计报告
2. 制作实物
3. 《竞赛登记表》

全部封入本校自备纸箱内，纸箱封条由赛区组委会统一制备。密封后的纸箱内外不得出现任何校名、参赛队代号、参赛队员姓名及其它暗记。

## 六、竞赛纪律与学术诚信

### 6.1 竞赛期间纪律

| **纪律项** | **技术规格** |
| :--- | :--- |
| **独立完成** | 不得以任何方式与队外人员进行讨论交流，教师和其他非参赛队员必须迴避[citation:2] |
| **资料使用** | 可以使用图书资料和网络资源，但不得使用计算机网络资源交流[citation:5] |
| **巡视制度** | 各赛区设立网络在线监控，对竞赛场地全景实时监控[citation:2] |

### 6.2 违规处理

| **违规行为** | **处理措施** |
| :--- | :--- |
| 教师参与、他人代做 | 取消评奖资格[citation:2] |
| 抄袭及被抄袭 | 取消评奖资格[citation:2] |
| 队与队之间交流 | 取消评奖资格[citation:2] |
| 不按规定时间结束 | 取消评奖资格[citation:2] |

## 七、评审与奖项设置

### 7.1 “一次竞赛，两级评奖”机制

| **级别** | **评审方式** | **获奖比例** |
| :--- | :--- | :--- |
| **赛区奖** | 赛区专家组评审 | 一、二、三等奖总获奖比例≤赛区总参赛队数的40%，其中一等奖≤10%[citation:2] |
| **全国奖** | 全国专家组评审 | 全国一、二等奖总数≤全国实际参赛队总数的8%（一等奖:二等奖≈3:7）[citation:2] |

### 7.2 综合测评（2025年细则）

- **测试对象**：赛区推荐上报全国评奖的优秀参赛队全体队员[citation:5]
- **测试时间**：8月10日8:00～15:00（统一时间）[citation:5]
- **测试形式**：以队为单位在全封闭方式进行，题目与评分标准由全国专家组统一制定[citation:5]
- **满分**：30分，超过最低分数线的作品按实际得分计入全国评审总分[citation:5]
- **限制**：不能上网、不能使用手机、计算机[citation:5]

### 7.3 奖项设置

| **奖项** | **说明** |
| :--- | :--- |
| **全国一等奖** | 获奖队数不超过全国实际参赛队总数的8%中30%[citation:2] |
| **全国二等奖** | 获奖队数不超过全国实际参赛队总数的8%中70%[citation:2] |
| **TI杯** | 从全国一等奖中推选出[citation:2] |
| **赛区一、二、三等奖** | 由各赛区组委会颁发[citation:2] |
| **成功参赛奖** | 赛区可酌情颁发[citation:3] |

### 7.4 学校推荐名额限制

同一题目、同一所学校获得全国一、二等奖的总队数合计**不超过4个**，其中一等奖队数**不超过2个**[citation:2]。
