# 全国大学生光电设计竞赛 技术文档

## 一、赛事概述

**全国大学生光电设计竞赛**（National Photoelectric Design Competition for University Students）由中国光学学会主办，中国光学学会光学教育专业委员会代表主办机构、全国大学生光电设计竞赛委员会（以下简称“光电竞赛委”）具体负责[citation:1]。自2008年至今已成功举办十三届，赛事旨在为学生提供一个光、机、电、算一体化系统设计与开发的实训平台，促进光电知识的普及，加强大学生科学创新创业意识和团队协作精神，开阔大学生科学视野，提高大学生创新创业设计能力、工程实践能力和综合科技能力[citation:3]。

该赛事已**纳入全国普通高校学科竞赛排行榜**，是国内光电类级别最高、参赛队伍最多、影响最大的一项全国性学科竞赛[citation:3][citation:7]。

### 1.1 第十四届赛事基本信息
- **举办时间**：2026年6月下旬（具体时间另行通知）
- **举办地点**：吉林省长春市
- **承办单位**：长春理工大学[citation:1][citation:3]
- **官方网站**：http://gd.moocollege.com/ [citation:1]

### 1.2 组织机构
- **主办单位**：中国光学学会
- **指导单位**：中国光学学会光学教育专业委员会
- **负责机构**：全国大学生光电设计竞赛委员会
- **执行机构**：第十四届全国光电竞赛组织委员会（含光学设计赛道分委员会）[citation:8]

## 二、竞赛赛道与组别

第十四届全国大学生光电设计竞赛包含**两大赛道**：创意设计赛道和光学设计赛道[citation:1][citation:3]。

### 2.1 创意设计赛道

创意设计赛道是指围绕光电学科领域的创意、创新、创业开放性路演类竞赛类型，参赛队可按要求自行设立创意、创新、创业类开放性主题参赛[citation:9]。该赛道下设**两个组别**：

| **组别** | **说明** |
| :--- | :--- |
| **创意组** | 参赛项目具有较好的创意或较为成型的产品原型或服务模式[citation:9] |
| **初创组** | 参赛项目在2026年5月15日前已完成工商登记注册，且获机构或个人股权投资不超过1轮次，累计融资额不超过1000万人民币[citation:9] |

#### 2.1.1 选题方向
创意赛道鼓励将光电信息技术与以下领域深度融合[citation:9]：
- 移动互联网、云计算、大数据、人工智能、物联网等新一代信息技术
- 教育、医疗、交通、制造、金融、绿色能源、生态农业、消费生活等经济社会各领域

#### 2.1.2 作品形式
- 创意类项目（仅有创意）
- 初创类项目（已注册公司）[citation:6]

### 2.2 光学设计赛道（“宇瞳杯”）

光学设计赛道是围绕光学系统设计技术的竞技类竞赛类型，沿袭往届做法继续独立开展试点[citation:9]。

#### 2.2.1 第十四届赛题

第十四届光学设计赛道设以下两道赛题[citation:9]：

| **赛题** | **名称** | **内容说明** |
| :--- | :--- | :--- |
| **赛题1** | 微光夜视观察物镜设计 | 设计适用于微光夜视环境的观察物镜系统 |
| **赛题2** | AR眼镜拍摄镜头设计 | 设计增强现实（AR）眼镜的拍摄镜头系统 |

#### 2.2.2 第十三届赛题参考
第十三届光学设计赛道赛题[citation:7]：
- 水浸物镜设计：设计高分辨率、高数值孔径液浸显微物镜
- 微单镜头设计：在限定尺寸和成本条件下完成高性能、小型化相机镜头的光学与结构设计

## 三、参赛资格与组队要求

### 3.1 参赛对象
- **创意组**：2026年暑期前在校的具有正式学籍的全日制**专科生、本科生、留学生及研究生**[citation:3][citation:9]
- **初创组**：除上述在校生外，**毕业5年以内**（2021年5月31日之后毕业）的全日制专科生、本科生、研究生也可参赛[citation:9]
- 当年毕业的学生可以以在校生身份参赛[citation:9]

### 3.2 组队规模与要求

#### 3.2.1 创意设计赛道
| **组别** | **队员人数** | **研究生限制** | **队长要求** |
| :--- | :--- | :--- | :--- |
| **创意组** | 不多于3人 | 研究生不多于1人 | 须为本科生或专科生[citation:9] |
| **初创组** | 不多于7人 | 研究生不多于2人 | 须为初创企业法人代表[citation:6][citation:9] |

#### 3.2.2 光学设计赛道
| **项目** | **要求** |
| :--- | :--- |
| **队员人数** | 每支参赛队由3名学生组成[citation:3][citation:9] |
| **研究生限制** | 研究生人数不能多于1名，且不能担任队长[citation:3][citation:9] |
| **指导教师** | 每支参赛队指导教师人数为1-2名[citation:3][citation:5] |

### 3.3 通用参赛规则
1. **每人限报**：每名学生在一个赛道只能参加一支参赛队[citation:3][citation:5]
2. **跨赛道参赛**：允许学生同时报名参加创意设计赛道和光学设计赛道[citation:1][citation:3]
3. **跨校组队**：鼓励跨学科、跨专业、跨校组队参赛，以参赛队队长所在高校报名[citation:5][citation:9]
4. **境外参赛**：鼓励各高校推荐境外友好合作高校参赛，队长为境外高校的按境外赛道进行推荐[citation:8][citation:9]
5. **原创要求**：参赛项目须为本团队策划或经营的项目，不可借用他人项目参赛；已获往届全国决赛奖励的项目不得再报名[citation:9]

## 四、赛制与赛程安排

### 4.1 赛制模式

#### 创意设计赛道
采用“**校赛晋级区赛、区赛晋级国赛制**”模式[citation:3]：
- **校赛**：学校通过选拔，推荐队伍参加赛区赛
- **区赛**：各赛区先举办区赛，2026年5月底前完成，再推荐获胜队参与国赛[citation:1][citation:8]
- **国赛**：全国总决赛，2026年6月下旬举行

#### 光学设计赛道
采用“**全国统一初赛、决赛**”两级赛制[citation:1][citation:8]

### 4.2 七大区划
全国共划分为七个赛区，各区所辖境内各省、区、市的划分如下[citation:8]：

| **赛区** | **所辖省份/地区** |
| :--- | :--- |
| **华北区** | 北京、天津、河北、山西、内蒙古 |
| **东北区** | 辽宁、吉林、黑龙江 |
| **西北区** | 陕西、宁夏、甘肃、青海、新疆 |
| **西南区** | 重庆、四川、云南、贵州、西藏 |
| **中部区** | 河南、湖北、湖南、江西、安徽 |
| **东南区** | 广东、广西、福建、海南 |
| **东部区** | 上海、山东、江苏、浙江 |
| **境外赛道** | 含中国台港澳地区和其他国外高校参赛队 |

| **阶段** | **时间节点** | **说明** |

## 五、竞赛内容与技术要求

### 5.1 创意设计赛道
#### 5.1.1 提交材料
| **材料名称** | **内容要求** |
| :--- | :--- |
| **项目计划书** | 详细阐述项目创意、技术方案、创新点、商业模式等[citation:6] |
| **介绍视频** | 3分钟以内，MP4格式，清晰展示项目核心内容[citation:3][citation:6] |
| **路演PPT** | 用于现场汇报展示[citation:6] |

#### 5.1.2 评审要素
- 创新性
- 技术可行性
- 商业模式与市场前景
- 团队能力
- 现场表现

### 5.2 光学设计赛道
#### 5.2.1 第十三届实物赛道赛题（参考）

第十三届实物赛道设置两道赛题，体现了光电技术的系统集成与精密检测两大方向[citation:4]：

| **赛题** | **名称** | **竞赛要点** |
| :--- | :--- | :--- |
| **赛题1** | 智能车的激光对抗 | 设计具有激光对抗功能的智能小车，实现行驶、识别、跟踪和激光打击[citation:2][citation:4] |
| **赛题2** | 大深径比微孔参数的光学无损测量 | 开发测量装置，测量直径小于0.3mm、深径比大于3的微孔的深径比[citation:2][citation:5] |

#### 5.2.2 赛题1：智能车的激光对抗技术要求
- **小车尺寸**：长宽高均在15cm到30cm之间
- **目标区**：侧面涂装高5cm的白色漫反射区作为激光照射的目标区
- **激光要求**：可见光，目视连续，符合激光安全标准GB7247，光斑直径不大于2cm
- **场地**：方形场地，中间设分界线，均布3颗地雷，小车不可触碰[citation:2]

#### 5.2.3 赛题2：大深径比微孔测量技术要求
- **测量对象**：直径小于0.3mm，深径比大于3的微孔
- **评分要素**：
  - 深径比测量精度
  - 可测量的最大深径比
  - 可测量的最小微孔直径[citation:2]

## 八、参赛注意事项

### 8.1 知识产权
- 参赛项目不得侵犯他人知识产权，所涉及的发明创造、专利技术、资源等必须拥有清晰合法的知识产权或物权[citation:2][citation:5]
- 凡抄袭、盗用、提供虚假材料或违反相关法律者，一经发现即刻取消参赛资格[citation:2]

### 8.2 人员变更
- 报名结束后不接受更改队员和指导教师[citation:5]
- 自报名至比赛期间，参赛队员不得随意更换[citation:9]

### 8.3 作品要求
- 鼓励跨学科交叉融合
- 鼓励使用开源硬件和软件
- 作品须为原创，具有创新性和实用性

### 8.4 查重机制
- 大赛设置查重环节，与往年作品高度相似将被取消资格
