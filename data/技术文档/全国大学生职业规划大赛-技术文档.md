# 全国大学生职业规划大赛 参赛技术指南

## 一、赛事概述

**全国大学生职业规划大赛**是由教育部主办、面向全国高校学生的一类学科竞赛。大赛旨在通过科学化的职业规划评审机制，引导大学生树立正确的成才观和就业观，提升职业规划能力与求职实战水平。

- **主办单位**：教育部、天津市人民政府
- **全国总决赛承办**：天津市教育委员会、南开大学、天津大学、天津师范大学
- **大赛官网**：https://zgs.chsi.com.cn/
- **大赛平台**：全国大学生职业规划大赛平台（简称“大赛平台”）

---

## 二、赛道设置与技术规范

第三届大赛设**三大主体赛事**，各赛道的技术参数如下：

| **赛道** | **面向对象** | **组别设置** | **核心考察点** |
| :--- | :--- | :--- | :--- |
| **成长赛道** | 本、专科非毕业年级 | 高教组、职教组 | 职业目标设定、成长行动规划、自我优化能力 |
| **就业赛道** | 高年级计划求职学生、研究生 | 高教本科生组、高教研究生组、职教组 | 岗位胜任力、求职实战能力、发展潜力 |
| **课程教学赛道** | 职业发展与就业指导课程教师 | 高教组、职教组 | 课程建设质量、教学创新、实施效果 |

## 三、成长赛道技术参数

### 3.1 参赛资格
普通高等学校全日制本、专科非毕业年级在校学生。

### 3.2 提交材料技术规格

| **材料名称** | **格式要求** | **容量限制** | **内容要点** |
| :--- | :--- | :--- | :--- |
| **生涯发展报告** | PDF | ≤2000字，图表≤5张 | 职业目标设定依据、成长行动记录、阶段性成果、自我评估与优化 |
| **生涯发展展示** | PPT（可嵌入视频） | ≤50MB | 可视化呈现发展路径、关键节点、成果佐证 |

### 3.3 比赛环节与时间分配

| **环节** | **时长** | **技术要求** |
| :--- | :--- | :--- |
| **主题陈述** | 7分钟 | 结合PPT展示，逻辑清晰，重点突出成长行动与目标匹配度 |
| **评委提问** | 5分钟 | 针对陈述内容即时回应，考察应变能力和自我认知深度 |
| **天降实习offer** | 2分钟 | 用人单位根据表现发放实习意向（可选环节） |

### 3.4 评审技术指标

| **指标** | **权重** | **技术性考察要点** |
| :--- | :--- | :--- |
| **职业目标** | 30% | 与国家战略、社会需求、个人特质的契合度；目标的SMART原则体现 |
| **学习实践行动** | 50% | 行动路径的系统性；成果的可量化、可验证性；专业能力提升的证据链 |
| **优化改进** | 20% | 基于反馈的自我调整机制；目标迭代的逻辑性和合理性 |

## 四、就业赛道技术参数

### 4.1 参赛资格
普通高等学校全日制本、专科高年级计划求职学生（不含已通过推免等确定升学的毕业年级学生）和研究生。

### 4.2 提交材料技术规格

| **材料名称** | **格式要求** | **容量限制** | **内容要点** |
| :--- | :--- | :--- | :--- |
| **求职简历** | PDF | 1页为宜 | 个人信息、教育背景、实习经历、项目成果、技能证书（数据真实、排版规范） |
| **求职综合展示** | PPT | ≤50MB | 岗位匹配度分析、核心竞争力展示、职业准备路径 |
| **辅助证明材料** | 单个PDF整合 | ≤50MB | 实习证明、获奖证书、项目文档、推荐信等（按时间或重要性排序） |

### 4.3 比赛环节与时间分配

| **环节** | **时长** | **技术要求** |
| :--- | :--- | :--- |
| **主题陈述** | 6分钟 | 聚焦求职意向，展示个人能力与目标岗位的匹配度 |
| **综合面试** | 6分钟 | 真实工作场景问题解决（案例分析/情景模拟）+ 自由提问 |
| **天降offer** | 2分钟 | 用人单位现场发放录用意向（可选环节） |

### 4.4 评审技术指标

| **指标** | **权重** | **技术性考察要点** |
| :--- | :--- | :--- |
| **职业目标** | 10% | 目标的行业匹配性、与个人能力的契合度 |
| **岗位胜任力** | 80% | 综合素质（沟通、协作、执行）+ 专业知识技能 + 实践成果的有效性 |
| **发展潜力** | 10% | 学习能力、适应性、职业成长空间 |

## 五、课程教学赛道技术参数

### 5.1 参赛资格
普通高等学校开设的**大学生职业发展与就业指导类课程**主讲教师（每校限报1门）。

### 5.2 提交材料技术规格

| **材料名称** | **格式要求** | **容量限制** | **内容要点** |
| :--- | :--- | :--- | :--- |
| **参赛申报表** | Word/PDF | 按模板填写 | 课程基本信息、教学团队、课程特色 |
| **课程支撑材料** | 单个PDF整合 | ≤30MB | 课程大纲、3个完整教案节段、近2年学生评教数据、教学成果证明 |

### 5.3 比赛环节与时间分配

| **环节** | **时长** | **技术要求** |
| :--- | :--- | :--- |
| **课程建设汇报** | 6分钟 | 课程定位、设计理念、教学实施、创新点、教学成效 |
| **教学展示** | 10分钟 | 提前提交5个教学节段，现场随机抽取1个进行无生授课 |
| **互动答辩** | 6分钟 | 回答评委关于课程建设、教学方法、学生反馈等方面提问 |

### 5.4 评审技术指标
- **课程定位**（与学校人才培养目标的契合度）
- **教学团队**（结构合理性、专业背景）
- **课程内容**（模块设计、案例更新、理论与实践结合）
- **教学改革**（方法创新、技术应用）
- **实施效果**（学生满意度、就业质量提升证据）

## 六、赛程与技术平台操作指南

### 6.1 三级赛制时间节点

| **阶段** | **时间安排** | **技术操作要求** |
| :--- | :--- | :--- |
| **平台开放** | 2025年10月20日 | 登录zgs.chsi.com.cn完成学信网账号注册/绑定 |
| **参赛报名** | 2025年10月—2026年1月 | 选择赛道、填写信息、上传材料（截止时间以校赛通知为准） |
| **校赛** | 2025年10月—2026年3月上旬 | 按学校要求提交材料、参加校级评审 |
| **省赛** | 2025年10月—2026年3月15日 | 省级赛事机构组织线上/线下评审 |
| **全国总决赛** | 2026年4月 | 现场比赛（地点：天津） |

### 6.2 平台功能说明
校赛期间，大赛平台开放以下辅助功能：
- **成长赛道**：生涯闯关系统（模拟职业规划路径）
- **就业赛道**：职业适配度测评（提供岗位匹配分析报告）
- 选手可根据需要选择使用，测评结果不作为强制提交材料

### 6.3 报名操作流程
1. **访问官网**：https://zgs.chsi.com.cn/
2. **登录/注册**：使用学信网账号（支付宝/微信扫码或账号密码）
3. **身份核验**：如学信档案未核验，需先完成身份验证
4. **填写信息**：准确填写个人基本信息、学籍信息
5. **选择赛道**：根据自身条件选择成长赛道或就业赛道（每人限报1个）
6. **上传材料**：按赛道要求上传PDF/PPT文件
7. **确认提交**：材料提交后可在报名截止前修改

## 七、材料制作技术规范

### 7.1 通用规范
- **文件命名**：赛道+学校+姓名+材料类型（例：成长赛道_南开大学_张三_生涯发展报告）
- **PDF生成**：使用Adobe Acrobat或WPS转换，确保字体嵌入、无水印
- **PPT制作**：使用16:9宽屏比例，确保投影清晰度，嵌入视频时测试播放兼容性

### 7.2 视频嵌入技术要求（PPT内）
- **视频格式**：MP4（H.264编码）
- **分辨率**：1280×720或1920×1080
- **时长**：单个视频片段不超过2分钟
- **嵌入方式**：使用“插入-视频-此设备”而非超链接，确保换机播放时正常

### 7.3 简历制作技术要点
- **版面**：1页为宜，左侧边栏个人信息/技能，右侧正文经历
- **数据量化**：使用数字呈现成果（如“组织活动5场，覆盖300人”）
- **格式**：PDF导出，避免Word排版错乱

### 7.4 生涯发展报告结构建议
1. **职业目标设定**（背景分析、个人特质匹配）
2. **成长行动路径**（时间轴、关键节点、行动措施）
3. **阶段性成果**（证书、项目、能力提升证据）
4. **反思与优化**（遇到的挑战、调整策略、下一步计划）

### 7.5 辅助材料整合规范
- 使用PDF合并工具将多个文件整合为1个
- 按重要性排序：实习证明→获奖证书→项目成果→推荐信
- 添加目录页（可选）

## 八、评审规则与技术要点

### 8.1 评审流程

| **阶段** | **评审方式** | **技术要点** |
| :--- | :--- | :--- |
| **校赛** | 材料评审+现场答辩 | 各高校自主确定晋级比例 |
| **省赛** | 材料评审+现场/线上答辩 | 按省份统一组织，择优晋级国赛 |
| **全国总决赛** | 现场答辩+评委合议 | 各组别晋级选手现场竞技 |

### 8.2 材料评审技术指标
- **真实性**：证明材料是否可验证、数据是否合理
- **规范性**：格式是否符合要求、排版是否清晰
- **逻辑性**：目标-行动-成果之间的因果链条是否完整
- **创新性**：规划思路是否有独特视角、解决方案是否有新意

### 8.3 答辩评审技术要点
- **表达清晰度**：语言流畅、重点突出、时间把控精准
- **应变能力**：针对提问的回答是否切题、有深度
- **形象展示**：着装得体、肢体语言自然、PPT辅助有效

### 8.4 违规处理
- **信息造假**：一经核实取消参赛资格
- **代笔抄袭**：发现学术不端行为，通报所在学校
- **超时扣分**：陈述环节超时将酌情扣分
