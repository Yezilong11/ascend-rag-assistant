# WUPENiCity 城市可持续调研报告国际竞赛 参赛技术指南

## 一、赛事概述

**WUPENiCity城市可持续调研报告国际竞赛**是由世界规划教育组织（WUPEN）主办的国际性学科竞赛，鼓励学生针对城市可持续发展议题，通过科学调查与研究方法，提出创新性的分析与见解。

- **主办单位**：世界规划教育组织（WUPEN）、联合国教科文组织iCity网站
- **竞赛平台**：https://wupen.org/
- **竞赛主题**：通常围绕城市可持续发展、智慧城市、低碳交通、社区更新、公共空间等议题

## 二、报告技术要求

### 2.1 报告内容要求

| **项目** | **技术规格** |
| :--- | :--- |
| **研究对象** | 城市中的特定空间、人群、现象或问题 |
| **调研方法** | 鼓励使用访谈、问卷、实地勘察、案例分析、数据分析等多种调查研究方法 |
| **分析深度** | 需包含问题识别、数据呈现、原因分析、对策建议等完整逻辑链条 |
| **成果形式** | 图文并茂的调研报告 |

### 2.2 报告格式技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **页数限制** | 正文不超过10页 |
| **版面方向** | 横向版式 |
| **宽高比例** | 16:9 |
| **底板颜色** | 白色底板 |
| **文件格式** | PDF |
| **分辨率** | 300dpi |
| **文件大小** | 建议不超过50MB（参考平台通用限制） |

### 2.3 匿名评审要求

参赛作品中**不得包含透露参赛者及其所在学校的内容和提示**（如姓名、学校标识、指导教师信息等），否则将直接取消参赛资格 [citation:1][citation:2]。

- **视频文件**：参赛码-视频.mp4

## 五、报名与提交流程

### 5.1 报名流程

| **步骤** | **操作说明** |
| :--- | :--- |
| **1. 平台注册** | 登录 WUPEN 官网（http://wupen.org）完成用户注册 |
| **2. 进入竞赛页面** | 由团队负责人前往竞赛页面选择“城市可持续调研报告国际竞赛” |
| **3. 填写报名信息** | 填写团队成员信息、指导教师信息，点击保存即完成报名，获得**参赛码** |
| **4. 上传作品** | 在作品提交截止日前上传报告PDF及其他可选材料 |
| **5. 确认提交** | 确认无误后点击提交，作品进入待评审后台 |

### 5.2 重要时间节点

| **阶段** | **时间** | **说明** |
| :--- | :--- | :--- |
| **注册报名与成果提交开启** | 2026年03月02日 | — |
| **最终成果提交截止** | **2026年05月31日 18:00（北京时间）** | 逾期系统关闭 |
| **获奖名单公布** | 2026年07月初 | — |
| **人气奖投票** | 另行通知 | — |

### 5.3 作品修改规则

- 从报名开始至作品提交截止日，可随时编辑修改表单信息、上传作品
- 可在竞赛首页点击“取消报名”放弃参赛
- 一旦点击提交并确认，作品即进入待评审后台，不可再更改

### 5.4 参赛费用

- 大赛**不收取报名费、参赛费**
- 所有参赛费用由参赛团队自理

## 六、评审与奖项技术指标

### 6.1 评审流程

| **阶段** | **评审方式** | **说明** |
| :--- | :--- | :--- |
| **资格审查** | 技术审核 | 检查是否符合匿名要求、格式规范 |
| **第一轮专家评审** | 线上评审 | 按得分排序晋级 |
| **第二轮专家评审** | 线上评审 | 综合两轮得分确定最终获奖名单 |

### 6.2 奖项设置与获奖比例

| **奖项** | **获奖比例** | **说明** |
| :--- | :--- | :--- |
| **一等奖** | 得分前1% | 电子版获奖证书 |
| **二等奖** | 得分前2-5% | 电子版获奖证书 |
| **三等奖** | 得分前6-10% | 电子版获奖证书 |
| **提名奖** | 得分前11-15% | 电子版获奖证书 |
| **人气奖** | 10份 | 投票产生，电子版获奖证书 |

### 6.3 同分处理规则

若出现综合得分相同情况：
- 第一轮评审：同分作品同时晋级
- 第二轮评审：由评委会统一讨论投票决定奖项归属

## 七、原创性与学术诚信技术规范

### 7.1 原创性要求

- 参赛方案必须是**参赛者个人原创作品**
- 不能侵犯任何第三方个人和单位的任何专利权、著作权、商标权及其他合法知识产权

### 7.2 违规处理

| **违规行为** | **处理措施** |
| :--- | :--- |
| **抄袭** | 取消参赛资格，作品公开展示并接受监督举报 |
| **匿名信息泄露** | 直接取消参赛资格 |
| **身份造假** | 取消参赛资格 |
| **举报机制** | 可通过官方邮箱 cqa@wupen.org 举报疑似抄袭 |
