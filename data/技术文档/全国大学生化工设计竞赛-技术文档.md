# 全国大学生化工设计竞赛 参赛技术指南

## 一、赛事概述

**全国大学生化工设计竞赛**是由中国化工学会、中国化工教育协会、教育部高等学校化工类专业教学指导委员会主办的国家级学科竞赛，是国内化工类级别最高、参赛队伍最多、影响最大的全国性学科竞赛。竞赛旨在多方面培养大学生的创新思维和工程技能，培养团队协作精神，增强大学生的工程设计与实践能力，实践“卓越工程师教育培养计划”。

- **主办单位**：中国化工学会、中国化工教育协会、教育部高等学校化工类专业教学指导委员会
- **竞赛官网**：http://iche.zju.edu.cn/
- **竞赛官方邮箱**：ichezju@foxmail.com
- **竞赛举报邮箱**：hgsjjs@foxmail.com

## 五、作品技术规范

### 5.1 设计任务

| **项目** | **技术规格** |
| :--- | :--- |
| **设计对象** | 某一化工产品的生产工艺流程 |
| **设计内容** | 工艺流程设计、设备设计、车间布置、厂区布置、经济分析、安全环保等 |
| **设计深度** | 达到初步设计或可行性研究深度 |

### 5.2 提交材料

| **材料类型** | **内容要求** |
| :--- | :--- |
| **设计说明书** | 完整的设计文档，包括工艺说明、设备计算、经济分析等 |
| **工艺流程模拟文件** | Aspen Plus等软件的源文件 |
| **设备设计文件** | 设备图纸、计算书 |
| **厂区布置图** | CAD图纸 |
| **项目可行性报告** | 经济分析、市场分析 |

## 六、评审技术指标

### 6.1 评审维度

| **维度** | **考察要点** |
| :--- | :--- |
| **技术方案** | 工艺流程的先进性、合理性、创新性 |
| **工程可行性** | 设计的可实施性、设备选型的合理性 |
| **经济性** | 投资估算、成本分析、经济效益 |
| **安全性** | 安全设计、风险评估 |
| **环保性** | 清洁生产、三废处理 |
| **文档质量** | 设计文档的完整性、规范性 |
