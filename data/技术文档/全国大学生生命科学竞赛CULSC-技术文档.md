# 全国大学生物联网设计竞赛 技术文档

## 一、赛事概述

**全国大学生物联网设计竞赛**（National College Student Internet of Things Design Competition）是由全国高等学校计算机教育研究会主办、上海交通大学承办的一项全国性学科竞赛。竞赛以促进国内物联网相关专业建设和人才培养为目标，以物联网技术为核心，激发物联网相关专业学生的创造、创新、创业活力，推动高校创新创业教育而举办的面向大学生的学科竞赛。

### 1.1 赛事地位
2023年3月，本竞赛新增进入中国高等教育学会《2022全国普通高校大学生竞赛分析报告》竞赛榜单；2023年4月，被全国高等学校计算机教育研究会等发布的《全国普通高校大学生计算机类竞赛研究报告》选为报告数据采集覆盖的竞赛。竞赛已成为国内物联网领域**最具规模和影响力的学科竞赛**。

### 1.2 第十三届基本信息
- **举办时间**：2026年4月-8月
- **大赛官网**：https://iot.sjtu.edu.cn/
- **主办单位**：全国高等学校计算机教育研究会
- **竞赛秘书处**：设在上海交通大学

### 1.3 组织机构

| **机构类型** | **单位名称** |
| :--- | :--- |
| **主办单位** | 全国高等学校计算机教育研究会 |
| **金牌合作伙伴** | 华为、乐鑫信息科技、霍尼韦尔、CSA联盟、广和通、TI、火山引擎、涂鸦智能 |
| **支持单位** | 机械工业出版社 |
| **竞赛组委会** | 由物联网工程专业教学研究专家组设立，负责组建专家指导委员会、评审委员会和监督委员会 |

## 二、参赛资格与组队要求

### 2.1 参赛对象
参赛对象为普通高校全日制在校学生，包括**本科生、研究生或本科生和研究生混合组队**。同时设置高职赛道，欢迎职业学校全日制在校学生参赛。

### 2.2 组队要求

| **项目** | **要求** |
| :--- | :--- |
| **队员人数** | 每支参赛队参赛学生**不超过4人** |
| **指导教师** | 指导教师**不超过2人** |
| **跨校组队** | **不允许**跨校组队，须来自同一所学校 |
| **每人限报** | 每位参赛学生只能参加1支参赛队 |
| **教师指导限额** | 指导教师可同时带领本校的多支参赛队 |

### 2.3 指导教师职责
指导教师负责指导参赛队选题、组织学生参加赛前的技术培训，并鼓励学生应用竞赛推荐技术平台进行作品的创意设计与实现，同时负责竞赛过程中与学校及组委会之间的信息沟通。

## 三、竞赛命题与选题

### 3.1 命题发布
组委会于每年4月发布竞赛通知、章程和竞赛命题。为促进参赛师生与业界的交流，提高参赛作品质量，竞赛组委会邀请合作伙伴设计了若干具有挑战性的竞赛命题。

### 3.2 技术平台支持
- **免费发放**：竞赛推荐的技术平台由组委会**免费向参赛队发放**
- **加分政策**：使用推荐技术平台参赛将获得适当的加分
- **技术指导**：竞赛合作伙伴将选派资深工程师指导选择这些命题的参赛队伍
- **贵重平台**：贵重的技术开发平台由合作伙伴与参赛队伍协商，参赛队伍通过免费租借（完赛后归还）、优惠购买等多种方式获得

### 3.3 选题方式
参赛队有两种选题方式：
1. **选择命题**：从组委会发布的竞赛命题中选择，获得技术平台支持和加分
2. **自拟主题**：参赛队也可以自拟竞赛主题报名参赛

### 3.4 技术讲座
组委会在4月-6月举办**15场线上/线下技术讲座**以及**10场校企合作交流活动**，参赛师生可通过多种方式与合作伙伴企业专家交流技术和合作。

## 四、竞赛形式与作品要求

### 4.1 作品形式

| **形式** | **要求** |
| :--- | :--- |
| **线上提交** | 一个基于物联网技术的、具有现实应用价值的物联网应用设计方案，以及作品实物演示视频。文档和视频需要按照组委会发布的文档内容和格式要求制作 |
| **现场答辩** | 现场的作品演示和答辩。参赛作品必须是学生原创，谢绝任何形式的导师课题参赛，或不经修改直接使用参加其他竞赛的参赛作品参赛 |

### 4.2 竞赛形式

| **阶段** | **形式** | **说明** |
| :--- | :--- | :--- |
| **线上预赛** | 线上评审 | 参赛队在竞赛网站提交作品完整方案和演示视频，采用线上评审方式打分，按分数高低决定入围分赛区决赛的参赛队伍名单 |
| **分赛区决赛** | 线下集中 | 采用作品讲解和作品现场演示两个环节，评审专家打分，决定分赛区奖项归属及入围全国总决赛名单。入围全国总决赛队伍总数**不多于170支** |
| **全国总决赛** | 线下集中 | 采用作品讲解和作品演示两个环节，评审专家打分，决定最终奖项归属 |

## 八、评审与奖项设置

### 8.1 评审方法

| **阶段** | **评审方式** | **考察重点** |
| :--- | :--- | :--- |
| **分赛区网评预赛** | 线上评审 | 作品的创意、技术方案及其实现质量、应用价值等 |
| **分赛区决赛** | 线下评审 | 技术方案及其实现质量、讲解和作品的演示效果 |
| **全国总决赛** | 线下评审 | 技术方案及其实现质量、讲解和作品的演示效果 |

### 8.2 奖项设置

| **奖项类别** | **说明** |
| :--- | :--- |
| **分赛区奖项** | 设一等奖、二等奖若干名，优秀指导教师和优秀学校组织奖若干名，发放获奖证书。部分优秀的分赛区一等奖队伍入围全国总决赛 |
| **全国总决赛奖项** | 设一等奖、二等奖、三等奖各若干名，颁发获奖证书 |
| **企业创新奖** | 在一等奖、二等奖、三等奖的获奖作品中遴选企业创新奖若干名，颁发证书 |
| **优秀指导教师奖** | 颁发获奖证书 |
| **优秀学校组织奖** | 颁发获奖证书 |

### 8.3 获奖公示
竞赛的获奖结果由竞赛评审委员会审定，并在竞赛网站上公示，获奖证书由全国高等学校计算机教育研究会会同竞赛组委会统一印制、颁发。

## 十、参赛注意事项

### 10.1 报名注意事项
- 往届参赛学生和指导教师需**重新注册**
- 必须同时在**学校创新创业平台**和**竞赛官网**进行注册和报名，全国组委会审核通过才能具备参赛资格
- 最终报名信息将在大赛官网上公布

### 10.2 作品提交注意事项
- 作品完整方案和演示视频提交系统准时关闭，切勿错过截止日期
- 严格按照组委会发布的文档内容和格式要求制作

### 10.3 原创性要求
- 参赛作品必须是学生原创，谢绝任何形式的导师课题参赛
- 不可不经修改直接使用参加其他竞赛的参赛作品参赛

### 10.4 技术平台使用
- 选择命题可获得免费技术平台和工程师指导
- 使用推荐技术平台参赛将获得适当的加分
- 贵重平台可通过租借（完赛后归还）或优惠购买获得
