# 全国航空航天模型锦标赛 参赛技术指南

## 一、赛事概述

**全国航空航天模型锦标赛**是由国家体育总局航空无线电模型运动管理中心、中国航空运动协会等主办的全国性科技体育赛事。赛事涵盖创新实践竞赛、科技创新评比、青少年教育竞赛、无人机竞速等多个类别，是我国航空航天模型领域级别最高、规模最大的赛事体系之一。

- **主管单位**：国家体育总局航空无线电模型运动管理中心
- **主办单位**：中国航空运动协会、中国学生体育联合会等
- **竞赛规则**：依据《航空航天模型及无人机运动竞赛规则（2025版）》执行[citation:9]
- **赛事官网**：https://www.sport.gov.cn/hgzx/

---

## 二、赛事类别与定位

全国航空航天模型锦标赛包含以下主要分支赛事：

| **赛事名称** | **定位** | **时间** | **规模** |
| :--- | :--- | :--- | :--- |
| **中国国际飞行器设计挑战赛（CADC）** | 科研类、大学生为主，含创新实践竞赛与科技创新评比 | 分站赛+总决赛（9-10月）[citation:2] | — |
| **全国青少年航空航天模型锦标赛** | 青少年群体，侧重基础技能与教育普及 | 7-8月，赛期8天[citation:1] | 约2000人[citation:1] |
| **全国航空航天模型（无人机项目）锦标赛** | 无人机专项竞速与竞技 | 6-9月，赛期4天[citation:3][citation:4] | 约150人[citation:3][citation:4] |
| **全国航空航天模型锦标赛（航天/自由飞/室内/室外项目）** | 传统航空航天模型分类竞技 | 2026年多个分项[citation:7] | — |

## 三、中国国际飞行器设计挑战赛（CADC）技术规范

### 3.1 参赛资格与组别

| **项目** | **技术规格** |
| :--- | :--- |
| **组别设置** | 大学生组、高中生组、公开组[citation:2] |
| **大学生组** | 在校大学生或科研院所在职人员（以学信网、军校学员证或工作证明为准）[citation:2] |
| **高中生组** | 在校高级中学学生（以学校提供的在校证明为准）[citation:2] |
| **公开组** | 不限，鼓励企业及个人参赛[citation:2] |
| **会员要求** | 除军事院校外，领队、指导教师、参赛选手须为中国航空运动协会当年度注册会员[citation:2] |

### 3.2 竞赛项目

#### 3.2.1 创新实践竞赛

| **序号** | **项目名称** |
| :--- | :--- |
| 1 | 限时载运空投[citation:2] |
| 2 | 模拟搜救[citation:2] |
| 3 | 太阳能飞机[citation:2] |
| 4 | 垂直起降载运[citation:2] |
| 5 | 对地侦察与打击[citation:2] |
| 6 | 多级模型火箭发射与载荷回收[citation:2] |
| 7 | 模型水火箭助推航天器[citation:2] |
| 8 | 限距载重空投[citation:2] |
| 9 | 微型飞行器[citation:2] |
| 10 | 固定翼飞行器精确撞网[citation:2] |
| 11 | 电动滑翔机[citation:2] |

*注：分站赛需设上述11个项目中的至少4项；总决赛设置全部项目[citation:2]。*

#### 3.2.2 科技创新评比

科技创新作品鼓励围绕以下主题设计[citation:2]：
- 模型飞行器的总体设计、动力装置、结构工艺、飞行控制、起落装置、抓取投放装置创新
- 参赛模型飞行器的飞行训练设备和辅助地面设备创新
- 新概念模型飞行器的创新设计及其飞行验证

*注：分站赛不设科技创新评比[citation:2]。*

### 3.3 组队与兼项限制

| **项目** | **技术规格** |
| :--- | :--- |
| **领队** | 每代表队可填报领队1名[citation:2] |
| **指导教师** | 创新实践竞赛每飞行组可报指导老师2名；科技创新评比每项目可报2名[citation:2] |
| **指导教师比例** | 指导老师人数与参赛项目数比值为1:2[citation:2] |
| **兼项限制** | 操纵手不得兼任其他机组的操纵手[citation:2] |
| **项目内兼组限制** | “多级模型火箭发射与载荷回收”和“模型水火箭助推航天器”项目选手不得项目内兼组[citation:2] |
| **往届冠军限制** | 曾获单项第一名的操纵手，不能再担任原获奖项目的操纵手[citation:2] |
| **设备共享限制** | 同一代表队各小组间不允许共用飞行器及机载设备[citation:2] |

### 3.4 赛程安排

| **阶段** | **时间** | **地点** |
| :--- | :--- | :--- |
| **分站赛** | 2025年（时间待定） | 浙江温州、湖南衡阳、江苏溧阳[citation:2] |
| **总决赛** | 2025年9-10月 | 河北张家口崇礼[citation:2] |

*注：2026年赛事申办公告已发布，具体时间地点待定[citation:7]。*

## 六、竞赛规则与标准

### 6.1 最新竞赛规则

2026年2月，中国航空运动协会正式发布 **《航空航天模型及无人机运动竞赛规则（2025版）》**，作为全国各级航空航天模型及无人机运动竞赛活动的重要依据[citation:9]。

### 6.2 场地国标

所有赛事场地须符合国家标准 **GB 19079.26-2013**《体育场所开放条件与技术要求 第26部分：航空航天模型场所》[citation:1][citation:3][citation:4]。
