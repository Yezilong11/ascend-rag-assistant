# 全国大学生化学实验创新设计大赛 技术文档

## 一、赛事概述

**全国大学生化学实验创新设计大赛**是由中国化学会和教育部高等学校国家级实验教学示范中心联席会（以下简称“联席会”）主办的全国性大学生化学类和近化学类专业多学科综合性竞赛[citation:2]。该赛事被譽为我国化学类学科竞赛的最高等级赛事，已纳入全国普通高校大学生竞赛排行榜[citation:1][citation:10]。

### 1.1 办赛宗旨
举办竞赛的目的在于建立一个大学生实验创新能力的展示与交流平台，推动我国高等学校实验教学改革，夯实大学生的化学基础知识、基本理论和基本技能，强化大学生发现问题、分析问题和解决问题的能力，培养大学生的创新意识、创新精神和创新能力[citation:2]。

### 1.2 官方网站
- **总决赛官网**：https://cid.nju.edu.cn/
- **赛区子页面**：通过官网可进入各分赛区专属页面

### 1.3 组织机构
- **主办单位**：中国化学会、教育部高等学校国家级实验教学示范中心联席会
- **负责机构**：全国大学生化学实验创新设计大赛竞赛委员会
- **技术支持**：北京微瑞集智科技有限公司

## 二、竞赛赛道与内容

### 2.1 四大赛道

第五届大赛共设四个赛道[citation:4][citation:6][citation:8]：

| **赛道** | **名称** | **简要说明** |
| :--- | :--- | :--- |
| **赛道一** | 新创实验 | 将科研成果转化为适合本科教学的实验 |
| **赛道二** | 改进实验 | 对现有实验进行创新设计或仪器改进 |
| **赛道三** | 科普实验 | 面向公众的趣味化学实验 |
| **赛道四** | 数智化实验 | 融合数字、人工智能技术的实验 |

### 2.2 赛道详细要求

#### 2.2.1 新创实验
是指把反映新知识、新理论、新技术、新方法的科研成果设计为适合本科生实验教学需要的基础实验或者综合实验[citation:2][citation:8]。

**具体要求**：
- 未在国内外教材、杂志发表
- 需要经过反复验证，确保可重复
- 时长、成本和安全性符合教学需要
- **基础实验**：总时长不超过8小时
- **综合实验**：总时长不超过24小时
- 对提升实验教学水平具有重要意义

#### 2.2.2 改进实验（包括教学实验仪器创制或改进）
是指针对现有国内外教材或杂志的教学实验，对教学内容、教学方法及教学手段进行创新设计，或对教学实验仪器进行创制或改进，使之更加符合实验教学需要，更有利于培养学生的创新思维和科研能力[citation:2][citation:8]。

#### 2.2.3 科普实验
科普实验的受众为没有或者很少有化学素养的社会公众及中小学生[citation:2][citation:8]。

**具体要求**：
- 有助于公众了解和正确认识化学
- 能够激发青少年学习化学的兴趣和热情
- 内容反映化学之趣、化学之美、化学对社会发展的贡献
- 作品应安全、绿色、有趣、价廉、便于展示
- 方便公众亲手操作，并能给公众留下深刻印象

#### 2.2.4 数智化实验
是指以真实实验为基础，将数字、人工智能等技术与化学实验深度融合，能够全面提升学生的数智意识和数智能力的实验[citation:8][citation:9]。

**具体要求**[citation:9]：
- 基于已有、二次开发或新开发的数学物理模型和数据库
- 对实验场景、实验过程和实验结果进行模拟、预测和评价
- 通过对实验的虚拟呈现、数据获取、判断和处理，实现对实验过程的控制与指导
- 提升学生理解、掌握、运用和拓展实验原理和方法的能力

**可使用的技术**：基于大模型的人工智能技术(AI)、数值模拟与虚拟仿真技术、半实物自动化远程控制技术等多种不同数字化技术及其合理组合

## 三、参赛资格与组队要求

### 3.1 参赛对象
全国普通高等院校**全日制在校本科生**[citation:2][citation:6]。当年毕业的学生可以以在校生身份参赛[citation:1]。

### 3.2 组队规模与要求

| **赛道** | **队员人数** | **指导教师** | **备注** |
| :--- | :--- | :--- | :--- |
| 新创实验 | 3人 | 1-2名 | 设队长1名 |
| 改进实验 | 3人 | 1-2名 | 设队长1名 |
| 科普实验 | 3人 | 1-2名 | 设队长1名 |
| 数智化实验 | 3-5人 | 1-3名 | 设队长1名 |

*数据来源：[citation:4][citation:6][citation:8]*

### 3.3 参赛规则
1. **每人限报**：每名学生只能参加一支参赛队[citation:1][citation:6]
2. **每队限报**：每个参赛队只能提交1个作品[citation:6]
3. **跨校组队**：鼓励跨专业、跨年级组队参赛[citation:1][citation:8]
4. **原创要求**：参赛项目须为本团队策划或经营的项目，不可借用他人项目参赛[citation:5]
5. **参赛限制**：已获往届全国决赛奖励的项目不得再报名[citation:2]

## 四、赛制与赛程安排

### 4.1 赛制模式
大赛采用“**校赛—分赛区初赛—全国总决赛**”三级赛制[citation:2][citation:4]：
- **校赛**：各高校自行组织，选拔队伍参加区赛
- **分赛区初赛**：各赛区组织初赛，选拔队伍参加总决赛
- **全国总决赛**：全国统一组织，决出最终奖项

### 4.2 七大分赛区划分[citation:2]

| **赛区** | **所辖省份/地区** |
| :--- | :--- |
| **华北赛区** | 北京市、天津市、河北省、山东省 |
| **东北赛区** | 辽宁省、吉林省、黑龙江省、内蒙古自治区 |
| **华东赛区** | 上海市、江苏省、浙江省 |
| **华中赛区** | 湖北省、河南省、安徽省、江西省 |
| **华南赛区** | 广东省、广西壮族自治区、海南省、湖南省、福建省、台湾省、香港特别行政区、澳门特别行政区 |
| **西南赛区** | 重庆市、四川省、贵州省、云南省、西藏自治区 |
| **西北赛区** | 山西省、陕西省、甘肃省、青海省、宁夏回族自治区、新疆维吾尔自治区 |

### 4.3 第五届大赛时间安排（2025-2026年）

| **阶段** | **时间节点** | **说明** |
| :--- | :--- | :--- |
| **竞赛委员会发布通知** | 2025年1月 | 发布竞赛通知和竞赛章程[citation:2] |
| **分赛区发布通知** | 2025年2月 | 各分赛区发布竞赛通知[citation:2] |
| **校赛选拔** | 2025年3月-4月 | 各高校自行组织[citation:1][citation:6][citation:8] |
| **区赛报名与作品提交** | 2025年5月-6月 | 各赛区截止时间略有差异[citation:4][citation:8] |
| **分赛区初赛** | 2025年6月-7月 | 采取作品评审和答辩方式进行[citation:2][citation:4] |
| **分赛区获奖公示** | 2025年7月 | 公示1周[citation:2] |
| **全国总决赛** | 2025年8月 | 第五届总决赛在兰州大学举办[citation:9] |

### 4.4 总决赛晋级名额
- 总决赛参赛队伍总数控制在**90支以内**[citation:2]
- **每个学校进入总决赛的队伍不超过1支**[citation:2]
- 如某校有多支队伍出线，按下列顺序确定：
  1. 由学校自行确定
  2. 竞赛成绩第一的队伍
  3. 由分赛区根据各赛道情况制定出线规则

## 五、作品提交要求

### 5.1 提交材料清单

| **材料名称** | **格式要求** | **备注** |
| :--- | :--- | :--- |
| **实验论文** | Word版和PDF版 | 按官方模板撰写[citation:8][citation:10] |
| **答辩PPT** | PPT或PPTX | 用于现场汇报 |
| **实验视频** | MP4格式 | 展示实验过程和结果 |
| **其他附件** | 不限 | 如原始数据、图片等 |

*数据来源：[citation:2][citation:6][citation:8]*

### 5.2 盲审要求
所有评审材料（实验论文PDF版、答辩PPT、实验视频及其他附件）必须**隐匿任何与参赛学校、指导教师、参赛学生相关的信息**[citation:2][citation:10]。

**具体要求**[citation:8]：
- 论文中不得出现学校名称、选手姓名、指导教师姓名
- 视频中须隐去学校标识（包括仪器标签、实验服、实验室名称以及建筑标志等）
- 不得出现指导教师画面

### 5.3 命名规范
| **阶段** | **命名格式** |
| :--- | :--- |
| **校赛提交** | 学院名称+参赛队队名+作品类型[citation:8] |
| **区赛提交** | 按各赛区通知要求 |

### 5.4 作品知识产权要求
- 参赛作品须具备自有或许可的知识产权[citation:6]
- 不得侵犯他人知识产权[citation:5]
- 所涉及的发明创造、专利技术、资源等必须拥有清晰合法的知识产权或物权[citation:8]
- 凡抄袭、盗用、提供虚假材料或违反相关法律者，一经发现即刻取消参赛资格[citation:5]

## 六、评审规则

### 6.1 评分构成
竞赛成绩由两部分组成[citation:2][citation:4][citation:6]：
- **作品成绩**：50%
- **答辩成绩**：50%

### 6.2 评审维度
专家委员会根据作品的**科学性、创新性、可行性和经济性**等对作品进行评审[citation:8]。

| **维度** | **说明** |
| :--- | :--- |
| **科学性** | 理论依据充分，实验设计合理 |
| **创新性** | 设计理念、技术方法的独创性 |
| **可行性** | 方案的可实现程度 |
| **经济性** | 成本控制和教学适用性 |

### 6.3 泄密扣分规则[citation:2]
在作品合格性审查、评审和答辩等环节，发现泄露参赛学校、指导教师和参赛人员信息等情况，将进行扣分：
- 信息第一次泄露：**扣2分**
- 同一信息多次重复泄露：再追加**扣1分**
- 各类信息泄露总扣分限在**10分之内**

## 八、申诉与仲裁

### 8.1 申诉范围[citation:2]
如发现以下问题，可以向竞赛委员会举报或者提出申诉：
1. 参赛作品存在违反学术道德、违反法律法规、违反竞赛纪律等情况
2. 比赛过程中存在影响比赛结果公正公平的问题

### 8.2 申诉要求[citation:2]
- 递交**书面材料**
- **署名并加盖单位公章**
- 特殊情况来不及加盖公章时，向组委会先口头申请，随后及时补交盖章申诉材料
- **不接受匿名举报或申诉**

### 8.3 申诉时间
从比赛开始至作品获奖公示期结束前[citation:2]。

### 8.4 仲裁裁定
督查仲裁组作出的仲裁为**最终裁定**[citation:2]。

5. **校赛选拔**：参加校内选拔赛[citation:8][citation:9]
6. **区赛报名**：获得推荐资格后，在区赛平台完成正式报名[citation:4]

## 十一、参赛注意事项

### 11.1 时间节点
- 密切关注官网（https://cid.nju.edu.cn/）和各赛区通知
- 各高校校内截止时间通常早于区赛截止时间1-2个月[citation:1][citation:6]
- 作品提交后，在合格性审核前可进行修改[citation:4]

### 11.2 材料准备
- 严格按照论文模板撰写[citation:8][citation:10]
- 视频拍摄注意隐去学校标识[citation:8]
- 所有材料反复检查是否存在泄密信息

### 11.3 查重要求
- 大赛设置查重环节[citation:4][citation:8]
- 与往年作品高度相似将被取消资格
- 参赛作品需在参赛当年1月1日前未在正式出版物公开发表[citation:2][citation:6]

### 11.4 人员变更
报名结束后原则上不接受更改队员和指导教师[citation:2]。如需变动，应由参赛单位提出书面申请，主管领导签字并盖好公章，报竞赛组委会批准[citation:2]。
