# 中国高校智能机器人创意大赛 技术文档

## 一、赛事概述

**中国高校智能机器人创意大赛**（China University Intelligent Robot Creative Contest）创办于2017年，由中国高等教育学会、教育部工程图学课程教学指导委员会、中国高校智能机器人创意大赛组委会共同主办[citation:1]。大赛以 **“更好、更快、更强”** 为主题，旨在培养学生提出问题能力为起点，形成问题提出、解决方案、具体创作和后期孵化一体化的人才培育链条[citation:1]。

大赛于**2020年列入中国高等教育学会发布的全国普通高校大学生竞赛排行榜**，是目前机器人领域最具影响力的国家级学科竞赛之一[citation:1]。

### 1.1 组织机构（第九届）
- **指导单位**：中国高等教育学会
- **主办单位**：中国高校智能机器人创意大赛组委会
- **承办单位**：宁波工程学院、余姚市机器人研究中心[citation:1]
- **组织架构**：设立组织委员会、专家委员会、裁判委员会、仲裁委员会

### 1.2 历届规模
大赛每年举办一次，至今已连续举办8届，覆盖全国数百所高校，参赛师生规模逐年扩大，助力机器人相关人才培养成效显著[citation:1]。

## 二、大赛主题与赛项设置

第九届中国高校智能机器人创意大赛设**主题赛、专项赛和产教融合赛**三大类[citation:1][citation:7]。

### 2.1 主题赛

#### 主题一（创意设计）：家用智能机器人——让生活更美好
服务于未来生活的智能型服务机器人创意设计，适用于千家万户的智能机器人，用途包括：家务劳动、娱乐、情感交流、陪伴、个人卫生、家庭管家、安全与防护等家用服务智能机器人[citation:2]。

**作品形式**，评审时按以下类别分组[citation:2][citation:5]：
| **组别** | **作品形式要求** |
| :--- | :--- |
| **无实物组** | 以文字、图片、动画等形式展示作品的创意设计 |
| **自制实物模型组** | 采用自行创意、设计并制作模型（或原理样机）的形式展示 |
| **模块化产品搭建组** | 采用慧鱼模块、启创远景模块、越疆模块、探索者模块等搭建作品 |
| **生成式人工智能（AIGC）组** | 采用国内AI工具协助完成设计，需提交提示词、截屏等原始资料，不得直接使用AI生成内容代替自主思考 |

#### 主题二（创意竞技）：魔方机器人——挑战更快
参照人类魔方竞速规则，设计制作魔方机器人，综合运用机械、电子、信息和自然科学知识，实现比人“计算”更快、“翻动”更加灵活迅速的目标[citation:2]。

**技术要求**[citation:2][citation:4]：
- **机器人结构**：限采用双手臂，手指限二指或五指形式，手腕容许转动和摆动，手臂固定
- **外廓尺寸**：不超过480mm×480mm×480mm
- **总重量**：不超过20kg
- **视觉系统**：摄像头数量不限，允许自行增设光源
- **魔方规格**：竞赛采用标准三阶魔方，决赛用魔方由组委会统一提供
- **限项要求**：同一学校进入全国决赛的参赛作品不超过2项，且结构、技术方案不得雷同

#### 主题三：智能机器人对抗赛——挑战更强
分统一部件组和开放部件组两大类别[citation:2][citation:6]：

| **组别** | **说明** |
| :--- | :--- |
| **统一部件组** | 选用统一标准的控制器、传感器、动力模块等部件，通过策略制定和程序设计进行对抗 |
| **开放部件组** | 在重量、尺寸等限制条件下，自行设计制作机器人，在擂台上自主对抗 |

比赛项目包括：轮式格斗、仿人格斗、视觉对抗、无人机对抗、服务机器人竞技、机器人仿真、创意设计等[citation:6]。详细规则请访问：http://www.robo-maker.org/dszq/[citation:2]

### 2.2 专项赛

#### 专项赛一：基于ROS技术应用的机器人挑战赛
| **组别** | **要求** |
| :--- | :--- |
| **单臂机器人竞赛组** | 参照俄罗斯方块规则，设计基于ROS框架的系统，融合机器视觉和AI算法，将随机散放的方块装配到托盘中。手臂限串联六轴及以上，臂展≤1000mm，须在ROS框架下运行[citation:6] |
| **双臂机器人竞赛组** | 设计基于ROS框架的双臂服务机器人系统，融合语义识别、机器视觉、深度强化学习，完成端茶倒水、物品取放、人机协同等任务。手臂限串联六轴及以上，臂展≤1000mm，须在ROS框架下运行[citation:6] |

#### 专项赛二：足式机器人挑战赛
| **组别** | **说明** |
| :--- | :--- |
| **四足机器人组** | 分为大型组和小型组，对运动部分和感知部分二次开发，任务包括越障、避障、竞速、识别、检测、路径规划、踢足球等[citation:2] |
| **双足机器人组** | 分为大型组和小型组，任务同四足组[citation:2] |

#### 专项赛三：VEX U智能机器人对抗赛
- **竞赛主题**：第九届主题为“狭路相逢”[citation:7]
- **比赛场地**：约3.7m×3.7m正方形场地
- **赛制**：两支联队各控制两台机器人，包含30秒自动时段和90秒手动控制时段
- **得分方式**：将套环放在尖桩上、挪动移动桩、赛局结束时攀爬
- **详细规则**：请查阅VEX中文官方论坛 https://www.vexforum.cn[citation:7]

### 2.3 产教融合赛
本赛道立足国家新质生产力培育需求，聚焦人工智能技术前沿领域。第九届设以下赛道[citation:7]：
1. 舜宇“未来视界”创意赛
2. 软件系统安全赛
3. 北控水务“智赋生态”创新赛
4. 中兴捧月“星匠师”巧匠精英挑战赛-超级智能体开发大赛
5. 中国移动“梧桐杯”数智创新大赛-智能体创新大赛
6. 信捷电气“数智融合”创新赛

采用大赛提供的硬件和软件平台，依据相应赛道竞赛大纲完成竞赛任务[citation:7]。

## 三、赛制与赛程安排

### 3.1 赛制
大赛采用**区域赛和全国赛二级赛制**[citation:1]：
- **区域赛**：按省、自治区、直辖市组织，为全国赛选拔赛。评出不高于24%的参赛队伍获得全国赛资格[citation:1]
- **全国赛**：获得资格的参赛队经现场展示、答辩，由专家委员会评选出各奖项[citation:1]
- 主题三、各专项赛、产教融合赛视同为一个区域赛，由大赛组委会统一组织全国选拔赛[citation:1]

### 3.2 第九届（2026年）时间安排[citation:1][citation:3]
| **阶段** | **时间** | **说明** |
| :--- | :--- | :--- |
| **校赛选拔** | 2026年3月-4月 | 各高校自行组织，具体时间见校内通知 |
| **区域赛报名** | 2026年3月1日-5月8日 | 报名网址：www.robotcontest.cn，各赛区截止时间有差异[citation:1] |
| **区域赛选拔** | 2026年6月10日前 | 各赛区公布入选全国赛名单[citation:1] |
| **全国总决赛** | 2026年7月12-13日 | 产教融合赛决赛时间另行公布[citation:1] |

## 四、参赛资格与组队要求

### 4.1 参赛对象
全国高校在校**专科生、本科生、研究生**，经学校同意可报名参赛[citation:1]。

### 4.2 组队规模
| **赛项** | **学生人数** | **指导教师** |
| :--- | :--- | :--- |
| 主题一、主题二 | 1-3人 | 1-2人[citation:1] |
| 主题三、专项赛、产教融合赛 | 1-4人 | 1-2人[citation:1] |

### 4.3 限项说明
- 主题二（魔方机器人）：**每个学校进入全国决赛的参赛作品不超过2项**[citation:1]
- 同一学校参赛的魔方机器人结构、技术方案不得雷同[citation:2]

## 五、参赛作品提交要求

### 5.1 通用要求
所有参赛队首先在官网（www.robotcontest.cn）提交《参赛作品申报表》电子版和签字盖章的PDF扫描版，审核通过后方可按主题提交作品材料[citation:1]。

### 5.2 各主题提交要求

#### 主题一（创意设计）[citation:1][citation:2]
| **组别** | **提交材料** | **规格要求** |
| :--- | :--- | :--- |
| 无实物组 | 设计创意的PDF文档 | 文字、设计图、效果图或动画，限A4纸6页以内，≤20M |
| 有实物组 | PDF文档 + 原理样机视频 | 视频MP4格式，限60秒以内，≤50M |
| AIGC组 | PDF文档 + AI协助原始资料 | 原始资料（提示词、截屏等）篇幅不限 |

#### 主题二、专项赛二、专项赛三[citation:1][citation:2]
| **材料类型** | **要求** |
| :--- | :--- |
| **作品视频** | MP4格式，一次完整动作过程，≤90M；魔方机器人≤90秒，足式机器人/VEX U≤120秒 |
| **技术文档** | PDF格式，包括文字、设计图、效果，限A4纸30页 |

#### 主题三、专项赛一
详细要求请见主题三、专项赛一的比赛细则[citation:1]。

#### 专项赛四（产教融合-舜宇“未来视界”）[citation:2]
- **无实物组**：文字、图片、动画等形式展示创意设计
- **自制实物模型组**：模型或原理样机展示

## 六、评审标准与奖项设置

### 6.1 评审原则
- **科学性**：理论依据充分，技术路线合理
- **创新性**：设计理念、技术方法的独创性
- **可行性**：方案的可实现程度
- **经济性**：成本控制和市场潜力[citation:10]

### 6.2 奖项设置

#### 全国赛奖项[citation:1]
| **奖项** | **比例** |
| :--- | :--- |
| 一等奖 | 20% |
| 二等奖 | 40% |
| 三等奖 | 40% |

*注：各主题、专项赛分别评审。奖项评选采取宁缺毋滥原则，根据作品质量可小于上述比例[citation:3]。*

#### 区域赛奖项
- 已成立区域赛组委会的赛区：由赛区组委会确定并公布[citation:1]
- 由大赛组委会统一组织评审的区域赛：
  - 一等奖：10%
  - 二等奖：20%
  - 三等奖：30%[citation:1]

此外，设立“优秀组织奖”和“优秀指导教师奖”表彰突出单位和个人[citation:8]。

## 七、报名与联系方式

### 7.1 官方渠道
- **官方网站**：www.robotcontest.cn（报名、提交材料、查询通知）[citation:1]
- **专项赛规则查询**：http://www.robo-maker.org/dszq/[citation:2]
- **VEX规则查询**：https://www.vexforum.cn[citation:7]

### 7.2 报名流程
1. 关注所在高校校内选拔通知
2. 加入校内竞赛QQ群（各校不同，如哈工大917666236[citation:1]、华南理工471587534[citation:5]）
3. 在官网（www.robotcontest.cn）选择相应赛区或专项报名
4. 提交《参赛作品申报表》电子版及签字盖章扫描件
5. 审核通过后按要求提交作品材料

### 7.3 参赛费用（参考）
- 区域赛选拔赛参赛费：**600元/队**（由大赛组委会统一收取，学生自筹）[citation:10]
- 部分赛区可能有差异，以官网通知为准

### 7.4 联系方式（参考）
- **大赛组委会**：可通过官网“联系我们”获取
- **各区域赛承办单位**：名单在官网陆续公布[citation:1]
- **各高校负责人**：见校内通知

## 八、知识产权说明

1. **原创性要求**：参赛作品必须为原创，不得侵犯他人知识产权[citation:4]
2. **权利归属**：已经公开或申请专利的请注明[citation:4]
3. **大赛权利**：主办方享有免费对参赛获奖作品进行部分或全部复制、信息网络传播、展示、汇编和出版的权利，作者拥有署名权[citation:4]
