# 全国高校BIM毕业设计创新大赛 参赛技术指南

## 一、赛事概述

**全国高校BIM毕业设计创新大赛**是由中国土木工程学会建筑市场与招标投标研究分会、广联达科技股份有限公司主办的国家级学科竞赛[citation:1]。大赛连续多年入选《全国普通高校学科竞赛排行榜》，是全国规模最大、涵盖专业最多的高校土木建筑专业赛事之一，也是建筑类专业比赛BIM方向唯一入选排行榜的赛事[citation:4][citation:10]。

- **主办单位**：中国土木工程学会建筑市场与招标投标研究分会、广联达科技股份有限公司[citation:1]
- **大赛官网**：https://gxbsxs.glodonedu.com/ [citation:1]
- **官方微信公众号**：广联达数字教育[citation:1]

---

## 二、赛道设置与技术模块

第十二届大赛常规赛道设**7个赛项模块**，各模块技术方向如下[citation:7]：

| **模块** | **名称** | **技术方向** |
| :--- | :--- | :--- |
| **A模块** | 新型城市基础建设与应用 | 城市基础设施BIM建模与集成应用 |
| **B模块** | 建筑设计AI+BIM应用与创新 | 建筑设计BIM建模、AI辅助设计 |
| **C模块** | 机电设计BIM应用与创新 | 机电BIM建模、管线综合优化 |
| **D模块** | BIM建筑碳排放计算与减碳设计 | 建筑碳排放计算、减碳方案设计 |
| **E模块** | BIM与价值工程驱动的工程成本管控 | 全过程造价管理、价值工程分析 |
| **F模块** | 施工深化设计建模与应用 | 施工BIM建模、深化设计、施工模拟 |
| **G模块** | BIM+工程项目管理与应用 | 项目管理BIM应用、进度/成本/质量管控 |

*注：各模块均单独评奖，本科组与专科组（含中职）分别评奖[citation:1][citation:7]。*

## 三、参赛资格与技术规范

### 3.1 参赛对象

| **类别** | **面向对象** |
| :--- | :--- |
| **本科组** | 全国全日制本科院校建筑类相关专业在籍学生（含研究生，每队≤2人）[citation:7] |
| **专科组** | 高职高专、中职院校建筑类相关专业在籍学生[citation:1][citation:7] |

### 3.2 组队技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **队员人数** | 3-5名学生[citation:1][citation:7] |
| **指导教师** | 1-2名[citation:1][citation:7] |
| **参赛单位** | 以二级院系为单位，可跨院系组队（至少2名学生隶属于本院系）[citation:7] |
| **跨校组队** | **不允许**跨校组队[citation:1] |
| **每人限报** | 每名学生限加入1支队伍[citation:1][citation:7] |
| **每队限报** | 每支队伍限报1个模块[citation:1][citation:7] |
| **单位限额** | 同一参赛单位每个模块限报2支队伍[citation:1] |

## 四、作品技术规范

### 4.1 作品形式要求

| **维度** | **技术规范** |
| :--- | :--- |
| **成果形式** | 项目案例成果，按任务指导书要求创建并输出各模块要求的工程成果文件[citation:1] |
| **软件使用** | 备赛练习及作品制作所需软件由广联达科技股份有限公司提供[citation:1] |
| **软件授权** | 报名审核通过后，组委会授权软件云加密锁（使用至比赛结束）[citation:1] |
| **图纸选用** | 同一模块参赛选用图纸不得雷同（除指定统一图纸外）；不同模块不得使用同一套图纸[citation:6] |

### 4.2 软件环境要求

| **项目** | **技术要求** |
| :--- | :--- |
| **操作系统** | Windows系统（版本≥win10，**不兼容IOS**）[citation:2] |
| **考试平台** | 广联达数字考试平台（需更新至最新版本）[citation:2] |
| **硬件要求** | 带摄像头的笔记本电脑或台式机（全程启用摄像头监考）[citation:2] |
| **网络要求** | 带宽≥100M[citation:2] |

### 4.3 提交材料技术规格

| **材料类型** | **规格要求** |
| :--- | :--- |
| **工程成果文件** | 按任务指导书要求格式和内容[citation:1] |
| **作品上传时间** | 按官网通知（各届略有差异）[citation:1] |
| **阶段性提交** | 部分届次设置阶段性提交（如第一阶段提交占5分）[citation:6] |

### 4.4 原创性技术规范

- **原创要求**：参赛作品应为原创，不得抄袭、盗用、代笔[citation:1][citation:6]
- **往届限制**：不得使用往届作品参赛[citation:6]
- **违规处理**：一经发现抄袭或使用往届作品，取消参赛资格并公示[citation:6]

## 五、赛程与技术评审流程

### 5.1 三级赛制

第十二届大赛采用以下赛制[citation:7]：

| **级别** | **阶段** | **时间安排** | **技术任务** |
| :--- | :--- | :--- | :--- |
| **晋级赛** | 校内赛/海选赛 | 2025.09 - 2025.12上旬 | 各校自行组织，选拔优秀团队 |
| **全国网络竞赛** | 作品提交+评审 | 2026.01 - 2026.05 | 提交作品，线上评审 |
| **全国总决赛** | 现场答辩+展示 | 2026.05 - 2026.06 | 入围团队角逐特等奖 |

### 5.2 评审技术指标

| **评审维度** | **考察要点** | **参考权重** |
| :--- | :--- | :--- |
| **作品完整性** | 是否按要求提交完整工程文件[citation:6] | 约40分 |
| **技术合理性** | BIM技术应用深度、业务问题解决能力[citation:6] | 约50分 |
| **阶段性提交** | 是否按时完成阶段性成果[citation:6] | 约5-10分 |

*注：每份作品由约5位评委打分，取平均值[citation:6]。*

### 5.3 校赛选拔形式参考

部分高校校赛采用以下形式[citation:2][citation:4]：

| **形式** | **内容** | **题型** | **分值** |
| :--- | :--- | :--- | :--- |
| **线上考试** | BIM基础知识、建筑专业知识、建模技术 | 50单选+10多选 | 100分 |

## 七、报名技术规范

### 7.1 报名渠道

| **平台** | **网址** | **说明** |
| :--- | :--- | :--- |
| **大赛官网** | https://gxbsxs.glodonedu.com/ | 统一报名入口[citation:1][citation:7] |
| **校内平台** | 各校创新创业管理平台 | 部分高校需同时在校内系统报名[citation:2] |

### 7.2 报名流程

| **步骤** | **操作说明** |
| :--- | :--- |
| **1. 官网注册** | 登录大赛官网，以二级院系为单位注册 |
| **2. 填写信息** | 如实填写学校、二级院系名称（否则审核不通过）[citation:1] |
| **3. 上传材料** | 上传《学生赛道—参赛回执表》或《参赛同意表》[citation:1][citation:7] |
| **4. 审核确认** | 组委会审核通过后报名完成 |

### 7.3 参赛费用

| **项目** | **技术规格** |
| :--- | :--- |
| **收费标准** | 以二级院系为单位，收取竞赛服务费**3500元**[citation:1] |
| **费用包含** | ①软件云加密锁使用权限（报名审核后至比赛结束）；②师资培训费（继续教育学时证书）；③求职辅导课程及就业服务；④作品提交与评审；⑤总决赛不另收费[citation:1] |
| **缴费时间** | 以官网通知为准（第九届为10月-次年3月）[citation:1] |
| **缴费方式** | 二维码支付（支持公务卡）、对公转账[citation:1] |
| **发票** | 增值税普通电子发票（技术服务费）[citation:1] |
