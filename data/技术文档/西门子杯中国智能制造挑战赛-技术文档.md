# “西门子杯”中国智能制造挑战赛 参赛技术指南

## 一、赛事概述

**“西门子杯”中国智能制造挑战赛**（CIMC）是由中国仿真学会和西门子（中国）有限公司联合主办的国家A类竞赛。大赛方向涉及智能制造领域中的科技创新、产品研发、工程设计和智能应用等，是针对智能制造发展所需的技术及创新人才进行培养及选拔的工程类竞赛。自2006年发展至今，已成为中国智能制造领域规模最大、规格最高的国家级学科竞赛。

- **主办单位**：中国仿真学会、西门子（中国）有限公司
- **全国竞赛秘书处**：北京化工大学
- **大赛官网**：http://www.siemenscup-cimc.org.cn/
- **官方论坛**：http://bbs.siemenscup-cimc.org.cn/

---

## 二、赛道设置与技术参数

大赛设置**三大类赛项**，涵盖智能制造领域的多个技术方向。

### 2.1 智能制造工程设计与应用类赛项

| **赛项** | **技术方向** | **参赛对象** |
| :--- | :--- | :--- |
| **流程行业自动化方向** | 流程工业过程控制、自动化系统设计 | 研究生、本科生、高职/高专/技师院校学生 |
| **离散行业自动化方向（逻辑算法）** | 离散制造业逻辑控制、算法设计 | 研究生、本科生、高职/高专/技师院校学生 |
| **离散行业自动化方向（工程实践）** | 离散制造业工程实施、系统集成 | 研究生、本科生、高职/高专/技师院校学生 |
| **离散行业运动控制方向** | 伺服驱动、运动规划、轨迹控制 | 研究生、本科生、高职/高专/技师院校学生 |
| **信息化网络化方向** | 工业网络、工业物联网、数据采集 | 研究生、本科生、高职/高专/技师院校学生 |
| **智能装备设计与数字孪生制造方向** | 智能装备设计、数字孪生建模 | 研究生、本科生、高职/高专/技师院校学生 |
| **精益智造与协作机器人方向** | 精益生产、人机协作、机器人应用 | 研究生、本科生、高职/高专/技师院校学生 |
| **工业嵌入式系统开发方向（试）** | 嵌入式系统开发、工业控制器编程 | 研究生、本科生、高职/高专/技师院校学生 |
| **智能产线数字孪生设计与开发方向（试）** | 产线仿真、数字孪生系统开发 | 研究生、本科生、高职/高专/技师院校学生 |
| **智能制造通识方向（试）** | 智能制造基础知识、系统认知 | 研究生、本科生、高职/高专/技师院校学生 |

### 3.1 参赛对象

| **类别** | **面向对象** |
| :--- | :--- |
| **研究生组** | 全国控制科学与工程、电气工程、机械工程、仪表科学与工程、信息与通讯工程、计算机科学与技术等相关学科的研究生 |

| **高职高专组** | 全国自动化类、机电设备类、机械设计制造类、电子信息类、计算机类及通信类等相关专业的高职、高专、技师院校学生 |

| **项目** | **技术规格** |
| :--- | :--- |

## 四、竞赛技术特点

### 4.1 赛题来源
- 竞赛以**企业真实的工程项目和科研项目**作为竞赛赛题

### 4.2 竞赛环境
- 以**真实的工业设备和工业环境**作为赛场

### 4.3 评分标准
- 以**工业企业的工程标准**作为考核评分指标

### 4.4 培养目标
- 全面锻炼学生**解决复杂工程问题的综合能力、系统思维**
