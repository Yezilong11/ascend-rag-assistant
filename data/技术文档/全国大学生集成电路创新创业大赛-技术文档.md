# 全国大学生集成电路创新创业大赛 参赛技术指南

## 一、赛事概述

**全国大学生集成电路创新创业大赛**（简称“集创赛”）是由工业和信息化部人才交流中心主办，国内集成电路领域规模最大、最具影响力的高校赛事。大赛是中国高等教育学会《全国普通高校学科竞赛排行榜》中唯一入榜的集成电路专业赛事，已连续举办九届，第十届于2026年正式启动。

- **主办单位**：工业和信息化部人才交流中心
- **联合承办单位**：中共无锡市滨湖区委员会、东南大学、江南大学
- **协办单位**：IEEE中国代表处、中国科技发展基金会、北京电子学会、雄安新区未来芯片创新研究院
- **支持单位**：中芯国际、冉谱微电子、赛氪、北京橙色云科技、《集成电路与嵌入式系统》期刊
- **运营单位**：北京智芯国信科技有限公司
- **大赛官网**：http://univ.ciciec.com/
- **大赛邮箱**：icbaoming@miitec.org.cn

## 二、赛道设置与技术方向

第十届大赛设**三大赛项**，覆盖集成电路全产业链关键环节：

### 2.1 芯片设计与产业链赛项

面向本、硕、博学生，由数十家行业重要企业冠名出题，赛题方向覆盖：

| **技术领域** | **典型方向** |
| :--- | :--- |
| 数字集成电路设计 | CPU/GPU设计、数字信号处理、数字逻辑电路 |
| 模拟集成电路设计 | 放大器、ADC/DAC、电源管理芯片 |
| 射频集成电路设计 | 射频前端、收发机、射频PA |
| 混合信号设计 | PLL、SerDes、传感器接口 |
| 存储器设计 | SRAM、DRAM、Flash、新型存储器 |
| EDA工具开发 | 布局布线、时序分析、验证工具 |
| FPGA创新应用 | 硬件加速、原型验证、嵌入式系统 |
| 处理器设计 | RISC-V、AI加速器、DSP |

### 2.2 芯片应用与芯创成果赛项

面向本、硕、博学生，侧重芯片应用系统设计与创新成果：

| **技术领域** | **典型方向** |
| :--- | :--- |
| 智能硬件系统 | AIoT设备、智能家居、可穿戴设备 |
| 汽车电子应用 | 车规级芯片应用、车载系统 |
| 工业控制应用 | 工业自动化、电机控制 |
| 医疗电子应用 | 医疗仪器、健康监测设备 |
| 通信系统应用 | 5G/6G通信、无线传输 |
| 创新成果展示 | 已有芯片成果的产业化应用 |

### 2.3 职业技能赛项

面向中职、高职学生，侧重工程实践能力：

| **技术领域** | **典型方向** |
| :--- | :--- |
| 芯片测试技术 | 芯片功能测试、性能测试、可靠性测试 |
| 芯片封装技术 | 封装设计、封装工艺、封装测试 |
| 芯片应用开发 | 基于开发板的嵌入式系统设计 |
| 版图设计 | 模拟版图、数字版图设计 |

## 五、作品技术规范

### 5.1 设计报告要求

| **项目** | **技术规格** |
| :--- | :--- |
| **报告格式** | PDF |
| **正文页数** | ≤30页（不含附录） |
| **语言** | 中文或英文 |
| **结构要求** | 题目、摘要、目录、正文、参考文献、附录 |
| **原创声明** | 须附原创性声明 |

### 5.2 技术文件要求

| **文件类型** | **内容要求** |
| :--- | :--- |
| **源代码** | 完整可编译的代码工程文件 |
| **设计文档** | 架构设计、模块划分、接口说明 |
| **仿真结果** | 功能仿真、时序仿真波形图 |
| **测试报告** | 测试方案、测试用例、测试结果 |
| **演示视频** | 展示作品核心功能（≤5分钟） |
| **答辩PPT** | 用于现场答辩的演示文稿 |

### 5.3 原创性与学术诚信

| **要求项** | **技术规格** |
| :--- | :--- |
| **原创性** | 参赛作品必须是参赛团队原创，不得抄袭、盗用他人成果 |
| **引用规范** | 引用他人成果必须在正文中标注，并在参考文献中列出 |
| **查重要求** | 查重率≤20%（以当年通知为准） |
| **AI工具使用** | 如使用AI工具辅助，须在附录说明工具名称、版本和使用方式 |

## 七、评审技术指标

### 7.1 评审流程

| **阶段** | **评审方式** | **晋级规则** |
| :--- | :--- | :--- |
| **初赛** | 通讯评审 | 按得分排序晋级分赛区决赛 |
| **分赛区决赛** | 现场答辩 | 赛区一等奖晋级全国总决赛 |
| **全国总决赛** | 现场答辩+作品演示 | 决出全国一、二等奖 |

### 7.2 评审维度

| **评审维度** | **考察要点** | **参考权重** |
| :--- | :--- | :--- |
| **创新性** | 设计思路的独创性、技术突破 | 25% |
| **技术难度** | 设计复杂度、实现难度 | 20% |
| **完成度** | 功能实现程度、性能指标达成 | 20% |
| **文档规范** | 设计报告完整性、规范性 | 15% |
| **现场表现** | 答辩逻辑、演示效果 | 20% |
