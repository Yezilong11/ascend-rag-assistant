# 全国大学生嵌入式芯片与系统设计竞赛 技术文档

## 一、赛事概述

**全国大学生嵌入式芯片与系统设计竞赛**是由中国电子学会、国家级实验教学示范中心联席会电子学科组主办的一项全国性学科竞赛。大赛旨在提高全国高校学生在嵌入式芯片及系统设计领域和可编程逻辑器件应用领域的自主创新设计与工程实践能力，培养具有创新思维、具备解决复杂工程问题能力且拥有团队合作精神的优秀人才，在活跃校园创新创业学术氛围的同时，推进高校与企业人才培养合作共建[citation:1]。

### 1.1 第九届赛事基本信息
- **举办时间**：2026年2月-8月
- **官方网站**：http://www.socchina.net/
- **官方微信公众号**：嵌入式芯片与系统设计竞赛[citation:5]
- **主办单位**：中国电子学会、国家级实验教学示范中心联席会电子学科组

### 1.2 第九届赛事口号
本届大赛的口号是 **“AI赋能设计，设计点亮AI！（AI for Design & Design for AI!）”** [citation:2]

**口号内涵解读**：
- **AI for Design**：AI让嵌入式应用设计更高效
- **Design for AI**：在端侧使用AI使应用更智能

这一口号既彰显技术融合的核心趋势，也传递“双向赋能、价值共创”的竞赛理念[citation:2]。

## 三、芯片应用赛道详细规程

### 3.1 参赛对象

大赛参赛对象包括（但不限于）国内外高校电子电气类相关专业（电子、信息、计算机、自动化、电气、仪科等）**全日制在校研究生、本科生、高职高专生**[citation:1][citation:5]。

### 3.2 组别划分

根据参赛学生学籍，大赛分三个组别[citation:1][citation:7]：

| **组别** | **划分标准** |
| :--- | :--- |
| **研究生组** | 参赛队员中只要有一名研究生即为研究生组 |
| **本科组** | 全体参赛队员为本科学籍 |
| **高职高专组** | 全体参赛队员为高职高专学籍（含职业本科） |

*注：参赛队员身份以报名截止日身份为准[citation:1]。*

### 3.3 组队要求

| **项目** | **要求** |
| :--- | :--- |
| **队员人数** | 每支参赛队由来自同一所学校的**1-3名学生**组成[citation:1][citation:5] |
| **指导教师** | 每支参赛队可有**不超过2名指导老师**[citation:1][citation:5] |
| **跨校组队** | 不允许跨校组队，须来自同一所学校[citation:5] |
| **每人限报** | 每位参赛选手仅可参加一支队伍[citation:9] |
| **队长权限** | 仅队长账号具备提交报名和作品等操作权限，获奖证书将严格按照组队顺序制作[citation:5] |

### 3.4 竞赛方式

参赛队采用**赛题指定的开发平台为核心**，根据选题指南自由选择赛题，开放式自主设计并完成参赛作品。在充分发挥核心平台功能和性能的基础上，**允许自行设计扩展电路构成完整的应用系统**[citation:1][citation:3][citation:8]。

### 3.9 评审流程

#### 3.9.1 参赛资格审定[citation:5]
组委会根据参赛队伍信息提交完整度、项目创新性、科学性、工程可行性、设计难度以及平台适用度等因素进行参赛资格审定。

#### 3.9.2 线上初赛评选[citation:5]
- 由赛区推荐专家、全国专家组组织线上评审
- 重点针对参赛作品合格性进行线上初筛
- 根据作品完成度和技术要求进行评审
- 确定入围赛区复赛名单，公示3天

#### 3.9.3 赛区复赛评选[citation:5]
- 由赛区执委会组织专家评审
- 原则上采用线下评审方式
- 评审流程：作品介绍及演示、质询与答辩
- 评审维度：作品的完成度、创新性、难度、系统功能与指标、答辩状况
- 晋级全国总决赛名单公示3天

#### 3.9.4 全国总决赛评选[citation:5]
- 由大赛组委会专家组进行现场评审
- 评审流程：作品介绍及演示、质询与答辩
- 评审维度：作品的完成度、创新性、难度、系统功能与指标、答辩状况
- 总决赛期间将安排**能力测评**，测评细则后续发布
- 获奖名单公示3天

## 四、AI应用特别说明

### 4.1 AI应用鼓励方向[citation:2]

本届大赛口号“AI赋能设计，设计点亮AI！”中的“双向赋能”，正是大赛鼓励的核心方向：

| **方向** | **说明** |
| :--- | :--- |
| **AI for Design** | 利用AI工具（如大模型、机器学习）辅助嵌入式系统设计，让设计更高效 |
| **Design for AI** | 在嵌入式端侧部署AI算法，使应用更智能 |

### 4.2 AI应用非强制要求[citation:2]

**需要明确的是，引入AI工具并非参赛的“必选项”，而是提升作品的“可选项”。** 大赛充分尊重每一支队伍的创意与设计思路：

- 如果作品更适合通过传统嵌入式技术、非AI前沿方案实现功能与创意，只要能体现出足够的创新性、实用性与技术完成度，同样能在赛场脱颖而出
- 赛事评审的核心始终聚焦于作品的**综合质量**——无论是AI驱动的智能设计，还是传统技术的极致打磨，只要能展现专业能力、创新思维与实践精神，都将获得认可

### 4.3 LOGO丝印要求[citation:2]

所有自制开发板，**必须丝印本届赛事口号LOGO**“AI for Design & Design for AI！”。这不仅是赛事规范的体现，更是展现设计态度、彰显原创精神的直接方式。

## 五、参赛注意事项

### 5.1 报名须知

| **事项** | **说明** |
| :--- | :--- |
| **报名方式** | 官网（www.socchina.net）注册报名[citation:1] |
| **校内备案** | 必须先参加校内选拔赛，严禁不参加校赛直接官网报名，否则学校不予认定参赛成绩[citation:6][citation:7] |
| **报名费用** | **大赛不收取报名费和评审费**，差旅及食宿费用自理[citation:5][citation:6][citation:7] |

### 5.2 原创性要求
1. **原创作品**：所有参赛作品必须为原创，不能侵犯他人知识产权[citation:8]
2. **未参赛要求**：所有参赛作品必须是未公开参加过校外任何类型比赛的作品[citation:8]
3. **内容健康**：作品必须遵守我国相关的法律、法规以及道德规范，内容健康向上[citation:8]

### 5.3 人员变更
- 报名结束后原则上不接受更改队员和指导教师[citation:5]
- 获奖证书将严格按照组队顺序制作，请队长确认指导老师和队员顺序及名称准确[citation:5]

### 5.4 申诉与仲裁[citation:5]
- 公示期内如有异议，可向组委会实名书面申诉
- 总决赛期间如有异议，可在公示期内以邮件形式向组委会发出实名仲裁申请
- 正式受理的申诉，组委会将以邮件形式回复仲裁意见
