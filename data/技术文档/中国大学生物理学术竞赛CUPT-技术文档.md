# 中国大学生物理学术竞赛（CUPT）参赛技术指南

## 一、赛事概述

**中国大学生物理学术竞赛**（China Undergraduate Physics Tournament，简称CUPT）是中国借鉴国际青年物理学家锦标赛（IYPT）模式创办的全国性赛事，得到了教育部的大力支持，是实践国家教育中长期发展规划纲要的重要大学生创新竞赛活动之一[citation:1][citation:5]。CUPT以团队对抗为形式，参赛学生围绕开放性物理问题的理论分析、实验研究、结果讨论等进行辩论性比赛，旨在提高学生综合运用所学知识分析解决实际物理问题的能力，培养学生的创新意识、团队协作精神和交流表达能力[citation:5][citation:8]。

- **赛事届数**：第十七届（2026年）[citation:5]
- **赛题来源**：第39届国际青年物理学家锦标赛（IYPT 2026）题目[citation:2]
- **官方信息发布平台**：https://www.cupt-iypt.com/

---

## 二、赛题设置与技术方向

### 2.1 赛题数量与范围

CUPT竞赛采用IYPT同年赛题，共**17道**开放性物理问题，涵盖力学、热学、光学、电磁学、声学等物理学分支[citation:1][citation:5][citation:8]。

### 2.2 研究要求

参赛学生需针对所选题目开展完整的研究工作，包括：

| **研究阶段** | **技术内容** |
| :--- | :--- |
| **理论分析** | 建立物理模型，进行理论推导与数值模拟 |
| **实验研究** | 设计实验方案，搭建实验装置，采集与分析数据 |
| **结果讨论** | 对比理论与实验结果，分析误差来源，得出结论 |
| **成果呈现** | 制作汇报PPT、学术海报，撰写研究报告[citation:3][citation:6] |

### 2.3 常用技术工具

| **工具类型** | **推荐软件** |
| :--- | :--- |
| **理论推导** | Mathematica、Maple |
| **数值模拟** | MATLAB、COMSOL Multiphysics、Python |
| **实验追踪** | Tracker（视频分析）、phyphox（手机传感器） |
| **数据绘图** | Origin、MATLAB、Python（Matplotlib）[citation:6] |

## 三、参赛资格与组队规范

### 3.1 参赛对象

| **项目** | **技术规格** |
| :--- | :--- |
| **学历层次** | 全国普通高等学校全日制在校本科生[citation:5][citation:9] |
| **年级要求** | 大一至大三学生为主[citation:3][citation:6] |

### 3.2 团队赛组队规格

| **项目** | **技术规格** |
| :--- | :--- |
| **队员人数** | **5人**/队（正式上场队员） |
| **预备队员** | 可配备1-2名预备队员，每支代表队总人数通常为5-7人[citation:2][citation:8] |
| **领队** | 1-2名领队（可由教师或学生担任）[citation:2] |
| **指导教师** | 人数不限 |
| **跨校组队** | 不允许跨校组队，须来自同一所学校[citation:2] |
| **参赛限制** | 曾获单项第一名的操纵手，不能再担任原获奖项目的操纵手 |

### 3.3 作品赛参赛要求

| **项目** | **技术规格** |
| :--- | :--- |
| **队员人数** | 个人或团队形式参赛 |
| **人员限制** | 作品赛参赛者不得同时担任团队赛选手或领队[citation:2] |
| **题目限制** | 同一高校报送的作品题目不得重复[citation:2] |
| **推荐限额** | 每校最多可提交**3项作品**参赛[citation:2] |

### 3.4 参赛经验要求

首次参赛的高校须先参加一次CUPT全国赛或区域赛的观摩，方可报名参赛[citation:2]。

## 四、赛制与赛程技术安排

### 4.1 三级赛制

CUPT采用校赛、区域赛（省赛）、全国总决赛三级赛制[citation:1][citation:3]。

| **级别** | **组织单位** | **晋级规则** |
| :--- | :--- | :--- |
| **校级选拔赛** | 各高校 | 选拔优秀队员组队参加区域赛[citation:3][citation:6] |
| **区域赛/省赛** | 各赛区组委会 | 选拔优胜队伍晋级全国总决赛 |
| **全国总决赛** | 全国CUPT组委会 | 决出全国奖项 |

| **校赛初赛/复赛** | 2025年12月 - 2026年4月 | 个人汇报/团队对抗 |

| **区域赛/省赛举办** | **2026年5月 - 6月** | 华东、华北、西北、中南等各赛区 |

## 五、竞赛规则与技术流程

### 5.1 团队对抗赛流程

每场正式比赛时长**47分钟**，由主持人计时，具体流程如下[citation:7]：

| **流程** | **限时（分钟）** |
| :--- | :--- |
| 反方挑战题目和正方准备 | 1 |
| 正方进行所选题的报告 | 12 |
| 反方向正方提问，正方回答 | 3 |
| 反方准备 | 2 |
| 反方的报告 | 3 |
| 正反方讨论 | 10 |
| 评论方提问，正、反方回答 | 3 |
| 评论方准备 | 2 |
| 评论方报告 | 3 |
| 正方总结发言 | 1 |
| 打分 | 2 |
| 裁判点评 | 5 |
| **总计** | **47** |

### 5.2 角色轮换规则

每支队伍在三轮对抗赛中，需分别担任正方、反方、评论方，每轮结束后进行角色轮换[citation:4]。

### 5.3 个人赛/初赛形式

多数高校采用“个人赛+团体赛”两阶段选拔模式[citation:3][citation:6]：

| **阶段** | **形式** | **提交材料** |
| :--- | :--- | :--- |
| **初赛（个人）** | 任选一题进行研究，提交PPT/录屏/研究报告 | 汇报PPT、录屏（8-10分钟）、研究报告[citation:6] |
| **复赛（团队）** | 5人组队，进行团体对抗赛 | 现场答辩[citation:3] |

### 5.4 作品赛规则

| **项目** | **技术规格** |
| :--- | :--- |
| **作品形式** | 电子版单页中文学术海报[citation:2] |
| **海报尺寸** | 宽度**90厘米**，高度**120厘米**[citation:2] |
| **文件格式** | PDF |
| **文件大小** | ≤ **10MB**[citation:2] |
| **匿名要求** | 不得出现学校名称、校徽、个人姓名、校训等可能影响评审公正性的信息[citation:2] |

## 六、评审技术指标

### 6.1 评审维度

| **评审维度** | **考察要点** |
| :--- | :--- |
| **物理本质的理解** | 对题目核心物理问题的把握程度 |
| **理论分析** | 模型的合理性、推导的严谨性 |
| **实验研究** | 实验设计的科学性、数据的可靠性 |
| **结论与讨论** | 结果的分析深度、误差讨论、改进方向 |
| **辩论水平** | 逻辑清晰度、临场应变、语言表达 |
| **团队协作** | 队员分工配合、角色履行情况 |

### 6.2 评委组成

| **级别** | **评委要求** |
| :--- | :--- |
| **区域赛** | 各参赛高校须推荐**2-3名**符合资质的教师担任裁判，需具备CUPT评审或观摩经验[citation:2] |
| **作品赛** | 参加作品赛的高校需推荐**2名**教师担任作品赛评委[citation:2] |

## 十、参赛注意事项

### 10.1 材料准备

| **事项** | **要求** |
| :--- | :--- |
| **PPT制作** | 内容应包括：题目剖析、理论分析、数值模拟、实验方案、结果讨论、结论、参考文献[citation:3][citation:6] |
| **海报制作** | 严格按照尺寸要求（90×120cm），确保匿名[citation:2] |
| **视频录制** | 部分高校需提交讲解录屏，时长8-10分钟[citation:6] |

### 10.2 学术诚信

| **要求项** | **技术规格** |
| :--- | :--- |
| **原创性** | 参赛作品必须是参赛团队原创，不得抄袭、盗用他人成果[citation:3][citation:6] |
| **引用规范** | 引用他人成果必须在报告中注明来源 |

### 10.3 退赛规定

若出现恶意退赛情况，将报CUPT全国组委会备案，并取消该校下一年度参赛资格[citation:2]。
