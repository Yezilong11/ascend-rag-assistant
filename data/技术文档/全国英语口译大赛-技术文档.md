# 全国英语口译大赛 参赛技术指南

## 一、赛事概述

**全国英语口译大赛**是由当代中国与世界研究院、北京第二外国语学院联合主办的国家级翻译类学科竞赛。大赛旨在加强新时代高水平翻译人才培养与选拔，推动人工智能时代翻译与语言服务行业创新发展，是国内最具权威性的英语口译赛事之一 [citation:1][citation:2]。

- **指导单位**：中国外文局、中国翻译协会
- **主办单位**：当代中国与世界研究院、北京第二外国语学院
- **承办单位**：北京市翻译协会、北京第二外国语学院高级翻译学院等
- **大赛官网**：https://www.lscat.cn/
- **官方微信公众号**：LSCAT

---

## 二、赛道设置与比赛形式

第十四届全国口译大赛设**学生赛道**和**人工智能赛道**。学生赛道涵盖英语和多语种（日语、法语、德语、俄语、朝（韩）语、西班牙语、阿拉伯语）[citation:2]。

### 2.1 英语口译大赛

| **比赛项目** | **赛制** | **晋级机制** |
| :--- | :--- | :--- |
| **交替传译** | 初赛、复赛、决赛三级赛制 | 初赛优胜者参加复赛；复赛优胜者参加决赛；决赛分为淘汰赛与精英赛，淘汰赛前10名晋级精英赛 [citation:2] |
| **同声传译** | 选拔赛、决赛两级赛制 | 选拔赛前20名晋级决赛 [citation:2] |

### 2.2 多语种口译大赛

| **比赛项目** | **赛制** | **晋级机制** |
| :--- | :--- | :--- |
| 日语交传、日语同传、法语交传、德语交传、俄语交传、朝（韩）语交传、西班牙语交传、阿拉伯语交传 | 初赛、复赛、决赛三级赛制 | 初赛选拔15-20名进入复赛；复赛选出10名进入决赛 [citation:2] |

### 2.3 人工智能赛道

| **项目** | **技术规格** |
| :--- | :--- |
| **参赛对象** | 国内外人工智能和语言服务相关企业（每家企业限派1队） |
| **比赛形式** | 同声传译，分中译外和外译中两个方向 |
| **报名入口** | http://acic-ai.trs.com.cn:8090/register/home |
| **决赛规则** | 每个语种方向参赛企业超过6家时，先评审筛选前6名进入决赛，现场专家打分决定名次，过程对公众开放 [citation:2] |

## 七、评审技术指标

### 7.1 评分维度

| **维度** | **考察要点** |
| :--- | :--- |
| **信息完整性** | 原文信息点是否完整传达 |
| **语法准确性** | 译文的语法正确性、用词准确性 |
| **语言流畅性** | 表达流畅度、语流节奏 |
| **口译技巧** | 应对策略、笔记能力、临场应变 |

### 7.2 评分方式

| **阶段** | **评审形式** |
| :--- | :--- |
| **初赛/复赛** | 平台自动评分或专家线上评分 |
| **决赛** | 现场专家评审 |
