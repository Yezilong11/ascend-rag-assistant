# 中国大学生方程式系列赛事 参赛技术指南

## 一、赛事概述

**中国大学生方程式系列赛事**（Formula Student China，简称FSC）是由中国汽车工程学会主办，蔚来、吉利等国内外企业支持的全国性工程实践与科技创新竞赛[citation:2][citation:6]。赛事自2010年首届举办以来已成功举办十六年，被誉为“汽车工程师的黄埔军校”[citation:9]。2026赛季共有来自全球的**203支车队**（78支油车、86支电车、39支无人车）完成报名[citation:8]。

- **主办单位**：中国汽车工程学会
- **赛事官网**：http://www.formulastudent.com.cn/
- **英文官网**：http://formulastudent.sae-china.org
- **官方微信公众号**：中国大学生方程式汽车大赛

---

## 二、赛事构成与竞赛组别

2026赛季设置**三大核心竞赛**及**一个专项组别**：

| **赛事名称** | **组别代号** | **冠名赞助** | **拟比赛时间** |
| :--- | :--- | :--- | :--- |
| 中国大学生方程式汽车大赛（内燃机） | FSCC | 吉利杯 | 2026年11月3-8日[citation:2] |
| 中国大学生电动方程式大赛 | FSEC | 蔚来杯 | 2026年10月13-18日[citation:6] |
| 中国大学生无人驾驶方程式大赛 | FSAC | 蔚来杯 | 待定[citation:5] |
| **甲醇内燃机组** | FSCC-M | 吉利集团 | 同FSCC[citation:4] |

*注：甲醇内燃机组为2026赛季首次启动，首年限15支车队参赛[citation:4]。*

## 三、参赛资格与报名技术规范

### 3.1 会员资格要求

| **对象** | **会员类型** | **要求** |
| :--- | :--- | :--- |
| **参赛车队** | 中国汽车工程学会团体会员 | 报名时须为团体会员或报名成功后两个月内成为团体会员[citation:2][citation:6] |
| **指导教师及正式队员** | 中国汽车工程学会个人会员 | 必须成为个人会员[citation:2][citation:6] |

### 3.2 院校组队限制

| **组别** | **组队限制** |
| :--- | :--- |
| **燃油组（FSCC）** | 原则上每校仅允许一支车队报名；独立学院和异地校区可单独申请[citation:2] |
| **电动组（FSEC）** | 原则上每校仅允许一支车队报名；独立学院和异地校区可单独申请[citation:6] |
| **无人车组（FSAC）** | 以当年公告为准 |

### 3.3 报名时间节点

| **类别** | **车队类型** | **关键时间** |
| :--- | :--- | :--- |
| **模拟答题抢车号** | 境内车队 | 2026年3月7日 10:00-18:00[citation:2][citation:6] |
| **正式答题抢车号** | 境内燃油车队 | 2026年3月8日 09:30-11:30[citation:2] |
| **正式答题抢车号** | 境内电车队 | 2026年3月8日 13:30-16:30[citation:6] |
| **报名截止** | 境内车队 | 对应答题开始时间（即3月8日9:30/13:30）[citation:2][citation:6] |
| **报名截止** | 境外车队 | 2026年4月30日[citation:2][citation:6] |
| **参赛回执提交** | 所有晋级车队 | 车号确认后10个工作日内[citation:2][citation:6] |

### 3.4 车号确认机制

| **车队类型** | **车号获取方式** |
| :--- | :--- |
| 2025赛季总成绩前九名（燃油） | 直接获得1-9号车号[citation:2] |
| 2025赛季总成绩前十二名（电动） | 直接获得E01-E12车号[citation:6] |
| 其他境内车队 | 必须参与答题，按成绩获得车号[citation:2][citation:6] |
| 境外车队 | 可参与答题或按报名顺序顺延获得车号[citation:2][citation:6] |

### 3.5 2026赛季正式参赛规模

截至2026年3月9日，完成报名车队共计**203支**[citation:8]：
- **燃油组（FSCC）**：78支
- **电动组（FSEC）**：86支
- **无人车组（FSAC）**：39支

## 五、甲醇内燃机组（2026赛季新增）技术规范

为响应国家“双碳”战略目标，2026赛季正式启动甲醇内燃机组别，首年限制参赛车队**15支**[citation:4]。

### 5.1 发动机技术参数

吉利集团向首次参加甲醇组别并申请使用的车队支持**QJ467MU-2发动机**[citation:4]。

| **项目** | **技术规格** |
| :--- | :--- |
| 发动机型号 | QJ467MU-2[citation:4] |
| 排量 | 680cc[citation:4] |
| 发动机类型 | 直列四缸四冲程[citation:4] |
| 压缩比 | 11.5：1[citation:4] |
| 缸径×行程 | 67×48.2[citation:4] |
| 最大功率 | 67kW/11500rpm[citation:4] |
| 最大扭矩 | 64Nm/9000rpm[citation:4] |
| 供油系统 | 电喷[citation:4] |
| 冷却系统 | 水冷[citation:4] |
| 启动方式 | 电启动[citation:4] |
| 发动机重量（不含油） | 61kg[citation:4] |
| 支持数量 | ≤15台[citation:4] |

### 5.2 甲醇组技术规则（节选）

| **规则项** | **技术规格** |
| :--- | :--- |
| **发动机型号** | 可使用吉利支持的QJ467MU-2发动机，或自行选用其他型号进行醇化改造[citation:4] |
| **发动机排量** | 与汽油机一致（710cc以下）[citation:4] |
| **进气限流阀** | 内径不得大于20mm[citation:4] |
| **耐醇材料** | 燃油系统所有部件必须使用耐醇材料（不锈钢、PTFE、FKM、PEEK等），禁止使用普通尼龙、锌、镁、未经处理铝合金、复合纤维及不耐醇橡胶[citation:4] |
| **灭火器要求** | 至少配备一只抗醇类泡沫灭火器（标识“酒精”或AB类火灾）或其他B类灭火器[citation:4] |
| **效率测试** | 采用参赛车辆总能耗（燃料消耗体积×燃料密度×燃料低热值）进行排名计算[citation:4] |

### 5.3 甲醇燃料安全要求

| **安全项** | **要求** |
| :--- | :--- |
| **个人防护** | 操作甲醇燃料时，必须佩戴化学护目镜和耐化学品手套[citation:4] |
| **应急设施** | 维修区应配备紧急洗眼器和清水冲洗装置[citation:4] |
| **燃料操作** | 加注甲醇后，严禁在燃料加注区以外拆装燃料系统部件[citation:4] |
| **电气布置** | 所有线束、点火线圈等电气部件需远离燃油系统接头和通风口，做好防水防溅保护[citation:4] |

### 5.4 甲醇组专项支持

| **支持项目** | **金额/内容** | **说明** |
| :--- | :--- | :--- |
| **发动机支持** | QJ467MU-2发动机 | 首次参加甲醇组并申请使用的车队，支持1台[citation:4] |
| **李书福甲醇助力奖** | 5万元/队 | 参赛资格确认后一次性补助，首年预计15支车队[citation:4] |
| **甲醇内燃机技术奖** | 第1名10万，第2名8万，第3名7万 | 根据动态赛（直线加速、8字绕环、高速避障、耐久赛）成绩单独排名[citation:4] |
| **甲醇燃料安全培训** | 2026年4月 | 面向甲醇组车队开展专项技术培训[citation:4] |

*注：以上全部奖金均为税前金额[citation:4]。*
