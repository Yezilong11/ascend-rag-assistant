# 中国高校计算机大赛（C4）技术文档

## 一、赛事概述

**中国高校计算机大赛**（China Collegiate Computing Contest，简称C4）是由教育部高等学校计算机类专业教学指导委员会、教育部高等学校软件工程专业教学指导委员会、教育部高等学校大学计算机课程教学指导委员会、全国高等学校计算机教育研究会联合创办于2016年的一项国家级学科竞赛[citation:1]。2026年第十一届大赛由**全国高等学校计算机教育研究会**主办[citation:1][citation:7]。

### 1.1 办赛宗旨
大赛旨在促进高校计算机课程教学内容和教学方法改革，强化学生创新意识，提升学生计算机问题求解水平，增强学生计算机应用能力，培养团队合作精神，促进校际交流，丰富校园学术气氛[citation:3]。大赛始终坚持“**服务教学、推动教改、促进融合、引领创新**”的办赛理念[citation:3]。

### 1.2 赛事地位
大赛设立以来，产生广泛影响，多个系列赛入选中国高等教育学会“**全国普通高校大学生竞赛排行榜**”，并被众多高校列为本科生推免（推荐免试攻读研究生）的科技竞赛加分项目[citation:1][citation:4]。

### 1.3 组织机构
- **主办单位**：全国高等学校计算机教育研究会[citation:1][citation:2]
- **官方网站**：http://www.c4best.cn/ [citation:1]
- **各分项赛事**：由不同高校和企业联合承办（详见各赛项章节）

### 1.4 赛事构成（2026年）
2026年第十一届中国高校计算机大赛共包含**8个系列赛事**[citation:10]：

| **序号** | **赛事名称** | **官方网站/专题站** |
| :--- | :--- | :--- |
| 1 | 团体程序设计天梯赛 | http://gplt.patest.cn [citation:4] |
| 2 | 大数据挑战赛 | 详见官网通知 |
| 3 | 网络技术挑战赛 | http://net.c4best.cn [citation:1][citation:7] |
| 4 | 人工智能创意赛 | 详见官网通知 |
| 5 | 智能交互创新赛 | 详见官网通知 |
| 6 | **嵌入式设计赛** | http://www.c4best.cn/ [citation:2] |
| 7 | **AIGC创新赛** | http://aigc.vivo.com.cn [citation:5] |
| 8 | 移动应用创新赛 | 详见官网通知 |

下文将基于2026年最新官方通知，对各分项赛事的技术要求进行详细说明。

## 二、团体程序设计天梯赛

团体程序设计天梯赛聚焦程序设计能力与团队合作精神，是考察学生算法设计与编程实现能力的重要赛事[citation:4][citation:6]。

### 2.1 基本信息
- **第十一届比赛时间**：2026年4月18日 13:30-16:30[citation:4][citation:6]
- **主办单位**：全国高等学校计算机教育研究会[citation:4]
- **竞赛语言**：C、C++、Java、Python[citation:4][citation:6]
- **竞赛平台**：拼题A（Pintia）在线自动判题系统（https://pintia.cn）[citation:4][citation:6]

### 2.2 组别设置
竞赛分为2个组别[citation:4]：
- **珠峰争鼎**（本科组）
- **华山论剑**（本科组）

### 2.3 参赛要求
- **组队方式**：每支参赛队由**最多10名队员**组成，每名参赛队员必须是高校在册本科生[citation:4]
- **教练要求**：每支参赛队至少有1名教练，必须是高校正式教师[citation:4]
- **参赛限制**：每所高校报名参赛的队数不限，但只有**成绩最好的3支队伍**参与计分与评奖[citation:4]

### 2.4 竞赛内容
竞赛内容涵盖[citation:6]：
- 程序设计基础
- 数据结构
- 算法设计与分析

### 2.5 竞赛规则与计分机制

#### 题目结构
竞赛题目分3个梯级[citation:6][citation:9]：
| **梯级** | **题量** | **分值设置** | **满分** |
| :--- | :--- | :--- | :--- |
| **基础级** | 8道题 | 5分、10分、15分、20分的题各2道 | 100分 |
| **进阶级** | 4道题 | 每道题25分 | 100分 |
| **登顶级** | 3道题 | 每道题30分 | 90分 |

#### 核心规则
1. **独立解题**：参赛队员必须独立按照严格的输入输出要求提交每一题的解题程序[citation:6]
2. **得分机制**：每题得分为通过的指定测试用例得分之和；整场比赛得分为各题得分之和；程序可反复提交，取最高分，提交错误不扣分[citation:6]
3. **有效分规则**：
   - 只有当一支队伍的**基础题总分超过800分**时，该队进阶部分的题目分数才被判为有效[citation:6]
   - 只有当其**进阶题总分超过400分**时，该队登顶部分的题目分数才被判为有效[citation:6]
4. **先锋奖励**：在进阶和登顶阶段最先获得基础/进阶级满分，且获得进阶/登顶级任一题满分的前5位队员，分别依次获得**25、20、15、10、5分**的进阶/登顶“先锋奖励”。该奖励分数计入个人总分。当团队进阶或登顶成功后，也计入团队的有效分[citation:6]
5. **个人有效分**：只有当该队员的基础题总分超过80分时，其进阶部分的题目分数（包括奖励）才被判为对其个人有效；当其进阶题总分超过40分时，其登顶部分的题目分数（包括奖励）才被判为对其个人有效[citation:6]

#### 排名规则
- **团队排名**：根据所有队员的总有效得分进行排名。若多支队伍总有效分相同，则根据其**最高级别的有效分**进行排名；若还有并列，则根据其最高级别完整解决问题的总个数进行排名[citation:6]
- **个人排名**：参赛队员的个人排名由其个人获得的总分决定[citation:6]

#### 反作弊机制
命题组在比赛结束后对所有提交的代码进行**查重检验**，在24小时内提交检验合格报告。一所高校只要有一名队员有作弊行为，**该所高校全体队员成绩将被清零**。组委会将向该所高校通报作弊事件，并将作弊证据以适当方式公布[citation:6]

### 2.6 环境要求
- 参赛队员须自备笔记本电脑、手机支架以及竞赛所需的基本调试环境[citation:4]
- 竞赛现场除竞赛用机外，仅可以使用无计算功能的铅笔或水笔，以及空白草稿纸若干张[citation:4]
- 可以使用本地的代码调试工具，但仅可用于独立完成解题代码的现场编写、调试与提交[citation:4]

## 三、网络技术挑战赛

网络技术挑战赛聚焦网络技术与应用的快速发展，对接经济社会人才需求，服务于网络强国建设[citation:7]。

### 3.1 基本信息
- **第十一届比赛时间**：报名2026年3月4日启动，**2026年4月14日截止**[citation:1][citation:7]
- **中文名称**：中国高校计算机大赛-网络技术挑战赛
- **英文名称**：C4-Network Technology Challenge[citation:1][citation:7]
- **主办单位**：全国高等学校计算机教育研究会[citation:1][citation:7]
- **官方网站**：http://net.c4best.cn [citation:1][citation:7]
- **微信公众号**：c4-network[citation:7]

### 3.2 赛事定位
- **归属产业**：网络与信息产业[citation:7]
- **赛事品质**：入选中国高等教育学会“全国普通高校大学生竞赛排行榜”、“计算机类竞赛指数星级评价体系”四星级竞赛[citation:7]
- **承办单位**：温州大学、温州永嘉县人民政府、江苏省未来网络创新研究院[citation:7]

### 3.3 面向对象
高等学校计算机类、网络空间安全类、软件工程类、人工智能与智能制造类、电气信息类和其他相关专业本科学生与研究生[citation:1][citation:7]

### 3.4 参赛要求
- **组队规模**：以不少于**2名、不多于6名学生**组成的团队为参赛单位[citation:1][citation:7]
- **成员排序**：团队所有成员在报名时按对参赛作品的贡献度自行排序[citation:1][citation:7]
- **队长限制**：一位学生不能同时担任某赛项两个参赛团队的队长[citation:1][citation:7]
- **组队鼓励**：鼓励跨专业、跨学科与跨高校组建团队，鼓励境外高校组队参赛[citation:1][citation:7]
- **指导教师**：每支团队可有**1至2名指导教师**，允许有一名指导教师来自企业[citation:1][citation:7]
- **组别划分**：竞赛分为**本科生和研究生两个组别**，以所有成员中的最高学籍学历（在报名时）作为参赛团队分组的依据[citation:1][citation:7]

### 3.5 竞赛内容与形式

#### 竞赛系列
竞赛分为**创意（A）、攻关（B）** 两大系列[citation:1][citation:7]：

| **系列** | **赛项** | **说明** |
| :--- | :--- | :--- |
| **创意（A）系列** | 普通A赛项 | 不限领域与主题 |
| | A-ST赛项 | 专为“网络空间与信息安全”单独设置 |
| | A-ICV赛项 | 专为“车联网与交通智能网联”单独设置 |
| **攻关（B）系列** | B-EP1赛项 | 未来网络的“智能体互联网创新攻关赛项”（企业参与规划） |

#### 创意（A）系列技术要求
A系列的作品选题须至少关联以下网络技术分支之一[citation:7]：
- 网络智能、软件定义网络、云计算、边缘计算
- IPv6网络、云中开放网络软件、物联网、工业互联网
- 车联网、算力网络、网络安全、网络数据分析等

可以是网络技术的发明与创造，或网络系统的研究、设计、开发、部署与管理，或将网络与IT技术用于解决经济社会各领域关注的应用热点或难点问题，鼓励体现学科交叉融合的选题[citation:7]

#### 作品要求
1. 按不同系列进行选题，挑战赛阶段的最终作品为**可用的系统、实物或软件**[citation:7]
2. 在作品选题或应用领域、设计思想或方法、技术开发与应用等方面有不同程度的开拓或创新[citation:7]
3. 作品的主要研究、设计与开发工作须由参赛团队成员独立完成，**不存在任何侵犯他人知识产权**的问题，且未曾在任何其他赛事中获得过全国性奖项[citation:7]
4. 严禁作品涉及不健康、淫秽、色情等违规（法）内容[citation:7]

### 3.6 竞赛阶段与评审

#### 三个阶段
竞赛分为三个阶段[citation:7]：
1. **资格赛**：线上评审
2. **选拔赛**：线上评审
3. **挑战赛**：现场评审

#### 评审方式
- 选拔赛和挑战赛阶段的作品评审一律以“**双盲**”方式进行[citation:7]
- A系列作品的评价标准包括：创意、技术、应用、设计、效果[citation:7]

#### 晋级规则
- **A系列**：资格赛阶段确定晋级选拔赛的规模；选拔赛阶段，各赛区本科组第1名和研究生组第1名作品晋级挑战赛（前提是作品评审成绩全国排序须位于前三分之一）[citation:7]
- **B系列**：资格赛和选拔赛由组委会组织评审，每校资格赛不设报名数额限制，每校入围同一个赛项选拔赛的作品数不超过10项[citation:7]

### 3.7 奖项设置

#### A系列奖项[citation:7]
- **选拔赛**：按赛区单独设置，分别按照赛区参赛规模的10%、20%和40%比例确定一、二、三等奖并颁发电子证书
- **挑战赛**：设特等奖不超过2名，一、二、三等奖若干

#### B系列奖项[citation:7]
- **选拔赛**：按赛区单独设置，比例同上
- **挑战赛**：设一、二、三等奖若干，各赛项特等奖由组委会视第1名作品质量决定是否设置

#### 特别奖励[citation:7]
- **“英才计划”奖赏**：报名B-EP1赛项的团队可获得未来网络的相关线上学习与培训服务；晋级B-EP1赛项挑战赛的团队可获得暑期“英才创新特训营”入营资格
- **“优秀指导教师”奖**：指导学生团队获本届竞赛挑战赛特等奖、一等奖，或指导2支以上学生团队进入本届竞赛挑战赛的教师可获得候选资格

### 3.8 时间安排[citation:7]
| **阶段** | **时间** |
| :--- | :--- |
| 竞赛报名 | 2026年3月4日 - 4月14日 |
| 资格赛作品提交 | 截止至2026年4月30日 |
| 资格赛评审 | 2026年5月 |
| 选拔赛作品提交 | 截止至2026年6月15日 |
| 选拔赛评审 | 2026年6-7月 |
| 挑战赛/总决赛 | 2026年8月中下旬 |

### 3.9 报名费用[citation:7]
- 资格赛：**不收取报名费**
- 选拔赛：每项作品收取报名费**600元**
- 挑战赛：不收取报名费，交通及食宿费用自理

## 四、嵌入式设计赛

嵌入式设计赛是中国高校计算机大赛里**唯一以硬件为主、软硬件结合**的赛事，聚焦嵌入式人工智能人才培养[citation:2][citation:3]。

### 4.1 基本信息
- **第三届（2026年）时间**：报名截止**2026年5月10日**[citation:2]
- **主办单位**：全国高等学校计算机教育研究会[citation:2]
- **承办单位**：北京工业大学、中国电子学会嵌入式系统与机器人分会[citation:2][citation:3]
- **支持单位**：北京博创智联科技有限公司[citation:2]
- **官方网站**：http://www.c4best.cn/ [citation:2]
- **报名网址**：https://www.cie-eec.cn [citation:2]
- **微信公众号**：C4-Embed[citation:2]

### 4.2 赛事背景
嵌入式设计赛起源于2005年创办的“**博创杯**”全国大学生嵌入式设计大赛，2024年正式更名为现名。二十多年来，大赛为促进我国高校嵌入式人工智能、物联网、AI机器人技术教育的发展做出了突出贡献[citation:2][citation:3]。

### 4.3 参赛要求
- **参赛单位**：以参赛高等院校为基本单位[citation:2]
- **参赛队规模**：每支队伍参赛指导老师**1-2人**，参赛队员**1-3人**[citation:2]
- **总决赛限额**：各高校总决赛参赛队伍数量**不得超过5支**[citation:2]
- **参赛资格**：参赛队员必须具有正式学籍的全日制在校专科生、本科生、研究生[citation:2]
- **人员固定**：自报名至比赛期间，参赛队员不得随意更换[citation:2]

### 4.4 赛项设置[citation:2]
1. **标准赛项**
2. **龙芯专项赛**
3. **捡乒乓球机器人专项赛**

### 4.5 竞赛平台
为使大赛更加规范统一，参赛队伍须使用大赛支持单位的平台设计作品并参赛[citation:2]：

| **赛项** | **推荐平台** |
| :--- | :--- |

配套学习资源[citation:2]：
- **魔法学院**：http://www.magic-college.com（大量学习视频）
- **魔法师商城**：https://shop322553369.taobao.com（丰富的硬件平台）

### 4.6 命题方式
本赛事采用**开放式命题**的形式，涉及内容可覆盖[citation:2]：
- 嵌入式、人工智能系统设计，硬件、软件、系统等
- 嵌入式、人工智能系统应用展示：AI机器人、智能交通、智能装备、智能制造、智能家居、工业应用、医疗卫生等领域
- 嵌入式AIoT应用：城市交通，医疗，港口物流，环境监测，多网融合等

### 4.7 作品要求
- **原创性**：作品必须为原创，且不能在其它同类赛事中参评[citation:2]
- **查重机制**：大赛设置查重环节，若参赛作品与往年作品高度相似，组委会将取消参赛资格[citation:2]
- **作品形式**：参赛作品需以**实物作品**的形式参赛，进行公开展示、现场评审[citation:2]

| 全国总决赛 | 2026年7月（具体时间待定） |

## 五、AIGC创新赛

AIGC创新赛聚焦人工智能生成内容（AIGC）的创新应用，由南开大学与vivo公司联合承办，以vivo自研通用大模型矩阵为技术底座[citation:5]。

### 5.1 基本信息
- **第三届（2026年）**：由南开大学与vivo公司联合承办[citation:5]
- **官方网站**：http://aigc.vivo.com.cn [citation:5]
- **面向对象**：全国（含港澳台）高校在校学生，不限专业[citation:5]

## 七、通用参赛指南

### 7.1 报名方式
1. **访问官网**：http://www.c4best.cn/ 了解各赛事详情[citation:1]
2. **选择赛项**：根据专业背景和兴趣选择对应的分项赛事

### 7.2 参赛注意事项
1. **人员固定**：报名成功后，参赛团队成员原则上不得随意更换[citation:7]
2. **原创承诺**：所有作品必须为原创，不存在侵犯他人知识产权的问题[citation:2][citation:7]
3. **查重机制**：多个赛项设有查重环节，与往年作品高度相似将被取消资格[citation:2][citation:6]
4. **双盲评审**：选拔赛和挑战赛阶段的作品评审一律以“双盲”方式进行[citation:7]
