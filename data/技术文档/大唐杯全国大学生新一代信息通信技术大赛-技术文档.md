# “大唐杯”全国大学生新一代信息通信技术大赛 参赛技术指南

## 一、赛事概述

**“大唐杯”全国大学生新一代信息通信技术大赛**（2026年正式更名为**“大学生新一代信息通信科技大赛”**，简称“信科赛”）是由工业和信息化部人才交流中心、中国通信企业协会、中信科移动通信技术股份有限公司联合主办的国家级学科竞赛[citation:2][citation:5]。大赛已连续多年列入中国高等教育学会“全国普通高校大学生竞赛分析报告”，是国内信息通信领域最具权威性的创新竞赛品牌之一[citation:5][citation:10]。

- **主办单位**：工业和信息化部人才交流中心、中国通信企业协会、中信科移动通信技术股份有限公司[citation:2]
- **承办单位**：北京邮电大学、电子科技大学、天津大学、北京航空航天大学等[citation:2]
- **大赛官网**：https://dtcup.dtxiaotangren.com/[citation:3][citation:6]
- **赛事宗旨**：围绕信息通信领域真标准创新、真设备实践、真问题解决、真场景应用、真行业赋能设置竞赛内容[citation:5]

---

## 二、赛道设置与技术参数

第十三届大赛设置**三个赛道**，各赛道技术方向与参数如下：

### 2.1 赛道一：工程实践赛

本赛道以信息通信工程项目流程、5G-A关键技术、6G关键技术、人工智能技术为核心，融合无线通信网络工程实践、星地一体网络工程实践，推动通感算智一体化、确定性网络、新型物联、高容量通信等技术创新应用[citation:1][citation:2]。

| **项目** | **技术规格** |
| :--- | :--- |
| **参赛人数** | 2人/组 |
| **组别设置** | 本科A组（全部院校）、本科B组（普通本科院校）、研究生组 |
| **省赛获奖比例** | 一等奖≤7%、二等奖≤15%、三等奖≤25% |
| **国赛获奖比例** | 一等奖≤7%、二等奖≤10%、三等奖≤15% |
| **竞赛平台** | 大赛提供的专用平台 |
| **竞赛依据** | 《工程实践赛竞赛大纲》 |

### 2.2 赛道二：产教融合5G+创新应用赛

本赛道以信息通信技术创新应用为核心，以信息通信产品开发设计流程和经济决策分析为主线，以5G、5G-A关键技术融合人工智能或大数据等技术赋能低空智联网、智能网联车、智能制造等行业特色应用为导向[citation:1][citation:3]。

| **项目** | **技术规格** |
| :--- | :--- |
| **参赛人数** | 4-6人/组（指定一名队长） |
| **专业要求** | 至少由2个不同专业学生组成 |
| **赛项数量** | 5个专项赛 |
| **省赛获奖比例** | 一等奖≤15%、二等奖≤20%、三等奖≤25% |
| **国赛获奖比例** | 一等奖≤15%、二等奖≤20%、三等奖≤25%、优胜奖≤30% |
| **开发平台** | 指定虚拟仿真软件 + 推荐硬件（组包） |
| **竞赛依据** | 《产教融合5G+创新应用赛说明》 |

#### 五个专项赛[citation:1][citation:2][citation:3]
| **赛项** | **技术方向** |
| :--- | :--- |
| 赛项一 | 软件无线电创新设计 |
| 赛项二 | 射频电路系统开发设计 |
| 赛项三 | 智能网联车创新设计 |
| 赛项四 | 智能制造创新设计 |
| 赛项五 | 行业垂直应用综合设计（5G+低空经济、5G+人工智能、移动信息网络安全） |

### 2.3 赛道三：ICT基础通识赛

本赛道以电路分析、数字电子技术、模拟电子技术、数字信号处理、信号与系统、通信原理等基础知识为核心，用虚拟仿真方式设计并编程实现基本通信系统或电路系统[citation:1][citation:4]。

| **项目** | **技术规格** |
| :--- | :--- |
| **参赛人数** | 2人/组 |
| **组别设置** | 不区分组别 |
| **省赛获奖比例** | 一等奖≤7%、二等奖≤15%、三等奖≤25% |
| **国赛获奖比例** | 一等奖≤7%、二等奖≤10%、三等奖≤15% |
| **竞赛平台** | 虚拟仿真平台 + 编程平台 |
| **竞赛依据** | 《ICT基础通识赛说明》 |

## 三、参赛资格技术规范

### 3.1 参赛对象

| **类别** | **面向对象** |
| :--- | :--- |
| **本科生** | 电子信息类、计算机类、自动化类、工商管理类等相关专业全日制在读本科生[citation:6] |
| **研究生** | 信息与通信工程、软件工程、电子信息等学科专业在读研究生[citation:6] |

### 3.2 组队技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **指导教师** | ≤2名/组，同一教师可指导多组[citation:1][citation:4] |
| **跨校组队** | 不同学校的学生不可联合组队[citation:1][citation:3] |
| **多赛道报名** | 参赛选手可同时报名所有赛道[citation:1][citation:3] |
| **校内组数上限** | 工程实践赛每校≤300组[citation:1][citation:2] |

### 3.3 各赛道组队限制

| **赛道** | **组队限制** |
| :--- | :--- |
| **工程实践赛** | 只能报名一个赛事组别，不可在本赛道内重复组队[citation:1] |
| **产教融合5G+创新应用赛** | 仅限报名一个赛项，不可重复组队[citation:2] |
| **ICT基础通识赛** | 不可在本赛道内重复组队[citation:1] |

### 3.4 留学生组特殊要求

| **赛道** | **留学生组要求** |
| :--- | :--- |
| **工程实践赛** | 参赛选手须全部为留学生[citation:2][citation:3] |
| **产教融合5G+创新应用赛** | 每队最多包含1名中国籍学生[citation:2][citation:3] |

### 8.1 学术诚信要求

| **要求** | **说明** |
| :--- | :--- |
| **原创性** | 参赛作品须遵守学术诚信规范，不得剽窃、抄袭他人学术成果[citation:1] |
