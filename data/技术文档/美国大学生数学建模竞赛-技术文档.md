# 美国大学生数学建模竞赛 参赛技术指南

## 一、赛事概述

**美国大学生数学建模竞赛**（Mathematical Contest in Modeling, MCM®）与**交叉学科建模竞赛**（Interdisciplinary Contest in Modeling, ICM®）是由美国数学及其应用联合会（COMAP）主办的国际性大学生学科竞赛。竞赛旨在挑战学生团队在有限时间内分析、建模、解决开放式应用问题，并提交完整的解决方案报告。

- **主办单位**：美国数学及其应用联合会（COMAP）
- **竞赛官网**：https://www.comap.com/contests/mcm-icm
- **注册官网**：https://www.contest.comap.com/undergraduate/contests/
- **赞助机构**：美国数学协会（MAA）、工业与应用数学学会（SIAM）、美国统计协会（AMSTAT）、美国数学学会（AMS）、运筹学与管理科学研究所（INFORMS）

## 三、赛题设置与技术方向

竞赛设**6个问题选择**，涵盖不同数学建模方向：

### 3.1 MCM赛题（数学建模竞赛）

| **题号** | **类型** | **技术方向** |
| :--- | :--- | :--- |
| **Problem A** | 连续型 | 连续数学模型、微分方程、连续系统仿真 |
| **Problem B** | 离散型 | 离散数学模型、组合优化、离散系统仿真 |
| **Problem C** | 数据洞察 | 数据分析、统计建模、机器学习、数据挖掘 |

### 3.2 ICM赛题（交叉学科建模竞赛）

| **题号** | **类型** | **技术方向** |
| :--- | :--- | :--- |
| **Problem D** | 运筹学/网络科学 | 运筹优化、网络分析、图论、复杂网络 |
| **Problem E** | 可持续发展 | 环境建模、可持续性评估、政策分析 |
| **Problem F** | 政策研究 | 政策建模、决策分析、社会系统建模 |

### 7.2 报名流程

| **步骤** | **操作说明** |
| :--- | :--- |
| **1. 指导教师注册** | 指导教师创建账户，填写学校信息 |
