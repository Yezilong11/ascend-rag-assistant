# 霍普杯2025国际大学生建筑设计竞赛 参赛技术指南

## 一、赛事概述

**霍普杯国际大学生建筑设计竞赛**始于2012年，由国际建筑师协会（UIA）任国际主办，天津大学建筑学院、《城市 环境 设计》（UED）杂志社任主办单位，是由霍普股份独家赞助的面向国际建筑高校大学生的年度建筑设计竞赛。每届竞赛的评委会主席由一名国际著名建筑大师担任，竞赛评委为来自国内外的著名建筑师及学院院长。

- **国际主办**：国际建筑师协会（UIA）
- **主办单位**：天津大学建筑学院、《城市 环境 设计》（UED）杂志社
- **独家赞助**：霍普股份
- **竞赛官网**：https://hypcup.uedmagazine.net/

## 二、参赛资格技术规范

### 2.1 参赛对象

| **类别** | **技术规格** |
| :--- | :--- |
| **学历要求** | 经教育部认证的建筑及相关专业学生：全日制本科生、硕士研究生（全日制及含2023年之后的非全日制研究生）、全日制博士研究生、2025年毕业的学生 |
| **参赛形式** | 个人或小组形式参赛 |
| **组别划分** | 以就读高校划分：中国大陆高校属国内组，中国港澳台地区及国际高校属国际组；国内外组员混合参赛按国内组报名 |

### 2.2 组队技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **队员人数** | ≤4人/组 |
| **指导教师** | ≤2名，须为高校在职教师 |
| **组长职责** | 小组组长负责联络，组员不予联络 |
| **每人限报** | 每位参赛者限报名一个参赛小组 |
| **每队限报** | 各小组提交一组参赛作品，严禁重复提交 |

## 四、作品技术规范

### 4.1 图纸技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **图纸数量** | 3幅 |
| **图纸尺寸** | A1（841mm×594mm） |
| **版面方向** | 横向排版 |
| **文件格式** | JPG |
| **分辨率** | ≥300dpi |
| **文件命名** | 作品名称-图1 / 作品名称-图2 / 作品名称-图3 |
| **设计说明** | 500字左右，组合于图面之中 |

### 4.2 视频技术规格

| **项目** | **技术规格** |
| :--- | :--- |
| **文件格式** | MP4 |
| **时长限制** | ≤2分钟 |
| **字幕要求** | 须配有英文字幕 |
| **匿名要求** | 不得出现任何有关作者姓名和所在院校的文字或图案 |
| **文件命名** | 作品名称-影片 |

### 4.3 文本资料技术规格

| **材料名称** | **内容要求** | **备注** |
| :--- | :--- | :--- |
| **原创声明** | 小组每个成员均需签名 | 官网“下载文件”中下载模板 |
| **身份证明** | 中国大陆学生：身份证扫描件；港澳台及国际学生：护照扫描件 | 可辨认的扫描件 |
| **学生证明** | 学生证电子扫描件 | — |
| **作者信息文本** | TXT格式，包含作者姓名、报名序列号、电子邮箱、通讯地址、手机号码、QQ/微信号、指导教师姓名及联系方式、学校及院系全名、作品名称及简要设计说明 | 需中英文双语版本，以设计者姓名命名 |

### 4.4 文件提交结构

| **文件夹名称** | **包含内容** |
| :--- | :--- |
| **（1）图纸** | 三张JPG图纸 |
| **（2）影片** | MP4视频文件 |
| **（3）身份证明** | 身份证/护照及学生证扫描件 |
| **（4）文本** | 作者信息文本（TXT）+ 原创声明 |

### 4.5 打包提交要求

| **项目** | **技术规格** |
| :--- | :--- |
| **压缩格式** | ZIP 或 RAR |
| **总大小** | 50M - 150M |
| **提交邮箱** | uedmedia@163.com |
| **邮件标题格式** | 参赛作品标题（中英文作品名都需有）+ 报名序列号 |

### 4.6 语言要求

| **项目** | **技术规格** |
| :--- | :--- |
| **官方语言** | 英文（必须提供英文作品名，内容至少包含全英文表达的设计说明） |
| **中国大陆学生** | 可提供中文和英文双语作品 |
| **港澳台及国际学生** | 提供英文作品 |

### 4.7 单位要求

- 比例与尺寸一律采用**公制单位**

### 4.8 匿名要求

- 电子图纸及视频中**不得出现任何有关作者姓名和所在院校的文字或图案**，不符合规定者将被取消参赛资格
