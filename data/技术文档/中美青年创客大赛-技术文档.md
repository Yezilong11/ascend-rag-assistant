# 中美青年创客大赛 技术文档

## 一、赛事概述

**中美青年创客大赛**（China-US Young Maker Competition）由**中华人民共和国教育部**主办，是中美人文交流高层磋商机制的成果之一[citation:1]。大赛致力于搭建跨文化共创平台，深化两国人文交流，通过融合中美文化视角与跨界合作，鼓励青年创客以首创精神为核心，共同开发解决社会问题的创新原型[citation:1]。

### 1.1 办赛宗旨
大赛以“**共创未来**”为主题，鼓励参赛者结合未来思维和设计创新，运用前沿科技和开源工具，打造兼具社会意义和产业价值的全新作品[citation:1]。大赛强调开源共享文化、引导创意向实际应用转化，推动两国青年关注人类未来福祉，促进中美创客文化与生态的共同建设[citation:1]。

### 1.2 组织机构[citation:1]
- **主办单位**：中华人民共和国教育部
- **承办单位**：中国（教育部）留学服务中心、清华大学、北京歌华文化发展集团有限公司、中国大学科技园联盟及美方有关合作方

### 1.3 赛事官方网站
- **官方主页**：https://chinaus-maker.cscse.edu.cn/

## 二、竞赛主题与方向

### 2.1 年度主题
大赛以“**共创未来**”为核心主题，探索以下可持续发展领域的创新机遇[citation:1]：
- 韧性社区
- 环境教育
- 低碳环保
- 食物系统
- 危机应对
- 公共卫生
- 健康福祉
- 清洁能源
- 气候变化
- 绿色交通
- 循环经济

### 2.2 技术导向
鼓励参赛选手应对**人工智能的新趋势**，开发前瞻性解决方案，推进社会数智化转型，助力全球可持续发展[citation:1]。

## 三、参赛资格与组队要求

### 3.1 参赛对象
中美两国高校在校学生及青年创客[citation:1]。

### 3.2 组队方式
- **团队规模**：以团队形式参赛，具体人数要求请参照当年各分赛区通知
- **成员构成**：鼓励跨学科、跨专业组队，融合不同背景的创意与技术能力

## 五、作品要求

### 5.1 基本要求
1. **原创性**：作品必须为原创，具有创新性和实用性
2. **知识产权**：作品不得侵犯他人知识产权，未曾在其他赛事中获得过全国性奖项
3. **表现形式**：作品原型应呈现为实现一定创新功能的智能硬件或软件[citation:1]

### 5.2 技术导向
- 鼓励使用**开源硬件和软件**进行开发
- 鼓励结合**人工智能、物联网、大数据**等前沿技术
- 鼓励体现**跨学科交叉融合**的创新思维

### 5.3 提交材料
参赛团队需提交以下材料：
| **材料名称** | **内容要求** |
| :--- | :--- |
| **作品说明文档** | 详细阐述作品的设计理念、技术方案、创新点、实现过程及应用价值 |
| **演示视频** | 清晰展示作品的功能、操作流程和运行效果（通常要求MP4格式，3-5分钟） |
| **作品原型/样机** | 总决赛现场需进行实物演示 |

## 六、评审标准

大赛评委通常从以下维度对作品进行综合评估：

| **评审维度** | **说明** |
| :--- | :--- |
| **创新性** | 设计理念、技术方法的独创性 |
| **实用性** | 对现实问题的解决能力和应用价值 |
| **技术完成度** | 作品原型的实现程度和运行稳定性 |
| **社会价值** | 对可持续发展目标的贡献 |
| **跨文化融合** | 中美青年合作元素的体现（特别加分项） |
| **现场表现** | 演示效果、答辩逻辑 |

## 七、奖项设置

### 7.1 分赛区奖项
各分赛区根据参赛规模设置一、二、三等奖及优秀奖，具体比例由各赛区组委会确定。

### 7.2 全国总决赛奖项
全国总决赛设：
- **特等奖**：不超过2名
- **一等奖**、**二等奖**、**三等奖**：若干名
- **优秀指导教师奖**：表彰突出指导老师
- **优秀组织奖**：表彰突出贡献单位

## 八、报名与联系方式

### 8.1 官方渠道
- **大赛官网**：https://chinaus-maker.cscse.edu.cn/
- **主办单位**：中华人民共和国教育部
- **承办单位**：中国（教育部）留学服务中心

### 8.2 报名流程
1. 访问大赛官网，查看当届赛事通知
2. 根据所在地区选择对应的分赛区
3. 在规定时间内完成在线报名
4. 提交作品说明文档和演示视频
5. 关注分赛区选拔结果和总决赛通知

### 8.3 参赛费用
- 大赛不收取报名费
- 总决赛交通及食宿费用由参赛团队自理或由学校支持（具体以当年通知为准）

---

## 九、知识产权说明

1. **原创性承诺**：参赛作品必须为原创，不得侵犯他人知识产权
2. **权利归属**：作品的著作权归参赛团队所有
3. **大赛权利**：主办方享有对参赛获奖作品进行宣传、展示、汇编和出版的权利
