# 全国大学生创新年会 参赛技术指南

## 一、赛事概述

**全国大学生创新年会**（简称“大创年会”）由教育部发起并主办，是依托“国家级大学生创新创业训练计划”（简称“国创计划”）开展的一项重要年度性展示交流活动。自2008年至今已连续举办十八届，是全国高校本科教育教学改革中覆盖面最广、影响力最大、学生参与最多、水平最高的盛会之一。年会优秀参展项目已纳入《全国普通高校学科竞赛排行榜》，是展示高校创新教育成果的重要平台[citation:1][citation:3][citation:5]。

- **主办单位**：教育部高等教育司
- **依托计划**：国家级大学生创新创业训练计划（“国创计划”）
- **第十八届承办单位**：南京大学（苏州校区）
- **大赛官网**：http://gjcxcy.bjtu.edu.cn/
- **年会主题（第十八届）**：创无止境·“新”潮澎湃[citation:1][citation:5]

## 二、参展类别与内容

### 2.1 三大参展类别

年会议**三大类别**进行项目遴选和交流展示[citation:2][citation:10]：

| **类别** | **遴选数量** | **交流形式** | **核心定位** |
| :--- | :--- | :--- | :--- |
| **学术论文** | 约200篇 | 学术报告会 | 反映学术研究情况，按学科分组报告 |
| **改革成果项目** | 约250项 | 展板+实物展示 | 展示创新创业项目成果，现场交流 |
| **创业推介项目** | 约60项 | 项目推介会 | 推介创业项目，宣传和交流 |

### 2.2 第十八届年会规模（参考）

第十八届全国大学生创新年会共收到来自部属高校和地方教育主管部门推荐的项目**1030项**，其中[citation:5][citation:7]：
- 学术论文：443篇
- 改革成果项目：462项
- 创业推介项目：125项

经专家初审及“国创计划”专家工作组复审，最终遴选出：
- 学术论文：200篇
- 改革成果展示项目：250项
- 创业推介项目：60项
- **共计510项**集中代表全国高校创新教育最新成果[citation:5][citation:7]

## 三、学术论文技术规范

### 3.1 论文来源要求

| **要求项** | **技术规格** |
| :--- | :--- |
| **项目来源** | 须来源于“国创计划”项目组，标注“国创计划”项目编号[citation:2] |
| **第一作者** | 必须是参加“国创计划”的本科生（项目已完成并继续攻读研究生的学生，原则上只允许一年级研究生参加年会）[citation:2][citation:8] |
| **已发表论文** | 如已在正式出版物上发表且标明了获得“国创计划”资助，推荐时须标明发表的刊物名称等相应信息，并提交PDF格式原文附件[citation:2][citation:8] |

### 3.2 论文内容与格式要求

| **项目** | **技术规格** |
| :--- | :--- |
| **字数限制** | **不超过5000字**（含图表）[citation:2][citation:8] |
| **语言要求** | 中文撰写；如已在外文期刊发表，须按学术论文格式用中文重新整理，中外文论文的作者、标注和内容须一致，并附上已发表论文的期刊封面、目录和外文原文[citation:2][citation:8] |
| **内容要求** | 主要反映学术研究情况（包括研究目的、方法、主要观点及结论等），由本科生为主完成[citation:2][citation:8] |
| **标注要求** | 须在首页或致谢部分按规定标注：“国家级大学生创新训练计划支持项目（项目批准号）”[citation:2][citation:8] |
| **查重要求** | 学校须对申报论文严格把关，做好查重查新工作，确保无抄袭、作假现象[citation:2][citation:8] |

### 3.3 学术论文交流形式

| **项目** | **技术规格** |
| :--- | :--- |
| **分组方式** | 按学科分成10组，分组进行论文报告交流[citation:2] |
| **主持形式** | 大学生创新学术年会分会场由**学生主持**[citation:2] |
| **报告时间** | 每个报告**15分钟**（论文作者报告10分钟，参会代表讨论3分钟，专家点评2分钟）[citation:2] |
| **优秀论文评选** | 每组由专家遴选出本组2项优秀论文，共选出20篇，由年会组织机构颁发证书[citation:2][citation:5] |

## 四、改革成果项目技术规范

### 4.1 成果项目来源要求

| **要求项** | **技术规格** |
| :--- | :--- |
| **项目来源** | 须来源于“国创计划”项目组，标注“国创计划”项目编号[citation:2] |
| **第一完成人** | 必须是参加“国创计划”的本科生（项目已完成并继续攻读研究生的学生，原则上只允许一年级研究生参加年会）[citation:2][citation:8] |
| **专利要求** | 申请或获得专利的项目，专利申请人或发明人需有参加项目的本科生[citation:2][citation:8] |

### 4.2 成果形式要求

改革成果项目应有明显的成果形式，包括但不限于[citation:8]：
- 论文、实物、软件、服务平台等
- 有其他参赛获奖
- 对专业技术问题和社会发展问题有重大改进和政策建议
- 有较强实用价值

### 4.3 展板内容技术规格

每个项目组1个展位，展位提供包括但不限于以下信息[citation:2]：

| **信息项** | **内容要求** |
| :--- | :--- |
| **项目类型** | 创新训练项目、创业训练项目或创业实践项目 |
| **项目名称** | 全称 |
| **项目编号** | 须标注“国创计划”项目编号 |
| **项目简介** | **200字左右** |
| **图片（含图表）** | 2-3张，要求有图注（不超过20字） |
| **创新点描述** | **100字左右** |
| **项目成员信息** | 姓名、年级、专业 |
| **项目指导教师信息** | 姓名、职称、研究方向 |
| **立项年份** | — |
| **参赛获奖记录** | 参加竞赛名称、获奖时间、奖励级别、获奖作品形式 |

### 4.4 评选方式

| **奖项** | **评选方式** | **数量** |
| :--- | :--- | :--- |
| **我最喜爱的项目** | 由学生代表投票选出[citation:2] | 20项[citation:5] |
| **最佳创意项目** | 由高校教师和参会专家投票，结合评审专家投票选出[citation:2] | 20项[citation:5] |

## 五、创业推介项目技术规范

### 5.1 项目来源要求

| **项目类型** | **内容要求** |
| :--- | :--- |
| **创业实践项目** | 企业（团队）简介、项目实践程度、项目市场表现、项目成果（注册资本、盈利能力、员工数量、业务范围、企业运营状况等）、与预期目标比较说明、下一步发展计划、创业历程与感悟[citation:2] |
| **创业训练项目** | 团队简介、模拟创业经历、主要业务或产品、与预期目标比较说明、下一步发展计划、对项目参与学生能力培养、项目所取得的研究成果（论文、作品或专利）[citation:2] |

### 5.2 人员要求

| **要求项** | **技术规格** |
| :--- | :--- |
| **项目完成人** | 项目主要完成人是参加“国创计划”的本科生（或已经毕业4年内的毕业生）[citation:2] |
| **团队负责人/企业法人** | 创意团队、初创企业和成长企业的团队负责人或企业法人参加过“国创计划”[citation:2][citation:8] |

### 5.3 内容要求

| **项目** | **技术规格** |
| :--- | :--- |
| **内容简介字数** | **不超过5000字**（含图表）[citation:2] |
| **真实性要求** | 学校须对简介严格把关，保证内容的真实性，优先推荐创业实践项目[citation:2] |
| **商业模式要求** | 商业模式完整、可行，盈利能力合理；在机会识别与利用、竞争与合作、技术基础、产品或服务设计、资金及人员需求、现行法律法规限制等方面具有可行性[citation:8] |

### 5.4 推介会形式

| **项目** | **技术规格** |
| :--- | :--- |
| **参会人数** | 每个项目选派1-2名学生参加[citation:2] |
| **交流时间** | 每项**15分钟**（项目介绍10分钟，参会代表讨论3分钟，专家点评2分钟）[citation:2] |
| **国际晋级机会** | 年会将遴选**12项左右**优秀创业推介项目，直接晋级下一年度中国国际大学生创新大赛总决赛[citation:2][citation:5][citation:8] |

## 六、项目申报与评审体系

### 6.1 三级工作体系

创新年会项目申报、评审工作采取**校级、省级、国家级三级工作体系**[citation:2]。

| **级别** | **组织单位** | **职责** |
| :--- | :--- | :--- |
| **校级** | 各高校 | 举办校级创新年会或竞赛遴选优秀作品 |
| **省级** | 各省级教育行政部门 | 组织省级评选和推荐，保证推荐质量 |
| **国家级** | 国创计划工作组 | 组织资格和形式审查、网络评审、会议评审 |

### 6.2 推荐名额限制

| **高校类型** | **学术论文** | **改革成果项目** | **创业推介项目** |
| :--- | :--- | :--- | :--- |
| **中央部委所属高校** | ≤3篇/校[citation:10] | ≤3项/校[citation:10] | ≤1项/校[citation:10] |
| **地方所属高校** | 由省级教育行政部门按配额推荐，三类项目占比约为45%、45%、10%[citation:10] |

### 6.3 项目范围要求

| **要求项** | **技术规格** |
| :--- | :--- |
| **立项年份** | 2022年-2024年立项的国创项目（第十八届）[citation:4][citation:8] |
| **重复限制** | 往届年会参会项目不再推荐参加本届年会[citation:8][citation:10] |
| **优先条件** | 同等条件下，近年立项的国创重点支持领域项目优先考虑[citation:2] |
| **企业项目** | 鼓励教育部产学合作协同育人创新创业联合基金项目、网络安全学院学生创新资助计划项目、“国创计划”企业命题项目申报，同等条件下优先认定创业推介项目[citation:10] |

### 6.4 文件命名规范

| **类别** | **中央部委所属高校** | **地方所属高校** |
| :--- | :--- | :--- |
| **学术论文** | 学校校名-lw序号-项目编号.doc | 省份名-lw序号-项目编号.doc |

## 十、参赛注意事项

### 10.1 参会要求

入选年会参会作品所在的高校，应为学生参加年会提供便利和支持，保证每项入选作品的学生代表积极参加年会并进行展示和交流。**未到年会参加交流的作品**意味着该项目未完成整个创新创业训练的全过程，**取消推荐该作品的高校或省份下一年相关作品的申报资格**[citation:2]。

### 10.2 学术诚信要求

各高校负责对入选年会的学术论文、改革成果和创业推介项目进行严格审核和把关，**避免出现学术不端、弄虚作假、知识产权和投资股权纠纷等问题**[citation:2]。

### 10.3 模板与排版要求

参加年会的学术论文、改革成果项目和创业推介项目需按组委会统一下发的模板要求进行排版、制作，在规定的时间期限内进行提交[citation:2]。
