# 全国大学生混凝土材料设计大赛 技术文档

## 一、赛事概述

**全国大学生混凝土材料设计大赛**是由中国混凝土与水泥制品协会（CCPA）教育与人力资源工作委员会主办的面向全国高校无机非金属材料与土木工程专业大学生的一项科技竞赛活动，每两年举办一次。大赛旨在激发大学生对混凝土材料设计的兴趣和创新精神，鼓励青年学生将理论与实践结合，设计高性能、满足各种工程建设需要的混凝土材料，推动混凝土行业的材料技术进步与应用创新的同时，为行业发展培养后继人才 [citation:1][citation:2]。

大赛遵循“**公开、公平、竞争、交流**”的原则，为全国大学生提供一流的混凝土材料理论知识和实践操作能力的竞赛平台，实现同台竞技、相互交流、增进友谊和共同进步 [citation:3]。

### 1.1 第八届基本信息
- **举办时间**：2026年7月17-19日
- **举办地点**：甘肃兰州
- **承办单位**：西北民族大学
- **协办单位**：兰州大学、兰州理工大学、兰州交通大学等
- **同期活动**：超高性能混凝土学术交流会、CCPA教育与人力资源工作委员会四届二次理事会
- **大赛官网**：https://www.ccpa.com.cn/

## 二、第八届大赛主题与内容

### 2.1 大赛主题
第八届大学生混凝土材料设计大赛的主题为：**“轻质高强高韧性混凝土材料设计大赛”** [citation:1]。

### 2.2 作品形式和要求

#### 2.2.1 作品形式
参赛队伍制作**2根尺寸为50×50×1000mm的纤维混凝土小梁**并在赛前邮寄至组委会 [citation:1]。

#### 2.2.2 原材料要求
混凝土小梁采用以下原材料进行制作 [citation:1]：

| **原材料类别** | **具体要求** |
| :--- | :--- |
| **水泥** | 包括但不限于硅酸盐水泥、铝酸盐水泥、硫铝酸盐水泥 |
| **矿物掺合料** | 包括但不限于粉煤灰、矿渣粉、硅灰、微珠、石粉 |
| **骨料** | 种类不限，但骨料粒径不宜大于10mm |
| **纤维** | 种类不限，但纤维直径不应大于2mm，长度不应大于50mm |
| **化学外加剂** | 根据需要添加 |

#### 2.2.3 强制性要求
| **要求项** | **说明** |
| :--- | :--- |
| **容重限制** | 纤维混凝土小梁的容重不得大于2300kg/m³，否则参赛队伍的成绩无效 |
| **配筋限制** | 所制作的纤维混凝土小梁中不应出现直径大于2mm的各种加强筋，不应出现连续配筋，否则参赛队伍的成绩无效 |
| **龄期要求** | 混凝土小梁邮寄组委会时的等效龄期为28天（组委会的接收日期稍后通知） |

### 2.3 纤维混凝土小梁测试方法

#### 2.3.1 测试流程
1. **试样抽取**：在参赛队伍提供的2根小梁中随机抽取一根进行测试 [citation:1]
2. **尺寸测量**：对试样进行质量和尺寸测量，获得体积密度 [citation:1]
3. **预制切口**：在小梁的底面制作深度5mm、宽度（切割片厚度）不大于2mm的预切口 [citation:1]
4. **抗弯折性能测试**：将小梁以三分点加载的方式（跨距为800mm），在位移控制模式下进行测试，控制压头的有效行程为6mm [citation:1]

#### 2.3.2 数据分析指标
测试完成后，对荷载-挠度曲线进行分析，获得以下指标 [citation:1]：

| **指标** | **说明** |
| :--- | :--- |
| **抗弯强度** | 根据最大荷载计算 |
| **弯曲韧性（能量比）** | Scurve/Srectangle |
| **荷载比** | f6mm/fmax |
| **均质性** | 依据断裂面上纤维分布的均匀程度判定 |

测试结果将在赛前反馈给参赛队伍 [citation:1]。

## 三、参赛资格与组队要求

### 3.1 参赛对象
我国全日制本科生或大专生（含2026届毕业生）。参赛队伍的成员应为我国全日制本科生或大专生（含2026届毕业生），领队应为相应院校的教师 [citation:1]。

### 3.2 组队要求
| **项目** | **要求** |
| :--- | :--- |
| **队伍组成** | 由一名领队教师、一名队长（学生）和两名队员（学生）组成，共四人 [citation:1] |
| **跨专业组队** | 提倡参赛学生跨专业、跨年级组队 [citation:4] |
| **每人限报** | 每位参赛者只允许参加一个参赛队 [citation:4] |
| **报名数量** | 参赛队伍的报名数量不限，每个院校内部的报名数量也不限 [citation:1] |

*注：第七届大赛曾规定“每个学校参赛队伍不超过2支”，第八届已取消此限制，报名数量不限 [citation:1][citation:3]。*

## 五、竞赛环节与成绩评定

### 5.1 竞赛环节

第八届大赛设置以下三个竞赛环节 [citation:1]：

| **环节** | **内容** | **要求** |
| :--- | :--- | :--- |
| **基础理论考试** | 土木工程材料理论基础考试 | 三名学生成员全部参加，成绩取平均值 |
| **PPT汇报** | 8分钟PPT汇报 | PPT需赛前一周提交 |
| **作品性能测试** | 纤维混凝土小梁抗弯折测试 | 由组委会统一测试 |

### 5.2 理论考试内容
考试内容包括但不限于 [citation:1]：
- 水泥基材料制备和性能
- 混凝土配合比设计
- 混凝土性能表征和调控
- 土木工程材料与工程应用
- 工程实践和工程性能优化

### 5.3 PPT汇报要求
汇报内容应包括 [citation:1]：
- 纤维混凝土小梁的配合比设计理念
- 配合比设计方法
- 前期预测试结果
- 组委会提供的测试结果
- 下一步的性能优化措施

### 5.4 成绩评定方法

| **序号** | **因素** | **权重** |
| :--- | :--- | :--- |
| 1 | 土木工程材料基础理论考试 | 35% |
| 2 | PPT答辩 | 15% |
| 3 | 抗弯强度 | 仅记录，不参与评定 |
| 4 | 容重 | 仅记录，不参与评定 |
| 5 | 抗弯强度/容重 | 20% |
| 6 | 弯曲韧性（能量比）和荷载比 | 25%（0.5×能量比 + 0.5×荷载比） |
| 7 | 均质性（断裂面上纤维分布均质性） | 5% |

*数据来源：[citation:1]*

## 六、第七届大赛参考（2024年）

### 6.1 第七届基本信息
- **举办时间**：2024年7月19-21日
- **举办地点**：安徽合肥
- **承办单位**：安徽建筑大学、江苏省建筑科学研究院有限公司“高性能土木工程材料国家重点实验室”
- **冠名赞助**：“苏博特杯”

### 6.2 第七届大赛主题
以有利于混凝土耐久性为原则，采用机制砂配制“**C40大流态绿色高性能混凝土**”，并考虑工程应用环境和经济性，展示大学生解决复杂工程问题的能力 [citation:3][citation:8]。

### 6.3 第七届竞赛形式
由理论考试和实践操作两部分组成 [citation:3][citation:9]：
- **理论考试成绩**：占总成绩的40%
- **实践操作比赛成绩**：占总成绩的60%

### 6.4 第七届参赛限制
每个学校参赛队伍**不超过2支**，同一学校的两支参赛队配合比应有明显不同，体现不同的设计思路 [citation:3]。
