# 中国大学生服务外包创新创业大赛 - 评分标准

**来源网址**: http://www.fwwb.org.cn/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

中国大学生服务外包创新创业大赛（简称“服创大赛”）是由教育部、商务部和无锡市人民政府联合举办的服务外包领域唯一的创新、创业国家级赛事[citation:4][citation:8]。大赛自2010年举办至今，每年一届，累计吸引1600多所院校、近50万名大学生参赛，为服务外包产业输送了15万名创新人才[citation:1]。自2018年起，大赛连续入选中国高等教育学会《全国普通高校大学生竞赛分析报告》竞赛目录，2025年排行第24位[citation:1]。

**大赛宗旨**：紧贴服务外包、创新创业主题，以应用为导向，加强产学互动，搭建大学生服务外包创新创业能力展示平台；引导学生关注现代服务产业，吸引企业关注学生创新创业，促进高校教育改革适应战略性新兴产业发展需求，为产业发展提供人才支撑，推动人才交流合作，努力促进大学生的就业和创业[citation:2][citation:9]。

**第十七届（2026年）竞赛信息**：
- **报名时间**：2026年2月11日 - 3月20日16:00
- **初赛作品提交**：2026年4月（各类别时间略有差异）
- **区域赛现场答辩**：2026年5月中旬-6月下旬
- **全国总决赛**：2026年8月（江苏无锡）

## 二、竞赛类别设置

第十七届服创大赛设置四个竞赛类别[citation:2][citation:4][citation:6]：

| 类别 | 名称 | 核心定位 | 校参赛名额 | 评审特点 |
|:---:|:---|:---|:---:|:---|
| **A类** | 企业命题类 | 企业发布真实项目需求，高校提供响应方案 | 数量不限 | 侧重专业技能及产业对接能力 |
| **B类** | 创业实践类 | 具备成熟度的创业团队和项目，已取得一定成效 | 限报2队 | 侧重创业能力和成熟度 |
| **C类** | OPC创客类 | 借助AI工具完成从设计到市场的全流程项目 | 数量不限 | 单独组织评审，不参加区域赛 |
| **D类** | 人工智能专项赛道 | 腾讯开悟人工智能全球公开赛 | 数量不限 | 聚焦AI场景真实需求 |

## 三、参赛要求

### 3.1 参赛对象与组队

| 要求类型 | 具体规定 |
|:---:|:---|
| **参赛对象** | 全国高等学校具有正式学籍的全日制在校学生（含2026年应届毕业生，本专科、研究生不限）及毕业不超过5年（2021年后毕业）的大学生[citation:4][citation:6] |
| **组队人数** | 每队队员数量上限5人，指导老师数量上限2人[citation:2][citation:4] |
| **跨校组队** | 允许跨校组队[citation:6][citation:7] |
| **每人限报** | 每位队员限参加一支团队，禁止不同参赛团队之间共用队员[citation:6] |
| **类别限制** | 参赛团队仅限选一个竞赛类别参赛[citation:4][citation:5] |
| **往届限制** | 已获本大赛往届全国赛奖项（包括一、二、三等奖）的项目，不可报名参加本届大赛[citation:4][citation:6] |

### 3.2 项目真实性要求

参赛项目须真实、健康、合法，无任何违法、不良信息，项目立意应弘扬正能量，践行社会主义核心价值观，不得违背公序良俗，不得侵犯他人知识产权[citation:5][citation:6]。

### 3.3 B类项目特殊要求

B类（创业实践类）要求参赛项目已经取得一定成效，参赛团队须拥有项目知识产权并提供相关证明文件，不会侵犯第三方的知识产权、所有权、使用权和处置权。禁止参赛团队携带指导老师或他人项目参赛，一经发现，取消参赛资格并进行通报处理[citation:6]。

### 3.4 作品匿名要求

在提交的文档作品中不得出现参赛学院名称、专业名称、学生信息和指导教师信息，及其提示、图片、照片、图像或链接等形式的暗示内容，并注意打包文件中的文件名或目录名出现以上所列的名称或暗示，否则视为违规，取消比赛资格[citation:3]。

## 四、评审体系总览

### 4.1 评审基本原则[citation:3]

| 原则 | 具体内容 |
|:---:|:---|
| **过程与结果并重** | 在评审参赛团队提交的作品同时，也关注参赛团队在作品过程中体现出的意识与素质 |
| **重视团队与人员表现** | 综合考察团队在方案中体现的综合素质与能力评价，着重考虑赛题、工作成果本身与参赛团队具体贡献的关联紧密程度 |
| **体现“三创”特色** | 秉承“创新、创业、创富”的精神，综合考察参赛团队对竞赛主题的理解，对客户及市场的深入分析与把握 |

### 4.2 通用评审维度

根据西部区域赛评审规则，评分涵盖了以下维度[citation:1]：

| 评审维度 | 评审要点 |
|:---:|:---|
| **路演水平与团队实力** | 团队分工配合、表达清晰度、整体表现 |
| **产品（服务）** | 产品/服务的完整性、实用性、技术实现 |
| **创新性** | 创意的新颖度、技术突破、模式创新 |
| **商业模式** | 盈利模式清晰度、市场定位准确性 |
| **市场前景** | 市场规模、竞争分析、增长潜力 |

## 五、各类别详细评分标准

### 5.1 A类（企业命题类）评分标准

A类侧重企业命题，通过企业发布真实项目需求，由高校提供响应方案的方式，来加强校企结合及提升产业对接[citation:2][citation:4]。主要考察参赛团队的专业技能及竞争力水平[citation:1]。

#### 5.1.1 A类初赛作品评分要点（锐捷网络赛题适用）[citation:7]

| 评分项目 | 评分要点 |
|:---:|:---|
| **方案完整性** | 项目目标、解决思路、解决方案的完整程度 |
| **技术实现** | 技术路线可行性、技术方案创新性、实现程度 |
| **创新性** | 创意新颖度、技术突破、应用创新 |
| **商业模式** | 业务模式、盈利方式、可行性分析 |
| **现场表现** | 答辩逻辑、问题回答准确度 |

#### 5.1.2 A类提交材料要求[citation:2]

| 材料名称 | 格式要求 | 内容要求 |
|:---:|:---|:---|
| 概要介绍 | PDF，≤1500字，≤10M | 目标、解决思路、解决方案、亮点等 |
| 项目简介PPT | PPT/PDF，≤20页，≤20M | 目标与解决思路、技术方案、业务模式等 |
| 项目详细方案 | PDF，≤20M | 详细解决方案 |
| 项目演示视频 | MP4，≤5分钟，≤100M | 展示技术实现方式、运行方式和完成程度 |
| 项目知识产权证明 | PDF，≤2M（可选） | 专利证书、著作权证书等 |

### 5.2 B类（创业实践类）评分标准

B类侧重创业实践，鼓励具备成熟度的创业团队和项目参赛，要求参赛项目已经取得一定成效。重点考察参赛团队的创业能力和成熟度，侧重考查项目细分领域的竞争力和商业模式的创新性[citation:1][citation:2]。

#### 5.2.1 B类评分维度[citation:2]

| 评审项目 | 评审要点 |
|:---:|:---|
| **项目背景** | 行业背景、市场痛点的准确把握 |
| **核心团队** | 团队背景、执行能力、资源整合能力 |
| **产品/服务** | 产品成熟度、技术壁垒、用户体验 |
| **商业模式** | 盈利模式清晰度、商业逻辑合理性 |
| **市场及运营情况** | 市场表现、运营数据、客户反馈 |
| **竞争分析** | 行业排名、主要竞争对手分析 |
| **财务现状及预测** | 财务数据、盈利预测、融资计划 |
| **主要客户及合作** | 客户资源、合作伙伴、渠道建设 |

#### 5.2.2 B类提交材料要求[citation:2]

| 材料名称 | 格式要求 | 内容要求 |
|:---:|:---|:---|
| 项目商业计划书PPT | PPT/PDF，≤50M | 项目背景、团队、产品、商业模式、市场情况等 |
| 商业计划书详细方案 | PDF，≤20M | 商业计划书详细内容 |
| 项目演示视频 | MP4，≤5分钟，≤100M | 展示项目和团队基本情况 |
| 公司简介 | PDF，≤1000字（已成立公司必选） | 公司基本信息 |
| 项目知识产权证明 | PDF，≤2M（可选） | 专利证书、著作权证书等 |

### 5.3 C类（OPC创客类）评分标准

C类侧重OPC模式特征，鼓励学生借助AI工具在服务外包领域完成从设计到市场的全流程项目，并强调创新性、可行性与原创性[citation:2][citation:4]。该类项目单独组织评审，不参加区域赛[citation:4][citation:9]。

#### 5.3.1 C类评分维度[citation:2]

| 评审项目 | 评审要点 |
|:---:|:---|
| **行业背景与市场痛点** | 对行业理解深度、问题识别的准确性 |
| **项目/产品介绍** | 产品定位、核心功能、应用场景 |
| **技术/路径介绍** | AI工具应用深度、技术实现路径 |
| **核心团队** | 团队背景、分工合理性 |
| **市场及目标客户** | 目标市场定位、客户需求匹配 |
| **商业模式** | 盈利方式、商业逻辑 |
| **进展现状及竞争分析** | 项目进展、竞争优劣势 |
| **财务预测及发展规划** | 财务可行性、发展路径 |

#### 5.3.2 C类提交材料要求[citation:2]

| 材料名称 | 格式要求 | 内容要求 |
|:---:|:---|:---|
| 项目商业计划书PPT | PPT/PDF，≤50M | 行业背景、产品介绍、技术路径、商业模式等 |
| AI协同流程说明文档 | PDF，≤20M | 说明各环节使用的AI工具/平台/技术，解决的真实问题 |
| 产品原型或演示视频 | MP4，≤5分钟，≤100M | 展示项目核心功能、应用场景 |

### 5.4 D类（人工智能专项赛道）评分标准

D类为腾讯开悟人工智能全球公开赛，聚焦人工智能场景真实需求，依托腾讯开悟AI开放研究平台领先技术底座，旨在助力世界科技青年学子间的智竞交流，为人工智能解决真实场景问题提供前瞻性样本[citation:2][citation:4]。

根据燕山大学通知，D类D01、D02、D03赛题需提交最终模型至腾讯开悟平台，系统将以参赛团队提交的最新模型自动运行，并按照各团队得分高低排名[citation:10]。

## 六、区域赛与全国总决赛评审

### 6.1 区域赛设置[citation:1][citation:7]

全国共设四个区域赛：

| 区域赛 | 覆盖省份 | 承办单位 |
|:---:|:---|:---|
| **东部区域赛** | 江苏、上海、浙江、福建、江西、安徽、香港、澳门、台湾 | 南京大学 |
| **中部区域赛** | 湖南、湖北、河南、广东、广西、云南、贵州、海南 | 中南大学 |
| **西部区域赛** | 陕西、四川、重庆、宁夏、青海、甘肃、新疆、西藏 | 西安电子科技大学 |
| **北部区域赛** | 北京、天津、山东、河北、山西、内蒙古、辽宁、吉林、黑龙江 | 山东大学 |

### 6.2 区域赛评审[citation:1]

区域赛采用现场答辩形式，评审专家按照评分规则对每一支队伍进行严格评审。西部区域赛第十六届数据：95支队伍晋级决赛（A类72支、B类23支），评审出A类一等奖21支，B类一等奖8支，直接晋级全国总决赛。

### 6.3 全国总决赛评审[citation:7]

全国总决赛在江苏无锡现场举行，参赛团队须自备所需工具。决赛期间进行项目演示答辩、作品展示并参加颁奖典礼。

## 八、评审特点分析

1. **四赛道分类评价**：A类企业命题侧重专业技能，B类创业实践侧重创业成熟度，C类OPC创客强调AI工具应用，D类人工智能聚焦技术实现，评分标准精准匹配各类别特点。

2. **过程与结果并重**：评审不仅关注最终作品，也关注参赛团队在作品过程中体现出的意识与素质，着重考虑赛题、工作成果本身与参赛团队具体贡献的关联紧密程度[citation:3]。

3. **“三创”特色鲜明**：秉承“创新、创业、创富”精神，综合考察参赛团队对竞赛主题的理解，对客户及市场的深入分析与把握[citation:3]。

4. **严格匿名评审**：提交文档中不得出现学院、专业、学生、指导教师信息及任何暗示内容，确保评审公平公正[citation:3]。

5. **企业深度参与**：A类赛题由华为、超星等具有代表性的企业参与命题，评审标准贴近产业实际需求，获奖团队可获得与命题企业进行项目对接和成果转化的机会[citation:1][citation:6]。

6. **创业实践要求严格**：B类项目要求已经取得一定成效，禁止携带指导老师或他人项目参赛，须拥有项目知识产权证明，确保项目的真实性和团队的原创性[citation:6]。

7. **AI工具应用规范**：C类项目要求详细说明AI协同流程，包括各环节使用的具体AI工具/平台/技术，强调创新性、可行性与原创性[citation:2]。

8. **区域赛选拔机制**：通过四个区域赛现场答辩，评选出晋级全国总决赛的团队，区域赛与国赛形成递进评审机制[citation:1][citation:10]。

**注意**：以上评审规则综合参考了《第十七届中国大学生服务外包创新创业大赛参赛手册》、各区域赛评审规则及各高校校赛通知。每届竞赛的具体评分细则以当届发布的官方通知为准，各类别评分标准可能存在差异，请以官网公布的最新版本为准。
