# 全国大学生广告艺术大赛 - 评分标准

**来源网址**: https://www.sun-ada.net/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国大学生广告艺术大赛（简称“大广赛”）是由全国大学生广告艺术大赛组委会、中国传媒大学、大广赛文化传播（北京）有限公司共同举办，是迄今为止全国规模大、覆盖高等院校广、参与师生人数多、作品水准高的全国性高校学科竞赛[citation:3]。自2005年至今，大广赛已成功举办16届，共有1857所高校参与其中，超过百万学生提交作品[citation:7]。该赛事是面向全国在校大学生的一项广告策划创意实践活动，旨在活跃大学生的课外文化生活，激发大学生的创意灵感，加强大学生实践能力、创新能力和合作精神的培养[citation:3]。

**大赛宗旨**：促进教改、启迪智慧、强化能力、提高素质、立德树人[citation:3]。

**组织形式**：政府指导、学生为主、企业参与、专家评审、专业机构举办[citation:3]。

**第十八届（2026年）竞赛信息**：
- **线上提交时间**：2026年5月10日至6月12日16:00[citation:2]
- **命题发布**：2026年1月－4月陆续公布
- **竞赛形式**：采用学校初评、赛区评选、总赛区评审的三级评选形式[citation:3]

## 二、参赛要求

### 2.1 参赛资格

| 要求类型 | 具体规定 |
|:---:|:---|
| **参赛对象** | 全国各类高等院校在校全日制大学生、研究生、港澳台籍学生、外籍留学生均可参加[citation:2][citation:3] |
| **组队限制** | 不得跨赛区、跨学校组队参赛，鼓励同一学校跨专业组队参赛[citation:7] |

### 2.2 作者与指导教师人数限制

根据淮北师范大学校赛通知，各类别作者和指导教师人数限制如下[citation:8]：

| 作品类别 | 作者人数限制 | 指导教师人数限制 |
|:---:|:---:|:---:|
| **平面类、文案类** | ≤2人/组 | ≤1人/组 |
| **短视频、互动类、广播类** | ≤3人/组 | ≤2人/组 |
| **影视广告、微电影广告、动画类、策划案类、UI类、科技类、营销创客类** | ≤5人/组 | ≤2人/组 |

### 2.3 创作规范

| 要求 | 具体规定 |
|:---:|:---|
| **遵循命题要求** | 参赛作品必须严格依照大广赛组委会统一发布的命题进行创作[citation:2][citation:5][citation:6] |
| **原创性原则** | 各类参赛作品必须为本人原创作品，拥有独立知识产权，遵守《广告法》和其他相关法律及政策法规、行业规范等要求[citation:2][citation:5][citation:6] |
| **鼓励创新** | 鼓励采用广告新思维、新形式、新媒介进行创作[citation:2][citation:5][citation:6] |
| **杜绝抄袭** | 坚持原创，杜绝抄袭，遵守《承诺书》的承诺[citation:2][citation:5][citation:6] |
| **一稿多投禁止** | 禁止同一件或多件创意雷同作品按不同类别或不同命题提交；禁止将其他赛事创作的作品再投大广赛[citation:6] |
| **作品购买禁止** | 禁止参赛者通过各种渠道购买作品，一经发现，立即取消其参赛资格[citation:6] |

### 2.4 AI工具使用规定

| 要求 | 具体规定 |
|:---:|:---|
| **AI辅助创作** | 创作中如使用AIGC工具辅助创作，须在报名表中予以注明[citation:6] |
| **科技类（生成式AI设计方向）** | 必须使用AI工具辅助完成，需附上生成式AI工具的原始输出文件（如AI生成的图片、文本等）及工具使用过程的说明或截图，以证明作品的原创性[citation:2] |

### 2.5 作品匿名要求

参赛作品中严禁出现参赛者的院校、系、姓名及其他特殊标记[citation:6]。视频类、动画类作品片头不要出现倒计时及创作者相关信息[citation:2][citation:5]。

## 四、竞赛形式与赛程安排

### 4.1 三级评审机制

大广赛采取**学校初评、赛区评选、总赛区评审**的三级评选形式[citation:3]：

| 评审阶段 | 主要内容 | 备注 |
|:---:|:---|:---|
| **学校初评** | 各高校对参赛作品进行初评，筛选优秀作品报送至赛区 | 学校在系统中将初评选出的作品信息提交至所在赛区组委会[citation:7] |
| **赛区评选** | 各省赛区组织专家评审，获等级奖的作品报送大广赛组委会参加全国总赛区评审 | 各省赛区获奖作品由各省赛区颁发获奖证书[citation:3] |
| **全国总评审** | 全国大广赛组委会聘请高校学者和广告业界专家组成评奖委员会，对参赛作品进行评审 | 获全国总赛区奖项的作品由全国大广赛组委会颁发证书、奖牌及其他奖励[citation:3] |

### 4.2 第十八届大赛日程安排

| 阶段 | 时间安排 | 主要内容 |
|:---:|:---:|:---|
| **命题发布** | 2026年1月－4月 | 陆续公布第18届大广赛命题[citation:7] |
| **作品创作** | 1月－5月 | 学生创作、教师指导 |
| **线上提交** | 2026年5月10日至6月12日16:00 | 在作品提交平台注册，按流程上传作品[citation:2] |
| **学校初评** | 6月中旬－7月上旬 | 学校初评、报送作品 |
| **赛区评选** | 7月 | 各赛区组织评选 |
| **全国总评审** | 7月下旬－8月 | 全国总评审，分为线上初评及线下终评[citation:4] |
| **策划案现场决赛** | 9月 | “中国大学生好创意”大广赛策划案现场决赛[citation:7] |
| **成果展示盛典** | 11月－12月 | 学科竞赛成果展示盛典、获奖作品网络展播[citation:7] |

### 4.3 全国总评审流程

第17届大广赛全国总评审采用线上线下相结合的模式，评审流程如下[citation:4][citation:9]：

| 评审阶段 | 评审形式 | 主要内容 |
|:---:|:---:|:---|
| **第一阶段线上初评** | 学界专家评委与企业评委进行初评 | 对参赛作品进行初步筛选 |
| **第二阶段线上评审** | 对初评作品进行第二轮筛选 | 聚焦作品等级奖的评定 |
| **线下终评** | 业界专家评委进行终评，多元复合型评审团（业界评委占主导） | 对作品进行深度研判，确定等级奖 |
| **公益广告大奖与全场大奖评选** | 全体评委终评 | 聚焦社会价值与创意表达，最终遴选出全场大奖提名作品[citation:9] |

## 五、评分标准

### 5.1 通用评分标准

根据重庆科技大学校赛通知，总分100分，评分项目如下[citation:1]：

| 评审项目 | 分值 | 评审要点 |
|:---:|:---:|:---|
| **作品创意** | 30分 | 创意的新颖性、独特性、创新思维 |
| **艺术表现** | 30分 | 艺术形式的表达、视觉美感、设计水准 |
| **制作质量** | 30分 | 技术实现水平、制作精良度、细节处理 |
| **作品规范** | 10分 | 是否符合命题要求、格式规范、时长控制 |

### 5.2 江西应用科技学院校赛评分标准

根据江西应用科技学院校赛实施方案，评审标准如下[citation:6]：

| 评审项目 | 分值 | 评审要点 |
|:---:|:---:|:---|
| **作品思维** | 30% | 创意理念、思维深度、洞察力 |
| **艺术形式** | 30% | 艺术表现力、形式美感、设计风格 |
| **制作质量** | 30% | 技术实现、制作水平、细节处理 |
| **作品规范** | 10% | 是否符合命题要求、格式规范 |

### 5.3 各类别评审侧重

根据第17届大广赛全国总评审的评审实践，不同类别作品的评审侧重有所不同[citation:9]：

| 作品类别 | 评审侧重 |
|:---:|:---|
| **平面类** | 创意独特性、执行完整性、视觉表现力、命题诉求精准传达 |
| **影视/动画/互动类** | 创意表现、技术实现、视听语言、互动体验 |
| **微电影类** | 故事叙述、情感表达、影像质量、品牌融合 |
| **广播/文案类** | 语言表达、创意构思、听觉表现、文案张力 |
| **策划案类** | 策略思考、创意呈现、执行落地、市场适配性 |
| **公益类** | 社会价值、主题洞察、创意表达、传播效果[citation:9] |

### 5.4 策划案现场决赛

策划案的全国一等奖通过现场提案的形式产生，参赛者约有不少于20天的准备时间[citation:2][citation:5]。现场提案重点考察[citation:2]：

| 评审项目 | 评审要点 |
|:---:|:---|
| **策划方案** | 策略推导、创意呈现、落地实施 |
| **提案表现** | 表达清晰度、逻辑性、专业素养 |
| **现场答辩** | 问题回答准确度、应变能力 |

### 5.5 全场大奖评选

全场大奖评选以“评委推荐”的形式展开，多位评委主动上台阐述推荐理由，从创意高度、执行精度等维度展开深度剖析，最终遴选出2件备选作品，于学科成果展示盛典进行最终角逐[citation:9]。

## 七、学术诚信与违规处理

### 7.1 原创性要求

| 要求 | 具体规定 |
|:---:|:---|
| **独立知识产权** | 参赛作品必须拥有独立知识产权，遵守《广告法》和相关法律法规[citation:2][citation:5][citation:6] |
| **引用注明出处** | 创作中如使用了素材，务必在报名表中详细注明出处，并取得授权[citation:6] |
| **AI工具注明** | 使用AIGC工具辅助创作，须在报名表中予以注明[citation:6] |

### 7.2 违规处理

| 违规情形 | 处理措施 |
|:---:|:---|
| **抄袭剽窃** | 取消参赛资格，组委会保留追究法律责任的权利 |
| **一稿多投** | 取消参赛及获奖资格[citation:6] |
| **购买作品** | 立即取消其参赛资格[citation:6] |
| **侵犯知识产权** | 凡涉及知识产权纠纷，责任由参赛者自负，组委会有权取消其参赛资格[citation:1] |

### 7.3 公示与举报制度

| 项目 | 具体规定 |
|:---:|:---|
| **公示范围** | 获得一等、二等、三等及优秀奖的作品[citation:3] |
| **公示时间** | 10-15天[citation:3] |
| **举报要求** | 实行实名制，要求写真实姓名，并提供相应的证据（如抄袭作品来源的复印件等），匿名举报无效[citation:3] |
| **举报处理** | 由各赛区组委会核查并提出处理意见，报大广赛组委会裁决[citation:3] |

## 八、评审特点分析

1. **三级递进评审机制**：学校初评→赛区评选→总赛区评审层层递进，确保评审质量。第17届大广赛从582359组参赛作品中评选出6419组全国奖，获奖比例约为1.1%[citation:4]。

2. **多元复合型评审团**：全国总评审汇聚了学术界、行业精英与企业代表的多元评审阵容，业界评委占据主导地位，确保了评审与市场需求的紧密接轨及评价维度的全面性[citation:4][citation:9]。

3. **四维核心评价体系**：作品创意（30分）、艺术表现（30分）、制作质量（30分）、作品规范（10分）四个维度综合评价，全面考察学生的创新思维、艺术表达能力和技术实现水平[citation:1][citation:6]。

4. **分类评审精准评价**：平面类、视频类、动画类、策划案类等不同类别作品，评审侧重各有不同，如公益类聚焦社会价值与创意表达，策划案类注重策略推导与落地实施[citation:9]。

5. **严格的原创性要求**：强调独立知识产权，禁止抄袭剽窃，禁止一稿多投，禁止购买作品，对学术不端行为实行零容忍[citation:2][citation:5][citation:6]。

6. **AI工具规范使用**：允许使用AI工具辅助创作，但要求在报名表中注明，科技类（生成式AI设计方向）需附上AI工具的原始输出文件及使用过程说明，以证明作品的原创性[citation:2][citation:6]。

7. **策划案现场决赛**：策划案的全国一等奖通过现场提案的形式产生，考察学生的现场表达能力和专业素养[citation:2][citation:5]。

8. **全场大奖评委推荐制**：全场大奖以“评委推荐”形式产生，多位评委主动上台阐述推荐理由，从创意高度、执行精度等维度进行深度剖析，体现评审的严谨性和专业性[citation:9]。
