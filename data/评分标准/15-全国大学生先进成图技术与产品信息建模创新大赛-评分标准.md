# 全国大学生先进成图技术与产品信息建模创新大赛 - 评分标准

**来源网址**: http://www.chengtudasai.com/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国大学生先进成图技术与产品信息建模创新大赛（简称“成图大赛”）因其高难度和广泛影响力，被誉为 **“图学界的奥林匹克”** [citation:3]。该赛事由原教育部高等学校工程图学课程教学指导委员会、中国图学学会制图技术专业委员会和中国图学学会产品信息建模专业委员会联合主办，是图学类课程最高级别的国家级赛事，自2018年起被中国高等教育学会列入全国普通高校学科竞赛排行榜[citation:2][citation:10]。

**大赛宗旨**：以培养学生的工匠精神，激发学生的创新意识，探索图学的发展方向，创新成图载体的方法与手段。目的在于**以赛促教，以赛促学，以赛促改**，全面提高大学生的图学能力，为中国制造走向中国创造催生和助长大量优秀人才[citation:2][citation:10]。

**大赛规模**：每年吸引超过1000所院校参赛，全国总决赛参赛学生数量超过12000人，包括上海交通大学、哈尔滨工业大学、武汉大学、华中科技大学、香港城市大学等众多名校[citation:8]。

## 二、竞赛类别与赛道设置

大赛结合新工科建设和工程教育专业认证，设立多个竞赛类别，并不断与时俱进，增设前沿技术赛道。

### 2.1 竞赛类别

| 类别 | 涵盖方向 |
|:---:|:---|
| **机械类** | 传统机械设计、先进成图技术、增材制造、轻量化设计、数字化创新设计等 |
| **建筑类** | 建筑工程图绘制、BIM技术应用、建筑施工图设计等 |
| **道桥类** | 道路、桥梁、隧道等结构制图与建模 |
| **水利类** | 水工建筑物制图与建模 |
| **电子类** | 电子类先进成图技术 |

### 2.2 2025年新增赛道

2025年赛事引入前沿技术，增设以下赛道[citation:3]：

| 新增赛道 | 核心内容 |
|:---:|:---|
| **轻量化设计与AI应用** | 结合拓扑优化、运动仿真等技术对产品进行性能分析 |
| **数字化创新设计** | 数字化环境下的创新设计实践 |
| **面向社会的产品创新设计** | 鼓励学生与企业合作解决实际工程问题 |

## 三、竞赛形式与赛程安排

### 3.1 三级赛制

大赛采用“校赛→省赛（预选赛）→国赛（全国总决赛）”三级赛制[citation:2][citation:8]：

| 竞赛阶段 | 时间安排（以2025-2026年为例） | 主要内容 |
|:---:|:---:|:---|
| **校赛** | 3月-4月 | 校内选拔，确定参加省赛队伍 |
| **省赛** | 5月-6月 | 省级评审，确定推荐国赛名单 |
| **国赛** | 7月-8月 | 全国集中评审，确定最终奖项 |

### 3.2 第十九届（2026年）大赛日程（参考）

根据郑州轻工业大学2026年3月发布的校级预选赛通知[citation:6]：
- **校赛时间**：2026年3月28日
- **省赛时间**：预计2026年5月（需通过省赛选拔获得国赛资格）
- **国赛时间**：预计2026年7月下旬[citation:2]

## 四、参赛要求

### 4.1 组队要求

| 要求类型 | 具体规定 |
|:---:|:---|
| **参赛对象** | 全国高等院校全日制在校大学生（含本科生、研究生）[citation:2] |
| **组队人数** | 机械类团体赛要求至少5名选手参加先进成图技术赛道[citation:9] |
| **赛道限制** | 参赛者仅能在机械类、建筑类、道桥类、水利类等类别中选一个类别参加[citation:10] |
| **指导教师** | 每队可有1-2名指导教师 |

### 4.2 作品与技术平台要求

| 要求类型 | 具体规定 |
|:---:|:---|
| **软件自备** | 参赛学生自备可连接网络的电脑，安装所需绘图软件（版本不限，建筑类部分赛道限定使用Revit系列软件）[citation:6][citation:10] |
| **作品原创性** | 参赛作品必须为原创，不得抄袭 |
| **提交格式** | 按要求提交PDF或JPG格式的图纸文档[citation:6] |

## 五、评分体系总览

### 5.1 评审工作基本原则

大赛评审遵循“公平、公正、公开、科学、高效”的原则。评委通过审阅设计图纸、观摩建模过程、评审创新作品等环节，对参赛选手的图学能力、创新思维和工程实践能力进行综合评价。

### 5.2 通用评分观测点

| 评价维度 | 观测点 | 权重参考 |
|:---:|:---|:---:|
| **图形准确性** | 投影关系正确、图形表达完整、符合国家标准 | 30%-40% |
| **规范性** | 图线、字体、标注符合规范、图面整洁 | 20%-25% |
| **创新性** | 设计思路新颖、技术应用创新 | 15%-25% |
| **技术难度** | 模型复杂度、功能实现难度 | 15%-20% |
| **完成度** | 任务完成情况、细节处理 | 10%-15% |

## 六、各阶段详细评分标准

### 6.1 校赛评分标准（以郑州轻工业大学2026年校赛为例）[citation:6]

| 考核内容 | 评分要点 |

| **装配体建模与工程图生成** | 装配关系正确性、爆炸图表达、装配动画效果 |

| 考核内容 | 评分要点 |
|:---:|:---|
| **根据建筑施工图纸建立三维BIM模型** | 模型完整性、构件准确性、参数设置合理 |

### 6.3 尺规绘图详细评分标准（以建筑类为例）[citation:5]

**时间**：90分钟  
**图幅**：A3  
**满分**：100分

| 评分项目 | 分值 | 评分要点 |
|:---:|:---:|:---|
| **图形** | 40分 | 图形表达正确、完整、清晰，投影关系准确 |
| **尺寸** | 25分 | 尺寸标注完整、清晰、基本合理（包括图中文字） |
| **图线** | 15分 | 图线粗细分明、层次感强、符合国家标准 |
| **字体** | 10分 | 汉字、数字和字母笔划清晰、字体端正、排列整齐 |
| **布图** | 10分 | 各视图布局合理、图面均衡匀称、整洁美观 |

### 6.4 计算机三维建模详细评分标准

#### 6.4.1 建筑类三维建模评分标准[citation:5]

**时间**：150分钟  
**满分**：100分

| 评分项目 | 分值 | 评分要点 |
|:---:|:---:|:---|
| **三维模型** | 50分 | 模型完整性、准确性，包含建筑物内部和外部 |
| **细部设计与表达** | 20分 | 雨棚、门窗样式、散水等细部设计合理 |
| **材质、背景等** | 10分 | 材质赋予恰当、背景设置合理 |
| **剖面图** | 20分 | 根据模型生成的剖面图准确、规范 |

#### 6.4.2 道桥类三维建模评分标准[citation:7]

**时间**：120分钟（与二维绘图合计180分钟）

| 评分项目 | 评分要点 |
|:---:|:---|
| **结构三维建模** | 模型完整性、结构准确性、符合图纸要求 |
| **结构材质处理** | 材质赋予恰当、质感真实 |
| **环境设置** | 场景设置合理、环境协调 |
| **渲染等后期效果处理** | 渲染效果真实、整体效果图美观 |

### 6.5 计算机二维绘图评分标准（道桥类）[citation:7]

**时间**：60分钟

| 评分项目 | 评分要点 |
|:---:|:---|
| **图形** | 绘图环境设置规范（图层、颜色、线型、线宽），图形绘制完整正确 |
| **标注** | 文字样式、尺寸标注样式符合国家标准，标注完整清晰 |
| **图面布局** | 图面布局美观、合理 |

### 6.6 制图基础知识考核

**形式**：现场答题（选择题，含单选和多选）[citation:10]  
**时间**：30分钟  
**考察内容**：

| 知识点 | 具体内容 |
|:---:|:---|
| 正投影理论基础 | 投影规律、三视图形成 |
| 立体截切与相贯 | 截交线、相贯线的投影 |
| 组合体构型 | 组合体分析、表达方法 |
| 工程形体表达 | 剖面图、断面图的应用 |
| 专业图样识读 | 建筑施工图、水工建筑物图等 |

## 八、评审创新与改革

### 8.1 2025年评审三大变化[citation:3]

| 变化方向 | 具体内容 |
|:---:|:---|
| **赛道升级** | 机械类增设“轻量化设计与AI应用”赛道，要求学生结合拓扑优化、运动仿真等技术对产品进行性能分析 |
| **评审优化** | 首次采用 **“人机协同”评审模式**，通过AI系统对机械类和建筑类作品进行初步筛选，再由专家进行精细化评分 |
| **校企联动** | 新增“面向社会的产品创新设计”赛道，鼓励学生与企业合作解决实际工程问题 |

### 8.2 图学教育发展趋势[citation:3]

随着AI技术的普及，传统图学教育需从 **“工具应用”转向“思维培养”**，注重提升学生的：
- 空间想象力
- 创新设计能力
- 跨学科协作能力

## 九、评审特点分析

1. **“图学奥林匹克”的权威性**：作为图学类课程最高级别赛事，评审标准严格、规范，对参赛选手的图学素养进行全面考察。

2. **多类别分类评价**：机械、建筑、道桥、水利、电子五大类别各有侧重，评分标准精准体现各专业特点。

3. **三级递进选拔机制**：校赛筛选基础扎实的选手，省赛考察综合能力，国赛选拔顶尖人才，层层递进确保评审质量。

4. **传统与现代融合**：既保留尺规绘图这一传统技能考核，又引入BIM技术、轻量化设计、AI应用等现代技术赛道。

5. **团体与个人并重**：个人全能奖与团体奖并重，既考察个人技术水平，也强调团队综合实力。

6. **“人机协同”评审创新**：2025年起引入AI辅助评审系统，通过AI初步筛选再由专家精细评分，提升评审效率和科学性。

7. **注重工程实践能力**：强调解决实际工程问题的能力，鼓励校企合作，推动“赛教融合”，将竞赛成果转化为教学资源。
