# 全国大学生化工设计竞赛 - 评分标准

**来源网址**: http://iche.zju.edu.cn/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国大学生化工设计竞赛由中国化工学会、中国化工教育协会共同主办，浙江大学等高校发起承办，是目前国内级别最高、参赛队伍最多、影响最大的化工类大学生专业性比赛[citation:1]。竞赛自2007年起连续举办，2018年起进入全国高校学科竞赛排行榜榜单[citation:1]。

**第二十届（2026年）竞赛信息**：
- **竞赛主题**：**“创新驱动、绿色发展”**
- **设计题目**：**“某大型化工企业设计一座苯乙烯清洁生产的分厂，要求技术符合中国绿色低碳循环发展要求”**[citation:1]
- **全国总决赛承办单位**：宁夏大学
- **赛区决赛承办单位**：东北赛区（大庆师范学院）、华北赛区（北京理工大学）、华东赛区（台州学院）、华南赛区（广西大学）、华中赛区（江汉大学）、西北赛区（中北大学）、西南赛区（重庆文理学院）

**2025年竞赛规模**：479所高校、4337支队伍报名参赛，参赛人数首次超2万人[citation:1]。

**竞赛宗旨**：多方面培养大学生的创新思维和工程技能，培养团队协作精神，增强大学生的工程设计与实践能力，实践“卓越工程师教育培养计划”[citation:1]。

## 二、参赛要求

### 2.1 组队要求

| 要求类型 | 具体规定 |
|:---:|:---|
| **参赛对象** | 全日制在校本科生[citation:5] |
| **组队人数** | 每支参赛团队由**同一所学校的5人**组成，设队长1人[citation:5] |
| **跨学科组队** | 鼓励学生多学科组队参赛[citation:5] |
| **参赛限制** | 每位学生只允许参加一支团队[citation:5] |
| **队员替换** | 团队有队员因故退出时，最多允许替换2名队员或缺席1名队员参赛，否则作弃权处理[citation:5] |

### 2.2 作品原创性要求

| 要求 | 具体规定 |
|:---:|:---|
| **独立完成** | 设计工作必须由本队参赛成员独立完成，不允许外人代工和抄袭外队作品[citation:5] |
| **真实性承诺** | 必须提交《参赛作品真实性声明及诚信承诺书》，保证内容真实、数据可靠、设计方案原创[citation:6] |
| **AI工具规范** | 严禁使用生成式人工智能工具直接生成全文或核心设计内容并隐瞒使用事实[citation:6] |
| **违规处理** | 违反承诺将承担取消参赛资格、成绩无效、通报批评等后果[citation:6] |

### 2.3 作品提交要求

| 材料类型 | 提交时间 | 说明 |
|:---:|:---:|:---|
| **预赛作品** | 7月15日前 | 按《提交作品指南》上传至指定云存储，提供完整材料方为合格[citation:5] |
| **参赛队员和指导老师确认表** | 7月1日-31日 | 在线填写并提交，作为最终奖状名单排序依据，未填写确认表作弃权处理[citation:5] |
| **决赛作品** | 8月10日前 | 全国总决赛团队提交修改后的决赛作品[citation:5] |

## 三、竞赛形式与赛程安排

### 3.1 三级赛制

竞赛采用“校赛—赛区赛—全国总决赛”三级赛制[citation:5]：

| 竞赛阶段 | 时间安排（第二十届） | 主要内容 |
|:---:|:---:|:---|
| **报名组队** | 3月1日-3月31日 | 官网在线填写报名表 |
| **实施设计** | 获准参赛日-7月15日 | 完成初赛作品 |
| **预赛评审** | 7月25日前 | 各赛区评阅参赛作品，遴选出参加赛区决赛团队 |
| **赛区决赛** | 7月31日前 | 答辩会形式，评定赛区获奖级别，甄选全国总决赛团队 |
| **全国总决赛** | 8月12日-17日 | 作品专项评审+总决赛答辩会 |

### 3.2 赛区设置

预赛分**七个赛区**进行[citation:5]：

| 赛区 | 涵盖省份/地区 |
|:---:|:---|
| **华东赛区** | 上海、江苏、浙江、安徽、福建、江西、山东、中国台湾 |
| **华南赛区** | 广东、广西、海南 |
| **西北赛区** | 陕西、甘肃、宁夏、青海、新疆 |
| **华北赛区** | 北京、天津、河北、山西、内蒙古 |
| **华中赛区** | 湖北、湖南、河南 |
| **东北赛区** | 辽宁、吉林、黑龙江 |
| **西南赛区** | 重庆、四川、贵州、云南、西藏 |

## 四、评审体系总览

### 4.1 评审基本原则

2026年竞赛将按照**新修订的评分实施细则**评审作品[citation:1]。评审工作遵循“公平、公正、公开”的原则，评委通过作品评审和现场答辩相结合的方式进行综合评价。

### 4.2 通用评审环节

根据北京理工大学校赛规则，竞赛通过**作品评审**和**现场答辩**相结合的方式进行选拔[citation:2]：

| 评审环节 | 权重 | 主要内容 |
|:---:|:---:|:---|
| **作品评审** | 0.7 | 依据全国大学生化工设计竞赛评分标准对提交作品进行评审 |
| **现场答辩** | 0.3 | 依据现场答辩评分表进行评价 |

### 4.3 通用评分维度

根据竞赛对苯乙烯清洁生产分厂设计的要求，评审围绕以下核心维度展开：

| 评审维度 | 评审要点 |
|:---:|:---|
| **工艺路线选择** | 苯乙烯生产工艺的先进性、清洁生产水平、技术成熟度 |
| **设备选型与设计** | 关键设备选型合理性、设计计算准确性 |
| **经济分析** | 投资估算、成本分析、经济效益评估 |
| **热集成与节能** | 能量系统优化、热交换网络集成、节能效果 |
| **厂址选择与布局** | 厂址选择合理性、总图布置科学性 |
| **仪表自动化控制** | 控制系统设计、安全联锁方案 |
| **风险分析** | 安全风险识别、环境风险评估、应急预案 |
| **创新性** | 技术创新、设计理念创新、绿色低碳技术应用 |

## 五、校赛评分标准

### 5.1 北京理工大学校赛评分标准（2026）

| 评审环节 | 权重 | 评审方式 |
|:---:|:---:|:---|
| **作品评审** | 70% | 依据全国大学生化工设计竞赛评分标准进行 |
| **现场答辩** | 30% | 依据现场答辩评分表进行[citation:2] |

### 5.2 河北科技大学校赛评分标准（2026）

**校赛流程**：预赛作品经初审遴选出优秀作品参加决赛，决赛由评审委员会评选获奖作品，并确定代表本校参加国赛的团队[citation:3]。

**校赛奖项设置**[citation:3]：

| 奖项 | 获奖比例 |
|:---:|:---:|
| **一等奖** | 参赛队伍数的10% |
| **二等奖** | 参赛队伍数的20% |
| **三等奖** | 参赛队伍数的30% |

## 六、赛区决赛评分标准

### 6.1 赛区决赛形式

赛区决赛原则上采用**答辩会的形式**，各参赛团队依次报告本队的作品，接受赛区决赛评审专家的质询，即时答辩[citation:5]。

### 6.2 赛区决赛评分维度

| 评审环节 | 评审要点 |
|:---:|:---|
| **口头报告质量** | 报告逻辑清晰度、重点突出性、时间把控能力 |
| **作品内容深度** | 设计方案完整性、技术创新性、工程实用性 |
| **答辩表现** | 问题回答准确度、专业知识扎实程度、应变能力 |
| **团队协作** | 团队成员分工配合、整体表现协调性 |

### 6.3 赛区决赛评审目标

赛区决赛评审专家根据参赛团队的口头报告质量和答辩表现进行评议，完成以下两项工作[citation:5]：
1. 评定各参赛团队的获奖级别（赛区奖）
2. 甄选出代表本赛区参加全国总决赛的团队

## 七、全国总决赛评分标准

### 7.1 总决赛形式

全国总决赛包括**作品专项评审**和**总决赛答辩会**两个环节[citation:5]。

### 7.2 总决赛答辩会流程

| 环节 | 具体安排 |
|:---:|:---|
| **分组抽签** | 各队在总决赛答辩会上的分组和出场顺序均通过抽签决定 |
| **作品报告** | 各参赛团队依次报告本队的设计作品（口头报告+演示文档） |
| **即时答辩** | 接受总决赛评审委员会的质询，即时答辩 |

### 7.3 总决赛评分维度

总决赛评审委员会根据以下方面进行**综合评价**[citation:5]：

| 评审项目 | 评审要点 |
|:---:|:---|
| **提交作品质量** | 设计完整性、技术创新性、工程可行性、经济合理性 |
| **口头报告质量** | 报告逻辑、表达清晰度、重点突出性 |
| **答辩表现** | 问题回答准确度、专业知识深度、应变能力 |

## 九、评审特点分析

1. **三级递进评审机制**：校赛→赛区赛→全国总决赛层层递进，校赛筛选基础扎实的队伍，赛区决赛通过答辩评定获奖级别并甄选总决赛团队，全国总决赛综合评审产生最终奖项。

2. **作品评审与现场答辩相结合**：校赛阶段作品评审占70%、现场答辩占30%，赛区决赛和全国总决赛均设置答辩环节，全面考察学生的设计能力和表达沟通能力。

3. **新修订评分实施细则**：2026年竞赛将按照最新修订的评分实施细则评审作品[citation:1]，体现竞赛规则的持续优化和完善。

4. **严格的原创性要求**：要求提交《参赛作品真实性声明及诚信承诺书》，严禁抄袭、剽窃及AI工具直接生成，对学术不端行为实行零容忍。

5. **技术、经济、安全、环保多维评价**：评审涵盖工艺路线、设备选型、经济分析、热集成、风险分析等多个维度，全面考察学生的综合工程能力。

6. **绿色低碳导向**：2026年设计题目明确要求“技术符合中国绿色低碳循环发展要求”，评审中对清洁生产技术和绿色创新给予重点考量。

7. **抽签决定答辩顺序**：全国总决赛通过抽签决定分组和出场顺序，确保评审公平公正。

**注意**：以上评审规则综合参考了全国大学生化工设计竞赛官网通知、第二十届竞赛任务书及相关高校校赛通知。2026年竞赛将按照新修订的评分实施细则评审作品，具体细则请至竞赛官网“下载中心”下载[citation:1]。每届竞赛的具体评分细则以当届发布的官方通知为准。
