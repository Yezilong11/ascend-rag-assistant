# 全国大学生金相技能大赛 - 评分标准

**来源网址**: https://www.jxds.tech/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国大学生金相技能大赛是由教育部高等学校材料类专业教学指导委员会指导的国家级学科竞赛，最初由清华大学、北京科技大学、天津大学、国防科技大学、昆明理工大学、重庆大学、东南大学、中南大学、湖南大学、郑州大学、上海应用技术学院（现上海应用技术大学）等高校联合发起。第一届全国大学生金相技能大赛于2012年12月在北京科技大学举办，此后每年举办一届[citation:2]。

2015年8月，教育部高等学校材料类专业教学指导委员会正式发文，决定作为大赛的主办单位对大赛的组织工作进行具体指导。自此，全国大学生金相技能大赛成为一项得到教育部有关部门认可的全国性大学生赛事。2020年2月22日，大赛被正式纳入中国高等教育学会《全国普通高校大学生竞赛排行榜》[citation:2]。

**大赛宗旨**：以赛促教，以赛促改，以赛促学，不断提高人才培养质量[citation:1]。通过“以赛代练”的模式提升学生的专业技能、工匠精神、艺术审美和科学素养，为全国材料专业的大学生搭建良好的交流平台，引导大学生努力成为精于一技、专于一业的高技能人才[citation:2]。

## 二、赛道设置

目前，全国大学生金相技能大赛共开设三个赛道[citation:7]：

| 赛道 | 名称 | 设置时间 | 核心内容 |
|:---:|:---|:---:|:---|
| **第一赛道** | 实验技能赛道 | 2012年（第一届） | 金相样品制备技能 |
| **第二赛道** | 综合分析赛道（金相大会） | 2023年（第十二届） | 材料科学理论知识 |
| **第三赛道** | 创新应用赛道（材料分析大赛） | 2025年（第十四届） | 材料分析技术创新应用 |

## 三、实验技能赛道（第一赛道）评分标准

### 3.1 竞赛内容与流程

在金相技能大赛中，选手通过现场抽签的方式，从工业纯铁、20钢和球墨铸铁三种样品中随机抽取两种作为决赛样品，按照竞赛规则要求，在规定时间内完成样品的制备[citation:2]。每个指定样品需经过磨制、抛光、浸蚀、显微镜观察等工序，最终制备出供评委评分的样品[citation:3][citation:6]。

**时间限制**：每位选手须在**30分钟内**对样品的指定端面完成全部制备工序[citation:3][citation:4]。

### 3.2 评分构成

每位选手每个样品的实际得分由三部分构成[citation:3][citation:6]：

| 评分项目 | 说明 |
|:---:|:---|
| **金相图像质量** | 显微镜下观察到的组织清晰度、对比度、均匀性 |
| **样品表面质量** | 样品表面平整度、划痕控制、清洁度、无腐蚀残留 |
| **现场操作规范** | 操作流程规范性、设备使用正确性、安全规范遵守 |

### 3.3 详细评分细则

根据重庆理工大学叶宏老师从全国大赛评审角度带来的“技术解码”，评分细则包括[citation:9]：

| 评分维度 | 评审要点 |
|:---:|:---|
| **表面平整度** | 样品表面无明显起伏、无倾斜、无倒角 |
| **划痕控制** | 无粗大划痕，细划痕均匀分布，不影响组织观察 |
| **组织质量** | 组织清晰可辨，相界分明，无假象、无腐蚀过度或不足 |
| **边缘情况** | 边缘无倒角、无塌边、无残留 |
| **清洁度** | 样品表面无污渍、无腐蚀液残留、无水渍 |
| **操作规范** | 磨制手法正确、抛光时间恰当、腐蚀程度适中 |

### 3.4 评审方式

评委从金相图像质量、样品表面质量和操作规范三个方面，对选手的实验技能进行评比考评[citation:2]。

## 四、综合分析赛道（第二赛道）评分标准

### 4.1 竞赛内容

综合分析赛道又称“金相大会”，自2023年第十二届大赛开始设置[citation:7]。命题涉及的内容为面向材料类、机械类各专业所开设的基础核心课程中的知识点、实验方法、典型案例分析[citation:3][citation:4]。

**知识范围**：
- 《材料科学基础》
- 《金属学及热处理》
- 《金相分析技术》
- 《材料工程基础》
- 《金属工艺学》
- 《材料及热加工工艺》
- 《失效分析》等

**扩展内容**：融入材料学科的发展史、科学家与贡献，以及与材料相关的热点话题等[citation:3]。

### 4.2 考试形式与评分

| 项目 | 具体要求 |
|:---:|:---|
| **考试方式** | 统一在线答题（学习通等平台）[citation:3] |
| **题目类型** | 判断题、单选题、多选题[citation:3][citation:4] |
| **总分** | 100分 |
| **考试时间** | 60分钟[citation:3][citation:4] |

## 五、创新应用赛道（第三赛道）评分标准

### 5.1 赛道定位

创新应用赛道又称“全国大学生材料分析大赛”，自2025年第十四届大赛开始设置[citation:7]。竞赛特色是理论联系实际，赛课结合、赛教结合。竞赛内容涵盖材料设计、合成、制备、加工以及服役全过程中的材料分析技术的应用，依托材料分析测试技术课程及其相关材料专业课程，以全面检验和加强参赛学生的理论基础和实践创新能力[citation:8]。

### 5.2 竞赛形式

采用校赛（预赛）-区赛（复赛）-国赛（决赛）三级赛制[citation:8]。

**预赛形式**：自选课题答辩方式进行[citation:8]。

| 环节 | 时长 | 内容 |
|:---:|:---:|:---|
| **PPT汇报** | 5分钟 | 就一个自选的原创性材料类研究课题进行汇报，偏重于研究中所使用的分析测试方法在研究中起到的作用 |
| **评委提问** | 7分钟 | 着重考察选手对所使用的分析测试方法基本原理及其应用的理解和掌握程度 |

### 5.3 课题类别

答辩内容所涉及的原创性研究课题可以是以下两类之一[citation:8]：

| 类别 | 说明 |
|:---:|:---|
| **创新类** | 选手参与的材料类科研类项目 |
| **创意类** | 选手针对特定的材料应用中的实际问题，提出研究背景、目标、技术思路、可行性和创新性方案（虚拟性课题，侧重提出材料分析设想，关键技术思路，可以不要求获得完整的实验数据） |

### 5.4 作品要求

| 要求 | 具体规定 |
|:---:|:---|
| **原创性** | 参赛作品必须是参赛者原创或获得原作者授权的科研训练或发表论文的实际内容，不得抄袭或剽窃他人的研究成果[citation:8] |
| **科学性** | 材料分析的方法、数据、结论等应具有科学性，符合相关的学术规范和实验标准[citation:8] |
| **完整性** | 参赛作品应包含完整的材料分析过程，从材料的选取、实验设计、数据采集到结果分析和结论推导等环节都要清晰呈现[citation:8] |
| **规范性** | 对于提交的材料格式、图表制作、参考文献引用等方面应符合一定的规范要求[citation:8] |

### 5.5 评审标准

由专业评委组成评审组对汇报及问答环节进行评审[citation:8]：

| 评审项目 | 评审要点 |
|:---:|:---|
| **学术价值** | 课题内容对材料科学领域的理论贡献、对现有知识体系的拓展或完善等方面价值 |
| **创新价值** | 参赛作品在材料分析方法、技术应用、研究思路等方面的创新程度 |
| **表达能力** | 参赛者的口头表达能力、PPT制作水平、现场演示的效果 |
| **技术理解** | 选手回答问题时对表征技术应用的理解、对表征结果的理解深度 |

## 六、校赛选拔参考标准

各高校在校赛选拔中，通常参照国赛标准执行。以下为部分高校校赛规则参考：

### 6.1 笔试内容（部分高校）

| 笔试项目 | 内容要求 |
|:---:|:---|
| **《我对金相的认识》** | 针对比赛样品金相显微图片，写出其材料种类、显微组织特征、制样存在问题及如何改进等内容。字数不少于500字，要求字迹工整，条理清晰，有真情实感[citation:1] |
| **金相大会题库** | 在线答题，内容涵盖材料科学基础知识[citation:1] |

### 6.2 第三赛道校赛参考

部分高校在组织第三赛道校赛时，采用以下方式[citation:1]：
- 材料分析相关内容PPT演讲，时长**20分钟**

## 七、奖项设置

### 7.1 全国总决赛奖项

全国总决赛设立个人奖项（金、银、铜牌）和团体奖项。大赛官网设有“获奖证书查验”页面，可查验自第五届以来的所有电子版证书[citation:7]。

**奖牌统计**：大赛官网设有按学校统计的“金牌总数、银牌总数、铜牌总数”排行榜[citation:7]。

### 7.2 校赛奖项设置（参考）

| 奖项 | 获奖比例 |
|:---:|:---|
| **一等奖** | 参赛人数的5%[citation:1] |
| **二等奖** | 参赛人数的10%[citation:1] |
| **三等奖** | 参赛人数的20%[citation:1] |
| **优秀奖** | 根据实际情况确定 |

## 八、参赛资格与要求

### 8.1 参赛对象

| 要求类型 | 具体规定 |
|:---:|:---|
| **参赛对象** | 普通高等教育本科院校正式注册的全日制在校本科生[citation:1][citation:3] |
| **专业要求** | 材料类、机械类相关专业为主，部分高校不限专业[citation:3] |
| **组队形式** | 单人组队[citation:1][citation:6] |
| **指导教师** | 每名选手可有1名指导教师，每位指导教师指导最多3名学生[citation:5] |

### 8.2 安全要求

所有进入实验室进行实验操作的人员必须完成实验室安全准入考试，未通过者不得进入实验室参加选拔赛[citation:10]。

### 9.1 组织架构

全国大学生金相技能大赛设有完善的规章制度体系[citation:7]：

| 机构/文件 | 作用 |
|:---:|:---|
| **全国大学生金相技能大赛章程** | 大赛基本法 |
| **竞赛委员会工作条例** | 规范竞赛委员会工作 |
| **实验技能赛道组织办法** | 规范第一赛道组织 |
| **实验技能赛道决赛评审工作条例** | 规范决赛评审工作 |
| **综合分析赛道组织办法** | 规范第二赛道组织 |
| **创新应用赛道组织办法** | 规范第三赛道组织 |
| **制样通用操作规程** | 统一制样操作标准 |

### 9.2 评审原则

大赛建立了一整套行之有效的机制确保大赛在规章制度框架下的**公平、公正、公开**[citation:7]。

## 十、评审特点分析

1. **三赛道分类评价**：实验技能赛道侧重动手能力，综合分析赛道考察理论知识，创新应用赛道评估科研创新思维，评分标准精准体现各赛道特点。

2. **操作规范与结果并重**：第一赛道不仅看最终金相图像质量，还关注样品表面质量和操作规范，体现“工匠精神”的培养导向。

3. **时间严格限制**：30分钟内完成全部制样工序，考察选手的时间管理能力和临场应变能力。

4. **理论与实践结合**：第二赛道通过在线答题考察理论知识，第三赛道通过课题答辩考察科研创新，形成“动手-理论-创新”三位一体的评价体系。

5. **严格的原创性要求**：第三赛道特别强调作品的原创性，不得抄袭或剽窃他人成果，确保学术诚信。

6. **完善的组织体系**：建立从章程到操作规程的完整规章制度体系，确保评审工作的规范性和权威性。

7. **安全准入前置**：强调实验室安全准入考试，将安全意识纳入参赛资格要求。
