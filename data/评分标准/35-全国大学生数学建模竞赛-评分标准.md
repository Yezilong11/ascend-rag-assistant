# 全国大学生数学建模竞赛 - 评分标准

**来源网址**: http://www.mcm.edu.cn/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国大学生数学建模竞赛（Contemporary Undergraduate Mathematical Contest in Modeling，简称CUMCM）创办于1992年，每年一届，是首批列入“高校学科竞赛排行榜”的19项竞赛之一，由中国工业与应用数学学会主办。目前，该竞赛已成为世界上规模最大的数学建模竞赛 [citation:5]。

**2025年竞赛规模**：来自全国及美国、英国、加拿大、芬兰、马来西亚等国家的1837所院校/校区、68311队（本科61463队、高职高专6848队）、20多万人报名参赛 [citation:5]。

**竞赛宗旨**：激励学生学习数学的积极性，提高学生建立数学模型和运用计算机技术解决实际问题的综合能力，鼓励广大学生踊跃参加课外科技活动，开拓知识面，培养创造精神及合作意识，推动大学数学教学体系、教学内容和方法的改革 [citation:7]。

**竞赛方式**：采取通讯竞赛方式，全国统一竞赛题目，以队为单位参赛 [citation:7]。

**主办单位**：中国工业与应用数学学会

## 二、竞赛内容与要求

### 2.1 竞赛内容

竞赛题目一般来源于科学与工程技术、人文与社会科学（含经济管理）等领域经过适当简化加工的实际问题，不要求参赛者预先掌握深入的专门知识，只需要学过高等学校的数学基础课程。题目有较大的灵活性供参赛者发挥其创造能力 [citation:5][citation:7]。

### 2.2 论文要求

参赛者应根据题目要求，完成一篇包括以下内容的论文（答卷）：

| 组成部分 | 核心内容 |
|:---:|:---|
| **模型假设** | 对实际问题进行合理简化与假设 |
| **模型建立** | 建立数学模型描述问题 |
| **模型求解** | 计算方法的设计和计算机实现 |
| **结果分析** | 对求解结果进行分析和检验 |
| **模型改进** | 对模型的不足进行讨论和展望 |

### 2.3 论文格式规范

根据《全国大学生数学建模竞赛论文格式规范（2026年修订稿）》，论文需满足以下要求 [citation:6]：

| 项目 | 具体要求 |
|:---:|:---|
| **篇幅限制** | 正文不超过30页，附录页数不限 |
| **摘要页** | 第三页为摘要专用页，内容（含标题和关键词）原则上不超过一页 |
| **匿名要求** | 论文摘要专用页、正文和附录中任何地方都不能有显示参赛者身份和所在学校及赛区的信息 |
| **参考文献** | 所有引用他人或公开资料的成果必须按照科技论文规范列出参考文献 |
| **源程序** | 附录必须包含建模所用到的全部完整、可运行的源程序代码 |
| **文件格式** | 电子版论文为PDF或Word格式，大小不超过20MB |
| **支撑材料** | 包含源程序、数据资料等，压缩后不超过20MB |

### 2.4 人工智能工具使用规定

参赛队员可以使用人工智能（AI）工具作为辅助，但各参赛队必须对所提交作品的原创性、真实性和准确性负全部责任，并遵守《全国大学生数学建模竞赛人工智能工具使用规定》 [citation:1][citation:2]。

## 三、参赛要求

### 3.1 组队要求

| 要求类型 | 具体规定 |
|:---:|:---|
| **参赛对象** | 在校大学生，研究生不得参加 [citation:7] |
| **组队人数** | 每队不超过3人（须属于同一所学校），专业不限 [citation:7] |
| **竞赛分组** | 分本科、专科两组进行，本科生参加本科组竞赛，专科生可参加专科组或本科组竞赛 [citation:7] |
| **指导教师** | 每队最多可设一名指导教师或教师组，从事赛前辅导和参赛的组织工作 [citation:7] |

### 3.2 竞赛纪律

根据《全国大学生数学建模竞赛参赛规则（2026年修订稿）》，主要纪律要求如下 [citation:1][citation:2]：

| 纪律类型 | 具体规定 |
|:---:|:---|
| **独立完成** | 各参赛队必须独立完成赛题解答 |
| **交流限制** | 严禁参赛队员以任何方式与队外任何人（包括指导教师）交流、讨论任何与赛题有关的问题 |
| **平台限制** | 不得在任何交流平台（贴吧、QQ群、微信群、知乎、小红书、CSDN、GitHub等）浏览、发布或讨论与赛题相关的内容 |
| **指导教师限制** | 指导教师在竞赛期间不得通过任何方式对参赛学生进行任何形式的指导 |
| **抄袭禁止** | 抄袭是严重违反竞赛纪律的行为，引用他人成果必须规范标注 |

### 3.3 违规处理

| 违规情形 | 处理措施 |
|:---:|:---|
| **违反承诺或规范** | 无条件取消评奖资格 [citation:1] |
| **指导教师违纪** | 全国组委会两年内不受理该指导教师指导学生参赛的报名申请 [citation:1] |
| **严重违纪** | 无条件取消评奖资格，并视情节给予相应处理 [citation:1] |
| **学术不端** | 取消评奖资格，公开通报批评 [citation:1] |

## 四、评审标准

### 4.1 核心评审维度

竞赛评奖以以下四个维度为主要标准 [citation:5][citation:7]：

| 评审维度 | 权重 | 评审要点 |
|:---:|:---:|:---|
| **假设的合理性** | 25% | 模型假设是否合理、是否符合实际问题背景 |
| **建模的创造性** | 30% | 模型的创新程度、解决问题的方法是否新颖独特 |
| **结果的正确性** | 25% | 计算结果是否准确、分析是否合理、结论是否可靠 |
| **文字表述的清晰程度** | 20% | 论文结构是否清晰、逻辑是否严谨、表达是否准确 |

### 4.2 具体评审要点

| 评审项目 | 评审要点 |
|:---:|:---|
| **问题理解** | 对问题背景的理解深度、问题重述的准确性 |
| **模型假设** | 假设的合理性、完整性、与实际问题的契合度 |
| **模型建立** | 数学模型的正确性、适用性、创新性 |
| **模型求解** | 计算方法的选择、算法设计、计算机实现 |
| **结果分析** | 结果的合理性、敏感性分析、误差分析 |
| **模型检验** | 模型的验证、与实际数据的对比 |
| **模型改进** | 对模型局限性的认识、改进方向的合理性 |
| **论文写作** | 结构完整性、逻辑清晰度、表达准确性 |
| **程序实现** | 源程序的完整性、可运行性、与论文的一致性 |

### 4.3 一票否决项

以下情况将导致论文被无条件取消评奖资格 [citation:1][citation:2][citation:6]：

| 情形 | 说明 |
|:---:|:---|
| **违反承诺或规范** | 未履行《全国大学生数学建模竞赛承诺书》中的承诺 |
| **抄袭** | 大篇幅照抄他人成果，未按规定引用 |
| **违纪交流** | 在竞赛期间与队外人员交流讨论赛题 |
| **缺少源程序** | 附录中缺少必要的源程序，或程序不能运行 |
| **论文不符** | 支撑材料文件与论文内容不相符 |
| **泄露信息** | 论文中出现显示参赛者身份和所在学校及赛区的信息 |

## 五、评审流程

### 5.1 两级评审机制

竞赛采用“赛区评阅—全国评阅”两级评审机制：

| 评审阶段 | 评审方式 | 主要职责 |
|:---:|:---:|:---|
| **赛区评阅** | 各赛区组织专家评阅 | 评定赛区奖项，推荐优秀论文参加全国评阅 |
| **全国评阅** | 全国组委会组织专家评阅 | 评定全国奖项，确定最终获奖名单 |

### 5.2 赛区评阅

各赛区评阅专家组严格按照《章程》和《规范》要求对违纪行为把关，并将发现的违纪行为书面报告赛区组委会和全国组委会 [citation:1]。

### 5.3 全国评阅

全国评阅专家组对各赛区推荐的论文进行复审，最终确定全国奖项。对于查处违纪行为高度负责的赛区，全国组委会将予以表彰；对于查处违纪行为严重不负责任的赛区，将按一定比例缩减该赛区下一年度送全国评阅的论文数量 [citation:1]。

## 六、奖项设置

### 6.1 全国奖项

| 奖项 | 说明 |
|:---:|:---|
| **全国一等奖** | 全国组委会颁发证书 |
| **全国二等奖** | 全国组委会颁发证书 |

### 6.2 赛区奖项

各赛区根据参赛队伍数量按一定比例评选赛区一、二、三等奖。

### 6.3 优秀组织工作奖

对组织工作突出的赛区和学校，全国组委会授予优秀组织工作奖 [citation:1]。

## 七、评审特点分析

1. **四维核心评价体系**：以“假设的合理性、建模的创造性、结果的正确性、文字表述的清晰程度”为核心评价标准，全面考察学生的建模能力、创新思维和学术表达能力 [citation:5][citation:7]。

2. **创造性权重最高**：建模的创造性权重达30%，体现竞赛对创新思维的高度重视，鼓励学生在解决问题时提出新颖独特的方法。

3. **严格的原创性要求**：设置多重防抄袭机制，要求规范引用参考文献，严禁大篇幅照抄，对学术不端行为实行零容忍 [citation:1][citation:2]。

4. **程序实现刚性要求**：附录必须包含全部完整、可运行的源程序代码，缺少必要源程序或程序不能运行将取消评奖资格，确保成果的真实性和可复现性 [citation:6]。

5. **匿名评审制度**：论文任何地方不得出现显示参赛者身份和所在学校及赛区的信息，确保评审的公平公正 [citation:6]。

6. **AI工具规范使用**：2026年新规明确允许使用AI工具作为辅助，但要求参赛队对作品的原创性、真实性和准确性负全部责任 [citation:1]。

7. **竞赛纪律严格**：竞赛期间严禁与队外任何人交流讨论赛题，严禁在各种网络平台发布或讨论与赛题相关的内容，确保竞赛的公平性 [citation:1]。

8. **篇幅控制要求**：正文不超过30页，摘要不超过一页，要求参赛队在有限的篇幅内清晰完整地呈现研究成果。
