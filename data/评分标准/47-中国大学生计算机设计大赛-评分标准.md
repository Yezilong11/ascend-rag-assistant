# 中国大学生计算机设计大赛 - 评分标准

**来源网址**: http://jsjds.blcu.edu.cn/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

中国大学生计算机设计大赛（简称“4C”或“大赛”）是我国高校面向本科生最早的赛事之一，始筹于2007年，首届于2008年举办[citation:1]。大赛由教育部计算机相关教指委创办，现由中国大学生计算机设计大赛组织委员会主办[citation:1][citation:5]。自2019年开始，大赛一直是全国普通高校大学生竞赛排行榜的榜单赛事之一，名列全国普通高校大学生计算机类竞赛列表第3位[citation:1][citation:6]。

**大赛宗旨**：以赛促学、以赛促教、以赛促创，为国家培养德智体美劳全面发展的创新型、复合型、应用型人才服务[citation:1][citation:5]。

**大赛性质**：非营利的、公益性的、科技型的群众活动，遵循“三公”原则，即公开、公平、公正[citation:10]。

**第十九届（2026年）竞赛信息**：
- **参赛对象**：全国高校当年在籍本科生（含粤港澳大湾区学生及来华留学生）[citation:5]
- **竞赛形式**：校级赛、省级赛、国家级赛三级竞赛形式[citation:5]
- **校赛时间**：3月-4月
- **省赛时间**：5月
- **国赛时间**：7月-8月[citation:8]

## 二、大赛分类与主题

### 2.1 大赛分类

2025年（第18届）大赛分设11个大类，2026年（第19届）预计延续此分类[citation:2][citation:8]：

| 序号 | 大类名称 | 说明 |
|:---:|:---|:---|
| 1 | 软件应用与开发 | Web应用、管理信息系统、移动应用开发、算法设计等 |
| 2 | 微课与AI辅助教学 | AI通识课、中小学教学、唐诗宋词微课等 |
| 3 | 物联网应用 | 物联网创新转化（创业实践） |
| 4 | 大数据应用 | 大数据分析与应用 |
| 5 | 人工智能应用 | AI算法与应用 |
| 6 | 信息可视化设计 | 数据可视化、信息图表 |
| 7 | 数媒静态设计 | 平面设计、静态数字媒体 |
| 8 | 数媒动漫与短片 | 动画、短视频、微电影 |
| 9 | 数媒游戏与交互设计 | 游戏设计、交互应用 |
| 10 | 计算机音乐创作 | 数字音乐创作 |
| 11 | 国际生“汉学” | 来华留学生参赛类别 |

### 2.2 大赛主题

| 类别 | 主题要求 |
|:---:|:---|
| **数媒类与计算机音乐创作类** | 中国古代物理——中华优秀传统文化系列之五（限1911年前）[citation:2][citation:7] |
| **信息可视化设计类** | 中华自然科学及其它优秀文化瑰宝（限1911年前）[citation:2][citation:7] |
| **国际生“汉学”类** | 中国古代文化相关成就（限1911年前）[citation:2][citation:7] |

## 三、参赛要求

### 3.1 组队要求

| 要求类型 | 具体规定 |
|:---:|:---|
| **参赛对象** | 全国高校当年在籍本科生[citation:5] |
| **组队人数** | 每件作品由同一所院校的**2～5名本科生**组成[citation:2][citation:5] |
| **指导教师** | 每队指导教师不多于2名[citation:2][citation:8] |
| **参赛限制** | 每位作者在每个大类中只能提交1件作品[citation:2][citation:5] |
| **答辩要求** | 每队到国赛决赛现场参与答辩的作者不少于2人[citation:2][citation:5] |

### 3.2 作品原创性要求

| 要求 | 具体规定 |
|:---:|:---|
| **原创时间** | 必须是参赛作者在本届大赛期间（2024.7.1～2025.6.30）完成的原创作品[citation:5] |
| **禁止重复参赛** | 与2024.7.1之前校外展出或获奖的作品雷同的不得重复参赛[citation:5] |
| **一稿多投禁止** | 参赛作品不得在本大赛的11个大类间一稿多投[citation:5] |
| **知识产权** | 参赛作品的版权必须属于参赛作者，不得侵权；凡已经转让知识产权或不具有独立知识产权的作品，均不得参赛[citation:5] |
| **数据合规** | 作品数据应来源合规、信息处理恰当，不得引用涉密数据，不得侵犯个人隐私[citation:5] |

### 3.3 地图使用规范

参赛作品中凡是包含涉及国界、边界、历史疆界、行政区域界线或者范围的地图，必须符合中华人民共和国自然资源部颁布的《公开地图内容表示规范》要求，并在地图出现之处明确注明审图号和地图来源，严禁使用未经过审核、私自篡改、来源不明的地图[citation:5]。

### 3.4 数媒类专业组界定

数媒各大类参赛作品参赛时，按普通组与专业组分别进行[citation:2]。专业组涵盖的专业包括：

| 学科门类 | 专业清单 |
|:---:|:---|
| 教育学类 | 艺术教育 |
| 新闻传播学类 | 广播电视学、广告学、网络与新媒体、数字出版 |
| 机械类 | 工业设计 |
| 计算机类 | 数字媒体技术、新媒体技术、电影制作、虚拟现实技术 |
| 建筑类 | 建筑学、城乡规划、风景园林等 |
| 林学类 | 园林 |
| 戏剧与影视学类 | 电影学、广播电视编导、动画、影视技术等 |
| 美术学类 | 美术学、绘画、雕塑、摄影、书法学、中国画、漫画等 |
| 设计学类 | 艺术设计学、视觉传达设计、环境设计、产品设计、数字媒体艺术等 |

## 四、竞赛形式与赛程安排

### 4.1 三级竞赛形式

大赛以**校级赛、省级赛、国家级赛**三级竞赛形式开展[citation:2][citation:5]：

| 竞赛阶段 | 时间安排 | 主要内容 |
|:---:|:---:|:---|
| **校级赛** | 3月-4月 | 校内选拔，推荐优秀作品参加省级赛[citation:8] |
| **省级赛** | 5月 | 省级评审，选拔作品上推国赛[citation:8] |
| **国赛决赛** | 7月-8月 | 全国集中评审，确定最终奖项[citation:2] |

**国赛只接受省级赛上推的本科生的参赛作品**[citation:5]。

### 4.2 国赛决赛区设置

第18届国赛共组合为5个决赛区[citation:7]：

| 决赛区 | 作品类别 | 承办单位 |
|:---:|:---|:---|
| **上海赛区** | 大数据应用/数媒游戏与交互设计/国际生“汉学” | 华东理工大学 |
| **南京南赛区** | 微课与AI辅助教学/数媒静态设计 | 南京大学 |
| **济南赛区** | 软件应用与开发 | 泰山学院 |
| **杭州赛区** | 物联网应用/信息可视化设计/计算机音乐创作 | 浙江理工大学 |
| **南京东赛区** | 人工智能应用/数媒动漫与短片 | 江西师范大学 |

## 五、评审体系

### 5.1 评审组织机构

大赛设有专家委员会，负责国赛作品的评审工作。评审标准具有**科学性、公正性和前瞻性**，既要注重作品的技术创新，也要关注其实际应用价值和社会影响力[citation:6]。

### 5.2 评审基本原则

| 原则 | 具体内容 |
|:---:|:---|
| **公平、公正、公开** | 严格遵守竞赛规则，操作规范、透明[citation:10] |
| **技术创新与应用价值并重** | 既注重作品的技术创新，也关注实际应用价值和社会影响力[citation:6] |
| **企业评委参与监督** | 企业直接参加命题，企业评委参加评审监督[citation:10] |
| **答辩形式规范** | 答辩形式贴近毕业生论文答辩、就业面试，对参赛学生具有实用意义[citation:10] |

### 5.3 通用评审维度

根据第18届大赛国赛作品评审标准落实研讨会的内容，评审围绕以下核心维度展开[citation:6]：

| 评审维度 | 评审要点 |
|:---:|:---|
| **技术创新** | 技术难度、算法创新、实现复杂度、AI技术应用深度 |
| **作品创意** | 创意的新颖性、独特性、创新思维 |
| **应用价值** | 实际应用场景、解决问题能力、社会影响力 |
| **设计表达** | 界面设计、用户体验、视觉美感 |
| **技术实现** | 功能完整性、系统稳定性、代码规范性 |
| **作品规范** | 是否符合命题要求、格式规范、文档完整性 |

### 5.4 各类别评审侧重

| 作品类别 | 评审侧重 |
|:---:|:---|
| **软件应用与开发** | 系统架构、算法效率、功能完整性、用户体验[citation:2] |
| **微课与AI辅助教学** | 教学设计、AI技术应用、互动性、教学效果[citation:2] |
| **物联网应用** | 硬件集成、数据传输、系统稳定性、创新应用 |
| **大数据应用** | 数据挖掘深度、分析算法、可视化呈现、洞察价值 |
| **人工智能应用** | 模型准确性、算法创新、应用场景、技术难度 |
| **信息可视化设计** | 数据转化能力、视觉设计、交互体验、信息传达效率 |
| **数媒类作品** | 创意表达、艺术表现、技术实现、主题契合度[citation:2] |
| **计算机音乐创作** | 音乐性、技术应用、创意表达、制作质量 |

### 5.5 答辩评审标准

国赛决赛采用现场答辩形式，每件作品答辩时，到场作者不少于2名，作者陈述（含作品演示）不超过10分钟[citation:2]。

| 评审项目 | 评审要点 |
|:---:|:---|
| **作品陈述** | 逻辑清晰、重点突出、时间控制合理 |
| **作品演示** | 功能展示完整、运行流畅、效果直观 |
| **现场答辩** | 问题回答准确、专业知识扎实、应变能力 |
| **团队协作** | 团队成员分工配合、整体表现协调性 |

## 六、特色作品点评机制

大赛设有特色作品点评环节，成为师生交流学习的平台[citation:10]。对不同大类的作品，评审组选出特色作品，由学生与指导教师介绍构思创作过程，评审专家对作品的优点与存在问题进行点评，参与的其他师生可以现场质疑，上下互动，以达到互相切磋学习的目的[citation:10]。

## 七、奖项设置

### 7.1 校级赛奖项

| 奖项 | 获奖比例 |
|:---:|:---|
| **校级赛一等奖** | 各校自行制定 |
| **校级赛二等奖** | 各校自行制定 |
| **校级赛三等奖** | 各校自行制定 |

**晋级规则**：校级赛以不多于合格作品**50%** 上推给省级赛[citation:9][citation:10]。

### 7.2 省级赛奖项

| 奖项 | 建议比例 |
|:---:|:---:|
| **省级赛一等奖** | 不高于参加省级赛有效作品数的10%[citation:9] |
| **省级赛二等奖** | 不高于20%[citation:9] |
| **省级赛三等奖** | 30～40%[citation:9] |

**晋级规则**：省级赛以不多于合格作品**20%** 上推给国赛[citation:10]。各个省级赛区组委会可将不超过上推限额的、按作品小类排名在省级赛前30%的优秀作品，上推入围国赛[citation:5]。

### 7.3 国赛决赛奖项

| 奖项 | 获奖比例 | 说明 |
|:---:|:---:|:---|
| **一等奖** | 不多于有效参赛作品数的5%[citation:2][citation:9] | 国赛最高荣誉 |
| **二等奖** | 不少于有效参赛作品数的25%[citation:2][citation:9] | 一等奖与二等奖合计为30%[citation:10] |
| **三等奖** | 不多于有效参赛作品数的30%[citation:9] | |
| **优胜奖/入围奖** | 其余作品 | |

### 7.4 其他奖项

| 奖项 | 说明 |
|:---:|:---|
| **优秀指导教师奖** | 指导作品获得优异成绩的教师 |
| **优秀组织奖** | 组织工作突出的单位 |

### 7.5 获奖质量保障

大赛实行限额设奖，奖项具有相当的质量和权威性。参赛院校平均得奖数不少于3个[citation:10]。

## 八、学术诚信与违规处理

### 8.1 违规作品处理

| 违规情形 | 处理措施 |
|:---:|:---|
| **含有违法违规内容** | 一经发现，即刻取消参赛资格及所获奖项，参赛师生自负一切法律责任[citation:5] |
| **剽窃、抄袭** | 竞赛委员会有权拒绝其参加比赛或撤销奖项，并通报参赛选手所在学院[citation:8] |
| **已获奖作品重复参赛** | 已经获得同级别或高于本竞赛奖项的作品不得参与本竞赛[citation:8] |
| **信息变更违规** | 在获得国赛参赛资格后，其作者与指导教师的姓名和排序，不得变更[citation:5] |
| **不尊重大赛纪律** | 竞赛期间不私下接触专家、评委，不说情、不请托，不公开发表或传播对大赛产生不利影响的言论，违规者取消参赛资格[citation:5] |

### 8.2 违规作品公示

大赛官网上将公布违规作品的作品编号、作品名称、作者与指导教师姓名、相关人员所在学校校名，以及所在省级赛区名[citation:5]。

### 8.3 投诉与举报

投诉和举报时，应有理有据并实名向相应的校级、省级或国家级组委会提交资料。对于缺乏证据、借投诉名义公开发表或传播对大赛不利的言论者，或向同一级组委会重复投递已被否定的投诉信息的投诉者，将被取消本届的参赛资格及其参赛作品所获奖项（如有），并自负一切法律责任[citation:5]。

## 九、评审特点分析

1. **三级递进评审机制**：校级赛→省级赛→国家级赛层层递进。校级赛以不多于合格作品50%上推省赛，省赛以不多于合格作品20%上推国赛，国赛一等奖不多于5%，确保获奖作品的质量和权威性[citation:9][citation:10]。

2. **11大类分类评价**：大赛分设11个大类，每类作品都有其独特的评审侧重点，从技术创新、作品创意、应用价值、设计表达等多个维度进行全面评价[citation:2][citation:6]。

3. **技术创新与应用价值并重**：评审标准既注重作品的技术创新，也关注其实际应用价值和社会影响力，体现“以赛促创”的宗旨[citation:6]。

4. **企业深度参与**：企业直接参加命题，企业评委参加评审监督，突出产学研结合，使评审更贴近产业实际需求[citation:10]。

5. **特色作品点评机制**：评审组选出特色作品，由学生与指导教师介绍构思创作过程，评审专家进行点评，师生互动交流，使竞赛成为学习平台而非单纯的竞技[citation:10]。

6. **专业组与普通组分类**：数媒各大类按普通组与专业组分别进行，确保不同专业背景的学生公平竞争[citation:2]。

7. **严格的原创性要求**：强调作品必须是本届大赛期间完成的原创作品，禁止重复参赛，对剽窃、抄袭行为零容忍[citation:5][citation:8]。

8. **答辩形式规范实用**：答辩形式贴近毕业生论文答辩、就业面试，以及教师职称评审的答辩，对参赛学生具有实用意义[citation:10]。

9. **地图使用规范刚性要求**：对涉及中国地图的作品有严格的审核要求，必须符合国家规范并注明审图号，体现对国家主权和领土完整的尊重[citation:5]。

10. **获奖比例严格控制**：国赛一等奖不多于5%，一等奖与二等奖合计为30%，拿高等级奖项相当不易，确保奖项的含金量[citation:10]。

---

**注意**：以上评审规则综合参考了中国大学生计算机设计大赛官网、第18届大赛竞赛规程、国赛作品评审标准落实研讨会综述及各高校校赛通知。每届竞赛的具体评分细则以当届发布的官方通知为准，各类别评分标准可能存在差异，请以官网公布的最新版本为准。
