# 全国大学生化学实验创新设计大赛 - 评分标准

**来源网址**: https://cid.nju.edu.cn/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国大学生化学实验创新设计大赛是由中国化学会和教育部高等学校国家级实验教学示范中心联席会联合主办的全国性大学生化学类和近化学类专业多学科综合性竞赛。大赛自2019年起每年举办一届，旨在建立一个大学生实验创新能力的展示与交流平台，推动我国高等学校实验教学改革，夯实大学生的化学基础知识、基本理论和基本技能，强化大学生发现问题、分析问题和解决问题的能力，培养大学生的创新意识、创新精神和创新能力[citation:2]。

**赛事地位**：大赛已连续被纳入中国高等教育学会《全国普通高校大学生竞赛分析报告》竞赛目录，是目前国内化学类学科竞赛中级别最高、影响力最广的赛事之一[citation:9]。

**第五届（2025年）竞赛信息**：
- **全国总决赛承办单位**：太原理工大学（西北赛区）、浙江大学（第四赛道数智化实验全国总决赛已于2024年12月举办）[citation:8]
- **赛区决赛承办单位**：各分赛区分别承办（华中赛区-安徽大学、西北赛区-太原理工大学等）[citation:5][citation:8]

## 二、赛道设置

第五届大赛共设四个赛道：

| 赛道 | 名称 | 核心内容 | 队伍人数 |
|:---:|:---|:---|:---:|
| **第一赛道** | 新创实验 | 科研成果转化为本科教学实验 | 3人 |
| **第二赛道** | 改进实验（含仪器创制/改进） | 对现有实验进行创新设计或仪器改进 | 3人 |
| **第三赛道** | 科普实验 | 面向公众的化学科普实验设计 | 3人 |
| **第四赛道** | 数智化实验 | 数字、AI技术与化学实验深度融合 | 3-5人 |

### 2.1 新创实验赛道

把反映**新知识、新理论、新技术、新方法**的科研成果设计为适合本科生实验教学需要的基础实验或者综合实验[citation:2][citation:6]。

**核心要求**：
- 未在国内外教材、杂志发表
- 经过反复验证，确保可重复
- 时长、成本和安全性符合教学需要
- 基础实验总时长≤8小时，综合实验总时长≤24小时

### 2.2 改进实验赛道（含教学实验仪器创制或改进）

针对现有国内外教材或杂志的教学实验，对**教学内容、教学方法及教学手段进行创新设计**，或对**教学实验仪器进行创制或改进**，使之更加符合实验教学需要，更有利于培养学生的创新思维和科研能力[citation:2][citation:3]。

### 2.3 科普实验赛道

受众为没有或者很少有化学素养的社会公众及中小学生，要求有助于**公众了解和正确认识化学**，**激发青少年学习化学的兴趣和热情**[citation:2]。

**核心要求**：
- 内容反映化学之趣、化学之美、化学对社会发展的贡献
- 安全、绿色、有趣、价廉、便于展示
- 方便公众亲手操作，能给公众留下深刻印象

### 2.4 数智化实验赛道

以真实实验为基础，将**数字、人工智能等技术与化学实验深度融合**，能够全面提升学生的数智意识和数智能力的实验[citation:3][citation:6]。

**设计要求**[citation:6]：
- 基于已有、二次开发或新开发的数学物理模型和数据库
- 对实验场景、实验过程和实验结果进行模拟、预测和评价
- 通过对实验的虚拟呈现、数据获取、判断和处理，实现对实验过程的控制与指导
- 提升学生理解、掌握、运用和拓展实验原理和方法的能力

**可使用的技术**：基于大模型的人工智能技术(AI)、数值模拟与虚拟仿真技术、半实物自动化远程控制技术等多种不同数字化技术及其合理组合[citation:6]。

## 三、竞赛形式与赛程安排

### 3.1 三级赛制

竞赛采用“校赛—分赛区初赛—全国总决赛”三级赛制[citation:2][citation:10]：

| 竞赛阶段 | 时间安排（第五届） | 主要内容 |
|:---:|:---:|:---|
| **校赛** | 3月-5月 | 校内选拔，推荐优秀队伍参加区赛（每校每赛道≤2支，总数≤4支） |
| **分赛区初赛** | 6月-7月 | 作品评审+现场答辩，确定赛区奖项及晋级总决赛名单 |
| **全国总决赛** | 7月-8月 | 作品评审+现场答辩，确定全国奖项 |

### 3.2 分赛区设置

全国共设**七个分赛区**[citation:2]：

| 赛区 | 涵盖省份/地区 |
|:---:|:---|
| **华北赛区** | 北京市、天津市、河北省、山东省 |
| **东北赛区** | 辽宁省、吉林省、黑龙江省、内蒙古自治区 |
| **华东赛区** | 上海市、江苏省、浙江省 |
| **华中赛区** | 湖北省、河南省、安徽省、江西省 |
| **华南赛区** | 广东省、广西壮族自治区、海南省、湖南省、福建省、台湾省、香港、澳门 |
| **西南赛区** | 重庆市、四川省、贵州省、云南省、西藏自治区 |
| **西北赛区** | 山西省、陕西省、甘肃省、青海省、宁夏回族自治区、新疆维吾尔自治区 |

### 3.3 参赛资格与组队要求

| 要求类型 | 具体规定 |
|:---:|:---|
| **参赛对象** | 普通高等院校全日制在校本科生[citation:2] |
| **组队人数** | 第一、二、三赛道：3人/队；第四赛道：3-5人/队[citation:3][citation:6] |
| **指导教师** | 第一、二、三赛道：1-2名；第四赛道：1-3名[citation:3][citation:6] |
| **每人限报** | 每位学生只允许参加一支代表队[citation:8] |
| **每校限报** | 初赛每校最多推荐4个队（同一赛道不超过2支，第四赛道不超过1支）[citation:2][citation:10] |
| **总决赛限报** | 每校进入总决赛队伍不超过1支[citation:2][citation:10] |

### 3.4 作品提交要求

| 材料类型 | 具体要求 |
|:---:|:---|
| **实验论文** | Word版和PDF版（PDF版需匿名，不得出现学校、指导教师、学生等信息）[citation:2][citation:7] |
| **答辩PPT** | 匿名版（不得出现任何相关信息）[citation:2] |
| **实验视频** | 展示实验过程、关键操作和结果[citation:2] |
| **其它附件** | 支撑材料、数据等[citation:2] |

**特别规定**：在作品、视频、附件材料、答辩等环节中出现泄露参赛学校、指导教师和参赛人员信息的，将视严重程度在总成绩中予以扣分。信息第一次泄露扣2分，同一信息多次重复泄露再追加扣1分，总扣分限在10分之内[citation:2]。

## 四、评审体系总览

### 4.1 评审基本原则

大赛本着“公开、公平、公正”的原则，评审工作由专家工作组负责，严格按照竞赛章程和评分标准执行[citation:2]。

### 4.2 成绩构成

**竞赛成绩 = 作品成绩 × 50% + 答辩成绩 × 50%** [citation:2][citation:5][citation:8]

| 评审环节 | 权重 | 评审形式 |
|:---:|:---:|:---|
| **作品评审** | 50% | 专家对实验论文、实验视频等材料进行评审 |
| **现场答辩** | 50% | PPT汇报+专家提问（通常10+10分钟）[citation:5] |

### 4.3 通用评分维度

根据第五届大赛章程，评审围绕以下核心维度展开[citation:2][citation:3][citation:6]：

| 评审维度 | 评审要点 |
|:---:|:---|
| **创新性** | 实验内容、方法、技术的原创性与新颖程度 |
| **科学性** | 实验原理正确性、数据可靠性、分析合理性 |
| **教学适用性** | 是否符合本科实验教学要求，时长、成本、安全性 |
| **完整性** | 实验设计、操作、结果分析的完整程度 |
| **规范性** | 论文撰写规范、图表规范、参考文献规范 |
| **可重复性** | 实验过程可验证、结果可重复 |
| **答辩表现** | 表达逻辑、问题回答准确度、专业知识掌握 |

## 五、各赛道详细评分标准

| 评审项目 | 权重 | 评审要点 |

| **教学效果提升** | 25% | 改进后更有利于培养创新思维和科研能力 |
| **仪器创制/改进价值** | 20% | 仪器创新性、实用性（如涉及） |

| **推广价值** | 15% | 可在其他高校推广的潜力 |

### 5.3 科普实验赛道评审要点

| 评审项目 | 权重 | 评审要点 |
|:---:|:---:|:---|
| **科普效果** | 25% | 能否激发兴趣、传播化学正面形象 |
| **趣味性** | 20% | 实验现象明显、有趣、吸引人 |
| **可操作性** | 20% | 便于公众亲手操作、安全、价廉 |
| **化学内涵** | 15% | 体现化学之美、化学之趣、化学贡献 |
| **安全性** | 10% | 绿色环保、安全无毒 |
| **展示效果** | 10% | 便于展示、印象深刻 |

### 5.4 数智化实验赛道评审要点

根据第五届大赛作品要求，数智化实验赛道评审包括以下八个方面[citation:6]：

| 评审项目 | 权重 | 评审要点 |
|:---:|:---:|:---|
| **数字化必要性** | 15% | 说明实验进行数字化设计的必要性和迫切性 |
| **教学目标实现** | 15% | 通过数字化设计所能够实现的教学目标和教学功能 |
| **科学原型与建模** | 15% | 数字化设计内容的科学原型和原理、数学物理建模过程、数据库及算法 |
| **实验过程设计** | 15% | 实验内容、步骤等设计的合理性 |
| **实验场景呈现** | 10% | 实验装置、反应、现象、产品或实验曲线、数据、图像等 |
| **数据处理** | 10% | 实验记录、结果处理过程及实验报告 |
| **评价机制** | 10% | 评分方法、评分指标与教学目标的对应关系 |
| **技术创新性** | 10% | AI、仿真、远程控制等技术应用的创新程度 |

### 10.1 原创性要求

| 要求 | 具体规定 |

| **真实性承诺** | 各参赛高校对参赛队所提交材料的真实性负责[citation:2] |
| **知识产权** | 参赛作品须具备自有或许可的知识产权，否则引起的法律纠纷由作品团队承担[citation:4] |

### 10.2 违规处理

| 违规情形 | 处理措施 |
|:---:|:---|
| **信息泄露** | 第一次泄露扣2分，同一信息多次泄露追加扣1分，总扣分≤10分[citation:2] |
| **抄袭剽窃** | 取消参赛资格、成绩无效、通报批评[citation:2] |
| **AI工具滥用** | 严禁使用生成式AI直接生成全文或核心设计内容并隐瞒使用事实 |
| **资格造假** | 一经查实，取消获奖资格并通报所在学校 |

### 10.3 异议处理

| 事项 | 规定 |
|:---:|:---|

| **仲裁机构** | 督查仲裁组（3-5人）负责仲裁，结果为最终裁定[citation:2] |

## 十一、评审特点分析

1. **四赛道分类评价**：新创实验、改进实验、科普实验、数智化实验四个赛道各有侧重，评分标准精准匹配各类型实验特点，体现“因类施评”的科学评价理念[citation:2][citation:6]。

2. **作品与答辩并重**：竞赛成绩由作品成绩和答辩成绩各占50%，既考察实验设计的质量，也考察学生的表达沟通能力和临场应变能力[citation:5][citation:8]。

3. **三级递进评审机制**：校赛→分赛区初赛→全国总决赛层层递进，初赛成绩不带入决赛，确保全国总决赛的公平公正[citation:2]。

4. **匿名评审制度**：作品PDF版、答辩PPT、实验视频等材料均需隐匿学校、指导教师、学生信息，确保评审的客观公正[citation:2][citation:7]。

5. **严格的信息泄露扣分制**：在作品或答辩环节泄露信息将面临扣分，总扣分可达10分，体现对评审纪律的高度重视[citation:2]。

6. **数智化实验特色评价**：第四赛道从数字化必要性、教学目标实现、科学建模、算法应用等8个维度进行评价，体现对AI、仿真、远程控制等前沿技术在化学实验中应用的重视[citation:6]。

7. **教学导向明确**：评审强调“符合本科实验教学需要”“可重复验证”“时长成本安全性”等教学适用性指标，体现竞赛服务实验教学改革的宗旨[citation:2]。
