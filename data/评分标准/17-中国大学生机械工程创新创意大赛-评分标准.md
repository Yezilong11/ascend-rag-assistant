# 中国大学生机械工程创新创意大赛 - 评分标准

**来源网址**: http://www.gczbds.org
**信息整理时间**: 2026-03-15

## 一、竞赛简介

中国大学生机械工程创新创意大赛（简称“MEICC”）是由中国机械工程学会主办，联合有关社会团体、行业企业、高校和地方政府共同开展的一项面向全国高校机械类、材料类、工业工程类及相关专业大学生的公益性竞赛活动[citation:2]。大赛自2019年起连续列入《全国普通高校大学生竞赛分析报告》竞赛目录[citation:3]，已成为机械工程领域最具影响力的国家级学科竞赛之一。

**大赛宗旨**：立足机械、面向工程、激发创意、促进创新。大赛旨在引导和鼓励机械工程及相关专业的大学生主动跟踪科技发展前沿，积极投身科技创新与工程实践活动，培养团队协作意识和工匠精神，提升大学生工程实践与创新能力，服务国家制造强国战略，加快创新创业人才培养[citation:2]。

**大赛原则**：公平、公正、公开[citation:2]。

**大赛赛制**：根据学科和专业领域特点，设置相应赛道和赛项；大赛实行两级赛制，即省级或区域选拔赛和全国总决赛，每年举办一届[citation:2]。

## 二、赛道与赛项设置

大赛采用“赛道-赛项”模式，设置多个赛道及赛项[citation:4]：

| 赛道 | 赛项 | 核心内容 |
|:---:|:---|:---|
| **创意赛道** | 机械产品数字化设计赛 | 数字化创新设计、数字孪生技术应用 |
| **创新赛道** | 工业工程与精益管理创新赛 | 工业工程应用、精益管理创新实践 |
| **创新赛道** | 铸造工艺设计赛 | 铸造工艺设计、材料成型创新 |
| **创新赛道** | 无损检测创新实践与应用赛 | 无损检测技术、创新实践应用 |
| **毕业设计赛道** | 毕业设计赛 | 本科毕业设计创新成果 |

### 2.1 创意赛道：机械产品数字化设计赛

2025年度本科组竞赛主题为 **“机械产品数智升级，赋能低空经济发展”**[citation:7][citation:8]。分两个类别：

| 类别 | 核心内容 | 说明 |
|:---:|:---|:---|
| **设计类** | 智能空中作业平台或机器人系统设计 | 针对120米以下低空保障与服务场景，设计用于光伏清洗、风电维护、灭火救援等作业的机械或机器人 |
| **数字孪生类** | 核心零部件制造工艺优化与数字孪生 | 针对低空经济装备关键零部件，进行制造工艺设计、数控编程、数字孪生仿真与产线联调 |

### 2.2 创新赛道：工业工程与精益管理创新赛

2025年度赛事主题为 **“精益智能，协同创新”**[citation:1][citation:3][citation:5]。参赛作品应为有实际应用经历并取得良好经济或社会效益的工业工程或精益管理创新案例[citation:3]。

### 2.3 创新赛道：铸造工艺设计赛

比赛题目采取统一命题方式，分为本科生组题目（A件、B件、C件、D件）和硕士研究生组题目（E件）[citation:6]。参赛者需根据题目要求，设计出完整的铸造工艺方案。

### 2.4 创新赛道：无损检测创新实践与应用赛

2025年度赛事主题为 **“智启新篇，无损领航”**[citation:10]。包括常规赛（超声、射线、渗透检测技术）和创新赛（人工智能评片）[citation:10]。

## 三、竞赛形式与赛程安排

### 3.1 三级赛制

大赛普遍采用“校内选拔赛→区域赛→全国总决赛”三级赛制[citation:6]：

| 竞赛阶段 | 时间安排 | 主要内容 |
|:---:|:---:|:---|
| **校内选拔赛** | 4月-7月 | 校内评审，确定参加区域赛队伍 |
| **区域赛** | 7月-8月 | 区域评审，确定推荐国赛名单 |
| **全国总决赛** | 9月-10月 | 全国集中评审，确定最终奖项 |

### 3.2 2025-2026年大赛日程示例（工业工程与精益管理创新赛）

| 阶段 | 时间节点 | 事项 |
|:---:|:---:|:---|
| **校赛报名** | 7月-8月 | 校内选拔，推荐区域赛队伍 |
| **区域赛** | 8月-9月 | 区域赛评审 |
| **全国总决赛** | 10月-11月 | 现场答辩评审 |

## 四、参赛要求

### 4.1 通用组队要求

| 要求类型 | 具体规定 |
|:---:|:---|
| **参赛对象** | 全国高等院校全日制在校大学生（含本科、高职、研究生）[citation:1][citation:3] |
| **组别划分** | 本科生组、研究生组（凡有研究生参与的参赛队均归入研究生组）[citation:1][citation:3] |
| **组队人数** | 每队3-5人（不同赛项略有差异，工业工程赛项3-5人[citation:1]，数字化设计赛不多于3人[citation:7]） |
| **指导教师** | 每队1-2名指导教师[citation:1][citation:3] |
| **跨校限制** | 原则上以参赛学校为单位，不可跨校组队[citation:6] |
| **参赛限制** | 参赛学生只能同时参加1支参赛队[citation:1] |

### 4.2 作品提交要求（各赛项通用）

| 材料类型 | 内容要求 | 格式要求 |
|:---:|:---|:---|
| **作品申报材料** | 参赛作品申报表、汇总表、版权声明 | 官网模板 |
| **设计/应用报告** | 完整的设计思路、技术方案、应用效果 | PDF文档 |
| **演示材料** | PPT、动画演示、试验录像 | MP4等通用格式 |
| **模型文件** | 三维模型、仿真文件（数字化设计赛项） | 主流3D软件格式 |

### 4.3 原创性要求

- 参赛作品必须是首次参赛的作品，禁止已经在其他赛事获奖的作品、往年已经在本赛项获奖或内容有较大重复的作品参赛[citation:1]
- 参赛作品必须由参赛队原创，无知识产权等纠纷[citation:3]
- 一经发现信息作假或违规行为，取消参赛资格及获奖资格[citation:1]

## 五、工业工程与精益管理创新赛评分标准

### 5.1 评审原则

竞赛全过程遵循**客观、公正、透明、科学**的原则，对参赛作品的科学规范性、作品选题、作品内容、应用效果、团队合作和答辩表现6个方面进行评分，主要考察参赛队的工业工程与精益管理创新思维、创新应用、团队协作等能力[citation:1][citation:3]。

### 5.2 详细评分细则

| 评审项目 | 分值 | 评审要点 |
|:---:|:---:|:---|
| **作品规范性** | 5分 | ①参赛作品各类资料齐全，达到竞赛各项要求；<br>②参赛作品报告和演示文件，格式标准，内容完整，清晰美观，重点突出 |
| **作品选题** | 10分 | ①参赛作品选题紧扣工业工程与精益管理实际应用或发展前沿，符合本年度赛事主题，构思立意新颖，有创新；<br>②参赛作品选题对工业工程与精益管理相关问题的定义准确、清晰 |
| **作品内容科学性** | 15分 | ①参赛作品能合理选择适用的工业工程与精益管理理论和方法工具；<br>②参赛作品能深入思考，正确使用工业工程与精益管理理论和方法工具解决问题 |
| **作品内容严谨性** | 10分 | ①参赛作品内容涵盖问题思考、解决方案、分析验证、实践应用的全流程；<br>②参赛作品所用数据来源可靠，计算、分析等过程合理 |
| **创新性** | 15分 | ①参赛作品分析解决问题过程充分、合理，能够体现参赛队发现问题、解决问题的创新思维，且符合客观规律；<br>②参赛作品解决方案具有一定的原创性或颠覆性（如提出全新理论、方法或优化算法等，或在传统工业工程与精益管理工具上有颠覆性的优化） |
| **可行性** | 10分 | ①参赛作品解决方案有充分的实验数据支持、正确的计算过程、仿真验证结果、实物验证等；<br>②参赛作品解决方案中涉及的相关装置及参数符合国家/行业标准要求，符合经济性原则 |
| **应用效果** | 15分 | ①参赛作品实际应用有显著效益和效果，或具有前瞻性并对工业工程与精益管理领域进步有潜在贡献；<br>②参赛作品结论归纳总结有深度，解决方案具备可复制性，有良好的推广应用价值 |
| **团队协作** | 10分 | ①团队成员组成合理，具有支撑完成参赛作品的知识、技术和经验；<br>②团队分工合理、任务明确、协作良好，团队成员个人贡献度合理 |
| **答辩表现** | 10分 | ①参赛队答辩人员声音洪亮、思路流畅、陈述得当，能够在规定时间内完整准确汇报参赛作品内容；<br>②参赛队答辩人员回答问题准确，思维敏捷，逻辑性强，专业知识扎实 |
| **总分** | **100分** | |

*评分细则来源：安徽工业大学2025年校赛通知[citation:3]*

## 六、机械产品数字化设计赛评分标准

### 6.1 设计类评分标准（2025年主题：赋能低空经济）

| 评审项目 | 权重 | 评审要点 |
|:---:|:---:|:---|
| **选题与需求分析** | 15% | 选题契合大赛主题，需求分析清晰，问题定义准确 |
| **创新性** | 25% | 设计理念新颖，技术突破，原创性强 |
| **方案完整性** | 20% | 设计方案完整，功能实现路径清晰 |
| **技术难度** | 15% | 技术复杂度，关键技术突破程度 |
| **工程可行性** | 15% | 设计可制造性，结构合理性，成本可控性 |
| **表达与呈现** | 10% | 模型精细度，动画演示效果，文档规范性 |

### 6.2 数字孪生类评分标准

| 评审项目 | 权重 | 评审要点 |
|:---:|:---:|:---|
| **工艺设计合理性** | 20% | 工艺路线合理，工序设计规范，参数选择恰当 |
| **数控编程质量** | 20% | 程序正确性，加工效率优化，刀轨合理性 |

| **生产调度优化** | 15% | 排产计划合理性，资源调度优化程度 |
| **系统联调效果** | 20% | 物联网通讯设置，多设备协同运行，系统稳定性 |

## 七、铸造工艺设计赛评分标准

### 7.1 作品评审内容

| 评审项目 | 评审要点 |
|:---:|:---|
| **零件分析** | 零件结构分析、材质要求、技术条件 |
| **工艺方案设计** | 造型方法、浇注系统设计、冒口设计、冷铁设置 |
| **工艺参数确定** | 收缩率、加工余量、拔模斜度、浇注温度 |
| **质量控制** | 缺陷预防措施、铸件检测方法 |
| **创新性** | 工艺优化、新技术应用 |
| **三维造型** | 零件三维造型、铸造工艺三维造型（加分项） |
| **数值模拟** | 计算机数值模拟分析与验证（加分项） |

### 7.2 评审方式

采用**作品盲审**方式，由赛项评审委员会专家进行评审[citation:6]。

## 八、无损检测创新实践与应用赛评分标准

### 8.1 常规赛评分标准

| 检测技术 | 评分要点 |
|:---:|:---|
| **超声检测** | 仪器设置、探头选择、缺陷定位定量、数据记录 |
| **射线检测** | 透照参数选择、底片质量、缺陷识别、评定准确性 |
| **渗透检测** | 表面处理、渗透时间控制、显像效果、缺陷判断 |

### 8.2 创新赛评分标准（人工智能评片）

| 评审项目 | 权重 | 评审要点 |
|:---:|:---:|:---|
| **算法创新性** | 30% | 模型创新、算法优化程度 |
| **识别准确率** | 35% | 缺陷识别准确率、误报率、漏报率 |
| **技术实现** | 20% | 系统完整性、代码规范性 |
| **应用价值** | 15% | 工程应用前景、推广价值 |

## 九、奖项设置

### 9.1 获奖比例规定

依据《中国大学生机械工程创新创意大赛章程》，各赛项获奖比例原则上不超过参赛作品总数的**30%**，其中一等奖数量不超过参赛作品总数的**8%**[citation:2]。

| 奖项 | 获奖比例 |
|:---:|:---:|
| **全国总决赛一等奖** | ≤ 参赛作品总数的8% |
| **全国总决赛二等奖** | 按实际评审结果确定 |
| **全国总决赛三等奖** | 按实际评审结果确定 |

### 9.2 区域赛奖项

区域竞赛设置一、二、三等奖，颁发纸质版证书[citation:6]。

### 9.3 证书颁发

所有赛级奖项获奖证书均由中国机械工程学会统一颁发[citation:6]。获奖学生可申请相应专业的见习工程师工程能力水平评价证书[citation:2]。

## 十、评审组织机构

### 10.1 组织架构

| 机构 | 职责 |
|:---:|:---|
| **大赛组织委员会** | 大赛组织领导机构，审定各赛道和赛项实施细则[citation:2] |
| **赛项执行委员会** | 制订本赛项实施细则，建立裁判员队伍，开展年度竞赛活动[citation:2] |
| **裁判工作组/裁判委员会** | 制定赛项比赛规则、评分细则，开展裁判工作[citation:2] |
| **监督仲裁委员会** | 监督大赛运行，受理仲裁申请[citation:2] |
| **赛项监督仲裁组** | 受理赛项参赛队的仲裁申请[citation:2] |

### 10.2 评审特点分析

1. **多赛道分类评价**：创意赛道、创新赛道、毕业设计赛道各有侧重，评分标准精准体现各领域特点。

2. **三级递进选拔**：校内选拔赛→区域赛→全国总决赛，层层递进确保评审质量。

3. **客观公正的评审原则**：竞赛全过程遵循客观、公正、透明、科学的原则[citation:3]。

4. **全面考察学生能力**：从选题、内容科学性、创新性、可行性、应用效果、团队协作到答辩表现，全方位评价学生综合素质。

5. **严格的原创性要求**：强调作品必须原创，禁止重复参赛，设置查重机制[citation:1]。

6. **完善的监督仲裁机制**：设立监督仲裁委员会和赛项监督仲裁组，保障参赛者权益[citation:2]。

7. **产业需求导向**：赛题设置紧密对接行业人才需求，如低空经济、精益智能、无损检测等前沿领域。

---

**注意**：以上评审规则综合参考了《中国大学生机械工程创新创意大赛章程》[citation:2]及各赛项2025-2026年官方通知。每届竞赛的具体评分细则以当届发布的官方通知为准，各赛项评分标准可能存在差异，请以官网公布的最新版本为准。
