# 全国大学生英语竞赛 - 评分标准

**来源网址**: https://www.chinaneccs.cn/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国大学生英语竞赛（National English Competition for College Students，简称NECCS）是我国规模较大、参与人数众多的全国性大学生英语综合能力竞赛。本竞赛由国际英语外语教师协会中国英语外语教师协会（TEFL China）和高等学校大学外语教学研究会联合主办，英语辅导报社、考试与评价杂志社承办。竞赛自1999年创办以来已连续举办二十八届，每年全国共有31个省（自治区、直辖市）的一千二百余所高校的120余万大学生参加此项赛事。

**竞赛宗旨**：促进大学英语教学改革，全面提高大学生英语综合运用能力，激发广大学生学习英语的积极性，鼓励英语成绩优秀的大学生。

**竞赛特点**：本竞赛内容主要包括大学英语学习阶段应掌握的英语基础知识和读、听、说、写、译五方面的技能，特别是英语综合运用能力。竞赛提倡“重在参与”的奥林匹克精神，坚持自愿报名参加的原则。

**竞赛阶段**：初赛、决赛及全国总决赛三个阶段，均在全国统一时间举行。

## 二、竞赛类别与适用对象

全国大学生英语竞赛分A、B、C、D四个类别，全国各高校的研究生及本、专科所有年级学生均可自愿报名参赛：

| 类别 | 适用对象 |
|:---:|:---|
| **A类** | 研究生 |
| **B类** | 英语专业本、专科学生 |
| **C类** | 非英语专业本科生 |
| **D类** | 体育类和艺术类的本科生、非英语专业高职高专类学生 |

## 三、竞赛形式与赛程安排

### 3.1 竞赛阶段

| 阶段 | 时间安排 | 主要内容 |
|:---:|:---:|:---|
| **初赛** | 2026年4月中旬 | 全国统一时间、统一试题，笔试（含听力） |
| **决赛** | 2026年5月中旬 | 全国统一时间、统一试题，笔试（含听力）及口试 |
| **全国总决赛** | 2026年8月初 | 英语演讲、英语辩论、英语风采等赛事 |

### 3.2 报名时间

2026年全国大学生英语竞赛报名时间为**2025年12月17日至2026年3月15日**。报名网址：www.chinaneccs.cn

## 四、初赛评分标准

### 4.1 初赛形式

初赛为笔试（含听力），满分150分，其中听力30分。各学校自行组织初赛，根据初赛成绩选拔出优秀选手参加决赛。

### 4.2 初赛晋级规则

| 项目 | 具体规定 |
|:---:|:---|
| **晋级依据** | 按参赛人数比例和初赛成绩确定决赛资格 |
| **晋级比例** | 根据各赛区参赛总人数6‰的比例（四舍五入）确定决赛名额 |
| **成绩公布** | 初赛成绩及决赛名单在初赛结束后两周内公布 |

### 4.3 初赛奖项设置

初赛产生以下奖项：

| 奖项 | 获奖比例 |
|:---:|:---|
| **二等奖** | 初赛人数的30‰ |
| **三等奖** | 初赛人数的50‰ |

## 五、决赛评分标准

### 5.1 决赛形式

决赛包括笔试（含听力）和口试，满分200分，其中笔试150分（听力30分），口试50分。决赛由全国统一命题，各省级竞赛组委会统一组织考试。

### 5.2 决赛题型与分值

根据《2026年全国大学生英语竞赛题型及分值划分》，决赛题型及分值如下：

| 题型 | 分值 |
|:---:|:---:|
| **听力理解** | 30分 |
| **词汇、语法和文化** | 15分 |
| **完形填空** | 10分 |
| **阅读理解** | 30分 |
| **翻译** | 15分 |
| **改错** | 10分 |
| **智力测试** | 10分 |
| **写作** | 30分 |
| **口试** | 50分 |
| **总分** | **200分** |

### 5.3 决赛奖项设置

决赛产生以下奖项：

| 奖项 | 获奖比例 |
|:---:|:---|
| **特等奖** | 决赛人数的1‰ |
| **一等奖** | 决赛人数的5‰ |

### 5.4 评分原则

| 题型 | 评分要点 |
|:---:|:---|
| **客观题（选择、填空）** | 答案正确性，机器阅卷 |
| **主观题（翻译、写作）** | 语言准确性、表达流畅性、内容完整性、逻辑清晰度 |
| **口试** | 语音语调、流利程度、语法准确性、内容逻辑、互动能力 |

## 六、全国总决赛评分标准

### 6.1 总决赛形式

全国总决赛在暑假期间举办，主要活动包括：

| 赛事 | 形式 | 评分要点 |
|:---:|:---|:---|
| **英语演讲赛** | 命题演讲+即兴演讲+回答问题 | 内容、语言、技巧、时间控制 |
| **英语辩论赛** | 团队辩论 | 立论、反驳、配合、语言 |
| **英语风采大赛** | 个人/团体才艺展示 | 创意、表现力、语言能力 |

### 6.2 总决赛奖项

| 奖项 | 说明 |
|:---:|:---|
| **演讲赛单项奖** | 一等奖、二等奖、三等奖 |
| **辩论赛单项奖** | 一等奖、二等奖、三等奖 |
| **风采大赛单项奖** | 一等奖、二等奖、三等奖 |
| **最佳辩手奖** | 辩论赛中表现突出的个人 |
| **最佳语音奖** | 演讲赛中语音语调优异的个人 |

## 九、评分特点分析

1. **四级分类评价**：A类（研究生）、B类（英语专业）、C类（非英语专业本科生）、D类（艺术体育类/高职高专）四个类别分别命题、分别评奖，确保不同层次、不同专业学生的公平竞争。

2. **初赛决赛分层选拔**：初赛选拔产生二等奖和三等奖（30‰和50‰），决赛产生特等奖和一等奖（1‰和5‰），形成“初赛→决赛→总决赛”三级递进选拔机制。

3. **笔试口试综合考核**：决赛设置笔试（150分）和口试（50分）两个环节，全面考察学生的听、读、写、译、说综合能力。

4. **题型多样化**：包括听力、词汇语法、完形填空、阅读理解、翻译、改错、智力测试、写作、口试等9大题型，全方位考察英语能力。

5. **客观主观结合**：既有客观题（选择、填空）考察基础知识的准确性，也有主观题（翻译、写作）考察语言表达和思维能力。

6. **智力测试特色**：设置智力测试题（10分），考察学生的逻辑思维和创新能力。

7. **全国统一标准**：初赛和决赛均采用全国统一命题、统一时间、统一评分标准，确保竞赛的公平性和权威性。

8. **重在参与精神**：坚持“重在参与”的奥林匹克精神，为每一位参赛学生颁发参赛证书，鼓励广大学生积极参与。
