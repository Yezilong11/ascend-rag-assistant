# “挑战杯”中国大学生创业计划竞赛 - 评分标准

**来源网址**: http://www.chuangqingchun.net/ | 综合各高校竞赛通知
**信息整理时间**: 2026-03-15

## 一、竞赛简介

“挑战杯”中国大学生创业计划竞赛（简称“小挑”）由共青团中央、中国科协、教育部、中国社会科学院、全国学联和地方政府共同主办，每两年举办一届[citation:6]。竞赛聚焦创业实践本质，旨在引导和激励大学生通过广泛的社会实践、深刻的社会观察，激发创新精神，培育创业意识，提升社会化能力。

**核心区别**：与“大挑”（课外学术科技作品竞赛）注重学术科研不同，“小挑”更侧重于**商业转化**和**实践落地**，其核心竞争力集中体现在**社会价值与经济价值的双重落地成效**上[citation:1]。

## 二、评审规则概述

竞赛采用“校级—省级—全国”三级赛制，评审工作分为**书面评审**与**决赛答辩**两大环节[citation:10]。全国评审委员会对各省报送作品进行复审，评出参赛作品总数的90%左右进入决赛，决赛设金奖（约10%）、银奖（约20%）、铜奖（约70%）[citation:6]。

### 评审核心原则
1.  **分类评审**：已创业（甲类）与未创业（乙类）作品实行相同评审规则，但对已创业作品根据实际运营情况给予**1%-5%的总分加分**[citation:6]
2.  **公开答辩**：终审决赛实行公开答辩制，确保评审透明度
3.  **回避制度**：评委不得参与与其有直接利益关系的作品评审

## 三、五大核心评审维度

评审工作围绕以下五个核心维度进行综合评定，总分为100分[citation:8][citation:10]。

### （一）社会价值（25分）

| 评审要点 | 具体内容 |
|:---:|:---|
| **社会责任** | 项目如何结合社会实践、履行社会责任，展现强烈的社会责任感和使命感[citation:2] |
| **贡献力度** | 在科技革新、乡村振兴、民生改善、生态保护、国际合作等领域的实际贡献[citation:10] |
| **就业潜力** | 项目未来在促进就业、吸纳人才方面的潜力和预期成效[citation:8] |
| **政策契合** | 项目缘起是否紧密贴合国家政策导向与行业实际痛点[citation:1] |

### （二）实践历程（25分）

| 评审要点 | 具体内容 |
|:---:|:---|
| **调研深度** | 深入社会、行业前沿开展实地调研、试点实施、实验验证的扎实程度[citation:2] |
| **实践成果** | 通过试点运营、社区服务、田间地头等实践积累的经验与第一手资料[citation:8] |
| **社会认知** | 实践成果对增进社会认知、提供政策参考、解决实际问题的参考价值[citation:10] |

### （三）创新意义（25分）

| 评审要点 | 具体内容 |
|:---:|:---|
| **技术创新** | 在科技、产品或服务模式上的原创性和突破性[citation:7] |
| **模式创新** | 商业模式、管理策略、应用场景等方面的新颖性与独特性[citation:10] |
| **产业赋能** | 创新成果如何赋能传统产业、应对社会挑战，促进新兴产业、业态、模式的形成与发展[citation:8] |

### （四）发展前景（15分）

| 评审要点 | 具体内容 |
|:---:|:---|
| **商业模式** | 商业模式的完整性、可行性，盈利路径的清晰性与复制推广潜力[citation:1] |
| **营销策略** | 营销规划的合理性，目标市场的清晰定位[citation:10] |
| **财务管理** | 财务分析需细化成本结构，精准做好盈利预测，做到数据真实可信[citation:1] |
| **发展战略** | 项目发展规划的前瞻性与可持续性[citation:8] |

### （五）团队协作（10分）

| 评审要点 | 具体内容 |
|:---:|:---|
| **专业素养** | 团队成员对社会现状的把握、对民生问题的关切程度，解决实际问题的综合能力[citation:2] |
| **能力矩阵** | 搭建“技术研发+市场运营”的能力矩阵，成员专业背景与项目需求的契合度[citation:1] |
| **协作效能** | 团队结构设置合理性、分工明确性、整体执行力与竞争力[citation:10] |

## 四、参赛类别与组别

### 4.1 作品类别[citation:6]

| 类别 | 申报条件 |
|:---:|:---|
| **已创业（甲类）** | 拥有或授权拥有产品或服务，已在工商、民政等政府部门注册登记为企业、个体工商户、民办非企业单位等，法人代表或经营者为在校学生，运营时间≥3个月 |
| **未创业（乙类）** | 拥有或授权拥有产品或服务，具备核心团队和实施创业的基本条件，但尚未注册或注册时间<3个月 |

### 4.2 竞赛组别[citation:6]

| 组别 | 聚焦领域 |
|:---:|:---|
| **科技创新和未来产业** | 人工智能、量子信息、集成电路、新材料等前沿科技 |
| **乡村振兴和农业农村现代化** | 生态种养、农村电商、乡村旅游、乡村治理 |
| **城市治理和社会服务** | 公共卫生、智慧城市、应急管理、教育服务 |
| **生态环保和可持续发展** | 环境治理、新能源、绿色低碳技术 |
| **文化创意和区域合作** | 非遗保护、文旅融合、IP开发、国际合作 |

## 五、评审流程与材料要求

### 5.1 评审流程[citation:4]

| 阶段 | 形式 | 时长 | 评审内容 |
|:---:|:---:|:---:|:---|
| **书面评审** | 材料审核 | — | 基于商业计划书、PPT及支撑材料，按五大维度评分 |
| **路演展示** | 现场演示 | 10分钟 | 围绕项目核心内容进行展示，突出实验数据、技术优势、行业痛点[citation:2] |
| **现场答辩** | 专家提问 | 3分钟 | 评估回答问题的真实度与精确度[citation:10] |

### 5.2 提交材料要求[citation:4]

| 材料名称 | 格式 | 备注 |
|:---:|:---:|:---|
| 项目申报表 | PDF | 基本信息、项目简介 |
| 商业计划书 | PDF | 逻辑清晰、数据详实、框架完整 |
| 支撑材料 | PDF | 专利、论文、合作协议、成果转化证明等 |
| 路演演示文稿 | PPT+PDF | 双格式提交，PPT版用于展示，PDF版用于存档 |
| 项目改进情况表 | PDF | 梳理【已改进】【待改进】两部分，篇幅不超过A4一页 |

## 六、优秀项目的十大特征[citation:3]

根据国赛评审专家的总结，优秀项目通常具备以下核心特质：
1. **社会价值突出**：直击民生痛点，展现社会责任感
2. **创新意义显著**：技术或模式具有突破性
3. **实践过程扎实**：有深度调研和试点验证
4. **商业模式清晰**：盈利路径明确，可复制推广
5. **团队能力匹配**：专业背景与项目需求高度契合
6. **发展战略前瞻**：贴合国家政策与行业趋势
7. **数据支撑有力**：实验数据、财务预测真实可信
8. **路演逻辑严密**：从背景到价值的完整叙事链
9. **支撑材料完备**：专利、协议、证明等佐证齐全
10. **细节准备到位**：资质证明、成果转化等关键材料扎实

## 七、评审特点分析

1. **社会价值与经济价值并重**：评审既关注项目创造的社会效益，也看重其商业落地能力，强调双重价值的双重落地[citation:1]

2. **实践过程权重提升**：要求项目必须深入社会、行业前沿，通过扎实的调研和试点积累真实经验，反对“纸上谈兵”[citation:2]

3. **反过度包装，重真实数据**：财务分析需细化成本结构，盈利预测必须真实可信，强调用实际数据和支撑材料说话[citation:1]

4. **分类导向明确**：已创业项目给予加分激励，体现对真实创业实践的支持[citation:6]

5. **与“大挑”差异化**：相比课外学术科技作品竞赛的理论深度，“小挑”更强调商业转化逻辑和创业实战能力[citation:1][citation:2]
