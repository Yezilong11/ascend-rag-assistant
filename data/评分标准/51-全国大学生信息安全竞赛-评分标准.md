# 全国大学生信息安全竞赛 - 评分标准

**来源网址**: http://www.ciscn.cn/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国大学生信息安全竞赛由教育部高等学校网络空间安全专业教学指导委员会发起，是国内信息安全领域最具影响力的学科竞赛之一。自2008年起每年举办一届，每届历时四个月，分初赛和决赛两个阶段。该赛事旨在宣传信息安全知识，培养大学生的创新意识与团队合作精神，提高大学生的信息安全技术水平和综合设计能力，促进高等学校信息安全专业课程体系、教学内容和方法的改革[citation:4]。

**竞赛组织架构**[citation:4]：
- **指导单位**：教育部高教司、工业和信息化部信息安全协调司
- **主办单位**：教育部高等学校网络空间安全专业教学指导委员会、中国信息安全测评中心
- **领导小组**：由中国互联网发展基金会有关负责人组成，负责指导竞赛活动，协调和裁决重大问题
- **竞赛组委会**：负责竞赛的具体组织实施

**第十九届（2026年）竞赛信息**：
- **创新实践能力赛**：采用线上线下结合的办赛模式，分为线上初赛、分赛区半决赛和决赛三个阶段。全国设置六个分赛区，半决赛拟于2026年3月举办，决赛拟于2026年7月举办[citation:1]。
- **作品赛**：以信息安全技术与应用设计为主要内容，涵盖系统安全、应用安全、网络安全、数据安全和安全检测五大类[citation:2]。

## 二、赛道设置

全国大学生信息安全竞赛主要分为两个赛道：

| 赛道 | 竞赛形式 | 核心内容 | 参赛对象 |
|:---:|::---:|:---|:---|
| **创新实践能力赛** | 线上初赛+线下半决赛+总决赛 | 网络攻防实战能力 | 各高校全日制在校学生（含高职高专、本科生、硕士研究生），每队不超过4人[citation:7] |
| **作品赛** | 网络评审+现场答辩 | 信息安全技术创新作品 | 全日制在校本科生、专科生，每队不超过4人[citation:2] |

### 2.1 创新实践能力赛

创新实践能力赛注重考核学生的网络安全攻防实战能力，采用CTF（Capture The Flag）夺旗赛、AWD（Attack With Defense）攻防对抗等多种形式。

**2026年赛程安排**[citation:1]：
- 线上初赛：2025年12月28日9:00-17:00
- 半决赛：2026年3月22日（线下，全国六个分赛区）
- 总决赛：2026年7月（全国总决赛）

**半决赛晋级规则**[citation:1]：
- 线上初赛每个高校最多有2支排名靠前的队伍晋级分区选拔赛，半决赛承办高校可多1个晋级名额
- 成绩排名相同时，场景实操模块得分高的队伍晋级，分数相同则用时较短的队伍排名靠前
- 每个赛区按照得分从高至低排名，选取不超过100支赛队晋级半决赛

**总决赛晋级规则**[citation:1]：
- 各赛区成绩排名前5的队伍直接晋级总决赛
- 其余名额按公式计算：5 + 30×(赛区线上初赛参赛队伍数/全国总参赛队伍数) + 20×(赛区初赛前200名数量/200)

### 2.2 作品赛

作品赛注重考核学生的创新设计能力和工程实践能力，要求提交完整的信息安全技术作品[citation:2]。

**竞赛范围**[citation:2]：
- 系统安全
- 应用安全（内容安全）
- 网络安全
- 数据安全
- 安全检测（鼓励人工智能安全等新兴前沿领域）

**作品要求**[citation:2]：
- 体现一定的创新性和实用性
- 可以是软件、硬件等形式
- 建议推广使用国产密码技术、国产软硬件
- 只接受防御性题目，不接受具有攻击性质或与国家法律法规相违背的题目

## 四、创新实践能力赛评分标准

### 4.1 线上初赛评分标准[citation:6]

初赛采用CTF（Capture The Flag）夺旗模式，参赛队伍通过网络在线解题。

| 题目类型 | 内容范围 |
|:---:|:---|
| **Web** | Web漏洞挖掘与渗透测试 |
| **Reverse** | 软件逆向工程 |
| **Pwn** | 二进制漏洞挖掘和利用 |
| **Crypto** | 密码学 |
| **Misc** | 杂项（隐写、流量分析等） |

**计分规则**[citation:6][citation:10]：
- 采用**动态积分模式**：每道题目的分值将根据解出队伍的数量进行动态调整，解出队伍越多，分值越低
- 每多一队解出，该题目的分值会随之下降，最低不低于题目原本分数的50%[citation:10]
- 排名规则：按总分从高至低排列，分数相同情况下，以提交时间为准，用时短者排名靠前

**加分机制**（新生赛规则）[citation:10]：
- 第一个正确提交某道题目flag的选手，所获分数加乘题目原本分数的5%
- 第二个正确提交的选手加乘3%
- 第三个正确提交的选手加乘1%
- 之后提交的选手无加分

### 4.2 半决赛/决赛评分标准

半决赛和决赛通常采用**CTF+AWDP赛制**（Attack With Defence Plus），即夺旗赛和人人对抗的攻防兼备模式[citation:6]。

| 环节 | 形式 | 评分要点 |
|:---:|:---:|:---|
| **CTF环节** | 解题夺旗 | 同上初赛规则，占总分60%[citation:6] |
| **AWD攻防对抗** | 人人对抗 | 防守得分+攻击得分 |
| **Build环节** | 知识库构建与安全检测项设计 | 依据回答中技术要点的准确性及内容完整性评分[citation:3] |

### 4.3 Build环节评分标准

第十九届竞赛创新实践能力赛的Build环节设置了知识库构建和安全检测项创新设计任务[citation:3]。

#### 4.3.1 知识库构建任务评分

| 方向 | 固定题 | 随机题 | 合计 |
|:---:|:---:|:---:|:---:|
| **网络硬件设备安全** | 7道 | 3道 | 10道 |
| **大模型安全** | 3道 | 2道 | 5道 |
| **总分** | | | **15分** |

**评分方式**：每一轮赛后平台方将知识库应用到大模型并进行训练，由专家评审团从平台方知识库中选取10道固定题与5道随机题对训练后的模型进行提问，依据回答中技术要点的准确性及内容完整性进行评分，每题1分[citation:3]。

#### 4.3.2 安全检测项设计任务评分

| 方向 | 内容要求 |
|:---:|:---|
| **信息收集** | 设计信息收集阶段的检测项 |
| **漏洞扫描** | 设计漏洞扫描阶段的检测项 |
| **应用安全** | 设计应用安全检测项 |
| **主机安全** | 设计主机安全检测项 |
| **应急响应** | 设计应急响应检测项 |

**评分要点**[citation:3]：
- 每个基础检测项中最多计分10个有效测试项（不包含原有样例）
- 新增检测项设计数量不限，但每支队伍最多计分50个有效的测试项
- 所有新增检测项由专家评审团进行审核，评分依据：结构清晰度、逻辑完整性、实战可行性

## 五、作品赛评分标准

### 5.1 初赛（网络评审）评分标准[citation:2][citation:9]

作品赛初赛采用网络评审方式，每件作品至少由3位专家进行盲审。

| 评审维度 | 评审要点 |
|:---:|:---|
| **原创性与创新性** | 作品的原创程度、创新点、技术突破 |
| **作品完成程度** | 功能完整性、技术实现水平 |
| **作品的性能** | 系统稳定性、性能指标、安全性 |
| **作品的应用价值** | 实用性、应用前景、社会效益 |
| **相关文档的规范性** | 设计报告完整性、测试报告规范性 |

**文档要求**[citation:2][citation:9]：
- 系统设计方案：功能、指标、实现原理、硬件框图、软件流程等
- 系统测试方案：测试设备、测试数据、结果分析、实现功能、特色等
- 其他文档：除上述规定文档以外的其他作品相关资料
- 参赛作品声明：版权、技术公开等

### 5.2 决赛（现场答辩）评分标准[citation:2][citation:6]

决赛采用现场答辩形式，每队答辩时间30分钟，包括PPT陈述、演示、测试与专家提问。

| 评审环节 | 时间 | 评审要点 |
|:---:|:---:|:---|
| **作品陈述** | 10-15分钟 | 作品创意与设计方案、主旨内容、作品实现技术、作品特色 |
| **演示测试** | 5-10分钟 | 现场演示作品功能，专家现场检查源代码 |
| **专家提问** | 5-10分钟 | 问题回答准确度、专业知识深度、应变能力 |

**评审维度**[citation:6]：
- 作品选题（创新性与实用性）
- 主旨内容（与竞赛主题的契合度）
- 作品创意与设计方案
- 作品实现技术与特色
- 作品呈现与答辩效果

## 七、评审组织机构与监督机制

### 7.1 评审组织机构

| 机构 | 职责[citation:4][citation:6] |
|:---:|:---|
| **领导小组** | 指导竞赛活动，对重大问题协调和裁决 |
| **全国评审委员会** | 负责参赛作品的评审工作 |
| **仲裁委员会** | 对争议事项进行仲裁 |
| **专家委员会** | 负责竞赛命题、评审规则制定 |

### 7.2 回避制度[citation:6]

为保证竞赛公平公正，竞赛组委会、专家委员会、仲裁委员会、秘书处成员及竞赛相关工作人员不得作为参赛指导教师。

### 7.3 匿名评审[citation:6]

初赛作品评审采用**双盲评审**形式，在作品文档中出现任何个人或学校信息将被视为作弊行为而取消参赛资格。

### 7.4 违规处理[citation:1][citation:2]

| 违规情形 | 处理措施 |
|:---:|:---|
| 参赛报名信息造假 | 取消参赛资格 |
| 抄袭、剽窃、代赛、串题 | 取消参赛资格，追究相关指导教师和高校责任 |
| 攻击比赛平台 | 取消比赛成绩，通报所在高校 |
| 违反相关法律法规 | 取消参赛资格 |

### 7.5 申诉与仲裁[citation:1]

| 项目 | 具体规定 |
|:---:|:---|
| **申诉主体** | 参赛队队长 |
| **申诉方式** | 向组委会秘书处提交申诉报告（邮箱：info@ciscn.cn），须有队长亲笔签名 |
| **申诉时效** | 比赛结束后2日内 |
| **仲裁时效** | 接到申诉报告后的2个工作日内组织复议 |

## 八、评审特点分析

1. **双赛道分类评价**：创新实践能力赛侧重实战攻防能力，作品赛侧重创新设计与工程实践，评分标准精准匹配两类人才的不同培养目标[citation:2][citation:6]。

2. **三级递进评审机制**：创新实践能力赛采用“线上初赛—分赛区半决赛—全国总决赛”三级评审；作品赛采用“网络盲审—现场答辩”两级评审，层层递进确保评审质量[citation:1][citation:2]。

3. **动态积分排名机制**：CTF竞赛采用动态积分制，题目分值随解出队伍数量动态下降，同时给予前三支解出队伍额外加分，既鼓励创新也保证公平[citation:6][citation:10]。

4. **Build环节创新评价**：创新实践能力赛新增Build环节，将知识库构建成果应用于大模型训练后测试评分，以技术要点的准确性和内容完整性为评分依据[citation:3]。

5. **严格的匿名评审制度**：作品赛初赛采用双盲评审，作品文档中出现任何个人信息即视为作弊，确保评审客观公正[citation:6]。

6. **实践能力证书激励**：“长城杯”决赛一等奖获奖队伍学生可直接获得CISP-PTE（国家注册渗透测试工程师）证书，实现“以赛促学、赛证结合”[citation:1]。

7. **源代码现场检查**：作品赛决赛环节要求专家现场检查源代码，确保作品的原创性和真实性[citation:2]。

8. **攻防兼备综合评分**：半决赛和决赛采用CTF+AWDP赛制，CTF占60%，攻防对抗占40%，全面考察学生的攻击能力和防守能力[citation:6]。
