# 美国大学生数学建模竞赛 - 评分标准

**来源网址**: https://www.comap.com/contests/mcm-icm
**信息整理时间**: 2026-03-15

## 一、竞赛简介

美国大学生数学建模竞赛（Mathematical Contest in Modeling, MCM®）和跨学科建模竞赛（Interdisciplinary Contest in Modeling, ICM®）是由美国数学及其应用联合会（COMAP）主办的国际性大学生学科竞赛，是目前世界上最具影响力的数学建模竞赛之一。

**2026年竞赛信息**：
- **竞赛时间**：2026年1月29日（周四）至2月2日（周一）
- **参赛对象**：全球高中生和大学本科生
- **组队要求**：每队不超过3名学生

**竞赛挑战**：参赛团队需在四天时间内，对一个开放性的实际问题进行分析、建模、求解，并提交完整的解决方案报告。在这个过程中，研究、分析、应用能力与时间管理和问题选择同等重要 。

## 二、问题类型与选择

MCM/ICM竞赛提供六个问题供参赛团队选择：

| 竞赛 | 问题 | 类型 | 核心特点 |
|:---:|:---:|:---:|:---|
| **MCM** | Problem A | 连续型 | 涉及连续数学的应用，如微分方程、物理过程模拟 |
| **MCM** | Problem B | 离散型 | 涉及离散数学的应用，如图论、组合优化 |
| **MCM** | Problem C | 数据洞察 | 大数据分析与建模，强调数据挖掘和洞察提取 |
| **ICM** | Problem D | 运筹学/网络科学 | 涉及网络流、优化算法、系统设计 |
| **ICM** | Problem E | 可持续发展 | 关注环境、资源、生态等可持续发展议题 |
| **ICM** | Problem F | 政策制定 | 涉及公共政策、社会决策、公平性分析 |

**问题选择**：参赛团队可以根据自身优势和兴趣，任选一个问题进行建模解答。

## 四、评审标准

### 4.1 核心评审维度

根据竞赛官方要求和历年评审实践，MCM/ICM的评审围绕以下核心维度展开：

| 评审维度 | 评审要点 |
|:---:|:---|
| **问题重述与假设** | 对问题的理解深度、假设的合理性、问题范围的界定 |
| **模型建立** | 模型的创造性、适用性、数学正确性 |
| **模型求解** | 计算方法的选择、算法实现、计算结果的可靠性 |
| **结果分析与验证** | 结果的合理性、敏感性分析、模型验证 |
| **模型优缺点讨论** | 对模型局限性的认识、改进方向的合理性 |
| **论文写作与表达** | 结构清晰度、逻辑严谨性、表达准确性、摘要质量 |

### 4.2 各问题类型评审侧重

| 问题类型 | 评审侧重 |
|:---:|:---|
| **连续型（A）** | 微分方程建模、物理过程模拟、参数估计的准确性 |
| **离散型（B）** | 离散数学应用、算法设计、优化效果 |
| **数据洞察（C）** | 数据预处理、特征工程、模型预测能力、数据可视化 |
| **运筹学/网络科学（D）** | 网络建模、优化算法、系统效率 |
| **可持续发展（E）** | 多因素综合建模、可持续性指标、政策建议的可行性 |
| **政策制定（F）** | 社会影响分析、公平性考量、决策支持的科学性 |

## 六、论文要求

### 6.1 论文结构

一份优秀的MCM/ICM论文通常应包含以下部分：

| 部分 | 内容要求 |
|:---:|:---|
| **摘要** | 简洁清晰地概括问题、方法、主要结果和创新点 |
| **问题重述** | 用自己的语言重新表述问题 |
| **模型假设** | 明确列出所有假设并说明其合理性 |
| **模型建立** | 详细描述模型的建立过程 |
| **模型求解** | 说明求解方法、算法和计算过程 |
| **结果分析** | 对结果进行解释、敏感性分析和验证 |
| **模型评价** | 讨论模型的优缺点和改进方向 |
| **参考文献** | 规范列出所有引用文献 |
| **附录** | 包含必要的代码、数据等 |

### 6.2 论文格式

| 项目 | 要求 |
|:---:|:---|
| **语言** | 英语 |
| **篇幅** | 无严格页数限制，通常20-30页（不含附录） |
| **格式** | PDF格式 |
| **匿名性** | 论文中不得出现任何可能识别参赛团队的信息 |

## 七、评审特点分析

1. **开放性问题的综合考察**：MCM/ICM的问题均为开放性的实际问题，没有标准答案，评审更注重解决问题的思路、模型的创造性和论文的表达质量，而非结果的唯一正确性。

2. **创新性权重高**：竞赛鼓励参赛者提出新颖独特的建模思路和解决方案，模型的创造性是评审的核心维度之一。

3. **学术写作能力要求**：技术报告的清晰度、逻辑性和专业性直接影响评审结果，良好的科技写作能力是获奖的关键。

4. **团队协作隐性考察**：虽然不直接评分，但论文的整体性和连贯性间接反映了团队的协作能力。

5. **多学科交叉融合**：ICM的问题尤其强调跨学科思维，如E题的可持续发展需综合环境、经济、社会等多方面因素。

6. **数据洞察能力突出**：C题（数据洞察）对数据处理、分析和可视化能力提出更高要求，评审中数据挖掘深度和洞察提取是关键。

7. **奖项梯度分明**：从成功参与到特等奖，奖项设置层次清晰，获奖比例反映了不同水平团队的分布。

---

**注意**：以上评审规则综合参考了MCM/ICM竞赛官网信息、历年评审经验及参赛指南。MCM/ICM官方并不发布详细的评分细则，上述标准是基于竞赛性质和历年评审结果的总结。每届竞赛的具体要求以当届发布的官方通知为准，请以官网公布的最新版本为准。
