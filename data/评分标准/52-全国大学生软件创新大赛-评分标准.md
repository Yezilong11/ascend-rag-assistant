# 全国大学生软件创新大赛 - 评分标准

**来源网址**: https://www.swcontest.com.cn/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国大学生软件创新大赛（以下简称“大赛”）是由示范性软件学院联盟主办，面向全国高校学生的专业科技创新类赛事。大赛自2008年开始举办，目前已成功举办十八届，是国内软件领域的标杆性赛事。2023年，大赛成功纳入全国普通高校大学生竞赛榜观察目录，并列入全国普通高校大学生计算机类竞赛研究报告竞赛项目清单 [citation:5][citation:7]。

**大赛宗旨**：进一步提升大学生创新思维，全面推动软件行业发展，促进软件专业技术人才培养，为国家软件产业输出有创新能力和实践能力的高端人才，提升高校毕业生的就业竞争力 [citation:1][citation:5]。

**第十九届（2026年）竞赛信息**：
- **大赛主题**：“软件定义世界，创新引领未来”
- **赛题名称**：“**AI无界 · 创见未来**”
- **主办单位**：示范性软件学院联盟
- **全国赛承办单位**：西北工业大学
- **支持单位**：OPPO广东移动通信有限公司、青软创新科技集团股份有限公司 [citation:5][citation:10]

| **参赛限制** | 每名参赛学生限参加一支队伍，每个参赛队伍只能提交一个软件作品 [citation:1][citation:5] |

## 三、赛题说明与作品要求

### 3.1 赛题：“AI无界 · 创见未来”

随着AI与多模态交互技术的成熟，智能终端已升级为“全场景随身智能体”。本次赛题聚焦手机应用创新，核心目标是探索AI如何适配移动端“轻量化操作、场景化响应、即时性服务”的特性，结合先进技术和创意方法，解决移动场景中的效率痛点与体验短板 [citation:5][citation:9]。

**应用举例** [citation:5][citation:10]：

| 赛道 | 应用场景举例 |
|:---:|:---|
| 全场景移动办公智能体 | 语音指令触发多任务处理，自动生成会议纪要并同步待办 |
| 随身AI互动导学 | 拍照解题生成3D动态步骤，长视频课程一键萃取知识点 |
| 智能生活服务工具 | 拍摄菜单识别成分并推荐适配选项，语音输入规划行程 |
| AI全模态影像处理 | 一句话调色，拍摄手工艺品实时生成3D演示动画 |
| AI协同互动游戏 | 语音指令指挥AI队友，输入关键词自动生成游戏装备模型 |
| 随身AI健康管家 | 拍摄药品自动识别并设置提醒，关联手环生成健康报告 |

### 3.2 作品要求

| 要求项 | 具体规定 |
|:---:|:---|
| **形式** | 完整的软件作品，需围绕赛题，针对真实应用场景，充分利用AIGC、机器学习、深度学习等前沿技术 [citation:5][citation:6] |
| **技术深度** | 具备一定技术深度，解决方案设计完备，严格按照软件工程规范开发，编程风格良好，注释清晰，文档完整 [citation:5][citation:6] |
| **研发工具** | 手机端须基于Android平台开发；允许使用开源工具；如使用开源模型，须明确呈现开源及非开源部分 [citation:5][citation:6] |
| **验证** | 最终作品需能够在比赛现场实际运行并进行功能展示 [citation:5][citation:6] |
| **原创性** | 必须是原创且未参加过其他国家级公开比赛的作品，核心工作在本次大赛期间完成 [citation:5][citation:6] |
| **匿名要求** | 所有提交材料中均不得透露学校信息和参赛成员姓名，违者取消参赛资格 [citation:1][citation:5] |

## 四、评审体系总览

### 4.1 评审组织机构

| 机构 | 职责 |
|:---:|:---|
| **大赛组委会** | 制定大赛赛程、参赛要求和评审方式 [citation:5][citation:10] |
| **专家委员会** | 制定具体评审标准，负责区域赛和全国赛的评审工作 [citation:5][citation:10] |
| **监察委员会** | 作为独立第三方，对组织、评审、财务等工作实施监督，确保公平公正 [citation:5][citation:10] |

### 4.2 评审基本原则

| 原则 | 具体内容 |
|:---:|:---|
| **公平、公正、公开** | 严格遵守竞赛规则，操作规范、透明 |
| **匿名评审** | 各阶段评审均采用匿名形式 |
| **分阶段晋级** | 区域赛成绩不带入全国赛，全国赛复赛成绩不带入决赛 [citation:1] |

## 五、各阶段评审标准

### 5.1 区域赛评审标准

区域赛分为初赛、复赛、决赛三轮，每一轮成绩不带入下一轮 [citation:1]。

**初赛和复赛**：线上通信评审 [citation:1]。
**决赛**：线上答辩会议评审 [citation:1]。

### 5.2 全国赛评审标准

全国赛复赛为线上评审，决赛为线下答辩演示 [citation:7]。

#### 5.2.1 评审维度（根据山东大学校赛评分表整理）

根据第十六届大赛校赛评分标准，评审维度及分值如下 [citation:2]：

| 评审维度 | 分值 | 评审要点 |
|:---:|:---:|:---|
| **软件概述** | 30分 | 应用背景、目标人群、软件价值、软件方案 |
| **软件创新** | 30分 | 技术创新点、应用创新点、其他创新点 |
| **可行性** | 20分 | 资源可行性、市场可行性 |
| **痛点** | 10分 | 痛点分析 |
| **竞品** | 10分 | 相关工作、竞品分析 |

#### 5.2.2 评审维度解析

| 评审维度 | 评审要点 |
|:---:|:---|
| **创新性** | 创意的新颖性、独特性；技术创新点、应用创新点的突破程度 [citation:2] |
| **技术实现** | 技术深度、解决方案完备性、编程风格、文档完整性 [citation:5][citation:6] |
| **作品完成度** | 功能完整性、系统稳定性、运行流畅度 |
| **应用价值** | 对真实应用场景的适配性、解决效率痛点与体验短板的能力 [citation:5] |
| **AI技术应用** | 对AIGC、机器学习、深度学习等前沿技术的应用深度 [citation:5][citation:6] |
| **现场演示效果** | 实际运行展示、功能演示效果、用户体验 [citation:5] |
| **答辩表现** | 逻辑清晰度、问题回答准确度 |

#### 5.2.3 开源比例评估

如使用开源模型，评审委员会将通过技术手段对开源比例进行扫描，以评估软件技术和创新性 [citation:5][citation:6]。

## 七、评审特点分析

1. **三级递进评审机制**：区域赛初赛、复赛、决赛 → 全国赛复赛 → 全国赛决赛层层递进，区域赛复赛前25%入围全国赛复赛，前3%直推全国赛决赛，确保优秀作品脱颖而出 [citation:1][citation:7]。

2. **匿名评审制度**：所有提交材料中不得出现学校信息和参赛成员姓名，确保评审公平公正 [citation:1][citation:5]。

3. **五维核心评价体系**：根据校赛评分标准，从**软件概述（30分）、软件创新（30分）、可行性（20分）、痛点（10分）、竞品（10分）**五个维度进行综合评价 [citation:2]。

4. **技术深度与创新并重**：作品必须具备一定技术深度，解决方案设计完备，同时鼓励技术创新和应用创新 [citation:2][citation:5]。

5. **开源比例评估机制**：评审委员会将通过技术手段对开源模型的使用比例进行扫描，以评估软件的技术原创性和创新性 [citation:5][citation:6]。

6. **现场演示刚性要求**：最终作品需能够在比赛现场实际运行并进行功能展示，确保作品的真实性和可验证性 [citation:5][citation:6]。

7. **企业深度参与**：OPPO等企业提供资金、技术支持及竞赛作品市场化辅导，使评审更贴近产业实际需求 [citation:5][citation:10]。

8. **严格的原创性要求**：强调作品必须是原创且未参加过其他国家级公开比赛，核心工作在本次大赛期间完成，对抄袭、重复参赛行为实行零容忍 [citation:5][citation:6]。

---

**注意**：以上评审规则综合参考了第十九届全国大学生软件创新大赛官网、多所高校发布的官方参赛通知及往届校赛评分标准。每届竞赛的具体评分细则以当届发布的官方通知为准，请以官网公布的最新版本为准。
