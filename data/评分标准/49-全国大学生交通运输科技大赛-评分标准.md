# 全国大学生交通运输科技大赛 - 评分标准

**来源网址**: http://www.nactrans.com.cn/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国大学生交通运输科技大赛是由中国交通教育研究会、中国交通运输协会、教育部高等学校交通运输类专业教学指导委员会主办，教育部高等教育委员会批准的全国性大学生科技竞赛，是全国普通高校学科竞赛排行榜的榜单赛事之一[citation:3][citation:8]。大赛以交通运输领域的科学和工程技术问题为载体，培养大学生科学精神和科学素养、发现和解决问题的能力及团队协作精神，促进大学生学术活动开展，加强大学生科技文化交流[citation:6]。

**大赛宗旨**：科学、创新、协同[citation:6]

**第二十一届（2026年）竞赛信息**：
- **大赛主题**：**“锻造未来交通之力：以高阶人才培养擎动智能转型与绿色发展”**[citation:10]
- **决赛时间**：2026年5月23-24日[citation:10]
- **决赛地点**：北京建筑大学[citation:10]
- **主办单位**：中国交通运输协会、中国交通教育研究会[citation:10]
- **承办单位**：北京建筑大学、中国交通运输协会高校教育专业委员会、中国交通教育研究会院长分会等[citation:10]

## 二、赛道设置

第二十一届大赛共设置本科生、研究生、“一带一路”主题、“船视宝”主题等四个赛道[citation:10]。

### 2.1 本科生赛道

本科生赛道结合作品研究领域及所在学科分设6个分赛道，作品团队成员中不得有研究生[citation:10]：

| 分赛道 | 名称 | 研究领域 |
|:---:|:---|:---|
| **A类** | 交通工程与综合交通 | 交通规划、设计、管理与控制等 |
| **B类** | 航海技术 | 船舶航行、导航、海上交通等 |
| **C类** | 道路运输与工程 | 道路设计、施工、养护、运输组织等 |
| **D类** | 水路运输与工程 | 港口、航道、水运系统等 |
| **E类** | 铁路运输与工程 | 轨道线路、列车运行、铁路运输组织等 |
| **F类** | 航空运输与工程 | 机场规划、空中交通管理、航空运输等 |

### 2.2 研究生赛道

研究生赛道设置2个分赛道[citation:10]：

| 分赛道 | 名称 | 成员要求 |
|:---:|:---|:---|
| **G类** | 硕士生分赛道 | 成员中不得含有博士研究生 |
| **H类** | 博士生分赛道 | 成员中可有硕士研究生和本科生 |

### 2.3 “一带一路”主题赛道

本赛道为国际化特色赛道，旨在促进“一带一路”沿线国家青年学子在交通领域的学术交流与创新合作[citation:10]。

| 项目 | 具体要求 |
|:---:|:---|
| **参赛要求** | 参赛团队核心成员中须至少包含1名国籍为“一带一路”沿线国家或地区（非中国大陆）的全日制在校留学生 |
| **答辩要求** | 作品展示和答辩环节由该类别学生负责 |
| **选题要求** | 题目源于“一带一路”沿线国家的实际交通需求 |
| **作品方向** | 适应特殊地理气候条件的交通基础设施、低成本交通运输解决方案、跨境物流优化、文化遗产保护协同策略等 |

### 2.4 “船视宝”主题赛道

本赛道聚焦航运智能与交通管养，全体在校生均可参与[citation:10]。设有四个赛题[citation:10]：

| 赛题 | 名称 | 核心内容 |
|:---:|:---|:---|
| **赛题一** | 集装箱码头船舶预抵等泊智能预测 | 基于AIS轨迹、气象数据，构建智能模型预测船舶锚地等待时长 |
| **赛题二** | MaritimeBench航运知识挑战 | 基于航运专业知识库，提升AI模型在航运知识点的理解与推理能力 |
| **赛题三** | 航数智算引擎 | 实现自然语言问题到航运API接口调用序列的精准转换 |
| **赛题四** | 道路路面病害智能检测 | 通过计算机视觉技术，构建识别道路病害的智能模型 |

## 三、参赛要求

### 3.1 参赛资格与组队

| 要求类型 | 具体规定 |
|:---:|:---|
| **参赛对象** | 全国开设交通运输类及相关专业的高校在校本科生、研究生、留学生[citation:10] |
| **组队人数** | 每个作品完成人员不得超过**5人**，指导教师不超过**2人**[citation:10] |
| **每人限报** | 每人只能参加1个项目[citation:2] |
| **跨校组队** | 对于跨校组队的项目，项目队长必须为本校学生[citation:8] |
| **跨专业组队** | 鼓励不同学科专业学生联合组队参赛[citation:7] |

### 3.2 作品要求

| 要求类型 | 具体规定 |
|:---:|:---|
| **原创性** | 所有参赛作品应为参赛者自主完成的原创性作品，不得将导师的科研成果而非成员自身成果的部分作为参赛作品[citation:10] |
| **成果时效** | 参赛作品必须是本次大赛之前未参加过相关学科竞赛的成果[citation:1][citation:4] |
| **主题契合** | 参赛作品应围绕大赛“锻造未来交通之力：以高阶人才培养擎动智能转型与绿色发展”的主题[citation:10] |
| **问题导向** | 针对交通运输系统中出现的具体问题，运用相关专业知识，提出优化方法或解决方案[citation:4] |
| **作品形式** | 可以是实物模型、研究报告、设计图纸和计算机软件等[citation:4] |

### 3.3 作品申报要求

| 要求 | 具体规定 |
|:---:|:---|
| **申报方式** | 大赛只接受以参赛单位名义推荐的作品，不接受个人申请[citation:6] |
| **推荐限额** | 本科生、研究生、“一带一路”主题赛道每一分赛道的作品数不超过**3件**；“船视宝”主题赛道推荐作品数不限[citation:10] |
| **组别符合度** | 作品申报组别应符合作品实际内涵，最终以评审专家意见为准[citation:4] |
| **不得重复推荐** | 同一作品不得重复推荐[citation:6] |

## 四、竞赛形式与赛程安排

### 4.1 三级竞赛形式

大赛分为**预赛（校赛）、初评（网评）、决赛（现场答辩）**三个阶段[citation:6][citation:10]：

| 竞赛阶段 | 时间安排 | 主要内容 |
|:---:|:---:|:---|
| **校赛** | 3月下旬-4月上旬 | 各高校自行组织校内选拔，严格按照要求推荐优秀作品[citation:2][citation:7] |
| **初评** | 4月中旬-5月上旬 | 大赛组委会组织网评，按赛道和分赛道参赛作品数量不超过**20%**的比例推荐参加决赛的作品[citation:10] |
| **决赛** | 5月23-24日 | 现场公开答辩，按照分赛道分组评审[citation:10] |

## 五、评审体系总览

### 5.1 评审组织机构

| 机构 | 职责 |
|:---:|:---|
| **学术委员会** | 大赛的决策机构，负责审查参赛作品与大赛主题的符合度、参赛作品与竞赛类内涵的符合度[citation:6] |
| **仲裁委员会** | 大赛争议事项的仲裁机构，接受实名举报并进行调查仲裁[citation:6] |
| **执行委员会** | 负责大赛的事务性工作[citation:6] |

### 5.2 评审基本原则

| 原则 | 具体内容 |
|:---:|:---|
| **公平公正** | 严格遵守竞赛规则，操作规范、透明 |
| **回避制度** | 专家对有利害关系的参赛作品实行回避；同一答辩组内不得有2人来自同一单位的专家担任评委[citation:6] |
| **匿名评审** | 预赛阶段采用匿名方式评审[citation:6] |
| **公开答辩** | 决赛阶段采用现场公开答辩方式[citation:10] |

## 六、各赛道评分标准

### 6.1 通用评审维度

根据大赛章程及各高校校赛通知，作品将从以下四个核心维度进行评价[citation:1][citation:3][citation:4]：

| 评审维度 | 评审要点 |
|:---:|:---|
| **创新性** | 创意的新颖性、独特性、创新思维 |
| **专业知识综合运用** | 对相关专业知识的掌握程度和综合运用能力 |
| **实用价值** | 作品的实用性、应用前景、社会效益 |
| **完成度** | 作品的完整程度、技术实现水平、成果质量 |

### 6.2 本科生赛道评分标准

本科生赛道作品从**创新性、专业知识综合运用、实用价值、完成度**四个方面进行评价[citation:4][citation:9]。

### 6.3 研究生赛道评分标准

研究生赛道作品在本科生赛道评价维度的基础上，还需体现[citation:4][citation:9][citation:10]：

| 附加维度 | 评审要点 |
|:---:|:---|
| **学术性** | 作品的学术深度、理论贡献 |
| **理论方法的科学严谨性** | 研究方法的科学性、严谨性、合理性 |
| **作品方案的系统性** | 方案的完整性、系统性、逻辑性 |

### 6.4 主题赛道评分侧重

| 赛道 | 评审侧重 |
|:---:|:---|
| **“一带一路”主题赛道** | 跨文化理解、本土化适配性、技术可行性、合作创新精神[citation:10] |
| **“船视宝”主题赛道** | 问题导向、技术落地、对真实产业需求的解决能力[citation:10] |

## 七、校赛评分标准（参考）

### 7.1 校赛评审形式

校赛一般分为网评和现场答辩，具体视作品数量而定[citation:2]。

| 环节 | 形式 | 评审要点 |
|:---:|:---:|:---|
| **项目陈述** | 5-8分钟PPT汇报 | 逻辑清晰、重点突出、时间控制 |

| **综合评分** | 专家打分 | 按创新性、专业知识运用、实用价值、完成度等维度评分 |

西安邮电大学校赛答辩会设置**项目陈述、评委问辩、综合评分**三大环节，评审团围绕**技术可行性、创新价值、应用前景及答辩表现**等维度进行系统考评[citation:5]。

## 八、全国总决赛评审标准

### 8.1 决赛评审流程

决赛阶段采用**现场公开答辩**方式进行，按照分赛道，约20项作品划分一个竞赛组[citation:6]。

| 评审阶段 | 组织形式 | 评审内容 |
|:---:|:---:|:---|
| **分组答辩** | 每组由不少于5位专家组成答辩组，按竞赛组评定出一、二、三等奖及优秀奖推荐名单 | 作品陈述、现场答辩、综合评分 |
| **一等奖复审** | 各竞赛组推荐的一等奖，由学术委员会会同执行委员会组织复审答辩，全体专家综合评定 | 对一等奖候选作品进行综合评议 |

### 8.2 答辩流程

各参赛小组事先制作好幻灯片并提前准备好参赛作品参加答辩，答辩分为以下两个环节[citation:10]：

| 环节 | 时间 | 评审要点 |
|:---:|:---:|:---|
| **第一环节：作品介绍** | 5-8分钟 | 突出作品重点内容、创新点、技术实现 |
| **第二环节：现场答辩** | 3-5分钟 | 回答评委问题准确、专业知识扎实 |

## 十一、评审特点分析

1. **三级递进评审机制**：校赛（预赛）→初评（网评）→决赛（现场答辩）层层递进。校赛由各高校自行组织选拔，初评按不超过20%的比例推荐决赛作品，决赛现场公开答辩最终确定奖项[citation:6][citation:10]。

2. **四维核心评价体系**：作品从**创新性、专业知识综合运用、实用价值、完成度**四个核心维度进行评价，研究生赛道还需体现**学术性、理论方法的科学严谨性、作品方案的系统性**[citation:4][citation:9][citation:10]。

3. **分类赛道精准评价**：本科生、研究生、“一带一路”、“船视宝”四个赛道各有侧重，本科生侧重基础综合能力，研究生强调学术深度和系统性，主题赛道注重跨文化融合和产业落地[citation:10]。

4. **严格的回避制度**：专家对有利害关系的参赛作品实行回避，同一答辩组内不得有2人来自同一单位的专家担任评委，确保评审公正性[citation:6]。

5. **现场公开答辩**：决赛采用现场公开答辩形式，设置作品介绍和评委问答环节，全面考察学生的表达能力、应变能力和专业知识深度[citation:10]。

6. **一等奖复审机制**：各竞赛组推荐的一等奖作品需参加复审答辩，由全体专家综合评定，确保最高奖项的含金量[citation:6]。

7. **原创性刚性要求**：作品必须为自主完成的原创性成果，不得将导师的科研成果而非成员自身成果的部分作为参赛作品，严格杜绝学术不端[citation:10]。

8. **命题来源真实需求**：主题赛道赛题来源于真实产业需求，如“船视宝”赛道的船舶预抵预测、路面病害检测等，强调问题导向和技术落地[citation:10]。
