# 全国大学生智能汽车竞赛 - 评分标准

**来源网址**: http://www.smartcarrace.com/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国大学生智能汽车竞赛是由教育部高等教育司委托教育部高等学校自动化类专业教学指导委员会（现由自动化类专业教学指导委员会与中国自动化学会共同主办）创办的一项创意性科技竞赛，是教育部倡导的大学生科技竞赛之一。竞赛自2006年起每年举办一届，至今已连续成功举办二十届，覆盖全国30余个省市自治区、近500所高校，累计参赛学生超33万人次[citation:6]。该竞赛已连续被纳入全国普通高校大学生竞赛排行榜，被广泛认可为含金量最高、参赛价值最大的竞赛项目之一[citation:1]。

**竞赛宗旨**：**“立足培养、重在参与、鼓励探索、追求卓越”** [citation:1][citation:3][citation:9]

**竞赛目标**：以智能汽车为竞赛平台，涵盖控制、模式识别、传感技术、电子、电气、计算机、机械、通信、汽车工程等多个学科交叉，旨在促进高等学校素质教育，培养大学生的综合知识运用能力、基本工程实践能力和创新意识，激发大学生从事科学研究与探索的兴趣和潜能，倡导理论联系实际、求真务实的学风和团队协作的人文精神[citation:3][citation:7]。

**主办单位**：中国自动化学会、清华大学、第二十一届全国大学生智能汽车竞赛组织委员会[citation:1]

## 二、竞赛体系与赛道设置

### 2.1 三级赛事体系

竞赛采用“校赛—省赛/分赛区赛—全国总决赛”三级赛事体系[citation:6]：

| 竞赛阶段 | 时间安排（第二十一届） | 主要内容 |
|:---:|:---:|:---|
| **校级选拔赛** | 2026年1月-3月 | 校内选拔，确定参加赛区赛队伍 |
| **省赛/分赛区赛** | 2026年7月 | 分赛区评审，确定入围全国总决赛名单 |
| **全国总决赛** | 2026年8月 | 全国集中竞赛，确定最终奖项 |

### 2.2 竞赛组别（第二十一届）

第二十一届竞赛共设11个竞速比赛组别，分为三个赛道子类：缩微赛道、室内赛道、室外赛道[citation:10]。

| 序号 | 组别名称 | 赛道子类 | 比赛任务描述 | 队伍人数 |
|:---:|:---:|:---:|:---|:---:|
| 1 | 飞檐走壁 | 缩微立体电磁赛道 | 自制轻量车模，利用电磁导航，在具有立体元素的赛道上运行 | 3人 |
| 2 | 疯狂电路 | 缩微电路赛道 | 自制轻量车模，利用光电或摄像头导引，在电路图赛道上运行 | 3人 |
| 3 | 蚂蚁搬家 | 缩微平面赛道 | 自制两个以上车模，协同将目标物搬运到指定区域 | 4人 |
| 4 | 飞跃雷区 | 室内平面光标赛道 | 自制车模与悬停飞行器（有线连接），协作完成信标检测与飞跃 | 5人 |
| 5 | 走马观碑 | 室内PVC赛道 | 三轮竞速车模，识别目标板图案并按规定路线通过 | 3人 |
| 6 | 雁过留痕 | 室内PVC赛道 | 四轮竞速车模，使用紫外激光在特定区域留下痕迹 | 3人 |
| 7 | 人工智能视觉 | 室内平面虚拟现实赛道 | 车模完成推箱子等智能游戏任务 | 待定 |
| 8 | 人工智能模型 | - | - | - |
| 9 | 卡丁快跑 | - | - | - |
| 10 | 轮腿穿越 | - | - | - |
| 11 | 单车定向 | - | - | - |

**专科组别**：在飞檐走壁、雁过留痕、卡丁快跑三个组别中设立专科组，报名队伍单独进行排名[citation:10]。

### 2.3 创意组赛项

除竞速比赛组别外，第二十一届竞赛还设有创意组赛项。以“天途&亚龙智慧救援创意组”为例[citation:4]：

- **赛项主题**：智慧救援
- **任务形式**：无人机与智能车空地协同完成系列救援任务（无人机巡检、智能车运送物资、协同装货、物资投送、返航）
- **参赛组别**：职教组（中职/高职学生）、高教组（本科生/研究生，每队最多1名研究生）
- **队伍组成**：每队不超过6人，指导教师不超过2人

## 三、参赛要求

### 3.1 参赛资格

| 要求类型 | 具体规定 |
|:---:|:---|
| **参赛对象** | 2025年9月至2026年8月期间具有本校正式学籍的全日制在校学生[citation:4] |
| **专业范围** | 电子通信类、计算机类、机械类等相关理工科专业[citation:1] |
| **组队要求** | 常规组别每队3人[citation:8][citation:9]，特殊协作组按规则执行[citation:4] |
| **跨专业组队** | 鼓励跨专业、跨年级组队，软件、硬件、机械合理搭配[citation:2][citation:9] |
| **跨校限制** | 不得跨校组队[citation:4] |
| **组别限制** | 每所学校每个竞赛组别仅可推荐1支队伍参赛[citation:6] |

### 3.2 作品要求

| 要求类型 | 具体规定 |
|:---:|:---|
| **车模平台** | 缩微赛道允许自制车模；室内、室外赛道需使用指定车模平台或指定配件自制[citation:10] |
| **微控制器** | 各组别指定MCU平台（如STC、英飞凌AURIX、NXP、龙芯等）[citation:10] |
| **传感器限制** | 各组别对传感器类型和数量有明确规定[citation:4][citation:10] |
| **电路板要求** | 最终参赛电路板需统一在指定平台免费制作，正面覆铜层放置队伍信息（学校名称、队伍名称、制作日期），丝网层包含制作文件链接二维码[citation:10] |
| **原创性** | 加装模块须为自行设计，严禁直接使用未经实质性改装的成品结构参赛[citation:4] |

## 四、评审体系总览

### 4.1 评审基本原则

参赛队伍的名次（成绩）由赛车现场成功完成赛道比赛时间来决定。参加全国总决赛的队伍同时须提交车模技术报告[citation:10]。

### 4.2 通用评分维度

| 评审维度 | 评审要点 |
|:---:|:---|
| **竞速成绩** | 完成赛道所需时间，时间越短成绩越好 |
| **任务完成度** | 规定任务（如搬运、识别、投送等）的完成情况 |
| **技术规范性** | 车模制作、电路设计、程序开发的规范程度 |
| **创新性** | 技术方案创新、结构优化、算法突破 |
| **技术报告** | 全国总决赛需提交车模技术报告，体现设计思路与技术实现 |

### 4.3 竞速赛成绩评定核心——时间制

**核心原则**：竞速赛以赛车现场成功完成赛道比赛的时间来决定名次（成绩）。完成比赛所用时间最短者取胜[citation:5][citation:10]。

## 五、各阶段详细评分标准

### 5.1 校级选拔赛评分标准

各高校在校内选拔赛阶段，通常采用竞速赛或基础能力测试方式。

#### 5.1.1 竞速赛形式（以大连理工大学2026年校赛为例）[citation:5]

| 项目 | 具体要求 |
|:---:|:---|
| **比赛形式** | 四轮摄像头组竞速赛 |
| **赛制** | 正跑（顺时针）和反跑（逆时针）两项，各三次有效机会 |
| **比赛时间** | 共计10分钟 |
| **成绩计算** | 有一次完成比赛即计入成绩，最终结果取正反跑成绩最好的一次 |
| **罚时规则** | 赛道环岛元素不能成功完成，一个罚时30秒 |
| **出界判罚** | 四轮车有两个轮完全在赛道以外算出界；两个及以上边裁举旗或主裁举旗判为出界 |

#### 5.1.2 基础能力测试形式（以长江师范学院2026年校赛为例）[citation:1]

| 环节 | 形式 | 评分方式 |
|:---:|:---|:---|
| **基础赛** | 限时2小时编程，完成LED灯、按键、数码管等指定基础内容 | 按完成度综合评分 |
| **竞速赛** | 培训3天后，实现智能小车完成指定行进科目 | 按完成时间及完成度综合评分 |

#### 5.1.3 现场评审形式（以河北科技大学2026年校赛为例）[citation:2]

| 环节 | 评分内容 |
|:---:|:---|
| **现场路演** | 项目展示、作品演示 |
| **专家提问答辩** | 技术方案、创新点、团队协作 |

### 5.2 创意组赛项评分标准（以“智慧救援”为例）

| 任务环节 | 评分要点 |
|:---:|:---|
| **任务一：无人机巡检** | 依次巡查四个救援点，记录救援等级，发送救援区编号给智能车 |
| **任务二：智能车运送物资** | 自主行驶到取货区，视觉识别物资位置，抓取物资并运送至装货区 |
| **任务三：智能车为无人机装货** | 完成货物从智能车到无人机的转移，通知无人机装货完成 |
| **任务四：救援物资投送** | 无人机将物资运送到救援区，智能车将物资放到指定区域内 |
| **任务五：智能车与无人机返航** | 任务完成后各自返航 |

**评分依据**：各环节任务完成度、完成时间、协同配合程度、技术实现质量[citation:4]。

### 5.3 全国总决赛评分标准

全国总决赛在分赛区比赛基础上，增加技术报告评审环节。

| 评审项目 | 评分内容 |
|:---:|:---|
| **现场竞速成绩** | 赛车现场成功完成赛道比赛的时间 |
| **车模技术报告** | 设计思路、技术方案、创新点、测试数据、总结反思 |

## 七、评审特点分析

1. **时间制核心评价**：竞速赛以赛车现场成功完成赛道比赛的时间作为核心评价标准，时间越短成绩越好[citation:5][citation:10]。

2. **分类赛道精准评价**：11个竞速组别分为缩微、室内、室外三个赛道子类，各有不同的任务描述和技术要求，评分标准精准匹配各赛道特点[citation:10]。

3. **三级递进选拔机制**：校赛筛选基础扎实的队伍，赛区赛考察综合实力，全国总决赛选拔顶尖人才，层层递进确保评审质量[citation:6]。

4. **技术报告补充评价**：全国总决赛要求提交车模技术报告，全面考察设计思路、技术方案和创新能力。

5. **罚时机制规范评判**：对未完成赛道元素（如环岛）等情形设置明确的罚时规则，确保评判的公平性和规范性[citation:5]。

6. **创意组多元评价**：创意组赛项以任务完成度为核心，考察无人机与智能车协同配合、技术实现质量等多维度能力[citation:4]。

7. **严格的设备规范**：对车模平台、MCU型号、传感器类型和数量、电路板制作等均有明确规定，确保竞赛的公平性和技术导向[citation:4][citation:10]。

**注意**：以上评审规则综合参考了第二十一届全国大学生智能汽车竞赛比赛规则及各高校校赛通知[citation:10]。每届竞赛的具体评分细则以当届发布的官方通知为准，各组别评分标准可能存在差异，请以官网公布的最新版本为准。
