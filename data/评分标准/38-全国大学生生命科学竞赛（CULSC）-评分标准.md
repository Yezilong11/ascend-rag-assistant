# 全国大学生生命科学竞赛（CULSC） - 评分标准

**来源网址**: https://www.culsc.cn/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国大学生生命科学竞赛（China Undergraduate Life Science Contest，简称CULSC）是在教育部高等学校大学生物学课程教学指导委员会、教育部高等学校生物科学类专业教学指导委员会、教育部高等学校生物技术与生物工程类专业教学指导委员会、教育部高等学校食品科学与工程类专业教学指导委员会、高等学校国家级实验教学示范中心联席会和《高校生物学教学研究（电子版）》杂志共同倡议下，由全国大学生生命科学竞赛委员会设立的全国性学科竞赛[citation:6][citation:9]。竞赛每年举办一届，分为“科学探究类”和“创新创业类”两个赛道，是生命科学领域最具影响力的国家级学科竞赛之一，已列入中国高等教育学会《全国普通高校大学生竞赛分析报告》竞赛目录。

**竞赛宗旨**：培养大学生的创新意识、实践能力和团队精神，拓宽科学视野，增强社会责任感，促进生命科学学科教学改革，提高人才培养质量[citation:6][citation:9]。

**第十一届（2026年）竞赛信息**：
- **科学探究类决赛承办单位**：河南师范大学[citation:6]
- **创新创业类决赛承办单位**：安徽农业大学[citation:5][citation:8][citation:10]
- **竞赛组织**：全国大学生生命科学竞赛委员会组织实施，监督委员会全程监督，确保竞赛公平、公开、公正[citation:5][citation:8][citation:10]

## 二、赛道设置与参赛要求

### 2.1 科学探究类赛道

科学探究类竞赛强调学生选题的自主性和原创性，要求围绕生命科学相关领域的科学问题，鼓励跨学科领域，开展自主性设计实验或野外调查工作[citation:3][citation:9]。

| 要求类型 | 具体规定 |
|:---:|:---|
| **参赛对象** | 全日制非成人教育的各类高等院校在校本、专科生[citation:3][citation:9] |
| **组队人数** | 每支参赛团队由1-2名指导老师和不超过5名学生组成[citation:3][citation:9] |
| **教师指导限制** | 每位老师当届指导的参赛团队数最多不超过3支，且作为第一指导老师的最多2支[citation:6][citation:9] |
| **学生参赛限制** | 每位学生当届只可参加一支团队，在校期间可以参赛2次（不限排序）[citation:6][citation:9] |
| **跨校组队** | 可以跨学校跨学院组队，团队信息只体现一所学校[citation:6][citation:9] |

### 2.2 创新创业类赛道

创新创业类竞赛分创新组和创业组，所有参赛项目必须和生命科学领域相关[citation:2][citation:5][citation:8]。

| 组别 | 成果要求 | 评审侧重 |
|:---:|:---|:---|
| **创新组** | 有创新实验取得的成果，形式包括学术论文（已发表或已录用，综述类论文或会议论文摘要不可申报）、发明专利（已受理申请并通过初审或公开或授权）、软件著作权等。团队负责人必须为成果的前三贡献者。每个参赛项目提供的成果不超过三项[citation:2][citation:5][citation:8] | 科学性与创新性、规范性、申请学生的贡献度[citation:2][citation:5][citation:8] |
| **创业组** | 完成一份具有市场前景的生命科学相关技术、产品或服务的创业计划书。分实践类和创意类，实践类项目成员之一须为公司股东（若仅有指导教师为股东，不能作为实践类项目）[citation:2][citation:5][citation:8] | 技术创新与经济性、规范性、申请学生的贡献度[citation:2][citation:5][citation:8] |

**参赛限制**：
- 每支参赛队伍由1-2名指导老师和不超过6名学生组成[citation:2][citation:5][citation:8]
- 创新组指导老师指导项目数没有限制，但所有指导老师必须在成果中有署名；创业组指导老师指导创业组项目数不超过2项[citation:2][citation:5][citation:8]
- 每位学生当届竞赛最多可参加创业组一个项目、创新组一个项目，且只能作为一个项目的负责人[citation:2][citation:5][citation:8]
- 可以跨学校跨学院组队，团队信息以项目负责人所在学校为第一单位[citation:5][citation:8][citation:10]
- 已在往届该赛事中获省级、国家级奖励的项目不得再次参赛[citation:2][citation:5][citation:8]

## 四、评审体系总览

### 4.1 评审组织机构

| 机构 | 职责 |
|:---:|:---|
| **竞赛组织委员会** | 负责制定大赛评审规则、遴选评审专家、评审评奖和异议处理等工作[citation:5][citation:8][citation:10] |
| **监督委员会** | 全程监督，确保竞赛公平、公开、公正。经查实参赛内容违反竞赛规则的，将取消参赛资格并通报所在省赛委员会和学校[citation:5][citation:8][citation:9] |

### 4.2 科学探究类评审机制

**网络评审规则**[citation:9]：
- 系统根据项目研究方向匹配5位网络评审专家
- 网络评审成绩为去掉最高分和最低分后的平均分
- 如果3个有效分值相差超过10分，将安排第6位专家评审，重新计算平均分
- 团队成员和指导老师均为加入状态，所有材料全部提交，同时满足以上条件才能进入网络评审环节

**省赛规则**[citation:9]：
- 省赛决赛中网络评审成绩占50%
- 原则上同一二级学院被推荐为国赛决赛的团队数不超过所在省总推荐团队数的15%
- 省赛结果须在省赛主页公示和公布

**国赛决赛**[citation:9]：
- 各省根据网络评审成绩组织省赛决赛确定参加国赛决赛的项目
- 没有省赛的地区可根据网络评审成绩排名推荐参加国赛决赛的项目
- 各省进入国赛决赛的团队数量原则上为有效参赛团队数量的6.5%

### 4.3 内部查重机制

竞赛平台以往届参赛论文为数据库，建立了竞赛内部查重系统[citation:9]。本届参赛项目如存在重复率过高且经人工复核后确认结果重复使用的情况，将被取消网络评审成绩[citation:9]。

## 五、科学探究类详细评分标准

### 5.1 网络评审总分构成[citation:9]

| 评审项目 | 分值 | 占比 |
|:---:|:---:|:---:|
| **立项报告** | 20分 | 20% |
| **实验记录** | 50分 | 50% |
| **论文** | 30分 | 30% |
| **总分** | **100分** | **100%** |

### 5.2 立项报告评分标准（20分）[citation:4][citation:9]

| 评审项目 | 分值 | 评审要点 |
|:---:|:---:|:---|
| **研究综述** | 10分 | 围绕参赛团队课题内容，阐述相应领域的最新研究进展，要求内容切题、信息正确、写作规范（不需要英文摘要，参考文献中的中文文献不需要翻译），字数3000-6000字（参考文献不计算在内），参考文献限1页[citation:4][citation:9] |
| **实验设计** | 10分 | 应包括本研究的目的与意义、研究内容、实验方案、技术路线、研究进度及预期成果。要求实验设计具有科学性、规范性和先进性[citation:4][citation:9] |

### 5.3 实验记录评分标准（50分）[citation:1][citation:4][citation:9]

| 评审项目 | 分值 | 评审要点 |
|:---:|:---:|:---|
| **实验自主性与工作量** | - | 强调学生选题的自主性和原创性[citation:9] |
| **实验技术** | - | 技术方法的掌握和应用能力 |
| **过程记录** | - | 实验操作和过程要尊重事实，认真严肃地在竞赛平台上及时记录实验数据和细节，上传实验过程和结果。实验记录题目须概括实验内容[citation:9] |
| **实验结果** | - | 所有图表结论等须有产生过程[citation:9] |
| **实验的真实性** | - | 确保实验数据的真实可靠 |
| **学生的收获** | - | 通过实验获得的成长与提升 |

**特别说明**：实验过程中出现失误或失败的，只要分析清楚，不影响得分。评审重在对整个实验过程的评价[citation:4][citation:9]。

### 5.4 论文评分标准（30分）[citation:9]

在上述实验的基础上形成论文，按照竞赛官方网站提供的论文模板撰写，包括中英文标题、中文摘要、正文图表，不需要英文摘要[citation:9]。论文重复率不超过20%[citation:3][citation:9]。

| 评审项目 | 评审要点 |
|:---:|:---|
| **论文质量** | 结构完整、逻辑清晰、表达准确 |
| **科学价值** | 研究的创新性和科学意义 |
| **规范性** | 格式规范、图表规范、参考文献规范 |
| **原创性** | 论文重复率不超过20% |

## 六、创新创业类评分标准

### 6.1 评审核心维度

根据竞赛规则，创新创业类作品的评审围绕以下核心维度展开[citation:2][citation:5][citation:7]：

| 组别 | 评审维度 | 评审要点 |
|:---:|:---:|:---|
| **创新组** | 科学性 | 研究方法的科学性、数据的可靠性、分析的合理性 |
| | 创新性 | 成果的创新程度、技术突破、原创性 |
| | 规范性 | 申报材料规范、成果规范 |
| | 申请学生的贡献度 | 团队负责人在成果中的贡献程度（须为成果的前三贡献者） |
| **创业组** | 技术创新 | 技术的先进性和创新程度 |
| | 经济性 | 市场前景、商业模式、盈利能力 |
| | 规范性 | 创业计划书规范、材料完整 |
| | 申请学生的贡献度 | 团队成员的参与程度和贡献 |

### 6.2 网络评审材料要求[citation:2][citation:5][citation:7]

| 组别 | 评审材料 | 匿名要求 |
|:---:|:---|:---|
| **创新组** | 报名表、作品申报书、佐证材料（论文/专利/软著等） | 需隐藏参赛团队成员个人、指导老师及所在单位信息 |
| **创业组** | 报名表、作品申报书、创业计划书（≤50页）、佐证材料、参赛视频（50M内，mp4格式） | 需隐藏参赛团队成员个人、指导老师及所在单位信息 |

## 八、学术诚信与违规处理

### 8.1 原创性要求

| 要求 | 具体规定 |
|:---:|:---|
| **自主原创** | 强调学生选题的自主性和原创性，相同内容请勿重复参赛[citation:9] |
| **查重要求** | 论文重复率不超过20%[citation:3][citation:9] |
| **内部查重** | 竞赛平台建立内部查重系统，重复率过高且经人工复核确认结果重复使用的，取消网络评审成绩[citation:9] |
| **禁止重复参赛** | 已在往届该赛事中获省级、国家级奖励的项目不得再次参赛[citation:2][citation:5][citation:8] |

### 8.2 违规处理

| 违规情形 | 处理措施 |
|:---:|:---|
| **材料中出现团队信息** | 网络评审时若发现材料中出现团队相关的姓名、学校、团队编号等信息，该项目总分做零分处理[citation:9] |
| **违反竞赛规则** | 经监督委员会查实，取消参赛资格并通报所在省赛委员会和学校[citation:9] |

## 九、评审特点分析

1. **双赛道分类评价**：科学探究类侧重实验研究过程的完整性和科学性，创新创业类侧重成果的创新性和应用价值，评分标准精准体现两类作品的不同特点。

2. **过程性评价为核心**：科学探究类竞赛中，实验记录占比高达50%，强调对实验全过程的记录和评价。实验过程中出现失误或失败的，只要分析清楚，不影响得分，评审重在对整个实验过程的评价[citation:4][citation:9]。

3. **三级递进评审机制**：网络评审→省赛→全国决赛层层递进，网络评审成绩在省赛中占50%，各省按比例推荐优秀队伍进入国赛决赛[citation:9]。

4. **网络评审双盲机制**：系统匹配5位专家评审，去掉最高分最低分后取平均分；有效分值相差超过10分时安排第6位专家重新计算；所有材料需匿名提交，出现团队信息零分处理[citation:9]。

5. **严格的查重制度**：论文查重率不超过20%，竞赛平台建立内部查重系统，防止重复参赛[citation:3][citation:9]。

6. **信息锁定机制**：网络评审开始后，项目名称、学校、指导教师、学生等信息不可更改，确保证书信息的准确性和严肃性[citation:9]。

7. **多维度综合评价**：科学探究类从立项报告（20分）、实验记录（50分）、论文（30分）三个维度评价；创新创业类从科学性/创新性、规范性、学生贡献度等维度评价，全面考察学生的科研能力、创新思维和团队协作精神。

---

**注意**：以上评审规则综合参考了《全国大学生生命科学竞赛章程》、第十一届全国大学生生命科学竞赛（科学探究类）规则及（创新创业类）通知、各高校校赛通知。每届竞赛的具体评分细则以当届发布的官方通知为准，各赛道评分标准可能存在差异，请以官网公布的最新版本为准。
