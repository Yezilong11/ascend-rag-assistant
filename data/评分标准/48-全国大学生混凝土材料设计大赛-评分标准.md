# 全国大学生混凝土材料设计大赛 - 评分标准

**来源网址**: https://bksy.bjtu.edu.cn/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国大学生混凝土材料设计大赛是由中国混凝土与水泥制品协会（CCPA）教育与人力资源工作委员会发起并主办的一项面向全国高校无机非金属材料与土木工程专业大学生的重要科技竞赛活动，每两年举办一届，迄今已成功举办七届。大赛以“以赛促教”为核心理念，旨在提升大学生理论结合实践的能力，培养实践型、创新型人才，现已成为土木工程材料领域最具影响力的全国性赛事之一[citation:1]。

**第八届（2026年）竞赛信息**：
- **大赛主题**：**“轻质高强高韧性混凝土材料设计大赛”**[citation:1]
- **主办单位**：中国混凝土与水泥制品协会教育与人力资源工作委员会
- **承办单位**：西北民族大学
- **协办单位**：兰州大学、兰州理工大学、兰州交通大学等
- **竞赛时间**：2026年7月17日-19日
- **竞赛地点**：甘肃·兰州

## 二、参赛要求

### 2.1 参赛资格与组队

| 要求类型 | 具体规定 |
|:---:|:---|
| **参赛对象** | 我国全日制本科生或大专生（含2026届毕业生），专业不限[citation:1] |
| **组队人数** | 每队由1名领队教师、1名队长（学生）和2名队员（学生）组成，共4人[citation:1] |
| **队伍数量** | 参赛队伍的报名数量不限，每个院校内部的报名数量也不限[citation:1] |
| **校内选拔** | 各高校自行组织校内选拔赛，择优推荐队伍参加全国大赛[citation:2][citation:3] |

### 2.2 作品要求

第八届大赛要求参赛队伍制作并提交纤维混凝土小梁试件：

| 项目 | 具体要求 |
|:---:|:---|
| **试件规格** | 2根尺寸为**50×50×1000mm**的纤维混凝土小梁，在赛前邮寄至组委会[citation:1] |
| **原材料要求** | 采用水泥、矿物掺合料、骨料、纤维、化学外加剂等原材料制作 |
| **水泥类型** | 包括但不限于硅酸盐水泥、铝酸盐水泥、硫铝酸盐水泥 |
| **矿物掺合料** | 包括但不限于粉煤灰、矿渣粉、硅灰、微珠、石粉 |
| **骨料要求** | 种类不限，但骨料粒径不宜大于10mm |
| **纤维要求** | 纤维种类不限，但纤维直径不应大于2mm，长度不应大于50mm |
| **容重限制** | 混凝土小梁的容重不得大于**2300kg/m³**，否则成绩无效[citation:1] |
| **禁用规定** | 所制作的纤维混凝土小梁中不应出现直径大于2mm的各种加强筋，不应出现连续配筋，否则成绩无效[citation:1] |
| **龄期要求** | 邮寄组委会时的等效龄期为28天[citation:1] |

## 五、全国总决赛评分标准

第八届大赛采用**七因素评价体系**，总分为各项因素加权得分之和[citation:1]。

### 5.1 成绩评定因素与权重

| 序号 | 因素 | 权重 | 说明 |
|:---:|:---|:---:|:---|
| 1 | 土木工程材料基础理论考试 | **35%** | 参赛队伍三名学生成员成绩的平均值 |
| 2 | PPT答辩 | **15%** | 配合比设计理念、方法、测试结果分析、优化措施 |
| 3 | 抗弯强度 | - | 仅记录，不参与评定 |
| 4 | 容重 | - | 仅记录，不参与评定 |
| 5 | 抗弯强度/容重 | **20%** | 单位容重下的抗弯承载能力 |
| 6 | 弯曲韧性（能量比）和荷载比 | **25%** | **0.5×能量比 + 0.5×荷载比** |
| 7 | 均质性（断裂面上纤维分布均质性） | **5%** | 依据断裂面上纤维分布的均匀程度判定 |
| **总分** | | **100%** | |

### 5.2 基础理论考试（35%）

| 项目 | 具体要求 |
|:---:|:---|
| **考试形式** | 闭卷笔试[citation:4] |
| **参考题型** | 单项选择题、多项选择题、简答题[citation:4] |
| **考试内容** | 水泥基材料制备和性能、混凝土配合比设计、混凝土性能表征和调控、土木工程材料与工程应用、工程实践和工程性能优化等[citation:1] |
| **成绩计算** | 每个参赛队伍的三名学生成员参加考试，队伍考试成绩为三名学生成员成绩的平均值[citation:1] |

### 5.3 PPT答辩（15%）

| 项目 | 具体要求 |
|:---:|:---|
| **汇报时长** | 8分钟[citation:1] |
| **PPT提交时间** | 赛事前一个星期[citation:1] |
| **汇报内容** | 纤维混凝土小梁的配合比设计理念、配合比设计方法、前期预测试结果、组委会提供的测试结果、下一步的性能优化措施等[citation:1] |
| **评审方式** | 组委会安排专家对每个队伍的PPT汇报进行评审[citation:1] |

### 5.4 抗弯折性能测试与评分（45%）

#### 5.4.1 测试方法

| 项目 | 具体要求 |
|:---:|:---|
| **试样选取** | 在参赛队伍提供的2根小梁中**随机抽取一根**进行测试[citation:1] |
| **预处理** | 在小梁底面制作深度5mm、宽度（切割片厚度）不大于2mm的预切口[citation:1] |
| **加载方式** | 三分点加载，跨距800mm[citation:1] |
| **控制模式** | 位移控制模式，压头有效行程6mm[citation:1] |
| **数据分析** | 对荷载-挠度曲线进行分析，获得抗弯强度、弯曲韧性（能量比）和荷载比[citation:1] |

#### 5.4.2 评分指标解析

| 指标 | 计算方法 | 评分权重 |
|:---:|:---|:---:|
| **抗弯强度/容重** | 抗弯强度实测值 ÷ 试件容重 | 20% |
| **能量比** | Scurve / Srectangle（曲线下面积与矩形面积之比） | 25%×0.5 |
| **荷载比** | f6mm / fmax（挠度6mm时荷载与最大荷载之比） | 25%×0.5 |
| **均质性** | 依据断裂面上纤维分布的均匀程度判定 | 5% |

## 八、评审特点分析

1. **七因素综合评价体系**：大赛采用七因素评价法，涵盖**理论考试（35%）、抗弯强度/容重（20%）、弯曲韧性与荷载比（25%）、均质性（5%）、PPT答辩（15%）**，全面考察学生的理论知识、设计能力、实践技能和表达水平[citation:1]。

2. **性能导向的核心评分**：评分重点围绕混凝土的**轻质（容重≤2300kg/m³）、高强（抗弯强度）、高韧性（能量比、荷载比）**三大核心性能指标，与大赛主题“轻质高强高韧性”高度契合[citation:1]。

3. **容重一票否决制**：作品容重超过2300kg/m³即成绩无效，体现了对“轻质”目标的刚性要求，引导学生在追求强度的同时注重减重设计[citation:1]。

4. **随机抽测确保公平**：从参赛队伍提交的2根小梁中随机抽取1根进行测试，避免了针对性制备的偏差，确保测试结果的代表性[citation:1]。

5. **理论实践并重**：理论考试占35%，实践测试占50%（性能指标）+15%（答辩汇报），合计65%，既考察基础知识，更强调实践创新能力[citation:1]。

6. **全过程评价**：从原材料选择、配合比设计、试件制备、性能测试到结果分析和优化建议，评价覆盖了混凝土材料设计的全过程[citation:1][citation:4]。

7. **团队协作能力考察**：队伍由4人组成（1名领队教师+3名学生），理论考试成绩取三人平均值，既考察个人能力，也强调团队协作[citation:1]。

8. **严格的禁用规定**：明确禁止使用直径大于2mm的加强筋和连续配筋，确保竞赛聚焦于材料本身的性能优化而非结构增强，体现了材料设计的竞赛本质[citation:1]。
