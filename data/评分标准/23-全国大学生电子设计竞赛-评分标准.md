# 全国大学生电子设计竞赛 - 评分标准

**来源网址**: http://www.nuedcchina.com/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国大学生电子设计竞赛（National Undergraduate Electronic Design Contest）是教育部高等教育司、工业和信息化部人事教育司共同发起的大学生学科竞赛，是目前中国规模最大、最具影响力的电子信息类学科竞赛之一。竞赛始于1994年，每两年举办一届（单数年），自2023年起改为每年举办。

**竞赛目的**：按照紧密结合教学实际，着重基础、注重前沿的原则，促进电子信息类专业和课程的建设，引导高等学校在教学中注重培养大学生的创新能力、协作精神；加强学生动手能力和工程实践能力的培养，提高学生针对工程问题进行电子设计、制作的综合能力；吸引、鼓励广大学生踊跃参加课外科技活动，为优秀人才脱颖而出创造条件[citation:5][citation:7]。

**竞赛特色**：
- 与高等学校相关专业的课程体系和课程内容改革密切结合，着重基础、注重前沿[citation:3]
- 强调“理论设计”与“实际制作”相结合，以电子电路和集成电路应用设计为基础[citation:5]
- 鼓励团队协作，每队3人，在四天三夜内完成作品设计与制作

**竞赛组织架构**：
- **全国竞赛组委会**：负责全国竞赛的组织领导、协调与宣传工作
- **全国专家组**：负责竞赛命题、评审工作[citation:7]
- **赛区组委会**：各省（自治区）、直辖市组成，负责本赛区竞赛的组织领导
- **赛区专家组**：负责本赛区竞赛的评审工作

## 二、竞赛形式与赛程安排

### 2.1 竞赛时间

2025年全国竞赛时间为**7月30日（周三）8:00至8月2日（周六）20:00**[citation:2][citation:4][citation:5]。竞赛以赛区为单位统一组织报名、竞赛、评审和评奖工作。

### 2.2 发题方式

全国竞赛采取**网上发题**方式。7月30日8:00开赛时，将依托以下网站发布全国竞赛题目[citation:2][citation:7]：
- 全国大学生电子设计竞赛网站（http://nuedc.xjtu.edu.cn）
- 全国大学生电子设计竞赛培训网（http://nuedc-training.com.cn）
- 其他有关赛区网站

### 2.3 竞赛形式

| 项目 | 具体要求 |
|:---:|:---|
| **竞赛时长** | 四天三夜（7月30日8:00至8月2日20:00） |
| **组队要求** | 每队3人，自愿组合[citation:2][citation:4] |
| **分组设置** | 本科生组、高职高专学生组[citation:5][citation:7] |
| **竞赛场地** | 原则上由参赛学校提供所需场地及仪器设备、元器件或材料[citation:7] |
| **竞赛规则** | 半开放，可使用图书资料和网络资源，但不得与队外人员讨论交流[citation:5] |

### 2.4 评审时间安排

| 评审阶段 | 时间安排（2025年） | 主要内容 |
|:---:|:---:|:---|
| **赛区测评** | 8月4日-8月8日 | 各赛区组织现场测试与评审 |
| **综合测评** | 8月10日8:00-15:00 | 推荐全国奖队伍全封闭设计与制作[citation:1][citation:6] |
| **全国评审** | 8月中旬-9月 | 全国专家组综合评审，确定获奖名单 |

## 三、参赛要求

### 3.1 参赛资格

| 要求类型 | 具体规定 |
|:---:|:---|
| **参赛对象** | 普通高等学校具有正式学籍的全日制在校本科或高职高专学生[citation:5][citation:7] |
| **组队要求** | 3人一队，由所在学校统一向赛区竞赛组委会报名[citation:2][citation:4] |
| **组别划分** | 参赛队分本科生组和高职高专学生组。参赛的本科生只能选本科组题目；高职高专学生原则上选择高职高专组题目，也可选择本科组题目。只要参赛队中有本科生，该队只能选择本科组题目[citation:5][citation:7] |
| **指导教师** | 每支参赛队可配备不超过2名赛前指导教师[citation:5] |

### 3.2 竞赛规则

| 规则类型 | 具体规定 |
|:---:|:---|
| **全程参与** | 参赛队3名学生必须全部按统一时间全程参加竞赛，按时开始和结束竞赛[citation:5] |
| **交流限制** | 竞赛期间不得以任何方式与队外人员进行讨论交流，教师和其他非参赛队员必须回避[citation:5][citation:7] |
| **作品要求** | 除题目特殊要求外，参赛队的作品中不得包含个人计算机、手机等，实际制作实物中凡需软件编程的芯片必须事先下载脱机工作[citation:5][citation:7] |
| **诚信要求** | 如发现教师参与、他人代做、抄袭及被抄袭、队与队之间交流等，将取消获奖，并通报批评[citation:5] |

## 四、评审体系总览

### 4.1 “一次竞赛，两级评奖”机制

全国竞赛采用**“一次竞赛，两级评奖”**方式，竞赛奖励分为“赛区奖”和“全国奖”两级[citation:2][citation:4][citation:7]。

| 评奖层级 | 负责机构 | 奖项设置 |
|:---:|:---|:---|
| **赛区奖** | 各赛区竞赛组委会 | 赛区一等奖、二等奖、三等奖、成功参赛奖 |
| **全国奖** | 全国竞赛专家组 | 全国一等奖、二等奖、TI杯 |

### 4.2 评审流程

校赛选拔 → 赛区测评 → 推荐全国奖 → 综合测评 → 全国评审

1. **校赛选拔**：各高校组织校内选拔，推荐优秀队伍参加赛区竞赛[citation:3][citation:8]
2. **赛区测评**：赛区专家组对参赛作品进行现场测试与评审
3. **推荐全国奖**：赛区报送不超过本赛区本科组实际参赛队总数10%的优秀队伍参加全国评奖[citation:2][citation:4][citation:7]
4. **综合测评**：推荐全国奖的队伍参加全封闭式综合测评，满分30分计入全国评审总分[citation:1][citation:6]
5. **全国评审**：全国专家组通过综合测评、复测等环节，产生全国竞赛获奖初评结果[citation:2][citation:4]

## 五、综合测评评分标准

### 5.1 综合测评概述

“综合测评”是全国竞赛评审工作中的重要环节，是“一次竞赛二级评审”工作中全国专家组评审工作的一部分[citation:1]。

**综合测评对象**：赛区推荐上报全国评奖的优秀参赛队全体队员，以队为单位在各赛区以**全封闭方式**进行[citation:1]。

**综合测评时间**：8月10日8:00～15:00（7小时设计制作）[citation:1][citation:6]。

### 5.2 综合测评规则

| 规则类型 | 具体要求 |
|:---:|:---|
| **封闭要求** | 各队不能上网、不能使用手机、计算机[citation:1][citation:6] |
| **可携带物品** | 纸质图书资料、纸笔尺削笔刀、少量导线、不带存储和网络功能的计算器[citation:1][citation:6] |
| **禁止携带** | 电子元器件、集成电路、除手持式万用表以外的任何仪器设备[citation:6] |
| **统一器件** | 使用的电路板及器件由全国竞赛组委会统一提供[citation:1][citation:6] |
| **测试记录** | 每队需至少3名专家负责测试记录，并在同一张测试记录表上同时签名。记录波形时需手绘，不得使用拍照打印附页[citation:1] |

### 5.3 综合测评评分标准

| 评分项目 | 满分 | 说明 |
|:---:|:---:|:---|
| **综合测评成绩** | 30分 | 测评题目与评分标准由全国专家组统一制定[citation:1][citation:6] |

**最低分数线**：超过最低分数线的作品，按实际得分计入全国评审总分。最低分数线划定事宜由全国专家组负责[citation:1][citation:6]。

## 六、赛区评审标准

### 6.1 赛区测评评分维度

赛区测评着重考核参赛学生综合运用基础知识进行理论设计的能力、实践创新和独立工作的基本能力、实验综合技能（制作与调试），同时鼓励参赛学生发扬团队协作精神[citation:5][citation:7]。

| 评审维度 | 评审要点 |
|:---:|:---|
| **理论设计** | 方案合理性、设计完整性、理论分析深度 |
| **实际制作** | 功能实现程度、性能指标达成、系统稳定性 |
| **创新性** | 技术突破、方案优化、创意应用 |
| **现场表现** | 作品演示效果、答辩应对能力 |

### 6.2 校赛评分标准参考（以北京工商大学2025年校赛为例）

单片机选题“智能循迹避障消防车设计”评分标准[citation:3]：

| 评分项目 | 分值 | 评审要点 |
|:---:|:---:|:---|
| **基本功能** | 100分 | 循迹、避障、消防等基本功能完成度 |
| **进阶功能** | 50分 | 通信功能、速度控制等（学有余力者选做） |
| **报告设计** | 50分 | 设计报告完整性、规范性、逻辑性 |
| **总分** | **200分** | - |

## 八、评审特点分析

1. **“一次竞赛，两级评奖”机制**：赛区奖与全国奖分开评审，既保证了各省的自主性，又确保了全国评奖的统一标准。

2. **综合测评核心环节**：推荐全国奖的队伍必须参加全封闭式综合测评，满分30分计入总分，有效检验学生的真实水平和独立设计能力。

3. **理论与实践并重**：竞赛题目包括“理论设计”和“实际制作”，既考察学生的理论知识，又检验动手能力和工程实践能力[citation:5][citation:7]。

4. **严格的诚信保障**：综合测评实行全封闭管理，赛区实施网络在线监控，测试记录必须由3名专家同时签名，确保评审公正性[citation:1][citation:5]。

5. **分组分类评价**：本科组与高职高专组分别命题、分别评奖，确保不同层次学生的公平竞争[citation:5][citation:7]。

6. **校赛-省赛-国赛三级选拔**：层层递进，确保最优秀的队伍能够脱颖而出。

7. **禁止携带成品**：除题目特殊要求外，参赛作品不得包含个人计算机、手机等，实际制作实物中凡需软件编程的芯片必须事先下载脱机工作，确保作品的原创性和完整性[citation:5][citation:7]。
