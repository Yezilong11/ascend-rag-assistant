# 全国大学生电子商务“创新、创意及创业”挑战赛 - 评分标准

**来源网址**: http://www.3chuang.net/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国大学生电子商务“创新、创意及创业”挑战赛（简称“三创赛”）是在2009年由教育部委托教育部高校电子商务类专业教学指导委员会主办的全国性在校大学生学科性竞赛。根据教育部、财政部（教高函〔2010〕13号）文件精神，三创赛是激发大学生兴趣与潜能，培养大学生创新意识、创意思维、创业能力以及团队协同实战精神的比赛[citation:2]。大赛的目的是强化创新意识、引导创意思维、锻炼创业能力、倡导团队精神[citation:1]。

**赛事地位**：三创赛现已成为颇具影响力的全国性品牌赛事，在《2023全国普通高校大学生竞赛分析报告》84项赛事中位列第12位，在2024年全国高校大学生学科竞赛排行榜“创新创业类”赛事中排名第三[citation:7]。

**第十六届（2026年）竞赛信息**：
- **主办单位**：全国电子商务产教融合创新联盟、西安交通大学[citation:1]
- **竞赛形式**：采用校赛、省赛和国赛三级竞赛体制[citation:1]
- **报名时间**：2025年11月07日-2025年12月31日[citation:1]
- **校赛时间**：2026年3月11日-2026年4月10日[citation:1]
- **省赛时间**：2026年4月20日-2026年6月22日[citation:1]
- **国赛时间**：2026年7月10日-2026年8月初[citation:3]

## 三、参赛要求

### 3.1 组队要求

| 要求类型 | 具体规定 |
|:---:|:---|
| **组队方式** | 分学生队（队长和队员须全部为全日制在校学生）和混合队（教师作为队长或队员，队员中学生数量必须多于教师）[citation:2] |
| **团队人数** | 3-5名，其中一名为队长[citation:1] |
| **参赛限制** | 参赛选手每人可以同期参加一个常规赛和一个实战赛（同一团队如果参加两个比赛必须注册两个团队ID号）[citation:2] |
| **跨校组队** | 可以跨校组队，以队长所在学校为该队报名学校[citation:3] |
| **指导教师** | 每个团队可以有0-2名高校指导老师，0-2名企业指导老师[citation:1] |

### 3.2 作品要求

| 要求类型 | 具体规定 |
|:---:|:---|
| **作品名称** | 不超出30个字符，团队名不能超过16个字符[citation:1] |
| **内容要求** | 应当充满正能量、符合主旋律，不能含有色情、暴力和低俗等内容，更不能与中华人民共和国法律相抵触[citation:2] |
| **原创性** | 参赛作品必须是参赛团队的原创作品和首次参加比赛（公开发表）[citation:2] |
| **迭代创新** | 非首次参赛作品需提交原参赛作品及迭代创新说明[citation:2] |

### 3.3 报名方式

由团队学生队长代表参赛团队在三创赛官网（www.3chuang.net）统一注册。在注册时，队长要按照系统提示，做参赛团队重要规则（第十六届三创赛规则的第四十八条到第五十四条）的答题测试，只有回答正确（通过了测试）的团队，才能完成正式注册[citation:1][citation:2]。

## 四、常规赛评分标准

### 4.1 评分项目与分值

根据第十六届三创赛官方竞赛规则，常规赛采用5项积分制，总分100分[citation:2]：

| 评分项目 | 分值 | 评分说明 |
|:---:|:---:|:---|
| **创新** | 0-25分 | 项目具备了明确的创新点：新产品、新技术、新模式、新服务等至少有一个明确的创新点 |
| **创意** | 0-25分 | 进行了较好的、创新性的项目商务策划和可行性分析。商务策划主要是对业务模式、营销模式、技术模式、财务支持等进行的设计；项目可行性分析主要是对经济、管理、技术、市场等方面的可行性分析 |
| **创业** | 0-25分 | 开展了一定的实践活动，包括（但不限于）：创业的准备、注册公司或与公司合作、电商营销、经营效果等，并需要提供相应的佐证材料 |
| **演讲** | 0-15分 | 团队组织合理、分工合作、配合得当；服装整洁，举止文明，表达清楚；有问必答，回答合理 |
| **文案** | 0-10分 | 提交的文案和演讲PPT逻辑结构合理，内容介绍完整、严谨，文字、图表清晰通顺，附录充实 |

### 4.2 评审维度解析

| 评审维度 | 权重 | 评审要点 |
|:---:|:---:|:---|
| **创新** | 25% | 新产品、新技术、新模式、新服务等创新点的明确性和独特性 |
| **创意** | 25% | 商务策划的创新性、可行性分析的全面性和科学性 |
| **创业** | 25% | 实践活动的真实性、佐证材料的充分性、经营效果的可验证性 |
| **演讲** | 15% | 团队配合、表达清晰度、问题回答的准确性 |
| **文案** | 10% | 逻辑结构、内容完整性、文字图表规范性 |

## 五、实战赛评分标准

### 5.1 通用评分框架

实战赛的评分规则在各《实战赛实施方案》中具体规定[citation:2]。以**美妆新零售实战赛**为例，其评分标准如下[citation:5]：

| 评分项目 | 分值 | 评分说明 |
|:---:|:---:|:---|
| **创新** | 15分 | 营销方式的独特性 |
| **创意** | 15分 | 内容策划与实施 |
| **创业** | 45分 | 涵盖准备、过程及业绩（实战数据） |
| **演讲** | 15分 | 团队配合与表达 |
| **文案** | 10分 | 逻辑清晰、附录完整 |

**重要说明**：实战赛的“创业分”通常由竞赛平台导出的实战业绩数据折算。例如，浙江财经大学校赛规则中明确：实战赛道的创业分由竞赛平台导出的3月1日至3月20日的业绩数据折算[citation:4]。

### 5.2 商务大数据分析实战赛

商务大数据分析实战赛参照常规赛道评分标准进行评审[citation:4]。

### 5.3 实战赛特别要求

实战赛团队必须依次添加《实战赛参赛学生知情书》和必要的授权书（协议），具体内容与模板见官网“资料下载”[citation:6]。

## 六、校赛评审形式

### 6.1 校赛流程

校赛通常采用“初赛网评+决赛答辩”两阶段形式[citation:7]：

| 阶段 | 评审形式 | 说明 |
|:---:|:---:|:---|
| **初赛（网评）** | 材料评审 | 直接评出二等奖，筛选出网评前30%（一般不超过20项）的团队进入答辩环节 |
| **决赛（答辩）** | 现场答辩 | 评选出特等奖和一等奖 |

### 6.2 答辩形式与时间

| 项目 | 具体要求 |
|:---:|:---|
| **答辩形式** | PPT讲解+实物展示（如需）[citation:6] |
| **团队陈述时间** | 8分钟[citation:10] |
| **提问与回答时间** | 7分钟[citation:10] |
| **总时长** | 15分钟 |

### 6.3 提交材料要求

| 材料类型 | 具体要求 |
|:---:|:---|
| **项目报告书** | PDF电子版，包括封页、承诺书、正文[citation:2] |
| **演讲PPT** | 用于现场答辩的演示文稿 |
| **承诺书** | 《参赛团队承诺与说明书》、《团队高校指导老师承诺书》（官网自动生成）[citation:2] |
| **匿名要求** | 所有参加校级选拔赛的参赛材料不得出现指导教师等信息[citation:7] |

## 七、奖项设置

### 7.1 校赛奖项

| 奖项 | 获奖比例（占有效参赛团队数量） |
|:---:|:---:|
| **特等奖** | 不超过5%（可空缺，要排出名次）[citation:2] |
| **一等奖** | 不超过25%[citation:2] |
| **二等奖** | 不超过35%[citation:2] |
| **单项奖** | 可设最佳创新奖、最佳创意奖、最佳创业奖等若干名[citation:2] |

### 7.2 实战赛专项奖

以美妆新零售实战赛为例，合作企业增设“综合营销类”“新媒体营销类”等专项奖，奖金池达150万元，包括华为设备、洗护套装等实物奖励，省级赛前三名可获价值千元至万元不等的核心洗护套装[citation:5]。

### 7.3 证书颁发

大赛获奖证书由竞组委在官网上统一颁发参赛证书和获奖证书[citation:2]。

## 八、学术诚信与违规处理

### 8.1 原创性要求

| 要求 | 具体规定 |
|:---:|:---|
| **原创作品** | 参赛作品必须是参赛团队的原创作品和首次参加比赛（公开发表）[citation:2] |
| **迭代创新** | 非首次参赛作品必须提交原参赛作品及迭代创新说明[citation:2] |
| **知识产权** | 参赛者应拥有作品著作权，大赛组委会不承担知识产权纠纷而产生的法律责任[citation:9] |

### 8.2 违规处理

| 违规情形 | 处理措施 |
|:---:|:---|
| **信息不一致** | 参赛过程中提交的作品文档和演讲中团队成员信息与官网注册信息不一致，取消参赛资格[citation:10] |
| **侵权行为** | 参赛队如果出现侵权行为，大赛组委会保留取消其参赛资格及追回奖项、奖品的权力[citation:9] |
| **无效项目** | 创业分归零或无实战数据者将取消资格[citation:5] |

## 九、评审特点分析

1. **“三创”核心权重均衡**：常规赛中，创新、创意、创业三项各占25分，合计75分，体现大赛名称“创新、创意及创业”的核心导向，三项能力并重，缺一不可[citation:2]。

2. **实战赛道创业主导**：实战赛中，创业分权重高达45分（占45%），且由平台导出的实战业绩数据折算，强调真实商业实践和经营效果，体现“真题真做”的导向[citation:4][citation:5]。

3. **演讲与文案并重**：演讲（15分）和文案（10分）合计25分，既考察书面表达能力，也重视现场展示和答辩表现[citation:2]。

4. **三级递进评审机制**：校赛（网评+答辩）→省赛→国赛层层递进，校赛初赛通过网评筛选，决赛通过答辩确定最终奖项[citation:7]。

5. **严格的原创性要求**：强调首次参赛，非首次参赛需提供迭代创新说明，确保项目的创新性和进步性[citation:2]。

6. **团队协作考察**：演讲环节明确考察“团队组织合理、分工合作、配合得当”，强调团队协同能力[citation:2]。

7. **实战数据真实性保障**：实战赛的创业分仅认可指定平台追踪记录的真实数据，确保评分客观公正[citation:5]。

8. **信息一致性红线**：参赛过程中所有材料信息必须与官网注册信息完全一致，否则取消参赛资格，确保证书的准确性和严肃性[citation:10]。
