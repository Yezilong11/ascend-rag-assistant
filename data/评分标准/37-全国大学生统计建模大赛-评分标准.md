# 全国大学生统计建模大赛 - 评分标准

**来源网址**: http://tjjmds.ai-learning.net/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国大学生统计建模大赛是在国家统计局统计教育培训中心指导下，由中国统计教育学会、教育部高等学校统计学类专业教学指导委员会、全国应用统计专业学位研究生教育指导委员会联合主办的全国性学科竞赛[citation:1]。大赛自2009年开始举办，每年一届，2023年成功入选《2023全国普通高校大学生竞赛分析报告》竞赛目录，是列入“高校学科竞赛排行榜”的国家级A类赛事[citation:3][citation:5]。

**第十二届（2026年）竞赛信息**：
- **大赛主题**：**“服务国家战略 创新统计赋能”**[citation:2]
- **主办单位**：中国统计教育学会
- **国赛承办单位**：内蒙古财经大学[citation:2]
- **省赛承办单位**：全国27个赛区院校分别承办[citation:2]

**大赛宗旨**：提高大学生运用统计方法和统计模型解决实际问题的能力；营造学习统计、应用统计的浓厚氛围；培育优良的科学精神、创新精神和实践精神；促进相关学科教育教学水平的不断提升；培养更多满足经济社会发展重大需求的统计人才[citation:1]。

## 二、参赛要求

### 2.1 参赛资格与分组

| 要求类型 | 具体规定 |
|:---:|:---|
| **参赛对象** | 高等院校全日制在校本科生、研究生均可报名，专业不限[citation:1][citation:2] |
| **组别设置** | 设本科生组和研究生组，本科生和研究生单独组队，不可跨组别组队[citation:2] |
| **组队要求** | 每支参赛队须满3人组队，不可跨校组队参赛[citation:2] |
| **每人限报** | 每名参赛者限报一支队[citation:1] |
| **指导教师** | 每队指导老师为1人，每位指导老师指导的参赛队伍总数不得超过4支[citation:2][citation:6] |

### 2.2 参赛材料要求

参赛队需提交以下材料[citation:2][citation:8]：

| 材料类型 | 具体要求 |
|:---:|:---|
| **报名表** | 官网下载模板填写 |
| **承诺书** | 《全国大学生统计建模大赛承诺书》 |
| **AI工具使用情况表** | 《全国大学生统计建模大赛参赛作品AI工具使用情况表》 |
| **论文全文** | Word完整版+PDF匿名版 |
| **知网查重报告** | 查重率不得超过20% |
| **数据包** | 原始数据、收集过程或数据出处、数据分析程序等 |

### 2.3 论文格式规范

| 项目 | 具体要求 |
|:---:|:---|
| **正文篇幅** | 正文字符数（计空格）不得超过16000字[citation:2][citation:4] |
| **查重要求** | 查重率不得超过20%，超过40%视为学术不端行为[citation:2][citation:4] |
| **匿名要求** | 匿名版论文中不得出现参赛人员姓名、指导教师姓名、参赛单位等相关信息，否则视为违规，取消参赛资格[citation:1][citation:4] |
| **论文结构** | 封面页、摘要与关键词、章节目录、表格与插图清单、论文正文、参考文献、附录、致谢等[citation:9] |

### 2.4 原创性要求

| 要求 | 具体规定 |
|:---:|:---|
| **原创作品** | 参赛作品必须是参赛队伍的原创作品，未参加过其他赛事，不得使用曾获奖论文参赛[citation:1] |
| **查重限制** | 查重率不超过20%[citation:2] |
| **禁止抄袭** | 抄袭、舞弊等学术不端行为将取消参赛资格，向学校通报批评[citation:2] |
| **往届禁止** | 不得使用往届论文重复参赛[citation:2] |
| **AI工具规范** | 须提交AI工具使用情况表，规范使用AI工具[citation:2] |

## 三、竞赛形式与赛程安排

### 3.1 三级赛制

竞赛采用“校内选拔推荐—省赛—国赛”三级赛制[citation:1]：

| 竞赛阶段 | 时间安排（第十二届） | 主要内容 |
|:---:|:---:|:---|
| **校内选拔推荐** | 5月15日前 | 各校自行选拔推荐优秀队伍进入省赛[citation:2] |
| **省赛** | 6月中旬 | 各赛区组织评审，评选省赛奖项并推荐国赛队伍[citation:2] |
| **国赛通讯/会议评审** | 7月-8月 | 通讯评审+现场会议评审，评出国赛三等奖、部分二等奖及入围答辩赛队伍[citation:2] |
| **全国总决赛现场答辩** | 8月 | 现场答辩，评出国赛部分二等奖及一等奖[citation:2] |

### 3.2 国赛评审环节

国赛设通讯评审、会议评审、现场答辩三个环节[citation:1]：

| 评审环节 | 评审方式 | 主要职责 |
|:---:|:---|:---|
| **通讯评审** | 每个参赛作品至少经3位评委评审 | 按照分数和分配比例遴选出进入现场复评的队伍[citation:1] |
| **会议评审** | 分组评审，每组至少3位评委 | 遴选出答辩赛的入选队伍[citation:1] |
| **现场答辩** | 现场PPT汇报+专家提问 | 考核参赛论文的原创性、科学性和合理性，评出国赛部分二等奖及一等奖[citation:2] |

## 四、评审体系总览

### 4.1 评审原则

| 原则 | 具体内容 |
|:---:|:---|
| **独立性原则** | 评委应独立按大赛《评审标准》明确给出个人打分并署名[citation:1] |
| **组长负责制原则** | 设评审组长1名，负责本级赛事的评审事务[citation:1] |
| **回避原则** | 评委应在校内选拔推荐环节回避自己指导的参赛队，在省赛和国赛中回避本校参赛队[citation:1] |

### 4.2 核心评审维度

竞赛评奖以以下四个维度为主要标准[citation:3]：

| 评审维度 | 评审要点 |
|:---:|:---|
| **假设的合理性** | 模型假设是否合理、是否符合实际问题背景 |
| **建模的创造性** | 模型的创新程度、解决问题的方法是否新颖独特 |
| **结果的正确性** | 计算结果是否准确、分析是否合理、结论是否可靠 |
| **文字表述的清晰程度** | 论文结构是否清晰、逻辑是否严谨、表达是否准确 |

### 4.3 具体评审要点

| 评审项目 | 评审要点 |
|:---:|:---|
| **问题理解** | 对问题背景的理解深度、问题重述的准确性 |
| **数据收集与处理** | 数据来源可靠性、数据处理方法科学性、数据挖掘深度 |
| **统计方法应用** | 统计方法选择的恰当性、应用的正确性、方法的创新性 |
| **模型建立** | 模型的科学性、合理性、创新性 |
| **模型求解** | 计算方法的选择、算法设计、计算机实现 |
| **结果分析** | 结果的解释、敏感性分析、误差分析 |
| **结论与建议** | 结论的合理性、建议的可行性、应用价值 |
| **论文写作** | 结构完整性、逻辑清晰度、表达准确性、格式规范性 |
| **原创性** | 论文查重率、创新程度、学术诚信 |

## 五、现场答辩评审标准

### 5.1 答辩形式

入选答辩队伍的3名队员原则上应全部到场参赛[citation:1]。参赛队伍应结合作品制作PPT演示文档，在现场答辩时进行汇报，并解答专家提问[citation:1]。

### 5.2 答辩评审维度

现场答辩以考核参赛论文的原创性、科学性和合理性为主要目标[citation:2][citation:6]：

| 评审项目 | 评审要点 |
|:---:|:---|
| **论文原创性介绍** | 必须包含论文原创性说明，证明作品的原创性[citation:2] |
| **内容自述** | 逻辑清晰、重点突出、时间控制合理 |
| **问题回答** | 回答准确、思路清晰、专业知识扎实 |
| **团队协作** | 团队成员分工配合、整体表现协调性 |

## 六、奖项设置

### 6.1 校赛奖项

| 奖项 | 获奖比例 | 说明 |
|:---:|:---:|:---|
| **校赛一等奖** | 10% | 由各校自行制定，部分学校设此奖项[citation:2][citation:6] |
| **校赛二等奖** | 20% | 由各校自行制定[citation:2][citation:6] |
| **校赛三等奖** | 30%-40% | 不同学校比例略有差异[citation:2][citation:6] |

**推荐规则**：各学校按照名额数选拔推荐队伍进入省赛，从获得校赛获奖的队伍中按照成绩排序推荐优秀队伍参加省赛[citation:2]。

### 6.2 省赛奖项

| 奖项 | 获奖比例 | 说明 |
|:---:|:---:|:---|
| **省赛一等奖** | 10% | 从入围省赛的参赛队中评选[citation:2][citation:6] |
| **省赛二等奖** | 20% | 从入围省赛的参赛队中评选[citation:2][citation:6] |
| **省赛三等奖** | 30% | 从入围省赛的参赛队中评选[citation:2][citation:6] |

**晋级规则**：从获得省赛一等奖的队伍中推荐优秀队伍参加国赛。入围国赛的参赛队同时获省赛一等奖，不占省赛获奖名额[citation:2][citation:6]。

### 6.3 国赛奖项

| 奖项 | 获奖比例 | 说明 |
|:---:|:---:|:---|
| **国赛一等奖** | 10% | 在入围国赛的队伍中选拔[citation:2][citation:6] |
| **国赛二等奖** | 20% | 在入围国赛的队伍中选拔[citation:2][citation:6] |
| **国赛三等奖** | 70% | 在入围国赛的队伍中选拔[citation:2][citation:6] |

### 6.4 其他奖项

| 奖项 | 说明 |
|:---:|:---|
| **优秀指导教师奖** | 获得全国赛一、二等奖的团队，指导教师获此证书[citation:5][citation:6] |
| **证书发放** | 获奖证书通过大赛平台以电子版方式发放，获奖队伍自行下载打印[citation:2][citation:5] |
| **论文出版** | 获奖的优秀论文将向中国知网推荐刊登，并公开出版《全国大学生统计建模大赛获奖论文选》[citation:5][citation:6] |

## 七、评审组织机构

### 7.1 组织机构

| 机构 | 职责 |
|:---:|:---|
| **大赛组织委员会** | 负责制定与修订大赛章程和赛事细则，指导和监督赛事组织实施[citation:1] |
| **大赛专家委员会** | 审定大赛评审标准，提供赛事专业咨询，评审与点评作品[citation:1] |
| **大赛仲裁委员会** | 负责对参赛作品中出现的学术不端、违规行为的鉴别和处理，对赛事期间的举报、投诉或争议进行裁决[citation:1] |

### 7.2 异议处理

大赛结束前，如发现抄袭、舞弊等学术不端行为，发现使用往届论文重复参赛等违规行为，发现违反大赛通知要求、承诺书条款等参赛基本条件的，可向本级组委会进行举报[citation:2]。举报须为实名制，并提供证据材料，否则不予以受理[citation:2]。

## 八、评审特点分析

1. **三级递进评审机制**：校内选拔推荐→省赛→国赛通讯/会议评审→现场答辩，层层递进，确保评审质量[citation:1]。

2. **四维核心评价体系**：以“假设的合理性、建模的创造性、结果的正确性、文字表述的清晰程度”为核心评价标准，全面考察学生的统计建模能力、创新思维和学术表达能力[citation:3]。

3. **严格的原创性要求**：查重率不得超过20%，超过40%视为学术不端行为；要求提交承诺书和AI工具使用情况表；严禁使用往届论文重复参赛[citation:2][citation:4]。

4. **匿名评审制度**：匿名版论文不得出现参赛人员姓名、指导教师姓名、参赛单位等相关信息，确保评审的公平公正[citation:1][citation:4]。

5. **现场答辩考核原创性**：现场答辩环节必须包含论文原创性介绍，以考核参赛论文的原创性、科学性和合理性[citation:2][citation:6]。

6. **分组分类评价**：本科生组和研究生组单独组队、单独评审，确保不同层次学生的公平竞争[citation:2]。

7. **多评委独立评分**：每个参赛作品至少经3位评委评审，评委独立打分并署名，确保评分的客观性和权威性[citation:1]。

8. **回避原则**：评委在省赛和国赛中回避本校参赛队，确保评审的公正性[citation:1]。

**注意**：以上评审规则综合参考了《全国大学生统计建模大赛章程（试行）》、第十二届（2026年）大赛官方通知及各高校校赛通知。每届竞赛的具体评分细则以当届发布的官方通知为准，请以官网公布的最新版本为准。
