# 中美青年创客大赛 - 评分标准

**来源网址**: https://chinaus-maker.cscse.edu.cn/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

中美青年创客大赛由中华人民共和国教育部主办，中国（教育部）留学服务中心、清华大学、北京歌华文化发展集团有限公司、中国大学科技园联盟承办，是中美人文交流框架下的国家级创客赛事。大赛旨在搭建跨文化共创平台，深化两国人文交流，鼓励青年创客以首创精神为核心，共同开发解决社会问题的创新原型。

**大赛主题**：**“共创未来”**

**主题内涵**：探索韧性社区、环境教育、低碳环保、食物系统、危机应对、公共卫生、健康福祉、清洁能源、气候变化、绿色交通、循环经济等领域的创新机遇，结合未来思维和设计创新，运用前沿科技和开源工具，打造兼具社会意义和产业价值的全新作品。

**核心使命**：
- 鼓励参赛选手应对人工智能的新趋势，开发前瞻性解决方案
- 推进社会数智化转型，助力全球可持续发展
- 推动中美创客文化与生态的共同建设，培育青年创客成长成才
- 引导创意向实际应用转化，实现创新方案的分享与合作行动

## 二、赛事体系与赛道设置

### 2.1 组织机构

| 机构角色 | 单位名称 |
|:---:|:---|
| **主办单位** | 中华人民共和国教育部 |
| **承办单位** | 中国（教育部）留学服务中心、清华大学、北京歌华文化发展集团有限公司、中国大学科技园联盟、美有关合作方 |

### 2.2 赛道设置

大赛设有多个赛道，以适应不同层次和类型的创客项目：

| 赛道 | 核心定位 | 评审侧重 |
|:---:|:---|:---|
| **主赛道** | 综合性创新项目 | 功能性原型、社会意义、产业价值、跨学科协作 |
| **青年英雄赛道** | 青年领导力与创新潜能 | 创意前瞻性、引领性、对青年群体的带动作用 |
| **高职院校赛道** | 技能应用与实践能力 | 与产业需求紧密结合、产教融合创新成果 |
| **中美联合组队赛道** | 跨文化协作创新 | 中美青年共创深度、融合视角的创新解决方案 |

## 三、竞赛形式与赛程安排

### 3.1 两级赛制

大赛采用“分赛区选拔赛+全国总决赛”两级赛制：

| 竞赛阶段 | 时间安排（2025年） | 主要内容 |
|:---:|:---:|:---|
| **启动、报名与分赛区选拔赛** | 2025年4月末至6月末 | 各分赛区组织选拔，推荐优秀作品 |
| **决赛入围团队优化作品** | 2025年6月末至7月中下旬 | 入围团队根据反馈优化完善作品 |
| **全国总决赛** | 2025年7月下旬 | 全国集中评审，确定最终奖项 |

### 3.2 作品形式要求

- 作品原型应呈现为实现一定创新功能的**智能硬件或软件**
- 强调完整的功能性原型
- 鼓励开源共享文化

## 四、官方评审原则

根据教育部“中美青年创客大赛”官方章程和历届评审办法，大赛秉持以下核心评审原则：

### 4.1 创新引领
鼓励原创性思维，考察作品的创新程度和独特性。强调首创精神，避免简单模仿或现有产品的微改良。

### 4.2 技术融合
评估前沿科技（特别是AI技术）与开源工具的应用深度。鼓励参赛选手应对人工智能的新趋势，开发前瞻性解决方案。

### 4.3 社会价值
关注作品对可持续发展、社区韧性、公共福祉等议题的贡献。考察作品对韧性社区、环境教育、低碳环保、食物系统、危机应对、公共卫生、健康福祉、清洁能源、气候变化、绿色交通、循环经济等领域的实际意义。

### 4.4 跨文化协作
体现中美青年在共创过程中的融合视角与合作精神。大赛致力于搭建跨文化共创平台，深化两国人文交流，通过融合中美文化视角与跨界合作，共同开发解决社会问题的创新原型。

## 五、通用评分细则

综合各分赛区和全国总决赛的评审标准，通常从以下四个维度进行打分：

| 评分维度 | 权重 | 评分要点 |
|:---:|:---:|:---|
| **创新性** | 30% | • 构思的原创性与独特性<br>• 对“共创未来”主题的诠释深度<br>• 问题发现与解决视角的新颖程度 |
| **可行性** | 25% | • 技术方案的合理性与可实现性<br>• 原型作品的完成度与稳定性<br>• 成果转化与社会推广的潜力 |
| **技术实现** | 25% | • 技术难度与复杂度<br>• 软硬件集成能力<br>• 对AI、物联网等前沿技术的应用水平 |
| **社会价值** | 20% | • 对社区、环境、健康等领域的实际意义<br>• 作品的社会影响力与推广价值<br>• 对可持续发展目标的贡献 |

## 六、各赛道特色评审要求

### 6.1 主赛道

|:---:|:---|

| **跨学科协作** | 鼓励不同专业背景的学生团队合作 |

### 6.2 青年英雄赛道

| 评审侧重 | 具体内容 |
|:---:|:---|
| **青年领导力** | 关注青年在项目中的主导作用和创新潜能 |
| **创新潜能** | 评估创意的突破性和前瞻性 |
| **带动作用** | 项目对青年群体的示范和带动效应 |
| **引领性** | 创意是否能够引领未来发展方向 |

### 6.3 高职院校赛道

|:---:|:---|

| **产业结合** | 鼓励与产业需求紧密结合的项目 |
| **产教融合** | 评估产教协同创新的成果 |
| **落地能力** | 作品的实际应用和推广潜力 |

### 6.4 中美联合组队赛道

| 评审项目 | 说明 |
|:---:|:---|
| **跨文化协作** | 中美青年在共创过程中的分工与协同深度 |
| **融合视角** | 融合中美文化视角的创新解决方案 |
| **加分项** | 跨文化协作的深度融合可获得额外加分 |

## 七、现场评审流程

全国总决赛通常包含以下评审环节：

| 环节 | 时间 | 评审重点 |
|:---:|:---:|:---|
| **作品展示** | 5-8分钟 | 原型演示、创新点讲解、技术实现说明 |
| **现场答辩** | 3-5分钟 | 回答评委提问、澄清技术细节、阐述社会价值 |
| **评委闭门合议** | - | 综合讨论、分数汇总、争议裁决 |

## 八、常见扣分项

根据历届参赛反馈，以下情况容易导致扣分：

| 扣分项 | 具体表现 |
|:---:|:---|
| **偏离主题** | 作品与“共创未来”核心主题关联性弱 |
| **创新不足** | 仅是现有产品的简单复现或改良 |
| **技术深度不够** | 停留在概念阶段，缺乏实质技术实现 |
| **社会价值模糊** | 未能清晰阐述作品对社会的实际贡献 |
| **完成度低** | 原型作品不稳定或关键功能缺失 |

## 九、获奖等级参考标准

| 奖项 | 综合评分参考线 | 特点 |
|:---:|:---:|:---|
| **特等奖** | 90分以上 | 创新性、技术深度、社会价值均极为突出 |
| **一等奖** | 85-89分 | 多个维度表现优异，整体完成度高 |
| **二等奖** | 75-84分 | 有明显亮点，但存在部分可改进之处 |
| **三等奖** | 60-74分 | 完整参赛作品，体现基本创新思维 |

## 十、重要提示

| 提示项 | 具体内容 |
|:---:|:---|
| **评分标准调整** | 评分标准每年可能微调，具体以当年发布的《大赛章程》和《评审细则》为准 |
| **分赛区补充规则** | 各分赛区可制定补充评分规则，但不得与全国总决赛基本原则冲突 |
| **评委独立性** | 指导教师不参与评分，评审全过程由独立评委完成 |
| **结果公示** | 获奖作品将在官网公示，接受社会监督 |
| **成果时效** | 强调开源共享文化，引导创意向实际应用转化 |

## 十一、评审特点分析

1. **跨文化协作核心导向**：大赛作为中美人文交流的重要平台，特别强调中美青年在共创过程中的融合视角与合作精神，中美联合组队赛道设置额外加分项。

2. **创新性与社会价值并重**：创新性30%、社会价值20%，既鼓励技术突破，又强调作品对可持续发展、公共福祉的实际贡献。

3. **主题导向明确**：“共创未来”主题贯穿始终，要求作品紧密围绕韧性社区、环境教育、低碳环保、健康福祉等全球性议题。

4. **技术融合要求**：鼓励应对人工智能新趋势，运用前沿科技和开源工具，开发前瞻性解决方案。

5. **实物原型要求**：作品须呈现为智能硬件或软件的功能性原型，强调完成度和可展示性。

6. **公平公正的评审体系**：独立评委评审，指导教师不参与评分，获奖作品公示接受监督，确保评审公正。

7. **多赛道分类评价**：主赛道、青年英雄赛道、高职院校赛道、中美联合组队赛道各有侧重，精准匹配不同类型项目特点。

---

**注意**：以上评审规则综合参考了教育部“中美青年创客大赛”官方章程、历届评审办法及分赛区参赛指南。每届竞赛的具体评分细则以当届发布的《大赛章程》和《评审细则》为准，各分赛区评分标准可能存在细微差异，请以官网公布的最新版本为准。
