# 中国大学生物理学术竞赛 - 评分标准

**来源网址**: https://www.cupt-iypt.com/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

中国大学生物理学术竞赛（China Undergraduate Physics Tournament，简称CUPT）是中国借鉴国际青年物理学家锦标赛（IYPT）的模式创办的一项全国性赛事。该项活动得到了教育部的支持，并被列入中国物理学会物理教学指导委员会的工作计划，是实践国家创新驱动发展战略纲要和国家教育中长期发展规划纲要的重要大学生创新竞赛活动之一[citation:1]。自2020年起，CUPT连续被纳入中国高等教育学会《全国普通高校大学生竞赛分析报告》竞赛目录。

**竞赛宗旨**：以协同创新为根本理念，旨在提高学生综合运用所学知识分析解决实际物理问题的能力，培养学生的开放性思维能力[citation:4]。参赛学生就实际物理问题的基本知识、理论分析、实验研究、结果讨论等进行辩论性比赛。

**核心目标**[citation:2][citation:8]：
1. 针对实际物理问题给出解决方案，锻炼学生解决复杂科学问题的能力
2. 培养学生应用物理学的基础知识、技术以及物理实验的研究方法解决实际问题的能力
3. 培养学生研究性学习的能力
4. 培养团队意识和协同研究的能力，注重个人能力与团队合作相结合
5. 提升学术表达和交流能力

**竞赛特色**：CUPT摆脱了应试教育的模式，体现知识学习与探索实践相结合，物理学与日常生活相结合，学术能力与人际交往能力相结合，个人与团队合作相结合的理念[citation:9]。

## 二、竞赛形式与赛道设置

### 2.1 竞赛题目

CUPT竞赛题目参考同年国际青年物理学家锦标赛（IYPT）题目，在力、热、光、电等物理分支下共设**17个题目**[citation:9]。2026年第十七届CUPT竞赛采用**第39届IYPT试题**[citation:4]。

### 2.2 赛道设置

CUPT竞赛设**团体赛**和**作品赛**两个赛道[citation:2][citation:8]。

| 赛道 | 核心内容 | 队伍组成 | 参赛要求 |
|:---:|:---|:---:|:---|
| **团体赛** | 团队对抗辩论 | 5名队员+1-2名领队 | 需有参赛资格（由各赛区委员会提供名单） |
| **作品赛** | 学术海报展示 | 1-5名队员+1-2名领队 | 不受“参与过或观摩过CUPT”的限制[citation:4] |

### 2.3 三级赛制

竞赛采用“校赛—省赛/区赛—全国总决赛”三级赛制：

| 竞赛阶段 | 时间安排（2026年） | 主要内容 |
|:---:|:---:|:---|
| **校赛** | 2025年10月-2026年3月 | 校内选拔，推荐优秀选手参加省赛/区赛 |
| **省赛/区赛** | 2026年5月-6月 | 各省/各赛区组织评审，选拔队伍晋级国赛[citation:4] |
| **全国总决赛** | 2026年8月 | 全国集中评审，确定最终奖项 |

### 2.4 分赛区设置

全国共设多个分赛区，例如：
- **东北赛区**：辽宁省、吉林省、黑龙江省、内蒙古自治区[citation:2]
- **中南赛区**：河南省、湖北省、湖南省、广东省、广西壮族自治区、海南省[citation:4]
- **华北赛区**：北京市、天津市、河北省、山东省、山西省、内蒙古自治区
- **华东赛区**：上海市、江苏省、浙江省、安徽省
- **西北赛区**：陕西省、甘肃省、宁夏回族自治区、青海省、新疆维吾尔自治区
- **西南赛区**：重庆市、四川省、贵州省、云南省、西藏自治区

## 四、团体赛评审体系

### 4.1 对抗赛形式

CUPT团体赛以抽签分组、团队辩论的方式进行[citation:9]。每轮对抗赛由三支或四支队伍参加，分别扮演不同角色：

| 角色 | 三队制 | 四队制 | 加权系数 |
|:---:|:---:|:---:|:---:|
| **正方(Rep)** | ✓ | ✓ | ×3.0 |
| **反方(Opp)** | ✓ | ✓ | ×2.0 |
| **评论方(Rev)** | ✓ | ✓ | ×1.0 |
| **观摩方** | - | ✓ | - |

### 4.2 对抗赛流程

每一阶段定时**55分钟**，具体流程如下[citation:9]：

| 流程 | 限时（分钟） |
|:---|:---:|
| 反方向正方提出挑战竞赛题目 | 1 |
| 正方接受或拒绝反方挑战的题目 | 1 |
| 正方准备 | 5 |
| 正方进行所选题的报告 | 12 |
| 反方向正方提问，正方回答 | 2 |
| 反方准备 | 3 |
| 反方的报告（最多五分钟），正反方讨论 | 15 |
| 评论方提问，正、反方回答 | 3 |
| 评论方准备 | 2 |
| 评论方报告 | 4 |
| 正方总结发言 | 2 |
| 评审团提问 | 5 |
| **总计** | **55** |

### 4.3 团体赛评分标准（全国通用）[citation:9]

#### 正方评分细则（满分10分）

| 评分项目 | 分值 | 评审要点 |
|:---:|:---:|:---|
| **内容** | 0-4分 | • 物理知识的正确性<br>• 论据是否切题<br>• 科学方法的正确运用<br>• 实验、理论及其一致性<br>• 结论的说服力 |
| **表达** | 0-2分 | • 思路清晰<br>• 表达清楚<br>• 公式和符号的正确解释<br>• 正确的模型，量纲的一致性<br>• 展示形式（现场演示实验，音频，视频）<br>• 正确的参考文献 |
| **讨论** | 0-3分 | • 物理的正确性<br>• 论据是否切题<br>• 恰当及扎实的物理知识<br>• 客观的辩论<br>• 对反方异议的讨论<br>• 礼貌的态度<br>• 对评论方的回答和总结发言<br>• 评委的问题和回答 |
| **机动分数** | 0-1分 | 额外加分项 |

#### 反方评分要点

| 评分项目 | 评审要点 |
|:---:|:---|
| **问题/表达** | • 提问是否离题<br>• 物理的正确性<br>• 表达清楚易懂<br>• 指出正方的优缺点 |
| **讨论** | • 物理的正确性<br>• 论点是否切题<br>• 恰当及扎实的物理知识<br>• 礼貌的态度<br>• 讨论正方的报告 |

### 4.4 团体赛成绩计算

在一轮对抗赛中，每一次阶段赛过后，每位裁判就各队承担的角色表现打分，分数为**1至10分的整数分数**[citation:9]。

**阶段赛成绩** = 裁判组的平均分数

**一轮比赛成绩** = 各阶段赛成绩的加权总和（正方×3.0、反方×2.0、评论方×1.0），结果四舍五入保留一位小数。

**预选赛总成绩** = 该队在所有五轮对抗赛中取得的成绩总和。

**排名规则**：以预选赛总成绩进行排名，前三名进入决赛。如果预选赛总成绩相同，则以各队赢得的对抗赛场次数目决定[citation:9]。

## 五、作品赛评分标准

### 5.1 作品赛形式

作品赛要求提交**单页的中文学术海报**[citation:2]：

| 项目 | 具体要求 |
|:---:|:---|
| **作品内容** | CUPT任意一道赛题的完整研究成果 |
| **版面规格** | 宽度90cm，高度120cm |
| **制作软件** | PPT、PS、AI等均可 |
| **匿名要求** | 内容中不得出现任何校名、校徽、人名、校训等可能影响评审公平性的信息 |
| **提交格式** | PDF电子文档，文件大小不超过8MB |

### 5.2 作品赛评审方式

| 环节 | 具体要求 |
|:---:|:---|
| **现场讲解** | 由学生现场进行讲解，接受裁判小组打分 |
| **材料准备** | 学生应自备作品的原始数据资料以备裁判质询[citation:2] |

### 5.3 作品赛评分维度

根据CUPT对研究成果的评审要求，作品赛评分应涵盖以下维度：

| 评审维度 | 评审要点 |
|:---:|:---|
| **物理正确性** | 理论分析准确、物理概念清晰 |
| **研究方法** | 科学方法的正确运用、实验设计合理性 |
| **理论分析** | 模型建立、理论推导、量纲一致性 |
| **实验研究** | 实验数据完整、现象明显、可重复验证 |
| **一致性** | 理论与实验结果的对比分析 |
| **创新性** | 研究方法创新、实验设计创新 |
| **表达呈现** | 海报设计清晰、逻辑性强、图文并茂 |

## 九、评审特点分析

1. **独特的对抗辩论形式**：CUPT以团队对抗辩论为核心，正方、反方、评论方角色轮换，评分加权系数不同（正方×3.0、反方×2.0、评论方×1.0），全面考察学生的学术表达、批判思维和临场应变能力。

2. **多维度综合评价**：从物理正确性、论据切题性、科学方法运用、实验与理论一致性、结论说服力等多个维度进行评价，而非单纯考察结果正确与否。

3. **校赛-省赛-国赛三级递进**：校赛以个人PPT答辩为主，省赛和国赛以团体对抗为主，层层递进，全面考察学生从独立研究到团队协作的综合能力。

4. **作品赛与团体赛双赛道**：团体赛侧重辩论能力与团队协作，作品赛侧重研究成果的完整呈现，两类赛道满足不同类型学生的需求。

5. **严格的时间控制**：每一阶段55分钟，各环节严格限时，考察学生的时间管理能力和临场应变能力。

6. **匿名评审制度**：作品赛海报须匿名提交，确保评审的客观公正。

7. **开放性物理问题**：赛题均为贴近实际生活的开放性物理问题，没有标准答案，评分更注重研究过程的科学性和创新性。
