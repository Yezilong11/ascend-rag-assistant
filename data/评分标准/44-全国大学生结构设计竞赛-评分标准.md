# 全国大学生结构设计竞赛 - 评分标准

**来源网址**: http://www.structurecontest.com/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国大学生结构设计竞赛是由教育部、财政部首次联合批准发文（教高函【2007】30号）的全国性9大学科竞赛资助项目之一，由中国高等教育学会工程教育专业委员会、高等学校土木工程学科专业指导委员会、中国土木工程学会教育工作委员会和教育部科学技术委员会环境与土木水利学部共同主办，各高校轮流承办。该竞赛被誉为 **“土木建筑工程皇冠上璀璨的明珠”** ，是土木工程学科最高水平的学科竞赛[citation:5]。

**竞赛宗旨**：以创造（Creativity）、协作（Cooperation）、实践（Construction）“3C”为宗旨；以“公平、公正、公开、公信”为竞赛原则；以践行“展示才华、提升能力、培养协作、享受过程、快乐竞赛”为竞赛理念，深入推进高校实践教育教学改革，为培养大学生“创意、创新、创业、创造”精神和团队协同以及工程创新设计能力[citation:3]。

**第十九届（2026年）竞赛信息**：
- **承办单位**：内蒙古科技大学[citation:5]
- **竞赛题目**：已于2026年1月2日公布
- **竞赛时间**：预计2026年10月举行

## 二、竞赛形式与赛程安排

### 2.1 两级赛制

竞赛采用“省（市）分区赛—全国总决赛”两级赛制[citation:5]：

| 竞赛阶段 | 时间安排 | 主要内容 |
|:---:|:---:|:---|
| **省（市）分区赛** | 4月-7月上旬 | 各省组织选拔，推荐优秀队伍参加全国总决赛[citation:4] |
| **全国总决赛** | 9月下旬-11月上旬 | 全国集中竞赛，确定最终奖项[citation:4] |

### 2.2 参赛资格与组队要求

| 要求类型 | 具体规定 |
|:---:|:---|
| **参赛对象** | 同一所高校在籍的全日制本科生、大专生[citation:4] |
| **组队要求** | 每队由3名学生组成，参赛学生必须属于同一所高校[citation:3][citation:4] |
| **指导教师** | 1-2名（3名及以上署名指导组），必须是参赛队所属高校在职教师[citation:3][citation:4] |
| **学校名额** | 参加全国总决赛的高校推荐1个参赛队，当年承办全国总决赛的高校可推荐2个参赛队[citation:4] |

### 2.3 竞赛流程

全国总决赛一般包括以下环节[citation:2][citation:4]：

| 环节 | 主要内容 |
|:---:|:---|
| **开幕式** | 竞赛启动 |
| **抽签** | 确定分组和加载顺序 |
| **现场模型制作** | 使用统一材料、工具在规定时间内制作模型 |
| **称重** | 测量模型重量 |
| **固定模型** | 将模型安装至加载台 |
| **陈述答辩** | 参赛者介绍作品构思，专家提问 |
| **加载测试** | 分级加载，记录模型表现 |
| **专家委员会讨论** | 综合评议成绩 |
| **闭幕式暨颁奖仪式** | 公布获奖名单 |

## 三、评审体系总览

### 3.1 评审组织机构

| 机构 | 职责 |
|:---:|:---|
| **全国竞赛专家委员会** | 审定竞赛规则和实施细则；评审参赛作品；确定获奖作品等级；点评参赛作品；处理竞赛过程中的异议问题[citation:2] |
| **全国竞赛组织委员会** | 负责具体组织实施竞赛的全过程[citation:2] |

### 3.2 评审基本原则

| 原则 | 具体内容 |
|:---:|:---|
| **公平、公正、公开** | 严格遵守竞赛规则 |
| **过程与结果并重** | 重视创新设计和动手实践能力 |
| **诚信参赛** | 参赛学生和指导教师必须严格遵守各项规定，认真履行所签署的各项承诺[citation:5] |

### 3.3 通用评审维度

竞赛评审包括方案设计与理论分析、模型制作效果、结构创新点、现场陈述与答辩、模型加载测试等环节[citation:5]。

以第十四届（2021年）竞赛为例，总分构成如下[citation:9]：

| 评审项目 | 分值 | 评审要点 |
|:---:|:---:|:---|
| **理论方案** | 5分 | 竞赛过程总结、现场计算[citation:9] |
| **模型结构与制作质量** | 10分 | 模型制作效果、结构合理性[citation:9] |
| **现场陈述与答辩** | 5分 | 作品构思介绍、问题回答[citation:9] |
| **加载表现** | 80分 | 模型承载能力、单位质量承载力[citation:9] |

## 四、加载表现评分标准（核心评分项）

加载表现是竞赛评分的核心部分，通常占总分的80%。以长江师范学院校赛采用的第十五届国赛评分规则为例，加载表现评分采用分级加载、单位质量承载力排名的方式[citation:8]：

### 4.1 加载流程

| 级别 | 总分 | 计分方式 |
|:---:|:---:|:---|
| **第一级加载** | 30分 | 加载成功，计算单位质量承载力k1i=M1i/M0i，k1i最高的参赛队得30分（k1,max），其他参赛队得分E1i=30k1i/k1,max[citation:8] |
| **第二级加载** | 40分 | 加载成功，计算单位质量承载力k2i=M2i/M0i，k2i最高的参赛队得40分（k2,max），其他参赛队得分E2i=40k2i/k2,max[citation:8] |
| **第三级加载** | 30分 | 加载成功，计算单位质量承载力k3i=M3i/M0i，k3i最高的参赛队得30分（k3,max），其他参赛队得分E3i=30k3i/k3,max[citation:8] |

**总分计算**：Ei = E1i + E2i + E3i[citation:8]

其中：
- M1i、M2i、M3i：各级加载放置的砝码总质量
- M0i：第i队模型总质量

### 4.2 计分特点分析

| 特点 | 说明 |
|:---:|:---|
| **相对评分** | 采用排名制，最高得分者得满分，其余按比例折算[citation:8] |
| **单位质量承载力导向** | 强调“轻质高强”，鼓励在保证承载力的前提下尽可能减轻模型重量[citation:8] |
| **分级递进** | 三级加载逐级增加难度，考察模型在不同荷载工况下的表现[citation:8] |

## 九、学术诚信与违规处理

### 9.1 原创性要求

| 要求 | 具体规定 |
|:---:|:---|
| **独立完成** | 参赛作品必须是参赛团队的原创作品 |
| **诚信参赛** | 必须严格遵守《章程》、《实施细则》等各项规定，认真履行所签署的各项承诺[citation:5] |

### 9.2 违规处理

| 违规情形 | 处理措施 |
|:---:|:---|
| **违反承诺及规则** | 取消其评奖资格[citation:5] |
| **严重尺寸违规** | 允许完成加载过程，但成绩不计入获奖排名[citation:8] |
| **违纪行为处理不力** | 对出现违纪行为并处理不力的高校，视情节可给予公开通报批评或取消其下一年度参赛评奖资格[citation:5] |

### 9.3 异议处理

获奖作品在竞赛结束后保留**15天的异议期**，若收到投诉，竞赛委员会将会同专家委员会组织调查，经确认有违规行为，则取消该作品奖项，并予以通报[citation:2]。

## 十、评审特点分析

1. **加载表现核心主导**：加载表现占总分80%，强调“轻质高强”的设计理念，通过分级加载和单位质量承载力排名的方式，考察模型的承载效率[citation:9][citation:8]。

2. **相对评分机制**：采用排名制，最高得分者得满分，其余按比例折算，确保评分的公平性和区分度[citation:8]。

3. **四级评审体系**：理论方案（5分）、模型制作质量（10分）、陈述答辩（5分）、加载表现（80分）四维评价，全面考察学生的理论分析能力、动手实践能力、表达沟通能力和工程创新思维[citation:9]。

4. **两级递进选拔机制**：省（市）分区赛→全国总决赛层层递进，各省15%一等奖比例获得参加全国总决赛的资格[citation:3]。

5. **现场制作刚性要求**：全国总决赛采用统一时间、地点，使用统一材料、工具制作和统一设备测试的方式，确保公平公正[citation:5]。

6. **单项奖鼓励创新**：最佳创意奖和最佳制作奖各1项，鼓励学生在结构创新和制作工艺方面追求卓越[citation:3]。

7. **严格的尺寸控制**：模型必须满足赛题规定的净空、尺寸要求，严重违规者虽可完成加载但不计入获奖排名[citation:8]。

8. **异议期制度**：15天公示期和异议处理机制，保障竞赛结果的公信力[citation:2]。
