# 全国高等院校数智化企业经营沙盘大赛 - 评分标准

**来源网址**: https://www.bizsand.cn
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国高等院校数智化企业经营沙盘大赛由中国商业联合会主办，是入选中国高等教育学会《全国普通高校大学生竞赛排行榜》的国家级赛事[citation:2]。大赛自2005年发起以来已成功举办二十届，有效推动了经管实践教学与创新创业教育的融合和相互促进[citation:4]。

**赛事定位**：通过还原真实的企业数智化转型改造应用场景，要求参赛选手根据项目需求，利用专业知识和技能，模拟营销总监、财务总监、生产总监、人力总监完成数智企业经营管理[citation:2]。

**竞赛目标**：考察参赛选手在数智化转型背景下的市场调查与分析、生产智能化、财务数字化、营销数字化、人力资源管理智能化、大数据统计分析、大数据管理运用等方面的实践应用能力；重点考核选手的数字化战略、数字化思维、数字化执行和数字化创新的技能[citation:2][citation:9]。

**技术支持**：新道科技股份有限公司提供“新道数智企业经营管理沙盘平台”作为竞赛平台[citation:2][citation:9]。

## 二、竞赛内容与形式

### 2.1 竞赛内容

本赛项通过还原真实的企业数智化转型改造应用场景，体现完整任务，主要考察选手对于企业经营管理应用的综合技能，突出应变能力[citation:4][citation:9]。

| 岗位角色 | 主要职责 |
|:---:|:---|
| **营销总监** | 市场调查与分析、营销数字化、市场开拓 |
| **财务总监** | 财务数字化、资金管理、成本控制、财务分析 |
| **生产总监** | 生产智能化、产能规划、生产排程 |
| **人力总监** | 人力资源管理智能化、人员招聘、绩效考核 |

### 2.2 竞赛方式

| 项目 | 具体要求 |
|:---:|:---|
| **组队要求** | 每支参赛队由4名参赛选手组成（人力总监、财务总监、营销总监、生产总监），每队指定1-2名指导教师[citation:2][citation:4][citation:9] |
| **跨校限制** | 以院校为单位组队参赛，不得跨校组队[citation:4][citation:9] |
| **学校名额** | 每所学校报名参赛队伍不超过2支[citation:4][citation:9] |
| **平台要求** | 采用“新道数智企业经营管理沙盘平台”[citation:2][citation:4][citation:9] |

### 2.3 竞赛能力要求

| 能力维度 | 具体要求 |
|:---:|:---|
| **数字化战略** | 制定企业数字化发展战略的能力 |
| **数字化思维** | 运用数字技术解决管理问题的思维方式 |
| **数字化执行** | 将数字方案转化为实际经营行动的能力 |
| **数字化创新** | 在数字化转型中提出创新方案的能力 |

竞赛中，参赛选手通过处理数智企业创业经营中常出现的各种典型问题，提升其团队协作能力、财务数据分析能力、计划预算能力、变化应对能力；学会依据数据驱动决策，使用数字化的、智能化的手段解决问题的临场决策能力与职业素养[citation:2][citation:4][citation:9]。

## 五、竞赛形式与赛程安排

### 5.1 三级赛制

竞赛采用“校赛—省赛—国赛”三级赛制[citation:2][citation:4][citation:9]：

| 竞赛阶段 | 时间安排 | 主要内容 |
|:---:|:---:|:---|
| **校赛** | 3月-5月 | 校内选拔，推荐优秀队伍参加省赛 |
| **省赛** | 5月-6月 | 各赛区组织评审，选拔队伍晋级国赛 |
| **国赛** | 10月-11月 | 全国总决赛，确定最终奖项 |

### 5.2 竞赛日程（参考2025年）

| 阶段 | 时间节点 | 事项 |
|:---:|:---:|:---|
| **报名** | 5月中旬前 | 各高校组织校内报名[citation:2] |
| **校内选拔** | 5月下旬 | 校内赛决赛[citation:4] |
| **省赛** | 6月下旬 | 省级总决赛[citation:4][citation:9] |
| **国赛** | 10月中旬 | 全国总决赛[citation:2] |

### 5.3 竞赛时间安排（以省赛为例）

| 活动 | 时间 | 内容 |
|:---:|:---:|:---|
| **报到** | 比赛日14:00前 | 参赛队报到 |
| **赛前说明会** | 比赛日15:00-17:00 | 规则说明、抽签 |
| **正式比赛** | 比赛日9:00-17:00 | 全天经营模拟[citation:4] |

## 六、评分标准

### 6.1 评审基本原则

| 原则 | 具体内容 |
|:---:|:---|
| **公平公正** | 本赛项评分标准制定遵循“公平、公正、公开”的原则[citation:4][citation:9] |
| **自动评分** | 应用信息化系统自动评分，无人为因素干扰[citation:4][citation:9] |
| **客观透明** | 竞赛评分采用系统按照规则自动生成方式进行[citation:4] |

### 6.2 系统评分指标

数智沙盘赛道采用BizSand数智商业经营模拟软件，从系统第3年（Y3Q1）开始模拟，采用2年8期赛制，在系统第16期（Y4Q4）后根据系统评分所得成绩进行判定[citation:1][citation:3][citation:8]。

| 评价指标 | 说明 |
|:---:|:---|
| **第4年末所有者权益** | 企业最终资产价值，核心评价指标 |
| **占领的销售市场** | 各区域市场份额和市场占有率 |
| **营业的商店（每个）** | 开设的实体销售网点数量 |
| **累计销售额加减分** | 销售业绩的加分项 |
| **未归还基金贷款** | 未偿还贷款的扣分项 |
| **第4年末偿债能力** | 企业偿债能力评价[citation:1][citation:10] |

根据安徽信息工程学院2024年参赛经验，系统综合评价指标包括：所有占领的销售市场、第16期各区域开设的商店（每个）、各区域销售总额排名、未归还基金贷款、经营中追加股东资金等多项得分或扣分指标[citation:6]。

### 6.3 比赛规则

| 规则类型 | 具体要求 |
|:---:|:---|
| **开始期数** | 从第1期（Y3Q1）开始模拟[citation:3] |
| **赛制** | 2年8期赛制，第8期（Y4Q4）后评定成绩[citation:1][citation:3][citation:8] |
| **托管选单** | 全程务必使用托管选单，手动选单因网络卡顿导致错过选单概不负责[citation:3] |
| **竞单时间** | 不同赛区竞单时间会有10-20分钟间隔[citation:3] |
| **决策提交** | 未提交决策默认为0分无获奖资格[citation:3] |
| **分组原则** | 若一所院校报名1支以上队伍，则同一院校的队伍被分隔在不同区域进行比赛，确保公平[citation:4] |

### 6.4 同分处理规则

在所有经营年度结束后，裁判将在现场公布大赛成绩，待各参赛队确认后，由裁判对数据进行备份和保存，成绩单提交给执委会备案[citation:4]。

如总成绩相同，则按照以下顺序确定前后名次[citation:4]：

| 优先级 | 判定依据 |
|:---:|:---|
| **第一优先级** | 参赛队经营结束的权益值高低 |
| **第二优先级** | 参赛队经营结束的净利润高低 |
| **第三优先级** | 参赛队经营结束的现金高低 |

## 九、评审特点分析

1. **全自动评分系统**：本赛项最显著的特点是采用信息化系统自动评分，无人为因素干扰，确保评审的客观公正[citation:4][citation:9]。

2. **多指标综合评价**：系统从所有者权益、市场份额、商店数量、销售额、偿债能力等多个维度综合评价企业绩效，避免单一指标的片面性[citation:1][citation:6][citation:10]。

3. **过程性评价导向**：比赛采用2年8期赛制，要求参赛团队在连续8个季度的经营中做出持续优化决策，考察团队的长期规划能力和应变能力[citation:1][citation:3][citation:8]。

4. **数字化能力核心考核**：重点考核选手的数字化战略、数字化思维、数字化执行和数字化创新的技能，体现数智化转型背景下的人才培养导向[citation:2][citation:9]。

5. **真实企业场景还原**：通过还原真实的企业数智化转型改造应用场景，考察选手处理数智企业创业经营中典型问题的能力[citation:2][citation:4][citation:9]。

6. **岗位角色明确分工**：4名选手分别模拟营销总监、财务总监、生产总监、人力总监，考察团队协作能力和专业岗位胜任能力[citation:2][citation:4][citation:9]。

7. **同分处理机制完善**：设立三级优先级（权益值→净利润→现金）的同分处理规则，确保排名的精确性[citation:4]。

8. **回避机制保障公平**：同一院校的多支队伍被分隔在不同区域进行比赛，避免内部干扰[citation:4]。
