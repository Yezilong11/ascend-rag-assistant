# 全国海洋航行器设计与制作大赛 - 评分标准

**来源网址**: http://www.mycmvc.cn/
**信息整理时间**: 2026-03-15

## 一、竞赛简介

全国海洋航行器设计与制作大赛是由中国科学技术协会、工业和信息化部指导，中国船舶集团公司、中国造船工程学会主办的全国性学科竞赛[citation:1]。大赛面向全国全日制非成人教育的各类高等学校、科研院所在校生，是我国船舶与海洋工程领域内的最高层次、最大规模与覆盖面的竞赛[citation:1]。

**大赛宗旨**：崇尚科学、实践求知、锐意创新、面向海洋、服务国防[citation:1]。大赛旨在引导高校学生树立开拓创新、刻苦钻研、勇于实践、团结协作的精神，促进高校科技创新活动的蓬勃发展，培养具有创新能力的科技人才[citation:1]。

**第十四届（2025年）竞赛信息**：
- **指导单位**：中国科学技术协会、工业和信息化部
- **主办单位**：中国船舶集团公司、中国造船工程学会[citation:1]
- **国赛承办单位**：武汉理工大学[citation:3]
- **国赛时间**：2025年8月7日-10日
- **比赛地点**：武汉理工大学（余家头校区）[citation:3]

## 二、赛事类别设置

第十四届大赛共设七大类比赛项目[citation:3]：

| 类别 | 名称 | 细分类别 |
|:---:|:---|:---|
| **A类** | 创新、创意及创业（“三创”） | A1新概念创意设计、A2技术难题求解、A3前沿科技与产业发展挑战、A4科普创意设计与实践 |
| **B类** | 设计与制作 | B1水面组、B2水下组 |
| **C类** | 智慧船舶与海洋工程技术 | C1智能航行、C2模拟对岸火力支援、C3智能感知、C4智能导航 |
| **D类** | 名船名舰模型仿真制作 | — |
| **E类** | 船模竞速 | E1常规动力组、E2改装动力组 |
| **F类** | 帆船模型竞速 | F1现代帆船竞速、F2中式古帆船竞速 |
| **G类** | 海洋知识竞赛 | — |

## 三、参赛要求

### 3.1 参赛资格

| 要求类型 | 具体规定 |
|:---:|:---|
| **参赛对象** | 全国高等院校、科研院所全日制在校学生（本专科生、硕士研究生、博士研究生）[citation:1] |
| **团队组成** | 每个团队的参赛成员须为项目的实际参与成员，允许跨专业组队[citation:4] |
| **组队人数** | 各类别参赛人数限制详见大赛细则，通常不超过5人[citation:3][citation:8] |
| **指导教师** | 通常不多于2人[citation:8] |

### 3.2 作品要求

| 要求类型 | 具体规定 |
|:---:|:---|
| **原创性** | 参赛作品必须是当年7月1日前完成的原创作品，未获得过国内同级别竞赛奖励[citation:1] |
| **知识产权** | 参赛单位需对本单位参赛作品进行原创性与保密审核，提供书面证明材料[citation:1] |
| **保密要求** | 如有涉密项目，必须脱密处理后，方可参赛[citation:3][citation:6] |
| **已获奖作品** | 曾经获奖但已实质性改进并再创新的作品，经资格审查同意、公示后无异议方可参赛[citation:1] |

### 3.3 校赛参赛名额

各赛项参赛名额不限，参赛单位审核、评审本单位参赛作品，推荐适宜的作品参加区域赛[citation:3]。

### 3.4 区域赛参赛规则

- 各赛项参赛名额不限
- 参赛单位参加本省所在区域赛，若本省无区域赛，可就近自主选择参加其他省份区域赛[citation:3]
- **同一单位不得分开重复参加两个及以上区域赛**[citation:3][citation:9]

### 3.5 国赛参赛规则

国赛参赛作品由区域赛晋级产生，**不得越级报名参加国赛**[citation:3]。

## 四、竞赛形式与赛程安排

### 4.1 三级赛制

大赛采用“**校赛—区域赛（省赛）—国赛**”三级赛制[citation:3][citation:4]：

| 竞赛阶段 | 时间安排 | 主要内容 |
|:---:|:---:|:---|
| **校赛** | 6月-7月 | 各高校自行组织校内选拔，推荐优秀作品参加区域赛 |
| **区域赛（省赛）** | 6月20日-7月21日 | 各赛区组织评审，确定晋级国赛名单 |
| **国赛** | 8月7日-10日 | 全国总决赛，确定最终奖项 |

### 4.2 报名流程

| 步骤 | 具体操作 |
|:---:|:---|
| **注册登录** | 在大赛官网（https://cmvc.moocollege.com/）进行注册报名[citation:3] |
| **信息填写** | 所有参赛作品及人员信息均需按照系统要求如实填写 |
| **作品命名** | 团队名字和作品名字必须保持一致，且反映作品特色，参赛过程中不得修改[citation:3] |
| **国赛信息修改** | 晋级国赛队伍，可在报名系统中直接修改相关信息及资料，不可另行报名[citation:3] |
| **会员注册** | 参赛师生需在指定网址（https://csname.kejie.org.cn/member/）注册个人会员[citation:3] |

## 五、各类别详细评分标准

### 5.1 创新、创意及创业（A类）评分标准

#### 5.1.1 A1新概念创意设计

A类竞赛的主题为新概念船舶与海洋装备创意设计介绍和演示[citation:8]。

**比赛形式**：初赛在网上进行，决赛为现场答辩[citation:5]。采用线上答辩的形式评价[citation:8]。

**作品要求**[citation:5][citation:8]：
- 设计方案应有功能原理创新或总体布局创新
- 设计说明书一般不得超过30页，应包括设计的创新点、计算实施方案、设计图纸、技术发展途径、现实及潜在应用的可行性分析
- 参赛作品还需准备实物或三维模型和功能演示视频
- 视频制作两个版本：演示版时长≤2分钟，文件大小≤200M；正式版时长≤5分钟，文件大小≤1G

**评价要素**[citation:8]：
| 评审维度 | 评审要点 |
|:---:|:---|
| **原理独特性** | 功能原理的创新程度 |
| **布局创新性** | 总体布局的新颖性 |
| **方式新颖性** | 实现方式的独创性 |
| **要素集成性** | 多技术融合的完整性 |
| **方案可行性** | 技术路线的可实现性 |

**比赛流程**[citation:5]：
- **预选阶段**：提交电子版设计说明书和演示版视频，由组委会组织专家进行网评预选
- **决赛阶段**：入围作品队员进行现场答辩，现场答辩总时不超过10分钟，每支队伍的作品阐述时间不超过5分钟

### 5.2 设计与制作（B类）评分标准

B类竞赛分水面组（B1）与水下组（B2）两个组别分别进行比赛[citation:8]。

**作品要求**[citation:8]：
- 参赛者须自主设计一种海洋航行器并制作作品参赛
- 设计制作说明书一般不得超过30页
- 演示视频时长一般不得超过5分钟

**功能演示要求**[citation:8]：
- **水面组（B1）**：功能演示不提倡只表现航行性能，应侧重展示各项作业功能，且不得目视直接操作，可采用自主控制、背对模型或异地等方式操作
- **水下组（B2）**：功能演示须首先具备可以入水下潜的基本能力，允许目视直接操作

**制作要求**[citation:8]：
- 制作方式不做限制，鼓励参赛学生自主手工制作
- 系统遥控使用的无线电频率应符合作品所在地区管理规定

**评审形式**：采用线上答辩的形式评价[citation:8]。

### 5.3 名船名舰模型仿真制作（D类）评分标准

**比赛形式**：参赛者自行设计制作指定船型的仿真模型，完成后将实物模型+作品说明书提交，由专家组进行现场评比[citation:10]。

**匿名要求**：名船名舰外观模型仿真制作类海报**不得出现参赛单位信息**[citation:3]。

**提交要求**：
- 提交制作宣传海报的电子版（规格60cm×160cm）[citation:6]
- 需提交实物模型至比赛现场

### 5.4 前沿科技与产业发展挑战（T类）评分标准

T类竞赛瞄准海洋防务、船海产业发展需要，以创新性思维提出科研项目设想或产品、产业构想，设计方案，能够实现目标[citation:8]。

**方向范围**[citation:8]：
- 防务装备技术（关注无人平台、智能传感、大数据、云计算的创新和应用）
- 船海产业装备技术（关注技术经济、安全智能、绿色环保优化升级，关注深远海、极地等方向）
- 应用产业装备技术（关注能源装备、应急装备、电子信息装备、新型材料、环保装备、基础设施建设与工程装备）

**参赛限制**：已在政府和军队渠道得到过支持的项目不得参赛[citation:8]。

**评审方式**：通过函评的方式评审[citation:8]。

**评价要素**[citation:8]：
| 评审维度 | 评审要点 |
|:---:|:---|
| **创新性** | 技术理念的原创程度 |
| **引领性和示范性** | 对行业发展的带动作用 |
| **可行性** | 技术路线的可实现程度 |
| **应用前景** | 产业化潜力和社会价值 |

**奖励政策**[citation:8]：
- 全国竞赛优胜者将获得证书
- 有机会与中船集团相关成员单位开展科研或产业合作
- 高校学生纳入中船集团人才储备计划

### 5.5 其他类别评分说明

**C类（智慧船舶与海洋工程技术）**：智能航行、模拟对岸火力支援等赛项，根据竞赛规则进行实航比赛或功能演示[citation:3]。

**E类（船模竞速）**：常规动力组和改装动力组，根据航行速度和时间评定成绩[citation:3]。

**F类（帆船模型竞速）**：现代帆船竞速和中式古帆船竞速，根据竞速成绩评定[citation:3]。

**G类（海洋知识竞赛）**：采用公开题库，根据答题成绩评定[citation:3][citation:4]。

## 六、校赛评审标准（参考）

### 6.1 上海海事大学校赛标准（2020）

根据上海海事大学2020年校内选拔赛通知，校赛参照全国大赛评分细则进行评审[citation:8]。

**评审形式**：各项目根据类别不同，采用线上答辩或函评形式。

**奖励办法**：每组竞赛设一等奖、二等奖、三等奖，授予奖金及证书。每类排名靠前的队伍将推荐至全国竞赛[citation:8]。

### 6.2 上海海洋大学校赛标准（2022）

上海海洋大学校赛主要采用**函评形式**进行评审[citation:4]。

**晋级规则**：校赛晋级后的作品方可参加区域赛报名，国赛参赛作品由区域赛晋级推荐，各参赛项目不得直接报名参加区域赛及国赛[citation:4]。

## 七、区域赛与国赛评审机制

### 7.1 区域赛评审

区域赛采用答辩方式进行评审，以线下答辩为主，如有特殊情况可申请线上答辩[citation:9]。

**提交材料要求**[citation:9]：
- **A、B、C、Q、T、S类**：每件一式六份完整纸质版参赛作品说明书，其中一份需有各参赛队员完整签名及学校盖章；同时提交200字以内并附两张图片的参赛作品简介
- **C、D、E、F类**：每件一份完整纸质版参赛作品说明书
- **电子版资料**：作品说明书、简介、PPT、视频

### 7.2 国赛评审

国赛采用线下比赛形式，如遇特殊情况，比赛形式调整[citation:3]。

**提交材料要求**[citation:3]：
- 盖有学校公章的参赛作品报名汇总表一份
- A1、A2、A3、B1、B2、C3类：每件一式六份完整纸质版参赛作品说明书（其中一份需有各参赛队员完整签名及学校/学院盖章）
- C1、C2、C4、D、E、F类：每件一份完整纸质版参赛作品说明书
- A（A4除外）、B、C类：同时提交200字以内并附两张图片的参赛作品简介
- 电子版资料：作品说明书、简介、PPT、视频

### 7.3 异议处理机制

对通过初评的参赛作品在指定网站上公示（公示期一个月）。在现场比赛前收到实名异议时，组委会秘书处负责调查和异议处理，处理结果报组委会批准。组委会保护异议人的合法权益[citation:1]。

## 九、评审特点分析

1. **七大类分类评价**：大赛设A-G七大类比赛项目，每类项目根据其特点采用不同的评审方式。创意设计类（A）采用现场答辩，设计与制作类（B）强调实物演示，智能航行类（C）注重实航竞赛，形成“创意-设计-制作-竞技”的完整评价体系。

2. **三级递进评审机制**：校赛→区域赛→国赛层层递进。校赛由各高校自行组织，区域赛选拔晋级国赛作品，国赛不得越级报名，确保优秀作品脱颖而出[citation:3]。

3. **多维度综合评分**：创意设计类作品从原理独特性、布局创新型、方式新颖性、要素集成性和方案可行性五个维度综合评价[citation:8]；实物制作类作品分材料审查、实物演示和现场答辩三部分进行[citation:1]。

4. **严格的匿名评审**：名船名舰外观模型仿真制作类海报不得出现参赛单位信息[citation:3]，确保评审公平公正。

5. **功能演示明确规范**：水面组功能演示侧重作业功能，不得目视直接操作；水下组须具备下潜能力，允许目视操作[citation:8]。不同组别设置差异化评价标准。

6. **原创性与保密审查**：参赛单位需对本单位参赛作品进行原创性与保密审核，提供书面证明材料；涉密项目必须脱密处理方可参赛[citation:1][citation:3]。

7. **产学研结合导向**：T类前沿科技与产业发展挑战赛优胜者有机会与中船集团相关成员单位开展科研或产业合作，高校学生纳入中船集团人才储备计划[citation:8]。

8. **视频材料双版本要求**：创意设计类需提交两个版本视频——演示版（≤2分钟）用于网评筛选，正式版（≤5分钟）用于决赛展示[citation:5]，兼顾评审效率和作品完整性。


**注意**：以上评审规则综合参考了全国海洋航行器设计与制作大赛官网、中国造船工程学会官方通知及多所高校校赛通知。每届竞赛的具体评分细则以当届发布的官方通知为准，各赛项评分标准可能存在差异，请以官网公布的最新版本为准。
