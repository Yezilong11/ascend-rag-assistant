# 全国航空航天模型锦标赛竞赛规则

## 一、竞赛简介

全国航空航天模型锦标赛是由国家体育总局航空无线电模型运动管理中心、中国航空运动协会主办的全国性航空航天模型专项赛事。该赛事是我国航空模型领域最具权威性和专业性的国家级赛事之一，旨在推动我国航空航天模型运动的发展，提高青少年科技素质，培养航空后备人才，丰富群众业余文化生活。

2026年全国航空航天模型锦标赛包含多个分项赛事，分别在不同时间段、不同地点举办，涵盖无人机项目、航天项目、自由飞项目、室内项目、室外项目等多个竞赛类别[citation:7]。

## 二、组织机构

### 1. 主办与指导单位

- **主办单位**：国家体育总局航空无线电模型运动管理中心、中国航空运动协会[citation:2][citation:4]
- **指导单位**：国家体育总局
- **规则制定机构**：中国航空运动协会航空航天模型委员会[citation:1]

### 2. 组织架构

| 机构 | 职责 |
|------|------|
| **体育总局航管中心** | 负责赛事整体规划、申办审批、监督管理 |
| **中国航空运动协会** | 负责制定竞赛规则、选派裁判、技术指导 |
| **各赛事组委会** | 由承办单位组建，负责具体赛事组织工作 |
| **裁判组** | 按照竞赛规则执行裁判工作[citation:2] |

### 3. 竞赛规则依据

中国航空运动协会于2026年2月正式发布《航空航天模型及无人机运动竞赛规则（2025版）》，该规则作为全国各级航空航天模型及无人机运动竞赛活动的重要依据，为广大运动员、教练员、裁判员及相关从业人员提供标准化、规范化的技术准则[citation:3][citation:1]。

《航空航天模型及无人机运动竞赛规则》由西北工业大学出版社出版，是全国航空航天模型和无人机运动竞赛活动的准则，有助于我国航空运动进一步规范化、体系化发展[citation:1][citation:6]。

## 三、赛事体系

### 1. 2026年全国航空航天模型锦标赛系列赛事

根据国家体育总局航管中心发布的申办公告，2026年全国航空航天模型锦标赛包含以下分项赛事[citation:7]：

| 赛事名称 | 赛事规模 | 赛期 | 举办时间 |
|----------|----------|------|----------|
| 全国青少年航空航天模型锦标赛 | 约2000人 | 8天 | 2026年7月—8月[citation:2] |
| 全国航空航天模型（无人机项目）锦标赛 | 约150人 | 4天 | 2026年6月—9月[citation:4][citation:5] |
| 全国航空航天模型（航天、自由飞项目）锦标赛 | 待定 | 待定 | 2026年[citation:7] |
| 全国航空航天模型（室内项目）锦标赛 | 待定 | 待定 | 2026年[citation:7] |
| 全国航空航天模型（室外项目）锦标赛 | 待定 | 待定 | 2026年[citation:7] |

### 2. 相关赛事

除锦标赛外，2026年还将举办[citation:7]：
- 全国航空模型公开赛（分站赛）
- 中国国际飞行器设计挑战赛（分站赛及总决赛）
- 全国纸飞机嘉年华暨“放飞梦想”全国青少年纸飞机通讯赛总决赛
- 全国青少年无人机创新教育竞赛活动总决赛
- “飞向北京•飞向太空”全国青少年航空航天模型教育竞赛

## 四、参赛资格与要求

### 1. 参赛对象

| 赛事 | 参赛对象要求 |
|------|--------------|
| 全国青少年航空航天模型锦标赛 | 全国青少年航空航天模型爱好者，具体年龄要求见各年度竞赛规程[citation:2] |
| 全国航空航天模型（无人机项目）锦标赛 | 全国航空航天模型及无人机运动爱好者[citation:4] |

### 2. 组队方式

- 以省、自治区、直辖市、计划单列市、新疆生产建设兵团体育主管部门组队参赛
- 中国航空运动协会的团体会员单位可组队参赛
- 经审核批准的基层单位可组队参赛

### 3. 参赛资格审定

- 参赛运动员须符合各分项赛事规定的年龄要求
- 参赛运动员须持有有效的人身意外伤害保险证明
- 参赛单位须签署参赛承诺书，保证遵守竞赛规则和赛场纪律

## 五、竞赛项目与规则

### 1. 竞赛项目分类

根据《航空航天模型及无人机运动竞赛规则（2025版）》，竞赛项目主要包括以下类别[citation:3]：

| 类别 | 说明 |
|------|------|
| 自由飞类模型 | 包括牵引模型滑翔机、橡筋模型飞机、内燃机模型飞机等 |
| 线操纵类模型 | 包括线操纵特技模型飞机、线操纵竞速模型飞机等 |
| 无线电遥控类模型 | 包括遥控特技模型飞机、遥控滑翔机、遥控直升机等 |
| 无人机类项目 | 包括无人机竞速、无人机任务飞行、无人机足球等 |
| 航天模型类 | 包括模型火箭、航天器模型等 |
| 室内模型类 | 包括室内橡筋模型飞机、室内遥控模型飞机等 |
| 仿真模型类 | 包括仿真飞机模型、静态展示模型等 |

### 2. 竞赛规则依据

具体竞赛项目的技术规则、评分标准、场地要求等，严格按照《航空航天模型及无人机运动竞赛规则（2025版）》执行[citation:3]。该规则由中国航空运动协会邀请行业专家系统整编，内容全面、体量大、质量高，涵盖航空航天模型及无人机运动的各项技术规范[citation:6]。

### 3. 场地与器材要求

| 项目 | 要求 |
|------|------|
| **场地要求** | 符合国标GB 19079.26-2013相关内容[citation:2][citation:4] |
| **器材要求** | 按照竞赛规则执行，由裁判组在赛前提交给承办单位[citation:2] |
| **设备设施** | 需提供与活动人数相适应的场地器材、办公用品等[citation:4] |

## 六、赛制流程

### 1. 赛事申办阶段

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| 申办公告发布 | 2025年10月 | 国家体育总局航管中心发布下一年度赛事申办公告[citation:2][citation:4] |
| 申办材料提交 | 2025年11月20日前 | 意向承办单位提交申办材料[citation:2][citation:5] |
| 承办单位审核 | 申办截止后 | 专家工作组对申办单位进行审核评估[citation:4] |
| 承办单位公示 | 审核通过后 | 公示3个工作日[citation:2][citation:4] |
| 签订协议 | 公示结束后 | 签订赛事承办及协办合作协议[citation:5] |

### 2. 赛事举办阶段

| 赛事 | 预计举办时间 | 赛期 | 规模 |
|------|--------------|------|------|
| 全国青少年航空航天模型锦标赛 | 2026年7月—8月 | 8天 | 约2000人[citation:2] |
| 全国航空航天模型（无人机项目）锦标赛 | 2026年6月—9月 | 4天 | 约150人[citation:4][citation:5] |

### 3. 竞赛组织要求

承办单位需提交以下材料，经审核通过后方可举办赛事[citation:4][citation:5]：
- 赛事组织方案
- 安全保卫方案
- 应急预案
- 熔断方案
- 活动宣传方案
- 媒体宣传计划
- 公益活动计划（可选）

## 七、评审标准

### 1. 竞赛成绩评定

各类项目的竞赛成绩评定严格按照《航空航天模型及无人机运动竞赛规则（2025版）》执行[citation:3]。不同项目类别采用不同的评分标准：

| 项目类别 | 评审维度 |
|----------|----------|
| **竞速类项目** | 完成规定任务的时间，用时短者名次列前 |
| **特技类项目** | 动作完成质量、难度系数、编排创意、表演效果 |
| **任务飞行类** | 任务完成度、完成时间、精准度 |
| **仿真模型类** | 仿真度、制作工艺、细节还原程度 |
| **航天模型类** | 飞行高度、回收效果、任务完成情况 |

### 2. 裁判组织

- 裁判组按照竞赛规则执行裁判工作[citation:2]
- 根据赛事规模提供相应裁判和工作人员[citation:5]
- 裁判员须持有中国航空运动协会颁发的相应等级裁判证书
