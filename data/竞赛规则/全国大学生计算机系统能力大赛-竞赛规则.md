# 全国大学生计算机系统能力大赛竞赛规则

## 一、竞赛简介

全国大学生计算机系统能力大赛（以下简称“大赛”）是由系统能力培养研究专家组发起、由全国高校计算机教育研究会和系统能力培养研究项目发起高校主办、面向高校大学生的全国性大赛[citation:1]。大赛目标是以学科竞赛推动专业建设和计算机领域创新人才培养体系改革，培育我国高端芯片、关键基础软件的后备人才[citation:1]。

大赛鼓励学生设计、实现综合性的计算机系统，培养系统级的设计、分析、优化与应用能力，提升学生的技术创新、工程实践、团队协作能力[citation:1]。大赛服务国家人才培养战略，以赛促学、以赛促教，为高水平计算机人才成长搭建交流、展示、合作的开放平台[citation:1]。

第十届大赛于2026年举办，包含多个赛项，如CPU设计赛、操作系统设计赛、编译系统设计赛、数据库管理系统设计赛等。

## 二、组织机构

### 1. 主办单位

- **主办单位**：全国高校计算机教育研究会、系统能力培养研究项目发起高校
- **发起单位**：系统能力培养研究专家组
- **承办单位**：各赛项承办高校（详见各赛项通知）

### 2. 竞赛官网与联系方式

- **大赛官方网站**：https://compiler.educg.net/ 
- **各高校校内联系方式**：详见各校通知

## 三、赛项设置

第十届全国大学生计算机系统能力大赛设置多个赛项，各赛项独立进行比赛和评奖：

| 赛项 | 说明 |
|------|------|
| **CPU设计赛（龙芯杯）** | 以CPU设计为核心，培养学生计算机系统设计能力 |
| **操作系统设计赛** | 操作系统内核设计与实现 |
| **编译系统设计赛** | 编译器设计与实现 |
| **数据库管理系统设计赛** | 数据库系统核心功能设计与实现 |

## 五、CPU设计赛（龙芯杯）竞赛规则

### 1. 竞赛内容

CPU设计赛以计算机各硬件课程为理论基础，学生综合运用所学计算机硬件知识来完成基于32位精简指令集架构的模型计算机的逻辑设计，通过系统仿真，设计至少包含38条指令，并编程验证[citation:2]。

大赛鼓励各参赛队综合运用各种知识并充分利用FPGA实验板硬件资源以尽可能拓展模型机的功能和提高模型机运行性能，包括但不局限于[citation:2]：

| 扩展方向 | 说明 |
|------|------|
| **处理器结构扩展** | 处理器采用流水线结构、精确异常中断、乘除法指令、原子指令等扩展 |
| **外设扩展** | 使用尽可能多的外设，如按键或键盘输入、数码管输出、VGA或LCD显示等 |
| **总线扩展** | 使用标准总线，如UART、AXI4等总线，使模型机有较好的扩展性 |
| **编译支持** | 完成高级语言到机器语言的垂直编译，方便使用模型机做应用开发 |
| **应用开发** | 较复杂的应用开发，如使用模型机进行图形图像处理、数字信号处理、人工智能等 |

### 2. 作品提交要求

各参赛队初赛阶段需要提交完整的设计内容[citation:2]：

| 材料名称 | 要求说明 |
|------|------|
| **完整工程文件** | 基于32位精简指令集架构模型机设计的完整工程文件，必须包含全部源代码、仿真波形、FPGA二进制下载文件 |
| **设计报告** | 基于32位精简指令集架构模型机设计报告。如果决赛阶段的硬件设计与初赛阶段的硬件设计有任何不同，均需再次提交完整的设计内容 |
| **第三方IP说明** | 如果需要使用第三方IP或者借鉴他人的部分源码，必须在设计报告中予以明确说明[citation:2] |

### 3. 原创性要求

- 大赛期间参赛队员可以使用各种图书资料、计算机和软件，在国际互联网上浏览，但不得剽窃、抄袭他人作品[citation:2]
- 对作弊参赛队将取消参赛资格，并予通报批评[citation:2]

## 六、数据库管理系统设计赛竞赛规则

### 1. 竞赛内容

竞赛内容涉及综合运用各种知识（包括但不局限于数据库系统原理与实现、编译原理、数据结构与算法、操作系统等），具备将上述知识用于设计、实现和优化数据库系统基本的存取管理、查询处理、事务处理三大核心功能的能力[citation:1]。

### 2. 参赛要求

| 项目 | 要求 |
|------|------|
| **设备要求** | 每位参赛队员使用一台计算机 |
| **软件平台** | 竞赛使用的软件平台将在竞赛命题组确定后公布[citation:1] |

## 七、赛制流程

大赛采用校级选拔赛、全国赛两级赛制。

### 1. 第十届时间安排

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **校内选拔赛报名** | 2026年3月上旬截止 | 各高校自行组织 |
| **校内选拔赛** | 2026年3月—4月 | 各高校自行组织 |
| **全国赛报名** | 详见官网通知 | - |
| **全国总决赛** | 详见官网通知 | - |

### 2. 各高校校内报名截止时间参考

| 高校 | 赛项 | 校内报名截止时间 |
|------|------|------------------|
| 西安工业大学 | 数据库管理系统设计赛 | 2026年3月13日中午12:00[citation:1] |
| 西安邮电大学 | CPU设计赛（龙芯杯） | 2026年3月13日[citation:2] |

### 3. 各阶段比赛形式

#### （1）校级选拔赛（以西安邮电大学CPU设计赛为例）

| 环节 | 说明 |
|------|------|
| **预赛** | 参赛队按照大赛技术方案要求在大赛网站提交作品设计方案。评审专家根据评测系统对预赛作品打分对各参赛队进行排序，并按分数高低决定入围决赛的参赛队[citation:2] |
| **决赛** | 参赛团队全部人员必须按组委会通知按时报到，由大赛组委会组织决赛，采用功能测试、系统展示、实现自定义指令、答辩4个环节。评审专家综合打分，并按分数高低决定奖项归属[citation:2] |

#### （2）全国总决赛
- 各赛项分别举行
- 入围队伍进行现场展示和答辩
- 评审专家现场评审，评选出全国一等奖、二等奖、三等奖

| 评审维度 | 说明 |

| **应用开发** | 应用开发的复杂度和创新性 |
| **答辩表现** | 现场陈述和答辩表现 |

### 2. 数据库管理系统设计赛评审维度

| 评审维度 | 说明 |
|------|------|
| **功能实现** | 存取管理、查询处理、事务处理三大核心功能实现 |
| **性能优化** | 系统性能优化程度 |
| **技术创新** | 技术创新点 |
| **文档规范** | 设计文档的完整性和规范性 |

## 十、报名方式

### 1. 通用报名流程

1. **校内组队**：按赛项要求组队，确定指导教师和队长
2. **加入校赛QQ群**：加入各校竞赛QQ群，获取后续通知
3. **校内报名**：按各校要求完成校内报名（加入QQ群报名或在线填写报名表）
4. **参加校赛**：通过校内选拔赛后获得国赛参赛资格
5. **官网报名**：登录大赛官网进行注册报名

### 2. 报名注意事项

- **报名截止时间**：各校不同，请关注本校具体通知
- **实名要求**：加入QQ群需实名申请
- **作品提交**：按各赛项要求提交作品设计方案
