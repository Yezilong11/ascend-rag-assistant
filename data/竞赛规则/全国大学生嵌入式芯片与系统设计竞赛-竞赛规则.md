# 全国大学生嵌入式芯片与系统设计竞赛竞赛规则

## 一、竞赛简介

全国大学生嵌入式芯片与系统设计竞赛是由中国电子学会主办，国内外高校电子电气类相关专业全日制在校学生广泛参与的全国性学科竞赛[citation:2]。大赛旨在提高全国高校学生在嵌入式芯片及系统设计领域和可编程逻辑器件应用领域的自主创新设计与工程实践能力，培养具有创新思维、具备解决复杂工程问题能力且拥有团队合作精神的优秀人才，在活跃校园创新创业学术氛围的同时，推进高校与企业人才培养合作共建[citation:1][citation:10]。

本赛事已入选中国高等教育学会《全国普通高校大学生竞赛分析报告》竞赛目录，是教育部官方认可的全国性A类大学生赛事之一[citation:2][citation:5]。大赛以“创意发挥、规范设计、突破自我、快乐大赛”为原则[citation:2][citation:6]，第九届（2026）竞赛口号为“**AI赋能设计，设计点亮AI!（AI for Design & Design for AI!）**”[citation:1][citation:8][citation:10]。

## 二、组织机构

- **主办单位**：中国电子学会[citation:2]
- **大赛组委会**：设立组织委员会，组委会下设秘书处和专家组，负责大赛的整体组织与评审工作[citation:2]
- **大赛官网**：http://www.socchina.net/ [citation:1][citation:2][citation:4]

## 三、赛道设置

第九届（2026）全国大学生嵌入式芯片与系统设计竞赛设三个赛道[citation:1][citation:2][citation:4]：

| 赛道 | 名称 | 竞赛方式 | 适合专业 |
|------|------|----------|----------|
| **赛道一** | 芯片应用赛道 | 开放式自主设计 | 电子、信息、计算机、自动化、电气、仪科等[citation:1][citation:4][citation:8] |
| **赛道二** | 芯片设计赛道 | 自主选题设计 | 集成电路、电子科学技术、信息、计算机、自动化等[citation:4][citation:9] |
| **赛道三** | FPGA创新设计赛道 | 自主选题设计 | 电子、信息、计算机、自动化、电气、仪科、生医等[citation:4][citation:9] |

各赛道单独进行评审与评奖。芯片应用赛道每年3月—8月举办，芯片设计赛道每年6月—12月举办，FPGA创新设计赛道每年8月—12月举办[citation:2]。

## 四、参赛资格与要求

### 1. 参赛对象

- **学历要求**：国内外高校电子电气类相关专业（电子、信息、计算机、自动化、电气、仪科等）全日制在校研究生、本科生、高职高专生均可参赛[citation:1][citation:4][citation:8]
- **专业范围**：包括但不限于电子信息、通信工程、测控技术与仪器、微电子科学与技术、自动化、自动控制、机器人、软件工程等专业[citation:7]

### 2. 组别设置

根据参赛学生学籍，大赛分三个组别[citation:1][citation:4][citation:5]：

| 组别 | 认定标准 |
|------|----------|
| **研究生组** | 参赛队员中只要有一名研究生即为研究生组 |
| **本科组** | 全体参赛队员为本科学籍 |
| **高职高专组** | 全体参赛队员为高职高专学籍（含职业本科） |

参赛队员身份以报名截止日身份为准[citation:1][citation:5][citation:8]。

### 3. 团队组成

| 赛道 | 队伍人数 | 指导教师 | 组队范围 |
|------|----------|----------|----------|
| 芯片应用赛道 | 1-3人 | 不超过2名 | 同一所学校[citation:1][citation:4][citation:5] |
| FPGA创新设计赛道 | 不超过3人 | 不超过2名 | 同一所学校[citation:9] |
| 芯片设计赛道 | 不超过6人 | 不超过2名 | 可跨校组队[citation:9] |

**通用要求**[citation:4][citation:5][citation:9]：
- 每位同学仅限参与1支队伍
- 组建队伍时，仅队长账号具备提交报名和作品等操作权限
- 由队长确认指导老师和队员顺序及名称准确，获奖证书将严格按照组队顺序制作

### 4. 参赛资格审定

参赛队伍报名后，参赛学校联络人或组委会将进行报名信息审核。组委会将根据参赛队伍信息提交完整度、项目创新性、科学性、工程可行性、设计难度以及平台适用度等因素进行参赛资格审定[citation:4][citation:9]。

**重要提示**：多所高校明确规定，不参加校内选拔赛直接官网报名者，学校不予认定参赛成绩[citation:5][citation:7]。

## 五、赛区划分

为方便大赛活动，根据地域设立六个分赛区[citation:1][citation:4][citation:9]：

| 赛区 | 所辖省份 |
|------|----------|
| **东部赛区** | 江苏、浙江、山东、上海 |
| **西南赛区** | 四川、重庆、云南、贵州、西藏 |
| **西北赛区** | 陕西、甘肃、宁夏、新疆、青海 |
| **南部赛区** | 广西、广东、海南、福建、香港、澳门、台湾 |
| **北部赛区** | 北京、天津、河北、内蒙古、山西、黑龙江、吉林、辽宁 |
| **中部赛区** | 湖北、湖南、江西、河南、安徽 |

海外院校参赛委托南部赛区代为组织与评审[citation:1][citation:4][citation:9]。

## 六、赛制流程

大赛分校级选拔赛（校赛）、分赛区初赛、分赛区复赛、全国总决赛四级赛制。

### 1. 时间安排（第九届芯片应用赛道）

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **校内选拔赛** | 2026年3月—4月 | 各高校自行组织，截止时间多为4月上中旬 |
| **官网报名截止** | 2026年4月20日 | 在大赛官网完成注册与报名[citation:1][citation:4][citation:5] |
| **作品提交截止** | 2026年7月上旬 | 提交设计报告、作品视频等材料[citation:1][citation:4][citation:5] |
| **分赛区初赛** | 2026年7月中旬 | 线上评审，确定入围复赛名单[citation:4][citation:10] |
| **分赛区复赛** | 2026年7月下旬 | 线下评审（原则上），确定入围总决赛名单[citation:4][citation:10] |
| **全国总决赛** | 2026年8月中旬 | 线下现场评审，含能力测评环节[citation:4][citation:10] |

### 2. 各阶段比赛形式

#### （1）校级选拔赛
- 由各高校自行组织，形式多为作品评审或现场答辩
- 校赛奖项：设一、二、三等奖，优秀作品推荐参加分赛区竞赛
- 多所高校明确规定：必须先参加校内选拔赛，否则不予认定参赛成绩[citation:5][citation:7]

#### （2）分赛区初赛（线上）
- 获得参赛资格的队伍完成作品后，由队长账号提交设计报告及作品视频等内容[citation:4][citation:9]
- 评审专家组重点针对参赛作品合格性进行线上初筛，针对作品完成度和技术要求进行初赛评审[citation:4]
- 根据专家组评审意见确定入围分赛区复赛的名单，在大赛网站公示不少于3天[citation:4][citation:9]

#### （3）分赛区复赛（线下）
- 如无特殊原因采用线下评审方式，流程详见各分赛区复赛通知[citation:4][citation:9]
- 评审流程包括作品介绍及演示、质询与答辩等环节
- 根据参赛作品的完成度、创新性、难度、系统功能与指标，以及答辩状况进行评奖[citation:4][citation:9]
- 晋级全国总决赛名单在大赛网站公示不少于3天[citation:4][citation:9]

#### （4）全国总决赛（线下）
- 评审流程包括作品介绍及演示、质询与答辩等环节[citation:4][citation:9]
- 为保证大赛公平公正，总决赛评审期间将安排能力测评，测评细则后续发布[citation:4][citation:9]
- 专家组根据参赛作品的完成度、创新性、难度、系统功能与指标及答辩状况进行评奖[citation:4][citation:9]
- 获奖名单在大赛网站公示，公示期为3—7天[citation:4][citation:9]

### 3. 芯片设计赛道与FPGA创新设计赛道赛制

**芯片设计赛道**[citation:9]：
- 分为初赛、全国总决赛两阶段
- 每支参赛队由不多于6名学生组成，可跨校组队
- 基于组委会指定要求，由参赛队自主选题完成相关芯片的设计与验证

**FPGA创新设计赛道**[citation:9]：
- 分为初赛、全国总决赛两阶段
- 每支参赛队不超过3人，每队不超过2名指导老师
- 决赛评审期间将安排FPGA基础编程设计能力考核

## 七、作品要求

### 1. 作品内容要求

参赛队采用赛题指定的开发平台为核心，根据选题指南自由选择赛题，开放式自主设计并完成参赛作品。在充分发挥核心平台功能和性能的基础上，允许自行设计扩展电路构成完整的应用系统[citation:1][citation:6][citation:8]。

关于大赛平台的技术细节及获取方式，详见大赛官网协办企业选题指南[citation:1][citation:5][citation:8]。

### 2. 提交材料要求

| 材料名称 | 要求说明 |
|----------|----------|
| **作品报名表** | 在大赛官网填写提交[citation:5] |
| **作品设计报告** | PDF格式，50M以内，按模板要求撰写[citation:5] |
| **作品演示视频** | MP4格式，编码为AVC(H264)，3分钟内，600M以内；重点放在作品演示上，切忌仅为PPT讲解过程[citation:5] |
| **作品相关照片** | 包括作品全局和开发板高清特写[citation:5] |

### 3. 原创性要求

- 参赛作品必须为团队原创，不得抄袭、剽窃他人成果
- 已有相关作品也能参赛，但须有实质性创新和改进[citation:7]
- 所有材料须真实有效，不得弄虚作假

## 八、评审标准

### 1. 评审维度

| 评审维度 | 说明 |
|----------|------|
| **完成度** | 作品是否按要求完整实现预定功能 |
| **创新性** | 作品的创意和创新程度 |
| **难度** | 技术实现的复杂程度和技术难度 |
| **系统功能与指标** | 作品的功能完整性和性能指标达成情况 |
| **答辩表现** | 现场演示、质询与答辩的应变能力[citation:4][citation:9] |

### 2. 成绩构成（参考）

- 初赛：重点针对作品完成度和技术要求进行评审[citation:4]
- 复赛/总决赛：根据作品的完成度、创新性、难度、系统功能与指标，以及答辩状况进行综合评奖[citation:4][citation:9]
