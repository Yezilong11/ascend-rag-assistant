# 全国大学生物联网设计竞赛竞赛规则

## 一、竞赛简介

全国大学生物联网设计竞赛（以下简称“竞赛”）是由教育部高等学校计算机类专业教学指导委员会创办，并于2020年1月并入新一届教学指导委员会后，由全国高等学校计算机教育研究会主办的一项物联网学科领域唯一的学科竞赛。竞赛以促进国内物联网相关专业建设和人才培养为目标，以物联网技术为核心，激发大学生的创新精神和创业能力，推动物联网技术在相关领域的应用与发展。

本竞赛已入选中国高等教育学会发布的《全国普通高校大学生竞赛排行榜》，是教育部官方认可的全国性大学生赛事之一。竞赛以学科交叉为特色，以物联网行业技术创新为驱动，每年吸引数百所高校的近万名学生参赛，已成为国内物联网领域最具规模和影响力的学科竞赛。

第十一届（2026年）全国大学生物联网设计竞赛由全国高等学校计算机教育研究会主办，由华北、东北、华东、华中、西北、西南和港澳台分赛区及安谋科技、乐鑫信息科技等知名企业共同协办。

## 三、竞赛宗旨

1. **创新性**：鼓励参赛队伍运用物联网技术进行创新设计，解决实际问题，推动物联网技术的应用与发展
2. **实践性**：强调理论与实践相结合，通过竞赛锻炼学生的动手能力和团队协作精神
3. **公平性**：坚持公平、公正、公开的原则，为所有参赛队伍提供平等的展示平台
4. **开放性**：面向全国高校，不限专业，鼓励跨学科组队，激发学生的创新潜能

## 四、参赛资格与要求

### 1. 参赛对象

- **学历要求**：普通高校全日制在校学生（本科、高职高专、研究生）均可参赛
- **专业范围**：不限专业，鼓励跨学科、跨专业组队

### 2. 团队组成

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每支参赛队由1-5名学生组成（建议3-5人） |
| **指导教师** | 每支参赛队指导教师不超过2名 |
| **组队范围** | 仅限校内组队，不可跨校组队参赛 |
| **参赛限制** | 每位参赛学生只能参加1支参赛队，每支参赛队只能选择1个技术方向 |
| **指导教师限制** | 每名指导教师指导的参赛队伍数量不限 |

### 3. 技术方向选择

参赛队伍须从竞赛支持的技术方向中选择一个参赛方向，并选择相应的组委会提供的平台进行作品开发：

- 安谋科技技术方向
- 乐鑫信息科技技术方向
- RT-Thread技术方向
- 广和通技术方向
- 新大陆技术方向
- 兆煊微技术方向
- 地平线技术方向
- 霍尼韦尔技术方向
- 中国移动技术方向
- 龙芯中科技术方向
- 海思技术方向
- 其他企业技术方向

### 4. 知识产权要求

- 参赛作品必须为原创，不得侵犯他人知识产权
- 竞赛支持企业有权在竞赛中使用参赛作品进行宣传和推广
- 参赛作品的知识产权归参赛队伍所有

## 五、赛制流程

竞赛分赛区预赛和全国总决赛两个阶段，华东、华北、华中、西南、西北、东北、华南七个分赛区。

### 1. 时间安排（第十一届）

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **作品提交** | 2026年6月15日前 | 提交作品设计方案 |
| **分赛区预赛** | 2026年7月 | 各分赛区进行预赛 |
| **全国总决赛** | 2026年8月 | 线下总决赛 |

### 2. 各高校校内报名时间参考

| 学校 | 校内报名截止时间 |
|------|------------------|
| 济南大学 | 2026年4月28日 |
| 安徽工业大学 | 2026年6月1日 |
| 安徽三联学院 | 2026年4月15日 |
| 广州大学 | 2026年4月25日 |

### 3. 各阶段比赛形式

#### （1）作品提交
- 在规定时间内，参赛队伍须完成组队、选择技术方向和平台
- 提交完整的作品设计方案（包括作品简介、系统架构图、软硬件设计说明、创新点说明等）
- 可选择提交作品演示视频（3分钟以内）

#### （2）分赛区预赛
- 各分赛区组织专家对提交的作品设计方案进行评审
- 评选出分赛区一、二、三等奖及入围全国总决赛的队伍
- 分赛区预赛通常采用线上评审或线下答辩相结合的方式

#### （3）全国总决赛
- 线下举行，入围队伍进行现场作品展示和答辩
- 评审专家现场评审，评选出全国总决赛一、二、三等奖
- 同期举办颁奖典礼、企业技术沙龙、获奖作品展示等交流活动

## 六、作品要求

### 1. 作品内容要求

参赛作品必须以物联网技术为核心，体现物联网的感知层、网络层、平台层、应用层的技术特点，包括但不限于以下方向：

- 智慧城市
- 智能家居
- 智能交通
- 智慧医疗
- 智慧农业
- 工业物联网
- 环境监测
- 可穿戴设备
- 边缘计算
- 人工智能与物联网融合

### 2. 作品形式要求

| 项目 | 要求 |
|------|------|
| **设计方案** | 完整的作品设计方案（Word/PDF格式） |
| **演示视频** | 可选，3分钟以内，展示作品功能和创新点 |
| **源代码** | 可选，作为评审参考 |
| **实物作品** | 进入总决赛需携带实物作品进行现场展示 |

### 3. 原创性要求

- 参赛作品必须为参赛队伍原创，不得抄袭他人作品
- 不得使用已获其他竞赛奖项的作品重复参赛
- 如使用开源代码或第三方库，须在作品中明确标注

## 七、评审标准

### 1. 评审维度

| 评审维度 | 权重 | 说明 |
|----------|------|------|
| **创新性** | 30% | 作品在技术、应用场景或商业模式上的创新程度 |
| **技术实现** | 30% | 作品的技术复杂度、完整性和实现质量 |
| **应用价值** | 20% | 作品的实际应用价值和市场前景 |
| **用户体验** | 10% | 作品的交互设计和用户体验 |
| **文档规范** | 10% | 设计方案的完整性和规范性 |

### 2. 加分项

- 使用竞赛支持企业的平台和技术进行深度开发
- 作品具有实际落地应用或与企业合作背景
- 跨学科组队，体现多专业融合创新

### 3. 评审方式

- 分赛区预赛：专家线上评审或线下答辩
- 全国总决赛：现场作品展示+答辩，专家现场评分

## 十、报名方式

### 1. 报名流程

1. **组队准备**：自由组队，确定指导教师，选择技术方向和平台
2. **官网注册**：登录竞赛官网（https://iot.sjtu.edu.cn/）进行注册报名
3. **提交作品**：在规定时间内提交作品设计方案
4. **校内备案**：按各校要求完成校内报名备案

### 2. 报名注意事项

- **报名截止时间**：以官网通知为准（通常在6月中旬）
- **实名要求**：报名信息需真实有效，包括学校、姓名、学号等
- **技术方向选择**：报名时需明确选择的技术方向和平台
