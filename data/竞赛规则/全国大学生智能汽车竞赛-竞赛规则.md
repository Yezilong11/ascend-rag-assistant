# 全国大学生智能汽车竞赛竞赛规则

## 一、竞赛简介

全国大学生智能汽车竞赛是由教育部高等学校自动化类专业教学指导委员会发起，现由中国自动化学会主办，以清华大学为秘书处单位的全国性A类学科竞赛[citation:1]。竞赛自创办以来，已成功举办二十届，覆盖全国30余个省市自治区、近500所高校，累计参赛学生超33万人次[citation:6]。

本赛事已连续多年被纳入中国高等教育学会《全国普通高校大学生竞赛分析报告》竞赛目录，被广泛认可为含金量最高、参赛价值最大的竞赛项目之一[citation:1]。竞赛以“立足培养、重在参与、鼓励探索、追求卓越”为指导思想[citation:1][citation:5]，面向全国大学生开展具有探索性的工程实践活动。

竞赛内容综合性强，涵盖了控制、模式识别、传感技术、电子、电气、计算机、机械、通信、汽车工程等多个学科知识[citation:1]，旨在激发大学生从事工程技术开发和科学研究探索的兴趣和潜能，培养大学生的综合知识运用能力、基本工程实践能力和创新意识。

第二十一届全国大学生智能汽车竞赛全国总决赛将于2026年8月举行。

## 二、组织机构

- **主办单位**：中国自动化学会、清华大学[citation:1]
- **秘书处单位**：清华大学
- **国赛承办单位**：待全国组委会正式通知
- **各分赛区承办单位**：待各赛区组委会正式通知
- **竞赛官方网站**：http://www.smartcarrace.com/ [citation:6]

## 四、参赛资格与要求

### 1. 参赛对象

- **学历要求**：全国普通高等院校全日制在校本科生、研究生、高职高专学生均可参赛[citation:3]
- **专业范围**：电子通信类、计算机类、机械类等相关理工科专业的在校大学生[citation:1]
- **组别划分**：
  - 高教组：全日制本科生及研究生[citation:3]
  - 职教组：全日制中职、高职学生[citation:3]

### 2. 团队组成

| 项目 | 要求 |
|------|------|
| **常规组别** | 每支队伍由3名学生组成，可跨专业、跨年级组队[citation:5][citation:7] |
| **创意组别（智慧救援）** | 每支队伍不超过6人（其中高教组最多1名研究生）[citation:3] |
| **指导教师** | 每支队伍指导教师不超过2人[citation:2][citation:3] |
| **组队范围** | 仅限校内组队，不得跨校组队[citation:3] |
| **参赛限制** | 每位学生只能参加1支队伍；每所学校每个竞赛组别仅可推荐1支队伍参赛[citation:6] |

### 3. 诚信与真实性要求

- 所有参赛选手报名须保证所提供的个人信息真实、准确、有效，否则取消参赛资格[citation:3]
- 参赛队伍报名成功后，不得调整和更换参赛队员[citation:3]
- 鼓励跨专业、跨学院组队，实现软件、硬件、机械合理搭配[citation:7]

## 五、赛制流程

大赛采用三级赛事体系：校级选拔赛、分赛区决赛、全国总决赛[citation:6]。

### 1. 时间安排（第二十一届）

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **校级选拔赛** | 2026年1月—4月 | 各高校自行组织，截止时间各校不同 |
| **分赛区决赛** | 2026年7月 | 全国八大赛区分别举行[citation:6] |
| **全国总决赛** | 2026年8月 | 具体地点待全国组委会通知 |

### 3. 各阶段比赛形式

#### （1）校级选拔赛
- 由各高校自行组织，形式包括基础技能测试和竞速比赛
- **基础赛**：限时编程，现场发放单片机开发板，完成LED灯、按键、数码管等基础程序开发[citation:1]
- **竞速赛**：参赛队伍自主研发具备视觉识别、路径规划与电机控制功能的智能车，以竞速完成指定赛道为核心考核目标[citation:5]
- 校赛奖项：设一、二、三等奖，获奖比例分别为10%、20%、30%左右[citation:2][citation:7]
- 晋级规则：通过校赛获得参赛资格后方可参加分赛区决赛

#### （2）分赛区决赛
- 以赛区为单位组织，由各赛区承办院校负责
- 参赛队伍按不同赛道要求完成小车软硬件功能设计、调试，在指定赛道完成竞速比赛[citation:1]
- 最终按完成时间及任务完成度综合评分，评选赛区奖项并确定晋级全国总决赛名单

#### （3）全国总决赛
- 线下举行，入围队伍进行现场竞速比赛
- 评审方式：按完成时间及任务完成度综合评分[citation:1]
- 评选出全国特等奖、一等奖、二等奖、三等奖

## 六、竞赛内容与要求

### 1. 常规竞速组别要求

参赛队伍需自主研发具备视觉识别、路径规划与电机控制功能的智能车，以竞速完成指定赛道为核心考核目标[citation:5]。各组别的具体技术要求参见《第二十一届全国大学生智能汽车竞速比赛规则》[citation:2]。

### 2. 创意组别要求（以“智慧救援”为例）

**赛题任务**[citation:3]：
- 任务一：无人机巡检——无人机从启动区起飞，巡查救援点，记录救援等级并发给智能车
- 任务二：智能车运送物资——智能车自主行驶到取货区，抓取物资并运送至装货区
- 任务三：智能车为无人机装货——智能车将物资转移至无人机搭载平台
- 任务四：救援物资投送——无人机将物资运送到救援区
- 任务五：智能车与无人机返航——任务完成后各自返航

**设备要求**[citation:3]：
- **智能车**：四轮驱动，尺寸长≤530mm、宽≤360mm、高≤250mm，加装模块自由度≤6，重量≤10KG
- **无人机**：四旋翼布局，轴距≤501mm，需自行设计物资搭载平台
- 参赛队可根据要求自主选配、组装符合规范的比赛设备，不限定具体型号

### 3. 原创性要求

- 参赛作品必须为团队原创，不得抄袭、剽窃他人成果
- 高教组参赛智能车的加装模块须为自行设计，严禁直接使用未经实质性改装的成品结构参赛[citation:3]
- 模块主要外立面及控制电路板均需通过3D打印、激光雕刻或电路丝印等工艺，清晰呈现校徽与参赛队名称[citation:3]

## 七、评审标准

### 1. 竞速比赛评审维度

| 评审维度 | 说明 |
|----------|------|
| **完成时间** | 完成规定赛道任务所用时间 |
| **任务完成度** | 规定任务的完成情况[citation:1] |
| **技术稳定性** | 智能车运行的稳定性和可靠性 |
| **创新性** | 技术方案的创新程度 |

### 2. 创意组别评审维度（参考）

| 评审维度 | 说明 |
|----------|------|
| **任务完成度** | 各子任务的完成情况 |
| **自主性** | 设备在无人干预情况下的自主运行能力[citation:3] |
| **技术集成** | 多系统协同的技术复杂度 |
| **创新性** | 硬件设计、软件算法的创新程度 |

### 3. 成绩构成

竞速比赛通常按完成赛道任务的时间及任务完成度进行综合评分[citation:1][citation:5]。
