# 全国大学生统计建模大赛竞赛规则

## 一、竞赛简介

全国大学生统计建模大赛是在国家统计局统计教育培训中心指导下，由中国统计教育学会联合教育部高等学校统计学类专业教学指导委员会、全国应用统计专业学位研究生教育指导委员会主办的一项全国性学科竞赛[citation:6]。大赛旨在在大学生中倡导学习统计、应用统计的良好氛围，促进大学生关注经济社会热点难点问题，适应大数据时代高校及统计部门对统计人才的培养要求，提高大学生数据挖掘、数据分析、运用统计方法及计算机技术处理数据的能力，加强创新思维意识，助力推进统计现代化改革[citation:1]。

大赛入选《全国普通高校大学生竞赛分析报告》竞赛目录，是教育部官方认可的全国性大学生赛事之一[citation:8]。第十二届全国大学生统计建模大赛（2026年）由内蒙古财经大学承办国赛，各省赛区分别由各赛区院校承办[citation:1]。

## 二、组织机构

- **指导单位**：国家统计局统计教育培训中心[citation:6]
- **主办单位**：中国统计教育学会、教育部高等学校统计学类专业教学指导委员会、全国应用统计专业学位研究生教育指导委员会[citation:6]
- **国赛承办单位**：内蒙古财经大学[citation:1]
- **省赛承办单位**：各省、自治区、直辖市赛区院校（如河南赛区由郑州大学承办[citation:9]、江苏赛区由南京审计大学承办[citation:8]、湖南赛区由湖南师范大学承办[citation:2]等）
- **竞赛官网**：http://tjjmds.ai-learning.net/

## 三、大赛主题

本届大赛主题为 **“服务国家战略 创新统计赋能”** [citation:1][citation:2][citation:3]，参赛队围绕主题自拟题目撰写论文。选题应紧扣国家战略，如高质量发展、新质生产力、“双碳”目标、共同富裕、科技自立自强等，鼓励融合大数据、机器学习、AI等前沿方法[citation:7]。

## 四、参赛资格与要求

### 1. 参赛对象

- **学历要求**：全国各类高等学校全日制在校本科生、研究生均可报名，专业不限[citation:1][citation:2][citation:3]
- **组别设置**：大赛设本科生组和研究生组，本科生和研究生单独组队，不可跨组别组队[citation:1][citation:2][citation:3]

### 2. 团队组成

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每支参赛队须满3人组队[citation:1][citation:2][citation:3] |
| **组队范围** | 仅限校内组队，不可跨校组队参赛[citation:1][citation:2][citation:3] |
| **参赛限制** | 每名参赛者限报一支队[citation:1][citation:2][citation:3] |
| **指导老师** | 每队指导老师为1人[citation:1][citation:2][citation:3]，每位指导老师指导的参赛队伍总数不得超过4支[citation:1][citation:2][citation:3] |
| **队长职责** | 各参赛队需指定1人作为队长负责填报队伍信息、提交参赛材料及下载证书[citation:1][citation:2][citation:3] |

大赛分校级选拔赛（校赛）、省级复赛（省赛）、全国决赛（国赛）三级赛制[citation:1][citation:5][citation:8]。

| 阶段 | 时间安排 | 说明 |

| **主题解读培训** | 3月份 | 线上视频课程，针对主题解读、AI使用规范等内容[citation:1][citation:2][citation:3] |
| **校内报名** | 3月—4月（各校不同） | 各高校自行组织报名，截止时间多为3月下旬至4月底 |

## 六、参赛材料要求

### 1. 参赛材料清单

参赛材料包括[citation:1][citation:2][citation:3]：
- 报名表
- 承诺书
- AI工具使用情况表（2026年新增）[citation:1][citation:2][citation:3]
- 论文全文（Word和PDF完整版）[citation:6]
- 知网查重报告
- 数据包

### 2. 论文硬性要求

| 项目 | 要求 |
|------|------|
| **正文字符数** | 不得超过16000字（计空格）[citation:1][citation:2][citation:3] |
| **查重率** | 不得超过20%[citation:1][citation:2][citation:3] |
| **学术不端认定** | 查重率超过40%的论文视为学术不端行为[citation:1][citation:2][citation:4] |
| **匿名要求** | PDF版与Word完整版完全一致，参赛队相关信息不得出现在封面页以外的任何位置，否则视为违规[citation:6] |

### 3. AI工具使用规范

2026年大赛首次明确人工智能工具使用规范，具体要求如下[citation:7]：

| 允许范围 | 禁止范围 |
|----------|----------|
| ✓ 文献检索、整理参考文献 | ✗ 生成选题、研究假设、论文框架 |
| ✓ 推荐图表类型（图表内容须自己完成） | ✗ 直接生成论文正文 |
| ✓ 语言润色、语法校对、格式调整 | ✗ 用AI改写他人/往届作品参赛 |
| ✓ 辅助代码调试（核心逻辑须自己实现） | ✗ 代写模型、代做核心分析 |

必须提交《AI工具使用情况表》，指导教师审核签字。未标注或隐瞒使用将取消参赛资格[citation:7]。

## 七、各阶段比赛形式

### 1. 校级选拔赛

- 由各高校自行组织
- 形式：论文评审、现场答辩[citation:8]
- 校赛奖项：评选校赛一、二、三等奖，获奖比例各校不同（如一等奖10%、二等奖20%、三等奖30%[citation:1][citation:7]；或一等奖20%、二等奖30%、三等奖40%[citation:8]）
- 晋级规则：从校赛获奖队伍中按成绩排序，根据省赛给定名额推荐优秀队伍参加省赛[citation:1][citation:4][citation:5]

### 2. 省级复赛

- 以省为单位组织，由各省赛区承办院校负责[citation:1][citation:2][citation:5]
- 形式：依照大赛统一评审标准进行评审[citation:1][citation:5][citation:8]
- 省赛奖项：评选省赛一、二、三等奖，获奖比例分别为10%、20%、30%[citation:1][citation:5][citation:6]
- 晋级规则：从获得省赛一等奖的队伍中推荐优秀队伍参加国赛[citation:1][citation:5][citation:8]
- 公示要求：各省赛区对省赛获奖名单进行为期3天的公示[citation:8][citation:9]

### 3. 全国决赛

- **第一阶段：通讯评审、现场会议评审**（7月—8月）
  - 评出国赛三等奖、部分二等奖及入围答辩赛的参赛队[citation:1][citation:5][citation:8]
  - 入围答辩赛的参赛队名单在大赛官网上公布[citation:1][citation:5][citation:8]

- **第二阶段：现场答辩**（8月）
  - 入围答辩的参赛队伍需使用PPT展示自述内容[citation:1][citation:5][citation:8]
  - 按照规定的时间和要求对参赛论文进行自述（其中必须包括论文原创性介绍）[citation:1][citation:5][citation:8]
  - 回答专家的提问，以考核参赛论文的原创性、科学性和合理性[citation:1][citation:5][citation:8]
  - 评出国赛的部分二等奖及一等奖[citation:1][citation:5][citation:8]

- **第三阶段：大赛总结会**
  - 答辩赛结束后举行，届时将为获奖队颁奖[citation:1][citation:5][citation:8]

## 八、评审标准

### 1. 评审维度

| 评审维度 | 说明 |
|----------|------|
| **科学性** | 研究方法的科学性、数据来源的可靠性 |
| **创新性** | 选题视角、研究方法、技术应用的创新程度 |
| **实用性** | 研究成果的实际应用价值和社会意义 |
| **规范性** | 论文结构的完整性、格式的规范性 |
| **原创性** | 论文的原创程度，需在答辩中专门介绍[citation:1][citation:5][citation:8] |

### 2. 评审方式

- 省赛：依照大赛统一评审标准进行评审[citation:1][citation:5][citation:8]
- 国赛：通讯评审+现场会议评审+现场答辩[citation:1][citation:5][citation:8]

## 十、报名方式

### 1. 报名流程

1. **校内组队**：自由组队，确定指导教师和队长
2. **加入QQ群**：加入各校竞赛QQ群和各赛区QQ群，后续通知均在群内公布[citation:1][citation:2][citation:4]
3. **校内报名**：按各校要求填写报名信息，提交组队情况（部分学校通过学科竞赛管理系统报名[citation:10]）
4. **参加校赛**：通过校内选拔赛后获得省赛推荐资格
5. **官网注册**：获得推荐资格的队伍指派一人登录全国大学生统计建模大赛官网（tjjmds.ai-learning.net）进行注册登录，填报本队队员基本信息并提交最终参赛材料[citation:1][citation:2][citation:5]

### 2. 报名注意事项

- **报名截止时间**：各校不同，请关注本校具体通知（一般在3月下旬至4月底）[citation:2][citation:3][citation:4]
- **报名费用**：报名参赛不收取任何费用[citation:6][citation:8][citation:9]
- **实名要求**：加入QQ群需实名申请，实名格式：所属院校+本科生组（研究生组）+姓名[citation:1][citation:4][citation:5]

### 3. 官方资源

- 大赛向参赛队员免费提供数据库及分析建模平台等部分资源，可在大赛官网“大赛资源”栏目中查询[citation:4][citation:6]
- 主题解读培训资料登载在大赛官网[citation:1][citation:2][citation:4]

## 十一、违规与学术不端处理

### 1. 违规行为认定

大赛结束前，如发现以下行为，将按规定处理[citation:1][citation:2][citation:3]：
- 参赛论文存在抄袭、舞弊等学术不端行为
- 使用往届论文重复参赛等违规行为
- 违反大赛通知要求、承诺书条款等参赛基本条件
- 字符数超标或查重率超过20%（取消参赛资格）[citation:1][citation:2][citation:3]
- 查重率超过40%（视为学术不端行为）[citation:1][citation:2][citation:4]

### 2. 违规处理方式

- 取消参赛资格[citation:1][citation:2][citation:5]
- 向学院和学校通报批评[citation:1][citation:2][citation:5]
- 按学校规章制度进行处理[citation:4]

### 3. 违规举报

- 举报须为实名制，并提供证据材料，否则不予受理[citation:1][citation:4][citation:5]
- 大赛（省赛）组委会将参照《全国大学生统计建模大赛举报处理办法》进行处理[citation:1][citation:5][citation:8]
- 举报邮箱：各赛区及学校有相应举报渠道[citation:1][citation:4]
