# 全国大学生节能减排社会实践与科技竞赛竞赛规则

## 一、竞赛简介

全国大学生节能减排社会实践与科技竞赛是由教育部高等学校能源动力类专业教学指导委员会指导，全国大学生节能减排社会实践与科技竞赛委员会主办的大学生课外科技作品和社会实践调查竞赛。该竞赛紧密围绕国家“碳达峰碳中和”战略目标等重大需求，以“节能减排、绿色能源”为主题，已发展成为起点高、精品多、覆盖面广且影响力大的全国大学生实践创新活动[citation:1][citation:3]。

本赛事入选中国高等教育学会《全国普通高校大学生竞赛分析报告》竞赛目录，是教育部官方认可的全国性A类大学生赛事之一[citation:3]。竞赛旨在激发当代大学生的青春活力，创新实践能力，通过广泛宣传节能减排重要性，增强大学生节能环保意识、科技创新意识和团队协作精神，扩大学生科学视野，提高学生创新设计能力、工程实践能力和社会调查能力[citation:1][citation:9]。

第十九届全国大学生节能减排社会实践与科技竞赛由大连理工大学承办，全国总决赛初步定于2026年8月举办[citation:1][citation:4]。

## 二、组织机构

- **指导单位**：教育部高等学校能源动力类专业教学指导委员会
- **主办单位**：全国大学生节能减排社会实践与科技竞赛委员会
- **国赛承办单位**：大连理工大学
- **竞赛官网**：http://www.jienengjianpai.org/

## 三、竞赛主题与内容

### 1. 竞赛主题

**节能减排，绿色能源**[citation:1][citation:4][citation:5]

### 2. 竞赛内容

紧扣竞赛主题，参赛作品包括实物制作（含模型）、软件、设计和社会实践调研报告等，体现新思想、新原理、新方法以及新技术[citation:2][citation:4][citation:6]。

作品类型分为两类：

| 作品类别 | 说明 |
|----------|------|
| **科技作品类** | 包括实物制作（含模型）、软件、设计等，体现科技创新与应用 |
| **社会实践类** | 包括社会实践调研报告等，体现社会调查与分析能力 |

## 四、参赛资格与要求

### 1. 参赛对象

| 项目 | 要求 |
|------|------|
| **学历要求** | 全日制非成人教育的专科生、本科生、硕士研究生和博士研究生（不含在职研究生）[citation:1][citation:3][citation:4] |
| **组别设置** | 分设本科生组和研究生组，参赛队伍中有研究生参加的将归类为研究生组[citation:1][citation:4][citation:9] |
| **专科生组别** | 专科生参加本科组别比赛，不单独设置高职高专组[citation:2] |

### 2. 团队组成

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每组不超过7名学生[citation:1][citation:4][citation:9] |
| **指导教师** | 每个参赛队伍聘请指导教师不超过3名[citation:1][citation:4][citation:9] |
| **特殊要求** | 如聘请3名指导教师，其中1名必须是企业技术人员或交叉学科老师（与前两位指导教师不在同一个一级学科视为交叉学科老师）[citation:2][citation:4] |
| **参赛限制** | 每位同学作为队长或队员同年参与作品不超过2项；担任第一指导教师同年不超过1项[citation:5] |
| **组队范围** | 以高等学校为参赛单位，每所高校限报15项作品。高校间可混合组队参赛并提交作品，但作品按署名第一的高校进行统计[citation:7] |

### 3. 诚信承诺要求

所有参赛作品成员及指导教师需提供身份证号并签订诚信承诺书[citation:3][citation:9]。一旦发现并查实学术不端问题：

- 涉事学生永久禁赛[citation:3][citation:9]
- 相关指导教师禁赛两年[citation:3][citation:9]
- 对涉事学校进行警告；如再次违犯则该校禁赛2年[citation:3]

从省赛（校赛）首次提交作品至推荐国赛过程中，参赛队员及指导老师不得进行更换调整[citation:8]。

### 4. 作品要求

参赛作品必须是比赛**当年完成**的作品[citation:1][citation:4][citation:9]。参赛队伍必须在规定时间内完成作品，并按要求准时提交参赛作品，未按时提交者视为自动放弃比赛[citation:1][citation:4]。

## 五、赛制流程

竞赛分校级选拔赛（校赛）、省级复赛（省赛）、全国决赛（国赛）三级赛制。

### 1. 时间安排（第十九届）

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **校内报名** | 2026年1月—3月 | 各高校自行组织报名，截止时间多为3月中上旬 |
| **校内选拔赛** | 2026年3月—4月 | 各高校组织校赛评审与答辩 |
| **省赛** | 2026年4月—5月 | 各省组织省级竞赛（部分省份单独设置省赛） |
| **国赛报名** | 2026年5月中下旬 | 各高校推荐作品参加国赛 |
| **国赛会评** | 2026年6月—7月 | 专家会评，确定入围决赛名单 |
| **全国总决赛** | 2026年8月上旬 | 大连理工大学举行 |

### 3. 各阶段比赛形式

#### （1）校级选拔赛
- 由各高校自行组织
- 形式：初审（作品评审）+ 终审（现场答辩）
- 初审：专家根据作品的科学性、创新性、可行性和经济性等指标进行评审[citation:1][citation:2]
- 终审：入围队伍进行现场答辩，PPT讲解5-10分钟，评委提问5分钟[citation:2][citation:6]
- 晋级规则：每所高校择优推荐不超过15项作品参加全国初赛[citation:3][citation:5][citation:7]

#### （2）省级复赛
- 以省为单位组织（部分省份如山东、江苏、四川、上海等单独设置省赛）
- 省赛与国赛不直接互通，省赛获奖作品按成绩排序推荐参加国赛[citation:5][citation:8]
- 形式：线上初评+线下决赛答辩[citation:4][citation:8]

#### （3）全国决赛
- **第一阶段：国赛会评**（线上）
  - 国赛组委会组织专家进行会评，确定入围决赛作品名单及其他获奖作品名单[citation:8]
  - 通过会评的作品进行公示[citation:8]

- **第二阶段：全国总决赛**（线下）
  - 入围队伍进行现场作品展示和答辩
  - 总决赛评审委员会根据作品质量和答辩表现进行综合评价
  - 评选出全国特等奖、一等奖、二等奖、三等奖

## 六、作品要求与申报材料

### 1. 申报材料清单

参赛团队需提交以下材料：

| 材料名称 | 要求说明 |
|----------|----------|
| **作品申报书** | 需签字盖章，按类别使用对应模板[citation:1][citation:9] |
| **作品说明书/报告书** | 科技作品类提交说明书，社会实践类提交调研报告[citation:1][citation:2] |
| **介绍视频** | 3-5分钟，大小不超过20MB，展示作品核心内容[citation:1][citation:2][citation:4] |
| **支撑材料** | 可选，包括PPT、图片、专利申请文件、发表论文、应用证明等，大小不超过10MB[citation:1] |

### 2. 格式要求

| 类别 | 页数限制 | 格式 |
|------|----------|------|
| 科技作品类说明书 | ≤10页A4纸[citation:2] | PDF格式[citation:2] |
| 社会实践类报告书 | ≤16页A4纸[citation:2] | PDF格式，建议5000字左右[citation:2] |
| 申报书 | 无具体限制 | PDF格式，需签字盖章[citation:2][citation:9] |
| 介绍视频 | 3-5分钟 | 大小≤20MB[citation:1][citation:2] |

### 3. 原创性要求

- 参赛作品必须为团队原创，严禁抄袭、剽窃他人成果[citation:3][citation:8]
- 所有数据、图表、设计方案等均应基于团队独立完成
- 不得使用往届作品重复参赛
- 一旦发现学术不端，按诚信承诺条款严肃处理[citation:3][citation:9]

## 七、评审标准

### 1. 评审维度

| 评审维度 | 说明 |
|----------|------|
| **科学性** | 作品原理的科学性和正确性 |
| **创新性** | 作品的创新程度和独特性 |
| **可行性** | 作品的工程可实现性或社会可推广性 |
| **经济性** | 作品的经济效益和成本控制 |

以上四个维度为各高校校赛和省赛通用的评审标准[citation:1][citation:2][citation:4]。

### 2. 成绩构成（参考）

| 环节 | 占比 |
|------|------|
| 作品评审 | 50%—70% |
| 现场答辩 | 30%—50% |

具体权重由各赛区及国赛组委会确定。

## 八、奖项设置

### 1. 校级奖项

| 奖项 | 获奖比例（参考） |
|------|------------------|
| 一等奖 | 不超过参赛队伍的10%[citation:6][citation:10] |
| 二等奖 | 不超过参赛队伍的15%[citation:6][citation:10] |
| 三等奖 | 不超过参赛队伍的25%[citation:6][citation:10] |

注：各高校获奖比例略有不同，科技类与社会实践类作品分赛道评选[citation:4][citation:9]。

### 2. 省级奖项

由各省竞赛组委会确定，通常设一等奖、二等奖、三等奖[citation:8]。

### 3. 国家级奖项

| 奖项 | 说明 |
|------|------|
| **全国特等奖** | 总决赛现场答辩产生 |
| **全国一等奖** | 总决赛现场答辩产生 |
| **全国二等奖** | 会评产生 |
| **全国三等奖** | 会评产生 |

各等级的获奖比例由大赛组委会根据参赛规模确定[citation:1][citation:2]。

## 九、报名方式

### 1. 报名流程

1. **校内组队**：自由组队，确定指导教师和队长
2. **加入QQ群**：加入各校竞赛QQ群，获取后续通知[citation:1][citation:4][citation:9]
3. **校内报名**：按各校要求填写报名信息，提交组队情况
4. **提交作品**：在规定时间内提交申报书、说明书/报告书、介绍视频等材料
5. **参加校赛**：通过校内选拔赛后获得国赛推荐资格

### 2. 报名注意事项

- **报名截止时间**：各校不同，请关注本校具体通知（一般在3月上旬至4月上旬）
- **实名要求**：加入QQ群需实名申请（学号+姓名+学院）[citation:9]
- **材料提交**：按要求提交电子版和纸质版材料
- **邮件命名**：通常要求按“[节能减排]+学院/作品名称+负责人”格式命名[citation:1][citation:2][citation:4]
