# 全国大学生光电设计竞赛竞赛规则

## 一、竞赛简介

全国大学生光电设计竞赛是由中国光学学会主办、中国光学学会光学教育专业委员会代表主办机构、全国大学生光电设计竞赛委员会具体负责的一项全国高校光电类专业重要的学科竞赛赛事[citation:1]。竞赛创设于2008年，至今已成功举办十三届，自2019年以来连续被纳入中国高等教育学会《全国普通高校大学生竞赛分析报告》竞赛目录，是教育部官方认可的全国性大学生赛事之一[citation:1][citation:5]。

竞赛旨在为学生提供一个光、机、电、算一体化系统设计与开发的实训平台，促进光电知识的普及，加强大学生科学创新创业意识和团队协作精神，开阔大学生科学视野，提高大学生创新创业设计能力、工程实践能力和综合科技能力[citation:1]。第十四届全国大学生光电设计竞赛由长春理工大学承办，将于2026年6月下旬在吉林省长春市举行[citation:4][citation:6]。

## 二、组织机构

- **主办单位**：中国光学学会
- **代表机构**：中国光学学会光学教育专业委员会
- **负责机构**：全国大学生光电设计竞赛委员会
- **承办单位**：长春理工大学
- **组织委员会**：第十四届全国大学生光电设计竞赛组织委员会（含光学设计赛道分委员会）
- **竞赛官网**：http://gd.moocollege.com/[citation:4][citation:6]

## 三、赛道设置

本届竞赛包含两个赛道：

| 赛道 | 名称 | 竞赛类型 | 赛制 |
|------|------|----------|------|
| **主赛道** | 创意设计赛道 | 开放性路演类竞赛 | 区赛晋级国赛制 |
| **分赛道** | “宇瞳杯”光学设计赛道 | 竞技类竞赛 | 全国统一初赛、决赛两级赛制 |

### 1. 创意设计赛道

创意设计赛道是指围绕光电学科领域的创意、创新、创业开放性路演类竞赛类型[citation:2]。参赛队可按要求自行设立创意、创新、创业类开放性主题参赛，将光电信息技术与移动互联网、云计算、大数据、人工智能、物联网等新一代信息技术和经济社会各领域紧密结合，培育新产品、新服务、新业态、新模式，促进光电技术与教育、医疗、交通、制造、金融、绿色能源、生态农业、消费生活等深度融合[citation:2][citation:5]。

创意设计赛道分为两个组别：

| 组别 | 说明 |
|------|------|
| **创意类竞赛** | 参赛项目具有较好的创意或较为成型的产品原型或服务模式[citation:2] |
| **初创类竞赛** | 参赛项目已完成工商登记注册，且获机构或个人股权投资不超过1轮次，累计融资额不超过1000万人民币[citation:2] |

### 2. 光学设计赛道

光学设计赛道是围绕光学系统设计技术的竞技类竞赛类型[citation:2][citation:5]。本届赛题由赛道命题组会商并经赛道分委会讨论通过形成，分为两个赛题[citation:2]：

- 赛题1：微光夜视观察物镜设计
- 赛题2：AR眼镜拍摄镜头设计

## 四、参赛资格与要求

### 1. 基本资格

- **参赛对象**：2026年暑期前在校的具有正式学籍的全日制本科生、专科生、留学生及研究生均可参赛[citation:1][citation:2]
- **毕业生资格**：毕业五年内（2021年5月31日之后毕业）的全日制专科生、本科生、研究生有资格报名参加初创类竞赛；当年毕业的学生可以以在校生身份参赛[citation:2]
- **境外参赛**：鼓励各高校推荐境外友好合作高校的项目参赛。境内外联合参赛队按队长所在高校计算学校推荐国赛获奖队伍限额指标，队长为境外高校的按境外赛道进行推荐[citation:2]

### 2. 团队组成

#### （1）创意设计赛道

| 组别 | 队伍人数 | 研究生限制 | 队长要求 |
|------|----------|------------|----------|
| **创意类竞赛** | 每队不超过3人 | 研究生不多于1人 | 队长须为本科生或专科生[citation:2] |
| **初创类竞赛** | 每队不超过7人 | 研究生不多于2人 | 队长须为初创企业法人代表[citation:2] |

#### （2）光学设计赛道

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每支参赛队由3名学生组成[citation:1][citation:2] |
| **研究生限制** | 每支参赛队中研究生人数不能多于1名，且不能担任队长[citation:1][citation:2] |
| **指导教师** | 每支参赛队中指导教师人数不能多于2名[citation:1][citation:2] |
| **赛题选择** | 每支参赛队只能选择1道赛题参加竞赛[citation:1][citation:2] |

### 3. 通用要求

- **参赛限制**：每名学生在本赛道只能参加一支参赛队[citation:1][citation:2]
- **同时参赛**：允许学生个人同时参加本届全国光电竞赛创意设计赛道和光学设计赛道[citation:1][citation:2][citation:4]
- **跨校组队**：鼓励学生跨学院、跨专业、跨学科、跨校组队参赛[citation:2]
- **原创要求**：参赛项目须为本团队策划或经营的项目，不可借用他人项目参赛[citation:2]

### 4. 禁止参赛情况

- 已获往届全国大学生光电设计竞赛决赛奖励的项目不得再报名参加本届竞赛[citation:2]
- 基于高校教师科技成果转化的项目不能参加创意组竞赛[citation:2]
- 初创类竞赛企业法人在本通知发布之日后进行变更的不予认可[citation:2]

## 五、赛制流程

### 1. 赛道赛制

| 赛道 | 赛制 | 说明 |
|------|------|------|
| **创意设计赛道** | 区赛晋级国赛制 | 各赛区在2026年5月底之前先举办区赛，再推荐各区赛优胜队参与国赛[citation:4][citation:6] |
| **光学设计赛道** | 全国统一初赛、决赛两级赛制 | 赛题由光学设计赛道分委员会秘书处组织征集[citation:4] |

### 2. 赛区划分

全国共划分为八个赛区[citation:4]：

| 赛区 | 所辖省份 |
|------|----------|
| **华北区** | 北京、天津、河北、山西、内蒙古 |
| **东北区** | 辽宁、吉林、黑龙江 |
| **西北区** | 陕西、宁夏、甘肃、青海、新疆 |
| **西南区** | 重庆、四川、云南、贵州、西藏 |
| **中部区** | 河南、湖北、湖南、江西、安徽 |
| **东南区** | 广东、广西、福建、海南 |
| **东部区** | 上海、山东、江苏、浙江 |
| **境外赛道** | 含中国台港澳地区和其他国外高校参赛队 |

### 3. 时间安排（第十四届）

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **校内选拔赛** | 2026年3月—5月 | 各高校自行组织，截止时间多为3月下旬至4月底[citation:3][citation:5] |
| **区赛** | 2026年5月底前 | 各赛区举办区赛，选拔优胜队[citation:4][citation:6] |
| **全国总决赛** | 2026年6月下旬 | 在长春理工大学举行[citation:4][citation:6] |

### 5. 各阶段比赛形式

#### （1）校内选拔赛
- 由各高校自行组织
- 形式：项目计划书评审、3分钟介绍视频、路演PPT、现场汇报路演等[citation:3][citation:5]
- 校赛奖项：设一、二、三等奖，优秀作品推荐参加区赛[citation:3]
- 晋级规则：通过校赛获得参赛资格后方可参加区赛及国赛[citation:5]

#### （2）区赛
- 以赛区为单位组织，由各赛区组委会负责
- 形式：参照国赛评审方式进行作品评审
- 晋级规则：各区赛优胜队获得参加国赛资格[citation:4]

#### （3）全国总决赛
- 线下举行，入围队伍进行现场展示和答辩
- 评审专家现场评审，评选出全国总决赛一、二、三等奖

## 六、作品要求

### 1. 创意设计赛道作品要求

| 作品形式 | 要求 |
|----------|------|
| **项目计划书** | 详细阐述项目的创意、技术方案、市场分析等[citation:3] |
| **介绍视频** | 3分钟以内，展示项目核心内容和创新点[citation:1][citation:3] |
| **路演PPT** | 用于现场汇报路演的演示文稿[citation:3] |

### 2. 光学设计赛道作品要求

参赛队伍需按照赛题要求，完成光学系统设计方案，并提交相关设计文件。

### 3. 原创性要求

- 参赛作品必须为原创，不得抄袭、剽窃他人成果[citation:5]
- 不可借用他人项目参赛[citation:2]
- 参赛作品存在抄袭剽窃、弄虚作假等学术不端行为的，不予推荐参加区赛及国赛[citation:5]

## 七、评审标准

### 1. 创意设计赛道评审维度

| 评审维度 | 说明 |
|----------|------|
| **创新性** | 项目的创意和创新程度 |
| **技术可行性** | 技术方案的可行性和实现难度 |
| **市场前景** | 项目的市场应用价值和推广前景 |
| **团队能力** | 团队成员的专业背景和协作能力 |
| **展示效果** | 项目展示的逻辑性和清晰度 |

### 2. 光学设计赛道评审维度

| 评审维度 | 说明 |
|----------|------|
| **设计合理性** | 光学系统设计的科学性和合理性 |
| **技术指标** | 是否达到赛题要求的技术指标 |
| **创新性** | 设计方案的创新程度 |
| **实用性** | 设计成果的实际应用价值 |

## 九、报名方式

### 1. 报名流程

1. **校内组队**：按赛道要求组队，确定指导教师
2. **加入QQ群**：加入各校竞赛QQ群，获取后续通知
3. **校内报名**：按各校要求填写报名信息，提交组队情况
4. **参加校赛**：通过校内选拔赛后获得区赛推荐资格
5. **官网注册**：通过全国大学生光电设计竞赛官方网站（http://gd.moocollege.com/）进行注册报名[citation:4][citation:6]

### 2. 报名注意事项

- **报名截止时间**：各校不同，请关注本校具体通知
- **实名要求**：加入QQ群需实名申请
- **材料提交**：按要求提交项目计划书、介绍视频、路演PPT等作品材料

## 十、注意事项

### 1. 资格审核

推荐参赛队的高校和参赛队所属赛区负责参赛队的参赛资格审核[citation:2]。

### 2. 区赛要求

由于竞赛赛制要求，晋级国赛前必须经过区赛选拔，请参赛队伍及时关注赛区发布的通知[citation:1]。

### 3. 违规处理

有以下情况之一的，不予推荐参加区赛及国赛[citation:5]：
- 未通过校赛获得参赛资格，自行参赛的
- 参赛作品存在抄袭剽窃、弄虚作假等学术不端行为的
- 参赛团队成员存在冒名顶替、有名无实等情况的
- 参赛团队成员破坏赛事秩序、违反赛事程序的
- 其他有损赛事或学校声誉、影响作品参赛质量的
