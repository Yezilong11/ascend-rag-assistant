# 全国大学生创新年会竞赛规则

## 一、竞赛简介

全国大学生创新年会是由教育部发起、国家级大学生创新创业训练计划（以下简称“国创计划”）专家组主办，依托“国创计划”开展的一项重要年度性展示交流活动，是全国高校本科教学改革中覆盖面最广、影响力最大、学生参与最多、水平最高的盛会之一[citation:1]。

年会深入贯彻落实《国务院办公厅关于进一步支持大学生创新创业的指导意见》《国务院办公厅关于深化高等学校创新创业教育改革的实施意见》等文件要求，进一步深化高校创新创业教育改革，根据《国家级大学生创新创业训练计划管理办法》部署，推动“国创计划”参与学生开展更多学术交流和成果推介[citation:4][citation:8]。

## 二、组织机构

- **指导单位**：教育部高等教育司[citation:10]
- **主办单位**：国家级大学生创新创业训练计划专家组[citation:1]
- **承办单位**：每年通过遴选确定的承办学校（如第十八届由南京大学承办）[citation:8][citation:10]

## 三、年会主要内容

| 类别 | 说明 |
|------|------|
| **学术论文交流** | 遴选参加“国创计划”中创新训练项目学生的学术论文（约200篇），以学术报告的形式进行学术交流[citation:2][citation:8] |
| **改革成果项目展示** | 遴选“国创计划”中创新训练项目、创业训练项目和创业实践项目（约250项），以展板和实物作品演示的形式进行项目交流[citation:2][citation:8] |
| **创业项目推介** | 遴选“国创计划”中创业训练项目和创业实践项目（约60项），进行项目推介、宣传和交流[citation:2][citation:8] |

## 四、参赛对象与资格

### 1. 基本资格

参赛项目须为国家级大学生创新训练计划项目，具体范围包括[citation:1][citation:7]：

- **学术论文类**：2023-2024年度立项的国家级大学生创新训练计划项目（不含往年已入选项目）
- **改革成果项目类**：近年立项的国家级大学生创新训练计划项目
- **创业推介项目类**：近年立项的国家级大学生创新训练计划项目

### 2. 人员要求

| 类别 | 人员要求 |
|------|----------|
| **学术论文** | 第一作者是参加“国创计划”的本科生。项目已经完成并继续攻读研究生的学生，原则上只允许一年级的研究生参加年会[citation:2][citation:4] |
| **改革成果项目** | 第一完成人是参加“国创计划”的本科生。项目已经完成并继续攻读研究生的学生，原则上只允许一年级的研究生参加年会[citation:2][citation:4] |
| **创业推介项目** | 项目主要完成人是参加“国创计划”的本科生（或已经毕业4年内的毕业生），创意团队、初创企业和成长企业的团队负责人或企业法人参加过大学生创新训练计划项目[citation:2][citation:4] |

### 3. 禁止参赛情况

- 已在往届年会上交流过的项目或论文不得再申报[citation:3][citation:7]
- 存在学术不端、弄虚作假、知识产权和投资股权纠纷等问题的不予参评[citation:1][citation:2]

## 五、作品要求

### 1. 学术论文类

| 项目 | 要求 |
|------|------|
| **字数** | 不超过5000字（含图表），A4版面，不超过4页[citation:2][citation:9] |
| **语言** | 中文撰写。如已在外文期刊上发表，需用中文重新整理和撰写，中外文论文的作者、标注和内容要一致，并附上已发表论文的期刊封面、目录和外文论文原文[citation:2][citation:4] |
| **内容** | 主要反映学术研究情况（包括研究目的、方法、主要观点及结论等），由本科生为主完成[citation:2] |
| **标注要求** | 论文首页或致谢部分严格标注：“国家级大学生创新训练计划支持项目（项目批准号）”[citation:2] |
| **发表要求** | 如已在正式出版物上发表且标明了获得“国创计划”资助，推荐时请标明发表的刊物名称等相应信息，并提交PDF格式的原文附件[citation:2] |
| **查重要求** | 学校须对申报论文严格把关，做好查重查新工作，确保无抄袭、作假现象[citation:2] |
| **提交材料** | 论文正文（DOC+PDF）、论文简介（不超过300字中文摘要+英文摘要）、答辩PPT[citation:9] |

### 2. 改革成果项目类

| 项目 | 要求 |
|------|------|
| **第一完成人** | 参加“国创计划”的本科生（研究生一年级可参会）[citation:2] |
| **标注要求** | 展板显著位置标注：“国家级大学生创新训练计划支持项目（项目批准号）”[citation:2] |
| **专利要求** | 申请或获得专利的项目，专利申请人或发明人需有参加项目的本科生[citation:2] |
| **展板内容** | 项目类型、项目名称、项目编号、立项年份、项目成员（姓名/年级/专业）、指导教师（姓名/职称/研究方向）、项目简介（200字左右）、项目图片（2-4张，有图注）、项目创新点（100字左右）[citation:2][citation:9] |
| **竞赛获奖** | 曾参加国家级学科竞赛的项目，请注明：竞赛名称、获奖时间、奖励级别以及获奖作品形式[citation:2] |
| **展板规格** | PSD格式，横版尺寸194cm×242cm，dpi≥200，RGB模式[citation:9] |
| **实物展示** | 有实物展示的项目，提供1桌2椅及220V标准电源插排（总功率≤500瓦）[citation:9] |

### 3. 创业推介项目类

| 项目类型 | 内容要求 |
|----------|----------|
| **创业实践项目** | 企业（团队）简介；项目实践程度；项目市场表现（项目市场盈利情况、项目市场拓展能力和项目市场反应）；项目成果（包括注册资本、盈利能力、员工数量、业务范围、企业运营状况等）；与预期计划和目标比较；下一步的发展计划和策略安排；创业历程与感悟等[citation:2] |
| **创业训练项目** | 团队简介；模拟创业经历；主要业务或产品；与预期计划和目标比较；下一步的发展计划和策略安排；对项目参与学生能力培养的作用；项目所取得的研究成果（论文、作品或专利）等[citation:2] |
| **字数要求** | 不超过5000字（含图表）[citation:2] |
| **真实性要求** | 学校对简介和推荐意见表严格把关，保证内容的真实性，优先推荐创业实践项目[citation:2] |
| **展示形式** | 展板+现场路演相结合。展板尺寸80cm×180cm，dpi≥200，RGB模式[citation:9] |

## 六、申报与评审流程

### 1. 三级工作体系

创新年会项目申报、评审工作采取校级、省级、国家级三级工作体系[citation:2]。

| 层级 | 责任主体 | 说明 |
|------|----------|------|
| **校级初赛** | 各高校 | 通过举办校级创新年会或竞赛等方式遴选优秀作品申报[citation:2] |
| **省级复赛** | 省级教育行政部门 | 地方所属高校由各省级教育行政部门负责组织申报、评选和推荐[citation:2][citation:8] |
| **全国决赛** | 国创计划专家组 | 组织专家开展资格和形式审查、网络评审、会议评审三级评审工作[citation:2] |

### 2. 推荐名额

| 高校类型 | 学术论文 | 改革成果项目 | 创业推介项目 |
|----------|----------|--------------|--------------|
| **中央部委所属高校** | ≤3篇 | ≤3项 | ≤1项[citation:8] |
| **地方所属高校** | 按各省配额 | 按各省配额 | 按各省配额[citation:8] |

### 3. 全国决赛遴选规模

| 类别 | 全国决赛入选数量 |
|------|------------------|
| 学术论文 | 约200篇[citation:8][citation:9] |
| 改革成果项目 | 约250项[citation:8][citation:9] |
| 创业推介项目 | 约60项[citation:8][citation:9] |

## 七、现场交流形式

### 1. 学术论文交流

- **形式**：分会场由学生主持[citation:2]
- **时间安排**：论文作者报告10分钟，参会代表讨论3分钟，专家点评2分钟，共计15分钟[citation:2]
- **材料准备**：自行打印论文一式七份，准备PPT（版面比例16:9）[citation:9]

### 2. 改革成果项目展示

- **形式**：展板展示为主，可同步展示实物[citation:9]
- **展位配置**：1桌2椅，220V标准电源插排[citation:9]

### 3. 创业项目推介

- **形式**：展板展示+现场路演[citation:9]
- **时间安排**：项目介绍10分钟，参会代表讨论3分钟，专家点评2分钟，共计15分钟[citation:2]

## 八、评审与奖项设置

### 1. 学术论文类

- **分组评审**：按学科分成10组，分组进行论文报告交流[citation:2]
- **优秀论文**：每组由专家遴选出2项优秀论文，共选出20篇，由年会组织机构颁发证书[citation:2]

### 2. 改革成果项目类

| 奖项 | 评选方式 |
|------|----------|
| **我最喜爱的项目**（20项） | 由学生代表投票选出[citation:2] |
| **最佳创意项目**（20项） | 由高校教师和参会专家投票，结合评审专家的意见选出[citation:2] |

### 3. 创业推介项目类

- **晋级机会**：年会将遴选12项左右优秀创业推介项目，直接晋级下一年度中国国际大学生创新大赛总决赛[citation:2][citation:4][citation:8]

### 4. 校级奖励政策（参考）

| 级别 | 奖励认定（参考各校政策） |
|------|--------------------------|
| 入选年会 | 部分高校认定为学科竞赛国家级二等奖[citation:4] |
| 年会获奖 | 部分高校认定为学科竞赛国家级一等奖[citation:1][citation:4] |

## 十一、注意事项

### 1. 参会要求

入选年会参会作品所在的高校，应为学生参加年会提供便利和支持，保证每项入选作品的学生代表积极参加年会并进行展示和交流。未到年会参加交流的作品，取消推荐该作品的高校或省份下一年相关作品的申报资格[citation:2]。

### 2. 诚信要求

指导教师需对报名的学术论文、改革成果和创业推介项目进行严格把关，避免出现学术不端、弄虚作假、知识产权和投资股权纠纷等问题[citation:1][citation:2]。

### 3. 优先推荐

同等条件下，近年立项的国家级大学生创新训练计划重点支持领域项目、教育部产学合作协同育人创新创业联合基金项目、网络安全学院学生创新资助计划项目、“国创计划”企业命题项目优先考虑推荐入选年会[citation:2][citation:8]。
