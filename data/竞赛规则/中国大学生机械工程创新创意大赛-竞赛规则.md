# 中国大学生机械工程创新创意大赛竞赛规则

## 一、竞赛简介

中国大学生机械工程创新创意大赛（以下简称“大赛”）由中国机械工程学会主办，是面向全国高校机械工程领域及工学、理学、医学、管理学等门类相关专业大学生开展的一项公益性竞赛活动。自2019年起，大赛连续列入中国高等教育学会《全国普通高校大学生竞赛分析报告》竞赛目录，成为教育部认可的大学生国家级学科竞赛项目[citation:2][citation:5]。

大赛旨在引导和鼓励机械工程及相关专业的大学生主动跟踪科技发展前沿，积极投身科技创新与工程实践活动，培养团队协作意识和工匠精神，提升大学生工程实践与创新能力，服务国家制造强国战略，加快创新创业人才培养。大赛坚持公平、公正、公开的办赛原则，每年举办一届[citation:2]。

## 二、组织机构

### 1. 主办单位

- **主办单位**：中国机械工程学会
- **合作单位**：有关社会团体、行业企业、高校和地方政府共同参与[citation:2]

### 2. 组织架构

| 机构 | 职责 |
|------|------|
| **组织委员会** | 大赛的组织领导机构，负责制修订大赛章程、审定各赛道实施方案、发布年度赛事公告、审定比赛结果等[citation:2] |
| **组委会秘书处** | 设在中国机械工程学会工作总部，负责大赛日常事务管理、宣传推广、网站维护等[citation:2] |
| **赛项执行委员会** | 由赛项承办单位、协办单位的领导和专家组成，负责具体执行大赛组委会工作要求，制订本赛项实施细则和年度实施方案[citation:2] |
| **监督仲裁委员会** | 由主办单位设立，负责监督大赛整体运行实施情况，受理社会各界对大赛的仲裁申请[citation:2] |
| **赛项监督仲裁组** | 独立于赛项执行委员会，受理相关赛项组织实施期间的仲裁申请[citation:2] |

### 3. 竞赛官网与联系方式

- **大赛官方网站**：http://meicc.cmes.org/datacenter [citation:9]
- **各赛项官方网址**：详见大赛官网公告[citation:5]
- **监督仲裁委员会联系方式**：010-68433326、meicc@cmes.org [citation:5]

## 三、赛道与赛项设置

大赛采用“赛道-赛项”模式，设置创意赛道、创新赛道和毕业设计赛道3个赛道，下设多个赛项[citation:5]。

### 1. 赛道设置

| 赛道 | 说明 | 包含赛项 |
|------|------|----------|
| **创意赛道** | 侧重创新设计意识与综合设计能力 | 机械产品数字化设计赛等[citation:5] |
| **创新赛道** | 侧重工程实践与技术创新 | 过程装备实践与创新赛、铸造工艺设计赛、材料热处理创新创业赛、物流技术创意赛、智能制造赛、工业工程与精益管理创新赛、微纳传感技术与智能应用赛、智能精密装配赛、无损检测创新实践与应用赛、塑性工程实践与创新赛、失效分析赛等[citation:5] |
| **毕业设计赛道** | 侧重毕业设计与工程实践结合 | 毕业设计赛等[citation:5] |

### 2. 新增赛项

2026年大赛新增**增材制造创新创意大赛**赛项，由中国机械工程学会增材制造技术分会、特种加工分会承办，清华大学、西安交通大学等八所高校协办[citation:9]。

## 四、参赛资格与要求

### 1. 基本参赛资格

| 项目 | 要求 |
|------|------|
| **学历要求** | 全日制在校大学生，分为专科生组、本科生组和研究生组三个组别[citation:1] |
| **专业范围** | 机械工程领域及工学、理学、医学、管理学等门类相关专业，专业不限[citation:1][citation:5] |
| **组队范围** | 鼓励校内跨学科组队，但不得跨校组队[citation:1][citation:9] |

### 2. 各赛项团队组成要求

不同赛项对团队人数要求有所不同，具体如下：

| 赛项 | 队伍人数 | 指导教师人数 | 特殊要求 |
|------|----------|--------------|----------|
| **机械产品数字化设计赛** | ≤3人 | ≤2人 | 每名学生只能参加一个参赛类别，严禁队伍成员重复或交叉[citation:3] |
| **铸造工艺设计赛** | 本科组≤5人，研究生组≤3人 | 1-2人 | 参赛的本科生只能选择本科生组题目，硕士研究生只能选择硕士研究生组题目[citation:6][citation:7] |
| **无损检测创新实践与应用赛** | 3人 | 未明确 | 每人限参加1支队，分为本科生组和研究生组[citation:4] |
| **增材制造创新创意大赛** | ≤5人 | ≤2人 | 凡有硕士研究生或博士生队员参与的团队均划分为研究生组；鼓励高校与企业联合参赛[citation:9] |

### 3. 参赛限制

- **限额申报**：大赛省级或区域选拔赛和全国总决赛均实行限额申报[citation:2][citation:8]
- **作品数量限制**：如机械产品数字化设计赛，每所学校参加同一个比赛类别的队伍数量区域赛不超过10个，国赛不超过6个[citation:3]
- **跨区域限制**：各参赛队伍不得跨省/区域参赛，以本人所属高校所在地区为准[citation:9]
- **跨组限制**：每名参赛者只能参加一个小组比赛，不可跨组参赛[citation:6]

## 六、各赛项竞赛内容与要求

### 1. 铸造工艺设计赛

**竞赛内容**：采取统一命题方式，分为本科生组题目和硕士研究生组题目。参赛者在所属组别的命题题目中只能选择一个铸件作为参赛题目[citation:6][citation:7]。

**命题分类**：

| 铸造工艺类型 | 对应题目 |
|--------------|----------|
| **砂型铸造工艺** | A件、B件、C件、D件、E件、F件、G件、H件、L件、M件[citation:6][citation:7] |
| **高压压力铸造工艺** | J件、K件[citation:6][citation:7] |

**作品内容要求**：

| 铸造工艺类型 | 作品主要内容 |
|--------------|--------------|
| **砂型铸造工艺** | 零件名称、材质要求、结构分析、主要生产技术要求（造型、熔炼、浇铸、热处理等）、工艺方案、工艺说明、参数、工艺图和表（卡）、铸件质量控制（缺陷的预防措施）等[citation:6][citation:7] |
| **高压压力铸造工艺** | 赛题零件图、压铸件毛坯图及尺寸精度分析；压铸件结构特点、压铸件缺陷等质量要求；压铸合金材料分析及合金熔炼工艺；压铸辅助工艺；压铸件浇注、溢流、排气系统设计图，充型模拟分析及P-Q2图；压铸模具设计三维总装图，压铸工艺参数的设计、计算及选用；编写压铸件生产操作工艺规程，编写压铸件检验规程；压铸件清理、表面处理、缺陷预防措施及其他[citation:6][citation:7] |

**鼓励创新点**：
- 使用三维造型软件造型设计，并提供零件和铸造工艺的三维造型图
- 对工艺方案进行计算机数值模拟，并进行分析和验证
- 借助模拟软件对工艺方案进行优化[citation:6][citation:7]

### 2. 机械产品数字化设计赛

**2026年竞赛主题**：数字赋能推进机械智造，具身智能引领产业未来[citation:3]

**本科组竞赛类别**：

| 类别 | 说明 |
|------|------|
| **设计类** | 针对低空经济场景设计智能空中作业平台或机器人系统 |
| **数字孪生类** | 针对空中作业平台核心零部件进行制造工艺优化设计，通过数字孪生技术验证制造可行性[citation:8] |

### 3. 无损检测创新实践与应用赛

**2026年竞赛内容**[citation:4][citation:10]：

| 子赛项 | 竞赛形式 | 参赛对象 |
|--------|----------|----------|
| **常规超声检测** | 理论+实操 | 本科生 |
| **射线检测+数字评片** | 理论+数字评片 | 本科生 |
| **渗透检测（着色法）** | 理论+实操 | 本科生 |
| **人工智能与无损检测（创新赛）** | 创新作品 | 本科生或研究生 |

### 4. 增材制造创新创意大赛

**2026年竞赛主题**：产业牵引创新，遴选优秀人才[citation:9]

**竞赛宗旨**：构建国内聚焦增材制造技术高端竞技平台，激发大学生在增材制造领域的创新潜能，推动增材制造技术从科研探索向工程应用转化[citation:9]

## 七、作品要求与提交材料

### 1. 通用原创性要求

- 参赛作品必须是参赛者原创作品，未侵犯任何他人的知识产权[citation:2]
- 参赛院校需严格遵守各赛项的《参赛院校行为规范》[citation:6]
- 所有参赛团队需要签署《参赛作品原创承诺书》[citation:6]

### 2. 铸造工艺设计赛作品提交要求

| 材料名称 | 要求说明 |
|----------|----------|
| **工艺方案作品纸质打印稿** | 1份，A4纸，双面打印，左侧胶订装订[citation:6] |
| **PDF电子文档** | 1份，与纸质作品完全一致，应包括工艺卡、工艺图等所有工艺文件[citation:6] |
| **参赛报名表** | 纸质版1份，须加盖学校或学院公章[citation:6] |
| **参赛作品汇总表** | 纸质版1份，须加盖学校或学院公章[citation:6] |
| **参赛作品原创承诺书** | 纸质版1份[citation:6] |

**匿名要求**：参赛作品文件任何地方不得出现参赛者的学校名称、参赛者和指导老师姓名[citation:6]。

## 八、评审标准

### 1. 铸造工艺设计赛评审维度

| 评审维度 | 观测点 |
|----------|--------|
| **资料评价** | 齐全性、规范性[citation:6] |
| **选题评价** | 必要性、实用性和市场前景[citation:6] |
| **方案设计评价** | 综合知识的运用、方案的可行性、创新性、简捷性和安全性[citation:6] |
| **答辩表现** | 现场陈述、回答问题情况 |

### 2. 无损检测创新实践与应用赛初赛方式

- **初赛方式**：理论赛笔试（闭卷），包括是非题和单选题
- **考试时间**：60分钟
- **满分**：100分
- **出题范围**：中国机械工程学会无损检测分会人员认证培训内部资料[citation:10]

## 九、奖项设置

### 1. 校级选拔赛奖项

各高校自行组织校内选拔赛，通常设一等奖、二等奖、三等奖若干名，各等级的获奖比例根据参赛规模的实际情况确定[citation:7]。

### 2. 全国总决赛奖项

| 奖项 | 获奖比例 | 说明 |
|------|----------|------|
| **一等奖** | ≤参赛作品总数的8%[citation:2] | 由大赛统一颁发获奖证书[citation:2] |
| **二等奖** | 与一等奖合计≤参赛作品总数的30%[citation:2] | 由大赛统一颁发获奖证书[citation:2] |
| **三等奖** | 与一、二等奖合计≤参赛作品总数的30%[citation:2] | 由大赛统一颁发获奖证书[citation:2] |

注：奖项须由全国总决赛产生[citation:2]。

### 3. 证书互认

为鼓励大学生参与学术交流和科技创新活动，获奖学生可以申请相应专业的见习工程师工程能力水平评价证书[citation:2]。
