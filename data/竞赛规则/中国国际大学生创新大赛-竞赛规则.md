# 中国国际大学生创新大赛竞赛规则

## 一、竞赛简介

中国国际大学生创新大赛（原中国国际“互联网+”大学生创新创业大赛）是由教育部、中央统战部、中央网信办、国家发展改革委、工业和信息化部、人力资源社会保障部、农业农村部、中国科学院、中国工程院、国家知识产权局、国家乡村振兴局、共青团中央和承办高校所在省（市）人民政府共同主办的一项具有国际影响力的全国性大学生创新创业大赛。

大赛旨在落实立德树人根本任务，传承和弘扬红色基因，聚焦“五育”融合创新创业教育实践，开启创新创业教育改革新征程，激发青年学生创新创造热情，打造共建共享、融通中外的国际创新盛会，让青春在全面建设社会主义现代化国家的火热实践中绽放绚丽之花。

大赛自2015年创办以来，已成为覆盖全国所有高校、面向全体大学生、影响最大的高校双创盛会，也是世界大学生创新创业领域参赛面最广、覆盖高校最全、参赛团队最多、赛事影响最大的国际赛事之一。

## 二、组织机构

### 1. 组织架构

| 机构 | 职责 |
|------|------|
| **组织委员会** | 设立大赛组织委员会，由教育部和承办省（市）人民政府主要负责同志担任主任、教育部和承办省（市）分管负责同志担任副主任、教育部高等教育司主要负责同志担任秘书长、有关部门（单位）负责同志作为成员，负责大赛的组织实施 |
| **专家委员会** | 设立专家委员会，负责项目评审等工作 |
| **纪律与监督委员会** | 设立纪律与监督委员会，负责对赛事组织、参赛项目评审、协办单位相关工作等进行监督，对违反大赛纪律的行为予以处理 |

### 2. 竞赛官网与联系方式

- **大赛官网（全国大学生创业服务网）**：https://cy.ncss.cn/ 
- **官方微信公众号**：全国大学生创业服务网
- **资料下载**：大赛通知、评审规则、省级校级操作手册、学生操作手册等均可在大赛官网“资料下载”栏目获取

## 三、参赛对象与组别

### 1. 参赛对象

| 项目 | 要求 |
|------|------|
| **学历要求** | 普通高等学校全日制在校生（包括本科生、研究生、博士生）及毕业5年内的全日制学生 |
| **国际参赛** | 全球全日制在校生及毕业5年内的全日制学生均可参加国际赛道 |

### 2. 赛道设置

大赛共设置五个赛道：

| 赛道 | 说明 |
|------|------|
| **高教主赛道** | 面向普通高等学校师生，分为本科生组和研究生组，涵盖新工科、新医科、新农科、新文科等多个领域 |
| **“青年红色筑梦之旅”赛道** | 聚焦乡村振兴、社区治理等社会服务领域，鼓励学生扎根中国大地了解国情民情，用创新创业实践助力精准扶贫和乡村振兴 |
| **职教赛道** | 面向职业院校（含高职高专、中职中专）学生，促进职业教育创新创业人才培养 |
| **产业命题赛道** | 由行业企业出题，学生团队答题，促进产学研用深度融合 |
| **国际赛道** | 面向全球全日制在校生及毕业5年内学生，促进中外创新创业教育交流合作 |

## 四、参赛要求

### 1. 基本要求

| 项目 | 要求 |
|------|------|
| **真实性** | 参赛项目须真实、健康、合法，无任何不良信息，项目立意应弘扬正能量，践行社会主义核心价值观 |
| **原创性** | 参赛项目不得侵犯他人知识产权；所涉及的发明创造、专利技术、资源等必须拥有清晰合法的知识产权或物权 |
| **合规性** | 参赛项目涉及他人知识产权的，报名时须提交完整的具有法律效力的所有人书面授权许可书、专利证书等；已完成工商登记注册的创业项目，报名时须提交营业执照及统一社会信用代码等相关复印件、单位概况、法定代表人情况、股权结构等 |
| **禁止行为** | 抄袭、盗用、提供虚假材料或违反相关法律法规，一经发现即刻丧失参赛相关权利并自负一切法律责任 |

### 2. 团队组成要求

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每个团队的参赛成员不少于3人，原则上不多于15人（含团队负责人） |
| **指导教师** | 团队可设指导教师不超过5人 |
| **组队范围** | 允许跨校组建团队，鼓励跨学科、跨专业、跨年级组队 |
| **人员变更** | 项目入围省赛、国赛后，原则上只可进行人员删减，不可进行人员顺序调整及人员添加 |

### 3. 往届作品限制

曾获往届大赛总决赛各赛道金奖和银奖的项目，不可报名参加本届大赛。

## 五、赛道详解

### 1. 高教主赛道

**参赛组别**：

| 组别 | 项目类型 | 参赛对象 |
|------|----------|----------|
| **本科生创意组** | 具有较好创意和较为成型的产品原型或服务模式 | 项目负责人及成员均须为普通高等学校全日制本科生 |
| **研究生创意组** | 具有较好创意和较为成型的产品原型或服务模式 | 项目负责人及成员均须为普通高等学校全日制研究生 |
| **初创组** | 已完成工商登记注册，获机构或个人股权投资不超过1轮次 | 项目负责人须为参赛企业法定代表人，企业法定代表人在大赛通知发布之日后进行变更的不予认可 |
| **成长组** | 已完成工商登记注册，获机构或个人股权投资2轮次及以上 | 项目负责人须为参赛企业法定代表人，企业法定代表人在大赛通知发布之日后进行变更的不予认可 |
| **师生共创组** | 基于国家级重大、重点科研项目的科研成果转化项目，或教师与学生共同参与创业且教师所占权重比例大于学生 | 项目负责人须为参赛企业法定代表人，企业法定代表人在大赛通知发布之日后进行变更的不予认可 |

### 2. “青年红色筑梦之旅”赛道

**参赛组别**：

| 组别 | 项目类型 | 参赛要求 |
|------|----------|----------|
| **公益组** | 以社会价值为导向的非盈利性项目 | 在公益服务领域具有较好的创意、产品或服务模式的创业计划和实践；申报主体为独立的公益项目或社会组织，注册或未注册成立公益机构（或社会组织）的项目均可参赛 |
| **创意组** | 基于专业和学科背景或相关资源，解决农业农村和城乡社区发展的项目 | 项目在推进革命老区、贫困地区、城乡社区经济社会发展等方面有创新性、实效性和可持续性 |
| **创业组** | 以商业手段解决农业农村和城乡社区发展的痛点问题、巩固脱贫攻坚成果、助力乡村振兴，实现经济价值和社会价值的融合 | 项目在大赛通知下发之日前已完成工商等各类登记注册，项目负责人须为法定代表人，且股权不得少于10%，参赛成员股权合计不得少于1/3 |

### 3. 职教赛道

**参赛组别**：

| 组别 | 项目类型 | 参赛对象 |
|------|----------|----------|
| **创意组** | 具有较好的创意和较为成型的产品原型或服务模式 | 项目负责人及成员均须为职业院校全日制在校学生 |
| **创业组** | 已完成工商登记注册，具有较好的创意和较为成型的产品原型或服务模式 | 项目负责人须为参赛企业法定代表人，企业法定代表人在大赛通知发布之日后进行变更的不予认可 |

### 4. 产业命题赛道

**参赛要求**：

| 项目 | 要求 |
|------|------|
| **命题来源** | 由行业企业围绕行业领域产业命题，包括新工科、新医科、新农科、新文科对应的产业领域 |
| **解题要求** | 项目负责人须为普通高等学校全日制在校生（包括本科生、研究生），或毕业5年以内的全日制学生 |
| **团队组成** | 参赛项目中的教师须为高校教师（2025年7月31日前正式入职） |
| **限制条件** | 已获往届大赛总决赛各赛道金奖和银奖的项目，不可报名参加本届大赛产业命题赛道 |

## 六、赛制流程

大赛采用校级初赛、省级复赛、全国总决赛三级赛制。

### 1. 2026年大赛时间安排（参考2025年）

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **参赛报名** | 即日起—8月上旬 | 各高校自行组织报名 |
| **校级初赛** | 6月—7月 | 各高校完成校赛评审，择优推荐至省级复赛 |
| **省级复赛** | 7月—8月 | 各省组织省级竞赛，遴选优秀项目参加全国总决赛 |
| **全国总决赛** | 10月—11月 | 现场比赛，评选出各赛道金奖、银奖、铜奖 |

## 十、报名方式

### 1. 通用报名流程

1. **官网注册**：登录全国大学生创业服务网（https://cy.ncss.cn/）进行注册
2. **创建项目**：在官网创建项目，填写项目基本信息
3. **组建团队**：邀请团队成员加入项目
4. **选择赛道**：根据项目类型选择对应赛道和组别
5. **提交材料**：按要求提交商业计划书、项目介绍PPT、项目介绍视频等材料
6. **校内备案**：按各校要求完成校内报名备案，加入学校竞赛QQ群

### 2. 报名注意事项

- **报名截止时间**：各校不同，一般在4月—6月，请关注本校具体通知
- **材料命名**：通常要求按“赛道+组别+项目名称”格式命名
- **信息一致性**：项目负责人、团队成员、指导教师等信息须与官网报名信息完全一致

## 十一、学术诚信与监督

### 1. 学术诚信要求

- 参赛项目须真实、健康、合法，无任何不良信息
- 项目立意应弘扬正能量，践行社会主义核心价值观
- 不得侵犯他人知识产权
- 抄袭、盗用、提供虚假材料或违反相关法律法规的，一经发现即刻丧失参赛相关权利并自负一切法律责任

### 2. 监督机制

大赛设立纪律与监督委员会，负责对赛事组织、参赛项目评审、协办单位相关工作等进行监督，对违反大赛纪律的行为予以处理。

## 十二、联系方式

### 1. 官方联系方式

- **官方微信公众号**：全国大学生创业服务网
