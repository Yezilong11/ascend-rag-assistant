# 中国风景园林学会大学生设计竞赛竞赛规则

## 一、竞赛简介

中国风景园林学会大学生设计竞赛是由中国风景园林学会（Chinese Society of Landscape Architecture，简称CHSLA）主办的全国性高水平设计竞赛。该赛事是风景园林学科领域最具权威性和影响力的国家级大学生竞赛之一，旨在鼓励和激发广大在校大学生的创造性思维，提升风景园林专业的教学水平和设计实践能力，促进风景园林事业的繁荣与发展。

竞赛每年举办一届，通常与中国风景园林学会年会同期举行。参赛作品涵盖了风景园林规划设计的多个方面，包括但不限于公园设计、城市开放空间、生态修复、乡村景观、历史遗产保护等。

## 二、组织机构

### 1. 主办与承办单位

| 机构类型 | 单位名称 |
|------|------|
| **主办单位** | 中国风景园林学会 |
| **承办单位** | 每年由中国风景园林学会指定高校或研究机构承办，通常与学会年会承办单位一致 |
| **支持单位** | 相关风景园林院校、设计院所、专业媒体等 |

### 2. 组织架构

| 机构 | 职责 |
|------|------|
| **竞赛组委会** | 由中国风景园林学会秘书处及相关专家组成，负责竞赛的整体组织与协调工作 |
| **评审委员会** | 邀请国内外风景园林领域知名专家、学者担任评委，负责参赛作品的评审工作 |

### 3. 竞赛官网与联系方式

- **中国风景园林学会官方网站**：http://www.chsla.org.cn/ 
- **竞赛信息发布渠道**：学会官网“竞赛”或“通知公告”栏目
- **官方微信公众号**：中国风景园林学会

## 三、参赛资格与要求

### 1. 参赛对象

| 项目 | 要求 |
|------|------|
| **学历要求** | 中国大陆及港、澳、台地区风景园林类专业（包括园林、风景园林、景观建筑、景观学等）的在校本科生、研究生均可报名参赛 |
| **毕业生资格** | 当年毕业的学生可以以在校生身份参赛 |
| **组别设置** | 竞赛通常分为**本科生组**和**研究生组**两个组别，分别进行评选 |

### 2. 团队组成要求

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每组参赛人数不超过5人（含5人） |
| **指导教师** | 每组可设指导教师不超过2名 |
| **组队范围** | 鼓励跨年级、跨专业组队，但所有成员须为同一学校的学生；不得跨校组队 |
| **组别划分** | 团队中有研究生参与的，须划归研究生组 |

### 3. 参赛限制

| 限制事项 | 说明 |
|------|------|
| **每人限投** | 每位参赛者限报一个作品，不得作为多组成员重复报名 |
| **作品原创** | 参赛作品须为原创，未在其他竞赛中获奖，未在公开媒体发表 |
| **往届限制** | 已获得本赛事往届奖项的作品不得重复参赛 |

## 四、竞赛主题与选题

### 1. 命题方式

竞赛每年设置一个主题，主题通常与中国风景园林学会年会主题相呼应，或围绕风景园林领域的重大议题。参赛者需围绕年度主题进行创作。

### 2. 历年主题示例

| 年份 | 竞赛主题 |
|------|----------|
| 2024年 | 具体主题以当年通知为准 |
| 2023年 | 具体主题以当年通知为准 |
| 2022年 | 具体主题以当年通知为准 |

注：每年具体命题于当年竞赛通知中公布。

### 3. 选题方向

参赛作品选题应紧扣年度主题，可选择以下方向（但不限于）：

- 城市公园与绿地系统设计
- 生态修复与可持续景观
- 乡村景观与乡村振兴
- 历史文化遗产保护与活化
- 社区微更新与公共空间营造
- 风景园林与健康福祉
- 风景园林与气候变化应对
- 其他与风景园林相关的创新设计

## 五、作品要求

### 1. 作品内容要求

参赛作品应包含以下内容：

| 内容 | 说明 |
|------|------|
| **设计说明** | 阐述设计理念、策略、技术路线及创新点，字数不限，但需清晰表达设计思路 |
| **图纸表达** | 包括但不限于场地分析、概念生成、总平面图、功能分区图、交通流线图、竖向设计图、植物配置图、重要节点效果图、鸟瞰图等 |
| **分析图纸** | 对场地现状、问题、策略的分析图示 |
| **技术图纸** | 必要的技术图纸，体现设计的可实施性 |
| **模型照片** | 可选，可作为辅助表达 |

### 2. 图纸格式要求

| 项目 | 要求 |
|------|------|
| **图纸数量** | 本科生组：不超过2张A0图纸；研究生组：不超过3张A0图纸 |
| **图纸尺寸** | A0尺寸（841mm×1189mm），横版或竖版构图（以当年通知为准） |
| **文件格式** | JPG或PDF格式，分辨率不低于300dpi |
| **文件大小** | 单张图纸不超过50MB |
| **语言要求** | 图纸中的文字须为中文，可附加英文翻译 |

### 3. 匿名要求

为保障评审的公平公正，参赛作品图纸中不得出现任何反映作者、指导教师及学校的信息，包括但不限于：

- 作者姓名、学号
- 指导教师姓名
- 学校名称、校徽、院系标识
- 任何可识别个人或学校的文字、符号、图案

违反匿名要求的作品将被取消参赛资格。

### 4. 原创性要求

- 参赛作品必须为原创，未在其他竞赛中获奖，未在公开媒体发表
- 不得抄袭、剽窃他人成果
- 如使用他人图片、资料，须在图纸中注明出处
- 设计中所涉及的知识产权问题由参赛者自行负责

## 六、提交方式

### 1. 提交材料清单

| 材料名称 | 要求说明 |
|------|------|
| **参赛作品图纸** | 按格式要求完成的电子版图纸 |
| **报名表** | 从学会官网下载，填写完整并签字盖章后扫描为PDF |
| **作者身份证明** | 学生证扫描件或在读证明 |
| **作品说明文档** | WORD格式，简要说明设计理念（可作为附件） |

### 2. 提交方式

参赛者需在规定时间内，将上述材料通过以下方式提交：

| 提交渠道 | 说明 |
|------|------|
| **官方网站上传** | 登录中国风景园林学会官网竞赛系统，按要求上传作品文件 |
| **电子邮件提交** | 将作品发送至竞赛指定邮箱，邮件主题按指定格式命名 |
| **邮寄提交** | 部分年份要求邮寄纸质图纸及光盘（详见当年通知） |

### 3. 邮件命名规则

邮件主题及附件命名格式为：“CHSLA竞赛+组别+作品名称+第一作者姓名+联系电话”。

## 七、评审标准

### 1. 评审维度

| 评审维度 | 权重 | 说明 |
|------|:---:|------|
| **主题契合度** | 20% | 作品对年度主题的回应程度和思考深度 |
| **创新性** | 25% | 设计理念的创新程度，对问题的独特解读 |
| **科学性与逻辑性** | 20% | 设计逻辑的清晰性、分析的科学性、策略的合理性 |
| **技术可行性** | 15% | 设计的技术合理性和可实施性 |
| **表达效果** | 10% | 图纸表达的清晰度、艺术性和专业性 |
| **生态与社会价值** | 10% | 作品对生态环境、社会问题的回应和价值 |

### 2. 评审流程

| 阶段 | 说明 |
|------|------|
| **初评** | 由评审委员会对全部参赛作品进行匿名筛选，确定入围作品 |
| **终评** | 评审委员会对入围作品进行综合评议，确定获奖作品 |
| **结果公示** | 获奖名单在学会官网公示，接受社会监督 |

### 3. 评委构成

评审委员会由中国风景园林学会邀请国内外风景园林领域知名专家、学者组成，确保评审的专业性和权威性。

## 九、时间安排

### 1. 年度时间安排（参考）

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **竞赛发布** | 每年3月—5月 | 公布竞赛主题和详细规则 |

## 十、参赛费用

| 项目 | 收费标准 | 说明 |
|------|----------|------|
| **报名费** | 免费 | 不收取任何报名费用 |
| **其他费用** | 自理 | 参赛作品制作、打印、邮寄等费用自理 |

## 十一、学术诚信与监督

### 1. 学术诚信要求

- 参赛作品必须是参赛者的原创作品，未侵犯任何他人的知识产权
- 不得抄袭、剽窃他人成果
- 不得使用已获奖作品或已在其他竞赛中提交的作品重复参赛
- 所有引用资料须在图纸中注明出处

### 2. 违规处理

| 违规行为 | 处理方式 |
|------|------|
| 抄袭、剽窃 | 取消参赛资格，追回已颁奖项，并在官网通报 |
| 匿名要求违规 | 取消参赛资格 |
| 一稿多投 | 取消参赛资格 |
| 信息造假 | 取消参赛资格，通报所在学校 |

### 3. 监督机制

竞赛设立监督机制，接受社会各界的监督。任何单位或个人对获奖作品有异议，可在公示期内向学会提交实名书面申诉。
