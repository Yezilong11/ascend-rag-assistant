# 建筑类竞赛规则爬虫

## 功能说明
本爬虫用于爬取全国大学生建筑类竞赛的规则信息，包括：
1. UIA霍普杯国际大学生建筑设计竞赛
2. 天作奖国际大学生建筑设计竞赛
3. 东南·中国建筑新人赛
4. 城市设计学生作业国际竞赛
5. 城市可持续调研报告国际竞赛
6. 中国风景园林学会大学生设计竞赛
7. IFLA国际大学生设计竞赛
8. "新人杯"全国大学生室内设计竞赛

## 使用方法
1. 安装依赖：`pip install -r requirements.txt`
2. 更新`competition_urls`中的网址为最新官网地址
3. 运行：`python architecture_competition_crawler.py`

## 输出文件
- `{竞赛名称}_竞赛规则.md`：Markdown格式
- `{竞赛名称}_竞赛规则.json`：JSON格式
- `所有竞赛规则汇总.json`：所有竞赛的汇总数据

## 注意事项
1. 请遵守网站的robots.txt规则
2. 设置合理的爬取间隔，避免对服务器造成压力
3. 信息仅供参考，请以官方网站为准
