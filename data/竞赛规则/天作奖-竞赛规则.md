# 天作奖大学生建筑设计竞赛竞赛规则

## 一、竞赛简介

“天作奖”大学生建筑设计竞赛是由《建筑师》杂志、天作国际联合主办的一项面向全球建筑类院校在校大学生的年度建筑设计竞赛。该竞赛自创办以来，已成为国内建筑学领域最具影响力的学生竞赛之一，旨在激发在校学生的建筑设计创作热情，促进建筑教育交流，发现和培养建筑设计新人才。

竞赛秉持“创新、前瞻、务实”的理念，鼓励参赛者立足时代背景，关注社会现实，以独特的视角和创新的思维回应建筑设计命题。每年邀请国内外知名建筑院校教授、著名建筑师担任评委，确保竞赛的专业性和权威性。

## 二、组织机构

### 1. 主办与承办单位

- **主办单位**：《建筑师》杂志、天作国际
- **支持单位**：中国建筑工业出版社、中国建筑学会建筑教育分会等
- **官方网站**：https://www.tianzuo.org/ 

### 2. 组织架构

| 机构 | 职责 |
|------|------|
| **竞赛组委会** | 负责竞赛的整体组织与协调工作 |
| **学术委员会** | 由国内外知名建筑院校教授、建筑师组成，负责竞赛的学术指导 |
| **评审委员会** | 每年邀请国内外知名建筑师、建筑教育家担任评委，负责参赛作品的评审工作 |

## 三、参赛资格与要求

### 1. 参赛对象

| 项目 | 要求 |
|------|------|
| **学历要求** | 中国大陆及港澳台地区，以及海外各国建筑类院校在校本科生、研究生（含硕士、博士研究生）均可报名参赛 |
| **毕业生资格** | 当年毕业的学生可以以在校生身份参赛 |
| **组队方式** | 个人参赛或团队参赛均可 |

### 2. 团队组成要求

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每组参赛人数不超过3人 |
| **指导教师** | 每组可设指导教师不超过2名 |
| **组队范围** | 鼓励跨年级、跨专业组队，但所有成员须为在校学生 |

### 3. 参赛限制

- 每位参赛者作为主创只能提交1份作品，可作为成员参与不超过2份作品
- 已获其他竞赛奖项的作品不得重复参赛
- 参赛作品须为原创，不得侵犯他人知识产权

## 四、竞赛主题与命题

### 1. 命题方式

“天作奖”每年设置一个竞赛主题，由主办方邀请知名建筑师或建筑学者命题。命题关注当代建筑学的前沿议题，回应社会现实需求，鼓励学生进行创新性思考。

### 2. 历年命题示例

| 年份 | 命题主题 |
|------|----------|
| 2024年 | 第七届“天作奖”主题：“城乡之间” |
| 2023年 | 第六届“天作奖”主题：“对话与共生” |
| 2022年 | 第五届“天作奖”主题：“边界与融合” |

注：每年具体命题于当年竞赛通知中公布。

## 五、作品要求

### 1. 作品内容要求

参赛作品应包含以下内容：

| 内容 | 说明 |
|------|------|
| **设计说明** | 阐述设计理念、策略及创新点 |
| **图纸表达** | 包括但不限于总平面图、平面图、立面图、剖面图、分析图、效果图等 |
| **模型照片** | 可选，可作为辅助表达 |
| **其他表达** | 可根据设计需要增加其他表达方式 |

### 2. 图纸格式要求

| 项目 | 要求 |
|------|------|
| **图纸尺寸** | 统一为A0尺寸（841mm×1189mm），竖版构图 |
| **图纸数量** | 每份作品限1张A0图纸 |
| **文件格式** | JPG或PDF格式，分辨率不低于300dpi |
| **文件大小** | 不超过50MB |

### 3. 匿名要求

为保障评审的公平公正，参赛作品图纸中不得出现任何反映作者、指导教师及学校的信息，包括但不限于：

- 作者姓名、学号
- 指导教师姓名
- 学校名称、校徽、院系标识
- 任何可识别个人或学校的文字、符号、图案

违反匿名要求的作品将被取消参赛资格。

### 4. 原创性要求

- 参赛作品必须为原创，未在其他竞赛中获奖，未在公开媒体发表
- 不得抄袭、剽窃他人成果
- 如使用他人图片、资料，须在图纸中注明出处

## 六、提交方式

### 1. 提交材料清单

| 材料名称 | 要求说明 |
|------|------|
| **参赛作品图纸** | 1张A0尺寸图纸，JPG或PDF格式 |
| **报名表** | 从官网下载，填写完整并签字 |
| **作者身份证明** | 学生证扫描件或学籍证明 |
| **作品说明文档** | 可选，WORD格式，简要说明设计理念 |

### 2. 提交方式

参赛者需在规定时间内，将上述材料通过以下方式提交：

- **电子邮箱提交**：将作品图纸及报名表发送至竞赛指定邮箱
- **网盘提交**：将作品文件上传至网盘，将下载链接发送至指定邮箱
- **邮寄提交**：部分年份要求邮寄纸质图纸（详见当年通知）

### 3. 邮件命名规则

邮件主题及附件命名格式为：“天作奖+作品名称+第一作者姓名+联系电话”。

## 七、评审标准

### 1. 评审维度

| 评审维度 | 说明 |
|------|------|
| **创新性** | 设计理念的创新程度，对命题的独特解读 |
| **逻辑性** | 设计逻辑的清晰性和完整性 |
| **技术性** | 建筑技术的合理性和可行性 |
| **表达性** | 图纸表达的清晰度和艺术性 |
| **社会性** | 对社会现实的回应和思考深度 |

### 2. 评审流程

| 阶段 | 说明 |
|------|------|
| **初评** | 由评审委员会对全部参赛作品进行筛选，确定入围作品 |
| **终评** | 评审委员会对入围作品进行综合评议，确定获奖作品 |
| **结果公示** | 获奖名单在官网公示，接受社会监督 |

### 3. 评委构成

每年邀请国内外知名建筑师、建筑院校教授担任评委，确保评审的专业性和权威性。往届评委包括：

- 中国工程院院士
- 全国工程勘察设计大师
- 国内外知名建筑院校院长、系主任
- 国际知名建筑师
