# 全国周培源大学生力学竞赛竞赛规则

## 一、竞赛简介

全国周培源大学生力学竞赛受教育部高等教育司委托，由中国力学学会、周培源基金会联合主办，教育部高等学校力学教学指导委员会参与指导，《力学与实践》编委会、中国力学学会教育工作委员会负责承办，中国力学学会科普工作委员会、国防科技大学、东南大学等单位协办[citation:1]。竞赛始于上世纪八十年代，每两年举办一届，是教育部认可的全国高水平学科竞赛之一，也是国内规模最大、影响力最广的高校力学学科赛事[citation:1]。

竞赛旨在促进高等学校力学基础课程的改革与建设，提高学生学习力学的兴趣，加强对理工科学生的素质教育和培养动手能力、创新能力和团队协作精神，发现和选拔后继创新人才，服务于教学和育人[citation:4]。竞赛不以盈利为目的，坚持公益性原则[citation:4]。

第十五届全国周培源大学生力学竞赛于2025年成功举办，第十六届竞赛将于2027年举行，2026年为偶数年，主要开展竞赛筹备和校内选拔工作[citation:1][citation:2]。

## 二、组织机构

### 1. 主办与指导单位

- **主办单位**：中国力学学会、周培源基金会[citation:1][citation:4]
- **指导单位**：教育部高等学校力学教学指导委员会[citation:1]
- **委托单位**：教育部高等教育司[citation:1][citation:4]

### 2. 组织架构

| 机构 | 职责 |
|------|------|
| **竞赛领导小组** | 由中国力学学会理事会、教育部力学基础课程教学指导分委员会、中国力学学会教育工作委员会、《力学与实践》编委会、周培源基金会与相关单位负责人组成，负责竞赛的全盘安排和协调工作[citation:4] |
| **组织委员会** | 在领导小组统一领导下，负责具体实施竞赛动员、报名、监考与授奖工作[citation:4][citation:6] |
| **仲裁委员会** | 由3-5位专家组成，负责全程监督竞赛、评奖各环节，对有争议的问题加以裁决[citation:4][citation:6] |
| **命题及评奖组** | 由上届团体冠军学校负责组织，命题学校不参加该届竞赛，命题小组成员不得参加任何与该届竞赛相关的辅导与答疑[citation:6] |

### 3. 承办与协办单位

- **个人赛承办**：《力学与实践》编委会[citation:4]
- **团体赛承办**：
  - “理论设计与操作”团体赛由《力学与实践》编委会承办[citation:4]
  - “基础力学实验”团体赛由中国力学学会教育工作委员会承办[citation:4]
- **协办单位**：中国力学学会教育工作委员会、科普工作委员会，各省（市）、自治区力学学会和2所指定高校，协办高校每届轮换[citation:4]

### 4. 信息发布渠道

- **官方网站**：http://zpy.cstam.org.cn/（发布报名通知、赛程安排、获奖名单、赛事动态等核心信息）[citation:1][citation:3]
- **官方微信公众号**：《力学与实践》微信公众号（试题解析、报名指引、赛事快讯）[citation:1]
- **期刊支持**：《力学与实践》期刊刊发竞赛试题、答案及工作动态[citation:1]

## 三、参赛资格与要求

### 1. 参赛对象

| 项目 | 要求 |
|------|------|
| **年龄要求** | 30周岁（含）以下（竞赛当年12月底不满31周岁）[citation:4][citation:6] |
| **学历要求** | 在校大学专科生、本科生及研究生均可报名[citation:4][citation:6] |
| **专业限制** | 无专业限制，所有符合年龄条件的学生均可报名[citation:1] |
| **港澳台地区** | 港澳台地区在校学生可报名参赛[citation:4][citation:6] |

### 2. 报名方式

- **学校统一报名**：由高等学校（研究所）直接向所在省、市、自治区或特区竞赛分组织委员会报名[citation:4][citation:6]
- **个人直接报名**：也可个人直接联系所在省、直辖市、自治区力学学会指定联系人报名（联系人名单可从竞赛官方发布的附件中查阅）[citation:1]
- **报名材料**：需按要求填写官方统一报名表（可通过官方渠道下载）[citation:1]
- **报名截止时间**：以当年竞赛通知为准（第十五届报名截止时间为3月31日）[citation:1]

### 3. 参赛费用

| 项目 | 说明 |
|------|------|
| **报名费** | 120元/人[citation:1] |
| **退费政策** | 报名后未参加竞赛者不予退还[citation:1] |
| **其他费用** | 竞赛将适当收取材料费等，具体费用需上报竞赛领导小组批准后执行[citation:4] |

## 四、竞赛内容与形式

### 1. 竞赛类别

全国周培源大学生力学竞赛分为个人赛和团体赛两个阶段[citation:1][citation:4]：

| 类别 | 形式 | 重点考察 |
|------|------|----------|
| **个人赛** | 闭卷笔试 | 力学基础理论掌握程度及实际应用能力[citation:1] |
| **团体赛** | 团队课题研究 | 团队协作、创新设计与动手实验能力[citation:6] |

团体赛又分为两个独立赛道[citation:1]：
- **理论设计与操作**赛道
- **基础力学实验**赛道

### 2. 考察范围

竞赛内容覆盖理论力学与材料力学两门课程的理论和实验内容，严格参照教育部基础力学课程教学指导委员会颁布的相关教学大纲命题[citation:1]。

| 科目 | 考察内容 |
|------|----------|
| **理论力学** | 静力学、运动学、动力学等基本理论与应用[citation:6] |
| **材料力学** | 基本概念、强度计算、变形分析等，含实验相关知识[citation:1][citation:6] |

**重点**：着重考核灵活运用基础知识、分析和解决问题的能力[citation:2][citation:6]。

### 3. 个人赛形式

- **考试方式**：闭卷笔试[citation:1][citation:6]
- **试卷结构**：理论力学和材料力学综合为一套试卷[citation:2]
- **考试时间**：通常为120分钟[citation:2]
- **考试组织**：试卷由组委会按保密信函寄达各省（市）竞赛分组织委员会，由分组织委员会就近安排考场，全国同时进行考试[citation:6]

### 4. 团体赛形式

- **参赛资格**：由个人赛成绩遴选产生[citation:1]
- **组队方式**：以学校为单位组队，每个学校至多一队，每队由3人组成。不能单独组队的学校可以在本地区跨校组队一次[citation:6]
- **选拔数量**：各省（市）提交本赛区的优秀团队名单（至多5个），组委会根据成绩选拔出20个团队参加决赛[citation:6]
- **比赛方式**：集中于一地进行，团体赛方式由命题学校确定[citation:6]

## 五、赛制流程

### 1. 时间安排（参考第十五届）

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **报名阶段** | 双数年12月—单数年3月 | 启动报名筹备工作，发布报名通知[citation:1] |
| **校内选拔赛** | 3月—4月 | 各高校自行组织，截止时间多为3月上中旬 |
| **个人赛** | 5月（单数年） | 全国统一时间闭卷笔试 |
| **团体赛** | 7月—8月（单数年） | 集中进行决赛 |

### 2. 各阶段比赛形式

#### （1）校内选拔赛
- 由各高校自行组织，形式多为闭卷笔试
- 校赛奖项：设一、二、三等奖，获奖比例分别为校赛团队总数的10%、20%、30%[citation:2]
- 晋级规则：学校根据校赛成绩择优推荐学生参加全国个人赛[citation:2]

#### （2）个人赛
- 全国统一时间进行闭卷笔试
- 各分组织委员会聘请有经验的力学教师集中阅卷[citation:6]
- 各省（市）提交本赛区的优秀个人名单（前5%，至多50位）[citation:6]
- 组委会根据成绩选拔出20个团队参加团体赛决赛[citation:6]

#### （3）团体赛
- 集中于一地进行现场比赛
- 两个赛道分别进行评选
- 根据团体赛成绩最终评出各奖项[citation:6]

## 六、评审标准

### 1. 个人赛评审维度

| 评审维度 | 说明 |
|----------|------|
| **理论掌握** | 力学基础理论的掌握程度 |
| **灵活运用** | 灵活运用基础知识的能力 |
| **分析能力** | 分析问题的逻辑性和准确性 |
| **解题能力** | 解决实际问题的能力 |

### 2. 团体赛评审维度

| 赛道 | 评审维度 |
|------|----------|
| **理论设计与操作** | 创新设计能力、动手操作能力、团队协作[citation:1] |
| **基础力学实验** | 实验方案设计、实验操作规范、数据分析能力[citation:1] |

### 3. 成绩评定

- 个人赛成绩由各赛区阅卷后提交优秀名单，组委会组织专家组进行最终评定[citation:6]
- 团体赛成绩由专家组根据现场表现综合评定[citation:6]

## 七、奖项设置

### 1. 个人赛奖项

| 奖项 | 获奖比例/名额 | 说明 |
|------|---------------|------|
| **特等奖** | 5名[citation:1][citation:6] | 全国个人赛最高荣誉 |
| **一等奖** | 全国报名人数0.5%[citation:1] | 由全国竞赛组委会颁发证书 |
| **二等奖** | 全国报名人数1%[citation:1] | 由全国竞赛组委会颁发证书 |
| **三等奖** | 各省赛区报名人数5%[citation:1] | 由全国竞赛组委会颁发证书 |
| **优秀奖** | 各省赛区报名人数15%[citation:1] | 由全国竞赛组委会颁发证书 |

注：一等奖15名、二等奖30名为早期规则中的固定名额，现按比例确定[citation:6]。

### 2. 团体赛奖项

| 奖项 | 名额（每个赛道） | 说明 |
|------|------------------|------|
| **特等奖** | 1个[citation:1] | 团体赛最高荣誉 |
| **一等奖** | 2个[citation:1] | 由全国竞赛组委会颁发证书 |
| **二等奖** | 4个[citation:1] | 由全国竞赛组委会颁发证书 |
| **三等奖** | 8个[citation:1] | 由全国竞赛组委会颁发证书 |
| **优秀奖** | 若干[citation:1] | 由全国竞赛组委会颁发证书 |

注：早期规则中团体奖设一等奖1队、二等奖3队、三等奖6队[citation:6]。

### 3. 赛区奖项

各省（市）可自行评出本赛区优胜奖，可命名为“第×届全国周培源大学生力学竞赛（省、市、自治区名称）等奖”[citation:6]。

### 4. 颁奖仪式

竞赛的各类奖项在当年举行的中国力学大会上为获奖者颁奖[citation:4]。

### 5. 荣誉认证

所有获奖者名单通过官方渠道公示，由全国竞赛组委会统一授予获奖证书，竞赛成果可作为学生学术评价、升学就业的重要参考[citation:1]。

2026年为偶数年，主要开展竞赛筹备和校内选拔工作。各高校组织校内选拔赛，为2027年第十六届全国竞赛选拔优秀选手[citation:1][citation:2]。
