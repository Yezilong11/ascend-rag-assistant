# 全国大学生电子设计竞赛竞赛规则

## 一、竞赛简介

全国大学生电子设计竞赛（National Undergraduate Electronics Design Contest）是教育部高等教育司、工业和信息化部人事教育司共同发起的大学生学科竞赛，是目前国内规模最大、影响力最强、行业认可度最高的本科电子设计类赛事之一[citation:3][citation:5]。竞赛自1994年创办以来，已成功举办数十届，位列全国普通高校大学生竞赛排行榜，是保研“十大赛事”之一[citation:5]。

竞赛旨在推动高等学校促进信息与电子类学科课程体系和课程内容的改革，培养大学生的实践创新意识与基本能力、团队协作的人文精神和理论联系实际的学风；加强学生动手能力和工程实践能力的培养，提高学生针对工程问题进行电子设计、制作的综合能力；吸引、鼓励广大学生踊跃参加课外科技活动，为优秀人才脱颖而出创造条件[citation:2][citation:3]。

## 二、组织机构

### 1. 主办与领导单位

- **主办单位**：教育部高等教育司、工业和信息化部人事教育司[citation:3]
- **组织运行模式**：政府主办、专家主导、学生主体、社会参与[citation:3]

### 2. 组织架构

| 机构 | 职责 |
|------|------|
| **全国竞赛组织委员会** | 负责全国竞赛的组织领导、协调与宣传工作，由教育部、工信部、部分参赛省市教育主管部门负责人及有关学校专家组成，任期四年[citation:2][citation:3] |
| **全国竞赛专家组** | 负责竞赛命题、评审工作[citation:2] |
| **各赛区竞赛组委会** | 由省（自治区）、直辖市教委（厅、局）、高校代表及电子类专家组成，负责本赛区竞赛的组织领导、协调与宣传工作[citation:2][citation:3] |
| **各赛区专家组** | 负责本赛区竞赛的评审工作，同时负责组织、遴选本赛区内的征题并向全国专家组推荐[citation:2] |

### 3. 赛区划分

原则上以省（自治区）、直辖市独立组成一个赛区。若参赛学校少于3所或参赛队少于20个队时，可与邻近省市联合组成一个赛区[citation:3]。暂无条件单独组成赛区的省、自治区的有关高等学校，可就近参与其他赛区的竞赛活动，或由全国竞赛组委会统筹安排[citation:2]。

## 三、参赛资格与要求

### 1. 参赛对象

| 项目 | 要求 |
|------|------|
| **学历要求** | 普通高等学校具有正式学籍的全日制在校本科或高职高专学生[citation:2] |
| **组别划分** | 分设本科生组和高职高专学生组，分别组队、命题、评奖[citation:2][citation:7] |
| **组别选择** | 参赛的本科生只能选本科组题目；高职高专学生原则上选择高职高专组题目，但也可选择本科组题目。只要参赛队中有本科生，该队只能选择本科组题目[citation:2] |

### 2. 团队组成

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每支参赛队由3名学生组成[citation:2][citation:5][citation:8] |
| **组队原则** | 学生自愿组合、3人一队[citation:2][citation:8] |
| **组队范围** | 以学校为单位统一向赛区竞赛组委会报名，同一学校学生组队[citation:2] |
| **参赛限制** | 每名学生只能参加1支队伍 |

### 3. 参赛要求

- 参赛队3名学生必须全部按统一时间全程参加竞赛，按时开始和结束竞赛，如不能参加，将取消该队员的参赛资格[citation:2]
- 参赛队员必须全部全程参加评审，如不能参加，将取消该队员的评奖资格[citation:2]
- 各高校通常采用校内报名-选拔制，经过校内选拔的队伍由学校统一向赛区报名[citation:8]

## 四、竞赛时间与形式

### 1. 办赛模式

全国大学生电子设计竞赛采用“奇偶年分级办赛”模式[citation:5]：
- **奇数年**：举办全国赛
- **偶数年**：举办省级赛及专题竞赛

2026年（偶数年）将组织开展三项专题竞赛[citation:1][citation:4]：
1. 大学生电子设计竞赛嵌入式AI专题赛（英特尔杯）
2. 全国大学生电子设计竞赛模拟电子系统设计专题赛（TI杯）
3. 全国大学生电子设计竞赛信息科技前沿专题赛（瑞萨杯）

### 2. 时间安排（以2025年全国赛为例）

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **报名截止** | 2025年5月31日 | 各赛区完成报名汇总[citation:2] |
| **全国竞赛** | 7月30日（周三）8:00至8月2日（周六）20:00 | 四天三夜集中竞赛[citation:2][citation:5][citation:7] |
| **作品提交** | 8月2日—3日 | 按赛区规定时间提交密封作品[citation:7] |
| **赛区评审** | 8月4日起 | 各赛区专家组进行评审[citation:7] |
| **综合测评** | 8月10日 | 推荐全国评奖队伍参加综合测评[citation:7] |
| **全国评审** | 8月—9月 | 全国专家组评审[citation:2] |

### 3. 竞赛形式

- **竞赛方式**：采取半封闭、相对集中的组织方式，四天三夜的封闭创作周期[citation:3][citation:5]
- **题目公布**：采用网上发题方式，开赛时依托全国大学生电子设计竞赛网站(http://nuedc.xjtu.edu.cn)、全国大学生电子设计竞赛培训网（http://nuedc-training.com.cn）及其他有关赛区网站发布全国竞赛题目[citation:2][citation:8]
- **作品要求**：参赛队在规定时间内完成“理论设计”和“实际制作”，按时提交设计报告和制作实物[citation:2]
- **作品封存**：收回的设计报告和制作实物后，及时严格封存，贴赛区统一制作的封条[citation:2]

## 五、竞赛题目及要求

### 1. 题目来源

全国竞赛采用广泛征题、全国统一命题方式。各赛区广泛发动本赛区高校师生、有关企业组织征题工作[citation:2]。

### 2. 题目范围

竞赛题目包括“理论设计”和“实际制作”，以电子电路和集成电路应用设计为基础，可以涉及嵌入式系统、可编程器件、射频及光电器件应用，以及支撑新质生产力的现代电子信息技术[citation:2]。命题范围涵盖模-数混合电路、嵌入式系统、人工智能等新兴产业技术领域[citation:3]。

### 3. 题目要求

- 具有实际意义和应用背景，考虑到目前教学的基本内容和新技术的应用趋势[citation:2]
- 着重考核参赛学生综合运用基础知识进行理论设计的能力、实践创新和独立工作的基本能力、实验综合技能（制作与调试）[citation:2]
- 在难易程度上，既要考虑使参赛学生能在规定时间内完成基本要求，又能使优秀学生有充分发挥与创新的余地[citation:2]

### 4. 技术限制

除题目特殊要求以外，参赛队的作品中不得包含个人计算机（如PC机、平板电脑、笔记本电脑以及通用键盘、鼠标等调试外设）、手机等。实际制作实物中凡需软件编程的芯片必须事先下载脱机工作封存在作品箱中。所有含存储器的器件、U盘、开发装置或仿真器等不在作品封箱中的物品不得携带进入评审测试现场，否则取消测试资格[citation:2]。

## 六、竞赛规则

### 1. 独立完成要求

竞赛期间，参赛学生可以使用各种图书资料和网络资源，但不得以任何方式与队外人员进行讨论交流，教师和其他非参赛队员必须迴避[citation:2]。

### 2. 监督检查

各赛区竞赛组委会要组织巡视检查，以保证竞赛活动公正进行。各赛区需设立赛区一级的网络在线监控，赛区组委会可对赛区内各个竞赛场地全景实施实时在线监控，作为对已有巡视检查制度的有效补充[citation:2]。

### 3. 违规处理

全国竞赛初评结果在网上公布，接受社会监督。在竞赛中如发现有教师参与、他人代做、抄袭及被抄袭、队与队之间交流、不按规定时间发题和收交作品等现象，将取消获奖，并通报批评[citation:2]。

### 4. 异议期制度

根据《全国大学生电子设计竞赛异议期制度若干规定》，获奖名单公示期间接受社会监督。

## 七、评审与奖项设置

### 1. 评奖方式

2025年全国竞赛采用“一次竞赛，两级评奖”方式，竞赛奖励分为“赛区奖”和“全国奖”两级[citation:2][citation:8]。

### 2. 赛区奖项

| 奖项 | 获奖比例 | 说明 |
|------|----------|------|
| **赛区一等奖** | ≤赛区总参赛队数的10% | 由赛区组委会颁发证书[citation:2][citation:7][citation:8] |
| **赛区二等奖** | ≤赛区总参赛队数的17% | 由赛区组委会颁发证书[citation:7] |
| **赛区三等奖** | ≤赛区总参赛队数的23% | 由赛区组委会颁发证书[citation:7] |

注：赛区一、二、三等奖总获奖比例不超过赛区总参赛队数的40%[citation:2][citation:8]。

### 3. 全国奖项

| 奖项 | 获奖比例 | 说明 |
|------|----------|------|
| **全国一等奖** | ≤全国实际参赛队总数的8%（含一、二等奖合计） | 由全国组委会颁发证书[citation:2][citation:8] |
| **全国二等奖** | ≤全国实际参赛队总数的8%（含一、二等奖合计） | 由全国组委会颁发证书[citation:2][citation:8] |
| **TI杯** | 从全国一等奖中推选 | 最高荣誉[citation:3][citation:8] |

注：同一题目、同一所学校获得全国一、二等奖的总队数合计不超过4个，其中一等奖队数不超过2个[citation:2][citation:8]。

### 4. 推荐规则

赛区报送的优秀参赛队数分别不得超过本赛区本科组和高职高专组实际参赛队总数的10%[citation:2][citation:8]。

### 5. 其他奖项

| 奖项 | 说明 |
|------|------|
| **赛区优秀组织奖** | 对竞赛组织中表现出色的赛区竞赛组委会给予表彰奖励[citation:2] |
| **优秀征题奖** | 对竞赛征题工作中表现突出的个人给予表彰奖励[citation:2] |

## 八、2026年专题竞赛说明

2026年（偶数年）将组织开展三项专题竞赛[citation:1][citation:4]：

| 专题竞赛 | 主办方 | 参赛形式 | 报名机制 |
|----------|--------|----------|----------|
| 嵌入式AI专题赛（英特尔杯） | 英特尔 | 初赛+复赛 | 选拔+邀请 |

## 九、参赛费用

| 项目 | 说明 |
|------|------|
| **报名费** | 各赛区可适当收取参赛报名费（由参赛学校支付），具体数额由各赛区竞赛组委会根据实际情况确定[citation:2] |
| **全国及专题竞赛** | 全国竞赛组委会和专题竞赛分组委会在专题竞赛初赛和决赛阶段不收取报名费用[citation:1][citation:4] |

经费使用要公开、透明，并接受社会各界监督[citation:2]。

## 十、报名方式

### 1. 报名流程

1. **校内组队**：学生自愿组合，3人一队，确定指导教师
2. **校内报名**：按各校要求完成校内报名，加入学校竞赛QQ群
3. **参加校赛**：通过校内选拔赛后获得参赛资格（多数高校要求）
4. **学校统一报名**：由所在学校统一向赛区竞赛组委会报名[citation:2]

### 2. 报名截止时间

- **全国赛报名截止**：5月31日（以2025年为例）[citation:2]
- **各高校校内报名**：各校不同，多在3月—5月，请关注本校具体通知
