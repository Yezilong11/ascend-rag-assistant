# 全国大学生机器人大赛（ROBOTAC）竞赛规则

## 一、竞赛简介

全国大学生机器人大赛（ROBOTAC）是由中华国际科学交流基金会、全国大学生机器人大赛组委会主办，北京深蓝智能机器人研究院联合主办，中国高等教育学会、中国工程院战略咨询中心指导，教育部应用技术大学（学院）联盟、中国教育电视台支持的全国性大学生机器人竞赛。ROBOTAC是中国原创的国家级机器人科技竞技赛事，自2015年起已成功举办多届，是中国高等教育学会学科竞赛排行榜赛事。

ROBOTAC名称来源于ROBOT（机器人）+TACTIC（策略/战术）。赛事秉承“以赛促教、以赛促学”的理念，以机器人设计制作为基础，多足仿生、轮式运动等机器人在复杂地形上开展战术配合，融合了电竞游戏中的对抗元素，是对抗型机器人的第一赛事。该赛事不仅考验参赛选手的机器人设计制作、编程调试、操控等工程实践能力，也考验选手的战术策略、团队配合等综合素质。

第二十五届全国大学生机器人大赛ROBOTAC于2025年11月启动报名，全国总决赛于2026年7月至8月举行。

## 三、参赛资格与要求

### 1. 参赛对象

| 项目 | 要求 |
|------|------|
| **学历要求** | 全国高校在校全日制学生（研究生、本科生、专科生）均可报名参赛 |
| **专业范围** | 机器人工程、机械工程、电子信息、自动化、计算机等相关专业，鼓励跨学科组队 |

### 2. 团队组成要求

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每支参赛队伍总人数不限，但上场队伍限制为1名指导教师和5名学生 |
| **指导教师与学生比例** | 指导教师与学生比例不得高于1:4 |
| **队长要求** | 每队需指定1名学生作为队长，负责团队管理和赛事联络 |
| **组队范围** | 可跨专业、跨年级组队，但不得跨校组队 |
| **参赛限制** | 每位学生只能参加一支队伍 |

### 3. 报名要求

- 报名时间通常为前一年的11月启动
- 需通过官方网站报名系统完成注册
- 报名信息须真实准确，不得冒用他人身份

## 四、竞赛赛项设置

第二十五届全国大学生机器人大赛ROBOTAC设置多个赛项，各赛项独立进行比赛和评奖：

### 1. 对抗赛赛项

| 赛项 | 说明 |
|------|------|
| **“深蓝使命”对抗赛** | ROBOTAC核心对抗赛项，红蓝双方机器人在复杂地形上开展战术配合与对抗 |
| **人形功夫搏击赛** | 人形机器人1V1搏击对抗，考验机器人的平衡性、稳定性和攻击能力 |

### 2. 挑战赛赛项

| 赛项 | 说明 |
|------|------|
| **能量球灌篮挑战赛** | 机器人通过自主或遥控方式，将能量球投入篮筐，考验机器人的精准控制和任务执行能力 |
| **足式机器人挑战赛** | 多足仿生机器人在复杂地形上的竞速和越障挑战 |
| **侦察任务挑战赛** | 机器人完成特定区域的侦察任务，考验机器人的自主导航和环境感知能力 |

### 3. 设计赛赛项

| 赛项 | 说明 |
|------|------|
| **三维数字设计赛** | 围绕ROBOTAC主题进行机器人三维模型设计和创意表达，考察学生的数字建模和设计创新能力 |

## 五、赛制流程

### 1. 整体赛制

比赛分为校内赛、区域赛、全国赛三级赛制：

| 层级 | 说明 |
|------|------|
| **校内选拔赛** | 各高校自行组织，选拔优秀队伍参加区域赛 |
| **区域赛** | 以省或大区为单位组织，优胜队伍晋级全国总决赛 |
| **全国总决赛** | 线下集中比赛，评选出各赛项奖项 |

### 2. 第二十五届时间安排

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **报名启动** | 2025年11月 | 官网开放报名系统 |
| **校内选拔赛** | 2026年3月—5月 | 各高校自行组织 |
| **区域赛** | 2026年5月—6月 | 各省或大区组织 |
| **全国总决赛** | 2026年7月—8月 | 线下集中比赛 |

### 3. 各赛项比赛形式

#### （1）对抗赛
- 红蓝双方机器人团队在指定场地进行对抗
- 每场比赛分为若干回合，每回合限定时间
- 根据得分或胜负判定晋级

#### （2）挑战赛
- 参赛队伍在规定时间内完成指定任务
- 根据任务完成度、完成时间、技术表现综合评分

#### （3）设计赛
- 提交三维数字设计作品及相关说明文档
- 评审专家对作品进行线上或线下评审

## 六、比赛规则

### 1. 通用规则

| 规则项 | 说明 |
|------|------|
| **机器人规格** | 各赛项对机器人的尺寸、重量、动力等有明确规定，详见各赛项规则文件 |
| **安全要求** | 机器人设计必须符合安全规范，不得使用危险材料或装置 |
| **公平竞赛** | 严禁任何形式的作弊、违规改装、恶意干扰对手等行为 |
| **服从裁判** | 参赛队伍必须服从裁判判罚，如有异议可通过规定渠道申诉 |

### 2. 对抗赛规则要点

- 机器人需具备自主或遥控功能
- 比赛场地设有障碍、功能区等特殊地形
- 得分方式包括但不限于：到达目标区域、完成特定动作、击倒对方机器人等
- 违规行为将受到警告、扣分或取消比赛资格等处罚

### 3. 挑战赛规则要点

- 参赛队伍需在规定时间内完成赛前调试
- 比赛过程中不得更换机器人核心部件
- 任务完成情况由裁判或自动检测系统判定

### 4. 设计赛规则要点

- 作品须为原创，不得侵犯他人知识产权
- 作品需围绕ROBOTAC主题进行创作
- 提交材料包括三维模型文件、设计说明、效果图等

## 七、评审标准

### 1. 对抗赛/挑战赛评审维度

| 评审维度 | 说明 |
|------|------|
| **技术实现** | 机器人设计的技术先进性和实现质量 |
| **性能表现** | 机器人在比赛中的稳定性、速度和准确性 |
| **战术策略** | 团队配合、战术运用和临场应变能力 |
| **规则遵守** | 对比赛规则的遵守情况和安全规范执行 |
| **创新性** | 机器人设计和技术应用的创新程度 |

### 2. 设计赛评审维度

| 评审维度 | 说明 |
|------|------|
| **创新性** | 设计理念的创新程度和独特性 |
| **技术性** | 三维建模技术的熟练程度和技术难度 |
| **艺术性** | 作品的视觉效果和艺术表现力 |
| **主题契合度** | 作品与ROBOTAC主题的契合程度 |
| **规范性** | 提交材料的完整性和规范性 |

## 十、报名方式

### 1. 报名流程

1. **校内组队**：按赛项要求组队，确定指导教师和队长
2. **官网注册**：登录ROBOTAC官方网站（https://www.robotac.cn）进行注册报名
3. **信息填写**：填写团队信息、参赛赛项、机器人方案等
4. **提交审核**：提交报名信息，等待组委会审核
5. **校内备案**：按各校要求完成校内报名备案

### 2. 报名注意事项

- **报名时间**：通常为前一年的11月启动，具体以官网通知为准
- **信息真实性**：报名信息须真实准确，否则取消参赛资格
- **材料提交**：部分赛项需提交设计方案等材料

## 十一、学术诚信与监督

### 1. 学术诚信要求

- 参赛作品必须是参赛者的原创成果，未侵犯任何他人的知识产权
- 不得抄袭、剽窃他人成果
- 不得使用往届获奖作品重复参赛

### 2. 违规处理

| 违规行为 | 处理方式 |
|------|------|
| 抄袭、剽窃 | 取消参赛资格，追回已颁奖项，并在官网通报 |
| 违规改装 | 取消比赛成绩 |
| 恶意干扰对手 | 取消比赛资格 |
| 信息造假 | 取消参赛资格，通报所在学校 |

### 3. 申诉机制

参赛队伍对比赛结果有异议，可在规定时间内通过官方渠道提交申诉，由仲裁委员会进行处理。
