# 全国大学生结构设计竞赛竞赛规则

## 一、竞赛简介

全国大学生结构设计竞赛是经教育部、财政部联合批准（教高函〔2007〕30号）的全国性九大学科竞赛资助项目之一，由浙江大学于2005年发起，现由中国高等教育学会工程教育专业委员会、高等学校土木工程学科专业指导委员会、中国土木工程学会教育工作委员会、教育部科学技术委员会环境与土木水利学部共同主办并获社会企业资助协办，各高校轮流承办。该竞赛被誉为“土木建筑工程皇冠上璀璨的明珠” [citation:1][citation:3]。

竞赛旨在培养大学生创新意识、合作精神和工程实践能力，为高等学校开展创新教育和实践教学改革、加强高校与企业之间联系、推动学科创新活动起到积极示范作用。每年举办一届，采用省（市）分区赛与全国总决赛两级赛制 [citation:1]。

第十九届全国大学生结构设计竞赛总决赛定于2026年10月14日至18日在内蒙古科技大学举行 [citation:4][citation:7]。

## 二、组织机构

### 1. 主办单位

- **主办单位**：中国高等教育学会工程教育专业委员会、高等学校土木工程学科专业指导委员会、中国土木工程学会教育工作委员会、教育部科学技术委员会环境与土木水利学部
- **秘书处**：设在浙江大学
- **第十九届总决赛承办单位**：内蒙古科技大学

### 2. 组织架构

| 机构 | 职责 |
|------|------|
| **全国大学生结构设计竞赛委员会** | 修改和审定竞赛章程；审定和聘任专家委员会组成人员；确定获奖比例原则；确定全国竞赛承办单位；处理竞赛中的有关重大事项 [citation:1] |
| **专家委员会** | 审定竞赛规则和实施细则；评审参赛作品；确定获奖作品等级；点评参赛作品；处理竞赛过程中的异议问题 [citation:1] |
| **组织委员会** | 由承办单位推荐有关人员组成，负责竞赛的筹备和组织工作；负责组织命题工作，制定竞赛实施细则；负责具体组织实施竞赛的全过程；负责筹集竞赛所需的经费 [citation:1] |

## 三、参赛资格与要求

### 1. 参赛对象

| 项目 | 要求 |
|------|------|
| **学历要求** | 全国各类高等院校在籍的全日制本科生、专科生 [citation:1] |
| **专业范围** | 土木工程及相关专业，但鼓励跨专业组队，部分高校校赛允许所有专业学生参加 [citation:2][citation:5][citation:10] |

### 2. 团队组成要求

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每个参赛队由**3名学生**组成 [citation:1][citation:2][citation:5] |
| **组队范围** | 参赛学生必须属于同一所高校，不得跨校组队 [citation:1] |
| **指导教师** | 每队可指定1-2名指导教师（3名及以上署名指导组），指导教师必须是参赛队所属高校在职教师，有责任保证参赛成员身份的真实性 [citation:1] |

## 四、赛制流程

竞赛分省（市）分区赛和全国总决赛两个阶段进行。

### 1. 第十九届时间安排

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **各省（市）分区赛** | 2026年4月至7月 | 各省（市、自治区）竞赛秘书处组织完成分区赛 [citation:4][citation:7] |
| **全国总决赛名额分配** | 2026年8月10日前 | 全国竞赛秘书处确定各省参加总决赛名额 [citation:4] |
| **参赛高校名单提交** | 2026年8月18日前 | 各省按成绩排序确定参加总决赛高校名单并提交 [citation:4] |
| **参赛高校名单公布** | 2026年8月25日 | 全国竞赛秘书处汇总、审核和正式公布参赛高校名单 [citation:4] |
| **总决赛通知发布** | 2026年9月6日前 | 承办高校起草并发布总决赛通知 [citation:4] |
| **全国总决赛** | 2026年10月14日至18日 | 内蒙古科技大学举行 [citation:4][citation:7] |

### 2. 分区赛组织要求

1. 省（市）分区赛一般由省（市）教育行政部门或委托相关学会等部门主办，设分区赛组委会秘书处，高校轮流承办 [citation:1]
2. 未举办过省（市）分区赛的，由秘书处指定高校组织分区赛选拔推荐参赛高校。从2018年起原则上均要求须通过省（市）分区赛方式选拔参加全国总决赛 [citation:1]
3. 各省（市）分区赛必须在完成后，上报赛区工作总结及评审结果等，由全国竞赛秘书处按总决赛名额分配原则下达推荐名额 [citation:1]

### 3. 全国总决赛参赛资格

全国总决赛一般由以下高校参赛 [citation:1]：
- 全国竞赛发起高校及承办过全国竞赛的高校
- 当年承办各省（市）分区赛的高校
- 各省（市）分区赛推荐的高校
- 适当邀请部分境内外高校

参赛高校总数一般控制在100-120所 [citation:1]。参加全国总决赛的高校推荐1个参赛队，当年承办全国总决赛的高校可推荐2个参赛队 [citation:1]。

## 五、竞赛形式与内容

### 1. 竞赛方式

全国总决赛一般采用提前公布题目，在同一时间、地点，使用统一材料、工具制作和统一设备测试等方式，也可视命题形式采用其他竞赛方式。省（市）分区赛可根据实际情况，参照全国总决赛方式或采取其他竞赛方式 [citation:1]。

### 2. 竞赛过程

竞赛过程包括参赛报名、提交方案、开幕式、现场制作模型、陈述答辩、加载测试、专家点评和闭幕式（颁奖仪式）等，参赛队必须参与完成上述全过程，方可取得参赛成绩 [citation:1]。

### 3. 模型制作材料与工具

竞赛按照统一规定提供的制作材料、工具和测试仪器，避免由于规定之外模型竹材和工具及测试设备所引起的不公平现象 [citation:4]。以洛阳理工学院校赛为例 [citation:10]：

**材料**：
- 竹皮：0.5mm厚2张，0.35mm厚2张，0.2mm厚2张
- 粘结材料：502胶5瓶，热熔胶棒3根

**工具**：
- 热熔胶枪一支
- 三角板一套（300mm等腰尺，330mm，30°直角尺）
- 钢直尺两个（1.0米长，0.5米长各一个）
- 游标卡尺一把，剪刀一把，美工刀三把
- 砂纸八张（180目和320目各四张）
- 铅笔三支，橡皮一个，水口钳两把，T形尺一个，镊子二支

### 4. 赛题特点

历届赛题涵盖桥梁、塔式结构等类型，2023年赛题为“撞击荷载下变参数两跨四车道桥梁结构设计与制作”，2025年赛题涉及“乌篷船式模型结构设计与制作” [citation:3]。第十九届全国大学生结构设计竞赛题目已于2026年1月上旬正式发文公布，倡导各省自主命题组织分区赛 [citation:4]。

## 六、评审标准

### 1. 评审环节

竞赛评审包括方案设计与理论分析、模型制作效果、结构创新点、现场陈述与答辩、模型加载测试等环节 [citation:1]。

### 2. 评分标准示例（以洛阳理工学院校赛为例）[citation:10]

| 评分项 | 分值 | 说明 |
|------|:---:|------|
| 模型的结构计算、制作等说明书 | 10分 | 理论分析的完整性和科学性 |
| 模型制作质量及实用性 | 5分 | 制作工艺和实际应用潜力 |
| 参赛队的模型及设计介绍 | 5分 | 现场陈述的清晰度和逻辑性 |
| 回答评委提问及答辩情况 | 5分 | 答辩应变能力 |
| 加载成绩 | 75分 | 模型承受荷载的能力 |
| **总分** | **100分** | |

注：不同高校校赛评分标准略有差异，但加载成绩通常占总分的绝大部分。

## 七、奖项设置

### 1. 全国总决赛奖项

全国大学生结构设计竞赛设立等级奖、单项奖和优秀组织奖三类奖项 [citation:1]。

| 奖项类别 | 奖项名称 | 说明 |
|------|------|------|
| **等级奖** | 特等奖一项（可空缺） | 最高荣誉 |
| | 一等奖 | 获奖比例由竞赛委员会根据参赛规模和队数实际情况确定 |
| | 二等奖 | 同上 |
| | 三等奖 | 同上 |
| | 参赛奖 | 完成全部赛程的队伍 |
| **单项奖** | 最佳创意奖 | 一项 |
| | 最佳制作奖 | 一项 |
| **组织奖** | 优秀组织奖 | 若干项 |

对参赛获奖学生和单位，由全国大学生结构设计竞赛委员会颁发获奖证书和奖牌 [citation:1]。

### 2. 省级分区赛奖项

各省自行确定获奖比例，通常设一等奖、二等奖、三等奖。例如安徽科技学院校赛获奖比例为：一等奖10%、二等奖20%、三等奖30%，总体获奖比例在60%左右 [citation:9]。

### 3. 校级选拔赛奖项

各高校自行组织校内选拔赛，奖项设置比例不同。例如洛阳理工学院校赛按照参赛作品总数的5%、10%、20%、30%的比例设置特等奖、一等奖、二等奖和三等奖 [citation:10]。

## 九、学术诚信与纪律

### 1. 诚信要求

- 诚信参赛，服从裁判，重在参与，减少功利性 [citation:1]
- 严禁校与校之间、队与队之间和社会第三方机构提供方案与制作模型交流等现象 [citation:4]
- 参赛作品必须严格遵守《章程》、《实施细则》等各项规定，认真履行所签署的各项承诺 [citation:1]

### 2. 违规处理

- 对违反承诺及《章程》、《实施细则》的行为与作品，将取消其评奖资格 [citation:1]
- 全国和各省评审专家委员会全权负责对参赛作品的雷同、作弊、违规、违纪、违约、申诉和奖项设置调整等事项进行审核与综合分析，提出评判意见和酌情裁定 [citation:4]
- 对出现违纪行为并处理不力的高校，视情节可给予公开通报批评或取消其下一年度参赛评奖资格 [citation:1]
- 对于查处违纪行为严重不负责任的赛区，可按一定比例缩减下一年度该赛区推荐参加全国总决赛高校的数量 [citation:1]

### 3. 申诉处理

全国总决赛违纪事件由全国竞赛专家委员会和秘书处负责处理；各省（市）分区赛违纪事件由赛区组委会秘书处负责处理，并报全国竞赛秘书处备案 [citation:1]。
