# 全国大学生电子商务“创新、创意及创业”挑战赛（三创赛）竞赛规则

## 一、竞赛简介

全国大学生电子商务“创新、创意及创业”挑战赛（以下简称“三创赛”）是在2009年由教育部委托教育部高校电子商务类专业教学指导委员会主办的全国性在校大学生学科性竞赛。根据教育部、财政部（教高函〔2010〕13号）文件精神，三创赛是激发大学生兴趣与潜能，培养大学生创新意识、创意思维、创业能力以及团队协同实战精神的比赛[citation:3][citation:5][citation:7]。

大赛的目的是强化创新意识、引导创意思维、锻炼创业能力、倡导团队精神。大赛的价值是促进教学，促进实践，促进就业，促进创业，促进升学、促进育人[citation:2][citation:3][citation:5]。三创赛采用校赛、省赛和国赛三级竞赛体制，是纳入中国高等教育学会《全国普通高校大学生竞赛分析报告》的高水平赛事，在《2023全国普通高校大学生竞赛分析报告》84项赛事中排名第12位，在2024年全国高校大学生学科竞赛排行榜“创新创业类”赛事中排名第三[citation:5][citation:6][citation:7]。

从第十届三创赛开始，大赛主办单位由教育部高等学校电子商务类专业教学指导委员会转变为全国电子商务产教融合创新联盟和西安交通大学[citation:2][citation:6][citation:10]。第十六届三创赛于2025年10月启动，全国总决赛定于2026年7月下旬至8月上旬举行。

## 四、参赛资格与要求

### 1. 参赛对象

| 项目 | 要求 |
|------|------|
| **学历要求** | 经教育部批准设立的普通高等学校的全日制在校大学生（专科、本科、研究生均可，专业不限）[citation:2][citation:4][citation:5] |
| **教师参赛** | 高校教师既可以作为指导老师（在学生队中），也可以作为参赛选手（在混合队中做队长或队员）组成师生混合队参赛[citation:1][citation:3][citation:9] |
| **国外高校学生** | 需依托国内高校报名和参赛[citation:10] |

### 2. 组队方式

参赛选手有两种组队方式[citation:1][citation:3][citation:9]：

| 组队方式 | 说明 |
|----------|------|
| **学生队** | 学生作为队长，队长和队员须全部为全日制在校学生 |
| **混合队** | 高校教师作为队长，队员中学生数量必须多于教师 |

### 3. 团队组成要求

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每支参赛团队由3-5名学生组成，其中一名为队长[citation:1][citation:2][citation:3] |
| **指导教师** | 每个团队可以有0-2名高校指导老师，0-2名企业指导老师[citation:1][citation:2][citation:3] |
| **跨校组队** | 允许跨校组队，以队长所在学校为该队报名学校。与参赛团队的队长不在同一个学校的队员身份信息的真实性由队长负责[citation:1][citation:3][citation:4] |
| **参赛限制** | 参赛团队成员每人可以同期参加常规赛、实战赛两类比赛中的两个（不能是一类比赛中的两个），但不能是同一个项目。同一团队如果参加两个比赛，必须通过两个不同的邮箱号进行注册，系统会分别自动生成两个不同的团队ID号[citation:1][citation:2][citation:3] |

### 4. 参赛题目要求

| 项目 | 要求 |
|------|------|
| **作品名称** | 参赛作品名称不超出30个字符，团队名不能超过16个字符[citation:1][citation:2][citation:3] |
| **内容要求** | 参赛作品名称及内容应当充满正能量、符合主旋律，不能含有色情、暴力和低俗等内容，更不能与中华人民共和国法律相抵触[citation:1][citation:2][citation:3] |
| **题目来源** | 大赛题目来源可以为国内外企业、行业出题以及学生自拟题目等，大赛提倡不拘一格选题参赛[citation:3] |

### 5. 原创性与迭代创新要求

| 项目类型 | 要求 |
|----------|------|
| **首次参赛** | 本项目在报名时没有参加过任何公开比赛，并且从报名参加本届三创赛的校赛、省级赛直到参加国赛时也没有参加过其他任何公开比赛[citation:6] |
| **非首次参赛（迭代创新）** | 参加过以前的三创赛或者其他公开比赛的作品，在满足下列条件时还可以参赛：<br>（1）在参加本次比赛前对原参赛作品已经做了明显的再创新（迭代创新）<br>（2）该团队参赛时必须将原参赛作品作为附件提交<br>（3）对在原参赛作品基础上进行迭代创新的主要内容给予明确的说明（也作为附件提交）[citation:3][citation:5][citation:7] |
| **禁止性规定** | 参赛作品禁止抄袭；禁止使用已公开发表过的专利、著作或论文（或进行改造后）参赛；禁止使用AI生成式作品；禁止提交已被期刊录用的论文；禁止使用在全国性赛事中获奖或修改加工过的获奖作品参赛[citation:10] |
| **学术诚信** | 须遵守学术诚信原则，在比赛任一阶段或比赛后发现学术不端行为，大赛组委会有权撤销参赛资格、收回获奖证书并通报所在高校[citation:10] |

### 6. 匿名要求

为保证大赛公平性，所有提交作品在封皮和正文中不得出现学校及二级机构名称、学生姓名、指导教师姓名、资助机构等文档和图片信息。在比赛任一环节发现此类问题，相关作品取消获奖资格[citation:10]。

### 7. 作品所有权

参赛作品所有权归参赛团队所有，除特别说明外，大赛组委会及相关单位不拥有参赛作品所有权[citation:10]。

### 8. 减员申请

大赛全部结束前，团队可以做成员减员申请。团队在官网下载《团队减员申请表》，由第一高校指导老师、队长以及被减掉的队员或指导老师签字，经由校赛管理员审查无误后提交竞组委秘书处备案复核确认，最终由三创赛竞组委秘书处进行删减操作。系统限定团队学生数不得低于3人[citation:1][citation:5][citation:6]。

三创赛采用校级选拔赛、省级选拔赛、全国总决赛三级赛制，竞赛优秀的团队按规则依次晋级获得高一级赛事参赛资格，不能跨级参赛[citation:2][citation:3][citation:4]。

### 4. 各阶段比赛形式

#### （1）校级选拔赛
- 由各高校自行组织，形式多为材料网评+现场答辩[citation:6]
- 网评阶段直接评出二等奖，筛选出网评前30%（一般不超过20项）的团队进入答辩环节，评选出特等奖和一等奖[citation:6]
- 校赛奖项：设特等奖、一等奖、二等奖，特等奖不超过有效参赛团队数量的5%（可空缺），一等奖不超过25%，二等奖不超过35%[citation:3][citation:6]
- 晋级规则：根据省赛相关要求，推选一定数量的团队代表学校参加省级赛[citation:1]

#### （2）省级选拔赛
- 以省为单位组织，由各省赛组委会负责
- 形式：现场答辩
- 省赛奖项：设特等奖、一等奖、二等奖
- 晋级规则：根据省赛成绩推荐参加全国总决赛

#### （3）全国总决赛
- 线下举行，入围队伍进行现场答辩
- 评审专家现场评审，评选出全国特等奖、一等奖、二等奖

## 七、评审标准

### 1. 常规赛评分标准[citation:3]

| 评分项目（5项积分制） | 评分说明 | 分值 |
|----------------------|----------|------|
| **创新** | 项目具备了明确的创新点：新产品、新技术、新模式、新服务等至少有一个明确的创新点 | 0-25 |
| **创意** | 进行了较好的、创新性的项目商务策划和可行性分析。商务策划主要是对业务模式、营销模式、技术模式、财务支持等进行的设计。项目可行性分析主要是对经济、管理、技术、市场等方面的可行性分析 | 0-25 |
| **创业** | 开展了一定的实践活动，包括(但不限于)：创业的准备、注册公司或与公司合作、电商营销、经营效果等，并需要提供相应的佐证材料 | 0-25 |
| **演讲** | 团队组织合理、分工合作、配合得当；服装整洁，举止文明，表达清楚；有问必答，回答合理 | 0-15 |
| **文案** | 提交的文案和演讲PPT逻辑结构合理，内容介绍完整、严谨，文字、图表清晰通顺，附录充实 | 0-10 |
| **得分合计** | | **100分** |

## 九、报名方式

### 1. 报名流程

1. **官网注册**：由团队学生队长代表参赛团队在三创赛官网（http://www.3chuang.net/）统一注册[citation:1][citation:2][citation:3]

2. **答题测试**：在注册时，队长要按照系统提示，做参赛团队重要规则（第十六届三创赛规则的第四十八条到第五十四条）的答题测试，只有回答正确（通过了测试）的团队，才能完成正式注册[citation:1][citation:2][citation:3]

3. **填写信息**：队长须准确填写基本信息，选择所在省份及学校，填写参赛队员信息、高校指导老师信息、企业指导老师信息、参赛作品名、作品摘要等信息，并对信息真实性负责[citation:7]

4. **添加成员**：通过官网“团队登录”模块登录团队账号，选择“成员管理”模块，点击“添加成员”进行团队成员添加[citation:1]

5. **签署承诺**：所有团队成员须仔细阅读大赛规则，注册时同意并遵守大赛规则。官网报名时自动生成《参赛团队承诺书》《团队高校指导老师承诺书》，参加实战赛的团队还需生成《实战赛参赛学生知情书》，打印后由团队成员、指导教师签字扫描为PDF文档后上传至官网[citation:1][citation:6]

6. **学校审核**：参赛团队须经本校校赛负责人审核通过后方为报名成功[citation:1][citation:5][citation:6]

7. **校内备案**：按各校要求完成校内报名，加入学校竞赛QQ群，提交校内报名材料

### 2. 报名截止时间

## 十一、学术诚信与监督

### 1. 学术诚信要求

- 参赛作品必须是参赛者的原创作品，未侵犯任何他人的任何知识产权[citation:7][citation:10]
- 参赛作品禁止抄袭；禁止使用已公开发表过的专利、著作或论文（或进行改造后）参赛；禁止使用AI生成式作品；禁止提交已被期刊录用的论文[citation:10]
- 所有参赛学生须签署《参赛承诺书》[citation:10]

### 2. 违规处理

| 违规行为 | 处理方式 |
|----------|----------|
| 抄袭、剽窃 | 取消参赛资格并通报学校[citation:10] |
| 使用往届获奖项目未说明迭代创新 | 取消参赛资格 |
| 信息不一致 | 取消团队比赛成绩[citation:6] |
| 匿名要求违规 | 相关作品取消获奖资格[citation:10] |

### 3. 监督机制

大赛组委会本着公平、公正、公开的原则，对每一件参赛作品进行评比[citation:2]。在比赛任一阶段或比赛后发现学术不端行为，大赛组委会有权撤销参赛资格、收回获奖证书并通报所在高校[citation:10]。
