# 全国大学生数学建模竞赛竞赛规则

## 一、竞赛简介

全国大学生数学建模竞赛（英文简称CUMCM）是由中国工业与应用数学学会主办的面向全国大学生的群众性科技活动，创办于1992年，每年一届，是首批列入《全国普通高校大学生竞赛分析报告》竞赛目录的19项竞赛之一[citation:9]。

竞赛以“创新意识、团队精神、重在参与、公平竞争”为宗旨，旨在激励学生学习数学的积极性，提高学生建立数学模型和运用计算机技术解决实际问题的综合能力，鼓励广大学生踊跃参加课外科技活动，开拓知识面，培养创造精神及合作意识，推动大学数学教学体系、教学内容和方法的改革[citation:7][citation:8]。

2025年，有来自国内外1837所院校的68311个队、超过20万大学生报名参赛，是目前我国乃至世界上规模最大的数学建模竞赛[citation:6][citation:7][citation:9]。

## 二、组织机构

- **主办单位**：中国工业与应用数学学会
- **冠名赞助商**：高等教育出版社
- **赞助商**：北京迈斯沃克软件有限公司
- **合作网站**：中国大学生在线网站
- **全国组委会**：全国大学生数学建模竞赛组织委员会
- **竞赛官网**：http://www.mcm.edu.cn/

## 三、竞赛内容

### 1. 题目来源

竞赛题目一般来源于科学与工程技术、人文与社会科学（含经济管理）等领域经过适当简化加工的实际问题[citation:7][citation:8][citation:10]。题目有较大的灵活性供参赛者发挥其创造能力，不要求参赛者预先掌握深入的专门知识，只需要学过高等学校的数学基础课程[citation:8][citation:10]。

### 2. 解题要求

参赛者应根据题目要求，完成一篇包括以下内容的论文（即答卷）[citation:7][citation:8]：
- 模型的假设
- 模型的建立和求解
- 计算方法的设计和计算机实现
- 结果的分析和检验
- 模型的改进等方面

### 3. 评审标准

竞赛评奖以以下要素为主要标准[citation:7][citation:8]：
- 假设的合理性
- 建模的创造性
- 结果的正确性
- 文字表述的清晰程度

## 四、参赛资格与要求

### 1. 参赛对象

- **学历要求**：全国普通高等学校全日制在校学生
- **组别划分**：竞赛分本科、专科两组进行，本科生参加本科组竞赛，专科生参加专科组竞赛（也可参加本科组竞赛）
- **禁止参赛**：研究生不得参加[citation:7][citation:8]

### 2. 团队组成

| 项目 | 要求 |
|------|------|
| **团队人数** | 每队不超过3名学生 |
| **学校要求** | 参赛队员须属于同一所学校，不允许跨校组队[citation:7][citation:8] |
| **专业限制** | 无专业限制 |

### 3. 指导教师要求

| 项目 | 要求 |
|------|------|
| **人数限制** | 每队最多可设一名指导教师或教师组 |
| **职责范围** | 从事赛前辅导和参赛的组织工作[citation:7] |
| **禁止行为** | 竞赛期间不得进行指导或参与讨论[citation:1][citation:2][citation:7] |

## 五、竞赛规则（2026年修订稿）

根据《全国大学生数学建模竞赛参赛规则（2026年修订稿）》，竞赛规则如下[citation:1][citation:2]：

### 1. 基本规定

指导教师和参赛学生必须严格遵守《全国大学生数学建模竞赛章程》和《全国大学生数学建模竞赛论文格式规范》中的各项规定，认真履行所签署的《全国大学生数学建模竞赛承诺书》中的各项承诺。对违反承诺及不符合要求的论文，将无条件取消评奖资格[citation:1][citation:2]。

### 2. 学校责任

参赛学校有责任结合本校的学风建设，指导和监督参赛学生与指导教师严格遵守竞赛纪律，支持和配合全国组委会及各赛区组委会对违规违纪行为的调查与处理[citation:1][citation:2]。

### 3. 指导教师纪律

指导教师主要从事赛前辅导和参赛的组织工作，并有责任教育和监督参赛学生严格遵守竞赛纪律。指导教师在竞赛期间不得通过任何方式对参赛学生进行任何形式的指导，包括[citation:1][citation:2]：
- 向学生解释赛题或提供选题、解题建议
- 提供参考资料
- 修改论文或提供修改建议

否则一律按违纪处理。对出现违纪行为的参赛队的指导教师，全国组委会两年内将不受理该指导教师指导学生参加本竞赛的报名申请[citation:1][citation:2]。

### 4. 学术诚信要求

抄袭是严重违反竞赛纪律的行为。参赛论文引用他人的研究成果或其他任何公开的资料（包括网上查到的资料），必须按照规定的参考文献的表述方式在正文中加以引用，并在参考文献中明确列出，且不得大篇幅照抄，否则视为学术不端行为和违反竞赛纪律，相应的参赛队将被无条件取消评奖资格[citation:1][citation:2]。

### 5. 独立完成要求

竞赛期间，各参赛队必须独立完成赛题解答。严禁参赛队员以任何方式与队外任何人（包括指导教师）交流、讨论任何与赛题有关的问题。参赛队员无论主动参与讨论，还是被动接收讨论信息，均视为严重违反竞赛纪律[citation:1][citation:2]。

竞赛期间，参赛队员不得在任何交流平台（包括但不仅限于“贴吧”、QQ群、微信群、网络直播间、知乎、小红书、CSDN、GitHub等）浏览、发布或讨论与赛题相关的内容，否则一律视为严重违反竞赛纪律。严重违纪的参赛队将被无条件取消评奖资格，并视情节给予相应处理[citation:1][citation:2]。

### 6. 人工智能工具使用规定

参赛队员可以使用人工智能（AI）工具作为辅助，但各参赛队必须对所提交作品的原创性、真实性和准确性负全部责任。参赛队须遵守《全国大学生数学建模竞赛人工智能工具使用规定》[citation:1][citation:2]。

### 7. 资源使用规范

竞赛期间参赛队员可以使用各种图书资料（包括互联网上的公开资料）、计算机和软件，但每个参赛队必须独立完成赛题解答[citation:7][citation:8]。

## 六、赛制流程

### 1. 时间安排

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **校级培训** | 上年12月—次年8月 | 各高校自行组织培训[citation:7] |
| **校赛选拔** | 次年5月—6月 | 各高校自行组织选拔[citation:7] |
| **暑期集训** | 次年7月—8月 | 入选队伍集中强化培训[citation:7] |
| **全国竞赛** | 每年9月中旬（通常为周四20:00至周日24:00，共74-76小时） | 全国统一时间[citation:9] |

### 2. 竞赛形式

- **竞赛方式**：采取通讯竞赛方式，全国统一竞赛题目[citation:7][citation:8]
- **题目公布**：竞赛开始后，赛题将公布在指定的网址供参赛队下载[citation:7][citation:8]
- **答卷提交**：参赛队在规定时间内完成答卷，并按要求准时交卷[citation:7][citation:8]

## 七、评审与奖项设置

### 1. 评审程序

| 层级 | 责任主体 | 说明 |
|------|----------|------|
| **赛区评阅** | 各赛区评阅专家组 | 严格按照《章程》和《规范》要求对违纪行为把关[citation:1][citation:2] |
| **全国评阅** | 全国评阅专家组 | 对赛区推荐的论文进行终评[citation:1][citation:2] |

### 2. 奖项设置

| 奖项 | 获奖比例 | 说明 |
|------|----------|------|
| **全国一等奖** | 约1-2% | 由全国组委会颁发证书 |
| **全国二等奖** | 约6-8% | 由全国组委会颁发证书 |
| **赛区奖项** | 各省比例不同 | 由各赛区组委会颁发证书 |

### 3. 违纪处理

- 对于查处违纪行为高度负责的赛区，全国组委会将予以表彰，在评选优秀组织工作奖时优先考虑[citation:1][citation:2]
- 对于查处违纪行为严重不负责任的赛区，将按一定比例缩减该赛区下一年度送全国评阅的论文数量[citation:1][citation:2]
- 对严重的、典型的违纪行为，全国组委会（或赛区组委会）将以适当的方式给予公开通报批评。所属学校须对当事人进行批评教育并作出相应处理，并提出整改方案[citation:1][citation:2]

## 八、报名方式

### 1. 报名流程

1. **校内报名**：关注所在高校教务处或相关学院发布的通知，加入学校竞赛QQ群
2. **组队备案**：完成组队后向学校报备
3. **官网注册**：通过指导教师在全国大学生数学建模竞赛官网完成注册
4. **缴费确认**：部分学校统一处理报名事宜

### 2. 报名时间

- **校内选拔报名**：各高校时间不同，通常在每年3月-6月
- **全国赛正式报名**：每年6月-8月（具体以官网通知为准）

## 九、论文格式要求

根据《全国大学生数学建模竞赛论文格式规范》[citation:1][citation:2]：

| 项目 | 要求 |
|------|------|
| **文件格式** | PDF格式 |
| **语言** | 中文 |
| **命名规则** | 按赛区组委会规定格式命名 |
| **页数限制** | 通常不超过20页（含附录） |
| **引用规范** | 参考文献必须在正文中明确标注 |
