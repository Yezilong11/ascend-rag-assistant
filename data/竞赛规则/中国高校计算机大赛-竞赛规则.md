# 中国高校计算机大赛（C4）竞赛规则

## 一、竞赛简介

中国高校计算机大赛（China Collegiate Computing Contest，简称C4）是由教育部高等学校计算机类专业教学指导委员会、教育部高等学校软件工程专业教学指导委员会、教育部高等学校大学计算机课程教学指导委员会、全国高等学校计算机教育研究会联合创办于2016年的一项全国性学科竞赛[citation:2]。大赛旨在促进高校计算机课程教学内容和教学方法改革，强化学生创新意识，提升学生计算机问题求解水平，增强学生计算机应用能力，培养团队合作精神，促进校际交流，丰富校园学术气氛[citation:6]。

大赛设立以来，始终坚持“服务教学、推动教改、促进融合、引领创新”的办赛理念，产生广泛影响[citation:6]。多个赛项已入选中国高等教育学会“全国普通高校大学生竞赛排行榜”，被各高校认定为本科生推免（推荐免试攻读研究生）的科技竞赛加分项目[citation:2]。2026年第十一届“中国高校计算机大赛”继续由全国高等学校计算机教育研究会主办[citation:2]。

## 二、组织机构

### 1. 主办单位

- **主办单位**：全国高等学校计算机教育研究会[citation:1][citation:2]
- **创办单位**：教育部高等学校计算机类专业教学指导委员会、教育部高等学校软件工程专业教学指导委员会、教育部高等学校大学计算机课程教学指导委员会、全国高等学校计算机教育研究会[citation:2]

### 2. 组织架构

各赛项分别设立组织委员会和评审委员会：

| 机构 | 职责 |
|------|------|
| **指导委员会** | 由全国高校计算机教育研究会、计算机类专业教指委、电子学会、支持企业、承办单位有关领导和专家组成，负责决定竞赛的重要事项并指导分/省赛区预赛和全国总决赛的相关工作[citation:1] |
| **组织委员会** | 作为大赛的组织机构全面负责大赛组织及事务性工作[citation:1] |
| **评审委员会** | 由嵌入式、人工智能、物联网领域的权威人士、专家学者组成，具体负责全国总决赛的评审工作[citation:1] |
| **分/省赛区竞赛组织委员会** | 由所在省（自治区）、直辖市教委（厅、局）、承办学校、相关学会委员及高校领导与专家、企事业代表组成，负责本赛区的竞赛组织领导工作[citation:1] |

## 四、嵌入式设计赛竞赛规则

### 1. 参赛条件

| 项目 | 要求 |
|------|------|
| **参赛单位** | 以参赛高等院校为基本单位，由相关院（系）负责本校学生的参赛事宜[citation:1] |
| **参赛对象** | 具有正式学籍的全日制在校专科生、本科生、研究生[citation:1] |
| **队伍人数** | 每支队伍参赛队员1-3人[citation:1] |
| **指导教师** | 每支队伍参赛指导老师1-2人[citation:1] |
| **参赛限制** | 各高校总决赛参赛队伍数量不得超过5支[citation:1] |
| **队员变更** | 自报名至比赛期间，参赛队员不得随意更换。如发现顶替或更换，将取消参赛及评奖资格[citation:1] |

### 2. 作品要求

| 项目 | 要求 |
|------|------|
| **原创性** | 作品必须为原创，且不能在其它同类赛事中参评[citation:1] |
| **查重要求** | 设置查重环节，如果参赛作品与往年的参赛作品高度相似，组委会将取消该参赛作品今年的参赛资格[citation:1] |

### 3. 命题设置

本赛事采用开放式命题的形式，涉及内容可覆盖[citation:1]：
- 嵌入式、人工智能系统设计，硬件、软件、系统等
- 嵌入式、人工智能系统应用展示，AI机器人、智能交通、智能装备、智能制造、智能家居、工业应用、医疗卫生等领域
- 嵌入式AIoT应用，城市交通，医疗，港口物流，环境监测，多网融合等
- AI机器人，人型机器人、医疗机器人、看护机器人等

### 4. 大赛平台

## 五、网络技术挑战赛竞赛规则

### 1. 参赛条件

| 项目 | 要求 |
|------|------|
| **面向对象** | 高等学校计算机类、网络空间安全类、软件工程类、人工智能与智能制造类、电气信息类和其他相关专业本科学生与研究生[citation:2] |
| **队伍人数** | 不少于2名、不多于6名学生组成的团队[citation:2] |
| **组队要求** | 团队所有成员在报名时按对参赛作品的贡献度自行排序；一位学生不能同时担任某赛项两个参赛团队的队长[citation:2] |

| **指导教师** | 每支团队可有1至2名指导教师，允许有一名指导教师来自企业[citation:2] |
| **组别划分** | 竞赛分为本科生和研究生两个组别，以所有成员中的最高学历作为参赛团队分组的依据[citation:2] |

| | A-ICV | 专为“车联网与交通智能网联”单独设置[citation:2] |
| **攻关（B）系列** | B-EP1 | 未来网络的“智能体互联网创新攻关赛项”，包括行业知名企业或研究机构参与规划的专门赛项[citation:2] |

## 六、团体程序设计天梯赛竞赛规则

### 1. 竞赛目的

程序设计能力是大学生利用计算机分析问题、解决问题的重要基础能力。为了推进该能力的培养，同时培养学生的团队合作精神，提高其综合素质，丰富校园学术气氛，促进校际交流[citation:3][citation:4]。

### 2. 参赛条件

| 项目 | 要求 |
|------|------|
| **参赛对象** | 在校本科生，专业不限[citation:3] |
| **团队组成** | 每支参赛队由最多10名队员组成[citation:4] |
| **教练要求** | 每支参赛队必须有至少1名教练，教练必须是学校的正式教师[citation:4] |
| **参赛名额** | 每所高校报名参赛的队数不限，但只有成绩最好的3支队伍参与计分与评奖[citation:4] |

### 3. 竞赛内容

竞赛内容为计算机算法编程，涵盖数据结构、动态规划、字符串、数论、图论、搜索、计算几何等常见计算机编程基础算法[citation:8]。

竞赛题目分3个梯级[citation:8]：

| 梯级 | 题目数量 | 分值 | 说明 |
|------|----------|------|------|
| **基础级** | 8道题 | 100分 | 5分、10分、15分、20分的题各2道 |
| **进阶级** | 4道题 | 100分 | 每道题25分 |
| **登顶级** | 3道题 | 90分 | 每道题30分 |

### 4. 竞赛语言

竞赛编程语言包括C、C++、Java和Python[citation:3][citation:4][citation:10]。

### 5. 竞赛规则

| 项目 | 要求 |
|------|------|
| **竞赛时长** | 3小时[citation:4] |
| **参赛设备** | 参赛队员须自备一台笔记本电脑、手机支架以及竞赛所需的基本调试环境[citation:4] |
| **允许物品** | 仅可以使用无计算功能的铅笔或水笔，以及空白草稿纸若干张[citation:4] |
| **禁止物品** | 禁止携带任何文字性参考资料，以及任何可用计算机处理的电子设备，也不能携带任何通讯工具[citation:10] |
| **提交要求** | 参赛队员必须独立按照严格的输入输出要求提交每一题的解题程序[citation:8] |
| **监考要求** | 比赛平台开发有国内最严格的监考和防作弊软件，一人作弊取消全校成绩[citation:8] |

### 6. 比赛时间（第十一届天梯赛）

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **全国统一比赛** | 2026年4月18日 | 线上、线下同时举行[citation:4][citation:8] |

### 7. 奖项设置

| 奖项级别 | 获奖比例 | 说明 |
|------|----------|------|
| **校赛** | 一、二、三等奖分别为参赛队伍数的10％、20％、30％[citation:3] | 校内选拔赛 |
| **全国赛团队奖** | 根据竞赛规程确定 | 团队奖项 |
| **全国赛个人奖** | 对有效得分175分以上的个人设置 | 个人一、二、三等奖[citation:7] |

## 七、AIGC创新赛竞赛规则

### 1. 竞赛简介

第三届（2026年）“AIGC创新赛”为“中国高校计算机大赛”系列竞赛之一，由南开大学与vivo公司联合承办。该竞赛面向全国（含港澳台）高校在校学生，以vivo自研通用大模型矩阵为技术底座，助力AIGC应用创新和内容创作，携手青年开发者共同推动大模型前沿技术快速发展，实现AI普惠[citation:5]。

### 2. 赛道设置

| 赛道 | 参赛人数 | 指导教师 | 赛题内容 |
|------|----------|----------|----------|
| **应用赛道** | 不超过5人 | 1-2名（高校在职教师） | 聚焦移动终端的应用开发，要求学生将创意转化为可行的AI解决方案，并落地vivo终端设备[citation:5] |
| **创作赛道** | 不超过5人 | 至多1名（高校在职教师） | 聚焦AI内容创作，要求学生通过AIGC工具创作具有艺术性的作品。主题：“AI Phone——共创下一代智能手机”[citation:5] |

### 3. 参赛要求

| 项目 | 要求 |
|------|------|
| **参赛对象** | 全国高校在校学生，不限专业[citation:5] |
| **组队范围** | 可跨年级、跨专业、跨校和跨赛区自由组队[citation:5] |
| **参赛限制** | 每位学生只能报名一种赛道，且只能加入一支队伍[citation:5] |
| **作品限制** | 每支参赛队伍限定提交一份作品[citation:5] |
| **指导教师** | 同一名指导教师可以指导多个参赛队伍[citation:5] |

### 4. 赛题详情

**应用赛道**：参赛团队通过运用蓝心大模型等工具，围绕蓝心小V（AI助手）、AI OS体验，探索移动办公/学习、出行、影像等场景的创意创新开发，作品形态包括但不限于APP、智能体、快应用、插件等，并最终能够在vivo手机上运行[citation:5]。

*鼓励团队使用蓝心大模型，但非必须。允许团队使用三方模型与AI工具*[citation:5]。

**创作赛道**：请参赛者以“AI Phone——共创下一代智能手机”为题，设计一部完整的未来手机，或其中一个关键能力模块，用AIGC重新定义未来手机的形态、交互与体验[citation:5]。

## 八、通用参赛要求

### 1. 学术诚信要求

- 参赛作品必须是参赛者的原创作品，未侵犯任何他人的知识产权[citation:1]
- 嵌入式设计赛设置查重环节，如果参赛作品与往年的参赛作品高度相似，组委会将取消该参赛作品今年的参赛资格[citation:1]
- 团体程序设计天梯赛比赛平台开发有国内最严格的监考和防作弊软件，一人作弊取消全校成绩[citation:8]

### 2. 违规处理

| 违规行为 | 处理方式 |
|------|------|
| 抄袭、剽窃 | 取消参赛资格 |
| 顶替或更换队员 | 取消参赛及评奖资格[citation:1] |
| 作弊行为 | 依规严肃处理，同时作弊者将被列入校赛黑名单并禁赛[citation:10] |

### 3. 信息变更

- 嵌入式设计赛：报名期间不得随意修改、替换，分赛开赛前可进行报名信息变更[citation:1]
- 天梯赛：报名截止后，参赛团队及指导老师信息均不得变更
