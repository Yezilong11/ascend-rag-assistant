# 东南·中国建筑新人赛竞赛规则

## 一、竞赛简介

东南·中国建筑新人赛（简称“新人赛”）是由东南大学建筑学院、东南大学建筑设计研究院有限公司主办，《建筑学报》协办，面向全国各高校本科一年级至三年级建筑类专业学生的一项设计竞赛[citation:1]。该赛事自2009年开始举办，已历经十余届，是国内面向建筑学专业低年级本科生的重要赛事之一，也是检验高校基础设计教学水平的重要平台[citation:2]。

新人赛旨在为年轻鲜活的低年级设计者提供竞赛平台，鼓励他们展现创造性与合理性并存的设计思维，体现中国建筑学科的新生力量[citation:1]。赛事突出“自主、开放、交流”的特点，为建筑学学生作业展示与竞赛、各国建筑教育者提供了积极的交流平台[citation:1]。新人赛同时作为亚洲建筑新人赛的中国区预选赛，优胜者将有机会代表中国参加亚洲建筑新人赛总决赛[citation:2]。

## 三、参赛资格与要求

### 1. 参赛对象

| 项目 | 要求 |
|------|------|
| **学历要求** | 中国（含港澳台）各高校建筑学院（建筑系）三年级及以下在读本科生[citation:8] |
| **专业范围** | 建筑学专业为主，规划类或风景园林类专业学生亦可参赛，但投稿作品必须是建筑设计作业[citation:8] |
| **课程要求** | 参赛作品须为本科阶段一年级至三年级学习期间的建筑设计作业[citation:8] |
| **时效要求** | 作品必须为本教学年度（2025-2026学年）的课程设计作业，三年级同学只能提交第三学年作品，不得提交第一或第二学年作品[citation:8] |

### 2. 团队组成要求

| 项目 | 要求 |
|------|------|
| **队伍人数** | 可以小组形式参赛，设计者人数最多为两人[citation:5] |
| **组队限制** | 除非课程设计中为两人跨年级合作，不允许跨年级组队[citation:5] |
| **资格要求** | 两位参赛者都必须符合参赛条件（目前年级为大一至大三）[citation:5] |
| **姓名排序** | 设计者姓名排序先后请自行确定[citation:5] |
| **指导教师** | 指导教师人数不限[citation:5] |

### 3. 参赛限制

| 限制事项 | 说明 |
|------|------|
| **每人限投** | 每个参赛者只能提交一份参赛作品[citation:8] |
| **作品原创** | 不接收已经在其他竞赛中获奖的作品[citation:8] |
| **模型要求** | 作品需以实体模型为重要表现载体，不接受无实体模型作品。入围100强的作品需按要求修改并提交至少一张模型照片[citation:8] |

## 四、竞赛主题与命题

### 1. 命题方式

新人赛不设置统一的竞赛主题，以各校教学环节的设计任务书为依据[citation:8]。参赛者提交的作品应基于设计课作业成果，可进行一定的修改和完善。

### 2. 提交材料要求

| 材料 | 内容要求 |
|------|----------|
| **任务书** | 需提交设计课任务书，必须为本教学年度（2025-2026学年）作品[citation:8] |
| **图纸** | 展现设计理念、空间关系、技术表达等 |
| **模型照片** | 实体模型的照片，作为重要表现载体 |

## 五、赛制流程

新人赛分为三个阶段：海选（线上初评）、100进16强复赛（线下评选）、总决赛（线下答辩）[citation:4]。

### 1. 2025年赛事时间安排（参考）

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **报名及提交电子图纸** | 即日起—7月28日 | 登录新人赛官方网站，按提示填写个人信息并上传图纸[citation:3] |
| **海选评选** | 7月29日—8月4日 | 由各高校教师组成的评委团队进行线上匿名打分[citation:3] |
| **公布TOP100名单** | 8月初 | 在网站公布获奖作品名单，并公开入围前100名的作品[citation:3] |
| **第二轮提交** | 8月5日—9月19日 | 进入前100名的参赛者提交2-5张图纸（A2横板）及1-2张实体模型照片[citation:3] |
| **100进16强决赛** | 9月20日 | 评委线下投票，100强选手现场参与布展，评委现场为图纸打分[citation:3] |
| **总决赛** | 9月21日 | 16强选手现场答辩，现场产生前三获得者[citation:3] |

### 2. 各阶段详细规则

#### （1）第一阶段：海选（线上初评）

**提交内容**[citation:3]：
- 封面1张（尺寸800×600像素）
- 任务书1页
- 图纸4页
- 视频1个（如需要，2分钟以内，100M以下）

**图纸要求**[citation:3]：
- 每张图片大小不大于2MB
- 分辨率在4000×4000像素以内
- 支持JPEG格式和PNG格式
- 图纸尺寸自定

**匿名要求**：除了登录信息以外，图纸上不得出现任何与参赛学校或个人相关的信息，否则投稿作品作废。图纸中不得使用繁体字[citation:3]。

**评选方式**[citation:3]：
- 由各高校负责本科建筑设计教学的教师组成评委团队进行线上匿名打分
- 5分制，每个作品得分为三名评委分数的平均分
- 以此得分决定进入100强的参赛作品

#### （2）第二阶段：100进16强复赛（线下评选）

**提交内容**[citation:3]：
- 每位参赛者提交2-5张图纸（A2横板）
- 1-2张实体模型照片（A2横板）

**评选方式**[citation:3]：
- 评委线下投票
- 100强选手来到现场参与布展
- 评委在现场为图纸打分，选出16强

#### （3）第三阶段：总决赛（线下答辩）

**评选方式**[citation:3]：
- 16强选手现场答辩
- 评委根据设计理念、技术实现和创意表达进行提问[citation:1]
- 现场产生前三名获得者

## 六、作品要求

### 1. 图纸表达要求

| 项目 | 建议 |
|------|------|
| **讲一个好故事** | 编排一个具有节奏感的故事，让评委在浏览作品时能顺着思路充分理解设计意图[citation:3] |
| **评委体验** | 海选阶段的评审全部在线上举行，请以方便评委线上评图为出发点来编排设计成果。可在手机或电脑上打开自己的作品，检验在手机屏幕或电脑屏幕的尺度上是否仍然易于阅读[citation:3] |
| **封面设置** | 设计一个优秀的封面有助于给评委留下好的第一印象[citation:3] |
| **作品名称** | 不宜过长，建议保持在24个字以内，以保证浏览效果[citation:3] |

### 2. 图纸格式要求（海选阶段）

| 项目 | 要求 |
|------|------|
| **封面尺寸** | 800×600像素[citation:3] |
| **图纸大小** | 每张不大于2MB[citation:3] |
| **分辨率** | 4000×4000像素以内[citation:3] |
| **文件格式** | JPEG或PNG[citation:3] |
| **视频要求** | 2分钟以内，100M以下，MP4格式（如需要）[citation:3] |

### 3. 图纸格式要求（第二轮提交）

| 项目 | 要求 |
|------|------|
| **图纸规格** | A2横板[citation:3] |
| **图纸数量** | 2-5张[citation:3] |
| **模型照片** | 1-2张实体模型照片（A2横板）[citation:3] |

### 4. 图纸绘制形式

图纸可以是电脑出图，也可以是手绘出图。手绘图纸须扫描提交，文件具体要求与电脑绘制的图纸相同[citation:5]。

### 5. 原创性要求

- 参赛作品必须为原创，不得抄袭、剽窃他人成果
- 不得使用已获奖作品重复参赛
- 参赛作品应基于设计课作业成果，可进行一定的修改和完善[citation:8]

## 七、评审标准

### 1. 评审维度

根据赛事官方信息，评审标准注重以下几个方面[citation:2]：

| 评审维度 | 说明 |
|------|------|
| **创意概念** | 设计理念的创新性和独特性 |
| **设计逻辑** | 设计思路的清晰性和完整性 |
| **空间与场所契合度** | 设计对场地环境的回应和空间关系的处理 |
| **作品完整呈现** | 图纸表达的完整性和专业性 |

### 2. 评审流程

| 阶段 | 评审方式 | 评委构成 |

| **总决赛** | 现场答辩[citation:3] | 7位决赛评委[citation:1] |

## 九、参赛建议

为帮助参赛者取得更好的成绩，组委会建议[citation:3]：

| 建议 | 说明 |
|------|------|
| **讲一个好故事** | 编排一个具有节奏感的故事，让评委顺着思路充分理解设计意图 |
| **注重评委体验** | 以方便评委线上评图为出发点编排设计成果，确保在手机/电脑屏幕尺度上易于阅读 |
| **设计优秀封面** | 好的封面有助于给评委留下良好的第一印象 |
| **作品名称简洁** | 建议保持在24个字以内，保证浏览效果 |
| **提前上传作品** | 避免交图截止时间段出现网速过慢、上传困难等问题 |

- 参赛作品必须是参赛者的原创课程作业成果，不得抄袭、剽窃他人成果
- 不接收已经在其他竞赛中获奖的作品[citation:8]
- 每位参赛者只能提交一份参赛作品[citation:8]

### 2. 违规处理

| 违规行为 | 处理方式 |
|------|------|
| **图纸中出现个人信息** | 投稿作品作废[citation:3] |
| **使用繁体字** | 投稿作品作废[citation:3] |
| **抄袭、剽窃** | 取消参赛资格 |
| **一稿多投** | 取消参赛资格 |
