# 全国高校BIM毕业设计创新大赛竞赛规则

## 一、竞赛简介

全国高校BIM毕业设计创新大赛（现更名为“国际高校BIM毕业设计创新大赛”）是由中国土木工程学会建筑市场与招标投标研究分会、广联达科技股份有限公司主办的一项全国性学科竞赛[citation:1]。大赛作为全国规模最大、涵盖专业最多的高校土木建筑专业赛事，已连续多年入选中国高等教育学会《全国普通高校大学生竞赛排行榜》，是教育部官方认可的全国性大学生赛事之一，也是全国大学生建筑类专业比赛中BIM方向唯一入选赛事[citation:2][citation:5]。

大赛旨在贯彻落实国家“十四五”规划有关“加快数字化发展，建设数字中国”的战略部署，在数字技术迅猛发展的今天，面对我国建筑业产业数字化、智能化转型升级的关键时期，加快建筑行业数字化人才培养，将行业新技术、新需求与传统教学更好的融合，全面培养大学生的创新思维和科研能力，提高全国高校大学生对数字建筑的认知，搭建相互交流、学习、展示的平台，实现以赛促教、以赛促学、以赛促创[citation:1][citation:8]。

## 二、组织机构

- **指导单位**：中国高等教育学会[citation:8][citation:10]
- **主办单位**：
  - 中国土木工程学会建筑市场与招标投标研究分会
  - 广联达科技股份有限公司[citation:1][citation:2][citation:8]
- **承办单位**：东南大学、华南理工大学、北京交通大学、北京建筑大学等（每年根据实际情况确定）[citation:1]
- **协办单位**：中关村数字建筑绿色发展联盟等[citation:1]
- **支持单位**：同济大学、湖南大学、中南大学、长安大学、福州大学、广西大学、合肥工业大学、新疆大学、西安建筑科技大学等[citation:1]
- **竞赛官网**：https://gxbsxs.glodonedu.com/[citation:1][citation:3]

## 四、参赛资格与要求

### 1. 参赛对象

- **学历要求**：全国全日制本科、高职高专、中职院校，所有建筑类相关专业的在籍学生（含研究生）均可参赛[citation:1][citation:3][citation:8]
- **组别设置**：分设本科组和专科组（含中职）进行报名，本科组、专科组独立报名，独立评奖[citation:1][citation:3]
- **研究生限制**：同一团队内研究生不可超过2人（第十二届起）[citation:3]
- **年级要求**：报名不限年级[citation:1][citation:7]

### 2. 团队组成

| 项目 | 要求 |
|------|------|
| **参赛单位** | 以二级院系为参赛单位，可以跨院系组队，至少2名学生隶属于本参赛单位[citation:3] |
| **队伍组成** | 每支队伍由3-5名参赛学生和1-2名指导教师组成[citation:1][citation:3] |
| **模块选择** | 每支队伍限报1个通道，1个模块[citation:1][citation:3] |
| **参赛限制** | 同一名参赛学生限加入1支参赛队伍[citation:1][citation:3] |
| **指导教师** | 每名指导教师指导模块、队伍数量不限[citation:1][citation:3] |
| **单位限制** | 同一参赛单位每个模块限报2支参赛队伍[citation:1][citation:6] |

## 五、赛制流程

大赛分为晋级赛（含校园赛和海选赛）、全国总决赛和全国风采展示三个阶段[citation:3][citation:7]。

### 1. 时间安排（第十二届）

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **晋级赛阶段** | 2025年9月10日—2025年12月上旬 | 包含校园赛和海选赛[citation:3] |
| **总决赛阶段** | 2026年1月—5月 | 全国总决赛[citation:3] |
| **全国风采展示** | 2026年5月—6月 | 优秀作品展示[citation:7] |

### 2. 各阶段比赛形式

#### （1）晋级赛阶段

晋级赛分为校园赛和海选赛两种形式[citation:6]：

**校园赛**：
- 以二级院系为单位组织，总规模须≥15支团队，每个模块参赛队伍数量不限
- 实施完成可获得3个晋级总决赛名额，同一模块最多2个晋级名额
- 校园赛以统一出题，限定时间完成赛题的形式进行选拔，考试需使用“建筑云课院校版”完成组织[citation:6]

**海选赛**：
- 由主办方（广联达）进行统一组织
- 参赛队伍以二级院系为参赛单位进行报名，同一参赛单位每个模块限报2支参赛队伍
- 参赛队伍按海选赛要求，在比赛系统中完成题目作答
- 海选赛考试前将根据各模块报名团队数量分配各模块晋级名额，以各团队成绩排名晋级总决赛[citation:6]

#### （2）全国总决赛阶段

- **作品提交**：参赛团队根据所报竞赛模块在比赛官网上传竞赛作品，作品形式为项目案例成果，需要按照任务指导书的要求，创建并输出各模块要求的工程成果文件[citation:1][citation:8]
- **作品评审**：由大赛组委会组织评审专家对作品进行评审[citation:1][citation:8]
- **全国总决赛**：在全国网络竞赛阶段获得全国一等奖的团队入围全国总决赛，角逐全国特等奖[citation:1][citation:8]

#### （3）全国风采展示阶段

优秀作品进行展示和交流[citation:7]。

## 六、作品要求

### 1. 作品内容要求

参赛作品须按照任务指导书的要求，创建并输出各模块要求的工程成果文件，包括但不限于[citation:1][citation:8]：
- BIM模型文件
- 设计图纸
- 计算书
- 分析报告
- 动画演示
- 其他各模块要求的成果文件

### 2. 原创性要求

- 参赛作品应为参赛团队的原创作品，作品必须合法、真实、健康，并确认未侵犯任何他人的任何专利、著作权、商标权及其他知识产权[citation:1]
- 由各参赛团队指导老师负责严格把关，杜绝采用模仿、抄袭、代笔等形式的舞弊行为[citation:4]
- 抄袭、盗用、提供虚假材料或违反相关法律法规的，一经发现即刻取消参赛相关权利并自负一切法律责任[citation:1]

### 3. 图纸使用规定

| 规定类型 | 要求 |
|----------|------|
| **相同模块** | 参赛选用图纸不得雷同（除官方统一给定图纸外）[citation:4] |
| **不同模块** | 参赛选用图纸不得雷同（除A/B模块间图纸可重复外，A/B模块也不得与其他模块图纸重复）[citation:4] |
| **官方图纸** | 官方给定的图纸仅限该模块参赛使用[citation:4] |
| **往届作品** | 不得使用往届作品参与本届评选，否则取消参赛资格[citation:4] |
| **软件授权** | 使用的软件及图集须经授权，否则相关后果由参赛队伍自行承担[citation:4] |

## 七、评审标准

### 1. 评审维度

| 评审维度 | 说明 |
|----------|------|
| **作品完整性** | 是否按提交要求的格式、数量以及任务指导书中的具体要求完成相关内容[citation:4] |
| **技术应用** | BIM技术解决实际业务问题的能力[citation:4] |
| **创新性** | 作品的创新程度和独特性 |
| **规范性** | 成果文件的规范性和专业性 |

### 2. 评审方式

- 各模块单独进行评奖[citation:1][citation:8]
- 本科组和专科组（含中职）分别进行评奖[citation:1][citation:8]
- 每份作品将由多位BIM评委专家参与打分，最后取平均值为该作品的得分[citation:4]

## 十、报名方式

### 1. 报名时间（第十二届）

- **报名时间**：2025年9月10日10:00 — 2025年11月28日16:00[citation:3]
- **历届报名时间参考**：每年9月—次年2月[citation:5]

### 2. 报名流程

1. **组队准备**：按模块要求组队，确定指导教师
2. **官网注册**：登录大赛官方网站（https://gxbsxs.glodonedu.com/）进行注册报名[citation:1][citation:3]
3. **上传材料**：报名需上传《参赛同意表》或《参赛回执表》[citation:1][citation:3]
4. **校内备案**：按各校要求完成校内报名备案，加入学校竞赛QQ群
5. **审核确认**：报名信息审核通过后获得参赛资格

### 3. 报名注意事项

- 学生赛道各参赛团队以二级院系为参赛单位进行报名，请务必如实完整填写学校和二级院系名称，否则将审核不通过，影响参赛资格[citation:1][citation:7]
- 若院系同时报名参赛学生赛道本科组和学生赛道专科组，本科组与专科组分开报名[citation:1]
