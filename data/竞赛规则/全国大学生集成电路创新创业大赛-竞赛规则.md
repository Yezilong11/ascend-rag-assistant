# 全国大学生集成电路创新创业大赛竞赛规则

## 一、竞赛简介

全国大学生集成电路创新创业大赛（简称“集创赛”）是由工业和信息化部人才交流中心主办，面向全国所有集成电路相关专业在校生的全国性学科竞赛 [citation:1][citation:2]。大赛以服务产业发展需求为导向，以提升我国集成电路产业人才培养质量为目标，打造产学研用协同创新平台，将行业发展需求融入教学过程，提升在校大学生创新实践能力、工程素质以及团队协作精神，助力我国集成电路产业健康快速发展 [citation:1][citation:6]。

大赛汇聚全国高校，吸引优秀人才，通过产学协同创新，以竞赛促学习，以培训促提升，积聚创新项目，引导创业实践 [citation:6]。第十届全国大学生集成电路创新创业大赛于2026年1月至8月举办，全国总决赛定于2026年7月下旬举行 [citation:1][citation:2]。

## 二、组织机构

### 1. 主办与承办单位

- **主办单位**：工业和信息化部人才交流中心 [citation:1][citation:3]
- **联合承办单位（芯片应用和芯创成果赛项总决赛）**：中共无锡市滨湖区委、东南大学、江南大学 [citation:1]
- **协办单位**：IEEE中国代表处、中国科技发展基金会、北京电子学会、雄安新区未来芯片创新研究院 [citation:1]
- **支持单位**：中芯国际集成电路制造（上海）有限公司、冉谱微电子（上海）有限公司、赛氪、北京橙色云科技有限公司、《集成电路与嵌入式系统》期刊 [citation:1]
- **运营单位**：北京智芯国信科技有限公司 [citation:1]

### 2. 组织架构

| 机构 | 职责 |
|------|------|
| **大赛组委会** | 设在工业和信息化部人才交流中心，负责全国范围内的大赛组织工作 [citation:1] |
| **专家委员会** | 负责把握赛题方向、大赛章程、验收评审等工作。首席科学家由中国工程院吴汉明院士担任 [citation:1] |
| **技术委员会** | 协助开展产学人才培养工作，为参赛团队提供技术及职业发展指导 [citation:1] |
| **组委会秘书处** | 由主办方、院校代表、企业代表共同组成，负责大赛的整体组织工作 [citation:1] |

## 三、赛道与赛题设置

第十届大赛共分为4个大类，14个技术方向，34个企业命题 [citation:5][citation:6]。

### 1. 赛道设置

| 类别 | 技术方向 | 企业命题示例 |
|------|----------|--------------|
| **芯片与方案设计** | 模拟与混合信号芯片设计、射频与高速电路芯片设计、SoC设计、数字电路模块设计、半导体产业链设计创新 | 国家集创中心、芯海、青软晶尊、IEEE、法动、竞业达、龙芯中科、七星微、Robei、叩持、华大九天、同惠、北方华创、加速科技 |
| **芯片应用** | 处理器应用开发、FPGA应用开发、AI芯片应用开发、具身智能应用开发、光芯片应用开发 | 飞腾、紫光同创、中科亿海微、复旦微、算能、思特威、中科芯、华强x昇腾、雄芯院、曦智科技 |
| **能力实践** | 半导体测试实践、集成电路制造和封装实践、国产半导体全流程实践 | 信诺达、雨骤（恩捷伦®）、胜达克、曾益慧创、奥施特、紫光教育 |
| **芯创成果** | 集成电路芯创成果 | 芯片设计成果命题、芯片应用成果命题、产业链创新成果命题 [citation:5][citation:8] |

### 2. 赛题要求

- 所有赛题均规定了可以报名的队伍组别（A组或B组），只允许符合组别的参赛队报名 [citation:1][citation:4]
- 部分赛题仅限本科生参加，如“竞业达”“龙芯中科”“增益汇创”“雨骤杯”等企业命题 [citation:7]

## 四、参赛资格与要求

### 1. 参赛对象

| 项目 | 要求 |
|------|------|
| **专业范围** | 集成电路、微电子、电子科学与技术及相关专业（包括但不限于电子信息工程、通信工程、计算机科学与技术、自动化、数学与应用数学、信息与计算科学、物理相关专业等）的在校专科生、本科生、硕士研究生和博士研究生 [citation:1][citation:2][citation:5] |
| **组别划分** | 团队成员均是本科生及以下的参赛团队划入**A组**；团队成员中有一名或一名以上是研究生（硕士/博士）的参赛团队划入**B组** [citation:1][citation:4] |
| **身份确认** | 本科生身份确认以报名时状态为准 [citation:1][citation:7] |

### 2. 团队组成要求

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每个团队1-3人 [citation:1][citation:3] |
| **指导教师** | 每队指导教师1-2人 [citation:1][citation:2] |
| **组队范围** | 可跨校组队，报名表需要学校或学院盖章 [citation:1][citation:4] |
| **参赛限制** | 除集成电路芯创成果方向外，每位同学只能参加一个团队，每队可选择一个题目 [citation:1][citation:4] |
| **芯创成果特殊规定** | 为鼓励创新探索与跨方向实践，集成电路芯创成果方向独立报名，参赛选手无论是否选择其他题目，均可在该方向组建1支队伍参赛 [citation:1][citation:4] |

### 3. 调剂意向

报名时可填写“调剂意向赛题”，组委会将会根据报名阶段根据赛题参赛热度给出调剂建议并提醒对应参赛团队，组委会不会强制调剂参赛团队杯赛选择，报名截止后参赛团队不可中途更换至调剂意向赛题 [citation:7]。

## 五、赛制流程

大赛采用初赛 + 分赛区决赛 + 全国总决赛三级赛制 [citation:1][citation:5]。

### 1. 第十届时间安排

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **报名时间** | 2026年1月—3月31日 | 大赛官网注册报名，截止日期：2026年3月31日 [citation:1][citation:2] |
| **作品设计时间** | 2026年1月—5月 | 赛题软硬件申请及发放日程以各题目具体规定为准 [citation:5][citation:6] |
| **校内选拔赛（可选）** | 2026年3月—5月 | 各高校自行组织，校内选拔赛成绩不计入后续比赛结果 [citation:1][citation:6] |
| **初赛作品提交** | 2026年5月7日截止 | 提交作品 [citation:1][citation:2] |
| **初赛评审** | 2026年5月 | 由命题企业技术专家开展线上技术评审 [citation:1][citation:2] |
| **分赛区决赛** | 2026年6月—7月 | 具体时间、地点待定 [citation:1][citation:5] |
| **全国总决赛** | 2026年7月下旬 | 具体时间、地点待定 [citation:1][citation:2] |

### 3. 各阶段比赛形式

#### （1）校内选拔赛（可选择）
- 参赛队伍数超过20支队伍的院校可申请举办校内选拔赛 [citation:1]
- 举办校内选拔赛申请通过，所在院校的参赛队伍必须参加校内选拔赛 [citation:1]
- 校内选拔赛的具体形式由学校组织方决定，成绩不计入后续比赛结果 [citation:1]

#### （2）初赛
- 由命题企业技术专家开展评审工作 [citation:1]
- 企业专家根据学生提交的作品或实操结果，进行线上技术评分 [citation:1]
- 组委会根据企业技术评分，确定晋级名单和前往线下评比的名单 [citation:1]

#### （3）分赛区决赛
- 由分赛区承办方组织专家进行评审 [citation:1]
- 组委会根据参赛团队的现场评审得分和初赛技术评分，确定分赛区成绩及一、二等奖名单和晋级全国总决赛名单 [citation:1]
- 不前往线下评比的晋级团队根据其初赛技术得分评出分赛区决赛三等奖 [citation:1]

#### （4）全国总决赛
- 评审工作由组委会组织专家进行评审 [citation:1]
- 根据参赛团队在演讲汇报、作品演示、提问等环节的综合表现确定比赛成绩 [citation:1]
- 组委会根据专家评审成绩，确定全国总决赛获奖名单并公布于大赛官网和公众号 [citation:1]

## 六、评审标准与奖项设置

### 1. 分赛区决赛奖项设置

| 奖项 | 获奖比例 | 说明 |
|------|----------|------|
| **分赛区一等奖** | 约初赛晋级队伍数量的20% | 颁发电子版获奖证书 [citation:1] |
| **分赛区二等奖** | 约初赛晋级队伍数量的30% | 颁发电子版获奖证书 [citation:1] |
| **分赛区三等奖** | 约初赛晋级队伍数量的50% | 颁发电子版获奖证书 [citation:1] |
| **分赛区优秀指导教师** | - | 获得一、二、三等奖团队的指导教师可获得 [citation:1] |
| **分赛区优秀组织奖** | 各赛区获奖学校总数不超过20所 | 根据各学校晋级分赛区的队伍数量排序 [citation:1] |

注：
- 对于仅面向A组或B组的题目，奖项按成绩排名确定；对于面向A、B组的题目，二等奖和三等奖为A组团队预留一定的获奖名额 [citation:1]
- 原则上分赛区每个题目排名前15%-40%的队伍晋级全国总决赛，和奖项无关联 [citation:1]

### 2. 全国总决赛奖项设置

| 奖项 | 获奖比例 | 奖金 | 说明 |
|------|----------|------|------|
| **企业大奖** | 每个题目1支团队 | 从一等奖团队中挑选 | 命题企业或承办单位如有其他奖金支持将另行通知 [citation:1] |
| **全国一等奖** | 约20% | 平均分配奖金池 | 各题目均设置4万元奖金池 [citation:1] |
| **全国二等奖** | - | 平均分配奖金池 | 颁发电子版获奖证书 [citation:1] |
| **全国三等奖** | - | 平均分配奖金池 | 颁发电子版获奖证书 [citation:1] |

注：
- 每个题目设置4万元（人民币，税前）的奖金池，一、二、三等奖金的总金额均为1万元，每个奖项的奖金会根据获奖团队的数量进行平均分配（向下取整） [citation:1]
- 对于面向A、B组的题目，一等奖按照成绩产生，二等奖和三等奖为A组团队预留一定的获奖名额 [citation:1]

### 3. 获奖证书

获奖证书将注明团队组别（A组或B组）[citation:1][citation:4]。所有获奖证书均为电子版证书 [citation:1]。

## 八、报名方式

### 1. 通用报名流程

1. **校内组队**：按赛题要求组队（1-3人），确定指导教师（1-2人）
2. **加入QQ群**：加入各校竞赛QQ群和各赛区官方咨询群，获取后续通知
3. **校内报名**：按各校要求完成校内报名（部分高校需在创新创业竞赛管理系统报名）
4. **官网注册**：登录大赛官网（http://univ.ciciec.com）进行注册报名 [citation:2][citation:5]
5. **选择赛题**：每队可选择1个企业命题，同时可选择芯创成果方向独立报名 [citation:4]
6. **提交报名表**：报名表需学校或学院盖章 [citation:1][citation:4]
7. **缴纳押金**：通过“赛氪”平台缴纳300元押金 [citation:2][citation:7]

### 2. 报名截止时间

- **全国统一报名截止**：2026年3月31日 [citation:1][citation:2]
- **各高校校内报名截止**：各校不同，多在3月中下旬，请关注本校具体通知
