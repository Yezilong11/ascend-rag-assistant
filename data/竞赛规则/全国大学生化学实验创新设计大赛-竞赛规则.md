# 全国大学生化学实验创新设计大赛竞赛规则

## 一、竞赛简介

全国大学生化学实验创新设计大赛是由中国化学会和教育部高等学校国家级实验教学示范中心联席会主办的全国性大学生化学类和近化学类专业多学科综合性竞赛[citation:8]。该竞赛旨在建立一个大学生实验创新能力的展示与交流平台，推动我国高等学校实验教学改革，夯实大学生的化学基础知识、基本理论和基本技能，强化大学生发现问题、分析问题和解决问题的能力，培养大学生的创新意识、创新精神和创新能力[citation:1][citation:8]。

本赛事已入选中国高等教育学会《全国普通高校大学生竞赛分析报告》竞赛目录，是国家级A类学科竞赛，也是我国高校化学领域规模最大、影响力最广的赛事之一[citation:4][citation:7]。竞赛本着公开、公平、公正的原则，坚持公益性和非盈利性[citation:8]。

第五届全国大学生化学实验创新设计大赛总决赛由兰州大学承办，于2025年8月举办[citation:4]。第六届竞赛预计于2026年举办，具体时间以官网通知为准。

## 二、组织机构

### 1. 主办与指导单位

- **主办单位**：中国化学会、教育部高等学校国家级实验教学示范中心联席会[citation:8]
- **指导单位**：教育部高等学校化学教育研究中心[citation:1][citation:2]

### 2. 组织架构

| 机构 | 职责 |
|------|------|
| **竞赛委员会** | 由中国化学会、联席会和相关高校专家组成，指导总决赛和分赛区成立组织委员会，审定竞赛方案，协调仲裁争议事项[citation:8] |

## 三、赛道设置

本届竞赛设置四个赛道[citation:2][citation:5][citation:6]：

| 赛道 | 名称 | 说明 |
|------|------|------|
| **第一赛道** | 新创实验 | 将反映新知识、新理论、新技术、新方法的科研成果设计为适合本科生实验教学的基础实验或综合实验 |
| **第二赛道** | 改进实验 | 针对现有教学实验，对教学内容、方法、手段进行创新设计，或对教学实验仪器进行创制或改进 |
| **第三赛道** | 科普实验 | 面向社会公众及中小学生，反映化学之趣、化学之美、化学对社会发展的贡献 |
| **第四赛道** | 数智化实验 | 以真实实验为基础，将数字、人工智能等技术与化学实验深度融合 |

### 1. 新创实验

把反映新知识、新理论、新技术、新方法的科研成果设计为适合本科生实验教学需要的基础实验或者综合实验[citation:8]。要求所提交的新创实验未在国内外教材、杂志发表，需要经过反复验证，确保可重复，时长、成本和安全性等符合教学需要[citation:6]。通常基础实验的总时长不超过8小时，综合实验的总时长不超过24小时[citation:5][citation:8]。

### 2. 改进实验（包括教学实验仪器创制或改进）

是指针对现有国内外教材或杂志的教学实验，对教学内容、教学方法及教学手段进行创新设计，或对教学实验仪器进行创制或改进，使之更加符合实验教学需要，更有利于培养学生的创新思维和科研能力[citation:8]。

### 3. 科普实验

科普实验的受众为没有或者很少有化学素养的社会公众及中小学生。要求有助于公众了解和正确认识化学，能够激发青少年学习化学的兴趣和热情[citation:8]。要求内容反映化学之趣、化学之美、化学对社会发展的贡献等。作品应安全、绿色、有趣、价廉、便于展示，方便公众亲手操作，并能给公众留下深刻印象[citation:6]。

### 4. 数智化实验

是指以真实实验为基础，将数字、人工智能等技术与化学实验深度融合，能够全面提升学生的数智意识和数智能力的实验[citation:5][citation:6]。基于已有、二次开发或新开发的数学物理模型和数据库，对实验场景、实验过程和实验结果进行模拟、预测和评价，通过对实验的虚拟呈现、数据获取、判断和处理，实现对实验过程的控制与指导[citation:9]。实验中数字化设计可以使用包括“基于大模型的人工智能技术(AI)”、“数值模拟与虚拟仿真技术”、“半实物自动化远程控制技术”等多种不同数字化技术及其合理组合[citation:5]。

## 四、参赛资格与要求

### 1. 基本资格

- **参赛对象**：普通高等院校全日制在校本科生[citation:1][citation:2][citation:8]
- **学历限制**：仅限本科生参与，研究生不可报名[citation:9]。同一团队内研究生不可参赛（各赛道均要求参赛者为本科生）
- **毕业生资格**：当年毕业的学生可以以在校生身份参赛[citation:8]

### 2. 团队组成

| 赛道 | 队伍人数 | 指导教师人数 | 队长要求 |
|------|----------|--------------|----------|
| **第一、二、三赛道** | 3名选手 | 1-2名 | 设队长1名 |
| **第四赛道（数智化）** | 3-5名选手 | 1-3名 | 设队长1名 |

**通用要求**[citation:2][citation:5][citation:6]：
- 每名参赛者只能参加一支参赛队
- 鼓励跨专业、跨年级组队参加比赛，发挥所长，协作创新
- 参赛团队命名方式为：XX大学新创实验队（或一队、二队）；XX大学改进实验队（或一队、二队）；XX大学科普实验队（或一队、二队）
- 指导教师需为学校正式在编教师，每位教师原则上指导队伍不超过2支[citation:9]

### 3. 学校参赛名额

| 竞赛阶段 | 名额限制 |
|----------|----------|
| **分赛区初赛** | 每个高校最多推荐4个队参赛，并且要求参赛队伍赛道不重复[citation:2] |
| **全国总决赛** | 每个学校进入总决赛的队伍不超过1支[citation:2][citation:4][citation:7] |

如某校有多支队伍在分赛区出线，可按下列顺序确定参加决赛的队伍[citation:8]：
1. 由学校自行确定
2. 竞赛成绩第一的队伍
3. 由分赛区根据各赛道队伍情况制定出线规则

### 4. 禁止参赛情况

- 参赛作品不符合本科实验教学或者科普宣传需要[citation:8]
- 在参赛当年1月1日前已在正式出版物公开发表[citation:8]
- 已获得过国家或省级课程建设荣誉称号[citation:5]
- 在同级竞赛活动中获奖[citation:5][citation:8]
- 已获往届全国大学生化学实验创新设计大赛决赛奖励的项目不得再报名参加本届竞赛[citation:8]

## 五、赛制流程

竞赛分分赛区初赛和全国决赛两个阶段[citation:8]。

### 1. 时间安排（参考第五届）

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **竞赛委员会发布通知** | 1月 | 发布竞赛通知和竞赛章程[citation:8] |
| **分赛区发布通知** | 2月 | 分赛区组委会发布分赛区竞赛通知[citation:8] |
| **校内选拔赛** | 3月—5月 | 各高校自行组织，选拔优秀队伍参加区赛 |
| **报名及作品提交** | 6月前 | 完成报名并提交作品（实验报告和实验视频）[citation:8] |
| **分赛区初赛** | 6月—7月 | 采取作品评审和答辩方式进行，确定分赛区获奖名单和参加总决赛名单[citation:8] |
| **全国总决赛** | 8月 | 采取作品评审和答辩方式进行[citation:8] |

### 2. 各阶段比赛形式

#### （1）校内选拔赛
- 由各高校自行组织
- 形式：项目计划书评审、实验视频评审、现场汇报路演等[citation:5]
- 校赛奖项：设一、二、三等奖，优秀作品推荐参加分赛区初赛
- 晋级规则：通过校赛获得参赛资格后方可参加区赛及国赛

#### （2）分赛区初赛
- 以赛区为单位组织，由各赛区组委会负责[citation:8]
- **初赛形式**：函评（作品评审）+ 会评（现场答辩）[citation:2]
  - 初赛函评：专家对提交的作品进行盲审
  - 复赛会评：PPT展示10分钟，专家提问10分钟[citation:2]
- **成绩构成**：参赛作品成绩（50%）+ 现场答辩成绩（50%）[citation:2]
- **晋级规则**：综合排名靠前的队伍获得参加全国总决赛的资格[citation:2]

#### （3）全国总决赛
- 线下举行，入围队伍进行现场展示和答辩[citation:4]
- 评审方式：作品评审 + 现场答辩[citation:8]
- 成绩构成：作品成绩和答辩成绩各占50%[citation:8]
- 初赛成绩不带入决赛[citation:8]

## 六、作品要求

### 1. 作品内容要求

参赛作品应符合本科实验教学或者科普宣传需要，且未在参赛当年1月1日前在正式出版物公开发表或在同级竞赛活动中获奖[citation:8]。

### 2. 作品形式要求

| 材料类型 | 要求 |
|----------|------|
| **实验论文** | Word和PDF两个版本，PDF版用于评审，需隐去参赛作者、指导教师姓名和单位名称等一切暗示身份的信息[citation:5][citation:6][citation:8] |
| **实验视频** | 不超过8分钟，内容可以是对实验内容必要的补充说明或证据材料等[citation:5]。视频中不得出现参赛作者、指导教师姓名和单位名称、校标或其他暗示学校和人员信息的内容[citation:5][citation:6] |
| **答辩PPT** | 用于现场汇报路演的演示文稿，需隐去身份信息[citation:6][citation:8] |
| **支撑材料** | 其他必要的证明材料 |

### 3. 论文格式要求

| 项目 | 要求 |
|------|------|
| **字数限制** | 论文字数控制在9000字以内(不含图表)[citation:5] |
| **格式规范** | 按照竞赛论文模板要求撰写[citation:5] |
| **匿名要求** | PDF版论文中必须隐去学校、选手、指导教师相关的任何信息[citation:5] |

### 4. 视频要求

- **时长**：不超过8分钟[citation:5]
- **内容**：可以是对实验内容必要的补充说明或证据材料等，也可以是实验视频[citation:5]
- **匿名要求**：视频材料中不得出现参赛作者、指导教师姓名和单位名称、校标或其他暗示学校和人员信息的内容（包括仪器标签、实验服、实验室名称以及建筑标志等）[citation:5][citation:6]
- **泄露处理**：如泄露暗示身份的信息，将按章程予以扣分[citation:5]

### 5. 原创性要求

- 参赛作品必须为原创，不得抄袭、剽窃他人成果[citation:5]
- 各参赛团队对所提交材料的真实性负责[citation:5][citation:8]
- 确保无版权争议，否则将被视为无效作品并取消参赛资格[citation:6]

## 七、评审标准

### 1. 评审维度

| 评审维度 | 说明 |
|----------|------|
| **科学性** | 实验原理的科学性和正确性 |
| **创新性** | 作品的创新程度和独特性 |
| **可行性** | 实验的可重复性和教学适用性 |
| **规范性** | 论文和视频的规范性 |
| **经济性** | 实验成本的经济性 |

### 2. 成绩构成

| 环节 | 占比 |
|------|------|
| **参赛作品成绩** | 50% |
| **现场答辩成绩** | 50% |

### 3. 匿名违规扣分标准

在作品合格性审查、评审和答辩等比赛环节中，发现在作品、视频、附件材料、答辩等环节中出现泄露参赛学校、指导教师和参赛人员信息等情况，将视泄露信息的严重程度在总成绩中予以适当扣分[citation:8]：

| 违规情形 | 扣分标准 |
|----------|----------|
| **信息第一次泄露** | 扣2分 |
| **同一信息多次重复泄露** | 再追加扣1分 |
| **各类信息泄露总扣分** | 限在10分之内 |

## 十、申诉与仲裁

### 1. 申诉范围

如发现以下问题，可以向竞赛委员会举报或者提出申诉[citation:8]：
- 参赛作品存在违反学术道德、违反法律法规、违反竞赛纪律等情况
- 比赛过程中存在影响比赛结果公正公平的问题

### 2. 申诉方式

- 进行举报和申诉时，应递交书面材料、署名并加盖单位公章[citation:8]
- 如遇特殊情况来不及加盖公章时，应向组委会先口头申请，随后及时补交盖章申诉材料[citation:8]
- 组委会不接受匿名举报或申诉[citation:8]

### 3. 申诉时间

举报和申诉时间为比赛开始至作品获奖公示期结束前[citation:8]。

### 4. 仲裁处理

督查仲裁组根据举报或申诉的具体情况，可决定采取接受或不接受方式处置。对于接受的举报或者申诉，将在公示期结束后二周内完成仲裁并答复。督查仲裁组作出的仲裁为最终裁定[citation:8]。
