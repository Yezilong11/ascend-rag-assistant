# “挑战杯”全国大学生课外学术科技作品竞赛竞赛规则

## 一、竞赛简介

“挑战杯”全国大学生课外学术科技作品竞赛（简称“大挑”）是由共青团中央、中国科协、教育部、中国社会科学院、全国学联和承办高校所在省（市）人民政府共同主办的一项具有导向性、示范性和群众性的全国竞赛活动[citation:4]。竞赛始终坚持“崇尚科学、追求真知、勤奋学习、锐意创新、迎接挑战”的宗旨，被誉为当代大学生科技创新的“奥林匹克”盛会[citation:6][citation:8]。

竞赛旨在引导和激励高校学生实事求是、刻苦钻研、勇于创新、多出成果、提高素质，培养学生创新精神和实践能力，并在此基础上促进高校学生课外学术科技活动的蓬勃开展，发现和培养一批在学术科技上有作为、有潜力的优秀人才[citation:1]。竞赛每两年举办一届（与“小挑”交叉轮流开展）[citation:8][citation:9]。

## 二、组织机构

### 1. 主办单位

- **主办单位**：共青团中央、中国科协、教育部、中国社会科学院、全国学联、承办高校所在省（市）人民政府[citation:4][citation:6]
- **承办单位**：通过申办机制确定的高校（如第十七届由四川大学承办，第十八届由贵州大学承办）[citation:4]

### 2. 组织架构

| 机构 | 职责 |
|------|------|
| **全国组织委员会** | 竞赛的最高领导机构，负责竞赛的组织领导工作 |
| **全国评审委员会** | 由主办单位聘请的相关学科具有高级职称的专家组成，负责参赛作品的评审工作 |
| **秘书处** | 设在全国学联秘书处，负责竞赛的日常事务 |
| **省级组织协调委员会** | 各省（区、市）成立相应机构，负责本地区竞赛的组织协调、作品评审和推荐工作 |

## 三、参赛资格与要求

### 1. 参赛对象

| 项目 | 要求 |
|------|------|
| **学历要求** | 2026年6月1日以前正式注册的全日制非成人教育的各类高等院校在校专科生、本科生、硕士研究生（不含在职研究生）均可申报作品参赛[citation:2] |
| **博士研究生限制** | 博士研究生仅可作为项目团队成员参赛（不作项目负责人），且人数不超过团队成员数量的30%[citation:2] |
| **毕业生资格** | 当年毕业的学生可以以在校生身份参赛 |

### 2. 团队组成要求

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每个项目学生成员（含项目负责人）不超过10人[citation:2][citation:6] |
| **指导教师** | 每件作品的指导教师人数不超过3人[citation:1][citation:2]；部分高校要求指导教师中须包含至少2名副高级及以上职称的专业教师[citation:1] |
| **组队范围** | 鼓励跨学科、跨专业、跨年级组队，但需以项目负责人所在学院进行申报[citation:2]；不得跨校组队 |
| **参赛限制** | 每位学生限参与1个项目（校赛阶段部分高校不做严格要求，但省赛严格限制）[citation:6] |

## 四、作品要求

### 1. 作品类别

申报参赛的作品分为三大类[citation:3]：

| 类别 | 说明 |
|------|------|
| **自然科学类学术论文** | 限本科生申报，涉及机械与控制、信息技术、数理、生命科学、能源化工等学科领域 |
| **哲学社会科学类社会调查报告** | 围绕经济、政治、文化、社会、生态文明建设等5个组别，开展与我国当前经济社会发展结合度高、前瞻性强的调查研究，全文在15000字以内[citation:1][citation:3] |
| **科技发明制作** | A类：科技含量较高、制作投入较大的作品；B类：投入较少，且为生产技术或社会生活带来便利的小发明、小制作。涉及机械与控制、信息技术、数理、生命科学、能源化工等学科领域 |

### 2. 作品时效性要求

参赛作品必须是2025年3月—2026年2月期间完成的学生课外学术科技或社会实践活动成果[citation:1]。毕业设计和课程设计（论文）、学年论文和学位论文、国际竞赛中获奖的作品、获国家级奖励成果等均不在申报范围之列[citation:1]。

### 3. 作品原创性要求

- 参赛作品须为团队原创，不得侵犯他人知识产权，不得重复使用往届省级及以上竞赛获奖作品[citation:6]
- 已在往届“挑战杯”竞赛上获奖的作品不得申报，但是在往届获奖作品基础上又有所创新的项目可以参赛[citation:3]
- 参赛项目涉及知识产权的，在报名时须提交具有法律效力的发明创造或专利技术所有人的书面授权许可、项目鉴定证书、专利证书等[citation:2][citation:6]

### 4. 申报形式

| 形式 | 要求 |
|------|------|
| **个人作品** | 申报者必须承担申报作品60%以上的研究工作，作品鉴定证书、专利证书及发表的有关作品上的署名均应为第一作者，合作者必须是学生且不得超过2人[citation:1][citation:3] |
| **集体作品** | 凡作者超过3人的项目，或者不超过3人但无法区分第一作者的项目，均须申报集体作品。集体作品的作者必须均为学生[citation:1][citation:3] |

## 五、竞赛组别

第十九届/二十届“挑战杯”全国大学生课外学术科技作品竞赛聚焦创新、协调、绿色、开放、共享五大发展理念，设以下五个组别[citation:2][citation:6]：

| 组别 | 说明 |
|------|------|
| **科技创新和未来产业** | 围绕创新驱动发展战略，推动数字经济健康发展，在量子技术、元宇宙、智能制造、信息技术、大数据、人工智能、生命科学、新材料、军民融合等领域，结合实践观察设计项目 |
| **乡村振兴和农业农村现代化** | 围绕乡村振兴战略，在农林牧渔、电子商务、乡村旅游等领域，结合实践观察设计项目 |
| **生态文明建设和绿色低碳发展** | 围绕绿色低碳发展和碳达峰碳中和目标，在绿色低碳产业、绿色消费、环境治理、可持续资源开发、生态环保、清洁能源应用等领域，结合实践观察设计项目 |
| **文化创意和区域交流合作** | 突出共融、共享，紧密围绕“一带一路”和京津冀、长三角、粤港澳大湾区以及成渝地区双城经济圈、长江经济带和黄河流域等区域合作，或在工业设计、动漫广告、体育竞技和国际文化传播、对外交流培训、对外经贸等领域，结合实践观察设计项目 |
| **社会治理和公共服务** | 围绕国家治理体系和治理能力现代化建设，在政务服务、消费生活、公共卫生与医疗服务、金融与财经法务、教育培训、交通物流、人力资源、城乡融合等领域，结合实践观察设计项目 |

## 六、专项赛道

第十七届“挑战杯”首次搭建了“1+3”赛事架构，在延续主体赛的同时，增设三个专项赛道[citation:4]：

| 专项赛道 | 说明 |
|------|------|
| **红色专项活动** | 教育学生赓续红色基因，鼓励学生通过社会实践接受红色教育 |
| **“揭榜挂帅”专项赛** | 鼓励学生用新技术攻克“卡脖子”难题，由政府、企业出题，学生答题 |
| **“黑科技”专项赛** | 引导青年学子为科技自立自强贡献力量，展示青年学子的奇思妙想和创新成果 |

中央财经大学2026年校赛采用“1+1+N”主题模式，即设立1个“人工智能+”专项、1个“乡村振兴+”专项及若干其他领域赛道[citation:1]。

## 七、赛制流程

竞赛采用校级初赛、省级复赛、全国决赛三级赛制[citation:7]。

### 1. 第十九届/二十届时间安排

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **校级初赛** | 2025年11月—2026年3月 | 各高校自行组织，选拔推荐作品参加省级复赛[citation:1][citation:2][citation:3] |
| **省级复赛** | 2026年5月—6月 | 各省（区、市）组织评审，选拔优秀作品参加全国决赛[citation:2] |
| **全国决赛** | 2026年10月—11月 | 现场终审答辩，评选出全国特等奖、一等奖、二等奖、三等奖 |

### 2. 各高校校内报名截止时间参考

| 高校 | 校内报名截止时间 | 来源 |
|------|------------------|------|
| 中央财经大学 | 2026年3月2日 | [citation:1] |
| 合肥工业大学 | 2025年12月25日 | [citation:2] |
| 洛阳理工学院 | 2026年3月31日（立项申报） | [citation:3] |
| 西南财经大学天府学院 | 2026年1月10日 | [citation:6] |
| 西安欧亚学院 | 2025年12月10日 | [citation:8] |

### 3. 各阶段比赛形式

#### （1）校级初赛
- 由各高校自行组织，形式多为材料评审+现场答辩[citation:1][citation:2]
- 各学院组织院内初审，推荐优秀作品参加校级复赛并进行排序[citation:2]
- 校赛奖项：评选院级一二三等奖，择优推报至学校[citation:2]
- 晋级规则：根据各校获得的省赛名额，从校赛获奖作品中择优推荐参加省级复赛

#### （2）省级复赛
- 由各省（区、市）组织协调委员会组织
- 形式：材料评审+现场答辩
- 省赛奖项：设一等奖、二等奖、三等奖
- 晋级规则：根据国赛分配的名额，从省赛一等奖作品中择优推荐参加全国决赛

#### （3）全国决赛
- 线下举行，入围队伍进行现场展示和答辩[citation:4]
- 评审专家现场评审，评选出全国特等奖、一等奖、二等奖、三等奖[citation:4]
- 同期举办优秀作品展览、创新创业论坛等交流活动

## 八、评审标准

### 1. 评审维度

突出实践导向，在考察项目学术价值的基础上，更加注重考察学生了解社会现状、关注社会民生、解决社会问题的意识、能力和水平[citation:6][citation:8]。

| 评审维度 | 说明 |
|------|------|
| **科学性** | 研究方法的科学性、理论基础的扎实性 |
| **创新性** | 选题的新颖性、研究视角的独特性、技术创新程度 |
| **实用性/现实意义** | 项目的实际应用价值、社会效益、对经济社会发展的贡献 |
| **社会价值** | 项目对社会发展的贡献和意义[citation:6] |
| **实践过程** | 项目的社会实践基础和实施过程[citation:6] |
| **团队协作** | 团队成员的分工合理性、协作能力[citation:6] |

### 2. 哲学社会科学类作品评审重点

哲学社会科学类社会调查报告和学术论文重点考察[citation:5]：
- 选题是否扎根实际、深入一线
- 是否紧扣服务国家经济、政治、文化、社会、生态文明建设
- 是否围绕传承中华优秀传统文化、赋能乡村振兴、社会公益服务等重点领域
- 是否开展与我国当前经济社会发展结合度高、前瞻性强的调查研究

| 作品类别 | 提交材料要求 |
|------|------|

| 自然科学类学术论文 | 学术论文全文[citation:3] |
| 哲学社会科学类社会调查报告 | 调查报告（15000字以内）[citation:1][citation:3] |

### 3. 特殊材料要求

参赛项目涉及下列内容时，必须由申报者在报名时提供有关证明材料，否则不予评审[citation:6][citation:8]：

- 动植物新品种的发现或培育，必须有省级及以上农科部门或者科研院所开具证明
- 对国家保护动植物的研究，必须有省级及以上林业部门开具证明，证明该项研究的过程中未产生对所研究的动植物繁衍、生长不利的影响
- 新药物的研究必须有卫生行政部门授权机构的鉴定证明
- 医疗卫生研究必须通过专家鉴定，并附有在公开发行的专业性杂志上发表过的文章
- 涉及燃气用具等与人民生命财产安全有关用具的研究，必须有国家相应行政部门授权机构的认定证明
