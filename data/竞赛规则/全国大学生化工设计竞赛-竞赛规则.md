# 全国大学生化工设计竞赛竞赛规则

## 一、竞赛简介

全国大学生化工设计竞赛由中国化工学会和中国化工教育协会共同主办，浙江大学等高校发起承办，是目前国内级别最高、参赛队伍最多、影响力最大的化工类大学生专业性比赛[citation:3][citation:10]。大赛从2007年起连年举办，迄今已经连续成功举办近20届，自2018年起进入全国高校学科竞赛排行榜榜单[citation:3][citation:10]。

2025年全国共有479所高校的4337支队伍报名参加本届赛事，参赛人数首次超2万人，参赛学校和报名队伍的数量再创新高[citation:3][citation:10]。大赛旨在多方面培养大学生的创新思维和工程技能，培养团队协作精神，增强大学生的工程设计与实践能力，实践“卓越工程师教育培养计划”，为培养化工领域“卓越工程师”夯实人才基础[citation:3][citation:7][citation:10]。

第二十届全国大学生化工设计竞赛由宁夏大学承办全国总决赛[citation:2][citation:8]。竞赛以“创新驱动、绿色发展”为导向，设计题目为“某大型化工企业设计一座苯乙烯清洁生产的分厂，要求技术符合中国绿色低碳循环发展要求”[citation:2][citation:3][citation:4]。

## 三、竞赛内容

### 1. 设计题目

第二十届全国大学生化工设计竞赛的设计题目为：

**为某大型化工企业设计一座苯乙烯清洁生产的分厂，要求技术符合中国绿色低碳循环发展要求**[citation:2][citation:3][citation:4]。

### 2. 设计任务书

竞赛题目及参赛作品具体要求公布在《2026年第二十届全国大学生化工设计竞赛设计任务书》中，参赛团队可在大学生化工设计竞赛网站的“下载中心”栏目中下载[citation:8]。请参赛同学和指导教师务必认真阅读任务书的具体条款（相较往年有修改），并用于指导参赛作品的编制[citation:3][citation:10]。

### 3. 设计要求

参赛团队需综合运用所学知识与方法，探索苯乙烯清洁生产的前沿技术，为化工行业的可持续发展注入新活力[citation:3][citation:10]。设计工作必须由本队参赛成员独立完成，不允许外人代工和抄袭外队作品[citation:5][citation:8]。

## 四、参赛资格与要求

### 1. 参赛对象

- **学历要求**：全国普通高等院校全日制在校本科生[citation:2][citation:4][citation:5]
- **专业范围**：化工、化学、制药、生物、资源环境、过程装备、材料、土木建筑、经济管理、自动化控制等专业的全日制在校本科生均可报名[citation:4][citation:6]

### 2. 团队组成

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每支参赛团队由同一所学校的5名学生组成，设队长1人[citation:2][citation:4][citation:5] |
| **组队范围** | 仅限校内组队，鼓励学生跨学科、跨专业联合组队[citation:2][citation:4][citation:5] |
| **参赛限制** | 每位学生只允许参加一支团队[citation:2][citation:4][citation:5] |
| **队员替换** | 团队有队员因故退出时，最多允许替换2名队员或缺席1名队员参赛，否则作弃权处理[citation:6][citation:8] |
| **指导教师** | 每支参赛团队可设指导教师，具体人数按各校要求确定 |

### 3. 作品真实性要求

按照全国大学生化工设计大赛组委会相关要求，所有参赛团队必须提交作品真实性声明和诚信承诺书[citation:1]：

- 参赛作品必须为团队原创，严禁抄袭、剽窃他人成果或使用AI等工具直接生成全部内容并谎称原创[citation:1]
- 所有数据、图表、计算过程、设计方案等均应基于团队独立完成或在指导教师指导下完成[citation:1]
- 团队全体成员应对作品的真实性、原创性负责，如有违反，将按照竞赛规则及学校学术规范严肃处理[citation:1]
- 提交《参赛队员和指导老师确认表》，该表作为各参赛团队最终的奖状名单排序，时间截止后不予更改，未填写确认表的团队作弃权处理[citation:8]

## 五、赛制流程

竞赛分为预赛和决赛两个阶段。预赛分华东、华南、西北、华北、华中、东北、西南共七个赛区进行[citation:8]。

### 1. 时间安排（第二十届）

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **报名组队** | 3月1日—3月31日 | 登录竞赛网站在线填写报名表[citation:8] |
| **实施设计** | 获准参赛日—7月15日 | 完成初赛作品[citation:8] |
| **提交预赛作品** | 7月15日前 | 按《提交作品指南》上传作品[citation:8] |
| **提交确认表** | 7月1日—7月31日 | 在线填写并提交《参赛队员和指导老师确认表》[citation:8] |
| **预赛评审** | 7月25日前 | 各赛区评阅参赛作品[citation:8] |
| **公布晋级名单** | 7月26日前 | 公布进入赛区决赛团队[citation:8] |
| **赛区决赛** | 7月31日前 | 答辩会形式，评定赛区奖项[citation:8] |
| **全国总决赛** | 8月12日—17日 | 宁夏大学举行[citation:2][citation:8] |

### 2. 各阶段比赛形式

#### （1）报名阶段
- 报名时间为3月1日～3月31日，请报名参赛的团队登录全国大学生化工设计竞赛网站（http://iche.zju.edu.cn），在线填写报名表[citation:8]
- 获准参赛的团队名单将在竞赛网站上公布[citation:8]
- 各高校通常会组织校内选拔赛，请关注本校具体通知[citation:4][citation:5][citation:6]

#### （2）预赛作品提交
- 将预赛作品相关文件于7月15日前按照《提交作品指南》的指示上传到指定的云储存上[citation:8]
- 按设计任务书要求提供完整材料的作品，方视为合格参赛作品[citation:8]

#### （3）参赛确认表提交
- 7月1日～7月31日，提交作品的团队队长登录竞赛网站，在线填写并提交《参赛队员和指导老师确认表》[citation:8]
- 该表作为各参赛团队最终的奖状名单排序，时间截止后不予更改，未填写确认表的团队作弃权处理[citation:8]

#### （4）预赛评审
- 各赛区于7月25日前对提交的参赛作品进行评阅，遴选出参加赛区决赛的团队[citation:8]
- 于7月26日前在竞赛网站公布，并通过电子邮件通知相关参赛队伍[citation:8]

#### （5）赛区决赛
- 赛区决赛于7月31日之前进行，具体时间由各赛区竞赛委员会确定[citation:8]
- 赛区决赛原则上采用答辩会的形式，各参赛团队依次报告本队的作品，接受赛区决赛评审专家的质询，即时答辩[citation:8]
- 赛区决赛评审专家根据参赛团队的口头报告质量和答辩表现进行评议，评定各参赛团队的获奖级别，并甄选出代表本赛区参加全国总决赛的团队[citation:8]

#### （6）全国总决赛
- 全国总决赛拟于8月12～17日在宁夏大学举行[citation:2][citation:8]
- 总决赛内容包括作品专项评审和总决赛答辩会[citation:8]
- 总决赛团队于8月10日前将决赛作品按照《总决赛通知》的指示上传到指定的云储存上[citation:8]
- 总决赛团队需准备口头报告和相应的演示文档，在报告会上介绍本队的设计作品并进行答辩[citation:8]
- 各队在总决赛答辩会上的分组和出场顺序均通过抽签决定[citation:8]
- 总决赛评审委员会根据各队提交的作品质量、口头报告和答辩表现进行综合评价[citation:8]

## 六、作品要求

### 1. 作品内容要求

参赛团队根据竞赛设计任务书的命题和要求完成设计，按时提交设计作品的电子文档[citation:8]。作品内容应包括但不限于：
- 工艺流程图
- 设备设计计算
- 工厂布置设计
- 经济分析与评价
- 安全与环境评估
- 其他设计任务书要求的内容

### 2. 原创性要求

- 作品必须由本队参赛成员独立完成，不允许外人代工和抄袭外队作品[citation:5][citation:8]
- 每支参赛团队只能提交一份作品[citation:5][citation:8]
- 严禁抄袭、剽窃他人成果或使用AI等工具直接生成全部内容并谎称原创[citation:1]
- 所有数据、图表、计算过程、设计方案等均应基于团队独立完成或在指导教师指导下完成[citation:1]

### 3. 作品真实性承诺

参赛团队需提交《全国大学生化工设计大赛参赛作品真实性声明及诚信承诺书》，经全体队员及指导教师签字确认后，将盖章扫描件（PDF格式）于规定时间内提交[citation:1]。

## 七、评审标准

### 1. 评分实施细则更新

为进一步提升参赛效果，减轻参赛学生负担，根据2025年全国大学生化工设计竞赛竞赛委员会和专家委员会联席会议精神对评分实施细则进行了修订[citation:3][citation:10]。2026年“天正设计杯”第二十届全国大学生化工设计竞赛将按照新的评分实施细则评审作品[citation:3][citation:10]。更新后的评分实施细请在竞赛官网“下载中心”下载[citation:3][citation:10]。

### 2. 评审维度

| 评审维度 | 说明 |
|----------|------|
| **设计创意** | 工艺路线、技术方案的创新性 |
| **技术可行性** | 设计方案的工程可实现性 |
| **经济合理性** | 投资回报、成本控制的经济分析 |
| **绿色环保** | 清洁生产、低碳循环的符合程度 |
| **文档规范性** | 设计文档的完整性和规范性 |
| **答辩表现** | 口头报告质量和答辩应变能力 |

### 3. 成绩构成（参考）

北京理工大学校内选拔赛评分方式[citation:6]：
- 作品评审：权重0.7
- 现场答辩：权重0.3

## 八、奖项设置

### 1. 赛区奖项

各赛区决赛由赛区评审委员会评选获赛区奖作品[citation:8]：
- 赛区一等奖
- 赛区二等奖
- 赛区三等奖

### 2. 全国总决赛奖项

总决赛评审委员会根据各队提交的作品质量、口头报告和答辩表现进行综合评价，于总决赛结束后公布评奖结果并举行颁奖仪式[citation:8]：
- 全国特等奖
- 全国一等奖
- 全国二等奖
- 全国三等奖

获奖名单将在竞赛网站公示，公示期后进行异议审查，异议审查结束后将公布正式获奖名单，并颁发获奖证书[citation:8]。

### 3. 校内选拔赛奖项

各高校自行组织校内选拔赛，通常设校赛一、二、三等奖[citation:5]。例如河北科技大学校赛获奖比例为参赛队伍数的10%、20%、30%[citation:5]。
