# 全国大学生广告艺术大赛竞赛规则

## 一、竞赛简介

全国大学生广告艺术大赛（简称“大广赛”）自2005年创办至今，遵循“促进教改、启迪智慧、强化能力、提高素质、立德树人”的竞赛宗旨，已成功举办17届共18次赛事。全国共有1912所高校参与其中，超过百万学生提交作品[citation:6]。

大广赛以立德树人为根本，以强教兴才为己任，搭建了以赛促学、以赛促教、以赛促创、以赛促就、以赛立德的实践教学改革平台。大赛整合社会资源、服务教学改革，以企业真实营销项目作为命题，与教学相结合，真题真做、了解受众、调研分析、提出策略，在现场提案的过程中实现教学与市场相关联[citation:6]。

大广赛是迄今为止全国规模大、覆盖高等院校广、参与师生人数多、作品水准高、受高校教师欢迎、有较大社会影响力的全国性高校学科竞赛，目前是全国普通高校大学生竞赛排行榜榜单赛事之一[citation:6][citation:7]。

## 二、组织机构

### 1. 主办单位

- **指导单位**：中国高等院校影视学会[citation:2]
- **主办单位**：全国大学生广告艺术大赛组委会、西安交通大学[citation:2]
- **承办单位**：西安交通大学新闻与新媒体学院、大广赛文化传播（北京）有限公司[citation:2]

### 2. 竞赛官网与联系方式

- **官方网站**：https://www.sun-ada.net/ 
- **命题下载**：https://www.sun-ada.net/mt_downloads.html 
- **作品提交平台**：大广赛官网“提交平台”
- **官方微信公众号**：大广赛

## 三、参赛资格与要求

### 1. 参赛对象

| 项目 | 要求 |
|------|------|
| **学历要求** | 全国各类高等院校在校全日制大学生、研究生、港澳台籍学生、外籍留学生均可参加[citation:1][citation:3] |

### 2. 团队组成要求

| 作品类别 | 作者人数限制 | 指导教师人数限制 |
|------|:---:|:---:|
| 平面类、文案类 | ≤2人/组 | ≤1人/组 |
| 短视频、互动类、广播类 | ≤3人/组 | ≤2人/组 |
| 影视广告、微电影广告、动画类、策划案类、UI类、科技类 | ≤5人/组 | ≤2人/组 |
| 营销创客单元 | ≤7人/组 | ≤2人/组[citation:2] |

**组队要求**：
- 大广赛严禁跨赛区、跨学校组队参赛，但鼓励同一学校跨专业组队参赛[citation:3]
- 营销创客单元的参赛人员不能跨团队报名，提交报名表时必须明确团队中各成员职位[citation:2]

## 四、作品类别与命题要求

### 1. 作品类别

第18届大广赛共设**11个作品类别**[citation:1][citation:3][citation:7]：

| 类别代码 | 类别名称 | 细分方向 |
|------|------|------|
| A | 平面类 | Aa 平面广告、Ab 产品与包装、Ac IP与创意周边 |
| B | 视频类 | Ba 影视广告、Bb 微电影广告（含系列短剧）、Bc 短视频广告 |
| C | 动画类 | - |
| D | 互动类 | Da 线上互动广告、Db 线下互动广告 |
| E | 广播类 | Ea 15秒广播广告、Eb 30秒广播广告 |
| F | 策划案类 | - |
| G | 文案类 | 创意长文案或种草长文案 |
| H | UI类 | 移动端、PC端 |
| I | 科技类 | 生成式AI设计方向 |
| J | 营销创客单元 | 微短剧、AIGC微短剧、微视频、网络直播 |
| K | 公益单元 | 根据公益命题要求创作 |

### 2. 命题要求

参赛作品必须严格依照大广赛组委会统一发布的命题进行创作[citation:1][citation:3]。命题可在官网（www.sun-ada.net/mt_downloads.html）进行查看下载[citation:3]。

营销创客单元参赛作品必须结合第18届大广赛营销创客单元指定命题进行创作，具体选品名录详见官网通知[citation:2]。

## 五、作品规格及提交要求

### 1. 平面类（A类）

| 项目 | 要求 |
|------|------|
| **作品形式** | 单幅作品、系列作品（不得超过3张画面） |
| **规格尺寸** | A3（297×420mm），横竖不限 |
| **色彩模式** | RGB |
| **分辨率** | 300dpi |
| **提交格式** | jpg格式，单个文件不大于5MB[citation:1] |

### 2. 视频类（B类）

| 类别 | 时长要求 | 规格要求 | 文件大小 |
|------|----------|----------|----------|
| Ba 影视广告 | 15秒或30秒 | 横屏，宽高比16:9 | ≤30MB |
| Bb 微电影广告 | 60秒-180秒 | 横屏，宽高比16:9 | ≤50MB |
| Bc 短视频广告 | 15秒-60秒 | 竖屏，宽高比9:20至9:16 | ≤30MB |

**提交格式**：mp4格式。作品严禁出现倒计时及创作者相关信息[citation:1]。

### 3. 动画类（C类）

| 项目 | 要求 |
|------|------|
| **时长要求** | 15秒或30秒两种规格，24帧/秒 |
| **规格要求** | 宽高比16:9，须有配音、配乐 |
| **提交格式** | mp4格式，文件大小不超过30MB[citation:1] |

### 4. 互动类（D类）

| 类别 | 作品要求 | 提交方式 |
|------|----------|----------|
| Da 线上互动广告 | 总页数不超过15页 | 提交作品发布后的链接及二维码 |
| Db 线下互动广告 | 视频时长180秒以内 | mp4格式，大小不超过50MB[citation:1] |

### 5. 广播类（E类）

| 项目 | 要求 |
|------|------|
| **时长规格** | 15秒或30秒 |
| **提交格式** | mp3格式，文件大小不超过3MB[citation:1] |

### 6. 策划案类（F类）

| 项目 | 要求 |
|------|------|
| **页面比例** | 16:9（横竖版画面均可） |
| **页数限制** | 正文不超过30页（含封面、正文内容、封底），附件不超过10页 |
| **提交格式** | pdf格式，文件大小不超过100MB[citation:1] |

**现场决赛**：策划案的全国一等奖，通过现场提案的形式产生[citation:1]。

### 7. 文案类（G类）

| 项目 | 要求 |
|------|------|
| **字数要求** | 100-500字之间（含标点） |
| **内容要求** | 作品内无需加入命题logo、图片、表情及其它形式文件 |
| **提交方式** | 在作品“文本输入框”直接录入作品内容[citation:1] |

### 8. UI类（H类）

| 项目 | 要求 |
|------|------|
| **界面数量** | 核心主功能流程界面数量建议不少于10-15个 |
| **页面尺寸** | A4 |
| **提交格式** | pdf格式，文件大小不超过100MB[citation:1] |

### 9. 科技类（I类）

此类别内容征集仅限于大广赛所设置的“AI无界 创意赋新章”命题，且必须使用AI工具辅助完成[citation:1]。

**提交格式**：pdf格式，页面尺寸为A4，内容不超过40页，文件大小不超过100MB。需附上生成式AI工具的原始输出文件及工具使用过程的说明或截图[citation:1]。

### 10. 营销创客单元（J类）

营销创客单元分区域选拔赛、实战竞技赛、全国总决赛三部分[citation:2]。

#### （1）微短剧

| 项目 | 要求 |
|------|------|
| **创作要求** | 完成剧情内容不少于20集，每集不少于3分钟时长，剧本不接收AI生成版 |
| **提交格式** | PDF格式[citation:2] |

#### （2）AIGC微短剧

| 项目 | 要求 |
|------|------|
| **创作要求** | 完成不少于3集文学剧本，每集不少于3分钟时长，剧本不接收AI生成版 |
| **提交格式** | PDF格式[citation:2] |

#### （3）实战决赛视频要求

| 项目 | 要求 |
|------|------|
| **视频规格** | 像素不低于1080p，限竖屏，宽高比9:16 |
| **提交格式** | mp4格式 |
| **内容要求** | 不少于20集的全剧完整合成包装视频作品，必须为高清剧情片[citation:2] |

### 11. 公益单元（K类）

根据公益命题具体要求，从所征集类别中自选类别进行创作，作品规格、提交方式及要求，按相关类别标准执行[citation:1]。

## 六、原创性与诚信要求

### 1. 原创性要求

各类参赛作品必须为本人原创作品，拥有独立知识产权，遵守《广告法》和其他相关法律及政策法规、行业规范等要求[citation:1][citation:3]。

### 2. 禁止行为

| 禁止事项 | 说明 |
|------|------|
| **禁止抄袭** | 坚持原创，杜绝抄袭，请遵守《承诺书》的承诺[citation:1][citation:3] |
| **禁止一稿多投** | 指同一件或多件创意雷同作品，在未经剪辑或仅缩短时间等简单处理后，按不同类别或不同命题提交；也指将别的赛事创作的作品再投大广赛，或大广赛作品投至其他赛事。一经发现，取消参赛及获奖资格[citation:3] |
| **禁止购买作品** | 禁止参赛者通过各种渠道购买作品。一经发现，立即取消其参赛资格[citation:3] |
| **素材使用** | 创作中如使用了素材，务必在报名表中详细注明出处，并取得授权[citation:3] |
| **AI工具使用** | 如使用AIGC工具辅助创作，须在报名表中予以注明[citation:3] |

### 3. 匿名要求

参赛作品中严禁出现参赛者的院校、系、姓名及其他特殊标记[citation:3]。

## 七、参赛流程

### 1. 标准参赛流程

| 步骤 | 操作内容 |
|------|----------|
| **第1步** | 查阅命题及下载命题素材包（详细见大广赛官网）[citation:1][citation:5] |
| **第2步** | 作品创作[citation:1][citation:5] |
| **第3步** | 线上提交，上传作品：在大广赛官网“提交平台”注册账号，按流程填写正确信息；参赛者须上传学生证拍图或学信网截图，每组作品只需一名代表进行线上提交；参赛者需在线电子签名[citation:1][citation:5] |
| **第4步** | 获取参赛报名表、承诺书：作品提交成功后，将进入到草稿箱，确认无误后转为正式作品；只有将作品转为正式作品，系统才自动生成唯一对应的参赛编号，方能获取参赛报名表及承诺书[citation:1][citation:5] |
| **第5步** | 线下提交作品文件，报送至学校[citation:1][citation:5] |
| **第6步** | 学校报送至赛区[citation:1] |
| **第7步** | 赛区报送至全国大广赛组委会秘书处[citation:1] |

**重要提示**：作者和指导教师的先后顺序一经确认提交不得变更[citation:1][citation:5]。

### 2. 退赛规定

如参赛者决定退赛，可在2026年6月24日24:00前，登陆大广赛作品提交平台，点击【退赛】按钮申请退赛；2026年6月25日后，退赛申请将不予受理[citation:3]。

## 九、评审与奖项设置

### 1. 三级评选机制

大赛采用“一次参赛，三级评选”的模式：校级初赛、省级复赛、全国总决赛[citation:6]。

### 2. 营销创客单元评审规则

#### （1）区域选拔赛评审维度[citation:2]

| 评审维度 | 说明 |
|------|------|
| **创作原则** | 坚持正确的创作方向、价值取向与审美趣向，作品需符合国家法律法规、社会公序良俗 |
| **格调品味** | 坚守讲品味、讲格调的底线，坚决抵制庸俗、低俗、媚俗的创作倾向 |
| **创新现实** | 鼓励现实题材创作，着重提升大学生创新创造能力 |

#### （2）实战竞技赛评分标准（微短剧）[citation:2]

| 评分项 | 说明 |
|------|------|
| **剧本创作** | 主题新颖、内容精炼、人物鲜明 |
| **故事节奏** | 轻快，符合网络传播特点 |
| **定位精准** | 符合平台营销传播特点 |
| **制作技术** | 画面构图、剪辑技巧、灯光效果、音效合成等 |

## 十一、违规处理

### 1. 违规行为认定

| 违规行为 | 说明 |
|------|------|
| 剽窃抄袭 | 参赛作品非原创，存在抄袭行为 |
| 一稿多投 | 同一作品在不同类别或不同命题重复提交 |
| 购买作品 | 通过各种渠道购买他人作品参赛 |
| 信息不一致 | 报送至学校的作品与提交平台内容不一致 |

### 2. 违规处理方式

| 处理方式 | 说明 |
|------|------|
| 取消参赛资格 | 一经发现，即刻取消参赛资格 |
| 取消获奖资格 | 若已获奖，则取消该奖项 |
| 不予学分认定 | 信息错误问题，不予双创学分认定[citation:3] |
