# 全球校园人工智能算法精英大赛竞赛规则

## 一、竞赛简介

全球校园人工智能算法精英大赛（简称“AIC算法大赛”）自2019年起已经连续举办多届，共吸引来自全球26个国家和地区、1000多所高校选手参赛，累计参赛队伍超过2.4万支，参赛选手人数超过3.7万人[citation:6]。2023年3月，赛事首次被列入中国高等教育学会发布的《全国普通高校大学生竞赛分析报告》竞赛目录，正式成为全国性学科竞赛[citation:3][citation:6]。

大赛秉持“以赛促学、以赛促教、以赛促创”的理念，聚焦“人工智能+”知识体系下的人才能力培养及人工智能核心技术应用，搭建算法竞技舞台，激发学子探索算法世界热情，增强自信、开拓视野，助力人工智能算法精英人才成长[citation:2][citation:3]。

第八届全球校园人工智能算法精英大赛于2026年6月至12月举办，全国总决赛定于2026年12月底前举行。

## 三、赛道设置

第八届大赛共设置6个赛道，各赛道竞赛规则于6月20日陆续公布[citation:2][citation:4]。

### 1. 算法挑战赛

测试参赛选手运用AI算法解决实际问题的能力和水平，算法赛题均来自实际应用场景需求[citation:2][citation:8]。

**赛题示例**[citation:2][citation:8]：
- 大规模SAR图像多类别有向目标检测
- 4D毫米波雷达和单目摄像头视觉融合算法
- 视觉+几何+语义：多源异构数据协同的视频目标跟踪
- 网络监督细粒度图像识别
- 基于AI的智能旅行规划
- 基于图书借阅数据的用户潜在借阅预测推荐
- AI算法在新材料未知相指标化中的应用
- 基于AI的化学反应过渡态结构预测
- 材料科学图像曲线识别与智能解析
- 离线强化学习工业应用

### 2. 算法创新赛

展现参赛选手运用AI解决实际问题的能力，挖掘和遴选一批优秀算法创新成果作品[citation:2]。

**赛题方向**[citation:2][citation:4]：
- 算法模型创新

- 智能硬件创新

- AI+创新创业
- AI未来场景

## 五、赛制流程

大赛根据不同赛道采用两种赛制：“赛区制”和“赛马制”[citation:2][citation:4]。

### 1. 第八届时间安排

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **报名开放时间** | 6月20日[citation:2][citation:4] | 大赛官网报名系统开放 |
| **报名截止时间** | 详见各赛道通知[citation:2] | 各赛道截止时间不同 |
| **校赛完成时间** | 由各院校自行决定[citation:2][citation:4][citation:6] | - |
| **省赛（区域赛）完成时间** | 11月20日前[citation:2][citation:4] | 具体时间、地点由各省赛组委会发布 |
| **全国总决赛** | 12月底前[citation:2][citation:4][citation:6] | 完成所有竞赛项目全国总决赛 |

### 2. 各赛道赛制

#### （1）“赛区制”赛制

适用于**算法创新赛、算法应用赛**[citation:2][citation:4]。

采用“校赛-省赛-总决赛”三级赛制，按参赛选手高校所在地划分赛区：

| 层级 | 说明 |
|------|------|
| **校赛** | 由学校自行组织，推荐成绩前30%晋级省赛[citation:2][citation:4] |
| **省赛（区域赛）** | 省赛组委会负责所在赛区竞赛组织实施。未设立省赛组委会或若个别省份参赛团队数量过少不能成赛，则设立区域赛[citation:2][citation:4] |
| **全国总决赛** | 省赛（区域赛）一、二等奖获奖作品推荐参加全国总决赛[citation:2][citation:4] |

#### （2）“赛马制”赛制

适用于**算法挑战赛、算法主题赛**[citation:2][citation:4]。

采用“初赛-复赛-总决赛”三级赛制，不分赛区：

| 层级 | 说明 |
|------|------|
| **初赛** | 设置基础性和简单性任务或目标，只要达到基本成绩均可进入复赛[citation:1] |
| **复赛** | 难度适中，成绩排名前40%选手进入半决赛[citation:1]；复赛等同省级赛事，复赛一、二等奖获奖作品推荐参加全国总决赛[citation:2][citation:4] |
| **半决赛** | 难度较高，成绩排名前40%选手进入总决赛[citation:1] |
| **全国总决赛** | 总决赛采用线下答辩形式，对选手解题思路进行评判打分，同时对选手提供的技术报告、模型、源代码等材料进行复核[citation:1] |

#### （3）其他赛制

“产业命题赛、算法专项赛”赛制方式详见相应竞赛通知[citation:2][citation:4]。

### 3. 总决赛比赛形式

全国总决赛采用线下答辩形式，对选手解题思路进行评判打分，同时对选手提供的技术报告、模型、源代码等材料进行复核[citation:1]。

## 六、评审标准

### 1. 成绩评判要求

赛题可根据选手提交结果文件进行自动判分。成绩计算规则应该保持一定区分度，避免出现多数选手出现满分或同分数的情况[citation:1]。

### 2. 评审维度

| 评审维度 | 说明 |
|----------|------|
| **算法设计** | 算法的创新性和科学性 |
| **程序实现** | 代码实现的规范性和效率 |
| **问题解决能力** | 解决实际问题的能力[citation:1] |
| **答辩表现** | 现场陈述的逻辑性、清晰度和答辩应变能力[citation:1] |

### 3. 赛题难度设置

为客观评价选手算法掌握能力，赛题设置考虑设置梯度难度[citation:1]：

| 赛段 | 难度设置 |
|------|----------|
| 初赛 | 基础性和简单性任务或目标 |
| 复赛 | 难度适中 |
| 半决赛 | 难度较高 |

## 十、学术诚信与监督

### 1. 学术诚信要求

- 参赛作品必须是参赛者的原创作品，未侵犯任何他人的任何知识产权[citation:4]
- 出题团队确保赛题未在其他竞赛中使用过，赛题及相关数据材料未侵犯他人知识产权[citation:1]
- 所有参赛作品必须是具有作者独立知识产权的、未发表过的原创作品。否则引起的法律纠纷及责任由作者本人承担。组委会将取消作品的参赛资格[citation:4]

### 2. 监督机制

- 大赛设立仲裁委员会、纪律与监督委员会，负责监督大赛整体运行实施情况[citation:2]
- 发生争议时，由大赛仲裁委员会介入调查[citation:2]
- 校赛选拔赛比赛环节、评审方式等由各校、各地自行决定，赛事组织须接受省赛组委会或大赛组委会监督[citation:2]

### 3. 信息变更限制

校赛、省赛、国赛，中途不可随意更换队员和指导教师，否则后果自负[citation:4]。报名截止后，参赛团队及指导老师信息均不得变更[citation:2]。
