# 国际大学生智能农业装备创新大赛竞赛规则

## 一、竞赛简介

国际大学生智能农业装备创新大赛（以下简称“大赛”）由国际农业和生物系统工程委员会、中国农业机械学会、中国农业工程学会、省部共建现代农业装备与技术协同创新中心（江苏大学）、农业工程大学国际联盟联合主办[citation:1]。大赛旨在培养学生创新精神、实践能力，激发创新创业灵感，推动高等院校农业装备工程领域创新创业人才培养和农业工程专业学生国际交流[citation:1]。

大赛以“发展农装新质生产力，赋能农业高质量发展”或“智汇农装创未来，科技赋能兴农业”为主题[citation:1][citation:3]，以培育行业亟需的“专业知识雄厚、动手能力较强、创新创业能力过硬”的现代农业装备创新创业人才为目标，努力创建高校、院所、企业和行业深度参与国内国际双向融合的综合育人平台，助力现代农业装备产业创新发展[citation:1]。大赛已成为农业装备工程领域颇具影响力、培养学生创新创业能力和综合素质成效显著的大学生竞赛项目，2023年成为中国高等教育学会的“全国普通高校学科竞赛排行榜”正式榜单赛事[citation:3]。

第十一届国际大学生智能农业装备创新大赛冠名为“奥凯杯”，由甘肃农业大学承办[citation:1]，决赛预计于2026年5月举行。

## 三、大赛宗旨

大赛以“发展农装新质生产力，赋能农业高质量发展”或“智汇农装创未来，科技赋能兴农业”为主题[citation:1][citation:3]，以培育行业亟需的“专业知识雄厚、动手能力较强、创新创业能力过硬”的现代农业装备创新创业人才为目标，努力创建高校、院所、企业和行业深度参与国内国际双向融合的综合育人平台，助力现代农业装备产业创新发展[citation:1]。

## 五、作品类别

作品分为A类、B类、C类和D类四个类别[citation:1]。

### 1. A类：自由选题类

为智能农业装备领域科技发明制作，主要包括[citation:1]：
- A1 智能耕作农业装备发明
- A2 智能种植农业装备发明
- A3 智能田间管理农业装备发明
- A4 智能节水灌溉农业装备发明
- A5 智能收获农业装备发明
- A6 智能产地初加工农业装备发明
- A7 基础零部件（液压部件、传动系、传感器、电驱动、导航等）
- A8 其他智能农业装备

**队长要求**：学历最高的作者为作品队长，按队长划分作品层次[citation:1]。

### 2. B类：机器人类

第十一届大赛主题为**马铃薯捡拾机器人**[citation:1]。

**队长要求**：学历最高的作者为作品队长，按队长划分为专本组、硕博组[citation:1]。

### 3. C类：企业出题类

由农业装备行业企业出题，学生选题进行创新设计[citation:1]。C类选题于大赛官网发布，敬请关注[citation:1]。

**队长要求**：不限定学历与队长，允许专科生、本科生和研究生混合组队[citation:1]。

### 4. D类：概念设计类

指面向未来的具有超前意识或颠覆性的智能农业装备创意设计及整机造型设计[citation:1]。

**队长要求**：学历最高的作者为作品队长，按队长划分作品层次[citation:1]。

**特别声明**：
针对有的学生为了避开A、C类作品须有样机或实物模型的规定，取巧申报D类作品的现象，作出以下声明[citation:1]：

> D类作品必须是具有颠覆性的创意设计或工业设计，不属于此内涵的作品，秘书处在形式审查时一票否决，作品将不进入复赛环节[citation:1]。

请各推荐单位对D类内涵严格把关，一旦出现本属于AC类内涵的作品推荐申报D类参赛，将停止下一届D类作品一届的申报资格[citation:4]。

## 八、参赛成果要求

### 1. 成果原创性与真实性

参赛作品须是学生团队**自主研发设计**的样机、实物模型、软件、概念视频等成果[citation:1]。

### 2. 成果时效要求

涉及的论文、专利等必须是**近二年（2023年9月～2025年9月）** 的成果[citation:1]。

### 3. 各类作品具体要求

| 作品类别 | 具体要求 |
|----------|----------|
| **A类、C类** | 须有样机或实物模型[citation:1] |
| **D类** | 须有概念视频或实物模型（MP4格式、720P、200M以内）[citation:1] |

### 4. 禁止性规定

| 禁止事项 | 说明 |
|----------|------|
| **禁止使用已获国奖成果** | 不得使用已获得国家级竞赛奖励的成果进行申报[citation:1] |
| **禁止使用导师成果** | 不得直接使用导师成果进行申报[citation:1] |
| **禁止剽窃** | 不得剽窃任何不属于本人的成果申报[citation:1] |
| **禁止雷同重复** | 作品核心内容不能与前十届参赛作品雷同或者重复[citation:1] |
| **禁止无署名知识产权** | 禁止使用无参赛学生署名的知识产权（如：专利、论文等）参赛[citation:1] |

### 5. 违规处理

对于违背大赛成果要求、弄虚作假者的参赛作品，大赛委员会核实后将在大赛官方网站或在大赛有关会议范围内通报参赛高校、参赛学院、指导教师和参赛学生名单，同时取消获奖作品资格、优秀指导教师资格和高校“优胜杯”资格；情形严重的，将依据大赛《章程》追究有关人员责任[citation:1]。

## 九、赛制流程

### 1. 第十一届大赛时间安排

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **报名** | 2025年9月10日-2025年11月30日 | 大赛官网注册报名[citation:1] |
| **作品申报** | 2025年12月1日-2025年12月20日 | 提交参赛作品材料[citation:1] |
| **资格审查** | 2025年12月21日-2025年12月30日 | 大赛承办单位对上报的参赛作品进行形式审查[citation:1] |
| **复赛** | 2026年1月1日-2026年3月5日 | 网络评审，按网评成绩排名，根据参赛情况综合确定进决赛比例[citation:1] |
| **决赛** | 预计2026年5月 | 甘肃农业大学举行[citation:1] |

### 2. 各阶段比赛形式

#### （1）校级选拔赛
- 由各高校自行组织，形式多为材料评审+现场答辩[citation:4][citation:5]
- 校赛奖项：设一、二、三等奖若干，获奖比例根据参赛规模确定[citation:5]
- 晋级规则：同类作品排名最高的优胜队方有资格代表学校参加国赛[citation:4]

**重要规定**：
- 未经校赛选拔、学校推荐的作品，不允许私自报名参加国赛[citation:4]
- 通过校赛选拔并计划报名参加国赛的作品，在国赛报名前，必须完成比赛规则所规定的全部设计任务且保证能顺利参加国赛现场赛[citation:4]

#### （2）复赛（网络评审）
- 通过形式审查的A、C、D类参赛作品，将进行复赛选拔[citation:1]
- 复赛采用网络评审方式，按网评成绩进行排名[citation:1]
- 复赛成绩不带入决赛[citation:1]
- 入围决赛的作品名单于2026年3月在大赛官网进行公示[citation:1]

**复赛分组**：
- 创意组（A类）
- 行业组（C类）
- 概念组（D类）[citation:1]

**B类比赛**将在决赛期间进行[citation:1]。

#### （3）全国决赛
- 决赛期间，A、C、D类作品进行现场问辩，参赛团队须将自主研制的样机、实物模型及概念视频等成果带到现场展示[citation:1]
- B类作品现场比赛[citation:1]
- A、C类作品如尺寸或质量特别大不便携带或物流发送，可提出申请，经大赛组委会审核同意后可采用现场视频连线的方式进行展示汇报，不得采用播放提前录制视频的形式[citation:1]
- 如不能现场展示或者现场视频连线展示，不能获特、一、二等奖[citation:1]

## 十、评审标准

### 1. 评审观测点

评审委员会本着“公平、公正、公开、科学、规范”的原则，通过设计资料审阅、现场答辩和实物演示等程序对参赛作品进行综合评审，确定获奖作品及等级[citation:4]。评审观测点包括以下几个方面[citation:4]：

| 评审维度 | 观测点 |
|----------|--------|
| **选题** | 新颖性；实用性；意义或前景 |
| **设计** | 创新性；结构合理性；工艺性；先进理论和技术的应用；设计图纸质量 |
| **制作** | 功能实现；制作水平与完整性；作品性价比 |
| **现场表现** | 介绍及演示；答辩与质疑 |

## 十一、奖项设置

### 1. 学生参赛作品奖

设特等奖、一等奖、二等奖以及优秀奖，大赛委员会决赛期间根据当年参赛作品数量和质量决定各等次获奖作品数量[citation:1]。

**特别规定**：
- A、C类无样机或实物模型的作品，不能获特、一、二等奖[citation:1]
- D类无概念视频的作品，不能获特、一、二等奖[citation:1]

### 2. 高校“优胜杯”奖

大赛将颁发一定数量的“优胜杯”，具体以参赛高校为单位，按照获奖作品总积分，从高分到低分排序[citation:1]。

**积分标准**：

| 获奖等级 | 积分 |
|----------|------|
| 特等奖 | 100分 |
| 一等奖 | 70分 |
| 二等奖 | 40分 |
| 优秀奖 | 10分 |

如遇积分相同，按照特等奖的个数计算，以此类推[citation:1]。

### 3. 优秀指导教师奖

大赛将为获得特等奖作品的指导教师颁发“优秀指导教师奖”[citation:1]。

### 4. 校级选拔赛奖项

各高校自行组织校内选拔赛，通常设一等奖、二等奖、三等奖若干[citation:5][citation:10]。例如，华北水利水电大学校赛获奖比例按照一等奖20%-30%、二等奖20%-30%、三等奖30%-40%设置[citation:10]。

## 十二、大赛成果转化

大赛将在决赛期间组织学生项目成果供需洽谈会和项目签约仪式[citation:1]。原则上，要求C类获奖项目学生团队与企业签订合作意向书，有关知识产权和成果转让等问题由学生与企业共同协商确定[citation:1]。
