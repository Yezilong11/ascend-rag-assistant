# “西门子杯”中国智能制造挑战赛竞赛规则

## 一、竞赛简介

“西门子杯”中国智能制造挑战赛（原为全国大学生控制仿真挑战赛、全国大学生工业自动化挑战赛）是在教育部与西门子公司战略合作框架下的一项国家级A类赛事[citation:2]。大赛由教育部高等学校自动化类专业教学指导委员会、西门子（中国）有限公司和中国仿真学会联合主办[citation:10]。

自2006年发展至今，大赛已得到全国近800所高校的支持，成为目前国内智能制造领域规模最大的学生类竞赛之一[citation:2][citation:4]。大赛于2019年纳入中国高等教育学会《全国普通高校学科竞赛排行榜》评估竞赛项目，同年成为中国高等教育学会“全国高校机器人竞赛创新指数”竞赛项目[citation:2][citation:8]。

大赛秉承“立足培养，重在参与，面向工程，追求卓越”的指导思想，旨在促进高等学校素质教育，着力提高学生的工程兴趣、工程素养、工程设计能力、工程实践能力和工程创新能力，倡导理论联系实际、求真务实的学风和团队协作的人文精神[citation:1]。大赛以企业真实的工程项目和科研项目作为竞赛赛题，以真实的工业设备和工业环境作为赛场，以工业企业的工程标准作为考核评分指标，全面锻炼学生解决复杂工程问题的综合能力、系统思维[citation:4][citation:9]。

## 三、竞赛类别与赛项设置

大赛分为“智能制造创新研发类”与“智能制造工程设计与应用类”两大类别[citation:3][citation:5]。

### 1. 智能制造创新研发类

| 赛项 | 说明 | 竞赛形式 |
|------|------|----------|
| **自由探索方向** | 组委会专家扮演风险投资人，参赛队扮演创业团队。根据国家发展战略、企业市场需求确定创新研发方向与范围，完成产品市场调研、创意设计、产品开发、原型机制作等[citation:5] | 省赛线上，总决赛线下 |
| **工业硬件研发方向（试）** | 组委会作为甲方，参赛队作为乙方，根据实际生产中面临的真实问题进行项目招标，完成问题解析、方案设计以及设备研发[citation:5] | 省赛线上提交方案，总决赛线下 |

| 赛项 | 背景说明 | 涉及知识 | 竞赛形式 |
|------|----------|----------|----------|
| **流程行业自动化方向** | 以炼油、化工、制药等典型流程行业工艺为背景[citation:1][citation:5] | 集散控制系统（DCS）、工业通讯网络、人机界面、过程控制工程[citation:5] | 省赛线下，总决赛线下 |
| **离散行业自动化方向（逻辑算法）** | 以电梯群控调度为背景[citation:5][citation:7] | 可编程控制器（PLC）、群控算法[citation:5] | 省赛线下，总决赛线下 |
| **离散行业自动化方向（工程实践）** | 以汽车制造等典型离散行业工艺为背景[citation:1][citation:5] | 可编程控制器（PLC）、工业物联网、RFID、机器视觉[citation:5] | 省赛线下，总决赛线下 |

| **智能制造通识方向（筹）** | 以某智能制造工程项目为应用背景，限本科1-2年级同学参加（单人组队）[citation:5] | 智能制造通论、信号与数据基础、数据可视化、自动化系统[citation:5] | 省赛线下（分赛区+赛点），总决赛线下 |
| **工业嵌入式系统开发方向（筹）** | 以工业现场数据采集与存储为背景，限本科1-2年级同学参加[citation:5][citation:8] | C语言、单片机原理、数字电子技术、模拟电子技术[citation:5] | — |

## 四、参赛资格与要求

### 1. 参赛对象

- **学历要求**：全国普通高等院校全日制在籍学生（本科生、硕士生、博士生均可参赛）[citation:2][citation:3]
- **专业范围**：控制科学与工程、电气工程、机械工程、仪表科学与工程、信息与通讯工程、计算机科学与技术等相关学科[citation:4]

### 2. 组队要求

| 项目 | 要求 |
|------|------|
| **队伍组成** | 每支参赛队由1-3名参赛选手和1-2位指导教师组成[citation:1][citation:3] |
| **智能制造通识方向** | 每支参赛队限1名参赛者（限本科1-2年级）[citation:2][citation:5] |
| **参赛限制** | 每位同学只能参加1支参赛队，每支队伍只能选择1个赛项[citation:2][citation:3] |
| **研究生限制** | 工程设计与应用类赛项至多允许1名研究生；创新研发类赛项至多允许2名研究生[citation:3] |
| **指导教师** | 每支队伍必须指定1位教师为第一指导教师，第一指导教师所在学院为本队伍所在学院。指导老师负责赛前指导，不得直接参与比赛现场的正式比赛环节[citation:1][citation:3] |
| **跨校组队** | 不同学校的学生不可联合组队[citation:1] |

### 3. 禁止参赛情况

- 竞赛报名截止后，所有赛项参赛队不得更换赛项（及选题方向），不得更换、增加参赛成员以及指导老师[citation:3][citation:4]
- 各分赛区及竞赛组织机构中相关赛项工作人员不得担任本赛项指导老师带队参赛[citation:7]

## 五、赛制流程

大赛分校级初赛（校赛）、省级/分赛区复赛（省赛/初赛）、全国决赛（国赛）三级赛制[citation:10]。

### 1. 时间安排（以第十九、二十届为例）

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| 报名阶段 | 每年3月1日-5月31日[citation:1][citation:4] | 官网注册报名 |
| 校级选拔赛 | 每年4月-5月 | 各高校自行组织 |
| 省赛/初赛 | 每年7月[citation:2][citation:9] | 分赛区线下/线上进行 |
| 全国总决赛 | 每年8月中下旬[citation:9][citation:10] | 线下进行 |

### 2. 各阶段比赛形式

#### （1）校级初赛
- 由各高校自行组织[citation:2]
- 形式：程序（实物功能）演示及方案答辩两个环节，评委从中选出优秀选手参加赛区赛[citation:2]
- 校赛奖项：设特等奖、一等奖、二等奖、三等奖若干[citation:2]

#### （2）省级/分赛区复赛
- 以省为单位组织，部分赛项在分赛区线下比赛[citation:4]
- 初赛分别设置特等奖、一等奖、二等奖和三等奖，所有奖项的证书由全国竞赛组委会颁发[citation:4]
- 晋级规则：各赛项（组别）荣获全国初赛特等奖及一等奖的参赛队伍中，每所高校成绩最高的1支队伍进入候选名单，然后根据成绩择优晋级。如晋级名额出现空缺，空缺名额将从各高校成绩第二的队伍按成绩从高到低择优补齐，每所高校最多晋级2支队伍[citation:9]

#### （3）全国决赛
- 总决赛均为线下比赛，由裁判、专家和计算机评分[citation:6]
- 设队伍特等奖、一等奖、二等奖[citation:4]
- 各赛项各组别成绩第一名队伍将被授予奖杯以及奖学金[citation:4]

## 六、比赛内容与要求

### 1. 流程行业自动化方向

**项目方案设计内容**：
- 系统分析：包括需求分析、对象特性分析、安全分析等
- 控制系统设计：包括开车顺序、控制回路、控制P&ID图、控制算法、仪表选型、安全联锁、人机界面等
- 控制系统组成：包括控制器、IO卡件、通讯网络等
- 系统实施说明：包括系统连接、系统安装、系统组态、系统整定、系统调试、系统投运等
- 经济效益分析：包括产能、耗能、安全、环保等[citation:1]

**项目方案实施内容**：
- 在SIMATIC S7-400 PLC上，完成硬件组态和控制程序开发；在SIMATIC WINCC上，完成监控画面组态与开发；建立PLC和WINCC之间的通讯连接
- 系统调试：包括控制器参数整定、故障排除、系统投运等
- 系统验收：包括项目方案设计书、现场实施报告，接受甲方对系统性能的评估[citation:1]

### 2. 离散行业自动化方向（逻辑算法）

**项目方案设计内容**：
- 系统分析：包括需求分析、对象特性分析、安全分析等
- 控制系统设计：包括控制回路、安全联锁等
- 方案架构设计：包括系统结构拓扑、功能设计、实现原理、网络数据传输协议等
- 系统设备选型：包括硬件设备、控制器、IO卡件、通讯网络等
- 系统实施说明：包括系统连接、系统安装、系统调试、系统投运等
- 经济效益分析：包括能耗、安全、环保等[citation:1]

**项目方案实施内容**：
- 在SIMATIC S7-1200 PLC上，完成硬件组态和控制程序开发；在SIMATIC WINCC上，完成监控画面组态与开发；建立PLC和WINCC之间的通讯连接；通过工业智能网关建立服务器与现场层的数据通讯连接
- 系统调试：包括控制器参数整定、故障排除、系统投运，智能网关组网、程序设计、界面展示等
- 系统验收：包括项目方案设计书、现场实施报告，接受甲方对系统性能的评估[citation:1]

### 3. 离散行业运动控制方向

**项目方案设计内容**：
- 系统分析：包括需求分析、对象特性分析、安全分析等
- 控制系统设计：包括控制逻辑、控制算法等的选择及理由[citation:1]

**项目方案实施内容**：
- 在SIMATIC CPU 315T-3 PN/DP（或SIMATIC CPU 1516-3 PN/DP）、SINAMICS S120驱动器上，完成硬件组态及控制程序开发；在Wincc上完成人机界面开发；建立相关设备间的通讯连接
- 系统调试：包括控制器驱动器参数整定、故障排除、系统开车等
- 系统验收：包括项目方案设计书、现场实施情况，接受甲方对系统性能的评估[citation:1]

### 4. 离散行业自动化方向（工程实践）

**项目方案设计内容**：
- 系统分析：包括需求分析、对象特性分析、系统安全分析等
- 控制系统设计：包括控制算法/策略、人机界面及功能设计、安全保护等
- 控制系统选型：包括控制器、I/O模块、网络拓扑等
- 系统实施说明：包括系统连接部署、系统安装、系统调试、系统操作交互流程、常见故障分析及排查方法等
- 经济效益分析：包括效率、能耗、安全等[citation:1]

**项目方案实施内容**：
- 在SIMATIC S7-1200 PLC上，完成系统自动化控制流程设计和系统连接及网络拓扑；建立PLC和WINCC之间的通讯连接，对现场就地人机交互界面HMI进行设计与开发；利用智能网关进行本地数据采集，实现边缘计算网关与工业云交互实施
- 系统调试：包括控制器相关参数整定、系统故障排除、系统投放运行、分工作站建立、智能网关互联、动态检测、界面展示等
- 系统验收：接受对现场实施情况的评估[citation:1]

## 十、报名方式

### 1. 报名时间

每年3月1日-5月31日（具体以当年官网通知为准）[citation:1][citation:4]

### 2. 报名流程

1. **官网注册**：登录大赛官网（http://www.siemenscup-cimc.org.cn）注册报名、选择赛项、组队[citation:3][citation:7]
2. **校内备案**：将组队名单报至学院赛事负责人完成校内备案，加入各校赛事QQ群

- 所有参赛者、指导教师必须在竞赛官网注册并完善相关信息[citation:9]

- 报名截止后，所有赛项参赛队不得更换赛项，不得更换、增加参赛成员以及指导老师[citation:3]
