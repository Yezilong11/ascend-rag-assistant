# 中国大学生计算机设计大赛竞赛规则

## 一、竞赛简介

中国大学生计算机设计大赛（简称“4C”或“大赛”）启筹于2007年，始创于2008年，是由教育部计算机相关教指委发起创办的、我国高校面向本科生最早的赛事之一[citation:2]。大赛已连续举办18届，是全国普通高校大学生竞赛排行榜榜单赛事之一，也是教育部A类学科竞赛赛事之一[citation:6][citation:8]。

大赛的目的是以赛促学、以赛促教、以赛促创，为国家培养德智体美劳全面发展的创新型、复合型、应用型人才服务[citation:1]。大赛以“三安全”（竞赛内容安全、经济安全、人身安全）为前提，始终遵守“三服务”宗旨，即为学生社会就业需要服务、为本专业需要服务、为创新创业人才培养的需要服务[citation:5]。

第十九届中国大学生计算机设计大赛于2026年3月至8月举办，全国总决赛定于2026年7月至8月举行[citation:1][citation:4]。

## 二、组织机构

### 1. 主办单位

- **主办单位**：由北京语言大学、中国人民大学、华东师范大学、浙江大学、南京大学、东南大学、山东大学、厦门大学、东北大学等高校，以及清华大学、北京大学、复旦大学等高校的教师组成的中国大学生计算机设计大赛组织委员会[citation:3][citation:9]
- **创办单位**：教育部高等学校计算机类专业教学指导委员会、教育部高等学校软件工程专业教学指导委员会、教育部高等学校大学计算机课程教学指导委员会、教育部高等学校文科计算机基础教学指导分委员会[citation:5]

### 2. 竞赛官网与联系方式

- **大赛官方网站**：http://jsjds.blcu.edu.cn/ [citation:1]
- **本科组作品提交平台**：http://2026.jsjds.com.cn/ [citation:2]
- **官方微信公众号**：计算机设计大赛服务号、计算机设计大赛JX信息[citation:2]
- **组委会联系方式**：详见官网公告

## 三、参赛对象与组队要求

### 1. 参赛对象

| 项目 | 要求 |
|------|------|
| **学历要求** | 全国普通高校2026年在籍的本科生（含港澳台学生，以及来华留学生）[citation:3][citation:9] |
| **专业范围** | 所有专业均可报名，专业不限 |

### 2. 团队组成要求

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每件作品的参赛者由同一所院校的**2-9名本科生**组成[citation:2][citation:3] |
| **指导教师** | 每队的指导教师不多于**2名**[citation:2][citation:8] |
| **组队范围** | 鼓励跨年级、跨专业、跨学院组队[citation:3] |
| **参赛限制** | 每位作者在每个大类中只能提交1件作品，无论作者排名如何[citation:3][citation:9] |
| **答辩要求** | 每队到国赛决赛现场参与答辩的作者不少于（含）2人（特殊情况除外）[citation:3][citation:9] |

## 四、竞赛类别与作品主题

### 1. 2026年大赛作品分类

第十九届大赛分设**11个大类**[citation:2][citation:8][citation:9]：

| 类别编号 | 大类名称 |
|------|------|
| （1） | 软件应用与开发 |
| （2） | 微课与AI辅助教学 |
| （3） | 物联网应用与物联网创新转化（创业实践） |
| （4） | 大数据应用 |
| （5） | 人工智能应用 |
| （6） | AI+信息可视化设计 |
| （7） | AI+数媒静态设计 |
| （8） | AI+数媒动漫与短片 |
| （9） | AI+数媒游戏与交互设计 |
| （10） | AI+计算机音乐创作 |
| （11） | 国际生“AI+汉学”（“中华优秀传统文化”数智创作） |

注：其中（7）、（8）、（9）三个大类统称为数媒类[citation:8]。

### 2. 2026年大赛作品主题

2026年大赛的**（6）至（11）共6个大类**的作品主题是：

**“中国古代建筑成就——中华优秀传统文化系列之六”**[citation:2][citation:3][citation:8]

**主题内容要求**：
- 内容包括：民居、官府、皇宫、桥梁（**不含庙宇、宝塔**）
- 时间限制：修建时间限在**1911年以前**[citation:2][citation:9]

**具体包括**：
（1）中国古代建筑成就——弘扬中华优秀自然科学成就
（2）中国古代建筑领域杰出科学家——弘扬中华优秀古建筑科学家精神
（3）中国古代建筑著作——弘扬中华优秀古建筑学专著
（4）中国古代建筑文化——弘扬中华优秀古建筑文明和文化传承[citation:2]

### 3. AI工具使用要求

参赛作品若使用AI工具，则需采用大赛组委会指定的**15款国产免费AI工具**（每年动态调整一次），或采用拥有自主知识产权的AI工具[citation:3][citation:9]。

## 五、赛制流程

大赛采用**校级赛-省级赛-国家级赛（国赛）**三级竞赛形式[citation:1][citation:7]。国赛只接受省级赛（含相当于省级赛的西北赛区、中南赛区，以及计算机音乐创作跨省区域赛）上推的普通高校全日制本科生的参赛作品[citation:9]。

## 六、作品要求

### 1. 原创性与时效性要求

| 项目 | 要求 |
|------|------|
| **完成时间** | 必须是参赛者在本届大赛期间（**2025年7月1日—2026年6月30日**）完成的原创作品[citation:1][citation:2][citation:3] |
| **禁止重复参赛** | 与2025年7月1日之前校外展出或获奖的作品雷同的作者的前期作品，不得重复参赛[citation:1][citation:3] |
| **知识产权** | 参赛作品的版权必须属于参赛作者，不得侵权；凡已经转让知识产权或不具有独立知识产权的作品，均不得参赛[citation:1][citation:3] |
| **一稿多投** | 参赛作品不得在本大赛的11个大类间一稿多投[citation:2][citation:3] |

### 2. 内容要求

| 项目 | 要求 |
|------|------|
| **内容健康** | 参赛作品要求内容健康、积极向上，符合国家宪法和相关法律、法规[citation:5] |
| **地图使用** | 参赛作品中如果包含地图，在涉及国家当代疆域时，应注明地图来源（如中华人民共和国自然资源部网站），并且注明审图号，否则属于违规，取消参赛资格[citation:1][citation:2] |
| **数据合规** | 参赛作品的数据应来源合规、使用得当，不得引用涉密数据，不得存在侵犯个人隐私等违法违规情形[citation:9] |
| **代码提交** | 软件类作品需同时提交该作品的源代码及源文件[citation:5] |

### 3. 提交材料要求

| 材料名称 | 要求说明 |
|------|------|
| **作品源文件** | 作品的过程文件或源文件 |
| **作品演示文件** | 用于网络评审及公示，时长不多于10分钟，文件大小不超过300M[citation:9] |
| **说明文件** | 作品说明文档 |
| **报名表** | 按规范填写 |

## 七、评审与奖项设置

### 1. 校级选拔赛奖项

| 奖项 | 获奖比例 | 说明 |
|------|----------|------|
| **一等奖** | 作品总数的5%[citation:3] | 由学校颁发证书 |
| **二等奖** | 作品总数的10%[citation:3] | 由学校颁发证书 |
| **三等奖** | 作品总数的20%[citation:3] | 由学校颁发证书 |

注：各校获奖比例略有不同，如山东财经大学采用上述比例，其他高校可能根据参赛规模调整[citation:3]。

### 2. 省级奖项

省级赛将分别评出一、二、三等奖，并将推荐一等奖参加国家级决赛[citation:2]。

### 3. 国家级奖项

| 奖项 | 获奖比例（以上推国赛有效参赛作品数为基数） |
|------|--------------------------|
| **全国一等奖** | 不多于上推国赛有效参赛作品数的**5%**[citation:4] |
| **全国二等奖** | 不少于上推国赛有效参赛作品数的**25%**[citation:4] |
| **全国三等奖** | 大约为上推国赛有效参赛作品数的**70%**[citation:4] |

注：所有入围全国总决赛的作品将获得相应的国家级获奖证书[citation:1][citation:7]。

## 八、违规处理

### 1. 违规行为认定

| 违规行为 | 说明 |
|------|------|
| 剽窃抄袭 | 参赛作品涉及剽窃、抄袭等违规行为 |
| 重复参赛 | 与前期作品雷同或使用已获奖作品参赛 |
| 一稿多投 | 同一作品在本大赛的多个大类间重复提交 |
| 提供虚假材料 | 参赛材料造假 |
| 知识产权侵权 | 侵犯他人知识产权 |
| 地图使用违规 | 涉及国家疆域的地图未注明来源和审图号 |

### 2. 违规处理方式

| 处理方式 | 说明 |
|------|------|
| 取消参赛资格 | 一经发现，即刻取消参赛资格[citation:1][citation:2] |
| 撤销奖项 | 若已获奖，则取消该奖项[citation:1][citation:2] |
| 官网公布 | 在大赛官网上公布违规作品的作品编号、作品名称、作者与指导教师姓名、相关人员所在学校校名，以及所在省级赛区名[citation:1][citation:2] |
| 学校处分 | 学校也会给予相应处分[citation:5] |
| 学术不端黑名单 | 取消其4年内的比赛资格[citation:9] |

## 九、报名方式

### 1. 通用报名流程

1. **校内组队**：按作品类别要求组队（2-9人），确定指导教师（不超过2人）
2. **加入校赛QQ群**：加入各校竞赛QQ群，获取后续通知
3. **校内报名**：按各校要求完成校内报名，提交报名表和参赛作品
4. **参加校赛**：通过校内选拔赛后获得省赛参赛资格
5. **省赛报名**：在省级赛平台完成报名（各省时间不同）
6. **国赛报名**：在通过省级赛获得入围国赛资格后，须通过国赛竞赛平台（2026.jsjds.com.cn）完成信息填报和核查工作，截止日期为**2026年5月30日**，逾期视为自动放弃参赛资格[citation:4]

**重要提示**：在获得国赛参赛资格后，其作者与指导教师的姓名和排序，**不得变更**[citation:4]。
