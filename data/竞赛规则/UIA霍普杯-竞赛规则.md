# UIA霍普杯国际大学生建筑设计竞赛竞赛规则

## 一、竞赛简介

UIA霍普杯国际大学生建筑设计竞赛由国际建筑师协会（UIA）国际认证，是中国最具影响力的大学生建筑设计竞赛之一。该竞赛由天津大学建筑学院、北京《城市·环境·设计》（UED）杂志社主办，上海霍普建筑设计事务所股份有限公司独家冠名赞助。自2012年起，竞赛已连续成功举办十余届，每届吸引全球众多知名院校学生参与，提交作品数量逐年攀升。

竞赛秉承国际建筑师协会（UIA）“建立一整套以建议和方案来解决全球建筑与城市规划问题的方法论”的宗旨，面向全世界建筑院校学生征集优秀建筑设计作品，旨在积极鼓励各国年轻建筑师和建筑学子不断思考与探索，激发创造力，启迪设计思想，促进建筑学的国际交流与发展。

## 二、组织机构

### 1. 主办与支持单位

| 机构类型 | 单位名称 |
|------|------|
| **国际主办** | 国际建筑师协会（UIA） |
| **国内主办** | 天津大学建筑学院、北京《城市·环境·设计》（UED）杂志社 |
| **独家冠名** | 上海霍普建筑设计事务所股份有限公司 |

### 2. 组织架构

| 机构 | 职责 |
|------|------|
| **学术委员会** | 由国内外知名建筑院校院长、系主任、著名建筑师组成，负责竞赛的学术指导和评审工作 |
| **组织委员会** | 负责竞赛的整体组织与协调工作 |
| **评审委员会** | 每年邀请国内外知名建筑师、建筑教育家担任评委，负责参赛作品的评审工作 |

### 3. 竞赛官网与联系方式

- **官方网站**：http://hypcup.uedmagazine.net/ 
- **官方微信公众号**：UED城市环境设计

## 三、参赛资格与要求

### 1. 参赛对象

| 项目 | 要求 |
|------|------|
| **学历要求** | 国内外建筑院校在校大学生（含本科生、硕士研究生、博士研究生）均可报名参赛 |
| **毕业生资格** | 当年毕业的学生可以以在校生身份参赛 |
| **组队方式** | 个人参赛或团队参赛均可 |

### 2. 团队组成要求

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每组参赛人数不超过5人 |
| **指导教师** | 每组可设指导教师不超过2名 |
| **组队范围** | 鼓励跨年级、跨专业、跨校组队 |

### 3. 参赛限制

- 每位参赛者只允许提交一份作品，无论个人独立参赛还是作为团队成员参与
- 已获其他竞赛奖项的作品不得重复参赛
- 参赛作品须为原创，不得侵犯他人知识产权

## 四、竞赛主题与命题

### 1. 命题方式

UIA霍普杯每年邀请一位国际著名建筑师或建筑教育家担任命题人，设置年度竞赛主题。命题关注当代建筑学的前沿议题，回应全球性挑战，鼓励学生进行创新性思考。

### 2. 历年命题人及主题示例

| 年份 | 命题人 | 命题主题 |

| 2024年 | 雷姆·库哈斯（OMA创始人） | 具体主题以当年通知为准 |
| 2023年 | 卡莫·皮格姆（2017年普利兹克奖得主） | 具体主题以当年通知为准 |

注：每年具体命题于当年竞赛通知中公布。

## 五、作品要求

### 1. 作品内容要求

参赛作品应包含以下内容：

| 内容 | 说明 |
|------|------|
| **设计说明** | 阐述设计理念、策略及创新点（中英文双语） |
| **图纸表达** | 包括但不限于总平面图、平面图、立面图、剖面图、分析图、效果图等 |
| **模型照片** | 可选，可作为辅助表达 |
| **其他表达** | 可根据设计需要增加其他表达方式 |

### 2. 图纸格式要求

| 项目 | 要求 |
|------|------|
| **图纸尺寸** | 统一为A0尺寸（841mm×1189mm），竖版构图 |
| **图纸数量** | 每份作品限2张A0图纸 |
| **文件格式** | JPG或PDF格式，分辨率不低于300dpi |
| **文件大小** | 单张图纸不超过50MB |
| **语言要求** | 图纸中文字须为中英文双语 |

### 3. 匿名要求

为保障评审的公平公正，参赛作品图纸中不得出现任何反映作者、指导教师及学校的信息，包括但不限于：

- 作者姓名、学号
- 指导教师姓名
- 学校名称、校徽、院系标识
- 任何可识别个人或学校的文字、符号、图案

违反匿名要求的作品将被取消参赛资格。

### 4. 原创性要求

- 参赛作品必须为原创，未在其他竞赛中获奖，未在公开媒体发表
- 不得抄袭、剽窃他人成果
- 如使用他人图片、资料，须在图纸中注明出处

## 六、提交方式

### 1. 提交材料清单

| 材料名称 | 要求说明 |
|------|------|
| **参赛作品图纸** | 2张A0尺寸图纸，JPG或PDF格式 |
| **报名表** | 从官网下载，填写完整并签字 |
| **作者身份证明** | 学生证扫描件或学籍证明 |
| **作品说明文档** | 可选，WORD格式，简要说明设计理念 |

### 2. 提交方式

参赛者需在规定时间内，通过官方网站提交系统完成作品上传。

**提交步骤**：
1. 登录竞赛官网注册账号
2. 填写参赛者信息
3. 上传作品图纸及相关材料
4. 确认提交

### 3. 提交截止时间

以当年竞赛通知公布的截止时间为准，逾期提交系统自动关闭，不予受理。

## 七、评审标准

### 1. 评审维度

| 评审维度 | 说明 |
|------|------|
| **创新性** | 设计理念的创新程度，对命题的独特解读 |
| **逻辑性** | 设计逻辑的清晰性和完整性 |
| **技术性** | 建筑技术的合理性和可行性 |
| **表达性** | 图纸表达的清晰度和艺术性 |
| **社会性** | 对社会现实的回应和思考深度 |

### 2. 评审流程

| 阶段 | 说明 |
|------|------|
| **初评** | 由评审委员会对全部参赛作品进行筛选，确定入围作品 |
| **终评** | 评审委员会对入围作品进行综合评议，确定获奖作品 |
| **结果公示** | 获奖名单在官网公示，接受社会监督 |

### 3. 评委构成

每年邀请国际著名建筑师、建筑院校教授担任评委，确保评审的专业性和权威性。往届评委包括普利兹克奖得主、UIA金奖得主、知名建筑院校院长等。

| **优秀奖** | 若干 | 获奖证书 |

### 2. 其他奖励

| 奖励 | 说明 |
|------|------|
| **作品发表** | 获奖作品将在《城市·环境·设计》（UED）杂志上择优发表 |
| **作品展览** | 获奖作品将在相关学术活动中展出 |

## 九、时间安排

### 1. 年度时间安排（参考）

| 阶段 | 时间安排 | 说明 |

| **注册报名** | 4月—8月 | 官网注册报名 |

参赛者需密切关注官网发布的各项时间节点，逾期提交的作品不予受理。

## 十一、学术诚信与监督

### 1. 学术诚信要求

- 参赛作品必须是参赛者的原创作品，未侵犯任何他人的知识产权
- 不得抄袭、剽窃他人成果
- 不得使用已获奖作品或已在其他竞赛中提交的作品重复参赛

### 2. 违规处理

| 违规行为 | 处理方式 |
|------|------|
| 抄袭、剽窃 | 取消参赛资格，追回已颁奖项，并在官网通报 |
| 匿名要求违规 | 取消参赛资格 |
| 一稿多投 | 取消参赛资格 |

### 3. 监督机制

竞赛设立监督机制，接受社会各界的监督。任何单位或个人对获奖作品有异议，可在公示期内向组委会提交实名书面申诉。
