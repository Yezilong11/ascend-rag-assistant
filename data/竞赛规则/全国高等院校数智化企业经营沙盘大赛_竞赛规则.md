# 全国高等院校数智化企业经营沙盘大赛竞赛规则

## 一、竞赛简介

全国高等院校数智化企业经营沙盘大赛（属于全国企业竞争模拟大赛的“数智沙盘赛道”）是一项面向全国高校大学生的具有中国特色的重要商业模拟赛事。该赛事已列入中国高等教育学会发布的《全国普通高校大学生竞赛分析报告》（全国普通高校大学生竞赛排行榜）竞赛项目之一[citation:2]。

大赛旨在通过还原真实的企业数智化转型改造应用场景，体现完整任务，主要考察选手对于企业经营管理应用的综合技能，突出应变能力[citation:2][citation:8]。赛事对促进管理理论与实践的结合、增进院校之间的友谊、培养学生的竞争意识和团队合作精神具有重要意义[citation:2]。

## 三、参赛资格与要求

### 1. 参赛对象

| 项目 | 要求 |
|------|------|
| **学历要求** | 全国高校在读专科生、本科生、研究生均可报名参赛[citation:2][citation:5][citation:6] |
| **组别设置** | 数智沙盘赛道分为本科组和高职组[citation:2][citation:6]。专科生参加高职组，本科生参加本科组[citation:2]。研究生仅能参加企业决策赛道研究生组，不可参加数智沙盘赛道[citation:2][citation:5][citation:8] |

### 2. 团队组成要求

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每支参赛队由**3名参赛选手**组成[citation:2][citation:4][citation:5] |
| **指导教师** | 每支参赛队可配备**1-2名指导教师**[citation:2][citation:4][citation:5] |
| **组队范围** | 可跨专业、跨年级组队，但**不得跨校组队**[citation:2][citation:4][citation:5] |
| **参赛限制** | 每位选手每个赛道只能报名一支队伍[citation:2][citation:7]；供应链决策赛道和数智沙盘赛道的比赛同步进行，每名学生只能从中选择一个赛道参加[citation:2][citation:8][citation:10] |
| **信息变更** | 报名结束后，比赛全过程中不得换人、不得增人、不得更改队员信息和次序，不得更改队伍名称[citation:2][citation:4]。获奖证书依照网上报名和实际参赛信息制作，不予更改[citation:2] |

### 3. 学校参赛名额限制

每所学校每个赛道（数智沙盘赛道）推荐进入全国复赛的队伍数量**不超过10支**[citation:2][citation:6][citation:9]。

## 四、竞赛内容与平台

### 1. 竞赛平台

数智沙盘赛道采用**BizSand数智商业经营模拟系统**进行比赛[citation:2][citation:7][citation:8]。

**比赛网址**：https://www.bizsand.cn [citation:2][citation:7][citation:8]

### 2. 竞赛内容

每个参赛团队代表一个虚拟企业[citation:7][citation:9]。数智沙盘赛道从系统第2年（Y2Q1）或第3年（Y3Q1）开始模拟[citation:9]，本次比赛通常采用**2年8期**赛制[citation:7]或**3年12期**赛制[citation:2][citation:8][citation:9]，在系统第16期（Y4Q4）后根据系统评分所得成绩进行判定[citation:7][citation:9]。

参赛团队需要根据市场环境、竞争对手的策略以及自身的资源条件，制定企业发展战略，进行生产、营销、财务等各个方面的决策[citation:3]。企业经营时应发挥管理团队的集体智慧与创造精神，追求企业的长期效益最大化[citation:9]。

## 五、评审标准

### 1. 系统评价指标

BizSand数智商业经营模拟系统的综合评价指标包括[citation:2][citation:7][citation:8]：

| 评价指标 | 说明 |
|------|------|
| **第4年末所有者权益** | 企业经营最终成果的核心指标 |
| **占领的销售市场** | 市场份额和区域覆盖情况 |
| **营业的商店（每个）** | 开设的商店数量 |
| **累计销售额加减分** | 销售业绩的累计表现 |
| **未归还基金贷款** | 贷款偿还情况 |
| **第4年末偿债能力** | 企业的财务健康状况 |
| **经营中追加股东资金** | 融资能力表现 |

各项指标的权重依赖模拟情景，并在模拟规则中发布[citation:7][citation:9]。

### 2. 排名规则

| 排名依据 | 规则说明 |
|------|------|
| **第一基准** | 先名次后总成绩标准分的原则决定晋级次序[citation:2] |
| **第二基准** | 在名次和总成绩标准分都相等的情况下，依次比较企业未标准化经营得分、经营最后一期的所有者权益、倒数一期的所有者权益[citation:2] |
| **破产处理** | 破产队伍排在正常成绩之后[citation:2] |

## 六、赛制流程

大赛采用**校内初赛-全国复赛-全国半决赛-全国总决赛**多级赛制[citation:2][citation:5][citation:8]。

### 1. 2026年大赛时间安排

| 阶段 | 时间安排 | 比赛形式 |
|------|----------|----------|
| **校内初赛** | 2026年3月中下旬（各校自行组织，3月23日前完成）[citation:2][citation:4][citation:5] | 线上或线下 |
| **全国复赛** | 2026年3月28日—4月12日[citation:1][citation:5][citation:9] | 线上远程竞赛[citation:5][citation:6] |
| **全国半决赛** | 2026年4月18日/19日/25日/26日[citation:1][citation:5][citation:9] | 线上快赛[citation:9] |
| **总决赛资格赛（备选）** | 2026年4月26日或5月10日[citation:1][citation:5][citation:9] | 线上快赛[citation:9] |
| **全国总决赛** | 2026年5月22日-24日[citation:1][citation:5][citation:9] | 线下现场集中进行[citation:5][citation:6][citation:9] |

### 2. 赛制说明

| 项目 | 说明 |
|------|------|
| **数智沙盘赛制** | 采用3年12期或2年8期[citation:2][citation:8][citation:9] |
| **比赛形式** | 分慢赛与快赛：慢赛每天1-2期，多天完成；快赛一天完成[citation:2][citation:8][citation:9] |
| **辅助决策工具** | 全国复赛和半决赛不限辅助决策工具，总决赛只能使用组委会统一发布的辅助决策工具，该工具于半决赛结束前发布[citation:2][citation:8][citation:9] |

## 七、晋级规则

### 1. 晋级比例

大赛组委会将根据各赛道报名队伍数量决定大赛层级和各层晋级的比例，并于全国复赛报名截止后及时发布[citation:2]。

### 2. 复赛晋级半决赛规则

| 规则 | 说明 |
|------|------|
| **学校限制** | 复赛晋级半决赛过程中，每学校每组别按成绩晋级半决赛队伍不超过5支[citation:2] |
| **赛区平衡** | 半决赛各赛区队伍数相等[citation:2] |

### 3. 半决赛晋级总决赛规则

| 规则 | 说明 |
|------|------|
| **学校限制** | 半决赛晋级总决赛资格赛过程中，每学校每组别按成绩进入总决赛资格赛队伍总数不超过2支[citation:2] |
| **总决赛名额** | 根据规则选拔不低于总决赛名额90%的队伍晋级总决赛；根据“星火计划管理办法”推荐不高于总决赛名额10%的队伍进入总决赛[citation:2] |
| **最终限制** | 每所学校每赛道进入总决赛队伍不超过1支[citation:2] |

### 4. 直通名额

| 直通方式 | 说明 |
|------|------|
| **省市赛直通** | 在地区省市赛中获得优秀成绩的队伍可获得一个直通半决赛的名额。需在复赛报名截止前将证明材料邮件发送至ibizsim@163.com，队伍成员信息须与省市赛中保持一致[citation:2] |
| **承办校名额** | 上届省市赛承办单位和本届总决赛承办校，可以获得所承办赛道的一个半决赛名额，晋级队伍依据复赛成绩确定[citation:2] |

## 十、报名方式

### 1. 通用报名流程

1. **校内组队**：按赛道要求组队（3人），确定指导教师和队长
2. **加入校赛QQ群**：加入各校竞赛QQ群，获取后续通知
3. **校内初赛报名**：登录校内初赛报名网站（摩课云：https://ibizsim.moocollege.com）进行注册报名[citation:2][citation:9]
4. **参加校赛**：通过校内选拔赛后获得全国复赛参赛资格
5. **全国复赛报名**：由学校统一推荐，在全国复赛报名截止前完成系统注册和报名[citation:2]

**重要提示**：
- 报名信息须真实准确，必须使用真实学生身份报名，若冒用他人姓名申报参赛，一经发现即取消该队参赛资格[citation:10]
- 参赛报名成员顺序为获奖证书团队成员次序，比赛全程不可修改[citation:9]
- 若校内初赛报名队伍数超过全国复赛队伍上限，须统一组织校内选拔赛[citation:2]

## 十一、学术诚信与监督

### 1. 学术诚信要求

- 参赛选手须遵守比赛规程，尊重对手；做到网络语言自我约束，严禁不文明用语；参赛队伍名称规范，符合社会主义核心价值观[citation:2]
- 参赛选手要遵守比赛规则，遵守赛场纪律，诚信参赛。竞赛须服从指挥，按时独立完成每一期决策[citation:2]
- 严禁各种作弊行为[citation:2]

### 2. 违规处理

| 违规行为 | 处理方式 |
|------|------|
| **作弊行为** | 对被认定为作弊的参赛队伍，取消作弊队伍的比赛成绩[citation:2] |
| **学校作弊数量≤3支** | 取消作弊队伍每个成员下一年度参赛资格，并通报该学校主管部门[citation:2] |
| **学校作弊数量＞3支** | 取消该学校下一年度参赛资格[citation:2] |
| **涉嫌犯罪** | 移送司法机关处理[citation:2] |
| **无故弃赛** | 取消该团队成绩和奖项[citation:2] |

### 3. 申诉机制

| 项目 | 规则说明 |
|------|------|
| **申诉主体** | 参赛队伍对于竞赛组织工作或比赛成绩认定有疑问，可向裁判和仲裁委员会提交实名申诉[citation:2] |
| **申诉时效** | 线上竞赛，申诉有效期不超过2天；线下竞赛，比赛结束后2小时之内，由学校指导老师向裁判和仲裁委员会提交书面申诉[citation:2] |
| **申诉流程** | 先向裁判组提出申诉，若对裁判组的处理结果不服，再向仲裁委员会提出申诉[citation:2] |
