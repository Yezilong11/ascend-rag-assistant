# 全国三维数字化创新设计大赛竞赛规则

## 一、竞赛简介

全国三维数字化创新设计大赛（简称“全国3D大赛”或“3DDS”）是在国家大力实施创新驱动发展战略、推动实体经济和数字经济融合发展的时代背景下开展的一项大型公益品牌赛事。大赛自2008年发起以来，已连续成功举办18届，被列入了中国高等教育学会《全国普通高校大学生竞赛分析报告》竞赛目录，是教育部认可的全国性高校大学生学科竞赛，也是全国规模最大、规格最高、水平最强、影响最广的全国性三维数字化创新设计大赛之一。

大赛秉承“以赛促教、以赛促学、以赛促用、以赛促新”的宗旨，多年被教育部正式列入全国高校学科评估体系，对推动大众创业、万众创新，特别是引导广大青年学生积极投身数字经济和创新创业的时代洪流，发挥了不可替代的作用。

第十九届全国三维数字化创新设计大赛于2026年3月启动。

## 二、组织机构

### 1. 主办与承办单位

- **指导单位**：教育部、科学技术部、工业和信息化部、中国科学技术协会
- **主办单位**：全国三维数字化创新设计大赛组委会、国家制造业信息化培训中心、全国3D技术推广服务与教育培训联盟（北京昆仑三迪科技发展有限公司）
- **承办单位**：各赛区承办高校
- **协办单位**：各赛区协办高校及相关企业

### 2. 竞赛官网与联系方式

- **官方网站**：https://3dds.3ddl.net/ 
- **大赛官方微信**：3D大赛
- **数字工坊**：https://3dshow.3ddl.net/ 
- **大赛组委会联系方式**：见官网“联系我们”栏目

### 1. 参赛对象

| 项目 | 要求 |

## 四、开放赛项设置

第十九届全国三维数字化创新设计大赛设以下开放赛项：

### 1. 数字工业设计大赛

包含工业产品设计/外观与人机交互设计、机电工程设计/工程分析/过程仿真、模具设计/数值分析/3D打印/再制造、工业/物流/医疗/教学等机器人设计、智能产线/智能制造/虚拟仿真等，以及数字工匠、汽车/高铁/舰船/航空航天/重型机械等相关设计。

### 2. 数字人居设计大赛

包含数字城市/规划/设计/BIM应用、室内外设计/装修装饰/环境艺术设计、智能家居/智慧社区/智慧城市设计、历史建筑/文化遗产/文物的数字化展示/修复/保护、绿色建筑/低碳城市/生态环境设计等。

### 3. 数字文化设计大赛

包含文化体育/游戏/动漫IP形象设计开发、数字人/虚拟偶像/虚拟IP设计、VR/AR/MR应用/互动体验/互动娱乐、数字媒体/创意广告/数字拍摄/虚拟制片/后期特效、数字十文化/旅游/非遗/文创创意设计、科幻创意/剧本杀/沉浸式体验设计等。

### 4. 元宇宙创建大赛

包含数字人/虚拟偶像开发、XR/数字孪生/虚拟仿真/互动影院/科技文旅、区块链/NFT应用/数字资产/数字藏品/数字确权、AI驱动的建模/交互/内容生成、区块链、Web3.0、AR/VR/MR场景/社交/游戏/会议/会展/商城等、虚拟制片/数字拍摄/后期特效/数字中控/远程遥控/数字矩阵等。

### 5. 专项赛与命题赛

为引导和推动3D技术及数字科技最新发展与应用，与有关企业、机构合作设立，如：
- AI+3D创新专项赛
- 云道智造CAE专项赛
- 超元·XR专项赛
- 元宇宙·3D/XR·AI新灵境创新大赛
- 视觉工程专项赛
- 智能汽车/无人机专项赛
- 机器人专项赛
- 工业低代码专项赛
- 国产数创软件专项赛
- 医疗健康专项赛
- 教育数字化专项赛
- 3D打印创新专项赛
- 军事/航天/科技专项赛
- 数字人/IP文创专项赛

## 五、赛制流程

大赛采用校级选拔赛、省级选拔赛和全国总决赛三级赛制。

### 1. 第十九届时间安排

| 阶段 | 时间安排 | 说明 |
|------|----------|------|
| **报名/初赛/网络海选** | 2026年3月1日—6月20日 | 大赛官网注册报名、提交作品 |
| **校级选拔赛** | 2026年3月—6月 | 各高校自行组织 |
| **省级选拔赛** | 2026年7月1日—10月31日 | 各省赛区组织评审 |
| **全国总决赛** | 2026年11月—12月 | 现场评审 |

注：具体时间安排以官网发布的《第19届全国三维数字化创新设计大赛（3D大赛）赛程》为准。

### 2. 各阶段比赛形式

#### （1）校级选拔赛
- 由各高校自行组织
- 形式：作品评审、现场答辩
- 校赛奖项：设特等奖、一等奖、二等奖、三等奖
- 晋级规则：各校推荐优秀作品参加省级选拔赛

#### （2）省级选拔赛
- 由各省赛区组委会组织
- 形式：作品评审（线上或线下）
- 省赛奖项：设特等奖、一等奖、二等奖、三等奖
- 晋级规则：省赛特等奖和一等奖作品晋级全国总决赛

#### （3）全国总决赛
- 线下举行，入围队伍进行现场展示和答辩
- 评审专家现场评审，评选出全国一等奖、二等奖、三等奖及龙鼎大奖

## 六、作品要求与提交材料

### 1. 作品提交材料

| 材料名称 | 要求说明 |
|----------|----------|
| **作品说明书/报告** | PDF格式，阐述作品的设计理念、技术路线、创新点等 |
| **作品3D模型源文件** | 根据参赛方向提交对应格式的3D模型文件 |
| **作品渲染图** | JPG/PNG格式，多角度展示作品外观 |
| **作品介绍视频** | MP4格式，3-5分钟，展示作品功能和应用场景 |
| **答辩PPT** | 用于现场演示的PPT文件 |

### 2. 原创性要求

- 参赛作品必须是参赛者的原创作品，未侵犯任何他人的知识产权
- 不得抄袭、剽窃他人成果
- 发现抄袭行为，主办单位将取消其参赛、入围与获奖资格

## 七、评审标准

### 1. 评审维度

| 评审维度 | 说明 |
|----------|------|
| **创新性** | 作品的创新程度和独特性 |
| **技术性** | 3D技术应用的深度和广度 |
| **艺术性** | 作品的视觉效果和艺术表现力 |
| **实用性** | 作品的实际应用价值和市场前景 |
| **完整性** | 作品设计的完整性和规范性 |

### 2. 评审方式

- 校级选拔赛：由各高校自行组织评审
- 省级选拔赛：由各省赛区组委会组织专家进行评审
- 全国总决赛：由大赛组委会组织专家进行现场评审

## 九、报名方式

### 1. 报名流程

1. **官网注册**：登录大赛官网（https://3dds.3ddl.net/）进行注册
2. **创建团队**：在官网创建参赛团队，邀请队员加入
3. **选择赛项**：根据作品类型选择对应赛项
4. **提交作品**：在规定时间内提交作品材料
5. **校内备案**：按各校要求完成校内报名备案

### 2. 报名截止时间

- **全国统一报名截止**：2026年6月20日
- **各高校校内报名截止**：各校不同，一般在5月—6月，请关注本校具体通知
