# 国际大学生程序设计竞赛（ICPC）竞赛规则

## 一、竞赛简介

国际大学生程序设计竞赛（International Collegiate Programming Contest，简称ICPC）是由ICPC基金会主办的面向全球高校学生的年度性权威程序设计竞赛[citation:5]。该赛事是最具影响力的大学生计算机竞赛，旨在为在校大学生搭建展示程序设计水平与创新思维能力的高层次平台，鼓励学生积极投身程序设计领域的学习与实践，不断提升综合技术素养[citation:3]。

ICPC竞赛与CCPC同为国际与国内具有代表性的高水平程序设计竞赛，在全球范围内具有广泛的参与度和深远影响，吸引了众多知名高校学生踊跃参与，成为促进各国大学生开展编程技术交流与创新理念碰撞的重要平台[citation:3]。该赛事被认定为国家级A类竞赛，具有广泛的社会认可度和行业影响力，受到国内外高校与用人单位的高度重视[citation:3]。

## 二、组织机构

### 1. 组织架构

| 机构 | 职责 |
|------|------|
| **ICPC基金会** | ICPC的组织机构，负责赞助、筹款、主办协议、校友外联、知识产权和运营事务 |
| **执行委员会** | 由执行主任主持，制定竞赛政策和通用规则 |
| **国际指导委员会** | 负责制定区域竞赛规则、政策和指导方针，监督财务状况良好的区域竞赛的执行，解决区域上诉，裁决国际问题 |
| **申诉委员会** | 处理竞赛相关的申诉事宜 |
| **资格审查委员会** | 负责参赛选手的资格审核[citation:10] |

## 三、参赛资格与要求

### 1. 参赛对象

| 项目 | 要求 |
|------|------|
| **学历要求** | 高等院校在籍在校学生（大学本科及以上的学位授予机构）[citation:10] |
| **年龄限制** | 2005年或之后出生的学生符合参赛资格；或在2021年或之后首次开始高等教育学习的学生符合参赛资格[citation:10] |
| **参赛次数限制** | 每位学生最多参加两次世界总决赛；每位学生最多参加五次不同竞赛年份的区域赛[citation:10] |
| **特殊例外** | 2020/21赛季的区域赛参赛不计入5次限制；2021/22和2022/23赛季的区域赛参赛合计仅计为1年[citation:10] |

### 2. 团队组成要求

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每支参赛队由**1名教练**和**3名参赛队员**组成[citation:2] |
| **组队范围** | 所有队员必须来自同一所高校，不得跨校组队[citation:10] |
| **教练要求** | 教练必须是参赛队伍的同一所高校的正式教职员工，负责证明参赛者的资格并作为团队官方联络人[citation:2][citation:10] |
| **参赛限制** | 每位学生只能加入一支队伍[citation:9]；一个队伍可以参加最多两个区域赛，且必须使用相同的队名[citation:9] |
| **替补队员** | 已注册的替补队员可以在第一场资格赛开始前替换正式队员[citation:10] |

### 3. 注册要求

| 项目 | 要求 |
|------|------|
| **注册平台** | 所有教练和参赛队员必须在ICPC全球官网（https://icpc.global）创建账号并完成注册[citation:8] |
| **注册流程** | 由教练负责在ICPC注册系统中完成团队注册，注册截止时间通常为区域赛开始前7天[citation:10] |
| **信息审核** | 团队需经区域赛总监在注册系统中确认接受后，才有资格参赛[citation:10] |
| **跨区域参赛** | 教练可申请将所在高校的所有团队迁移至不同的ICPC赛区，需全体教练一致同意并提交给区域赛总监[citation:10] |

## 四、赛制流程

### 1. 赛季赛程

ICPC竞赛为多层级赛事，每年举办一届，典型赛程安排如下[citation:5]：

| 阶段 | 时间安排 |
|------|----------|
| **网络预选赛** | 8月底至9月初 |
| **区域赛（Regionals）** | 9月底至11月底 |
| **超级区域赛（如欧洲锦标赛、亚太锦标赛）** | 次年2月至3月 |
| **世界总决赛（World Finals）** | 次年4月至6月（第50届世界总决赛于2025年举办，第51届预计2026年举办） |

### 2. 晋级机制

#### （1）欧洲超级区域晋级规则[citation:4]

| 晋级层级 | 规则说明 |
|------|------|
| **欧洲锦标赛（EUC）** | 欧洲四个区域（CERC、NWERC、SEERC、SWERC）各分配25%的名额；每个区域排名靠前的队伍晋级，每所高校仅限一支队伍 |
| **世界总决赛（WF）** | 欧洲四个区域中，每个区域排名前2的不同高校队伍直接晋级世界总决赛；在EUC中，尚未获得资格的最高排名队伍将获得额外8个名额 |

#### （2）亚太地区晋级规则[citation:9]

| 晋级层级 | 规则说明 |
|------|------|
| **区域赛冠军** | 每个区域赛的冠军队伍（排除南太平洋或其他超级区域的队伍）直接获得世界总决赛资格 |
| **亚太锦标赛** | 区域赛冠军队伍被邀请参加亚太锦标赛；同一高校若有多个区域赛冠军，需通过锦标赛竞争确定唯一晋级名额 |
| **世界总决赛名额分配** | 首先按区域赛冠军规则确定晋级队伍（B1-B3）；其余名额根据亚太锦标赛排名确定，需排除区域赛冠军队伍和同一高校的后续队伍 |

### 3. 参赛限制

- 同一支队伍最多参加两个区域赛，且必须使用相同的队名[citation:9]
- 来自同一国家的队伍不应参加其他国家的区域赛[citation:9]
- 南太平洋地区（澳大利亚、新西兰等）的队伍通过独立区域赛晋级，不占用亚太地区名额[citation:9]

## 五、竞赛形式

### 1. 比赛时长

- 区域赛通常为**5小时**[citation:4]
- 世界总决赛通常为5小时

### 2. 比赛规则

| 项目 | 规则说明 |
|------|----------|
| **赛制** | ACM赛制，实时评测并返回结果[citation:5] |
| **设备** | 每队使用**一台计算机**，不允许携带额外电子设备[citation:4] |
| **允许物品** | 可携带纸质参考资料（如书本、笔记、打印的源代码等）；每人可携带一本自然语言词典（无注释）[citation:4] |
| **禁止物品** | 任何可用计算机处理的电子设备、计算器、手机等[citation:4] |
| **封榜规则** | 比赛结束前**1小时**封榜，封榜期间的提交结果和排名对其他队伍不可见[citation:4][citation:5] |

### 3. 竞赛语言

| 语言 | 说明 |
|------|------|
| **C** | 允许使用 |
| **C++** | 允许使用，标准答案通常使用C++编写[citation:4] |
| **Java** | 允许使用 |
| **Python 3** | 允许使用[citation:4] |
| **Kotlin** | 允许使用[citation:7] |

### 4. 提交与评测

| 项目 | 规则说明 |
|------|----------|
| **提交次数** | 每道题目允许多次提交[citation:5] |
| **编译错误** | 编译错误不产生罚时[citation:4][citation:7] |
| **错误提交** | 每次未通过测试用例的错误提交，增加**20分钟罚时**[citation:5] |
| **通过标准** | 只有通过题目的全部测试用例才能视作该题通过[citation:5] |
| **澄清请求** | 参赛者可提交问题陈述的歧义或错误澄清请求，经裁判确认后会向所有参赛者发布澄清说明[citation:10] |

## 六、排名规则

### 1. 排名基准

| 排序依据 | 说明 |
|------|------|
| **第一基准** | 正确解答的题目总数，解题数多的队伍排名靠前[citation:5] |
| **第二基准** | 解题总时长（罚时总和），总时长少的队伍排名靠前[citation:5] |
| **第三基准** | 最后正确提交的解题时间，时间早的队伍排名靠前[citation:4] |

### 2. 罚时计算规则

| 计算项 | 规则说明 |
|------|------|
| **解题用时** | 从比赛开始到该题首次正确提交的时间（分钟）[citation:5] |
| **错误提交罚时** | 每次错误提交（编译错误除外）增加**20分钟**罚时[citation:5] |
| **总时长计算公式** | 总时长 = 所有已解题目的（解题用时 + 该题错误提交次数 × 20分钟）之和[citation:7] |

**示例**：某队在第30分钟首次正确提交A题，此前有2次错误提交；在第90分钟首次正确提交B题，此前有1次错误提交。则总时长 = (30 + 2×20) + (90 + 1×20) = 70 + 110 = 180分钟。

## 八、校内选拔赛（校赛）规则

### 1. 校赛目的

校内选拔赛旨在进一步营造良好的校园程序设计竞赛氛围，全面提升学生的创新意识、计算思维能力与程序设计水平，通过比赛选拔表现突出的优秀选手，优先吸纳进入学校ICPC集训队，经过系统化训练后择优组队代表学校参加ICPC系列赛事[citation:3]。

### 2. 校赛组织形式（以长江大学为例）

| 项目 | 规则说明 |
|------|----------|
| **参赛对象** | 具有正式全日制学籍的本科生，研究生可友情参赛但不参与排名[citation:3] |
| **比赛时长** | 4小时[citation:3] |
| **比赛形式** | 个人赛[citation:3] |
| **排名规则** | 采用ACM赛制，按解题数和罚时排名[citation:3] |
| **奖项设置** | 一等奖10%，二等奖20%，三等奖30%（向上取整）[citation:3] |

### 3. 校赛选拔标准

| 选拔方式 | 规则说明 |
|------|------|
| **队伍组成** | 获奖选手自愿组成三人队伍，每人只能参加一支队伍[citation:3] |
| **队伍排序** | 采用队员个人排名的加权平均值进行排序（三名队员个人排名之和除以3），按加权排名从低到高排序[citation:3] |
| **选拔数量** | 择优选取前5支队伍作为学校参赛候选队伍[citation:3] |
| **参赛机会分配** | 按队伍排名依次轮转分配参赛名额，形成循环参赛机制[citation:3] |
| **队员变更** | 队伍名单确定后原则上不得随意更换队员，特殊情况需经校赛事组办方审批[citation:3] |

## 九、参赛费用

| 项目 | 收费标准 |
|------|----------|
| **区域赛报名费** | 不同赛区标准不同，通常为每队200-300美元（如雅加达区域赛外国队250美元/队）[citation:2] |
| **世界总决赛费用** | 组委会承担住宿等部分费用，交通费用自理 |
| **校内选拔赛** | 通常免费参赛 |

## 十、学术诚信与监督

### 1. 违规行为

以下行为将被视为违规[citation:10]：

- 参赛队伍破坏竞赛设备（如拔掉电源线）
- 未经授权修改竞赛材料
- 任何可能有意或无意对其他队伍造成负面影响的活动
- 干扰比赛秩序的行为
- 交换代码、交流解题思路、请他人代替参赛[citation:3]
- 提交破坏比赛系统的代码[citation:3]
- 打开非比赛指定网页[citation:3]

### 2. 违规处理

| 违规类型 | 处理方式 |
|------|------|
| 一般违规 | 区域赛总监可取消队伍参赛资格[citation:10] |
| 严重违规 | 取消参赛资格，并予通报批评 |
| 学术不端 | 按学校相关规定处理[citation:3] |

### 3. 申诉机制

| 项目 | 规则说明 |
|------|----------|
| **申诉主体** | 由教练提交申诉[citation:4] |
| **申诉时效** | 结果公布后1个工作日内提交给赛事委员会[citation:4] |
| **申诉邮箱** | 欧洲锦标赛：euc.committee@icpc.global[citation:4]；全球资格审查：eligibility@icpc.global[citation:10] |
