# 全国大学生市场调查与分析大赛竞赛规则

## 一、竞赛简介

全国大学生市场调查与分析大赛（以下简称“市调大赛”）由中国商业统计学会创办于2010年，现已连续举办15届。大赛于2018年被正式纳入《全国普通高校大学生竞赛分析报告》竞赛目录，始终位居前列，现已成为国内具有广泛影响力的公益性专业品牌赛事[citation:3]。

大赛旨在引导大学生创新和实践，提高学生的组织、策划、调查实施和数据处理与分析等专业实战能力，培养学生的社会责任感、服务意识、市场敏锐度和团队协作精神[citation:1][citation:2]。大赛已成功构建起学术引领、政府支持、高校参与、企业协同的多方联动实践育人平台，深受广大师生和社会各界认可[citation:3]。

“正大杯”第十六届全国大学生市场调查与分析大赛于2025年9月27日正式启动[citation:3]。

## 三、组别设置

第十六届市调大赛设置四个组别：

| 组别 | 参赛对象 | 知识赛要求 |
|------|----------|------------|
| **专科组** | 团队成员均为专科生 | 须通过知识赛 |
| **本科组** | 团队成员均为本科生 | 须通过知识赛 |
| **研究生组** | 团队成员均为研究生 | 不参加知识赛，直接组队参加实践赛 |
| **在华留学生组** | 团队成员以在华留学生占多数 | 不参加知识赛，直接组队参加实践赛 |

**在华留学生组队具体要求**：
- 3人团队：至少2名留学生
- 4人或5人团队：至少3名留学生
- 团队成员不限制本科生或研究生，但全部成员必须是同一所学校的学生[citation:3][citation:4]

## 四、参赛资格与要求

### 1. 参赛对象

| 项目 | 要求 |
|------|------|
| **学历要求** | 全日制在校专科生、本科生、研究生及在华留学生均可报名参赛，专业不限[citation:3][citation:8] |
| **参赛单位** | 以学校为单位统一组织，由各学校相关部门负责本校报名与管理工作[citation:8] |

### 2. 团队组成要求

| 项目 | 要求 |
|------|------|
| **队伍人数** | 每个团队由3-5名学生组成[citation:3] |
| **指导教师** | 每个团队可设1-3名指导教师[citation:4][citation:5] |
| **组队范围** | 鼓励跨专业跨院系组队，但团队所有成员必须来自同一所高校[citation:3] |
| **参赛限制** | 每名学生只能参加一个团队；指导老师可以指导多个团队[citation:3] |
| **组队资格** | 专科组和本科组必须是网考通过的学生才能组队参加实践赛[citation:3][citation:4] |

### 3. 往届作品限制

禁止使用往届参赛作品或已公开发表过的研究成果重复参赛，一经发现取消参赛资格。

## 五、竞赛形式

大赛分为知识赛和实践赛两个竞赛环节[citation:1][citation:2][citation:3]。

### 1. 知识赛（仅限专科组、本科组）

| 项目 | 说明 |
|------|------|
| **形式** | 个人在线理论知识网考[citation:3] |
| **时间** | 2025年11月1日—11月20日[citation:3] |
| **模拟考试** | 2025年10月20日—11月10日（每人限一次）[citation:3] |
| **考试次数** | 每位考生可参加1-2次，取最高成绩[citation:1][citation:3] |
| **合格标准** | 成绩60分及以上视为通过；通过率按本校实际参考人数的70%核定[citation:1][citation:3] |
| **证书申请** | 通过者可自愿付费申请中国商业统计学会颁发的全国市场调查与分析专业技能（CRA）证书；90分及以上选手免费申领大赛荣誉证书，且姓名及所在学校将登上大赛官网及微信公众号荣誉榜单[citation:3][citation:8] |

### 2. 实践赛（所有组别）

| 项目 | 说明 |
|------|------|
| **形式** | 团队完成调研项目，提交报告并参与答辩[citation:3] |
| **阶段划分** | 校赛、企业命题赛、省赛及全国总决赛[citation:3] |

**特别说明**：
- 在华留学生组不设企业命题赛和省赛，参赛团队通过校赛选拔直接进入全国赛初赛[citation:3][citation:6]
- 在华留学生组团队必须以中文撰写参赛报告，展示答辩过程可选择中文或中英双语[citation:3][citation:6]

### 3. 各阶段比赛形式

#### （1）校级选拔赛
- 由各高校自行组织，于2026年3月25日前完成[citation:3]
- 形式：报告评审+PPT评审+现场答辩[citation:1][citation:5]
- 校赛奖项：设一、二、三等奖，获奖比例分别为参赛总队数的10%、20%、30%（晋级省赛的队伍不参与校级评奖）[citation:5]
- 晋级规则：根据各校网考通过人数计算晋级省赛名额[citation:3]

**晋级省赛名额计算方法**：

| 组别 | 计算方法 |
|------|----------|
| **专科组** | 按本校网考通过人数除以10（四舍五入），最多15支团队[citation:3][citation:9] |
| **本科组** | 通过人数≤300人：通过人数÷20（四舍五入），最多15支<br>通过人数>300人：(通过人数-300)÷30+15（四舍五入），最多30支[citation:3][citation:5] |
| **研究生组** | 报名人数≤200人：人数÷10（四舍五入），最多15支<br>报名人数>200人：(人数-200)÷20+15（四舍五入），最多20支[citation:3][citation:5] |
| **在华留学生组** | 各校选拔最多3支团队直接参加全国赛[citation:3][citation:6] |

注：以上名额不含省赛承办校2支直接晋级队[citation:3]。

#### （2）企业命题赛
- 2026年4月10日前完成[citation:3]
- 由全国大赛组委会和命题企业共同组织评委进行报告评审[citation:3]
- 参赛团队于2026年4月初向全国大赛组委会一次性提交参赛报告和相关附件，逾期未提交视同不参加企业命题赛[citation:3][citation:6]

#### （3）省级复赛
- 由各赛区组委会按大赛组委会制定的统一竞赛规则和评分标准选拔晋级全国赛团队[citation:3]
- 省赛奖项：设一等奖、二等奖、三等奖，由大赛组委会统一制作电子版证书[citation:3]

#### （4）全国赛初赛
- 形式：报告+PPT评审[citation:3]
- 评选出晋级全国总决赛的团队[citation:3]

#### （5）全国总决赛
- 形式：现场答辩[citation:3]
- 评选出全国一等奖、二等奖[citation:3]

## 七、作品要求与提交材料

### 1. 作品内容要求

参赛团队需完成一个完整的市场调查项目，包括但不限于：

| 内容模块 | 说明 |
|----------|------|
| **选题** | 围绕社会经济热点、企业实际问题或学生自主选题 |
| **调查设计** | 调查方案设计、问卷设计、抽样设计等 |
| **数据采集** | 实地调查、网络调查、数据收集等 |
| **数据分析** | 运用统计分析方法对数据进行处理和分析 |
| **报告撰写** | 形成完整的市场调查报告 |

### 2. 提交材料要求

| 材料名称 | 要求说明 |
|----------|----------|
| **调查报告** | Word和PDF版本，按规范格式排版 |
| **答辩PPT** | 用于现场演示的PPT文件 |
| **原始数据** | 调查原始数据文件，作为支撑材料 |
| **调查问卷** | 使用的调查问卷样本 |

### 3. 原创性要求

- 参赛作品必须是参赛团队的原创作品，未侵犯任何他人的知识产权
- 不得使用已公开发表过的研究成果或往届参赛作品重复参赛
- 发现抄袭行为，主办单位将取消其参赛、入围与获奖资格

## 八、评审标准

### 1. 评审维度

| 评审维度 | 说明 |
|----------|------|
| **选题价值** | 选题的现实意义和应用价值 |
| **方案设计** | 调查方案的科学性、合理性和创新性 |
| **数据采集** | 数据采集过程的规范性和真实性 |
| **数据分析** | 统计方法的运用深度和准确性 |
| **结论建议** | 研究结论的可靠性和建议的可行性 |
| **报告质量** | 报告的结构完整性、逻辑清晰性和表达规范性 |
| **答辩表现** | 现场陈述的逻辑性、清晰度和答辩应变能力 |

### 2. 评分方式

- 校赛、省赛、全国赛初赛：评审专家对提交的报告和PPT进行匿名评审
- 全国总决赛：现场答辩，专家现场评分

## 十一、报名方式

大赛报名分为三步进行：院校参赛报名（老师填报）、学生参赛报名和缴纳参赛费[citation:3][citation:6]。

- 各院校负责竞赛老师于2025年10月31日前在中国商业统计学会官网“第十六届全国大学生市场调查与分析大赛”专题网页上点击“院校参赛报名”进行填报[citation:3][citation:6]

- 报名网址：http://www.china-cssc.org/list-552-1.html [citation:8]

#### （3）缴费
- 参赛校负责老师于报名截止日期前将报名费统一汇到大赛组委会银行账户，并将确认参加网考的学生信息汇总表发送至大赛组委会邮箱[citation:3][citation:8]
