# 中国大学生物理学术竞赛 - 历史赛题集

## 一、竞赛简介

中国大学生物理学术竞赛（China Undergraduate Physics Tournament，简称CUPT）是我国借鉴国际青年物理学家锦标赛（International Young Physicists’ Tournament，简称IYPT）模式创办的一项全国性物理赛事[citation:2]。该项活动得到了教育部的支持，并被列入中国物理学会物理教学指导委员会的工作计划，是实践国家教育中长期发展规划纲要的重要大学生创新竞赛活动之一[citation:2]。

竞赛以团队辩论对抗为形式，要求学生根据给定的开放性物理问题进行深入研究，并就解决问题的基本知识、理论分析、实验研究、结果讨论等进行辩论性比赛[citation:4]。CUPT旨在培养参赛者的创新意识、创新能力、协作精神和实践能力，摆脱应试教育模式，体现知识学习与探索实践相结合，物理学与日常生活相结合，学术能力与人际交往能力相结合，个人与团队合作相结合的理念[citation:2][citation:4]。

## 二、竞赛规则与赛制

### 竞赛题目来源

CUPT竞赛题目参考同年国际青年物理学家锦标赛（IYPT）题目，在力、热、光、电等物理分支下共设17个题目[citation:2]。赛题均为贴近实际生活的开放性物理问题，在竞赛一年前公布，其中有不少源自《科学》（Science）、《自然》（Nature）、《物理评论快报》（PRL）、《现代物理评论》（RMP）等国际顶级期刊[citation:4]。

### 参赛方式

| 项目 | 具体要求 |
|:---:|:---|
| 参赛队伍 | 以团队为单位报名，不接受个人报名 |
| 人员构成 | 每队由5名本科学生组成（不限年级，竞赛过程中不能更换），另设1名领队（学生或教师） |
| 学校名额 | 原则上每所高校派出1支参赛队[citation:2] |

### 竞赛流程

竞赛以普通话为工作语言，以抽签分组、团队辩论的方式进行。赛前通过抽签分组，每支队伍参加五轮预选对抗赛，每轮对抗赛由三支或四支队伍参加[citation:2]。

**三支队伍参赛时的角色轮换**：

| 阶段 | 队1 | 队2 | 队3 |
|:---:|:---:|:---:|:---:|
| 1阶段 | 正方 | 反方 | 评论方 |
| 2阶段 | 评论方 | 正方 | 反方 |
| 3阶段 | 反方 | 评论方 | 正方 |

**每阶段比赛流程**（总时长55分钟）[citation:2]：

| 流程 | 限时 |
|:---|:---:|
| 反方向正方挑战竞赛题目 | 1分钟 |
| 正方接受或拒绝反方挑战的题目 | 1分钟 |
| 正方准备 | 5分钟 |
| 正方进行所选题的报告 | 12分钟 |
| 反方向正方提问，正方回答 | 2分钟 |
| 反方准备 | 3分钟 |
| 反方的报告（最多五分钟），正反方讨论 | 15分钟 |
| 评论方提问，正、反方回答 | 3分钟 |
| 评论方准备 | 2分钟 |
| 评论方报告 | 4分钟 |
| 正方总结发言 | 2分钟 |
| 评审团提问 | 5分钟 |

### 评分规则

不同角色的加权系数不同[citation:2]：
- 正方：×3.0
- 反方：×2.0
- 评论方：×1.0

各参赛队在一轮对抗赛中的成绩为各阶段赛成绩的加权总和，预选赛总成绩为所有五轮对抗赛成绩总和[citation:2]。

**正方评分标准**[citation:2]：

| 项目 | 内容 | 分值 |
|:---:|:---|:---:|
| 内容 | 物理正确性、论据切题、科学方法运用、实验理论一致性、结论说服力 | 0-4 |
| 表达 | 思路清晰、公式符号解释正确、模型正确、视频资料、表达清楚、参考文献 | 0-2 |
| 讨论 | 物理正确性、论据切题、物理知识扎实、客观辩论、对反方异议的讨论、礼貌态度、对评论方回答、评委问答 | 0-3 |
| 机动 | — | 0-1 |
| **总分** | | **0-10** |

## 四、地区赛与校内选拔赛赛制

### 2025年东北赛区竞赛[citation:3]

**赛事说明**：
- **现场团体赛**：各省选拔推荐，每校1支代表队（主办校可2支），采用IYPT2025题目，规则参照CUPT
- **作品赛**：1-5名学生，每校不超过3个团队，内容为CUPT2025任意1道题的完整研究成果
- **作品形式**：单页电子版学术海报（0号图纸，84cm×119cm，PDF格式），不得出现参赛学校信息

### 2025年辽宁省普通高等学校本科大学生物理竞赛[citation:8]

**赛道设置**：
- **物理实验赛**：采用第十一届全国大学生物理实验竞赛（创新）题目
- **物理学术赛**：采用CUPT2025赛题（17题任选其一），完成研究报告并准备答辩

### 北京科技大学校内选拔赛[citation:10]

**比赛形式**：个人赛，线下答辩。参赛队员从17个题目任选其一，围绕基本知识、理论分析、实验方案、结果讨论等进行PPT展示。

## 五、赛题特点分析

### 1. **与国际接轨，同步更新**

CUPT题目直接采用IYPT题目，与全球物理学术竞赛保持同步[citation:2][citation:4]。每年2月左右公布新题，为参赛者提供充足的准备时间。

### 2. **开放性极强，无标准答案**

每个题目都是开放性的物理问题，没有预设的标准答案[citation:4]。要求学生通过理论分析、实验探究、数值模拟等多种方法自主探索，培养独立科研能力。

### 3. **源于生活，归于物理**

题目多来源于日常生活中的有趣现象，如“尺子加农炮”[citation:6]、“沙池”[citation:1]等，引导学生用物理思维解读世界，体现“物理学与日常生活相结合”的理念[citation:2]。

### 4. **跨学科融合**

研究过程涉及力学、热学、光学、电磁学、流体力学、声学等多个物理分支，同时需要综合运用数学建模、实验设计、数据分析、计算机模拟等多种研究方法。

### 5. **辩论式竞赛，能力全面考核**

不同于传统解题竞赛，CUPT采用辩论对抗形式[citation:2][citation:4]，考核内容不仅包括研究的科学性和创新性，还包括表达交流能力、逻辑思辨能力、临场反应能力和团队协作精神。
