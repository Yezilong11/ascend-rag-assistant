# 中国高校智能机器人创意大赛 - 历史赛题集

**来源网址**: http://www.robotcontest.cn/
**信息整理时间**: 2026-03-14

## 一、竞赛简介

中国高校智能机器人创意大赛创办于2017年，首届大赛由中国高等教育学会、教育部工程图学课程教学指导委员会、中国高校智能机器人创意大赛组委会共同主办，浙江大学机器人研究院、中国高等教育学会工程教育专业委员会承办，决赛由浙江省余姚市人民政府承办。之后大赛每年举办一次，至今已经连续举办8届。[citation:1][citation:2][citation:3]

大赛以 **“更好、更快、更强”** 为主题，以培养学生提出问题能力为起点，形成问题提出、解决方案、技术创新和后期孵化一体化的人才培育链条，助力机器人相关人才培养成效显著。高校参赛积极性高、参与面广。大赛于2020年列入中国高等教育学会发布的全国普通高校大学生竞赛排行榜。[citation:1][citation:2][citation:3]

## 二、赛事体系构成

大赛每年举办一届，采用“校赛—省赛—国赛”三级赛制。经过多年发展，赛事体系不断完善，目前主要包括主题赛、专项赛和产教融合赛三大类。[citation:3][citation:10]

| 赛事类别 | 赛项名称 | 核心内容 | 创办年份 |
|:---|:---|:---|:---|
| **主题赛** | 主题一：创意设计 | 家用智能机器人创意设计 | 2017年 |
| | 主题二：创意竞技 | 魔方机器人竞速 | 2017年 |
| | 主题三：创意格斗 | 智能机器人对抗赛 | 2017年 |
| **专项赛** | 专项赛一 | 基于ROS技术应用的机器人挑战赛 | 2020年左右 |
| | 专项赛二 | 具身智能挑战赛（四足/双足/空中） | 近年新增 |
| | 专项赛三 | VEX U智能机器人对抗赛 | 第五届起 |
| **产教融合赛** | 多个企业命题 | 舜宇、中兴、中国移动、信捷电气等 | 近年新增 |

## 三、历届赛题汇总

### （一）主题赛

#### 主题一：创意设计——家用智能机器人·让生活更美好

**核心命题**：服务于未来生活的智能型服务机器人创意设计。适用于千家万户的智能机器人，其用途为家务劳动机器人、娱乐、情感交流、陪伴、个人卫生、家庭管家、安全与防护等家用服务智能机器人。[citation:1][citation:4][citation:6]

**作品形式演变**：

| 届数 | 年份 | 新增作品形式 | 评审分组 |
|:---:|:---:|:---|:---|
| 第1-6届 | 2017-2022年 | 无实物组、自制实物模型组 | 按有/无实物分组 |
| 第7届 | 2023年 | 模块化产品搭建组（慧鱼、启创远景、越疆、探索者等） | 增加模块搭建组 |
| 第8届 | 2024年 | 生成式人工智能（AIGC）组 | 增加AIGC辅助设计组 [citation:5] |
| 第9届 | 2025年 | 延续AIGC组，明确要求使用国内AI工具 | 四组并行评审 [citation:1][citation:4] |

**提交材料要求**（第9届）：[citation:1][citation:2][citation:4]

| 作品形式 | 提交材料 | 具体要求 |
|:---|:---|:---|
| 无实物组 | 设计创意的PDF文档 | 文字、设计图、效果图或动画，限A4纸6页以内，≤20M |
| 自制实物模型组 | PDF文档+原理样机视频 | 视频≤60秒，≤50M，MP4格式 |
| 模块化产品搭建组 | PDF文档+原理样机视频 | 同上 |
| AIGC组 | PDF文档+AI创作过程原始资料 | 提示词、截屏等，篇幅不限 |

#### 主题二：创意竞技——魔方机器人·挑战更快

**核心命题**：参照人类魔方竞速规则，设计制作魔方机器人，综合运用机械、电子、信息和自然科学知识，实现比人“计算”更快、“翻动”更加灵活迅速的目标。[citation:5][citation:10]

**技术规范**（第8-9届）：[citation:5][citation:10]

| 项目 | 具体要求 |
|:---|:---|
| 机器人结构 | 限采用双手臂，手指限二指或五指形式，手腕允许转动和摆动，手臂固定 |
| 外廓尺寸 | ≤480mm×480mm×480mm |
| 总重量 | ≤20kg |
| 摄像头 | 数量不限，允许自行增设光源 |
| 魔方规格 | 标准三阶魔方，决赛用魔方由组委会统一提供 |
| 限项要求 | 同一个学校参赛的魔方机器人结构、技术方案不得雷同；每个学校进入全国决赛不超过2项 |

**提交材料要求**：[citation:2][citation:5]

| 材料类型 | 具体要求 |
|:---|:---|
| 演示视频 | 一次完整动作过程，≤90秒，≤90M，MP4格式 |
| 技术文档 | 文字、设计图、效果图，限A4纸30页以内 |

#### 主题三：创意格斗——智能机器人对抗赛·挑战更强

**赛制设置**：分统一部件组和开放部件组。[citation:5][citation:10]

| 组别 | 参赛要求 | 比赛形式 |
|:---|:---|:---|
| **统一部件组** | 选用统一标准的控制器、传感器、动力模块、供电模块、结构组件等部件 | 轮式格斗、仿人格斗、视觉对抗、无人机对抗、服务机器人竞技、机器人仿真、创意设计等，小组循环赛+淘汰赛 |
| **开放部件组** | 在重量、尺寸等限制条件下自行设计、制作 | 擂台上自主对抗，小组循环赛+淘汰赛 |

**详细规则查询**：http://www.robo-maker.org/dszq/ [citation:5][citation:10]

### （二）专项赛

#### 专项赛一：基于ROS技术应用的机器人挑战赛

所有系统均在ROS框架下运行。[citation:3][citation:5][citation:10]

| 组别 | 赛题任务 | 技术要求 |
|:---|:---|:---|
| **单臂机器人竞赛组** | 参照俄罗斯方块游戏规则，设计基于ROS框架的俄罗斯方块机器人系统，融合机器视觉和人工智能算法，将随机散放的俄罗斯方块装配到托盘中 | 串联六轴及以上，臂展≤1000mm，机器人和视觉系统必须在ROS框架下运行 |
| **双臂机器人竞赛组** | 设计基于ROS框架的双臂服务机器人系统，融合语义识别与生成、机器视觉、深度强化学习等算法，通过双臂协作完成端茶倒水、物品取放和人机协同作业等任务 | 双臂串联六轴及以上，臂展≤1000mm，机器人和传感系统必须在ROS框架下运行 |
| **双轮足机器人竞赛组** | （第9届新增）具体任务待官网发布 | 在ROS框架下运行 |

#### 专项赛二：具身智能挑战赛

分为四足机器人、双足机器人、空中具身智能组。[citation:3][citation:10]

| 组别 | 赛项任务（供参考） |
|:---|:---|
| **四足机器人组** | 越障与避障、竞速、识别、检测与播报、路径规划、踢足球等 |
| **双足机器人组** | 越障与避障、竞速、识别、检测与播报、路径规划、踢足球等 |
| **空中具身智能组** | 复杂环境下的自主导航、识别与避障等 |

#### 专项赛三：VEX U智能机器人对抗赛

VEX U是全球规模最大的VEX机器人世界锦标赛的赛项之一。从第五届大赛开始设立。[citation:3][citation:7]

| 届数 | 年份 | 竞赛主题 | 比赛场地 | 赛局设置 |
|:---:|:---:|:---|:---|:---|
| 第7届 | 2024年 | 尖峰时刻 | 约3.7×3.7米正方形场地 | 两支赛队各控制两台机器人，30秒自动时段+90秒手动控制时段，目标是将套环放在尖桩上得分，挪动移动桩，赛局结束时攀爬 [citation:5] |
| 第8-9届 | 2025-2026年 | 狭路相逢 | 约3.7×3.7米正方形场地 | 具体规则详见VEX中文官方论坛 [citation:3][citation:10] |

## 四、赛题特点分析

### 1. **主题明确，梯度合理**
大赛以“更好、更快、更强”为核心主题，通过创意设计、创意竞技、创意格斗三个主题赛，形成了从创意到实物的完整能力考察梯度。[citation:1][citation:2]

### 2. **紧跟技术前沿，持续迭代**
近年新增AIGC辅助设计组、具身智能挑战赛、ROS技术应用等赛项，紧跟人工智能和机器人技术发展前沿。[citation:3][citation:5][citation:6]

### 3. **产教融合，真题真做**
产教融合赛引入舜宇、中兴、中国移动、信捷电气等企业真实需求，将产业需求转化为竞赛题目，促进产学研用结合。[citation:3][citation:10]

### 4. **分层分类，覆盖面广**
- **主题一**：面向创意设计，覆盖各专业背景学生
- **主题二**：面向竞技挑战，侧重机械、电子、控制综合能力
- **主题三**：面向对抗竞技，强调策略与实战能力
- **专项赛**：面向特定技术领域，考察专业深度
- **产教融合赛**：面向企业需求，强调实用性与创新性

### 5. **形式灵活，鼓励创新**
主题一设置无实物、自制实物、模块搭建、AIGC辅助四种作品形式，降低参赛门槛的同时鼓励多样化创新表达。[citation:1][citation:4][citation:6]
