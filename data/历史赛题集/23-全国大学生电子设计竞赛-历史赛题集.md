## 一、竞赛简介

全国大学生电子设计竞赛（National Undergraduate Electronic Design Contest，简称：NUEDC）是教育部高等教育司、工业和信息化部人事教育司共同发起主办的全国性大学生科技竞赛活动，是我国最高级别、覆盖面最广、最具影响力的电子设计类学科竞赛之一。竞赛始于1994年，每两年举办一次（单数年），逢双数年举办各省赛区竞赛或专题邀请赛。

竞赛的特点是与高校电子类课程体系紧密结合，坚持“政府主办、专家主导、学生主体、社会参与”的办赛模式，以“创意发挥、规范设计、突破自我、奇思妙想”为宗旨，着重考察参赛学生的理论基础、实践创新能力、团队协作精神和工程动手能力。

## 二、竞赛赛制与组别

### 赛制流程

| 阶段 | 时间 | 内容 |
|:---:|:---:|:---|
| 全国竞赛 | 单数年（如2025、2023年） | 全国统一命题、统一时间竞赛 |
| 省级竞赛 | 双数年（如2024、2026年） | 各省赛区组织，优秀作品推荐全国 |
| 专题邀请赛 | 不定期 | 针对特定技术方向的邀请赛 |

### 竞赛组别

| 组别 | 参赛对象 | 特点 |
|:---:|:---|:---|
| **本科组** | 全日制在校本科生 | 题目难度较高，涵盖系统设计、算法实现等 |
| **高职高专组** | 全日制在校专科生 | 题目侧重基础应用，强调动手能力 |

### 综合测评

每届全国竞赛结束后，优秀参赛队需参加**综合测评**，采用全封闭式命题，现场完成指定的电路设计与制作任务，重点考察学生的基础电路设计能力和现场应变能力。

## 四、典型赛题解析

### 1. 纸张计数显示装置（2019年F题）[citation:8]

| 项目 | 具体要求 |
|:---|:---|
| **任务** | 设计制作基于平行极板电容法的纸张计数显示装置 |
| **基本要求** | ① 极板50mm×50mm正方形，导线500mm±5mm；<br>② 具有自校准功能；<br>③ 可检测极板是否短路；<br>④ 测量1~10张纸，一键启动，≤5秒完成，蜂鸣提示 |
| **发挥要求** | ① 测量15~30张纸；<br>② 测量30张以上纸张 |
| **关键技术** | 电容测量、微弱信号检测、温度补偿、抗干扰设计 |

### 2. 智能送药小车（2021年F题）[citation:4]

| 项目 | 具体要求 |
|:---|:---|
| **任务** | 设计制作基于视觉识别的智能送药小车，模拟医院病房药品配送 |
| **基本要求** | ① 识别病房编号（数字或二维码）；<br>② 按照指定路线将药品送达指定病房；<br>③ 自动返回出发点 |
| **发挥要求** | ① 多车协同配送；<br>② 动态避障；<br>③ 无线通信上报任务状态 |
| **关键技术** | 视觉识别、路径规划、多机通信、电机控制 |

### 3. 复合信号发生器（2017年综合测评）[citation:9]

| 项目 | 具体要求 |
|:---|:---|
| **任务** | 使用指定芯片设计复合信号发生器 |
| **芯片** | READ2302G（双运放）×2、HD74LS74（双D触发器）×1 |
| **信号流程** | 方波产生→四分频→三角波产生→同相相加→滤波→正弦波 |
| **电源** | 仅限+5V单电源 |
| **输出电阻** | 600Ω |
| **考核点** | 5路输出波形（方波、四分频方波、三角波、复合波、正弦波） |

## 五、赛题类型分类统计

根据历年赛题统计，全国大学生电子设计竞赛的题目主要分为以下七大类[citation:7]：

| 类型 | 典型题目 | 考察重点 |
|:---|:---|:---|
| **电源类** | 开关电源、DC-DC变换器、逆变器、无线充电 | 功率电子、拓扑结构、效率优化 |
| **信号源类** | 函数信号发生器、DDS信号源 | 波形合成、频率稳定度、低失真 |
| **高频无线电类** | 调频收音机、射频放大器、无线收发系统 | 高频电路、阻抗匹配、频谱分析 |
| **放大器类** | 功率放大器、测量放大器、程控放大器 | 增益控制、带宽、噪声抑制 |
| **仪器仪表类** | 频率计、频谱分析仪、失真度测量仪 | 信号采集、数据处理、精度校准 |
| **数据采集与处理类** | 数据采集系统、语音存储回放、图像处理 | ADC/DAC、存储、实时处理 |
| **控制类** | 智能小车、四旋翼飞行器、倒立摆、机器人 | 传感器融合、控制算法、电机驱动 |

## 六、赛题特点分析

### 1. **紧贴课程体系，考察综合能力**
赛题与“模拟电子线路”、“数字电路”、“高频电路”、“单片机原理”、“自动控制”等核心课程紧密结合，要求选手具备扎实的理论基础和综合运用能力[citation:7]。

### 2. **与时俱进，技术前沿不断拓展**
从早期的纯模拟电路设计，发展到单片机应用、FPGA设计、机器视觉、神经网络硬件实现等前沿技术领域。近年新增深度学习目标检测、无人机协同、无线充电等方向。

### 3. **软硬结合，算法权重提升**
早期赛题偏重硬件电路设计，近年题目普遍要求结合算法实现智能控制、信号识别、数据分析等功能，软件编程能力日益重要。

### 4. **强调工程实现，注重实际问题解决**
题目多来源于工程实际问题（如纸张计数、电缆故障定位、药品配送等），要求选手不仅“懂原理”，更要“能实现”，具备解决实际工程问题的能力。

### 5. **综合测评选拔优秀**
通过综合测评环节，采用全封闭命题方式考察选手的基础电路设计能力和现场应变能力，选拔真正优秀的团队进入全国奖项角逐。
