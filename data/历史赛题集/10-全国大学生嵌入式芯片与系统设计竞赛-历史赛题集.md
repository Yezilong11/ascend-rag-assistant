# 全国大学生嵌入式芯片与系统设计竞赛 - 历史赛题集

**来源网址**: http://www.socchina.net/
**信息整理时间**: 2026-03-14

## 一、竞赛简介

全国大学生嵌入式芯片与系统设计竞赛是由中国电子学会主办，面向全国高校大学生的专业学科竞赛。竞赛旨在加强全国高校学生在嵌入式芯片与系统设计应用领域的创新设计与工程实践能力培养，推进高校与集成电路相关企业产学协同育人。

竞赛设有三大赛道，每年在不同时间段举行。

## 二、赛道设置与赛题方向

### 三大赛道

| 赛道 | 时间 | 赛题特点 |
|:---|:---|:---|
| **应用赛道** | 2月-8月 | 面向嵌入式系统实际应用开发，综合考察软硬件协同设计能力 |
| **设计专项赛** | 6月-12月 | 聚焦芯片设计、IP核开发、数字/模拟电路设计 |
| **FPGA创新设计赛道** | 6月-12月 | 基于FPGA的数字系统设计，强调硬件加速与并行计算 |

## 三、历届赛题方向汇总

### 应用赛道常见赛题方向

应用赛道要求参赛队基于指定或自选的嵌入式平台，完成具有实际应用背景的创新作品。近年来常见方向包括：

| 领域 | 具体方向 |
|:---|:---|
| **智能家居** | 家庭安防、环境监测、智能控制、老人看护 |
| **智慧交通** | 车联网、智能停车、路侧感知、车载终端 |
| **工业控制** | 工业物联网、预测性维护、数据采集、运动控制 |
| **医疗健康** | 可穿戴设备、健康监测、康复辅助、远程医疗 |
| **消费电子** | 智能穿戴、人机交互、音视频处理 |
| **机器人** | 移动机器人、机械臂控制、SLAM导航 |
| **物联网终端** | 边缘计算、传感网络、低功耗通信 |

### 设计专项赛方向

设计专项赛侧重芯片设计能力，方向包括：

| 方向 | 说明 |
|:---|:---|
| **数字IC设计** | 数字逻辑电路、处理器核、接口IP设计 |
| **模拟IC设计** | 放大器、ADC/DAC、电源管理芯片设计 |
| **混合信号设计** | 数模混合电路、锁相环、传感器接口 |
| **SoC系统设计** | 片上系统架构设计、软硬件协同设计 |

### FPGA创新设计赛道方向

| 方向 | 说明 |
|:---|:---|
| **数字信号处理** | FIR/FFT、图像处理、视频编解码 |
| **人工智能加速** | CNN加速器、神经网络推理 |
| **通信系统** | 调制解调、信道编解码、软件无线电 |
| **嵌入式系统** | 软核处理器、片上系统、外设控制器 |

## 五、赛题特点分析

### 1. 软硬件协同设计
竞赛强调将**硬件设计与软件开发**相结合，既考察硬件平台的理解，也考察软件算法的实现能力。

### 2. 多平台支持
参赛队伍可选择：
- **主流嵌入式平台**：ARM、RISC-V、STM32等
- **FPGA平台**：Xilinx、Intel(Altera)、国产FPGA
- **国产芯片平台**：鼓励使用国产嵌入式处理器

### 3. 工程实用性
赛题强调解决**实际工程问题**，作品需有明确的应用场景和现实意义。

### 4. 分层设计
三大赛道分别面向：
- 应用层开发（应用赛道）
- 芯片层设计（设计专项赛）
- FPGA硬件加速（FPGA赛道）
