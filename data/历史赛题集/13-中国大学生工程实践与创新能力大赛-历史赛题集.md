# 中国大学生工程实践与创新能力大赛 - 历史赛题集

**来源网址**: http://www.gcxl.edu.cn/
**信息整理时间**: 2026-03-14

## 一、竞赛简介

中国大学生工程实践与创新能力大赛（简称：工创赛）是教育部高等教育司主办、教育部工程训练教学指导委员会举办的全国性大学生科技创新实践竞赛活动。其前身为“全国大学生工程训练综合能力竞赛”。大赛旨在深化实验教学改革，提升大学生工程创新意识、实践能力和团队合作精神，跨学科、跨专业培养创新型、复合型卓越工程技术人才。

## 二、大赛演变说明

大赛于2021年（第七届）正式更名为“中国大学生工程实践与创新能力大赛”。以下按更名前后分别整理历届赛题。

## 三、历届赛题汇总

### 更名前：全国大学生工程训练综合能力竞赛（第1-6届）

| 届数 | 年份 | 赛题主题 | 具体赛项/要求 |
|:---:|:---:|:---|:---|
| 第一届 | 2009年 | **无碳小车越障竞赛** | 以重力势能驱动的小车，需在行进过程中自动绕过障碍物。重点考察机械结构设计、加工工艺与装配调试能力。 |
| 第二届 | 2011年 | **无碳小车越障竞赛** | 延续“无碳小车”命题，要求小车在“S”型或“8”字型赛道行驶并绕障。增加对能量利用效率和轨迹精度的考察。 |
| 第三届 | 2013年 | **无碳小车越障竞赛** | 继续以“无碳小车”为核心，对前轮转向机构、后轮驱动机构的设计提出更高要求。 |
| 第四届 | 2015年 | **无碳小车越障竞赛** | 首次引入“电控无碳小车”方向，鼓励结合简单电路控制实现复杂轨迹和避障功能（如环形跑道）。 |
| 第五届 | 2017年 | **无碳小车+智能物料搬运** | 除“S”型、“8”字型赛道常规赛外，新增“智能物料搬运机器人”赛项，向机电一体化方向发展。 |
| 第六届 | 2019年 | **无碳小车+全地形小车** | 保持传统“无碳小车”项目，新增“全地形小车”赛项，考察小车在不同地形上的适应和越障能力。 |

### 更名后：中国大学生工程实践与创新能力大赛（第7届至今）

#### 第七届（2021年）
**竞赛主题**：守德崇劳，工程创新求卓越

| 赛项名称 | 赛题要求 |
|:---|:---|
| **势能驱动车** | 延续无碳小车命题，利用重力势能驱动，在“S”型赛道上自动避障。考察机械设计与制造基础。 |
| **智能物料搬运机器人** | 设计制造能自主识别物料、规划路径并进行抓取搬运的智能机器人。综合考察机械、电子、控制、传感器技术。 |
| **桥梁结构设计** | 用指定材料（如木材）设计制作桥梁模型并进行加载测试。以结构效率（承载/自重）高者为胜。考察结构力学分析与设计能力。 |
| **水下管道智能巡检** | 设计制作水下机器人（ROV），模拟在复杂水环境中对管道进行智能巡检、识别故障并上报。考察水下机器人设计、水下通信与图像识别能力。 |
| **智能配送无人机** | 设计制作多旋翼无人机，实现自主起飞、路径规划、精准投放、自动返航。考察飞控算法、机器视觉及任务规划能力。 |
| **企业运营仿真** | 以虚拟仿真形式模拟企业从市场调研、产品设计、生产制造到市场营销的全过程。考察经营管理、供应链协同和商业决策能力。 |
| **工程场景数字化** | 利用VR/AR或数字孪生技术创建具体工程场景（如智能工厂），并完成交互任务。考察数字化建模和工程场景构建能力。 |

#### 第八届（2023年）
**竞赛主题**：交叉融合工程创新求卓越，守德崇劳制造强国勇担当

| 赛项名称 | 赛题要求 |
|:---|:---|
| **太阳能电动车** | 命题从重力势能转向新能源。设计制作以太阳能为主要动力的电动车，在规定赛道比拼速度和稳定性。考察能量收集、转换与管理技术。 |
| **生物活性物质智能分离** | 结合生物工程与自动化技术。设计自动化装置，实现对模拟生物活性物质（如特定颜色微珠）的精准识别、抓取和分类。考察跨学科设计与自动化控制能力。 |
| **智能网联汽车设计** | 基于智能网联汽车仿真平台或缩微模型，设计自动驾驶算法，实现车道保持、红绿灯识别、障碍物避让及自动泊车。考察算法设计与系统集成能力。 |
| **飞行器设计仿真** | 在虚拟仿真环境中完成飞行器的气动设计、结构优化、飞行性能分析及虚拟飞行测试全流程。考察飞行器设计理论与仿真软件应用能力。 |
| **生活垃圾智能分类** | 设计制作智能垃圾分类装置，自动识别并投放不同类别生活垃圾（如塑料瓶、易拉罐、电池、纸张等）。考察机器视觉、机械结构与自动控制技术的综合应用。 |

## 四、赛题特点分析

### 1. 从单一机械向机电软一体化发展
早期以纯机械结构的“无碳小车”为主，逐步发展为融合控制、传感器、机器视觉、人工智能等技术的智能装备。

### 2. 从基础制造向前沿技术拓展
赛题方向从传统机械加工制造，拓展到新能源（太阳能）、智能网联汽车、无人机、水下机器人、虚拟仿真等工程前沿领域。

### 3. 从单一学科向多学科交叉融合
每个赛项要求参赛团队综合运用机械、电子、计算机、控制、力学等多学科知识，解决复杂工程问题。

### 4. 从实物制作向虚拟仿真结合发展
除传统实物制作和现场运行外，引入企业运营仿真、飞行器设计仿真、工程场景数字化等虚拟仿真赛项，考察数字化设计与仿真能力。
