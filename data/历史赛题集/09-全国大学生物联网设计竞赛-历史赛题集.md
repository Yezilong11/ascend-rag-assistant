# 全国大学生物联网设计竞赛 - 历史赛题集

**来源网址**: https://iot.sjtu.edu.cn/
**信息整理时间**: 2026-03-14

## 一、竞赛简介

全国大学生物联网设计竞赛是由全国高等学校计算机教育研究会主办，上海交通大学承办的物联网领域最具规模和影响力的学科竞赛[citation:1]。竞赛自2014年创办，2023年3月入选中国高等教育学会《全国普通高校大学生竞赛分析报告》竞赛榜单，2023年4月入选《全国普通高校大学生计算机类竞赛研究报告》[citation:1][citation:4]。

竞赛以促进物联网相关专业建设和人才培养为目标，激发学生的创造、创新、创业活力，推动高校创新创业教育[citation:1]。

## 二、赛道命题（8大赛道）

根据2025年竞赛通知，竞赛命题分为8个赛道，由行业龙头企业冠名出题[citation:3][citation:8]：

| 出题企业 | 技术方向 | 赛题领域 |
|:---|:---|:---|
| **华为** | 华为云IoT/EI/PaaS、华为5G/5.5G、华为昇腾计算、华为数通、OpenHarmony | 城市智能体、智慧园区、车联网 |
| **乐鑫信息科技** | AI SoC ESP32-S3 | 智能家居、边缘计算 |
| **霍尼韦尔** | 物联网中间件Niagara、低碳精益技术 | 智慧建筑、工业物联网 |
| **CSA联盟** | Matter、Zigbee | 智能家居互联互通 |
| **广和通** | 5G通信、边缘AIoT | 工业互联、智慧城市 |
| **TI** | 毫米波雷达、SimpleLink | 智能传感、定位追踪 |
| **火山引擎** | xPICO端智能、具身智能 | AIoT、智能终端 |
| **涂鸦智能** | TuyaOpen、AIoT开发者平台 | 智能家居、云平台开发 |

**注**：参赛队也可选择常规赛道命题（自拟主题）报名参赛，对应用领域和场景没有特定限制[citation:8]。

## 三、历届赛题方向汇总

### 应用场景方向（每年通用）
参赛作品需基于物联网技术，开发具有现实应用价值的创新应用，涵盖但不限于以下场景[citation:3][citation:5]：

| 领域 | 具体方向 |
|:---|:---|
| 城市智能体 | 智慧城市、城市大脑、智能交通 |
| 智慧园区 | 园区管理、楼宇自控、安防监控 |
| 智慧交通 | 车联网、智能网联汽车、路侧感知 |
| 车联网 | V2X通信、车载智能终端 |
| 智联生活 | 智能家居、可穿戴设备、健康监测 |
| 智能制造 | 工业物联网、预测性维护、工业机器人 |
| 智慧仓储 | 仓储管理、物流追踪、AGV调度 |
| 智慧农业 | 精准灌溉、环境监测、农产品溯源 |

### 2022年华为赛题方向示例[citation:5]
| 赛题方向 | 技术要求 |
|:---|:---|
| 智慧城市应用 | 基于华为云IoT平台，开发城市治理类应用 |
| 工业互联网 | 结合5G技术，实现工业设备数据采集与分析 |
| 端云协同 | 基于OpenHarmony，开发端云协同智能设备 |

## 五、赛题特点与技术要求

### 作品形式要求[citation:1][citation:4]
1. **线上提交**：
   - 完整设计方案文档（按照组委会发布的格式要求）
   - 作品实物演示视频（展示作品功能与创新点）

2. **现场答辩**：
   - 作品讲解（PPT演示）
   - 实物演示（现场操作展示）

### 技术要求[citation:3]
| 技术维度 | 说明 |
|:---|:---|
| 硬件平台 | 可使用合作伙伴提供的免费技术平台，也可自选 |
| 软件系统 | 可采用华为云、OpenHarmony、TuyaOpen等 |
| 加分项 | 使用竞赛推荐技术平台可获得适当加分 |

### 原创性要求[citation:1]
- 参赛作品必须是学生原创
- 谢绝任何形式的导师课题参赛
- 不得直接使用参加其他竞赛的作品参赛
