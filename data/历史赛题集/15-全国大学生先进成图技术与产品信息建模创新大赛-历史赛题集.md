# 全国大学生先进成图技术与产品信息建模创新大赛 - 历史赛题集

**来源网址**: http://www.chengtudasai.com/

## 一、竞赛简介

全国大学生先进成图技术与产品信息建模创新大赛（简称：成图大赛）是由教育部高等学校工程图学课程教学指导委员会、中国图学学会制图技术专业委员会等单位主办的国家级A类竞赛。大赛被誉为“图学界的奥林匹克”，是图学类课程最高级别的国家级赛事。旨在培养大学生的工匠精神、创新意识和实践能力，掌握先进成图技术和产品信息建模方法。

## 二、大赛体系构成

成图大赛包含多个赛道，涵盖传统图学、数字化设计和前沿技术应用：

| 赛道分类 | 竞赛内容 | 参赛形式 |
|:---|:---|:---|
| **机械类** | 二维工程图绘制、三维数字建模、轻量化设计 | 个人赛+团体赛 |
| **建筑类** | 建筑施工图绘制、建筑信息模型(BIM)设计 | 个人赛+团体赛 |
| **道桥类** | 道路桥梁工程图绘制、道桥信息建模 | 个人赛+团体赛 |
| **水利类** | 水利工程图绘制、水利信息建模 | 个人赛+团体赛 |
| **电子类** | 电子线路图绘制、PCB设计建模 | 个人赛+团体赛 |
| **轻量化设计与AI应用** | 面向增材制造的优化设计、AI辅助设计 | 专项赛 |

## 四、轻量化设计与AI应用专项赛题解析

轻量化设计与AI应用是近年成图大赛的重点发展方向，以下为第五届（2025年）专项赛详细解析：

### 第五届轻量化设计与AI应用赛（2025年）

**竞赛题目**：面向增材制造的无人机机架轻量化设计

**原始模型**：给定标准无人机机架三维模型

**设计要求**：
| 指标 | 要求 |
|:---|:---|
| 减重目标 | 在满足强度前提下，减重≥30% |
| 强度约束 | 最大等效应力≤材料屈服强度 |
| 刚度约束 | 最大变形≤原始模型的1.2倍 |
| 制造约束 | 适应FDM/SLA等常见3D打印工艺 |
| AI辅助 | 鼓励使用AI工具辅助生成优化方案 |

**提交成果**：
1. 优化后的三维模型（STEP/IGES格式）
2. 有限元分析报告（含应力、变形云图）
3. 轻量化设计说明书（设计思路、优化过程）
4. AI辅助设计说明（如使用了生成式设计工具）

### 历年轻量化赛题方向演变

| 年份 | 赛题方向 | 关键技术 |
|:---:|:---|:---|
| 2023 | 支架类零件轻量化 | 拓扑优化、尺寸优化 |
| 2024 | 连杆机构轻量化 | 形状优化、多体动力学分析 |
| 2025 | 无人机机架轻量化 | 生成式设计、AI辅助优化 |
| 2026 | 机器人关节轻量化 | 多目标优化、 lattice结构设计 |

## 六、赛题特点分析

### 1. 分层递进，体系完善
从基础的二维绘图到复杂三维建模，再到轻量化优化和AI辅助设计，形成完整的能力考察梯度。

### 2. 多学科覆盖，赛道丰富
涵盖机械、建筑、道桥、水利、电子等多个工科领域，满足不同专业学生参赛需求。

### 3. 紧跟产业，技术前沿
轻量化设计、AI辅助生成、增材制造优化等赛题方向，与制造业数字化转型趋势紧密对接。

### 4. 师生同赛，教学相长
设立教师竞赛单元，推动图学课程教学改革和师资能力提升。

### 5. 标准严格，注重规范
强调图纸的国标规范性、建模的标准化流程，体现工程严谨性。
