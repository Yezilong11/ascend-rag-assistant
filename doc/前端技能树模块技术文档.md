# 前端技能树模块技术文档

## 1. 技术架构

### 1.1 整体架构
- **框架**: Streamlit
- **语言**: Python 3.9+
- **UI组件**: Streamlit内置组件
- **API调用**: requests库
- **状态管理**: Streamlit session_state

### 1.2 模块划分
- **主页面**: 应用入口，包含导航和主要功能区
- **技能树管理**: 技能树的创建、查看和管理
- **智能问答**: 基于知识库的智能问答功能
- **系统设置**: 应用配置和管理

## 2. 核心功能

### 2.1 技能树管理
- **技能树列表**: 展示所有技能树，支持选择和查看详情
- **创建技能树**: 表单提交创建新的技能树
- **技能管理**: 添加、编辑和删除技能节点
- **技能关系**: 建立和管理技能之间的关系
- **学习路径**: 查看和管理生成的学习路径

### 2.2 智能问答
- **问答界面**: 用户输入问题，系统返回答案
- **知识库管理**: 查看和管理知识库中的文档
- **文档导入**: 手动导入新的文档到知识库

### 2.3 系统设置
- **模型配置**: 配置LLM模型参数
- **知识库设置**: 配置知识库相关参数
- **系统状态**: 查看系统运行状态和日志

## 3. 界面设计

### 3.1 布局结构
- **侧边栏**: 导航菜单，包含技能树管理、智能问答和系统设置
- **主内容区**: 根据选择的功能显示相应的内容
- **顶部栏**: 显示应用标题和系统状态

### 3.2 组件设计
- **表单组件**: 用于创建技能树、添加技能等操作
- **列表组件**: 展示技能树列表、技能列表等
- **树形组件**: 展示技能树的层次结构
- **路径组件**: 展示生成的学习路径
- **问答组件**: 用于智能问答交互

### 3.3 交互设计
- **加载状态**: 显示操作的加载状态，提高用户体验
- **错误提示**: 友好的错误提示，帮助用户理解操作失败的原因
- **成功反馈**: 操作成功时的反馈信息
- **实时更新**: 数据变更时实时更新界面

## 4. 核心实现

### 4.1 状态管理
- **session_state**: 用于管理应用状态，包括技能树列表、当前选择的技能树等
- **缓存机制**: 缓存API响应，减少重复请求

### 4.2 API调用
- **技能树API**: 调用后端API进行技能树的管理操作
- **知识库API**: 调用后端API进行知识库的管理和查询
- **错误处理**: 处理API调用失败的情况，提供友好的错误提示

### 4.3 数据处理
- **数据转换**: 将后端返回的数据转换为前端展示所需的格式
- **表单验证**: 验证用户输入的数据，确保数据的有效性
- **数据可视化**: 将技能树和学习路径以可视化的方式展示

### 4.4 性能优化
- **懒加载**: 按需加载数据，提高应用响应速度
- **缓存策略**: 缓存常用数据，减少API调用
- **批量操作**: 支持批量导入和处理数据

## 5. 集成与部署

### 5.1 与后端集成
- **API地址配置**: 配置后端API的地址和端口
- **认证机制**: 与后端的认证机制集成
- **数据同步**: 确保前端和后端数据的一致性

### 5.2 部署方式
- **本地部署**: 在本地环境运行应用
- **容器部署**: 使用Docker容器部署应用
