# 技能树模块需求文档

## 1. 需求分析

### 1.1 原始需求
用户希望为昇腾AI竞赛智能助教项目增添一个技能树模块，目标群体是爱好竞赛的大学生们。该模块应包含多种竞赛相关技能，与现有竞赛知识库关联，并提供个性化的学习路径和进度跟踪功能。

### 1.2 需求拆解

| 编号 | 需求点 | 详细描述 | 优先级 |
|------|--------|----------|--------|
| RQ1 | 技能类型覆盖 | 包含技术类、设计类、学术类、综合类等多种技能类型，覆盖所有预置的竞赛类型 | P0 |
| RQ2 | 技能树结构 | 采用四级结构：技能领域 → 技能类别 → 具体技能 → 子技能 | P0 |
| RQ3 | 与竞赛知识库关联 | 根据用户感兴趣的竞赛推荐需要学习的技能 | P0 |
| RQ4 | 非线性学习路径 | 允许用户根据兴趣和需求自由选择学习路径 | P1 |
| RQ5 | 技能评估 | 通过自测题实现技能水平评估 | P0 |
| RQ6 | 进度跟踪 | 提供个性化的学习进度跟踪和报告 | P0 |
| RQ7 | 学习资源管理 | 为每个技能提供相关的学习资源，如教程、文档、视频等 | P1 |

### 1.3 可行性评估

| 评估维度 | 评估结果 | 说明 |
|----------|----------|------|
| 技术可行性 | 高 | 基于现有的Streamlit框架和知识库结构，可以扩展实现技能树模块 |
| 开发成本 | 中 | 需要设计新的数据结构和UI组件，但可以复用现有代码框架 |
| 商业价值 | 高 | 技能树模块可以帮助用户更系统地准备竞赛，提高用户粘性和使用价值 |

## 2. 领域模型设计

### 2.1 核心领域概念

| 概念 | 描述 | 关系 |
|------|------|------|
| 技能领域 | 技能的最高层级分类，如技术类、设计类等 | 包含多个技能类别 |
| 技能类别 | 技能领域下的二级分类，如编程、算法等 | 包含多个具体技能 |
| 具体技能 | 技能类别的下一级分类，如Python编程、数据结构等 | 包含多个子技能 |
| 子技能 | 技能的最细粒度分类，如Python基础、Python高级等 | 无下级分类 |
| 学习资源 | 与技能相关的学习材料，如教程、文档、视频等 | 属于特定技能 |
| 自测题 | 用于评估技能水平的测试题 | 属于特定技能 |
| 学习进度 | 用户的技能学习进度和状态 | 与用户和技能关联 |
| 竞赛关联 | 技能与竞赛的关联关系 | 多对多关系 |

### 2.2 领域服务

| 服务 | 描述 | 实现方式 |
|------|------|----------|
| 技能树管理服务 | 管理技能树的结构和内容 | 基于文件或数据库存储 |
| 技能评估服务 | 管理自测题和评估逻辑 | 基于规则引擎实现 |
| 进度跟踪服务 | 跟踪用户的学习进度 | 基于用户会话或数据库存储 |
| 竞赛关联服务 | 管理技能与竞赛的关联关系 | 基于知识库查询实现 |
| 学习路径推荐服务 | 基于用户兴趣和目标推荐学习路径 | 基于规则和用户数据实现 |

## 3. 功能模块设计

### 3.1 技能树管理模块

| 功能点 | 描述 | 优先级 | 实现方式 |
|--------|------|--------|----------|
| 技能树结构管理 | 管理技能树的四级结构，支持添加、编辑、删除技能 | P0 | 基于文件存储的JSON结构 |
| 技能详情管理 | 管理每个技能的详细信息，如描述、难度、学习时长等 | P0 | 基于文件存储的JSON结构 |
| 学习资源管理 | 为每个技能添加、编辑、删除学习资源 | P1 | 基于文件存储的JSON结构 |
| 自测题管理 | 为每个技能添加、编辑、删除自测题 | P0 | 基于文件存储的JSON结构 |

### 3.2 技能评估模块

| 功能点 | 描述 | 优先级 | 实现方式 |
|--------|------|--------|----------|
| 自测题展示 | 为用户展示特定技能的自测题 | P0 | Streamlit组件实现 |
| 答题与评分 | 允许用户答题并自动评分 | P0 | 基于规则的评分逻辑 |
| 评估结果展示 | 展示用户的技能评估结果和建议 | P0 | Streamlit组件实现 |

### 3.3 进度跟踪模块

| 功能点 | 描述 | 优先级 | 实现方式 |
|--------|------|--------|----------|
| 学习进度记录 | 记录用户的技能学习进度 | P0 | 基于Streamlit会话状态或本地存储 |
| 进度可视化 | 以图表形式展示用户的学习进度 | P0 | Streamlit图表组件实现 |
| 个性化报告 | 根据用户学习情况生成个性化的学习报告 | P0 | 基于用户数据的分析和生成 |

### 3.4 竞赛关联模块

| 功能点 | 描述 | 优先级 | 实现方式 |
|--------|------|--------|----------|
| 竞赛技能推荐 | 根据用户感兴趣的竞赛推荐需要学习的技能 | P0 | 基于知识库查询和规则匹配 |
| 技能竞赛关联 | 展示每个技能与相关竞赛的关联关系 | P1 | 基于文件存储的关联数据 |

### 3.5 用户交互模块

| 功能点 | 描述 | 优先级 | 实现方式 |
|--------|------|--------|----------|
| 技能树可视化 | 以树形结构展示技能体系 | P0 | Streamlit组件实现 |
| 技能详情查看 | 查看技能的详细信息和学习资源 | P0 | Streamlit页面实现 |
| 学习路径规划 | 基于用户目标规划个性化学习路径 | P1 | 基于规则和用户数据实现 |
| 进度查询 | 查询用户的学习进度和状态 | P0 | Streamlit页面实现 |

| 风险点 | 风险等级 | 应对措施 |
|--------|----------|----------|
| 技能树数据维护 | 中 | 设计易于维护的数据结构和管理界面 |

## 9. 结论

技能树模块是昇腾AI竞赛智能助教项目的重要扩展，它将帮助大学生用户更系统地准备竞赛，提高竞赛成功率。通过四级结构的技能树设计、非线性学习路径、技能评估和进度跟踪功能，以及与竞赛知识库的关联，该模块将为用户提供全面的竞赛技能学习体验。

项目团队应按照DDD开发流程，优先实现核心功能，确保系统的稳定性和可用性，同时为后续的功能扩展预留空间。
