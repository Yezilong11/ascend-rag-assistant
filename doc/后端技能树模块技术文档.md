# 后端技能树模块技术文档

## 1. 技术架构

### 1.1 整体架构
- **框架**: FastAPI
- **语言**: Python 3.9+
- **依赖管理**: pip
- **持久化**: 文件系统（JSON格式）
- **知识图谱**: Chroma（向量数据库）

### 1.2 模块划分
- **domain**: 领域模型和业务逻辑
- **application**: 应用服务层
- **infrastructure**: 基础设施层
- **api**: API路由

## 2. 核心功能

### 2.1 技能树管理
- 创建技能树
- 获取技能树列表
- 获取技能树详情
- 添加技能节点
- 建立技能关系
- 生成学习路径

### 2.2 知识库管理
- 文档自动导入
- 向量数据库初始化
- 智能问答

## 3. API设计

### 3.1 技能树API

| 端点 | 方法 | 功能 | 请求体 | 成功响应 |
|------|------|------|--------|----------|
| `/api/skill-tree/` | GET | 获取技能树列表 | N/A | `{"success": true, "data": [{"id": "...", "name": "...", "description": "..."}]}` |
| `/api/skill-tree/` | POST | 创建技能树 | `{"name": "...", "description": "..."}` | `{"success": true, "data": {"id": "...", "name": "...", "description": "..."}}` |
| `/api/skill-tree/{skill_tree_id}` | GET | 获取技能树详情 | N/A | `{"success": true, "data": {"id": "...", "name": "...", "skills": [...]}}` |
| `/api/skill-tree/{skill_tree_id}/skills` | POST | 添加技能 | `{"name": "...", "description": "...", "level": "...", "skill_type": "...", "learning_time": 0}` | `{"success": true, "data": {"id": "...", "name": "..."}}` |
| `/api/skill-tree/{skill_tree_id}/relations` | POST | 建立技能关系 | `{"source_skill_id": "...", "target_skill_id": "...", "relation_type": "..."}` | `{"success": true, "message": "关系建立成功"}` |
| `/api/skill-tree/{skill_tree_id}/learning-paths` | GET | 获取学习路径 | N/A | `{"success": true, "data": [{"path_id": "...", "skill_ids": [...], "estimated_time": 0, "difficulty": "..."}]}` |

## 4. 核心实现

### 4.1 领域模型
- **SkillTree**: 技能树根实体
- **SkillNode**: 技能节点
- **SkillRelation**: 技能关系
- **LearningPath**: 学习路径
- **SkillLevel**: 技能等级枚举
- **SkillType**: 技能类型枚举

### 4.2 仓储层
- **SkillTreeRepository**: 技能树仓储，负责技能树的持久化
- **序列化/反序列化**: 将领域模型转换为JSON格式存储

### 4.3 应用服务
- **SkillTreeApplicationService**: 处理业务逻辑，协调领域服务和仓储
- **SkillTreeService**: 领域服务，实现核心业务规则

### 4.4 知识图谱
- **KnowledgeBase**: 知识库管理，负责文档导入和向量检索
- **Chroma**: 向量数据库，用于存储和检索文档嵌入
- **Fallback机制**: 当Chroma初始化失败时，使用简单内存存储

## 5. 性能优化

### 5.1 算法优化
- **学习路径生成**: 将递归实现改为迭代实现，使用栈来模拟递归过程，避免栈溢出和性能问题

### 5.2 错误处理
- **数据库初始化**: 添加完善的错误处理，确保应用能够在数据库初始化失败时正常启动
- **API调用**: 统一的错误处理和响应格式，提高系统的可维护性

## 6. 部署与集成

### 6.1 启动方式
- **FastAPI服务器**: 运行在`api_port`配置端口（默认8000）
- **Streamlit前端**: 运行在`web_port`配置端口（默认8501）
- **配置文件**: 端口可在`config/config.yaml`中修改

### 6.2 依赖项
- **FastAPI**: Web框架
- **Streamlit**: 前端框架
- **langchain**: 知识图谱和向量检索
- **Chroma**: 向量数据库
- **uvicorn**: ASGI服务器

## 7. 安全与可靠性

### 7.1 错误处理
- 完善的错误捕获和日志记录
- 统一的错误响应格式
- 数据库初始化的fallback机制

### 7.2 数据验证
- 使用Pydantic进行请求数据验证
- 确保数据的一致性和完整性
