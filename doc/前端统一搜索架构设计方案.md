# 前端统一搜索架构设计方案

**文档版本**: v1.0
**创建日期**: 2026-05-09
**状态**: 待评审

---

## 1. 概述

### 1.1 背景

当前项目存在两个独立的向量数据库：

- **`./chroma_db`**: 主知识库，存储各类文档（PDF、TXT、MD 等）经文本切分后的片段
- **`./chroma_db_multimodal`**: 多模态知识库，存储图片经 OCR+VLM 处理后的文本描述

两个数据库使用相同的 Embedding 模型（bge-large-zh-v1.5），但数据结构、存储内容和检索方式存在差异。

### 1.2 目标

在**保持两个 Collection 独立**的前提下，实现前端的**统一搜索体验**，让用户无需关心数据来源，即可获得融合了文档和图片内容的检索结果。

### 1.3 原则

- **数据独立性**: 不合并底层数据库，保持两个 Collection 独立维护
- **接口统一性**: 提供统一的搜索 API，前端无需关心数据来源细节
- **渐进式演进**: 不破坏现有功能，支持逐步迁移
- **用户体验优先**: 搜索结果统一展示，根据内容类型自适应渲染

## 2. 现状分析

### 2.1 数据库结构对比

| 特性 | chroma_db | chroma_db_multimodal |
|------|-----------|---------------------|
| **存储路径** | `./chroma_db` | `./chroma_db_multimodal` |
| **Collection** | 默认 collection | `multimodal_image_chunks` |
| **数据来源** | 文档上传 | 图片上传、PDF 内嵌图片 |
| **存储内容** | 文档文本片段 | OCR 文字 + VLM 描述 |
| **元数据结构** | `metadata.source`, `doc_type` | `metadata.image_path`, `ocr_text`, `document_type` |
| **Entity 类型** | `langchain_core.Document` | 自定义 `ImageChunk` |
| **特有字段** | 无 | `image_path`, `bounding_box` |

### 2.2 当前检索入口

| 场景 | 当前实现 | 检索范围 |
|------|---------|---------|
| RAG 问答 | `rag_api/routes.py` → `KnowledgeBase.similarity_search()` | 仅 `chroma_db` |
| 文档导入 | `rag_api/routes.py` → `KnowledgeBase.ingest()` | 仅 `chroma_db` |
| 图片导入 | `multimodal_api/routes.py` → `/image/ingest` | 仅 `chroma_db_multimodal` |
| PDF 导入 | `multimodal_api/routes.py` → `/pdf/ingest` | 仅 `chroma_db_multimodal` |

### 2.3 存在的问题

1. **搜索体验割裂**: 用户需要分别检索两个数据库才能获得完整结果
2. **前端逻辑复杂**: 前端需要分别调用两个 API 再合并结果
3. **结果排序不统一**: 两个库的检索结果无法统一排序
4. **元数据差异**: 返回结果的数据结构不一致，前端处理逻辑复杂

```python
class UnifiedSearchRequest(BaseModel):
    """
    统一搜索请求模型

    用于 POST /api/search/unified 接口。
    支持同时搜索文档和图片知识库。

    字段说明：
        query:           搜索查询文本，必填
        top_k:           每个来源返回的结果数量，默认 5
        include_documents: 是否搜索文档库，默认 True
        include_images:   是否搜索图片库，默认 True
        rerank:          是否对结果进行重排序，默认 False
    """
    query: str = Field(min_length=1, description="搜索查询文本")
    top_k: int = Field(default=5, ge=1, le=20, description="每个来源返回的结果数量")
    include_documents: bool = Field(default=True, description="是否搜索文档库")
    include_images: bool = Field(default=True, description="是否搜索图片库")
    rerank: bool = Field(default=False, description="是否对结果进行重排序")
```

## 5. 后端改动

### 5.1 新增统一搜索服务

**文件**: `src/search/unified_search_service.py` (新建)

```python
"""
统一搜索服务
同时检索文档库和图片库，返回统一格式的搜索结果
"""

from typing import List, Dict, Any, Optional
from dataclasses import dataclass
import asyncio

from src.knowledge_base import KnowledgeBase
from src.multimodal.infrastructure.persistence.chroma_image_chunk_repository import ChromaImageChunkRepository


@dataclass
class UnifiedSearchResult:
    """统一搜索结果项"""
    content: str
    source_type: str  # "document" | "image"
    source: Optional[str]
    score: float
    metadata: Dict[str, Any]
    ocr_text: Optional[str] = None
    image_path: Optional[str] = None


class UnifiedSearchService:
    """
    统一搜索服务

    同时搜索文档知识库和图片知识库，返回统一的搜索结果格式。
    """

    def __init__(
        self,
        knowledge_base: KnowledgeBase,
        image_repository: ChromaImageChunkRepository,
    ):
        self.knowledge_base = knowledge_base
        self.image_repository = image_repository

    async def search(
        self,
        query: str,
        top_k: int = 5,
        include_documents: bool = True,
        include_images: bool = True,
    ) -> Dict[str, Any]:
        """
        执行统一搜索

        Args:
            query: 搜索查询
            top_k: 每个来源返回的结果数
            include_documents: 是否搜索文档库
            include_images: 是否搜索图片库

        Returns:
            统一的搜索结果
        """
        results: List[UnifiedSearchResult] = []
        tasks = []

        if include_documents:
            tasks.append(self._search_documents(query, top_k))

        if include_images:
            tasks.append(self._search_images(query, top_k))

        # 并行执行搜索
        search_results = await asyncio.gather(*tasks, return_exceptions=True)

        for result in search_results:
            if isinstance(result, list):
                results.extend(result)

        # 按分数排序
        results.sort(key=lambda x: x.score, reverse=True)

        # 统计
        doc_count = sum(1 for r in results if r.source_type == "document")
        img_count = sum(1 for r in results if r.source_type == "image")

        return {
            "results": [
                {
                    "content": r.content,
                    "source_type": r.source_type,
                    "source": r.source,
                    "score": r.score,
                    "metadata": r.metadata,
                    "ocr_text": r.ocr_text,
                    "image_path": r.image_path,
                }
                for r in results
            ],
            "stats": {
                "document_count": doc_count,
                "image_count": img_count,
                "total_count": len(results),
            },
        }

    async def _search_documents(self, query: str, top_k: int) -> List[UnifiedSearchResult]:
        """搜索文档库"""
        loop = asyncio.get_event_loop()
        docs = await loop.run_in_executor(
            None,
            self.knowledge_base.similarity_search,
            query,
            top_k
        )

        return [
            UnifiedSearchResult(
                content=doc.page_content,
                source_type="document",
                source=doc.metadata.get("source"),
                score=0.0,  # Chroma 默认不返回分数，需单独配置
                metadata=doc.metadata,
            )
            for doc in docs
        ]

    async def _search_images(self, query: str, top_k: int) -> List[UnifiedSearchResult]:
        """搜索图片库"""
        loop = asyncio.get_event_loop()
        chunks = await loop.run_in_executor(
            None,
            self.image_repository.search,
            query,
            top_k
        )

        return [
            UnifiedSearchResult(
                content=chunk.get_searchable_text(),
                source_type="image",
                source=chunk.source_file,
                score=0.0,
                metadata=chunk.metadata,
                ocr_text=chunk.ocr_text,
                image_path=chunk.image_path,
            )
            for chunk in chunks
        ]
```

```python
async def unified_search(
    request: UnifiedSearchRequest,
) -> dict:
    """
    统一搜索接口

    同时搜索文档知识库和图片知识库，返回统一的搜索结果。

    关联接口：本文档 4.1 统一搜索接口

    Args:
        request: 统一搜索请求

    Returns:
        dict: 统一响应格式，data 包含 results 和 stats
    """
    from src.search.unified_search_service import UnifiedSearchService

    kb = get_knowledge_base()
    from src.multimodal.infrastructure.persistence.chroma_image_chunk_repository import ChromaImageChunkRepository

    image_repo = ChromaImageChunkRepository()
    service = UnifiedSearchService(knowledge_base=kb, image_repository=image_repo)

    try:
        result = await service.search(
            query=request.query,
            top_k=request.top_k,
            include_documents=request.include_documents,
            include_images=request.include_images,
        )
        return {"success": True, "data": result}
    except Exception as e:
        logger.error(f"统一搜索失败: {e}", exc_info=True)
```

### 6.1 新增 API 客户端

**文件**: `frontend/src/services/unifiedSearchApi.ts` (新建)

```typescript
import { ragApiClient } from './api'
import type { UnifiedSearchResult, UnifiedSearchStats } from '@/types/search'

export interface UnifiedSearchResponse {
  success: boolean
  data?: {
    results: UnifiedSearchResult[]
    stats: UnifiedSearchStats
  }
  message?: string
}

export const unifiedSearchApi = {
  search: async (
    query: string,
    options?: {
      top_k?: number
      include_documents?: boolean
      include_images?: boolean
    }
  ): Promise<UnifiedSearchResponse> => {
    const params = new URLSearchParams({ query })
    if (options?.top_k) params.append('top_k', String(options.top_k))
    if (options?.include_documents !== undefined) {
      params.append('include_documents', String(options.include_documents))
    }
    if (options?.include_images !== undefined) {
      params.append('include_images', String(options.include_images))
    }

    const { data } = await ragApiClient.post<UnifiedSearchResponse>(
      '/search/unified',
      params
    )
    return data
  },
}
```

### 6.3 新增统一搜索组件

**文件**: `frontend/src/components/search/UnifiedSearchPanel.tsx` (新建)

```tsx
import React, { useState } from 'react'
import { unifiedSearchApi, UnifiedSearchResult } from '@/services/unifiedSearchApi'
import { Card, Tag, Segmented } from 'antd'
import { FileTextOutlined, PictureOutlined } from '@ant-design/icons'

type FilterType = 'all' | 'document' | 'image'

const UnifiedSearchPanel: React.FC = () => {
  const [query, setQuery] = useState('')
  const [results, setResults] = useState<UnifiedSearchResult[]>([])
  const [filter, setFilter] = useState<FilterType>('all')
  const [loading, setLoading] = useState(false)

  const handleSearch = async () => {
    if (!query.trim()) return
    setLoading(true)
    try {
      const response = await unifiedSearchApi.search(query, { top_k: 10 })
      if (response.success && response.data) {
        setResults(response.data.results)
      }
    } catch (error) {
      console.error('Search failed:', error)
    } finally {
      setLoading(false)
    }
  }

  const filteredResults = results.filter((r) => {
    if (filter === 'all') return true
    return r.source_type === filter
  })

  return (
    <div className="unified-search-panel">
      {/* 搜索输入 */}
      <div className="search-input-area">
        <input
          value={query}
          onChange={(e) => setQuery(e.target.value)}
          onPressEnter={handleSearch}
          placeholder="输入搜索关键词..."
        />
        <button onClick={handleSearch} disabled={loading}>
          {loading ? '搜索中...' : '搜索'}
        </button>
      </div>

      {/* 筛选器 */}
      <Segmented
        value={filter}
        onChange={(v) => setFilter(v as FilterType)}
        options={[
          { label: '全部', value: 'all' },
          { label: '文档', value: 'document' },
          { label: '图片', value: 'image' },
        ]}
      />

      {/* 结果列表 */}
      <div className="results-list">
        {filteredResults.map((result, index) => (
          <ResultCard key={index} result={result} />
        ))}
      </div>
    </div>
  )
}

const ResultCard: React.FC<{ result: UnifiedSearchResult }> = ({ result }) => {
  const isDocument = result.source_type === 'document'

  return (
    <Card
      className={`result-card ${isDocument ? 'document' : 'image'}`}
      title={
        <span>
          {isDocument ? <FileTextOutlined /> : <PictureOutlined />}
          <Tag color={isDocument ? 'blue' : 'green'}>
            {isDocument ? '文档' : '图片'}
          </Tag>
        </span>
      }
    >
      <div className="result-content">{result.content}</div>
      {result.source && (
        <div className="result-source">来源: {result.source}</div>
      )}
      {result.ocr_text && (
        <div className="result-ocr">
          <strong>OCR文字:</strong> {result.ocr_text}
        </div>
      )}
    </Card>
  )
}

export default UnifiedSearchPanel
```

## 8. 风险评估

### 8.1 技术风险

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|----------|
| 搜索性能下降 | 两个库并行检索可能增加延迟 | 中 | 添加缓存、分页、异步加载 |
| 数据不一致 | 两个库更新时机不同步 | 低 | 保持独立更新，不做同步 |
| API 响应格式变化 | 前端需要适配 | 中 | 保持响应格式稳定，版本化 |

### 8.2 功能风险

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|----------|
| 图片无法展示 | 用户看不到原图 | 高 | 后续实现图片持久化 |
| PDF 内嵌图片处理 | 可能与文档文本重复 | 中 | 文档标注来源避免混淆 |

### 8.3 后续优化方向

1. **图片持久化存储**: 将上传的图片保存到本地，修改 `image_path` 指向真实路径
2. **混合重排序**: 使用统一的重排序模型对文档和图片结果联合排序
3. **缓存机制**: 缓存高频查询结果，提升响应速度
4. **分页加载**: 支持大量结果的分页加载
