# 计划：增加文件类型输入支持

## 目标

扩展 RAG 系统支持的文件类型：
- 新增：doc/docx, html/htm, png/jpg/jpeg, ppt/pptx, csv/xls/xlsx, json/jsonl

## 详细步骤

### 阶段一：后端核心实现

1. **修改 `src/rag_api/routes.py`**
   - 第 296 行：更新 `allowed_extensions` 列表
   - 第 400 行：更新 `supported_extensions` 元组

2. **修改 `src/knowledge_base.py`**
   - 在 `ingest()` 方法中添加 8 种新文件类型的 elif 分支（docx/doc, html/htm, pptx/ppt, xlsx/xls, csv, json, jsonl, png/jpg/jpeg）
   - 新增 `csv_to_markdown()` 方法
   - 新增 `json_to_text()` 方法
   - 新增 `jsonl_to_text()` 方法
   - 新增 `image_ocr_to_text()` 方法（复用 EasyOCREngine）

3. **后端验证**
   - 启动 FastAPI 服务
   - 使用 curl 测试每种文件类型的 `/api/rag/ingest` 接口

### 阶段二：前端适配

4. **修改 `frontend/src/components/knowledge/FileUploader.tsx`**
   - 更新 `input.accept` 属性，添加新文件类型

5. **前端验证**
   - 测试每种文件类型的上传流程

### 阶段三：文档更新

6. **更新 `doc/API接口文档.md`**
   - 在 4.6 节更新 allowed_extensions 说明

## 改动文件清单

| 文件 | 改动类型 |
|------|---------|
| `src/rag_api/routes.py` | 修改 |

## 依赖检查

所有新文件类型处理所需的库均已在 `requirements.txt` 中：
- `unstructured>=0.18.0`（支持 docx/html/pptx/xlsx）
- `easyocr>=1.7.0`（支持图片 OCR）
- Python 内置 `csv`、`json` 模块（无需安装）

## 风险

- `unstructured` 库对旧格式（doc/ppt/xls）解析可能不稳定，需捕获异常
- 大 JSON 文件可能导致内存问题，建议限制文件大小
