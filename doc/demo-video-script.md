# 昇腾AI竞赛智能助教 — 五分钟演示视频录制脚本及操作指南

> **项目名称**：昇腾AI竞赛智能助教（Ascend RAG Assistant）
> **视频时长**：5 分钟（±10 秒容差）
> **目标受众**：大学生竞赛参赛者、高校教师、技术评审、潜在合作方
> **核心价值**：基于 RAG 技术的 7×24 智能问答系统，覆盖 60+ 场主流大学生竞赛

---

## 第一部分：五分钟演示视频录制脚本

## 第二部分：配套操作指南

### 一、录制环境要求

#### 1.1 硬件配置

| 项目 | 最低要求 | 推荐配置 | 说明 |

| **内存** | 16 GB DDR4 | 32 GB DDR4+ | 模型加载和向量数据库运行占用较大内存 |
| **硬盘** | 20 GB 可用空间（SSD） | 50 GB 可用空间（NVMe SSD） | 模型文件约 3-5GB，知识库数据约 2-5GB |
| **显卡** | 集显即可 | NVIDIA GTX 1660+（6GB 显存） | 如需 GPU 加速推理则需要独立显卡 |
| **显示器** | 1920×1080 分辨率 | 2560×1440 或 1920×1080 @125%-150% 缩放 | 录制分辨率基准 |
| **麦克风** | 内置麦克风或 3.5mm 接口麦克风 | USB 电容式降噪麦克风（如 Blue Yeti） | 确保旁白录音清晰 |

#### 1.2 软件环境

| 软件 | 版本要求 | 用途 |
|------|---------|------|
| **操作系统** | Windows 10/11 64-bit（21H2+） | 运行环境 |

#### 1.3 网络环境

- **网络类型**：稳定的宽带网络（建议下行 ≥ 50Mbps）

### 二、屏幕录制参数设置

#### 2.1 OBS Studio 推荐配置（免费方案）

```
【画布/输出分辨率】
  分辨率：1920 × 1080（Full HD）
  帧率（FPS）：30 帧/秒
  
【音频设置】
  采样率：48 kHz
  音频格式：Stereo（立体声）
  麦克风音量：建议 -6 dB 至 -12 dB（避免爆音）
  
【编码器设置】
  编码器：x264（软件编码）或 NVENC（NVIDIA 硬件加速）
  码率（Bitrate）：8000 - 12000 kbps（CBR 或 VBR Quality）
  Rate Control：CBR（固定码率）或 CQP（质量优先，值设为 18-23）
  Profile：High
  Preset（x264）：veryfast 或 faster（平衡编码速度和质量）
  
【高级设置】
  关键帧间隔：2 秒
  色彩空间：Rec.709
  色彩范围：Partial
  
【输出格式】
  容器：MP4（或 MKV 以防录制中断丢失数据）
  音频编码器：AAC，128 kbps，48 kHz
```

#### 2.2 录制区域设定

| 方案 | 适用场景 | 设置方式 |
|------|---------|---------|
| **全屏录制** | 推荐，展示完整界面 | 选择「显示器捕获」或「全屏」 |
| **窗口捕获** | 仅录制浏览器窗口 | 选择「窗口捕获」，选择 Chrome/Edge 窗口，勾选「捕捉光标」 |
| **自定义区域** | 特殊裁切需求 | 使用「游戏捕获」或手动设置区域 |

**强烈建议**：使用 **窗口捕获** 模式，仅录制浏览器窗口，排除桌面任务栏和其他应用的干扰。

#### 2.3 浏览器录制前优化

1. **关闭不必要的浏览器标签页**（减少内存占用和视觉干扰）
2. **按 F11 进入浏览器全屏模式**（隐藏地址栏和书签栏）
3. **或在开发者工具中使用设备模拟器**设置为固定分辨率
4. **关闭浏览器扩展**（尤其是广告拦截、翻译等会在页面注入内容的扩展）
5. **清除浏览器缓存和 Cookie 提示**（避免录制过程中弹出无关通知）

### 三、演示操作步骤规范

#### 3.1 操作速度标准

| 操作类型 | 速度要求 | 说明 |
|---------|---------|------|
| **页面切换/导航点击** | 正常速度，点击后有 0.5-1 秒停顿 | 给观众反应时间 |
| **文字输入** | 中等偏慢，3-4 字/秒 | 模拟真实用户，便于跟读 |
| **按钮点击** | 果断利落，无犹豫 | 展示操作的确定性 |
| **页面滚动** | 平滑匀速，约 200-300 px/秒 | 避免快速抖动 |
| **鼠标移动** | 有目的性的直线/弧线移动 | 避免无意义游走 |
| **等待加载** | 自然等待，不跳切 | 展示真实响应时间 |

#### 3.2 鼠标轨迹规范

**基本规则**：
- **起始位置**：每次操作前，鼠标应有明确的起始位置（通常在上一个操作结束的位置）
- **移动轨迹**：采用 A→B 直线或平滑曲线移动，禁止随机抖动
- **悬停时长**：到达目标元素后停留 0.5-1.5 秒（根据元素重要性调整）
- **点击方式**：使用稳定、果断的单击动作
- **光标样式**：确保系统光标可见，建议使用默认白色/黑色指针

**禁止事项**：
- ❌ 快速来回晃动鼠标（紧张表现）
- ❌ 在屏幕上画圈或无规律移动
- ❌ 操作中途改变目标（犹豫表现）
- ❌ 连续快速多次点击同一位置

#### 3.3 界面切换方式

| 切换类型 | 推荐方式 | 不推荐方式 |
|---------|---------|-----------|
| 页面导航 | 点击左侧菜单项，等待过渡动画完成 | 键盘快捷键（观众看不到触发方式） |
| 弹窗打开 | 点击对应按钮，自然等待动画 | 无 |
| 弹窗关闭 | 点击 X 按钮（明显操作） | 点击遮罩层（不够明确） |
| 详情展开 | 点击「查看」/「展开」按钮 | 双击（不直观） |
| 页面滚动 | 使用鼠标滚轮匀速滚动 | 拖动滚动条（较慢且不平滑） |

#### 3.4 录制前准备工作清单

- [ ] 关闭所有非必要的应用程序和系统通知

### 四、视频后期处理建议

#### 4.1 剪辑标准

| 处理项 | 标准 | 工具/方法 |
|-------|------|----------|
| **片头** | 3-5 秒，含项目 Logo + 名称 + 标语 | 使用 Keynote/Figma 制作静态或简单动画 |
| **片尾** | 3-5 秒，含致谢信息、GitHub 地址、联系方式 | 静态画面即可 |
| **错误片段剪除** | 剪掉所有操作失误、重复尝试、长时间空白等待 | 精确到帧级剪切 |
| **转场效果** | 使用简洁的硬切（Cut）或极短淡入淡出（0.3s） | 避免花哨转场 |
| **节奏把控** | 单个镜头不超过 60 秒无变化 | 必要时插入缩放/高亮强调 |
| **总时长** | 4:50 - 5:10 为合格区间 | 超过 5:20 需要删减 |

#### 4.2 字幕添加规范

**字幕类型选择**：

| 类型 | 场景 | 格式 |
|------|------|------|
| **硬字幕（ burnt-in ）** | 最终发布版本 | 直接渲染进视频画面 |
| **软字幕（ SRT 外挂 ）** | 多语言版本 | 生成 .srt 文件 |

**字幕样式规范**：

```
【字体】思源黑体（Source Han Sans）/ 苹方（PingFang SC）/ Microsoft YaHei UI
【字号】画面高度的 5%（1080p 下约 54 pt）
【颜色】纯白色（#FFFFFF）+ 黑色描边（2px）或半透明黑底
【位置】画面底部居中，距离底边 5%
【每行字数】不超过 20 个汉字
【最长显示时间】单句不超过 7 秒
【同步精度】误差 ≤ 0.3 秒
```

**字幕内容注意事项**：
- 与旁白文案一致，但可根据口语表达做适当调整
- 专业术语保持原文（如 RAG、ChromaDB、BGE 等）
- 数字和单位需清晰可读
- 建议使用剪映专业版的「语音转文字」功能先生成初稿，再人工校对

#### 4.3 高亮与标注（Visual Callouts）

在以下场景建议添加视觉标注：

| 场景 | 标注方式 | 示例 |
|------|---------|------|
| **重要数字** | 圈选/放大 + 浮动标签 | 知识库统计「388 个文档」 |
| **按钮操作** | 鼠标点击光环效果 + 脉冲动画 | 「自动导入知识库」按钮 |
| **功能区域** | 半透明色块框选 + 侧边标签 | AI 引擎控制面板 |
| **数据流转** | 箭头动画 + 渐变线条 | RSS → 知识库的数据流 |
| **关键词** | 文字高亮（黄色背景） | 旁白中提到的专业术语 |

**推荐工具**：
- 剪映专业版：内置丰富的贴纸、特效、高亮功能
- Camtasia：专业的标注和缩放功能
- After Effects：复杂动画效果（如需要）

#### 4.4 背景音乐（BGM）选择

**选择原则**：
- **风格**：轻科技感 / 企业宣传风格 / 轻快积极
- **节奏**：平稳舒缓，不抢夺旁白的注意力
- **音量**：旁白时降至 -20 dB ~ -18 dB（约原音量的 10%），无旁白时可略升至 -12 dB
- **版权**：使用无版权音乐（Royalty-Free）或自行创作

**推荐音乐风格参考**：

| 风格 | 适用段落 | 特征 |
|------|---------|------|
| **Ambient Electronic** | 全程背景 | 轻柔合成器铺底，无突兀鼓点 |
| **Corporate Uplifting** | 开场 + 结尾 | 温暖钢琴 + 轻弦乐，积极向上 |
| **Tech Minimal** | 功能演示段落 | 简洁电子节拍，体现科技感 |
| **Cinematic Build** | AI 问答生成过程 | 渐强氛围，配合期待感 |

**推荐音乐来源**：
- YouTube Audio Library（免费商用）
- Artlist.io / Epidemic Sound（订阅制商用）
- 自行使用 Suno/Udio 生成（注明 AI 生成）

  视频码率：8000 - 10000 kbps（H.264）/ 5000 - 6000 kbps（H.265）

## 第四部分：应急处理预案

| 异常情况 | 处理方案 | 后期补救措施 |
|---------|---------|------------|
| **AI 引擎启动失败** | 检查模型文件是否存在，重新下载；切换至 CPU 模式 | 剪辑时使用预先录制的备用素材或截图配音 |
| **问答响应超时** | 使用更简短的问题；切换至 qwen2-0.5b 轻量模型 | 剪辑加速处理或使用预设好的回答录屏 |
| **知识库导入卡住** | 跳过导入步骤，直接展示已有数据 | 使用已导入状态的录屏片段 |
| **RSS 服务不可用** | 展示离线缓存的文章数据 | 使用预录制的 RSS 页面视频片段 |
| **麦克风噪音** | 检查连接，降低增益，使用降噪滤镜 | 后期使用 Adobe Audition 或 DaVinci 降噪处理 |
| **操作失误（点错/输错）** | 保持冷静，自然纠正后继续 | 剪辑时剪掉失误片段（建议多录一条备用） |
| **超出 5 分钟时限** | 精简各环节的停顿时间，合并相近操作 | 后期加速处理（1.1x - 1.2x）或删除次要展示内容 |
