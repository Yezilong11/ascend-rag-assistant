# 竞赛技能树模块使用说明

## 📖 概述

技能树模块是一个**竞赛学习路径规划工具**，帮助你：

- 📊 **整理知识体系** - 将竞赛涉及的所有技能整理成结构化的技能树
- 🔗 **建立依赖关系** - 明确技能之间的前置/进阶/关联关系
- 🗺️ **自动生成学习路径** - 根据依赖关系自动生成从入门到精通的完整学习路径
- 📈 **跟踪学习进度** - 记录每个技能的完成进度
- ⏱️ **预估学习时间** - 统计整条路径的总学习时间

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 创建技能树 | 为每个竞赛创建独立的技能树 |
| 添加技能节点 | 支持4种难度、4种类型 |
| 建立技能关系 | 支持前置依赖、进阶、关联三种关系类型 |
| 自动生成学习路径 | 基于依赖关系自动生成所有可能的学习路径 |
| 浏览技能列表 | 卡片式展示，按难度着色区分 |
| 学习路径展示 | 展示每条路径的难度和预估学习时间 |
| 删除技能树 | 不需要可以删除 |

## 🚀 快速开始

### 启动准备

确保已启动两个服务：
```bash

```

打开浏览器访问 http://localhost:8501，点击顶部标签 **🌳 技能树** 进入。

## 🔗 关系类型

| 类型 | 说明 |
|------|------|
| `prerequisite` | 前置依赖 - A是B的前置，必须先学A才能学B |
| `related` | 相关 - A和B相关，可以并行学习 |
| `advanced` | 进阶 - B是A的进阶，学会A之后可以学B进阶 |

## ⚠️ 常见问题

### Q: 点击生成学习路径后没有生成任何路径？

**A:** 检查以下几点：
1. **是否至少有一个根技能** - 根技能 = 没有前置依赖的技能。如果所有技能都有前置，就没有起点，无法生成路径。
2. **是否形成了完整链路** - 从根技能开始必须能走到叶子技能（没有子技能的技能）才能生成路径。
3. **是否出现环路** - A→B→C→A 形成循环，算法能处理但不会生成无限路径。

**解决方法**：确保至少有一个技能**没有前置依赖**，这会自动成为根节点，算法从这里开始生成。

### Q: 为什么生成了很多路径？

**A:** 如果技能树有多个根节点或者多个分支，每个不同的组合都会生成一条路径。这是正常的，代表不同的学习路线选择。

### Q: 数据存储在哪里？

**A:** 所有技能树数据以JSON格式存储在 `./skill_tree_data/` 目录中，每个技能树一个文件，可以备份、迁移、编辑。

### Q: 可以修改已创建的技能吗？

**A:** 当前版本不支持直接修改，需要删除后重新添加。后续版本会增加编辑功能。

## 💡 使用建议

1. **自顶向下构建** - 先确定最终要达到的目标，再倒推需要学习哪些前置技能
2. **合理拆分技能** - 不要把整个课程揉成一个大技能，拆分成更小的技能点方便管理
3. **设置合理学习时间** - 根据自己的基础预估学习时间，方便整体规划赛程
4. **利用多种关系** - 除了前置依赖，合理使用"关联"关系表示可并行学习的技能
